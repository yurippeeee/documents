# 24. レビューとチェックリスト — 出す前に、何を確かめるか

> **この章のゴール.**
>
> レビューを「詳しい人に見てもらう会」ではなく、
> **抜けを構造的に潰す工程**として設計できるようになること。
> そして、このシリーズ全体を 1 枚の地図としてまとめること。

## 1. レビューは 3 回に分ける

出図直前に 1 回だけ行うレビューは、**手遅れのレビュー**である。
指摘が出ても直す時間がない。

```fig
p24_timing
```

| 回 | 時期 | 見るもの | 直せるもの |
|---|---|---|---|
| **① 制約レビュー** | 配置の前 | 層構成、外形、機構制約、ネットの分類、コスト目標 | **全部** |
| **② 配置レビュー** | 配線の前 | 部品配置、領域分け、電流の環、熱、実装性 | **配置と配線** |
| **③ 出図レビュー** | 出図の前 | 配線、ベタ、DRC/DFM、出図データ | 配線の一部と出図 |

**① と ② が本体である。** ③ は確認であって、そこで大きな指摘が出るのは失敗である。

> **配置レビューが最も費用対効果が高い.**
>
> 07 章のとおり、配置は後戻りが最も高い工程である。
> **配線を始める前に 30 分のレビューをする**だけで、
> 数日ぶんの手戻りが防げる。
>
> このとき、**まだ配線が引かれていない**ことが重要である。
> 配線済みの基板を見せられると、人は「もう完成している」と感じて、
> 配置への指摘を遠慮してしまう。

## 2. レビューの進め方

```fig
p24_how
```

| 原則 | 内容 |
|---|---|
| **紙のチェックリストを使う** | 記憶に頼らない。抜けは必ず起きる |
| **設計者以外が見る** | 自分の設計の穴は自分では見えない |
| **信号を追う** | 「重要ネットを 1 本ずつ、送信から受信まで指でたどる」 |
| **電流を追う** | 「この電流はどこから来て、どこへ帰るか」を口に出す |
| **指摘は記録して、対応を残す** | 「直した / 直さない（理由）」まで書く |
| **時間を区切る** | 1 回 1 時間。長いレビューは集中力が切れて見落とす |

> **最も効く質問は「この電流はどこを帰りますか」である.**
>
> 08 章の内容を、レビューでは質問の形にする。
>
> - このクロックのリターンはどこを通りますか
> - このビアの近くにリターンビアはありますか
> - このコンデンサの GND は、IC の GND ピンまで何 mm ですか
> - スイッチング電源の入力ループを指でなぞってください
>
> **答えられなければ、そこが穴である。**

## 3. 総合チェックリスト

以下は本シリーズ全体のチェック項目である。
**自分のプロジェクトに合わせて削り、追加して使うこと。**

```fig
p24_map
```

### 制約（① 制約レビュー）

- [ ] 外形・取付穴・部品高さ制限が、**確定した機構図面**に基づいているか（01・07 章）
- [ ] コネクタの位置と向きが筐体と合っているか
- [ ] 層構成が決まり、**メーカの標準構成**から選ばれているか（05 章）
- [ ] 高速・敏感・大電流のネットが分類され、要求が明文化されているか
- [ ] 基板メーカの**製造仕様書**を確認し、設計ルールに反映したか（04 章）
- [ ] コストと納期の目標が共有されているか（23 章）

### フットプリント（06 章）

- [ ] すべてのフットプリントを**データシートと 1 対 1 で照合**したか
- [ ] コネクタのピン番号、1 番ピンの向きを確認したか
- [ ] レジスト開口・ペースト開口・禁止領域・3D 外形が入っているか
- [ ] QFN のサーマルパッドのペースト開口率は 50〜70 % か

### 配置（② 配置レビュー）

- [ ] デカップリングは**電源ピンの直近**にあるか（14 章）
- [ ] スイッチング電源の**入力ループ**が最小か（19 章）
- [ ] ノイズ源と敏感回路が離れているか（07・17 章）
- [ ] 発熱部品が分散し、熱に弱い部品から離れているか（18 章）
- [ ] 部品間隔・基板端の禁止領域・部品高さを満たしているか（21 章）
- [ ] チップ部品の向きが揃っているか（21 章）
- [ ] 基準マーク（フィデューシャル）があるか（21 章）
- [ ] テストポイントの場所が確保されているか（21 章）
- [ ] 配線密度が破綻する箇所がないか（07 章）

### グラウンドと電源（08・13・14 章）

- [ ] **グラウンド面が連続しているか。分割していないか**
- [ ] スリットがある場合、それを横切る信号がないか
- [ ] ビアの列や部品の穴で面が分断されていないか
- [ ] 層を移る高速信号に**リターンビア**があるか（12 章）
- [ ] 電源面の分割線を、その面を基準にする信号が横切っていないか
- [ ] スティッチングビアが λ/20 間隔で入っているか
- [ ] **基板端にビアフェンス**があるか
- [ ] 表層ベタがビアで縫われているか。孤立した銅がないか
- [ ] 電圧降下を計算したか（09 章）

### 配線（09〜12・15・16 章）

- [ ] 電流を流す配線の幅を**温度上昇と電圧降下の両方**で確認したか
- [ ] インピーダンス制御が必要なネットを特定し、線幅を設定したか
- [ ] 差動ペアの間隔が一定で、途中で変わっていないか
- [ ] スキューが規格または $`t_r/10`$ 以内か。補正は**ずれた場所の近く**か
- [ ] クロストーク（3W 以上、クリティカルは 5W）を確認したか
- [ ] クロックが最短・基準面の上・他信号から離れているか
- [ ] 水晶の周りが規定どおりか
- [ ] スタブを作っていないか。ビアスタブが問題になる速度か（12 章）
- [ ] 直列終端抵抗が送信ピンの 5 mm 以内にあるか（10 章）

### 熱（18 章）

- [ ] 発熱の大きい部品のジャンクション温度を見積もったか
- [ ] サーマルビアが**9 本以上**あり、埋めるか塞ぐ指定をしたか
- [ ] 放熱用の銅面が確保されているか

### 製造・実装（20・21 章）

- [ ] DRC が**エラーゼロ**で通っているか（警告も確認したか）
- [ ] アシッドトラップ・細い首・孤立銅・スリバーがないか
- [ ] 銅残り率が層間で大きく偏っていないか（反り）
- [ ] ドリル径の種類を減らしたか
- [ ] シルクがパッドに乗っていないか。線幅・文字高は足りるか
- [ ] 銅から基板端まで 0.3 mm 以上あるか
- [ ] ステンシルの面積比を確認したか（21 章）

### 出図（22 章）

- [ ] **別のガーバービューアで全層を確認**したか
- [ ] 層の対応表を付けたか
- [ ] 裏面が鏡像になっていないか
- [ ] ドリルの単位・桁数・ゼロサプレスが正しいか
- [ ] PTH と NPTH を分けたか
- [ ] 仕様書に材料・銅厚・表面処理・インピーダンス要求を書いたか
- [ ] BOM に**完全な型番**と **DNP** が明記されているか
- [ ] 極性を示す実装図（PDF）を添えたか
- [ ] **基板にリビジョンのシルク**が入っているか

## 4. よくある失敗の上位

現場で繰り返し起きる失敗を、頻度順に並べる。

```fig
p24_top
```

| 順 | 失敗 | 章 |
|---|---|---|
| 1 | **フットプリントの間違い**（ピン配置、寸法、1 番ピン） | 06 |
| 2 | **グラウンドの分断**（分割、ビア列、面の層に配線） | 08 |
| 3 | **デカップリングが遠い** | 14 |
| 4 | **機構との不整合**（コネクタ位置、高さ、取付穴） | 01, 07 |
| 5 | **出図データの不備**（層の取り違え、ドリル設定、DNP 未記載） | 22 |
| 6 | 熱の見積り漏れ | 18 |
| 7 | 基準マーク・テストポイントの欠落 | 21 |
| 8 | 電圧降下の見落とし | 09 |

> **上位 5 つは、すべて「確認すれば防げる」ものである.**
>
> 難しい理論の話ではない。
> **データシートを開く、機構図面を確認する、ビューアで見る**——
> それぞれ 10 分で終わる作業の省略が、基板の作り直しになっている。
>
> **チェックリストは、賢さの代わりではなく、記憶の代わりである。**

## 5. シリーズ全体の地図

```fig
p24_series
```

| 層 | 中身 | 章 |
|---|---|---|
| **物理と製造** | 銅・樹脂・エッチング・めっき・公差。**すべてのルールの根拠** | 01〜04 |
| **骨格** | 層構成・フットプリント・配置・グラウンド。**性能の 8 割** | 05〜08 |
| **配線** | 線幅・インピーダンス・差動・ビア・ベタ・電源 | 09〜14 |
| **効かせる** | クロストーク・高速 IF・アナログ・熱・EMC | 15〜19 |
| **作れる形に** | DFM・実装性・出図・コスト・レビュー | 20〜24 |

**このシリーズを 1 文にまとめるなら、こうなる。**

> **基板アートワークとは、電流が通る道と帰る道を、
> 作れて・載せられて・冷える形で描く仕事である。**

「つなぐ」ことは回路図がすでに終えている。
アートワークが決めるのは、**その電流がどこを通り、どうやって帰るか**であり、
それが寄生成分・波形・放射・温度のすべてを決める。

そして、どれだけ良い設計でも**作れなければゼロ**なので、
製造と実装の制約が、常に同じ重みで隣にある。

上のチェック項目を分野ごとに表示する。
チェックを付けながら、自分の設計に抜けがないかを点検できる。
