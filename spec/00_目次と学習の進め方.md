# 00. 目次と学習の進め方

組み込み機器の開発で書く 2 つの文書、**システム仕様書**（何を作るか）と、その下の**設計書**（どう作るか）の書き方を、一般論と実例で示すシリーズである。一般論の 2 章で、文書の階層、要求文の書き方、要求の割り当て、インタフェース・振る舞い・資源の設計の書き方を、図と値を動かせるデモで示す。実例の 2 章では、同じ型で書いた電池で動く温湿度ロガーの仕様書と設計書を示し、要求の ID が設計と試験までつながる様子を確かめる。

試験の進め方は [ブラックボックステストのシリーズ](../embtest/00_目次と学習の進め方.md)、電池と省電力は [電源と周辺の制御のシリーズ](../periph/00_目次と学習の進め方.md)、タスクとリアルタイム性は [OS のシリーズ](../freertos/00_目次と学習の進め方.md)、BLE と状態機械は [組み込み通信シリーズ](../comm/00_目次と学習の進め方.md) が詳しく扱っているので、このシリーズでは文書に何をどう書くかを中心に書き、技術の中身はリンクする。

## 前提と表記

- 読者は、組み込み機器の開発に加わったことはあるが、仕様書や設計書を自分で書くのは初めての技術者とする。
- 要求の ID は、システムの要求を `SR-` で始め（例 `SR-F03`）、設計の要素を `DS-`、試験を `ST-` で始める。
- 実例の製品・部品・数値は、説明のための架空の例である。規格の値は、それぞれの規格の文書で確かめること。
