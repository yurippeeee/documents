Embedded Circuits

動いて理解する組み込み回路

回路の本には 2 つの型があります。教科書——理想の R・L・C で式は美しいが、実際の基板では通用しない。逆引きレシピ集——「この場合はこの回路」と書いてあるが、なぜそうなのか分からないので少しでも条件が違うと使えない。この全 25 章は、その間を通ります。素子の基礎から、オペアンプ・メモリ・LDO・DC-DC・ADC/DAC といった IC の内部回路までを一本で繋ぎ、「データシートの数値がどこから来るのか」「なぜその失敗が起きるのか」を説明します。全章に、値を動かすと波形と数値が変わるデモ（LIVE・計 46 点）を埋め込みました。

第 I 部 — 電気と素子

ここを飛ばすと以降が全部曖昧になります。とくに「理想の素子は存在しない」という 02 章。

CH 01電圧・電流・抵抗回路を読むための最小限。分圧は「負荷を繋ぐと崩れる」。▶ LIVE CH 02受動素子の実際ESR・ESL・DC バイアス。10 µF が 4 µF になる話。▶ LIVE ×2 CH 03過渡応答とフィルタτ = RC。すべての「なまり」の正体。t_r × f_c ≈ 0.35。▶ LIVE ×3 CH 04ダイオードと PN 接合60 mV で 10 倍。だから並列接続してはいけない。▶ LIVE

第 II 部 — トランジスタ

すべての IC はこの 2 種類でできています。どちらを使うかは「何を作るか」で決まります。

CH 05MOSFET電圧で開閉するスイッチ。ミラープラトーの間に熱が出る。▶ LIVE ×2 CH 06バイポーラと使い分けg_m = I_C/V_T。アナログで BJT が生き残る理由。▶ LIVE ×2

第 III 部 — アナログ IC

負帰還が精度を作り、位相余裕が安定を決める。中を知れば仕様が読めます。

CH 07オペアンプの内部回路差動対 → 利得段 → 出力段。どの段がどの仕様を決めるか。▶ LIVE CH 08応用と現実の制約仮想短絡が破れるところ。容量負荷は最も多い発振原因。▶ LIVE ×3 CH 09コンパレータ・発振・PLL比較する・振らせる・同期させる。水晶の負荷容量。▶ LIVE CH 10リファレンスと温度センサCTAT + PTAT。なぜ 1.2 V なのかには理由があります。▶ LIVE ×2

第 IV 部 — デジタル IC

CMOS は容量を充放電しているだけ。消費電力もタイミングもそこから出ます。

CH 11CMOS ロジックインバータ 1 個からすべてが作られる。P = αCV²f。▶ LIVE ×3 CH 12タイミングと消費電力セットアップは直せる、ホールドは直せない。メタステーブル。▶ LIVE ×2 CH 13メモリ IC の中身SRAM 6T・DRAM 1T1C・NOR/NAND。制約はセルで決まる。▶ LIVE ×3

第 V 部 — 電源 IC

捨てるか（LDO）、運ぶか（DC-DC）。どちらもインピーダンスの設計です。

CH 14LDO の内部回路誤差アンプ + パストランジスタ。ESR 範囲と発振の理由。▶ LIVE ×3 CH 15スイッチングレギュレータボルト秒平衡ですべてが決まる。ホットループが EMI を決める。▶ LIVE ×2 CH 16電源設計の実際デカップリング・シーケンス・保護・熱・電池。▶ LIVE ×2

第 VI 部 — データ変換 IC

アナログとデジタルの境界。入力インピーダンスと基準電圧がすべてです。

CH 17ADC の方式と内部回路SAR / ΔΣ / パイプライン / フラッシュ。整定不足の正体。▶ LIVE ×2 CH 18DAC の方式と内部回路R-2R / 電流セル / ΔΣ / PWM。単調性とグリッチ。▶ LIVE ×2

第 VII 部 — インタフェース

信号は電気である。差動・終端・絶縁で距離とノイズを克服します。

CH 19GPIO とディジタル入出力保護ダイオードが「壊れた」の原因。プルアップの決め方。▶ LIVE CH 20シリアル物理層UART / SPI / I2C / CAN / RS-485 / USB。I2C バスハング。▶ LIVE ×2 CH 21アイソレータとドライバ絶縁の 2 つの目的。CMTI とブートストラップ。▶ LIVE CH 22パワーデバイスとモータH ブリッジ・デッドタイム・電流検出・回生。▶ LIVE

第 VIII 部 — 実装

配線は伝送線路、リターン電流が主役。すべての設計が最後にここで試されます。

CH 23基板とシグナルインテグリティ周波数ではなく t_r で決まる。GND は分割しない。▶ LIVE ×2 CH 24EMC とノイズ対策コモンモードは µA で限度値を超える。落ちる主因はケーブル。▶ LIVE CH 25測定とデバッグ・部品選定グラウンドリードは、ないリンギングを見せる。▶ LIVE
