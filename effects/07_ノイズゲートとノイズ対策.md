# 07. ノイズゲートとノイズ対策 — 弾いていない時間を設計する

> **この章のゴール.**
>
> ノイズゲートの仕組み（スレッショルドとヒステリシス）と副作用を理解し、
> **ゲートで消してよいノイズと、発生源で断つべきノイズ**を区別できるようになること。

## 1. ノイズゲートの仕組み

**ノイズゲート**（noise gate）はコンプレッサーの裏返しで、**スレッショルドより小さい音を通さない**（または大きく減衰する）。
演奏中はノイズが演奏音にマスクされて聞こえないから、**弾いていない瞬間だけ黙らせれば、体感ノイズは激減する**——という発想である。

パラメータはコンプと同族:

- **スレッショルド**: これ以下を閉じる
- **アタック**: 開く速さ（速くしないと音の頭が欠ける）
- **ホールド/リリース**: 閉じるまでの猶予と閉じる速さ（速すぎると余韻がブツ切れ）
- **リダクション量**: 完全に閉じるか、−20 dB 程度に抑えるか

### ヒステリシス — バタつきの防止

閾値が 1 本だと、閾値付近の音量で**開閉が高速に繰り返されてバタバタ鳴る**（チャタリング）。
まともなゲートは「開く閾値」より「閉じる閾値」を数 dB 低く取る（**ヒステリシス**）。開いたら少し粘り、閉じたら少し渋る——リレーやサーモスタットと同じ設計である。

## 2. 副作用 — ゲートは余韻を殺す

ゲートはスレッショルド以下を機械的に切る。つまり、**減衰していく音の最後・ハーモニクスの尻尾・フェードアウト**も切る。
メタルの刻み（ザクザクの隙間を完全な無音にする）では**副作用ごと音楽的な武器**になるが、クリーン系・アンビエント系では余韻が不自然に消える。
「深い歪み + 速いリリース = タイト」「浅い設定 + 遅いリリース = 自然」の間で、ジャンルに合わせて選ぶ。

## 3. どこに入れるか

ノイズの多くは**歪み系で増幅されて**問題になる。基本は:

- **歪みの後ろ、空間系の前**。歪みが持ち上げたノイズを切り、ディレイ/リバーブの余韻はゲートの外に置く（余韻が切られない）
- 4 ケーブル方式のゲート（検出は**ギター直後**の信号で行い、切るのは歪み後）は理想形。検出信号がクリーンなので誤動作が少ない（6 章のサイドチェインと同じ思想）

## 4. そもそものノイズ対策 — 発生源で断つ

ゲートは「隠す」道具であり、ノイズ自体は減っていない。先に発生源を疑う。

| ノイズ | 原因 | 対策 |
|---|---|---|
| ジー（ハム、50/60 Hz とその倍音） | 電源、グラウンドループ（アースの輪）、シングルコイルの誘導 | 電源を1系統に、DC ケーブルの見直し、ハムバッカー/スタックド PU、体の向き |
| サー（ホワイトノイズ） | 高ゲイン回路の宿命、安物バッファ | ゲイン配分の見直し（前段で稼ぎすぎない）、機材の質 |
| ピー/ザザッ（デジタルノイズ） | スイッチング電源、スマホ、照明 | アイソレート電源（19 章）、距離を取る |
| ガリ | ポット/ジャックの接触 | 接点洗浄、修理 |
| ハウリング | アンプ→ギターの音響帰還 | 立ち位置、ゲインを下げる、ピックアップの蝋漬け |

**「ゲートが要るほどのノイズ」はたいてい電源かグラウンドの問題**である。19 章（電源とパッチングの実務）とセットで考える。

## 5. 音作りの勘どころ

- スレッショルドは「**弾かずに待つ → ノイズが消えるギリギリまで上げる → 弾いて余韻が切れないか確認**」の往復で追い込む
- メタルの刻み用は、スレッショルド高め + リリース最速。ゲートのオンオフをリズムの一部にする（ブリッジミュートの隙間が完全な無音になる快感）
- ゲートを深くかけるほど「弾いた瞬間だけ世界が現れる」感覚になる。ロングトーン主体の曲では浅く
- 「サーが気になるからゲート」で解決した気にならず、**ゲイン配分**（どの段で増幅しているか）を一度見直す
