# 02. 音の物理の最小限 — 波形・倍音・dB・エンベロープ

> **この章のゴール.**
>
> 以降の全章で使う 4 つの道具——**波形・スペクトル（倍音）・dB・エンベロープ**——を手に入れること。
> 「歪むと倍音が増える」「フィルタは倍音のバランスを変える」を、絵で説明できるようになること。

## 1. 波形 — 時間軸で見る

音は空気の圧力の波であり、エフェクターの中では**電圧の波形**である。
横軸に時間、縦軸に電圧を取ったグラフが**波形**（waveform）で、オシロスコープで見る形である。

- **周波数**（frequency、Hz）: 1 秒あたりの繰り返し回数。高いほど高い音。ギターの最低音 E は約 82 Hz、A 弦は 110 Hz、1 弦 12 フレットは約 660 Hz
- **振幅**（amplitude）: 波の大きさ。大きいほど大きい音
- **位相**（phase）: 波の「タイミングのずれ」。単体では聞こえないが、**2 つの波を混ぜたときに**山と山なら強め合い、山と谷なら打ち消す。フランジャーとフェイザー（12・13 章）の主役

## 2. 倍音 — 周波数軸で見る

楽器の音は、きれいな正弦波（単一周波数の波）ではない。
110 Hz の A 弦を弾くと、110 Hz（**基音**）に加えて、220、330、440 Hz…という**整数倍の成分**が同時に鳴っている。これが**倍音**（harmonics、高調波）である。

横軸に周波数、縦軸に各成分の大きさを取ったグラフが**スペクトル**（spectrum）で、
**音色の正体は倍音のバランス**である。

- 倍音が少ない → 丸い・柔らかい音（フルート、トーンを絞ったギター）
- 倍音が多い → 明るい・硬い・ギラギラした音（ブリッジ寄りのピッキング、歪んだ音）
- **偶数次倍音**（2、4 倍音…）は 1 オクターブ上・2 オクターブ上なので協和して「豊か」に、**奇数次倍音**（3、5 倍音…）は「硬さ・エッジ」に寄与する——歪み系の音色の違い（4 章）はここに帰着する

```fig
e02_harmonics
```

> **エフェクトの半分は「倍音の操作」である.**
>
> 歪みは倍音を**足す**（4 章）。フィルタと EQ は倍音の**バランスを変える**（8 章）。
> ワウは強調する倍音の場所を**動かす**（9 章）。フェイザーは特定の倍音帯を**打ち消す**（13 章）。
> スペクトルで考える癖をつけると、エフェクトの説明が全部同じ言葉で読めるようになる。

## 3. dB — 大きさの物差し

音量と利得（ゲイン）は **dB**（デシベル）で表す。dB は倍率の対数で、電圧比なら

$$
\text{dB} = 20 \log_{10} \frac{V_{\text{out}}}{V_{\text{in}}}
$$

| dB | 電圧比 | 感覚 |
|---|---|---|
| 0 dB | 1 倍 | 同じ |
| +6 dB | 約 2 倍 | はっきり大きい |
| +12 dB | 約 4 倍 | ブースターの標準的な持ち上げ幅 |
| +20 dB | 10 倍 | クリーンブースターの最大級 |
| −6 dB | 約 1/2 | はっきり小さい |
| −∞ dB | 0 | 無音 |

なぜ対数か——人間の耳は**倍率**で音量を感じるからである。「10 → 20」と「100 → 200」は同じ「倍」に聞こえる。
コンプレッサーのレシオ（6 章）や EQ のブースト量（8 章）は全部 dB で語られるので、**±6 dB = 半分/倍**だけでも体に入れておく。

## 4. エンベロープ — 音量の時間変化

1 つの音の**音量の時間変化**を**エンベロープ**（envelope、包絡線）と呼ぶ。

- **アタック**（attack）: 立ち上がり。ピッキングの「ツン」
- **ディケイ**（decay）: 立ち上がり直後の減衰
- **サステイン**（sustain）: 伸びている部分
- **リリース**（release）: 消え際

ギターの音は「鋭いアタック + 減衰し続けるサステイン」という形をしている。
**コンプレッサー（6 章）はこの形を作り変える道具**であり、エンベロープフィルタ（9 章）はこの形でフィルタを動かす。
「アタックを残す/潰す」「サステインを持ち上げる」という言葉は、全部このグラフの上の操作である。

## 5. フィルタの言葉 — 削る場所の名前

周波数ごとに大きさを変える処理が**フィルタ**（8 章で本格的に扱う）。名前だけ先に。

| フィルタ | 何をする |
|---|---|
| **ローパス**（LPF） | 高域を削る（低域を通す）。トーンツマミの正体 |
| **ハイパス**（HPF） | 低域を削る |
| **バンドパス**（BPF） | ある帯域だけ通す。ワウの正体 |
| **ノッチ** | ある帯域だけ削る。フェイザーの正体 |
| **カットオフ周波数** | 削り始める境目の周波数 |
| **レゾナンス（Q）** | カットオフ付近の強調。ワウの「クセ」の量 |

## 6. 周波数の地図 — ギターの音はどこにいるか

音作りの会話は「○○ Hz あたりを削る」で進む。ざっくりした地図を持っておく。

| 帯域 | 呼び名 | ギター/ベースでは |
|---|---|---|
| 60〜150 Hz | 低域 | ベースの土台。ギターではボワつき（お風呂感）の元 |
| 150〜400 Hz | 中低域 | 厚み。出しすぎると濁る（こもり） |
| 400 Hz〜1 kHz | 中域 | 音の芯。バンドで抜けるかはここ |
| 1〜3 kHz | 中高域 | アタック感、「おいしい」ところ。耳に刺さるのもここ |
| 3〜6 kHz | 高域 | ギラつき、プレゼンス |
| 6 kHz〜 | 超高域 | 空気感。ギターアンプのスピーカーはこの上をほぼ出さない（5 kHz 付近から急落）——**歪みがうるさくならない理由**（4 章） |
