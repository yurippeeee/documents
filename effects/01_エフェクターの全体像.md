# 01. エフェクターの全体像 — 音は電圧の列であり、順番がすべてを変える

> **この章のゴール.**
>
> エフェクターが「電圧の波形を加工する箱」であることを理解し、
> エフェクトの**5 つの系統**と、**つなぎ順の定石とその理由**を説明できるようになること。

## 1. エフェクターは何をしているのか

ギターやシンセの出力は、**電圧の波形**である。
弦の振動をピックアップ（磁石とコイルで振動を電圧に変える部品）が拾うと、数十 mV 程度の交流電圧になり、ケーブルの中を流れていく。

**エフェクター**（エフェクトペダル、effects pedal）は、この電圧の波形を**途中で加工する箱**である。
波形の形を変えれば音色が変わり、大きさを変えれば音量とニュアンスが変わり、時間的にずらしたコピーを混ぜれば空間と厚みが生まれる。
どんなに神秘的に聞こえるエフェクトも、やっていることは**波形に対する数学的な操作**であり、本編はその操作を 1 つずつ開けて見ていく。

```fig
e01_signal
```

## 2. エフェクトの 5 つの系統

エフェクトは無数にあるが、**波形に何をするか**で分類すると 5 系統に整理できる。本編の構成もこれに沿う。

| 系統 | 何をするか | 代表 | 章 |
|---|---|---|---|
| **歪み系**（ゲイン系） | 波形の頭を潰して倍音を足す | ブースター、オーバードライブ、ディストーション、ファズ | 03〜05 |
| **ダイナミクス系** | 音量の変化を制御する | コンプレッサー、リミッター、ノイズゲート | 06〜07 |
| **フィルタ系** | 周波数ごとの大きさを変える | EQ、ワウ、エンベロープフィルタ | 08〜09 |
| **モジュレーション系** | 何かを周期的に揺らす | トレモロ、ビブラート、コーラス、フランジャー、フェイザー、ロータリー | 10〜14 |
| **空間系**（時間系） | 遅らせたコピーを混ぜる | ディレイ、リバーブ | 16〜17 |

これに、**ピッチ系**（15 章。音の高さそのものを操作する）と**飛び道具**（18 章。上のどれにも収まらない変わり種）を加えたものが全体の地図である。

> **分類は「効果」ではなく「仕組み」で覚える.**
>
> コーラスとフランジャーとフェイザーは、耳には似た「うねり」に聞こえるが、
> 仕組みは「遅れの揺れ」「櫛形フィルタの揺れ」「位相の揺れ」で全部違う（11〜13 章）。
> 仕組みで覚えると、「なぜツマミがこう効くのか」「なぜこの順番でつなぐのか」が全部つながる。

## 3. つなぎ順の定石

複数のエフェクターを直列につなぐとき、**順番で音は劇的に変わる**。定石は次の並びである。

```fig
e01_chain
```

| 位置 | 系統 | 理由 |
|---|---|---|
| 1 | **ダイナミクス（コンプ）・フィルタ（ワウ）** | ピッキングの強弱やフィルタの反応は、**歪む前の素直な信号**に対して掛けたい |
| 2 | **歪み系** | 歪みは倍音を足す。前段の情報（強弱・フィルタの動き）に反応させる |
| 3 | **モジュレーション系** | 歪んだ後に揺らすと澄んだうねりになる。歪みの前に置くと揺れごと歪んで濁る（それを狙う流儀もある） |
| 4 | **ディレイ → リバーブ** | 遅らせたコピーは「演奏の響き」なので最後。**歪みの後**に置かないと、響きごと歪んで団子になる |

**なぜこの順か**は、1 つの原理で説明できる。

> **歪みは「後から来たもの全部」をまとめて潰す。**
>
> 歪み（クリッピング、4 章）は波形の大きい部分を潰す**非線形**（重ね合わせが成り立たない）処理である。
> ディレイやリバーブを歪みの前に置くと、原音と響きが**混ざった波形**が潰され、分離できない濁りになる。
> 逆に、コンプやワウは「これから歪む信号の性格づけ」なので前に置く。
> ——定石はあくまで定石で、ファズの前のワウ（ジミ・ヘンドリックス）、歪みの前のディレイ（轟音系）など、**濁りを音色として使う**例外も多い。理由が分かっていれば、例外は「選択」になる。

## 4. 直列と並列、ミックスという考え方

- **直列**（シリーズ）: 信号が順に通る。上の定石の話
- **並列**（パラレル）: 信号を分け、片方だけ加工して**混ぜ直す**。原音の芯を残したまま効果を足せる（ベースの歪み、パラレルコンプ、6 章）
- **ミックス（Dry/Wet）ツマミ**: 多くの空間系・モジュレーション系が内蔵する「原音と効果音の比率」。**並列を 1 つの箱の中でやっている**

エフェクトの内部ブロック図を見ると、ほとんどが「分岐 → 加工 → 混合」の組み合わせでできている。この見方は全章で使う。

```fig
e01_drywet
```

## 5. アナログとデジタル

| | アナログ | デジタル |
|---|---|---|
| 仕組み | トランジスタ・オペアンプ（増幅用の IC）・ダイオード・BBD（遅延素子、11 章）などの**回路**が波形を直接加工 | 波形を数値の列にして（AD 変換）、**計算**で加工し、戻す（DA 変換） |
| 得意 | 歪みの質感、回路の「癖」がそのまま音になる | 長いディレイ、リバーブ、ピッチ、複雑なアルゴリズム、プリセット |
| 代表 | ファズ、オーバードライブ、BBD コーラス | デジタルディレイ、リバーブ、マルチエフェクター、アンプシミュレータ |

本編は「仕組み」を扱うので、両方を対等に説明する。
アナログ回路の癖（ダイオードの曲がり方、BBD の劣化）は、デジタルでは**意図的にモデリング**される——つまり、どちらを使うにしても**仕組みの理解は同じ場所に着地する**。

## 6. ツマミの共通語彙

先に、ほぼすべてのエフェクターに共通するツマミの言葉を押さえる。

| ツマミ | 意味 |
|---|---|
| **Level / Volume / Output** | 出力の音量。エフェクト後の大きさを原音と揃える（またはあえて持ち上げる） |
| **Gain / Drive** | 入力をどれだけ増幅して**回路に突っ込むか**。歪み系では歪みの深さ |
| **Tone** | 高域の量。多くは単純なローパスフィルタ（8 章） |
| **Rate / Speed** | 揺れの速さ（モジュレーション系。LFO の周波数、10 章） |
| **Depth / Intensity** | 揺れの深さ |
| **Mix / Blend** | 原音と効果音の比率 |
| **Feedback / Repeat** | 出力を入力に戻す量（ディレイの繰り返し回数、フランジャーのクセの強さ） |

## 7. 音作りの勘どころ — 最初の 3 原則

各章の「勘どころ」の前提になる、系統を問わない 3 原則。

1. **バイパスと同じ音量から始める**。人間の耳は「大きい音 = 良い音」に錯覚する。Level を揃えてから音色を比べないと、判断を誤る
2. **1 つずつ動かす**。ツマミを同時に回すと、どれが効いたか分からない。極端（最小・最大）を聞いてから中間を探すと、そのツマミの「軸」が早くつかめる
3. **バンドの中で決める**。1 人で弾いて気持ちいい音（低域たっぷり・歪み深め）は、アンサンブルでは埋もれる。ミックスの中で抜ける音は、単体ではやや細く聞こえるくらいが多い
