# 11. コーラス — 揺れる遅延を原音に混ぜる

> **この章のゴール.**
>
> コーラスの構造「**LFO で揺れる 10〜30 ms の遅延 + 原音とミックス**」を理解し、
> なぜ「複数人で弾いているよう」に聞こえるのかを説明できるようになること。
> BBD（アナログ遅延素子）の仕組みと、80s トーンの作り方を知ること。

## 1. 合唱の物理

2 人が同じフレーズを弾くと、どうしても**タイミングと音程がわずかにずれる**。このずれが常に変動することが「厚み」「広がり」の正体である。
**コーラス**（chorus）はこれを 1 台で再現する。

1. 原音を分岐する
2. 片方を **10〜30 ms 遅らせる**（1 人目と 2 人目の弾き始めのずれ）
3. その遅延時間を **LFO でゆっくり揺らす**（10 章のビブラート = 音程のずれの変動）
4. **原音と混ぜる**

つまり「**原音 + 揺れたビブラート**」がコーラスである。10 章の部品がそのまま組み上がっている。


- **Rate**: LFO の速さ。遅い = ゆったりしたうねり、速い = 回転感
- **Depth**: 遅延の揺れ幅 = 音程のずれ幅。深いほど酔う
- **Mix**: 原音との比率。100 % ウェットにするとビブラートに戻る（多くの機種の隠し技）
- **Delay time（プリディレイ）**: 中心の遅延。短い（5〜10 ms）と金属的でフランジャー寄り、長い（20〜30 ms）とダブリング的

## 2. BBD — アナログ遅延の主役

デジタル以前、遅延は **BBD**（Bucket Brigade Device、バケツリレー素子）で作られた。
数百〜数千段のコンデンサの列に電荷を貯め、クロックで**隣へ順送り**する IC である（バケツリレーの名の通り）。

- 遅延時間 = 段数 ÷ クロック周波数。**クロックを LFO で揺らせば遅延が揺れる**——コーラスに最適
- 段を通るたびに信号は劣化する（高域が落ち、ノイズが乗る）。この**劣化こそが「アナログコーラスの温かさ」**の正体で、デジタル機はわざわざ劣化をモデリングする
- クロックのキャリア（数十 kHz）が漏れないよう、前後に急峻なローパスが入る——これも高域が丸くなる一因

BOSS CE-1/CE-2、Electro-Harmonix Small Clone（ニルヴァーナ「Come as You Are」）が BBD コーラスの金字塔である。

## 3. 派生形

| 名前 | 構造 | 音 |
|---|---|---|
| **ステレオコーラス** | 左右で LFO の位相を逆に（または片側ドライ/片側ウェット） | 大きく広がる。モノ再生で消えないかは要確認（10 章） |
| **ディメンション系** | 2 系統の BBD を逆相で揺らして混ぜる（Roland SDD-320 / BOSS DC-2） | 「揺れを感じさせずに広がる」上品なコーラス |
| **トライコーラス** | 3 系統の遅延を別々の LFO で | 分厚い（Strymon 等のモード名） |
| **ビブラート** | 同じ回路の Mix 100 % | 10 章 |
| **ダブラー/ADT** | 揺れの遅い長め遅延（30〜50 ms）+ 少しのピッチ差 | 「もう 1 本録った」感。ボーカルの Automatic Double Tracking 由来 |
| **デチューン** | LFO でなく**固定のピッチずれ**（±5〜15 セント）を混ぜる（15 章のピッチシフタ製） | 揺れないコーラス。12 弦風、ラックの定番 |

## 4. なぜ「クリーンで映える」のか

コーラスの本質は原音と遅延音の**干渉**（周波数ごとの強弱の変動）である。
歪んだ音は倍音が密集しているので、干渉が複雑になりすぎて「シュワシュワ」が濁りに埋もれやすい。
クリーン〜クランチの音は倍音が整理されているので、干渉の動きがきれいに聞こえる。
——深歪み + コーラスをやるなら、**歪みの後ろ**（定石どおり）で薄く。80s メタルのリードは実際この使い方（歪み → コーラス → ディレイ）である。

## 5. 音作りの勘どころ

- **80s クリーン**（The Police、シティポップ）: Rate 遅め（0.3〜0.8 Hz）、Depth 深め、Mix 50 %。アルペジオ + ステレオで決まり
- **Come as You Are**: Rate やや速め・Depth 深めの BBD 系（Small Clone は Depth スイッチ深い側）。クリーン〜軽いクランチ
- **さりげない厚み**: Rate 速め（2〜4 Hz）・Depth 浅め・Mix 30 %。「効いてる」と気づかれない広がり
- **ベースコーラス**: 低域までコーラスすると芯が揺れて気持ち悪い。**低域を原音のまま残す**専用機（BOSS CEB-3 等）か、Mix 低めで
- **ビブラートモード**（Mix100%）はワンポイントのテープ風演出に

## この章のポイント

- コーラス = **原音 + LFO で揺れる 10〜30 ms の遅延**。合唱の「ずれの変動」の再現
- **BBD** はコンデンサのバケツリレー。クロックを揺らして遅延を揺らす。**劣化が「温かさ」の正体**
- Mix 100 % でビブラート、遅延長めでダブラー、固定ピッチ差でデチューン——全部親戚
- 干渉がきれいに聞こえる**クリーン〜クランチで映える**。深歪みには後段で薄く
- Rate/Depth/Mix の 3 点で「80s」「さりげない」「酔う」を作り分ける
