Chapter 08

イコライザとトーン回路 — 倍音のバランスを設計する

この章のゴール.

フィルタの基本形（シェルビング・ピーキング・パス系）と、グラフィック/パラメトリック EQ の使い分けを理解し、 ギター/アンプのトーン回路が何をしているかを説明できるようになること。 「足す前に削る」という EQ の作法を身につけること。

1. EQ はフィルタの詰め合わせ

イコライザ（EQ、equalizer）は、周波数ごとに音量を上げ下げする装置で、中身は 2 章で名前だけ出したフィルタの組み合わせである。

型形使いどころ
シェルビング（棚型）ある周波数から上（下）をまとめて持ち上げ/下げBass / Treble ツマミの正体
ピーキング（山型）ある周波数を中心に山/谷を作る。幅は Q で決めるMid ツマミ、パラメトリック EQ
ハイパス/ローパスある周波数から下（上）を切り落とす不要帯域の掃除

2. グラフィックとパラメトリック

  • グラフィック EQ: 固定の帯域（ギター用は 100〜6.4k を 6〜10 バンド）にスライダーが並ぶ。見た目がそのまま周波数特性。素早い・再現しやすい
  • パラメトリック EQ: 1 バンドごとに周波数・ブースト量・Q を自由に設定。「刺さる 3.2 kHz だけを狭く 4 dB 削る」のような精密作業ができる
  • セミパラメトリック: 周波数とゲインのみ（Q 固定）。ベースプリに多い

グラフィックは「絵を描く」、パラメトリックは「狙撃する」。ライブの足元はグラフィック、ミックスの問題解決はパラメトリック、が典型的な住み分けである。

3. ギターのトーンとアンプのトーンスタック

3.1 ギター本体のトーンツマミ

正体はコンデンサ 1 個のローパスフィルタ。絞るほどカットオフが下がり高域が落ちる。 コンデンサの値（0.022 µF / 0.047 µF）で「絞ったときの暗さ」が変わる——改造の定番ポイント。

3.2 アンプの Bass / Mid / Treble

Fender/Marshall 系アンプのトーン回路（トーンスタック）は、3 つのツマミが相互に干渉する受動回路で、しかも全部 5 でもフラットではない（中域が数 dB 凹むのが標準）。

  • 「Mid を上げる」は実質「Bass/Treble を下げる」に近い動きをする
  • フラットが欲しければ Mid を上げ気味にする
  • ペダルの EQ でアンプの凹みを埋める/深めるのが実戦的な使い方

4. EQ の作法 — 足す前に削る

  1. 削る方が安全: ブーストはヘッドルーム（3 章）を食い、位相も動く。問題の帯域を削る方が副作用が少ない。「こもる → 高域を足す」の前に「200〜400 Hz を削る」を試す
  2. 狭い Q で探して、広い Q で整える: パラメトリックで大きくブーストして周波数を掃くと、問題の帯域が「鳴く」場所で見つかる。見つけたら、カットに転じて Q を適度に緩める
  3. ±3 dB で足りることが多い: EQ は 12 dB も動かす道具ではない（それが要るなら他に原因がある）
  4. バンドの中で決める（1 章）。単体で「良い音」に整えた EQ はミックスで崩れる

5. EQ ペダルの置き場所

位置役割
歪みの前歪み方を変える（低域を削ってタイトに = TS の原理、中域を足してブースト）
歪みの後出来上がった歪みの音色補正（Big Muff のミッド復活、5 章）
チェーン最後段全体のトーン仕上げ、アンプ・箱鳴りの補正
ソロ用スイッチ中域 +3〜4 dB + Level 少しでソロが前に出る（音量だけ上げるより自然）

同じ EQ でも歪みの前後で仕事が別物——1 章・3 章と同じ原理がここでも効く。

6. 重箱の隅 — 変わり種フィルタ

  • ティルト EQ: 1 ツマミで「低域を上げつつ高域を下げる（またはその逆）」シーソー型。音の重心を 1 発で動かす
  • プレゼンス/レゾナンス: アンプのパワー段の帰還をいじる特殊なトーン。スピーカーの共振域（低域）と超高域を制御
  • バリトーン/C スイッチ: ノッチフィルタの切り替えで「鼻づまり」ポジションを作る（Gibson の Varitone）
  • フィクスドワウ（ハーフワウ）: ワウを途中で止めた音 = 強いピーキング EQ。ミッシェル・ガン・エレファント等のギラついた音
  • アイソレータ: DJ 用の 3 バンド「完全カット」EQ。帯域ごとに音を消す演出

7. 音作りの勘どころ

  • こもり取り: 250〜400 Hz を −3 dB。たいていの「なんかモコモコする」はここ
  • 刺さり取り: 2.5〜4 kHz を狭い Q で −3〜6 dB
  • 抜け: 800 Hz〜1.5 kHz を +2〜3 dB（歪みの後ろで）
  • 宅録のアンプっぽさ: ライン録りの歪みに 5 kHz 以上を大胆にローパス（4 章のスピーカーの代役。キャビシミュがあればそちらで）
  • ベースとの住み分け: ギターの 100 Hz 以下はバッサリ切っても、バンドの中では誰も気づかない。ベースの帯域が空いてアンサンブルが締まる
