# 06. コンプレッサー — 音量の時間変化を作り変える

> **この章のゴール.**
>
> コンプレッサーの 5 つのパラメータ（スレッショルド・レシオ・アタック・リリース・メイクアップ）が
> **エンベロープ（2 章）のどこを操作するか**を図で説明でき、
> 「パコパコにする/自然に揃える/サステインを伸ばす」を意図して作り分けられるようになること。

## 1. コンプレッサーは自動音量ツマミである

**コンプレッサー**（compressor）は、**大きい音を自動で下げる**装置である。
中身は「音量を検出する回路（エンベロープフォロワ）」が「音量を変える素子（VCA など）」を操作する自動化されたフェーダーであり、
結果として音量差が**圧縮**され、全体を持ち上げれば「小さい音が持ち上がった」ようにも聞こえる。

## 2. 5 つのパラメータ

| パラメータ | 意味 | 効果 |
|---|---|---|
| **スレッショルド**（threshold） | ここより大きい音だけ圧縮する境目 | 低くするほど広範囲が圧縮される |
| **レシオ**（ratio） | 超えた分を何分の 1 に縮めるか。4:1 なら超過 8 dB → 2 dB に | 大きいほど強い。∞:1 は**リミッター**（それ以上大きくさせない） |
| **アタック**（attack） | 大きい音が来てから**圧縮が効き始めるまで**の時間 | 遅い（20 ms〜）とピッキングの「ツン」が通り抜けて残る。速いと頭から潰れる |
| **リリース**（release） | 音が小さくなってから**圧縮をやめるまで**の時間 | 速いと元気だがパンピング（後述）、遅いと滑らか |
| **メイクアップゲイン**（level） | 圧縮で下がった分を持ち上げる | 「音が太くなった」の多くはこれによる錯覚込み |

**アタックとリリースがエンベロープの彫刻刀**である。

- アタック遅め: 頭のアタックを**残し**、その後を潰す → ピッキングが際立つ「パコパコ」カントリー/ファンクの音
- アタック速め: 頭から潰す → 粒が完全に揃うが、ノペッとする
- リリースをフレーズのテンポに合わせると、圧縮の戻りが呼吸のように聞こえる

```fig

```

## 3. サステインが伸びる仕組み

コンプの効果でよく言われる「伸びる」は、こういうことである。

1. 弾いた瞬間の大きな音を圧縮で下げる
2. メイクアップゲインで全体を持ち上げる
3. すると、**減衰していく後半（もともと小さい音）が持ち上げられて**、聞こえる時間が長くなる

つまり「音を伸ばして」いるのではなく「**消え際を持ち上げて**」いる。ノイズも一緒に持ち上がるので、深いコンプはノイズとの戦いになる（7 章のゲート）。

## 4. 検出と制御の方式 — 質感の出どころ

音量を下げる**素子**の違いが、各機種の質感の違いになる。

| 方式 | 素子 | 特徴 | 代表 |
|---|---|---|---|
| **OTA** | オペレーショナル・トランスコンダクタンス・アンプ | 速く効いてパコッとした質感。ペダルコンプの主流 | MXR Dyna Comp、Ross |
| **オプティカル** | LED/ランプ + 光抵抗（フォトカプラ） | 光抵抗の応答が遅く滑らか。**自然で音楽的** | LA-2A、ペダルでは Diamond 系 |
| **FET** | 電界効果トランジスタ | 極速アタック、攻撃的 | 1176（スタジオの定番） |
| **VCA** | 電圧制御アンプ IC | 正確・クリーン・設定どおり | スタジオ系、ベースコンプ |
| **真空管（バリミュー）** | 真空管の増幅率を変える | 遅く濃厚 | Fairchild 670 |

「Dyna Comp のパコパコ」「オプトの自然さ」は、検出/制御素子の**応答速度のカーブ**の違いがそのまま聞こえているのである。

## 5. 派生と応用

- **リミッター**: レシオ∞。上限を作る安全装置
- **パラレルコンプレッション**: 深く潰した音を**原音と混ぜる**（1 章の並列）。アタックの生々しさと持ち上がった消え際を両取りできる。Blend ツマミ付きコンプはこれを内蔵している
- **サイドチェイン**: 検出回路に**別の信号**を入れる。キックが鳴った瞬間だけベースが下がる「ダッキング」（EDM の脈動）はこれ。検出経路に EQ を入れて「低域に反応しすぎない」ようにするのも同じ思想
- **マルチバンドコンプ**: 帯域を分けて別々に圧縮。ベース・マスタリング用
- **サステイナー系**: ギター用「サステイナー」と呼ばれるペダルの実体はほぼ深めのコンプ

## 6. 音作りの勘どころ

- **カッティング/カントリー**: アタック遅め（20〜30 ms）、レシオ 4:1〜6:1、リリース速め。「パコッ」を残す定番
- **クリーンアルペジオの粒揃え**: アタック速め、レシオ 2:1〜3:1、浅く（下がっても 3 dB 程度）。「効いているか分からないが、切ると寂しい」が正解の深さ
- **ベース**: レシオ 3:1〜4:1、アタック中くらい。ライン録りの定番。ピック弾きはアタック遅めでアタック音を活かす
- **ソロのサステイン**: レシオ高め + メイクアップ多め。ノイズが上がるので、弾かないときの無音管理（ゲート・手元ボリューム）とセットで
- **パンピングに注意**: リリースが速すぎると、音量が波打って「息継ぎ」が聞こえる。気になったらリリースを遅く
- **歪みの前か後か**: 前（定石）はピッキングを揃えてから歪ませる = 歪みの深さが安定。後は歪みのノイズごと持ち上がるので注意。深歪みは自身が強いコンプ効果を持つので、コンプ不要のことも多い

## この章のポイント

- コンプ = **自動音量ツマミ**。スレッショルド超過分をレシオで縮め、メイクアップで持ち上げる
- **アタック/リリースはエンベロープの彫刻刀**。アタック遅め = 頭を残す
- 「伸びる」= 消え際が持ち上がる。ノイズも一緒に上がる
- 質感の違いは制御素子（**OTA / オプト / FET / VCA**）の応答カーブの違い
- パラレル・サイドチェイン・マルチバンドは「分けて・別の信号で・帯域ごとに」の応用
