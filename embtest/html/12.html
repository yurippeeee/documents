Chapter 12

サブGHz・独自無線と SDR — 規格外の電波を捕まえる

この章のゴール.

BLE や Wi-Fi のような「道具が揃った」無線ではなく、サブ GHz 帯（315/433/868/915 MHz など）の 独自プロトコルや、リモコン・センサの生の電波を、SDR（ソフトウェア無線）で観測・解析する 入口をつかむこと。合法性の枠（受信は基本自由、送信は規制）も押さえる。

1. 「規格がない」無線をどう見るか

産業機器・リモコン・気象センサ・独自メッシュなどは、BLE でも Wi-Fi でもないサブ GHz の独自方式を使うことが多い。仕様書がなく、道具も特化していない。ここで武器になるのが SDR（Software Defined Radio、ソフトウェア無線）——電波を可能な限り生のデジタルデータとして取り込み、変調の解読をソフトウェア側で行う受信機である。「アナログの世界（4・7 章）を無線に広げたもの」と考えるとよい。

サブ GHz とは、おおむね 1 GHz 未満の周波数帯（例: 433 MHz、868 MHz、915 MHz）を指す。障害物に強く到達距離が長いので、低速・長距離の IoT でよく使われる。国ごとに使える周波数と出力が法律で決まっている。

2. SDR の道具立て

  • RTL-SDR: 数千円の USB ドングル。受信専用だが入門に最適。約 24〜1700 MHz を聞ける
  • HackRF One / LimeSDR / bladeRF: 送受信できる高機能機（送信は規制対象、後述）
  • ソフト: GQRX／SDR#（スペクトルを眺める）、GNU Radio（信号処理をブロックで組む）、Universal Radio Hacker (URH)（変調・符号化の解析に特化）、rtl_433（既知のサブ GHz センサを自動デコード）

まずは RTL-SDR ＋ rtl_433 で「身の回りのセンサが何を垂れ流しているか」を体験するのが分かりやすい。

rtl_433 -F json           # 対応済みの温湿度計・タイヤ空気圧計などを自動デコードして表示

3. 電波を「見る」— スペクトラムとウォーターフォール

無線観測の基本表示は二つ。

  • スペクトラム: 横軸=周波数、縦軸=強さ。「どの周波数に信号があるか」の瞬間の絵
  • ウォーターフォール: 横=周波数、縦=時間（下へ流れる）、色=強さ。「いつ・どの周波数で・どれだけ」出たかを時間で追える。ボタンを押した瞬間にどこが光るかが見える

対象の周波数（多くは 315/433/868/915 MHz のどれか、機器の技適・FCC 表示や基板の水晶で当たりをつける）にチューニングし、動作させてどこが光るかを探すのが第一歩。

4. 変調を解く — 生の電波から意味へ

信号を見つけたら、それを「意味のあるビット列」に落とす。手順はおおむね:

  1. 変調方式を見分ける: ON/OFF（OOK/ASK、振幅を切る）か、周波数を振る（FSK）か。ウォーターフォールの形で見当がつく
  2. シンボル速度（1 ビットの長さ）を測る: 波形の最短パルス幅から。ロジアナのサンプリング（4 章）と同じ発想
  3. 符号化を解く: マンチェスタ符号、プリアンブル、同期語、長さ、チェックサム
  4. 再現して確かめる: 同じ操作を繰り返し、ビット列のどこが変わるか（ボタン番号、カウンタ、CRC）を差分で突き止める

URH はこの 1〜4 を GUI で支援してくれる（自動でパルス幅を推定し、ビット列を並べ、繰り返し送信を比較できる）。

5. 送信は「規制」— 合法性の線引き

観測（受信）は基本的に自由だが、送信には強い法規制がある。日本では技適、多くの国で同様の認証・帯域・出力の制限がある。テストで能動的に電波を出す（リプレイ、ファジング）場合は:

  • 原則、有線や近接・シールド環境で。電波暗室・シールドボックスに入れて外へ漏らさない
  • 自分の機器・自分の帯域に限る。他者の通信や免許帯を邪魔しない
  • 送信できる SDR（HackRF 等）は強力なので、法令と社内規程を確認してから

本書は観測・受動解析を中心に据える。能動送信テストは、環境と権限が整った場でのみ行うこと。

6. 何をオラクルにするか

  • 出している電波が想定の周波数・帯域幅・タイミングに収まる（余計な放射がない）
  • ペイロードに秘密が平文で乗っていない、リプレイ攻撃に弱くない（毎回同じビット列＝危険、17 章）
  • 動作（ボタン等）と電波が期待どおり対応する
  • 送信出力・デューティが設計・法規の範囲

7. 手を動かす

スペクトラムと変調を読む

この章のポイント

  • 規格外・独自のサブ GHz 無線は SDR（ソフトウェア無線）で生の電波として捕まえる
  • 道具は受信入門の RTL-SDR、送受信の HackRF、解析の URH、自動デコードの rtl_433
  • スペクトラム（周波数×強さ）とウォーターフォール（＋時間）で「どこがいつ光るか」を見る
  • 変調→シンボル速度→符号化→再現差分、の順でビット列の意味を解く
  • 受信は自由、送信は規制。能動テストはシールド環境と法令順守が前提
