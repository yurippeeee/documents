# IIR フィルタを理解するための知識体系 — 目次

IIR（Infinite Impulse Response / 無限インパルス応答）フィルタを「なぜそうなるのか」まで理解するには、
いくつかの土台となる知識を順番に積み上げる必要がある。このフォルダは以下の順で読むことを想定している。

## 学習マップ

```
01 離散時間信号とサンプリング     …「デジタル信号とは何か」
02 複素指数関数とオイラーの公式   …「周波数を扱う数学の道具」
03 LTIシステムと畳み込み          …「フィルタとは数学的に何をするものか」
04 DTFT（離散時間フーリエ変換）   …「周波数特性とは何か」
05 Z変換                          …「IIRを解析する最重要ツール」
06 伝達関数・極と零点・安定性     …「IIRの挙動を決める仕組み」
07 IIRフィルタの基礎              …【本丸】IIRとは何か、FIRとの違い
08 IIRフィルタの設計法            …バタワース、双一次変換など
09 実装構造と数値的な注意点       …直接形、biquad、量子化
```

## 各章の依存関係

- **01 → 02 → 03 → 04** は信号処理全体の共通基盤。
- **05 (Z変換)** は 04 の拡張であり、IIR 解析の中核。ここを飛ばすと IIR は「レシピの暗記」になる。
- **06** で「極が単位円の内側にあれば安定」という IIR 最重要の定理を導出する。
- **07** が IIR 本体。01〜06 の道具をすべて使う。
- **08, 09** は実際に IIR を設計・実装する段階で必要になる。

## この文書群の方針

1. **直感的な理解を最優先** — 各概念に「物理的・図形的なイメージ」を必ず添える。
2. **数式の導出は一切省略しない** — 「〜であることが知られている」で済ませず、途中式をすべて書く。
3. 記号の約束:
   - $`n`$: 離散時間のインデックス（整数）
   - $`x[n]`$: 離散時間信号（角括弧は離散、丸括弧$`x(t)`$は連続）
   - $`j`$: 虚数単位（$`j^2 = -1`$、電気系の慣習に従い$`i`$ではなく$`j`$）
   - $`\omega`$: 正規化角周波数 [rad/sample]、$`\Omega`$: アナログ角周波数 [rad/s]
   - $`f_s`$: サンプリング周波数、$`T = 1/f_s`$: サンプリング周期
