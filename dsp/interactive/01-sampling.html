離散時間信号と
サンプリング

連続する波を一定間隔で「スナップ写真」に撮り、数列に変える——。その一連の考え方を、スライダーを動かし波形が動くのを見ながら体で掴む章です。数式の全文は元のドキュメントに、ここでは「動かして分かる」部分だけを。

§1 — 信号

サンプリング：連続 → 数列

マイクで音を録るとき、空気の振動（連続的な波）を周期 T ごとにパシャパシャと標本化して数値の列にする。この数列が離散時間信号で、サンプル同士の間の時刻には値が存在しない。

x[n] = xa(nT)   ／  fs = 1/T（サンプリング周波数）

下のスコープで fs を上げ下げすると、標本点（●）の密度が変わる。点が粗いほど「間の情報」が失われていく様子が見える。

Scope連続波形を「点」に落とす
連続信号 xa(t)標本列 x[n]
点だけを覚えた数列が離散時間信号。以後のすべての議論はこの「サンプル列」の上で行われる。

§1.2 — 基本信号と分解

インパルス・ステップと「積み木」分解

単位インパルス δ[n] は「時刻0に一発だけ叩く」信号（太鼓を一回ポン）。単位ステップ u[n] は「スイッチを入れっぱなし」。この2つは和と差で表裏一体になっている：

u[n] = ∑k≤n δ[k]  （積分側）  ⟷   δ[n] = u[n] − u[n−1]  （微分側）

そして最重要の式——どんな信号も、各時刻に置いた「高さ違いのインパルス」の寄せ集めに分解できる：

x[n] = ∑k=−∞∞ x[k] · δ[n−k]

下のパネルで「▶ 組み立てる」を押すと、目標の信号（灰の輪郭）が、1個ずつのインパルス（積み木）を足して再現されていく。

Build信号をインパルスで組み立てる
目標 x[n]いま足したインパルス x[k]δ[n−k]組み上がり
この分解の存在意義

ねらいは「たった1回の測定 h[n] から、あらゆる入力への出力を計算できるようにする」こと：

  1. どんな入力もインパルスの寄せ集め ∑ x[k]δ[n−k] に分解できる（この式）
  2. 1発 δ[n] の応答は「指紋」 h[n]
  3. 時不変性で δ[n−k] の応答は h[n−k]
  4. 線形性で足すと出力 = ∑ x[k]h[n−k] = 畳み込み

鐘を一度叩いた“ゴーン”さえ録れば、どんな連打の音も「遅らせて音量を変えたゴーンの足し算」で予測できる。その見方がこの分解。

§2 — 周波数

正規化周波数：1サンプルで何ラジアン回るか

離散の世界では時間の単位が「秒」でなく「サンプル」になる。周波数も正規化して ω = ΩT = 2πf/fs ［rad/sample］で測る。これは「1サンプル進むごとに位相が何ラジアン回るか」。

ω = 0 → 回らない（直流）  ·   ω = π → 半回転＝表せる最速   ·   ω と ω+2π → 区別不能

左の円で回る点（位相子）の実軸への影が、右の cos(ωn) になる。ω を上げていくと点がどんどん速く回る。ω=π でちょうど1サンプルごとに反対側（±1の交互）。さらに上げると——遅い波と見分けがつかなくなる（次節の伏線）。

Phasor回る点の影が余弦になる
「ω+2π を重ねる」を押すと、青（ω+2π）の標本が赤（ω）にぴったり重なる。だから離散の周波数は 2π 周期でしか意味を持たず、見るべきは 0〜π だけ。

§3 — サンプリング定理

エイリアシング（折り返し歪み）

回るタイヤをビデオで撮ると逆回転して見える（ワゴンホイール効果）。速すぎる回転がコマ間隔に対して「遅い回転」と区別できなくなる現象——それがエイリアシング。下のスコープが本題です。

fs = 48 kHz は固定。真の信号周波数 f0 をナイキスト（fs/2 = 24 kHz）を超えて上げると、標本点（●）を通る見かけの低い波（コーラル）が現れ、真の波（薄いティール）と同じ点を共有してしまう。

Alias高い波が低い波に化ける

周波数領域で見るとからくりは明快。サンプリングは元スペクトルのコピーを fs おきに無限に並べる：

Xs(jΩ) = (1/T) ∑k=−∞∞ Xa( j(Ω − kΩs) )  ／  Ωs=2πfs

信号の最高周波数を B とすると、コピー同士が重ならない条件がサンプリング定理 fs > 2B。スライダーで fs を下げてコピーを衝突させてみる。

Spectrumコピーが重なると混ざる
だから A/D 変換の前には必ずアナログのローパス（アンチエイリアシングフィルタ）で B を fs/2 未満に抑えてから標本化する。
