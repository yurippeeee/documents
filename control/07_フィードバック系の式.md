## 1. ブロック線図の結合 — 直列・並列・フィードバック

6 章 1 節で、ブロック線図の箱に伝達関数を書くことにした。箱から出る信号のラプラス変換は、入る信号のラプラス変換に、箱の伝達関数を掛けたものである。制御系は、制御器・制御対象・センサなど、いくつもの箱を矢印でつないだものなので、全体の伝達関数を求めるには、つないだ箱をまとめる規則が要る。この章では、信号はすべてラプラス変換したもの（大文字）で書き、初期値は 0 とする（伝達関数の約束）。

### 3 つの結合

箱のつなぎ方は、次の 3 つの組み合わせでできている。

- **直列結合**: 1 つ目の箱の出力が、そのまま 2 つ目の箱の入力になるつなぎ方。
- **並列結合**: 同じ信号を 2 つの箱に入れ、その出力を加え合わせ点で足し引きするつなぎ方。
- **フィードバック結合**: 箱 $`G`$ の出力を、別の箱 $`H`$ を通して、$`G`$ の入力の前の加え合わせ点へ戻すつなぎ方。戻した信号を引くものを**負帰還**、足すものを**正帰還**という。

それぞれを 1 つの箱にまとめたときの伝達関数を求める。

**方針**: 箱と箱の間の信号に名前を付けて、箱ごと・加え合わせ点ごとの式を書き、間の信号を消して、出力 $`Y`$ を入力 $`U`$ だけで表す。

**導出**: 直列結合では、間の信号を $`X`$ とすると $`X = G_1U`$、$`Y = G_2X`$ で、$`X`$ を消すと $`Y = G_2G_1U`$ である。並列結合では、2 つの箱の出力が $`G_1U`$ と $`G_2U`$ なので、$`Y = G_1U \pm G_2U = (G_1 \pm G_2)U`$ である。負帰還では、加え合わせ点の出力を $`E`$ とすると $`E = U - HY`$、$`Y = GE`$ である。2 つ目の式に 1 つ目を入れると $`Y = GU - GHY`$ で、$`Y`$ の項を左辺に移すと $`(1 + GH)Y = GU`$ となる。両辺を $`1 + GH`$ で割ると $`Y/U = G/(1 + GH)`$ である。正帰還では $`E = U + HY`$ なので、同じ手順で $`(1 - GH)Y = GU`$ となる。まとめると

$$
\text{直列: } G_1G_2, \qquad \text{並列: } G_1 \pm G_2, \qquad \text{負帰還: } \frac{G}{1 + GH}, \qquad \text{正帰還: } \frac{G}{1 - GH}
$$

である ∎

直列の掛け算の順は入れ替えてよい（入力 1 つ・出力 1 つの伝達関数は、数と同じく、掛ける順によらない）。負帰還の形は「入力から出力へ進む道の伝達関数 ÷ (1 ＋ 輪を一周する伝達関数)」と読める。例の対象で確かめる。

- 直列: 2 章 3 節のモータの電圧から角速度までの一次遅れ $`K/(Ts + 1)`$ に、角速度から角度までの積分 $`1/s`$（5 章 3 節）をつなぐと、$`K/\{s(Ts + 1)\} = 1000/\{s(s + 20)\}`$ rad/V になる（6 章 1 節の表の値）。
- 並列: 6 章 5 節のボイラの水位は、速く逆向きに効く $`-K_1/(T_1s + 1)`$ と、水がたまる $`K_2/s`$ の並列結合で、通分すると $`\{(K_2T_1 - K_1)s + K_2\}/\{s(T_1s + 1)\}`$ になる。
- 負帰還: 5 章 3 節の図の (a) の一次遅れの線図は、$`1/T`$ と積分 $`1/s`$ の直列 $`1/(Ts)`$ を、$`H = 1`$ で負帰還させたものである。$`(1/(Ts))/\{1 + 1/(Ts)\}`$ の分母と分子に $`Ts`$ を掛けると $`1/(Ts + 1)`$ になり、前に $`K`$ を直列につなぐと一次遅れ $`K/(Ts + 1)`$ を得る。正帰還にすると $`1/(Ts - 1)`$ で、極 $`+1/T`$ が右半平面に出て、不安定になる（6 章 4 節）。

### 等価変換

3 つの規則は、箱が隣り合っているときにしか使えない。箱と箱の間に、別の矢印が出入りする加え合わせ点や引き出し点があるときは、先にそれを動かす。入力から出力までの関係を変えずに線図の形を書き換えることを、線図の**等価変換**という。よく使うのは次の 4 つである。

1. 加え合わせ点を箱の出力側へ移す: もう一方の入力にも、同じ箱を掛ける（$`Y = G(U_1 + U_2) = GU_1 + GU_2`$）。
2. 加え合わせ点を箱の入力側へ移す: もう一方の入力に $`1/G`$ を掛ける（$`Y = GU_1 + U_2 = G(U_1 + U_2/G)`$）。
3. 引き出し点を箱の出力側へ移す: 取り出す信号に $`1/G`$ を掛ける（取り出したいのは $`U = Y/G`$）。
4. 引き出し点を箱の入力側へ移す: 取り出す信号に $`G`$ を掛ける（取り出したいのは $`Y = GU`$）。

$`1/G`$ の箱は、計算のための書き換えで、実際に作る必要はない。続けて並んだ加え合わせ点は、足し引きの順を入れ替えてよい（足し算の順序によらないため）。

### 例: 台車とばね・ダンパをまとめる

2 章 2 節の台車の式 $`m\ddot p + c\dot p + kp = u`$ を $`m\ddot p = u - c\dot p - kp`$ と書き、加速度 $`\ddot p`$ を積分すると速度 $`\dot p`$、速度を積分すると位置 $`p`$ になる順に箱を並べると、下の図の ① の線図になる。速度からダンパの力 $`c\dot p`$ を、位置からばねの力 $`kp`$ を取り出して戻す、2 つの輪がある。内側の輪から順にまとめる。

```fig
e07_msd_reduce
```

① の $`1/m`$ と $`1/s`$ の直列で $`1/(ms)`$ になり、② で内側の輪（$`H = c`$）を負帰還の式でまとめると $`1/(ms + c)`$ になる。これは 2 章 1 節の、ばねの無い台車の速度の式 $`m\dot v + cv = u`$（$`v = \dot p`$）の伝達関数である。③ で $`1/s`$ と直列にし、④ で外側の輪（$`H = k`$）をまとめると

$$
\frac{1/\{s(ms + c)\}}{1 + k/\{s(ms + c)\}} = \frac{1}{ms^2 + cs + k}
$$

となる（分母と分子に $`s(ms + c)`$ を掛けた）。例の値で $`1/(s^2 + 2s + 25)`$ m/N で、6 章 1 節の表の伝達関数と一致する。2 階の式の 2 つの係数 $`c`$ と $`k`$ は、それぞれ速度と位置を戻す輪から来ている。

### 入力が 2 つあるとき

2 章 3 節の DC モータ（巻線のインダクタンス $`L_\mathrm{a}`$ を含む）には、電圧 $`v`$ と負荷トルク $`\tau_\mathrm{L}`$ の 2 つの入力がある。線図は線形なので、片方の入力を 0 として、もう片方からの伝達関数をそれぞれまとめ、足せばよい（2 章 1 節の重ね合わせの原理）。

- $`\tau_\mathrm{L} = 0`$ のとき: 電気の箱 $`1/(L_\mathrm{a}s + R_\mathrm{a})`$、トルク定数 $`K_\mathrm{t}`$、機械の箱 $`1/(Js)`$ の直列が、逆起電力の箱 $`K_\mathrm{t}`$ で負帰還されているので、$`\Omega_\mathrm{m}/V = K_\mathrm{t}/(L_\mathrm{a}Js^2 + R_\mathrm{a}Js + K_\mathrm{t}^2)`$ になる。例の値で $`2 \times 10^6/(s^2 + 2000s + 40000)`$ で、6 章 1 節の伝達関数と一致する。
- $`v = 0`$ のとき: $`\tau_\mathrm{L}`$ から $`\omega_\mathrm{m}`$ へ進む道は $`-1/(Js)`$ だけで、輪は同じ逆起電力の輪なので、$`\Omega_\mathrm{m}/T_\mathrm{L} = -(L_\mathrm{a}s + R_\mathrm{a})/(L_\mathrm{a}Js^2 + R_\mathrm{a}Js + K_\mathrm{t}^2)`$（$`T_\mathrm{L}`$ は $`\tau_\mathrm{L}`$ の変換）になる。$`s = 0`$ では $`-R_\mathrm{a}/K_\mathrm{t}^2`$ = −5000 (rad/s)/(N·m) で、2 章 3 節の一次の式の負荷トルクの係数と同じである。

2 つの伝達関数の分子は違うが、分母は同じである。分母は輪で決まり、入力がどこから入るかによらない。2 節で、このことをフィードバック系について一般に示す。

## 2. 閉ループ伝達関数と一巡伝達関数

### フィードバック系の基本の形

1 章 4 節の比例制御の線図を、伝達関数で描き直す。制御器の伝達関数を $`C(s)`$、制御対象の伝達関数を $`P(s)`$ と書く。偏差から制御器が操作量を決め、操作量に外乱が加わって制御対象に入り、制御量を測ったときに観測ノイズが加わる。センサは制御量を遅れなく測る（伝達関数 1）とする。外乱 $`d`$ は、操作量と同じ向きに働く向きを正とし、加え合わせ点で足す。1 章の上り坂の力は台車を後ろへ引くので、この向きでは $`d`$ = −0.513 N である（1・3 章では、後ろ向きを正として 0.513 N と書いた）。

```fig
e07_loop
```

**方針**: 目標値 $`R`$・外乱 $`D`$・観測ノイズ $`N`$ の 3 つの入力を同時に考え、加え合わせ点ごとに式を書いて、$`Y`$ について解く。

**導出**: 偏差は目標値から測った値を引いた $`E = R - (Y + N)`$、操作量は $`U = CE`$、制御対象の入力は $`U + D`$ なので

$$
Y = P(U + D) = PC(R - Y - N) + PD
$$

である。$`Y`$ の項を左辺に集めると $`(1 + PC)Y = PCR + PD - PCN`$ で、両辺を $`1 + PC`$ で割って

$$
Y(s) = \frac{P(s)C(s)}{1 + P(s)C(s)}R(s) + \frac{P(s)}{1 + P(s)C(s)}D(s) - \frac{P(s)C(s)}{1 + P(s)C(s)}N(s)
$$

となる。偏差も $`E = R - Y - N`$ にこれを入れて整理すると、$`E = (R - N)/(1 + PC) - PD/(1 + PC)`$ である ∎

フィードバックの輪を閉じたまま、輪の外から入る信号（目標値・外乱・観測ノイズ）から、輪の中の信号（制御量・偏差・操作量）までの伝達関数を、**閉ループ伝達関数**という。目標値から制御量までを $`G_{yr}(s)`$、外乱から制御量までを $`G_{yd}(s)`$ と書く。

$$
G_{yr}(s) = \frac{P(s)C(s)}{1 + P(s)C(s)}, \qquad G_{yd}(s) = \frac{P(s)}{1 + P(s)C(s)}
$$

観測ノイズから制御量までの伝達関数は $`-G_{yr}(s)`$ で、目標値のものと符号だけが違う。加え合わせ点では、目標値から $`y + n`$ を引くので、制御器から見ると、観測ノイズ $`n`$ は、目標値が $`-n`$ だけずれたことと区別がつかないからである（6 節で使う）。

### 一巡伝達関数と閉ループの特性方程式

輪を 1 か所で切り、切り口の片側に信号を入れたとき、輪を一周して切り口のもう片側に戻ってくるまでの伝達関数を、**一巡伝達関数**という。加え合わせ点の − の符号は含めない。上の図の (b) のとおり、この線図では $`P(s)C(s)`$ である（センサに伝達関数 $`H(s)`$ があれば $`P(s)C(s)H(s)`$）。このシリーズでは、一巡伝達関数に新しい文字を置かず、$`P(s)C(s)`$ と書く。

閉ループ伝達関数は、どれも分母が $`1 + P(s)C(s)`$ である。1 節の負帰還の式の「$`1 +`$ 輪を一周する伝達関数」が、どの入力から見ても同じ輪だからである。閉ループ伝達関数の極を**閉ループの極**、一巡伝達関数の極を**開ループの極**という。閉ループの極は

$$
1 + P(s)C(s) = 0
$$

の根である。この式を、このフィードバック系の（閉ループの）**特性方程式**という。4 章 2 節の特性方程式は 1 つの微分方程式について決めたものだった。2 つの関係を確かめる。

**方針**: $`P`$ と $`C`$ を分母と分子の多項式で書き、閉ループ伝達関数を 1 つの多項式の分数にする。それを微分方程式に戻したときの特性方程式と比べる。

**導出**: $`P = N_\mathrm{P}/D_\mathrm{P}`$、$`C = N_\mathrm{C}/D_\mathrm{C}`$（$`N`$ は分子、$`D`$ は分母の多項式）とおく。$`G_{yr}`$ の分母と分子に $`D_\mathrm{P}D_\mathrm{C}`$ を掛けると

$$
G_{yr}(s) = \frac{N_\mathrm{P}N_\mathrm{C}}{D_\mathrm{P}D_\mathrm{C} + N_\mathrm{P}N_\mathrm{C}}
$$

である。$`1 + PC = 0`$ の分母を払った $`D_\mathrm{P}D_\mathrm{C} + N_\mathrm{P}N_\mathrm{C} = 0`$ の根が、閉ループの極である。6 章 1 節のとおり、伝達関数の分母の $`s^i`$ を $`i`$ 回の微分に戻すと、目標値から制御量までの微分方程式の左辺になり、その特性方程式（4 章 2 節）は、分母の $`s`$ を $`\lambda`$ に置き換えて 0 とおいたものである。したがって、閉ループの特性方程式は、ループ全体を 1 つの微分方程式にまとめたときの特性方程式と同じである ∎

4 章 6 節のモータの位置の比例制御では、$`P = K/\{s(Ts + 1)\}`$、$`C = K_\mathrm{P}`$ なので、$`D_\mathrm{P}D_\mathrm{C} + N_\mathrm{P}N_\mathrm{C} = s(Ts + 1) + KK_\mathrm{P} = Ts^2 + s + KK_\mathrm{P}`$ で、4 章 6 節で微分方程式から作った特性方程式 $`T\lambda^2 + \lambda + KK_\mathrm{P} = 0`$ と同じである。ただし、$`P`$ の極と $`C`$ の零点が同じ値で約分されると（6 章 6 節の極零相殺）、約分した $`PC`$ からはその極が見えなくなる。閉ループの極は、約分する前の $`D_\mathrm{P}D_\mathrm{C} + N_\mathrm{P}N_\mathrm{C}`$ から求める。

- 同じ制御で $`L_\mathrm{a}`$ を含めたもの（6 章 4 節）: 1 節の $`\Omega_\mathrm{m}/V`$ に $`1/s`$ を直列につないだものが $`P`$ で、閉ループの特性方程式は、$`L_\mathrm{a}J`$ で割ると $`s^3 + 2000s^2 + 40000s + 2 \times 10^6K_\mathrm{P} = 0`$ になる。

## 3. 定常偏差と制御系の型

1 章 4 節では、十分に時間がたった後に残る偏差（定常偏差）を、力の釣り合いから求めた。2 節の式で外乱と観測ノイズを 0 とすると、偏差のラプラス変換は

$$
E(s) = \frac{1}{1 + P(s)C(s)}R(s)
$$

である。ここから、5 章 5 節の最終値の定理 $`\lim_{t\to\infty}e(t) = \lim_{s\to 0}sE(s)`$ で定常偏差を求める。この定理が使えるのは、$`sE(s)`$ の分母の根の実部がすべて負のときだった。$`sE(s) = sR(s)D_\mathrm{P}D_\mathrm{C}/(D_\mathrm{P}D_\mathrm{C} + N_\mathrm{P}N_\mathrm{C})`$ の分母の根は、閉ループの極と、$`sR(s)`$ に残る根である。以下、閉ループは安定（閉ループの極がすべて左半平面にある）とする。

### 型 — ループの中の積分の数

一巡伝達関数を、原点の極（積分 $`1/s`$）を外に出して

$$
P(s)C(s) = \frac{1}{s^N}G_0(s) \qquad (G_0(0)\ \text{は 0 でも無限大でもない})
$$

と書いたときの $`N`$、つまり一巡伝達関数の原点にある極の数を、そのフィードバック系の**型**という（制御系の型。$`N`$ = 0 なら型 0、1 なら型 1）。台車の速度の比例制御は $`P(s)C(s) = KK_\mathrm{P}/(Ts + 1)`$ で型 0、モータの位置の比例制御は $`KK_\mathrm{P}/\{s(Ts + 1)\}`$ で、角速度を角度にする積分を 1 つ含むので型 1 である。

目標値を時刻 0 に 0 から 1 へ変える単位ステップに対する定常偏差を**定常位置偏差**、時刻 0 から 1 秒に 1 ずつ増える単位ランプ $`r = t`$ に対する定常偏差を**定常速度偏差**という。目標値が一定の位置にとどまるか、一定の速さで動くかに対応した名前で、制御量が位置でなくても（台車の速度でも）この名前で呼ぶ。

**方針**: $`E(s)`$ に単位ステップ $`1/s`$ と単位ランプ $`1/s^2`$（5 章 2 節）を入れて最終値の定理を使い、$`P(s)C(s) = G_0(s)/s^N`$ の $`N`$ で場合を分ける。

**導出**: 単位ステップでは $`sE(s) = 1/\{1 + P(s)C(s)\}`$ で、$`s`$ が 0 に近づくとき、$`N`$ = 0 なら $`P(s)C(s)`$ は $`G_0(0)`$ に近づき、$`N \ge 1`$ なら限りなく大きくなる。したがって定常位置偏差は、$`N`$ = 0 で $`1/\{1 + G_0(0)\}`$、$`N \ge 1`$ で 0 である。

単位ランプでは $`sE(s) = 1/[s\{1 + P(s)C(s)\}] = 1/\{s + sP(s)C(s)\}`$ で、$`sP(s)C(s) = G_0(s)/s^{N-1}`$ である。$`N`$ = 1 なら分母は $`G_0(0)`$ に近づき、定常速度偏差は $`1/G_0(0)`$ である。$`N \ge 2`$ なら分母は限りなく大きくなり、0 である。$`N`$ = 0 なら分母は 0 に近づき、$`sE(s)`$ の分母に $`s = 0`$ の根が残るので、最終値の定理は使えない。このとき $`E(s) = 1/[s^2\{1 + P(s)C(s)\}]`$ を部分分数に分けると $`1/[\{1 + G_0(0)\}s^2]`$ の項が残り、偏差は $`t/\{1 + G_0(0)\}`$ に近づいて増え続ける ∎

まとめると、$`\lim_{s\to 0}`$ を使って次の表になる。

| 型 | 定常位置偏差 | 定常速度偏差 |
|---|---|---|
| 0 | $`1/\{1 + \lim_{s\to 0}P(s)C(s)\}`$ | 増え続ける |
| 1 | 0 | $`1/\lim_{s\to 0}sP(s)C(s)`$ |
| 2 以上 | 0 | 0 |

### 例の値

制御器に、偏差を時間で積分した値に比例する操作量を足すと、$`C(s) = K_\mathrm{P} + K_\mathrm{I}/s`$ となり（$`K_\mathrm{I}`$ は積分した偏差に掛ける係数。10 章 2 節で I 動作として詳しく扱う）、ループに積分が 1 つ増えて型が 1 つ上がる。例の対象の 4 つの組み合わせで、実際の値を求める（値はどれも例の値）。

|---|---|---|---|---|
| 0 | 台車の速度、$`K_\mathrm{P}`$ = 8 N/(m/s) | $`4/(0.5s + 1)`$ | 1/(1 + 4) = 0.2 m/s | 毎秒 0.2 m/s ずつ増える |
| 1 | モータの位置、$`K_\mathrm{P}`$ = 0.21 V/rad | $`10.5/\{s(0.05s + 1)\}`$ | 0 | 1/10.5 = 0.0952 rad |
| 1 | 台車の速度、$`K_\mathrm{P}`$ = 8 N/(m/s)、$`K_\mathrm{I}`$ = 25 N/m | $`(4s + 12.5)/\{s(0.5s + 1)\}`$ | 0 | 1/12.5 = 0.08 m/s |
| 2 | モータの位置、$`K_\mathrm{P}`$ = 0.21 V/rad、$`K_\mathrm{I}`$ = 0.5 V/(rad·s) | $`(10.5s + 25)/\{s^2(0.05s + 1)\}`$ | 0 | 0 |

### 積分が偏差を 0 にする理由

最終値の定理の結果を、落ち着いたときのループの中の信号で確かめる。

```fig

```

- (a) 型 0（台車の速度、目標値 1 m/s）: 速度を 0.8 m/s に保つには、抵抗と釣り合う押す力 $`y/K`$ = 1.6 N が要る。比例制御は、その力を偏差に $`K_\mathrm{P}`$ を掛けて作るので、偏差は 1.6 ÷ 8 = 0.2 m/s 残る。1 章 4 節の「抵抗に打ち勝つ力そのものを、偏差から作らなければならない」の、伝達関数での言い方が $`1/\{1 + G_0(0)\}`$ である。
- (b) 型 1（モータの位置、目標値を 1 rad/s で回す）: 角度が 1 rad/s で増え続けるには、角速度 1 rad/s を保つ電圧 1/50 = 0.02 V が要り、その電圧を偏差から作るので、偏差は 0.02 ÷ 0.21 = 0.0952 rad になる。目標値が止まっていれば、要る電圧は 0 なので、偏差も 0 である。

ループの中の積分は、入力が 0 でも、それまでにためた値を出し続ける。要る信号（角度・電圧）を積分が保つので、偏差が 0 のまま落ち着ける。積分が無いと、要る信号は偏差から作るしかなく、その分の偏差が残る。

1 章で決めた力 $`u_0 = cr`$ を足したのは、要る力 $`cr`$ を、偏差からではなく目標値から前もって作ったことにあたる。2 節で計算したとおり、これで平らな道の定常偏差は 0 になる。ただし、対象の本当の $`c`$ が、決めた力に使った値と違うと偏差が残る（5 節）。目標値から操作量を前もって決める方法は、14 章で扱う（[14 章 2 節](14_フィードフォワードとカスケード.md#目標値のフィードフォワード-モデルの逆で先回りする)）。

## 4. 外乱を抑える — 入る場所と積分の働き

### 入る場所と伝達関数

外乱には、操作量に加わるもの（台車を引く坂の力、モータの軸にかかる負荷トルク）と、制御量に直接加わるものがある。例えば、台車が動く歩道に乗ると、地面から見た速度に歩道の速さがそのまま足される。モータと負荷をつなぐ継ぎ手（カップリング）が滑ると、負荷の角度だけが急にずれる。操作量に入る外乱から制御量までの伝達関数は、2 節の $`G_{yd}(s) = P(s)/\{1 + P(s)C(s)\}`$ である。制御量に入る外乱では $`Y = PU + D`$ なので、2 節と同じ手順で、外乱から制御量までの伝達関数は $`1/\{1 + P(s)C(s)\}`$ になる。

```fig
e07_dist_place
```

一定の外乱（大きさ $`d`$ のステップ）が入って落ち着いたときの、制御量のずれを求める。

**方針**: 最終値の定理で、外乱からの伝達関数の $`s = 0`$ の値を求める。対象の積分と制御器の積分を区別するため、$`P(s) = G_\mathrm{P}(s)/s^{N_\mathrm{P}}`$、$`C(s) = G_\mathrm{C}(s)/s^{N_\mathrm{C}}`$（$`G_\mathrm{P}(0)`$ と $`G_\mathrm{C}(0)`$ は 0 でも無限大でもない）と書く。型は $`N = N_\mathrm{P} + N_\mathrm{C}`$ である。閉ループは安定とする。

**導出**: 制御量に入る外乱では、ずれは $`\lim_{s\to 0}d/\{1 + P(s)C(s)\}`$ で、3 節の定常位置偏差と同じく、$`N`$ = 0 なら $`d/\{1 + G_\mathrm{P}(0)G_\mathrm{C}(0)\}`$、$`N \ge 1`$ なら 0 である。操作量に入る外乱では、分母と分子に $`s^{N_\mathrm{P} + N_\mathrm{C}}`$ を掛けて

$$
\frac{P(s)}{1 + P(s)C(s)} = \frac{G_\mathrm{P}(s)s^{N_\mathrm{C}}}{s^{N_\mathrm{P} + N_\mathrm{C}} + G_\mathrm{P}(s)G_\mathrm{C}(s)}
$$

である。$`s`$ を 0 に近づけると、$`N_\mathrm{P} + N_\mathrm{C}`$ = 0 なら $`G_\mathrm{P}(0)/\{1 + G_\mathrm{P}(0)G_\mathrm{C}(0)\}`$ に、$`N_\mathrm{P} + N_\mathrm{C} \ge 1`$ なら分母は $`G_\mathrm{P}(0)G_\mathrm{C}(0)`$ に近づくので $`s^{N_\mathrm{C}}/G_\mathrm{C}(0)`$ に近づく。これは $`N_\mathrm{C}`$ = 0 なら $`1/G_\mathrm{C}(0)`$、$`N_\mathrm{C} \ge 1`$ なら 0 である。ずれは、これに $`d`$ を掛けたものである ∎

制御量に入る外乱は、ループのどこに積分があっても消える。操作量に入る外乱を消すのは、外乱が入る点より前、つまり制御器の側にある積分だけで、対象の中の積分は役に立たない。例の値で確かめる。

| 対象と制御器 | 操作量に入る外乱 | 制御量に入る外乱 |
|---|---|---|
| 台車の速度、$`K_\mathrm{P}`$ = 8 N/(m/s)（型 0） | 坂の力 −0.513 N → 0.1 × (−0.513) = −0.0513 m/s | 歩道の速さ 0.2 m/s → 0.2 ÷ 5 = 0.04 m/s |
| モータの位置、$`K_\mathrm{P}`$ = 0.21 V/rad（型 1、積分は対象の中） | 負荷トルク 0.01 N·m（−1 V にあたる）→ −1 ÷ 0.21 = −4.76 rad | 継ぎ手の滑り 0.5 rad → 0 |
| 上の 2 つの制御器に積分を足す（$`K_\mathrm{I}`$ = 25 N/m・0.5 V/(rad·s)） | 0 | 0 |

坂の −0.0513 m/s は 1 章 4 節の値、負荷トルクの −4.76 rad は 4 章 6 節の値である。負荷トルクを電圧に換算するには、2 章 3 節の一次の式 $`T\dot\omega_\mathrm{m} + \omega_\mathrm{m} = Kv - (R_\mathrm{a}/K_\mathrm{t}^2)\tau_\mathrm{L}`$ を、$`K = 1/K_\mathrm{t}`$ を使って $`K\{v - (R_\mathrm{a}/K_\mathrm{t})\tau_\mathrm{L}\}`$ と書き直す。負荷トルクは、電圧に $`-(R_\mathrm{a}/K_\mathrm{t})\tau_\mathrm{L}`$ = −100 × 0.01 = −1 V を足したのと同じ働きをする。モータの位置は型 1 なのに、負荷トルクによるずれが残る。対象の中の積分は、電圧から角度までの間にあって、外乱が入る点より後ろにあるからである。

### 積分は、偏差なしで操作量を保つ

モータの位置で、負荷トルクを加えたときの、角度と電圧の動きを比べる。

```fig

```

比例制御だけでは、負荷トルクに釣り合う電圧 +1 V を、偏差 × 0.21 V/rad で作るしかないので、角度は 4.76 rad ずれたところで止まる。積分を足すと、偏差がある間、積分した値に比例する電圧が増え続け、+1 V に届いたところで、偏差 0 のまま負荷を支える。3 節の「要る信号を積分が保つ」と同じ働きである。ただし、閉ループの極が −3.20 と $`-8.40 \pm j9.26`$ に動き、遅い極 −3.20 があるので、ずれが 0.1 rad より小さくなるまで約 1.4 s かかる。1 章 6 節で予告した「偏差を時間で足し合わせる働き」がこれで、10 章 2 節で I 動作として扱う。

## 5. 感度関数 — 制御対象の変化に強いか

2〜4 節では、同じ関数 $`1/\{1 + P(s)C(s)\}`$ が、目標値から偏差までの伝達関数として、また制御量に入る外乱から制御量までの伝達関数として現れた。この関数を**感度関数**といい、$`S(s)`$ と書く。

$$
S(s) = \frac{1}{1 + P(s)C(s)}
$$

名前は、閉ループの伝達関数が、制御対象の変化にどれだけ敏感か（感度）を表すことから来ている。それを導く。

### 対象の変化は S 倍に縮んで伝わる

1 章では、荷物（質量の変化）があっても、比例制御の台車の速度はあまりずれなかった。制御対象の伝達関数が $`P`$ から $`P' = (1 + \delta)P`$ に変わったとき（$`\delta`$ は変化の割合。−0.5 なら半分になる）、閉ループ伝達関数 $`G_{yr}`$ がどれだけ変わるかを求める。

**方針**: 変わる前と後の $`G_{yr}`$ の比をとり、変化の割合 $`(G'_{yr} - G_{yr})/G_{yr}`$ を $`\delta`$ で表す。

**導出**: $`G_{yr} = PC/(1 + PC)`$、$`G'_{yr} = P'C/(1 + P'C)`$ なので

$$
\frac{G'_{yr}}{G_{yr}} = \frac{P'}{P} \cdot \frac{1 + PC}{1 + P'C} = \frac{(1 + \delta)(1 + PC)}{1 + PC + \delta PC}
$$

である。1 を引いて通分すると、分子は $`(1 + \delta)(1 + PC) - (1 + PC + \delta PC) = \delta`$ で、分母は $`1 + P'C`$ なので

$$
\frac{G'_{yr} - G_{yr}}{G_{yr}} = \frac{\delta}{1 + P'(s)C(s)} = \delta\,S'(s)
$$

となる。$`S'`$ は、変わった後の対象で計算した感度関数である ∎

開ループ制御（1 章 3 節）では、$`P`$ の前に決まった伝達関数をつなぐだけなので、全体の伝達関数も $`(1 + \delta)`$ 倍になり、対象の変化の割合 $`\delta`$ がそのまま伝わる。フィードバックをかけると、変化の割合は $`S'`$ 倍に縮む。変化が小さければ $`S' \approx S`$ で、$`\Delta G_{yr}/G_{yr} \approx S \cdot \Delta P/P`$ である。1 章の決めた力の道（2 節）があっても、$`G_{yr} = (c + K_\mathrm{P})P/(1 + K_\mathrm{P}P)`$ の比 $`G'_{yr}/G_{yr}`$ は、$`c + K_\mathrm{P}`$ が約分されて上と同じ式になるので、同じ結果が成り立つ。

### ばらつく対象の応答の束

台車の速度で、定常ゲイン $`K`$ と時定数 $`T`$ が、例の値（0.5 (m/s)/N・0.5 s）の 0.5 倍・1 倍・1.5 倍の 3 通りずつ、計 9 通りにばらつく場合を比べる（床の抵抗 $`c`$ が変わると $`K = 1/c`$ と $`T = m/c`$ が、荷物で $`m`$ が変わると $`T`$ が変わる）。開ループは 1 章 3 節の決めた力だけで押し（$`u = cr`$、$`c`$ は例の値の 2 N·s/m）、閉ループはそれに $`K_\mathrm{P}`$ = 8 N/(m/s) の比例制御を足す。

```fig

```

落ち着いた速度は、開ループでは 0.5〜1.5 m/s に広がるが、閉ループでは 0.833〜1.071 m/s に収まる。$`s = 0`$ では $`S'(0) = 1/(1 + K'K_\mathrm{P})`$ なので、定常ゲインが半分（$`\delta`$ = −0.5、$`K'`$ = 0.25）なら −0.5 ÷ (1 + 2) = −16.7 %、1.5 倍なら 0.5 ÷ (1 + 6) = +7.1 % で、図の値と一致する。比例ゲインを上げるほど $`S(0)`$ が小さくなり、束は細くなる。

## 6. 目標値・外乱・ノイズの間の釣り合い

### S と G_yr の和は 1

目標値を、制御器の前の加え合わせ点にだけ入れる（1 章の決めた力のような、別の道を通さない）とき、感度関数と目標値から制御量までの閉ループ伝達関数を足すと

$$
S(s) + G_{yr}(s) = \frac{1}{1 + P(s)C(s)} + \frac{P(s)C(s)}{1 + P(s)C(s)} = 1
$$

である。2 節と 4 節から、それぞれの関数は次の信号の通り方を決めている。

- $`S`$: 制御量に入る外乱が制御量に現れる割合。目標値から偏差までの割合。
- $`G_{yr}`$: 目標値が制御量に現れる割合。観測ノイズが（符号を変えて）制御量に現れる割合。

目標値に追従し、外乱を抑えるには $`S`$ を小さくしたい。観測ノイズを制御量に出さないためには $`G_{yr}`$ を小さくしたい。和が 1 なので、同じ $`s`$ で 2 つを同時に小さくすることはできない。これを時間の応答で確かめる。台車の速度の比例制御に、制御量に入るステップの外乱と、ステップの観測ノイズ（センサの読みが一定の値だけずれる）を別々に加える。

```fig

```

外乱による制御量のずれ（$`S(s)/s`$ の応答）と、ノイズによる制御量のずれの符号を変えたもの（$`G_{yr}(s)/s`$ の応答）は、どの時刻でも足すと 1 になる。$`K_\mathrm{P}`$ を上げると外乱は速く小さく抑えられるが、同じだけ速く、ノイズが制御量に現れる。$`K_\mathrm{P}`$ = 30 N/(m/s) では、外乱は 0.1 s で 0.10 倍まで抑えられ、ノイズは 0.1 s で 0.90 倍が制御量に現れる。センサの読みがずれると、ループは、ずれた読みを目標値に合わせるように、本当の速度をずらしてしまう。ループには、測った値のどこまでが本当の制御量で、どこからが観測ノイズかを区別する方法が無いからである。

### 遅い外乱と速いノイズ

外乱と観測ノイズが同じ形なら、どちらかをあきらめるしかない。ただ、実際の外乱（坂・負荷・周りの温度）や目標値の変化はゆっくりで、観測ノイズは速く揺れることが多い。台車の速度（$`K_\mathrm{P}`$ = 8 N/(m/s)）に、角周波数を変えた正弦波を入れて、十分に時間がたった後の揺れの振幅を数値計算で比べると、1 rad/s の正弦波の外乱は 0.22 倍に縮み、同じ 1 rad/s のノイズは 0.80 倍が制御量に現れる。50 rad/s では、外乱は 0.98 倍とほとんど縮まないが、ノイズは 0.16 倍しか現れない。遅い外乱は抑え、速いノイズは通さないという分担は、$`S`$ が遅い所で小さく、速い所で 1 に近いことで成り立っている。正弦波に対する振幅の比を伝達関数から求める方法は 8 章で、一巡伝達関数の形でこの分担を決める方法は 13 章で扱う（[8 章 1 節](08_周波数応答とボード線図.md#正弦波を入れる-定常状態のゲインと位相)・[13 章 1 節](13_ループ整形.md#一巡伝達関数の形で性能を決める)）。

```fig

```

1 章 4 節では、観測ノイズ（0.01 s ごとに変わる、標準偏差 0.02 m/s の値）による台車の速度の揺れが、$`K_\mathrm{P}`$ = 8 N/(m/s) の 0.0035 m/s から、30 N/(m/s) の 0.0071 m/s に増えた。同じ比例ゲインで、坂による速度のずれは 0.051 m/s から 0.016 m/s に減る。図の (a) のとおり、比例ゲインを上げるほど、坂には強くなり、ノイズには弱くなる。$`K_\mathrm{P}`$ が大きいほど $`G_{yr}`$ の時定数 $`T/(1 + KK_\mathrm{P})`$ が短くなり、速く変わるノイズまで制御量に通すからである。

1 章のように、目標値から別の道で操作量を足すと、$`G_{yr}`$ は $`1 - S`$ と違う形になる。それでも、観測ノイズから制御量までの伝達関数は $`-P(s)C(s)/\{1 + P(s)C(s)\} = -\{1 - S(s)\}`$ のままなので、外乱を抑えることとノイズを通さないことの釣り合いは変わらない。目標値への応答だけを別に決める構成は、14 章で扱う。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 直列結合・並列結合・フィードバック結合 | 出力をそのまま次の入力にする／同じ入力の出力を足し引きする／出力を $`H`$ を通して入力の前へ戻す。伝達関数は $`G_1G_2`$／$`G_1 \pm G_2`$／$`G/(1 + GH)`$（負帰還）・$`G/(1 - GH)`$（正帰還） |
| 等価変換 | 入力から出力までの関係を変えずに線図を書き換えること。加え合わせ点・引き出し点を箱の前後へ動かすときは、$`G`$ か $`1/G`$ を掛ける |
| 閉ループ伝達関数 | 輪の外の入力から輪の中の信号まで。$`G_{yr} = PC/(1 + PC)`$、$`G_{yd} = P/(1 + PC)`$、観測ノイズから制御量までは $`-G_{yr}`$。分母はどれも $`1 + PC`$ |
| 一巡伝達関数・閉ループの特性方程式 | 輪を切って一周させた伝達関数 $`P(s)C(s)`$／$`1 + P(s)C(s) = 0`$。根が閉ループの極で、ループ全体の微分方程式の特性方程式と同じ。1・3・4・6 章の結果を再現する |
| 制御系の型・定常位置偏差・定常速度偏差 | 一巡伝達関数の原点の極の数／単位ステップへの定常偏差（型 0 で $`1/\{1 + \lim PC\}`$、型 1 以上で 0）／単位ランプへの定常偏差（型 0 で増え続ける、型 1 で $`1/\lim sPC`$、型 2 以上で 0） |
| 外乱の入る場所 | 制御量に入る外乱はループのどこかに積分があれば消える。操作量に入る外乱は、制御器の側の積分でしか消えない（モータの位置の比例制御で負荷トルクのずれ 4.76 rad が残る） |
| 感度関数 | $`S = 1/(1 + PC)`$。対象の変化の割合 $`\delta`$ は、閉ループでは $`\delta S'`$ に縮む（台車、$`K_\mathrm{P}`$ = 8 で ±50 % が −16.7 %・+7.1 %）。動き始めの速い部分は縮まない |
| 目標値・外乱・ノイズの釣り合い | $`S + G_{yr} = 1`$。外乱を抑えることとノイズを通さないことは、同じ速さの信号では両立しない。遅い外乱は抑え、速いノイズは通さないように分担する（8・13 章） |

この章では、感度関数と閉ループ伝達関数を、主に落ち着いた後の値（$`s = 0`$）と時間の応答で見た。次章では、正弦波を入れて、系が周波数ごとにどれだけ通し、どれだけ遅らせるかを調べ、6 節の「遅い所では $`S`$ を小さく、速い所では $`G_{yr}`$ を小さく」を、周波数ごとの数値で読めるようにする。
