# 12. 根軌跡 — ゲインを変えると極はどう動くか

> **この章で扱う問い.**
> 4 章 6 節と 7 章 2 節では、モータの位置を比例制御すると、比例ゲインを上げるにつれて 2 つの閉ループの極が実軸の上で近づき、−10 で出会った後は実部 −10 のまま上下に離れることを見た。9 章では、ゲインを上げすぎて閉ループが不安定になる境目を求め、10 章では、D 動作や I 動作を足すと閉ループの極が別の位置へ動くことを、ゲインの組ごとに根を計算して確かめた。この章では、ゲインを 0 から限りなく大きくまで変えたときに閉ループの極が描く道筋を 1 枚の図に描き、その形を開ループの極と零点から読み、望む極の位置からゲインと制御器を決める。
>
> この章では次の 3 つの問いに答える。

## 1. 閉ループの極はゲインで動く

7 章 2 節で見たとおり、閉ループの極は特性方程式 $`1 + P(s)C(s) = 0`$ の根で、開ループの極（一巡伝達関数 $`P(s)C(s)`$ の極）と違い、制御器のゲインとともに動く。この節では、ゲインを細かく変えて閉ループの極を求め、その動きを曲線として見る。

### 動かすゲインを 1 つにまとめる

制御器の伝達関数を、全体の強さを表す正の定数 $`K_\mathrm{c}`$ と、形を表す伝達関数 $`C_0(s)`$ の積

$$
C(s) = K_\mathrm{c}\,C_0(s)
$$

に分ける。比例制御では $`C_0(s) = 1`$ で、$`K_\mathrm{c}`$ は比例ゲイン $`K_\mathrm{P}`$ そのものである。10 章 4 節の標準形の PID 制御では $`C_0(s) = 1 + 1/(T_\mathrm{I}s) + T_\mathrm{D}s`$、$`K_\mathrm{c} = K_\mathrm{P}`$ で、積分時間と微分時間を決めた後に、比例ゲインで全体の強さを変えることにあたる。閉ループの特性方程式は

$$
1 + K_\mathrm{c}\,P(s)C_0(s) = 0
$$

となる。$`P(s)C_0(s)`$ は $`K_\mathrm{c}`$ によらず、その極は一巡伝達関数 $`K_\mathrm{c}P(s)C_0(s)`$ の極、つまり開ループの極である。$`P(s)C_0(s)`$ を分母と分子の多項式で $`b(s)/a(s)`$ と書き（$`a(s)`$ の最も高い次の係数を 1 にそろえる。$`P(s)`$ の極と $`C_0(s)`$ の零点の約分はしない。7 章 2 節）、分母を払うと、特性方程式は

$$
a(s) + K_\mathrm{c}\,b(s) = 0
$$

となる。7 章 2 節の $`a_\mathrm{P}a_\mathrm{C} + b_\mathrm{P}b_\mathrm{C} = 0`$ を、$`K_\mathrm{c}`$ についてまとめたものである。

### 点を打って道筋を見る

例として、台車の速度（$`P(s) = 0.5/(0.5s + 1) = 1/(s + 2)`$ (m/s)/N）と、モータの位置（$`P(s) = 1000/\{s(s + 20)\}`$ rad/V。どちらも 6 章 1 節）を比例制御する。特性方程式は、台車では $`s + 2 + K_\mathrm{c} = 0`$、モータでは $`s^2 + 20s + 1000K_\mathrm{c} = 0`$ である。$`K_\mathrm{c}`$ を少しずつ上げながら閉ループの極を求め、s 平面に点を打つ。

```fig

```

- 台車の速度: 閉ループの極 $`-2 - K_\mathrm{c}`$ は、$`K_\mathrm{c}`$ = 0 の開ループの極 −2 から、負の実軸の上を左へ、$`K_\mathrm{c}`$ に比例して進む（7 章 2 節の −4・−10・−22 は、2・8・20 N/(m/s) の点）。
- モータの位置: 2 つの閉ループの極 $`-10 \pm \sqrt{100 - 1000K_\mathrm{c}}`$ は、開ループの極 0 と −20 から出て実軸の上を近づき、$`K_\mathrm{c}`$ = 0.1 V/rad で −10 に重なる。それより大きい $`K_\mathrm{c}`$ では根号の中が負になり、極は $`-10 \pm j\sqrt{1000K_\mathrm{c} - 100}`$ となって、実部 −10 の縦の線の上を上下に離れる。

点を細かく打つと、点はつながって曲線になる。$`K_\mathrm{c}`$ を 0 から限りなく大きな値まで変えたときに、閉ループの極が s 平面に描く曲線を**根軌跡**という。特性方程式が $`n`$ 次なら根は $`n`$ 個あり、根軌跡は根 1 つずつが描く $`n`$ 本の曲線でできている。この 1 本ずつを、根軌跡の**枝**と呼ぶ。特性方程式の係数は実数なので、根は共役な組で現れ（6 章 2 節）、根軌跡は実軸について上下対称である。

### 数値で描く

根軌跡は、$`K_\mathrm{c}`$ を細かく変えて特性方程式の根を数値で求め、点をつなげば描ける。$`K_\mathrm{c}`$ は 0 に近い値から大きな値まで広く変えるので、対数の目盛で等しい間隔に（1 桁を数百に分けて）とる。ただし、多項式の根を数値で求める計算は、根を決まった順に返すとは限らない。根を実部の小さい順に並べ、同じ順番の根どうしをつなぐと、根の実部の大小が入れ替わる所で、線が別の枝へ飛ぶ。そこで、1 つ前の $`K_\mathrm{c}`$ で求めた根に最も近い根を、同じ枝の続きとしてつなぐ。3 次の例として、10 章 2 節の PI 制御のモータの位置（積分時間 0.42 s。$`K_\mathrm{c}`$ = 0.21 V/rad で 7 章 3 節の $`K_\mathrm{P}`$ = 0.21 V/rad・$`K_\mathrm{I}`$ = 0.5 V/(rad·s) になる。根軌跡の形は 4 節で調べる）で比べる。

## 2. 根軌跡の性質 — 始点・終点・実軸上の部分・漸近線

1 節の 2 つの例では、特性方程式を解の公式で解けた。3 次以上では根の式は使いにくいが、根軌跡の形の多くは、開ループの極と零点の位置から、根を求めずに読める。その手がかりになる 2 つの条件を導き、そこから根軌跡の性質を順に導く。

### 角度の条件と大きさの条件

$`P(s)C_0(s)`$ の分母と分子を因数に分けて（6 章 2 節）

$$
P(s)C_0(s) = \frac{b(s)}{a(s)} = \beta\,\frac{(s - z_1)(s - z_2)\cdots(s - z_m)}{(s - p_1)(s - p_2)\cdots(s - p_n)}
$$

と書く。$`p_1, \ldots, p_n`$ は開ループの極である。$`z_1, \ldots, z_m`$ は $`P(s)C_0(s)`$ の零点（一巡伝達関数の零点）で、これを**開ループの零点**と呼ぶ。$`\beta`$ は分子の最も高い次の係数である。制御対象は厳密にプロパーで、$`C_0(s)`$ はプロパーなので（6 章 2 節）、$`m < n`$ である。また、6 節の最後を除き、この章の例はどれも $`\beta > 0`$ である（モータの位置では $`\beta`$ = 1000）。

8 章 2 節では、因数 $`s - p_i`$ を、極 $`p_i`$ から点 $`s`$ へ引いた矢印として表した。その長さが $`|s - p_i|`$、正の実軸から反時計回りに測った角度が $`\angle(s - p_i)`$ である（零点も同じ）。8 章では点 $`s`$ を虚軸の上の $`j\omega`$ に限ったが、矢印の見方は s 平面のどの点でも成り立つ。

**方針**: 特性方程式を $`P(s)C_0(s) = -1/K_\mathrm{c}`$ と書き直し、両辺の複素数の偏角と大きさをそれぞれ比べる。

**導出**: $`1 + K_\mathrm{c}P(s)C_0(s) = 0`$ の 1 を右辺へ移し、両辺を $`K_\mathrm{c}`$（正）で割ると、$`P(s)C_0(s) = -1/K_\mathrm{c}`$ である。右辺は負の実数で、偏角は −180°（360° の整数倍だけ違う ±180°・±540°・… も同じ向き）、大きさは $`1/K_\mathrm{c}`$ である。左辺は因数の積と商なので、偏角は因数の偏角の和と差、大きさは因数の大きさの積と商である（8 章 2 節）。$`\beta`$ は正なので偏角は 0 である。両辺を比べると

$$
\sum_{i=1}^{m}\angle(s - z_i) - \sum_{i=1}^{n}\angle(s - p_i) = \pm 180^\circ,\ \pm 540^\circ,\ \ldots
$$

$$
K_\mathrm{c} = \frac{|s - p_1|\,|s - p_2|\cdots|s - p_n|}{\beta\,|s - z_1|\,|s - z_2|\cdots|s - z_m|}
$$

が成り立つ。逆に、点 $`s`$ が 1 つ目の式を満たせば、$`P(s)C_0(s)`$ は負の実数なので、2 つ目の式で決まる正の $`K_\mathrm{c}`$ で $`1 + K_\mathrm{c}P(s)C_0(s) = 0`$ となる ∎

1 つ目の式（左辺が 180° の奇数倍になること）を**角度の条件**、2 つ目の式を**大きさの条件**という。点 $`s`$ が根軌跡の上にあるかどうかは角度の条件だけで決まり、そこを閉ループの極にする $`K_\mathrm{c}`$ は大きさの条件で決まる。モータの位置（$`n`$ = 2、$`m`$ = 0、$`\beta`$ = 1000）で確かめる。

```fig
e12_cond
```

- 点 $`-10 + j10.49`$: 極 0 からの矢印の角度は 133.6°、極 −20 からは 46.4° で、和は 180° なので、左辺は −180° となり、角度の条件を満たす。2 本の矢印の長さはどちらも 14.49 で、大きさの条件から $`K_\mathrm{c}`$ = 14.49 × 14.49 ÷ 1000 = 0.21 V/rad となり、1 節の値と一致する。
- 点 $`-5 + j10`$: 角度の和は 116.6° + 33.7° = 150.3° で、左辺は −150.3° になる。角度の条件を満たさないので、どの $`K_\mathrm{c}`$（正）でも、この点は閉ループの極にならない。
- 縦の線 $`\sigma = -10`$ の上の点では、2 本の矢印が −10 を挟んで左右対称になり、角度は $`\theta`$ と $`180^\circ - \theta`$ で、和はいつも 180° である。(c) のとおり、虚部 10.49 の横の線の上で角度の和が 180° になるのは、実部 −10 の 1 点だけである。

### 始点と終点

**方針**: 分母を払った特性方程式 $`a(s) + K_\mathrm{c}b(s) = 0`$ で、$`K_\mathrm{c}`$ = 0 の根と、$`K_\mathrm{c}`$ を限りなく大きくしたときの根を調べる。

**導出**: $`a(s)`$ は最も高い次の係数が 1 の $`n`$ 次、$`b(s)`$ は $`m`$ 次（$`m < n`$）なので、$`a(s) + K_\mathrm{c}b(s)`$ は最も高い次の係数が 1 の $`n`$ 次の多項式で、根は $`K_\mathrm{c}`$ によらず $`n`$ 個ある。$`K_\mathrm{c}`$ = 0 では $`a(s) = 0`$ なので、根は開ループの極 $`p_1, \ldots, p_n`$ である。$`K_\mathrm{c}`$ を少しずつ変えると、係数が少しずつ変わり、根も少しずつ動く（9 章 2 節の導出と同じ）。$`K_\mathrm{c}`$ を限りなく大きくするときは、両辺を $`K_\mathrm{c}`$ で割った $`a(s)/K_\mathrm{c} + b(s) = 0`$ を考える。この多項式の $`s^n`$ から $`s^{m+1}`$ までの係数は $`a(s)/K_\mathrm{c}`$ だけから来るので 0 に近づき、残りの係数は $`b(s)`$ の係数に近づく。9 章 2 節で、最も高い次の係数が 0 に近づくと根が 1 つ限りなく遠くへ去ったのと同じく、次数が $`n`$ から $`m`$ へ下がる分の $`n - m`$ 個の根は限りなく遠くへ去り、残りの $`m`$ 個の根は $`b(s) = 0`$ の根、つまり開ループの零点に近づく ∎

根軌跡の $`n`$ 本の枝は、開ループの極から出発し（$`K_\mathrm{c}`$ = 0）、そのうち $`m`$ 本は開ループの零点で終わり、残りの $`n - m`$ 本は限りなく遠くへ去る。1 節の 2 つの例は開ループの零点が無く（$`m`$ = 0）、どの枝も遠くへ去った。

### 実軸の上の部分

**方針**: 実軸の上の点 $`s = \sigma`$ で角度の条件の左辺を求める。開ループの極と零点を、実数のものと、共役な組のものに分けて、矢印の角度を足す。

**導出**: 共役な組 $`p`$ と $`\bar p`$ から点 $`\sigma`$ への 2 本の矢印は、実軸について対称なので、角度は $`\theta`$ と $`-\theta`$ で、和は 0 である（零点の組も同じ）。実数の極や零点が $`\sigma`$ より左にあれば、矢印は右を向き、角度は 0° である。右にあれば、矢印は左を向き、角度は 180° である。したがって左辺は（$`\sigma`$ より右にある実数の零点の数 − 右にある実数の極の数）× 180° で、これが 180° の奇数倍になるのは、2 つの数の差が奇数のとき、つまり和が奇数のときである ∎

実軸の上の点は、その点より右にある実数の開ループの極と零点の数の合計が奇数のとき、そのときに限り、根軌跡の上にある。モータの位置では、−20 と 0 の間の点の右には極 0 だけがあり（1 個）、根軌跡の上にある。0 より右（0 個）と −20 より左（2 個）は根軌跡の上に無い。1 節で 2 つの極が実軸の上を動いたのは、この区間の中だけだった。零点を含む例として、10 章 3 節の PD 制御のモータの位置（$`C_0(s) = 1 + T_\mathrm{D}s`$、微分時間 $`T_\mathrm{D}`$ = 0.0238 s。開ループの極は 0 と −20、零点は −42。4 節で詳しく調べる）で、始点・終点と実軸の上の部分を確かめる。

### 漸近線

$`n - m`$ 本の枝が遠くへ去る向きを求める。

**方針**: $`|s|`$ が大きい所で、$`a(s)/b(s)`$ を、上から 2 つの項までそろえた簡単な式で近似し、特性方程式 $`a(s)/b(s) = -K_\mathrm{c}`$ の大きな根を近似で求める。

**導出**: 因数の積を展開すると、$`a(s) = s^n - (p_1 + \cdots + p_n)s^{n-1} + \cdots`$、$`b(s)/\beta = s^m - (z_1 + \cdots + z_m)s^{m-1} + \cdots`$ である。$`a(s)`$ を $`b(s)/\beta`$ で割った商を $`s^{n-m} + cs^{n-m-1} + \cdots`$ とおくと、商に $`b(s)/\beta`$ を掛けた $`s^n + \{c - (z_1 + \cdots + z_m)\}s^{n-1} + \cdots`$ が $`a(s)`$ の上の 2 つの項に一致するので、$`c = -\{(p_1 + \cdots + p_n) - (z_1 + \cdots + z_m)\}`$ である。一方、2 項定理から $`(s - \sigma_\mathrm{a})^{n-m} = s^{n-m} - (n - m)\sigma_\mathrm{a}s^{n-m-1} + \cdots`$ なので、

$$
\sigma_\mathrm{a} = \frac{(p_1 + \cdots + p_n) - (z_1 + \cdots + z_m)}{n - m}
$$

とおくと、$`\beta a(s)/b(s)`$ と $`(s - \sigma_\mathrm{a})^{n-m}`$ は上から 2 つの項が一致し、違いは $`s^{n-m-2}`$ 以下の項だけになる。$`|s|`$ が大きいほど、この違いは $`s^{n-m}`$ に比べて小さくなるので、特性方程式 $`\beta a(s)/b(s) = -\beta K_\mathrm{c}`$ の大きな根は、$`(s - \sigma_\mathrm{a})^{n-m} = -\beta K_\mathrm{c}`$ の根に近い。$`-\beta K_\mathrm{c}`$ は大きさ $`\beta K_\mathrm{c}`$、偏角 180° の数なので、その $`n - m`$ 乗根は

$$
s = \sigma_\mathrm{a} + (\beta K_\mathrm{c})^{1/(n-m)}\,e^{j\phi}, \qquad \phi = \frac{180^\circ \times (2q + 1)}{n - m} \quad (q = 0, 1, \ldots, n - m - 1)
$$

である ∎

$`K_\mathrm{c}`$ を大きくすると、遠くへ去る枝は、実軸の上の点 $`\sigma_\mathrm{a}`$ から角度 $`\phi`$ の向きに引いた半直線に近づいていく。この直線を、**根軌跡の漸近線**という（8 章 4 節のボード線図の漸近線と同じく、曲線が限りなく近づく直線で、ここでは s 平面の上の直線である）。上から 2 つの項までそろえたので、枝と漸近線のずれは、$`|s|`$ が大きいほど 0 に近づく（1 つ目の項だけなら、向きしか分からない）。

| $`n - m`$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 漸近線の角度 | 180° | ±90° | ±60°・180° | ±45°・±135° |

### 分岐点

モータの位置の根軌跡では、0 と −20 から出た 2 本の枝が −10 で出会い、実軸を離れた。このように、根軌跡の枝が実軸の上で出会って実軸から離れる点、または実軸の外から実軸に戻ってくる点を**分岐点**という。分岐点では、2 つの根が重なっている（重根）。

**方針**: 重根では、多項式とその微分がどちらも 0 になる（$`(s - s_\mathrm{b})^2`$ を因数にもつ多項式は、微分しても $`s - s_\mathrm{b}`$ を因数にもつ）。特性方程式と、それを $`s`$ で微分した式を連立させ、$`K_\mathrm{c}`$ を消す。

**導出**: $`s_\mathrm{b}`$ が重根なら、$`a(s_\mathrm{b}) + K_\mathrm{c}b(s_\mathrm{b}) = 0`$ と $`a'(s_\mathrm{b}) + K_\mathrm{c}b'(s_\mathrm{b}) = 0`$ が成り立つ（$`'`$ は $`s`$ での微分）。1 つ目から $`K_\mathrm{c} = -a(s_\mathrm{b})/b(s_\mathrm{b})`$ で、これを 2 つ目に入れて $`b(s_\mathrm{b})`$ を掛けると

$$
a'(s_\mathrm{b})\,b(s_\mathrm{b}) - a(s_\mathrm{b})\,b'(s_\mathrm{b}) = 0
$$

である。実軸の上の点 $`\sigma`$ で大きさの条件から決まる $`K_\mathrm{c}(\sigma) = -a(\sigma)/b(\sigma)`$ を、商の微分の公式で微分すると $`dK_\mathrm{c}/d\sigma = -\{a'(\sigma)b(\sigma) - a(\sigma)b'(\sigma)\}/b(\sigma)^2`$ なので、上の式は $`dK_\mathrm{c}/d\sigma = 0`$ と同じである。分岐点は、$`dK_\mathrm{c}/d\sigma = 0`$ となる点のうち、根軌跡の上にある（$`K_\mathrm{c}`$ が正になる）点である ∎


- モータの位置: $`a(s) = s^2 + 20s`$、$`b(s) = 1000`$ で、$`a'(\sigma) = 2\sigma + 20 = 0`$ から分岐点は −10、$`K_\mathrm{c} = -a(-10)/1000`$ = 0.1 V/rad で、1 節で根が重なった点である。$`K_\mathrm{c}(\sigma)`$ は区間の両端の極で 0 から増えて −10 で最大になり、それより大きい $`K_\mathrm{c}`$ では実軸の上に根が無くなる。
- PD 制御（$`b(s) = 23.8(s + 42)`$）: 区間 −20〜0 では −11.6 で最大 0.135 V/rad になり、2 本の枝が実軸を離れる。区間 −42 より左では −72.4 で最小 5.24 V/rad になり、枝が実軸に戻る。

分岐点の $`K_\mathrm{c}`$ を $`K_\mathrm{b}`$ とすると、分岐点のまわりでは、特性方程式の左辺は $`c_\mathrm{b}(s - s_\mathrm{b})^2 + (K_\mathrm{c} - K_\mathrm{b})\,b(s_\mathrm{b})`$（$`c_\mathrm{b}`$ は実数の定数）で近似できる（テイラー展開の 1 次の項は、重根なので 0）。$`K_\mathrm{c}`$ が $`K_\mathrm{b}`$ を越えると $`(s - s_\mathrm{b})^2`$ の符号が変わり、根のずれ $`s - s_\mathrm{b}`$ は実数から純虚数に変わる。2 本の枝は、実軸と直角に離れる（戻る）。

下の図で、s 平面の点をドラッグすると（つまみでも動かせる）、開ループの極と零点からその点への矢印と角度、角度の条件の左辺、大きさの条件から求めた $`K_\mathrm{c}`$ が表示される。根軌跡と、実軸の上の部分・漸近線・分岐点を重ねて、性質と見比べられる。

## 3. 例で描く — 一次遅れ・積分・二次遅れ

2 節の性質から、根軌跡のおおよその形は、次の手順で、根を求めずに描ける。

1. 開ループの極（×）と零点（○）を描き、$`n`$ と $`m`$ を数える。枝は極から出て、$`m`$ 本は零点で終わる。
2. 実軸の上で、右にある極と零点の数の合計が奇数の区間を、根軌跡として描く。
3. $`n - m`$ 本の漸近線を、$`\sigma_\mathrm{a}`$ から引く。
4. 実軸の上の分岐点を、$`dK_\mathrm{c}/d\sigma = 0`$ から求める。
5. 枝が虚軸を横切るなら、その点と $`K_\mathrm{c}`$ を求める（この節の最後の例）。

例の対象を比例制御（$`C_0(s) = 1`$、$`K_\mathrm{c} = K_\mathrm{P}`$）したときの根軌跡を、この手順で描き、1 節の方法で数値で求めた根軌跡と比べる。

- (a) 一次遅れ 2 つ（$`L_\mathrm{a}`$ を含むモータの角速度。6 章 1 節）: $`P(s) = 2 \times 10^6/\{(s + 20.2)(s + 1980)\}`$ (rad/s)/V。実軸の上の部分は −1980 と −20.2 の間、$`\sigma_\mathrm{a}`$ = (−20.2 − 1980) ÷ 2 = −1000 で漸近線は ±90°、分岐点は $`a'(\sigma) = 2\sigma + 2000 = 0`$ から −1000（$`K_\mathrm{c}`$ = 0.48 V/(rad/s)）である。枝は右半平面に入らないので、どの比例ゲインでも安定である。
- (b) 積分＋一次遅れ（モータの位置）: 1 節の根軌跡である。$`\sigma_\mathrm{a}`$ = (0 − 20) ÷ 2 = −10、分岐点は −10（0.1 V/rad）。
- (c) 二次遅れ（台車とばね・ダンパの位置を、力で比例制御する）: $`P(s) = 1/(s^2 + 2s + 25)`$ m/N。開ループの極は $`-1 \pm j4.90`$ で、実数の極が無いので、実軸の上に根軌跡は無い。$`\sigma_\mathrm{a}`$ = −1 で、枝は極から真上と真下へ、漸近線の上を進む。特性方程式 $`s^2 + 2s + 25 + K_\mathrm{c} = 0`$ から、$`\omega_\mathrm{n} = \sqrt{25 + K_\mathrm{c}}`$、$`\zeta = 1/\sqrt{25 + K_\mathrm{c}}`$ で、比例ゲインはばねを強くしたのと同じ働きをし、減衰は増やせない。

### 極の和は変わらない

3 つの例は、どれも $`n - m`$ = 2 で、比例ゲインを上げても、極の組の実部は $`\sigma_\mathrm{a}`$ のまま変わらなかった。その理由を、閉ループの極の和で調べる。

**方針**: 最も高い次の係数が 1 の多項式の根の和は、2 番目に高い次の係数の符号を変えたものである（$`(s - r_1)\cdots(s - r_n)`$ を展開すると、$`s^{n-1}`$ の係数は $`-(r_1 + \cdots + r_n)`$）。$`a(s) + K_\mathrm{c}b(s)`$ の $`s^{n-1}`$ の係数を調べる。

**導出**: $`a(s)`$ の $`s^{n-1}`$ の係数は $`-(p_1 + \cdots + p_n)`$ である。$`b(s)`$ は $`m`$ 次なので、$`m \le n - 2`$ なら $`s^{n-1}`$ の項を含まない。このとき閉ループの極の和は、$`K_\mathrm{c}`$ によらず、開ループの極の和 $`p_1 + \cdots + p_n`$ に等しい。$`m = n - 1`$ なら、$`b(s)`$ の $`s^{n-1}`$ の係数は $`\beta`$ なので、閉ループの極の和は $`p_1 + \cdots + p_n - K_\mathrm{c}\beta`$ で、$`K_\mathrm{c}`$ とともに左へずれる ∎

$`n - m \ge 2`$ では閉ループの極の和が一定なので、ある極が左へ動けば、ほかの極が右へ動く。2 つの極の組だけの 3 つの例では、組の実部は和の半分 $`\sigma_\mathrm{a}`$ のまま変わらない。比例ゲインだけでは、2 % 整定時間の目安 $`4/(\zeta\omega_\mathrm{n})`$（4 章 4 節）を決める実部を左へ動かせないのは、このためである。

### 3 次の例 — 虚軸を横切る

$`L_\mathrm{a}`$ を含むモータの位置（6 章 4 節）は、$`P(s) = 2 \times 10^6/\{s(s + 20.2)(s + 1980)\}`$ で、$`n`$ = 3、$`m`$ = 0 である。

- 実軸の上の部分: −20.2 と 0 の間と、−1980 より左。
- 漸近線: $`\sigma_\mathrm{a}`$ = (0 − 20.2 − 1980) ÷ 3 = −666.7、角度は ±60° と 180°。
- 分岐点: $`a(s) = s^3 + 2000s^2 + 40000s`$ から、$`a'(\sigma) = 3\sigma^2 + 4000\sigma + 40000 = 0`$ の根は −10.08 と −1323 で、根軌跡の上にあるのは −10.08（$`K_\mathrm{c}`$ = 0.1005 V/rad）である。−1323 は実軸の上の部分の外にあり、$`K_\mathrm{c}(\sigma)`$ が負になる。
- 虚軸を横切る点: 特性方程式 $`s^3 + 2000s^2 + 40000s + 2 \times 10^6K_\mathrm{c} = 0`$ に $`s = j\omega`$ を入れると、実部は $`-2000\omega^2 + 2 \times 10^6K_\mathrm{c}`$、虚部は $`-\omega^3 + 40000\omega`$ である。両方が 0 になるのは $`\omega`$ = 200 rad/s、$`K_\mathrm{c}`$ = 2000 × 200² ÷ (2 × 10⁶) = 40 V/rad のときである。

## 4. 極と零点を足すと軌跡が曲がる

3 節で見たとおり、比例制御だけでは、閉ループの極の和が一定なので、極の組の実部を左へ動かせない。10 章では、D 動作を足すと減衰が増え（3 節）、I 動作を足すと行き過ぎが増える（2 節）ことを、ゲインの組ごとに閉ループの極を計算して確かめた。根軌跡で見ると、これは、制御器の $`C_0(s)`$ が開ループに零点や極を足して、根軌跡を曲げたことにあたる。同じモータの位置 $`P(s) = 1000/\{s(s + 20)\}`$ で、10 章と同じ値を使って比べる。

### 零点を足す — PD 制御

10 章 3 節の PD 制御（$`K_\mathrm{P}`$ = 0.84 V/rad、$`K_\mathrm{D}`$ = 0.02 V·s/rad）を、微分時間 $`T_\mathrm{D} = K_\mathrm{D}/K_\mathrm{P}`$ = 0.0238 s を決めた $`C_0(s) = 1 + T_\mathrm{D}s`$ と、$`K_\mathrm{c} = K_\mathrm{P}`$ に分ける。$`C_0(s)`$ は零点 $`-1/T_\mathrm{D}`$ = −42 を足す。$`P(s)C_0(s) = 23.8(s + 42)/\{s(s + 20)\}`$ で、$`n`$ = 2、$`m`$ = 1、$`\beta = 1000T_\mathrm{D}`$ = 23.8 である。

- $`n - m`$ = 1 なので、3 節の結果から、閉ループの極の和は $`-20 - 23.8K_\mathrm{c}`$ で、$`K_\mathrm{c}`$ とともに左へ動く。極が組になっている間、その実部は和の半分で、$`K_\mathrm{c}`$ = 0.84 V/rad では (−20 − 20) ÷ 2 = −20 である。
- 組になっている間、2 つの極は零点から一定の距離にある。極を $`s = -42 + w`$ とおいて特性方程式 $`s^2 + 20s + 23.8K_\mathrm{c}(s + 42) = 0`$ に入れて整理すると、$`w^2 + (23.8K_\mathrm{c} - 64)w + 924 = 0`$ である。共役な 2 つの根 $`w`$ と $`\bar w`$ の積 $`w\bar w = |w|^2`$ は定数の項 924 に等しいので、$`|w| = \sqrt{924}`$ = 30.4 である。根軌跡のこの部分は、零点 −42 を中心とする半径 30.4 の円になる。

根軌跡は、比例だけのときの縦の線から左へ曲がり、円を描いて −72.4（5.24 V/rad）で実軸に戻り、1 本は零点 −42 へ、もう 1 本は負の実軸を左へ進む。$`K_\mathrm{c}`$ = 0.84 V/rad の点は $`-20 \pm j21.0`$ で、10 章 3 節で求めた極そのものである。

角度の条件で見ても同じことが言える。上半分の点 $`s`$ では、零点からの矢印の角度 $`\angle(s + 42)`$ は正なので、比例だけの根軌跡の上の点（極からの角度の和が 180°）では、左辺が −180° より大きくなる。極からの矢印の角度は、点を左へ動かすほど大きくなるので、角度の条件を満たす点は左へずれる。零点は根軌跡を左へ引き寄せる。

10 章 6 節の不完全微分（$`N`$ = 10）では、$`C_0(s) = 1 + T_\mathrm{D}s/\{1 + (T_\mathrm{D}/N)s\} = (1 + 1.1T_\mathrm{D}s)/(1 + 0.1T_\mathrm{D}s)`$ で、零点は −38.2、極は −420 である。$`n - m`$ は 2 に戻るので、$`K_\mathrm{c}`$ を大きくすると、枝は $`\sigma_\mathrm{a}`$ = (0 − 20 − 420 + 38.2) ÷ 2 = −200.9 の縦の漸近線へ向かう。しかし原点の近くでは PD とほとんど同じ円を描き、0.84 V/rad の極は $`-21.1 \pm j21.1`$ になる。零点よりずっと左に足した極は、遠くで根軌跡を曲げ戻すだけで、原点の近くの形はほとんど変えない。零点とその左の極を組で足す制御器は、13 章で位相進み補償として扱う（[13 章 3 節](13_ループ整形.md#位相進み補償-交差周波数で位相を足す)）。

### 極を足す — PI 制御と積分だけ

7 章 3 節・10 章 2 節の PI 制御（$`K_\mathrm{P}`$ = 0.21 V/rad、$`K_\mathrm{I}`$ = 0.5 V/(rad·s)）を、積分時間 $`T_\mathrm{I} = K_\mathrm{P}/K_\mathrm{I}`$ = 0.42 s を決めた $`C_0(s) = 1 + 1/(T_\mathrm{I}s) = (s + 2.38)/s`$ と、$`K_\mathrm{c} = K_\mathrm{P}`$ に分ける。$`C_0(s)`$ は原点の極と、零点 −2.38 を足す。開ループの極は 0（重根）と −20、零点は −2.38 で、$`n - m`$ = 2 のままである。

- 閉ループの極の和は −20 で一定で、比例だけのときと同じだが、極が 3 つになった。$`K_\mathrm{c}`$ = 0.21 V/rad では、−20 から出て零点 −2.38 へ向かう枝の上の極 −3.20 が和の一部を受け持つので、極の組の実部は (−20 + 3.20) ÷ 2 = −8.40 で、比例だけのときの −10 より右になる。漸近線は $`\sigma_\mathrm{a}`$ = (0 + 0 − 20 + 2.38) ÷ 2 = −8.81 の縦の線で、極の組は −10 の線より右を上へ進む。
- 原点の重根から出る 2 本の枝は、実軸と直角に出て、左へ回りながら漸近線に近づく。

積分だけ（$`C_0(s) = 1/s`$、$`K_\mathrm{c} = K_\mathrm{I}`$）では、零点が無いので $`n - m`$ = 3 になり、漸近線は $`\sigma_\mathrm{a}`$ = −20 ÷ 3 = −6.67 から ±60° と 180° に出る。極の和は −20 で一定で、−20 から出た枝が左へ進むので、原点の重根から出た 2 本の枝は右半平面へ入る。特性方程式 $`s^3 + 20s^2 + 1000K_\mathrm{c} = 0`$ には $`s`$ の項が無いので、9 章 2 節の係数の条件から、どの $`K_\mathrm{c}`$（正）でも不安定である。

角度の条件で見ると、足した極からの矢印の角度は左辺から引かれるので、零点とは逆に、角度の条件を満たす点は右へずれる。極は根軌跡を右へ押し出す。PI 制御の零点 −2.38 は、原点に足した極が押し出す分の多くを引き戻している。

## 5. 根軌跡で設計する — 減衰比の線とゲイン

### 減衰比の線との交点からゲインを決める

4 章 4 節では、行き過ぎ量 5 % 以下を $`\zeta \ge 0.690`$ に、2 % 整定時間 1 s 以下を、目安の式 $`t_{2\%} \approx 4/(\zeta\omega_\mathrm{n})`$ から根の実部 −4 以下に直し、根の平面の領域として描いた。原点から左上と左下へ、負の実軸と角 $`\psi`$（$`\cos\psi = \zeta`$）をなすように引いた半直線の上の極の組は、どれも同じ減衰比 $`\zeta`$ をもつ（4 章 2 節）。この半直線を**減衰比の線**と呼ぶ。根軌跡が仕様の領域を通るなら、そこにある区間の $`K_\mathrm{c}`$ を選べばよい。手順は次のとおりである。

1. 仕様から、減衰比の下限と、実部の上限を決める。
2. 根軌跡と、下限の減衰比の線との交点を求める。交点は、減衰比の線の上で角度の条件を満たす点である。
3. 交点での $`K_\mathrm{c}`$ を、大きさの条件で求める。
4. 閉ループのステップ応答で、仕様を満たすことを確かめる（ほかの極と零点の影響は 6 節）。

モータの位置の比例制御では、根軌跡の縦の線 $`\sigma = -10`$ と、$`\zeta`$ = 0.690（$`\psi`$ = 46.4°）の減衰比の線は、$`-10 + j10\tan 46.4^\circ = -10 + j10.49`$ で交わる。大きさの条件から $`K_\mathrm{c}`$ = 14.49 × 14.49 ÷ 1000 = 0.21 V/rad で、4 章 6 節で減衰比の式から求めた値と一致する。実部 −4 の縦の線とは実軸の上の −4 で交わり、そこでは $`K_\mathrm{c} = -\{(-4)^2 + 20 \times (-4)\}/1000`$ = 0.064 V/rad である。根軌跡は $`K_\mathrm{c}`$ = 0.064〜0.21 V/rad の間で領域の中にあり、立ち上がりが最も速いのは上の端の 0.21 V/rad である。ただし、領域は目安の式で描いたので、下の端の 0.064 V/rad では、実際の 2 % 整定時間は 1.05 s で、わずかに仕様を外れる。手順の 4 でステップ応答を確かめるのは、このためでもある。

```fig
e12_zline
```

仕様を厳しくして、2 % 整定時間を 0.25 s 以下（実部 −16 以下）にすると、比例制御の根軌跡は実部が −10 より左に出ないので（3 節の極の和）、どの $`K_\mathrm{c}`$ でも満たせない。4 節のとおり、零点を足して根軌跡を左へ曲げる。

### 角度の条件から零点の位置を決める

**方針**: 仕様を満たす極の位置 $`s_\mathrm{d}`$ を先に決め、根軌跡がそこを通るように、角度の条件から PD 制御の零点 $`z = -1/T_\mathrm{D}`$ の位置を求める。次に、大きさの条件から $`K_\mathrm{c}`$ を求める。

**導出**: 減衰比 0.690 の線の上で、実部を −20（2 % 整定時間の目安 0.2 s）にとると、$`s_\mathrm{d} = -20 + j20.98`$ である。開ループの極 0 と −20 からの矢印の角度は 133.6° と 90° なので、角度の条件 $`\angle(s_\mathrm{d} - z) - 133.6^\circ - 90^\circ = -180^\circ`$ から、零点からの矢印の角度は $`\angle(s_\mathrm{d} - z)`$ = 43.6° でなければならない。実軸の上の零点から、高さ 20.98 の点を 43.6° で見上げるので、零点は $`s_\mathrm{d}`$ の真下の −20 から 20.98 ÷ tan 43.6° = 22.0 だけ左の、$`z`$ = −42.0 にある。$`T_\mathrm{D} = -1/z`$ = 0.0238 s、$`\beta = 1000T_\mathrm{D}`$ = 23.8 で、大きさの条件から

$$
K_\mathrm{c} = \frac{|s_\mathrm{d}|\,|s_\mathrm{d} + 20|}{\beta\,|s_\mathrm{d} + 42.0|} = \frac{28.99 \times 20.98}{23.8 \times 30.41} = 0.840\ \text{V/rad}
$$

である ∎


得た $`K_\mathrm{P}`$ = 0.84 V/rad、$`K_\mathrm{D} = K_\mathrm{c}T_\mathrm{D}`$ = 0.02 V·s/rad は、10 章 3 節で、減衰の係数を 2 倍にする $`K_\mathrm{D}`$ を先に選び、減衰比をそろえる $`K_\mathrm{P}`$ を求めた値と同じである。ここでは逆に、望む極の位置から、角度の条件で零点を、大きさの条件でゲインを決めた。望む極を決めれば、零点の位置は 1 つに決まる。D 動作を測った制御量に掛ける（10 章 3 節）と、目標値のステップに対する応答は、行き過ぎ量 5.0 %、2 % 整定時間 0.207 s で、厳しくした仕様を満たす。

下の図で、仕様（行き過ぎ量と 2 % 整定時間の上限）と制御器（比例・PD）を選ぶと、仕様の領域と減衰比の線、根軌跡が描かれる。比例では交点のゲインが、PD では望む極（領域の中をドラッグ）から角度の条件で求めた零点とゲインが表示され、その応答で仕様を確かめられる。

## 6. 根軌跡の限界

根軌跡が示すのは、閉ループの極の位置だけである。5 節の設計は、選んだ極の組が支配極で（6 章 6 節）、応答がその組だけの二次遅れに近いことを前提にしていた。この前提が崩れる場合と、根軌跡そのものが描きにくい場合がある。

### 零点が応答に効く

閉ループ伝達関数 $`G_{yr}(s) = P(s)C(s)/\{1 + P(s)C(s)\}`$ の零点は、$`P(s)C(s)`$ の零点で、$`K_\mathrm{c}`$ を変えても動かない（7 章 2 節の分子 $`b_\mathrm{P}b_\mathrm{C}`$ の根）。根軌跡には現れないが、6 章 5 節のとおり、応答の行き過ぎを変える。5 節の PD 制御で、D 動作を偏差に掛けると、閉ループの極は同じ $`-20 \pm j20.98`$ のまま、$`G_{yr}(s)`$ に零点 −42 が加わり、行き過ぎ量は 5.0 % から 7.5 % に増える（2 % 整定時間は 0.207 s から 0.183 s）。10 章 6 節の測定値微分は、閉ループの極を変えずに、目標値の通り道からこの零点を除く。

### 支配極の近似が崩れる

4 節の PI 制御（$`K_\mathrm{c}`$ = 0.21 V/rad）の極の組 $`-8.40 \pm j9.26`$ は減衰比 0.672 で、組だけの二次遅れなら、行き過ぎ量は 5.8 %、2 % 整定時間は 0.48 s である。実際の応答は、行き過ぎ量 26.0 %、2 % 整定時間 1.00 s で、大きく違う（10 章 2 節の値）。実軸の上の極 −3.20 が組より虚軸に近く、支配極は組ではなくこの極だからである。単位ステップに対する応答の変換を部分分数分解すると（5 章 4 節）、この極の項は $`+0.48e^{-3.20t}`$ で、時定数 0.31 s でゆっくり減りながら、応答を持ち上げ続ける。零点 −2.38 は極 −3.20 に近いが一致してはいないので、極零相殺（6 章 6 節）は起きず、この項は残る。根軌跡で極の組を減衰比の線に乗せても、組より虚軸に近い極があると、応答は予想と違う。

### むだ時間は扱いにくい

9 章 1 節の、測った速度が 0.1 s 遅れる台車の比例制御では、特性方程式は $`s + 2 + K_\mathrm{c}e^{-0.1s} = 0`$ で、多項式の方程式にならない。根は無限にあり（9 章 1 節）、根軌跡には無限の本数の枝がある。根を数値で 1 つずつ探すことはできるが（下の図の (a)）、2 節の性質は特性方程式が多項式であることを使って導いたので、そのままでは使えない。

$`e^{-Ls}`$ を多項式の分数で近似すれば、根軌跡を描ける。最も簡単な近似 $`e^{-Ls} \approx (1 - Ls/2)/(1 + Ls/2)`$（1 次のパデ近似）は、右半平面の零点 $`+2/L`$ = +20 と、極 −20 を足す。右半平面の零点（6 章 5 節の非最小位相）があると、$`K_\mathrm{c}`$ を限りなく大きくしたとき枝の 1 本がそこで終わるので、比例ゲインを上げるといずれ不安定になる。むだ時間の性質の一部を表してはいるが、この近似の根軌跡が虚軸を横切るのは $`K_\mathrm{c}`$ = 22.0 N/(m/s)（21.9 rad/s）で、本当の 17.0 N/(m/s)（16.9 rad/s。9 章 1 節）から 3 割ずれる（この近似では $`\beta`$ が負になり、角度の条件の −180° が 0° に、実軸の上の部分の「奇数」が「偶数」に入れ替わる）。2 次の近似（右半平面の零点の組と、左半平面の極の組）では 17.2 N/(m/s) まで近づくが、近似の極と零点の分だけ枝が増え、本当には無い根も現れる。むだ時間を含むループの安定と余裕は、9 章のとおり、ナイキスト線図と位相余裕で近似なしに扱うほうが確かである（[9 章 6 節](09_安定性と安定余裕.md#むだ時間と安定余裕)）。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 根軌跡・枝 | $`C(s) = K_\mathrm{c}C_0(s)`$ の $`K_\mathrm{c}`$ を 0 から限りなく大きくまで変えたとき、閉ループの極（$`1 + K_\mathrm{c}P(s)C_0(s) = 0`$ の根）が s 平面に描く曲線／根 1 つが描く曲線。実軸について対称。数値で描くときは、1 つ前の $`K_\mathrm{c}`$ の根に近い根をつなぐ |
| 角度の条件・大きさの条件 | 開ループの零点からの矢印の角度の和 − 開ループの極からの角度の和 = 180° の奇数倍（根軌跡の上にあるか）／$`K_\mathrm{c}`$ = 極からの距離の積 ÷（$`\beta`$ × 零点からの距離の積）（そこでのゲイン）。モータの位置の $`-10 + j10.49`$ で 0.21 V/rad |
| 始点・終点・実軸の上の部分 | 開ループの極から出て、$`m`$ 本は開ループの零点で終わり、$`n - m`$ 本は限りなく遠くへ去る／右にある実数の極と零点の数の合計が奇数の区間 |
| 根軌跡の漸近線 | 遠くへ去る枝が近づく直線。$`\sigma_\mathrm{a} = (\sum p_i - \sum z_i)/(n - m)`$ から、角度 $`180^\circ \times (2q + 1)/(n - m)`$。$`n - m \ge 3`$ なら右半平面へ向かう |
| 分岐点 | 枝が実軸の上で出会って離れる（戻る）点。$`a'b - ab' = 0`$（$`dK_\mathrm{c}/d\sigma = 0`$）。モータの位置で −10（0.1 V/rad）。枝は実軸と直角に離れる |
| 極の和 | $`n - m \ge 2`$ なら閉ループの極の和は一定（比例ゲインで組の実部を左へ動かせない）、$`n - m = 1`$ なら $`K_\mathrm{c}\beta`$ ずつ左へずれる |
| 零点・極を足す | 零点は根軌跡を左へ引き寄せる（PD: 零点 −42 を中心とする円、0.84 V/rad で $`-20 \pm j21.0`$）／極は右へ押し出す（PI: 組の実部 −8.40、積分だけでは不安定） |
| 減衰比の線・設計 | 原点から負の実軸と $`\psi`$（$`\cos\psi = \zeta`$）をなす半直線。根軌跡との交点の $`K_\mathrm{c}`$ を大きさの条件で求める（0.21 V/rad）。届かなければ、望む極から角度の条件で零点を置く（PD: −42、0.84 V/rad） |
| 根軌跡の限界 | 閉ループの零点は根軌跡に現れず行き過ぎを変える（5.0 % → 7.5 %）。組より虚軸に近い極があると予想が外れる（PI: 5.8 % の予想に 26.0 %）。むだ時間では根が無限にあり、近似が要る（9 章のナイキスト線図で扱う） |

この章では、閉ループの極を s 平面の上で動かして制御器を選んだ。次章では、同じ設計を周波数の世界で行い、一巡伝達関数のボード線図の形を、位相を進める補償器と遅らせる補償器で整える。
