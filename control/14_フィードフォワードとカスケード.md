# 14. フィードフォワード・カスケード・むだ時間補償 — 制御系の構成

> **この章で扱う問い.**
> 7 章では、目標値・外乱・観測ノイズへの応答が、どれも 1 つの制御器 $`C(s)`$ と 1 つのフィードバックの輪で決まることを見た。10〜13 章では、その輪の中の制御器の選び方を扱い、11 章 3 節では、同じ制御器で決まるために、目標値への応答を良くすると外乱への応答が悪くなる例も見た。この章では、制御器の中身ではなく、信号の道の組み立て方（制御系の構成）を変える。輪の外に道を足す、輪を入れ子にする、輪の中に対象のモデルを置く、の 3 つである。
>
> この章では次の 3 つの問いに答える。
>
> 1. 目標値への応答と外乱への応答を、別々に決めるにはどうするか。
> 2. 目標値の動きや外乱の大きさが前もって分かるとき、偏差が生まれる前に操作量を出すにはどうするか。モデルが本当の対象と違うと、何が残るのか。
> 3. 対象の途中の量を測れるとき、むだ時間が長いとき、構成をどう変えると何が良くなり、その代わりに何を受け入れるのか。
>
> 答えの道具は、目標値と測った値に別々の伝達関数を掛ける制御器の式、モデルの逆、感度関数で縮む残りの偏差、入れ子にしたループの速さの比、そしてむだ時間を輪の外へ出すモデルである。

## 1. 2 自由度制御 — 目標値への応答と外乱への応答を分ける

7 章 2 節のフィードバック系では、制御器は偏差 $`E = R - (Y + N)`$ だけを受け取り、操作量を $`U = C(s)E`$ と決めた。このとき、目標値から制御量まで、操作量に入る外乱から制御量までの閉ループ伝達関数は

$$
G_{yr}(s) = \frac{P(s)C(s)}{1 + P(s)C(s)}, \qquad G_{yd}(s) = \frac{P(s)}{1 + P(s)C(s)}
$$

だった。どちらも同じ $`C(s)`$ で決まるので、外乱への応答に合わせて $`C(s)`$ を選ぶと、目標値への応答もそれで決まってしまう。

### 1 つの制御器では両方を選べない

11 章 3 節の温度の板（$`P(s) = 1.25e^{-20s}/(500s + 1)`$。操作量はヒータの電力 [W]、制御量は 60 °C からの温度のずれ [K]）の 2 つの PI 制御で確かめる。どちらも比例ゲインは $`K_\mathrm{P}`$ = 10 W/K で、積分時間だけが違う。

- (a) $`T_\mathrm{I}`$ = 500 s（11 章 3 節の IMC で λ = 20 s とした値。積分時間を板の時定数にそろえる）: 目標値を 1 K 上げると、行き過ぎ量 4.1 %・2 % 整定時間 122 s で落ち着く。ところが、ヒータの電力に −10 W の外乱が入ると、偏差の面積（IAE）は 500 K·s で、0.05 K 以内に戻るまで 1540 s かかる。
- (b) $`T_\mathrm{I}`$ = 160 s（11 章 3 節で、外乱を速く戻すために縮めた値）: 外乱の IAE は 160 K·s、戻るまで 457 s と 3 倍ほど速い。代わりに、目標値を 1 K 上げると 19.3 % 行き過ぎ、2 % 整定時間は 367 s に延びる。

外乱による偏差の面積は積分ゲイン $`K_\mathrm{I} = K_\mathrm{P}/T_\mathrm{I}`$ で決まる（11 章 1 節）ので、外乱を速く消すには積分時間を縮める。すると PI の零点 $`-1/T_\mathrm{I}`$ が板の極 $`-1/500`$ を打ち消さなくなり、閉ループの最も遅い極（−0.0078）より原点に近い −0.00625 に残る。この零点は $`P(s)C(s)`$ の零点なので $`G_{yr}`$ の分子に現れ、6 章 5 節のとおり行き過ぎを足す。一方、$`G_{yd}`$ の分子は $`P(s)`$ だけで、制御器の零点は現れない。行き過ぎの原因は目標値の通り道だけにあるのに、$`U = C(s)E`$ の形では、目標値の通り道だけを変えることができない。

### 目標値と測った値に別の伝達関数を掛ける

そこで、制御器が目標値と測った値を別々の伝達関数に通して、操作量を

$$
U = C_r(s)R - C_y(s)(Y + N)
$$

と決める形を考える。$`C_r(s)`$ は目標値に、$`C_y(s)`$ は測った値に掛ける伝達関数である（添字は掛ける信号の名前）。$`C_r = C_y = C`$ なら、7 章の $`U = C(s)E`$ に戻る。

**方針**: 7 章 2 節と同じく、加え合わせ点ごとの式を書いて $`Y`$ について解き、目標値・外乱・観測ノイズのそれぞれから制御量までの伝達関数を求める。

**導出**: 制御対象には $`U + D`$ が入るので

$$
Y = P(U + D) = PC_rR - PC_y(Y + N) + PD
$$

である。$`Y`$ の項を左辺に集めると $`(1 + PC_y)Y = PC_rR + PD - PC_yN`$ で、両辺を $`1 + PC_y`$ で割って

$$
Y(s) = \frac{P(s)C_r(s)}{1 + P(s)C_y(s)}R(s) + \frac{P(s)}{1 + P(s)C_y(s)}D(s) - \frac{P(s)C_y(s)}{1 + P(s)C_y(s)}N(s)
$$

となる ∎

閉ループの特性方程式 $`1 + P(s)C_y(s) = 0`$、外乱と観測ノイズへの応答、そして 7 章 5 節の感度関数 $`S = 1/(1 + PC_y)`$ は、すべて $`C_y(s)`$ だけで決まる。$`C_r(s)`$ が現れるのは、目標値から制御量までの伝達関数の分子だけである。したがって、まず $`C_y(s)`$ を外乱・観測ノイズ・余裕で選び、次に $`C_r(s)`$ で目標値への応答だけを整える、という順に決められる。独立に選べる伝達関数が 2 つあるこの形の制御を **2 自由度制御** という。$`U = C(s)E`$ は、選べる伝達関数が 1 つの 1 自由度制御である。

ただし、落ち着いた後に目標値へ届くこと（$`G_{yr}(0) = 1`$）は守る必要がある。$`C_y`$ が積分 $`K_\mathrm{I}/s`$ を含むとき、$`s \to 0`$ で $`P(s)C_y(s)`$ は限りなく大きくなり、$`G_{yr}(s)`$ は $`C_r(s)/C_y(s)`$ に近づく。$`C_r`$ の積分を $`K_\mathrm{I}'/s`$ とすると $`G_{yr}(0) = K_\mathrm{I}'/K_\mathrm{I}`$ なので、$`C_r`$ にも同じ積分 $`K_\mathrm{I}/s`$ を入れる。積分は、いつも偏差 $`r - y`$ に掛ける。

### 前置フィルタとフィードフォワード

$`C_r(s)`$ の作り方には、よく使う 2 つの形がある（図の (c)・(d)）。

- 目標値を、1 自由度のループに入れる前に、伝達関数 $`G_\mathrm{f}(s)`$ に通す。このような、目標値の形を整えるためにループの前に置く伝達関数を **前置フィルタ** という。$`C_r = G_\mathrm{f}C`$、$`C_y = C`$ なので、$`G_{yr}`$ は 1 自由度の $`G_{yr}`$ に $`G_\mathrm{f}`$ を掛けたものになる。
- 目標値から、輪の外の道で操作量を作って足す。$`U = C(R - Y) + C_\mathrm{ff}(s)R`$ で、$`C_r = C + C_\mathrm{ff}`$、$`C_y = C`$ である。偏差が生まれるのを待たず、目標値の動きや外乱の大きさのように前もって分かる信号から、輪の外の道で操作量を決めて出す制御を **フィードフォワード制御** という。フィードバックとは逆に、信号を前（対象の入力の側）へ送るのでこう呼ぶ。

前の章で使った制御器のいくつかは、すでに 2 自由度になっていた。

| 前の章の例 | $`C_r(s)`$ | $`C_y(s)`$ | 形 |
|---|---|---|---|
| 1 章 4 節: 決めた力 $`u_0 = cr`$ を足した台車の比例制御 | $`c + K_\mathrm{P}`$ | $`K_\mathrm{P}`$ | フィードフォワード（$`C_\mathrm{ff} = c`$） |
| 6 章 5 節: 目標値の変わる速さに比例した電圧を足したモータの角度の比例制御 | $`K_\mathrm{f}s + K_\mathrm{P}`$ | $`K_\mathrm{P}`$ | フィードフォワード（$`C_\mathrm{ff} = K_\mathrm{f}s`$） |
| 10 章 6 節: 測定値微分の PID | $`K_\mathrm{P} + K_\mathrm{I}/s`$ | $`K_\mathrm{P} + K_\mathrm{I}/s + K_\mathrm{D}s`$ | D 動作を目標値に掛けない |
| 10 章 6 節: 目標値の重み $`b`$ の PI | $`K_\mathrm{P}\{b + 1/(T_\mathrm{I}s)\}`$ | $`K_\mathrm{P}\{1 + 1/(T_\mathrm{I}s)\}`$ | 前置フィルタ（下で導く） |

目標値の重みが前置フィルタと同じであることを確かめる。

**方針**: $`C_r(s)`$ を、$`C_y(s)`$ と、残りの因数の積に分ける。

**導出**: $`C_r = K_\mathrm{P}(bT_\mathrm{I}s + 1)/(T_\mathrm{I}s)`$、$`C_y = K_\mathrm{P}(T_\mathrm{I}s + 1)/(T_\mathrm{I}s)`$ なので

$$
C_r(s) = C_y(s)\,\frac{bT_\mathrm{I}s + 1}{T_\mathrm{I}s + 1}
$$

である。目標値の重み $`b`$ は、前置フィルタ $`G_\mathrm{f}(s) = (bT_\mathrm{I}s + 1)/(T_\mathrm{I}s + 1)`$ と同じ働きをする ∎

この前置フィルタの極 $`-1/T_\mathrm{I}`$ は、$`G_{yr}`$ の中の PI の零点を打ち消し、代わりに零点 $`-1/(bT_\mathrm{I})`$ を置く。$`b < 1`$ なら新しい零点は原点から遠く、行き過ぎが減る。温度の板の (b) の PI に $`b`$ = 0.8（$`G_\mathrm{f} = (128s + 1)/(160s + 1)`$）を足して、3 つを比べる。

(c) の外乱への応答は (b) と同じで、目標値への応答は行き過ぎ量 2.6 %・2 % 整定時間 127 s と、(a) とほぼ同じになる。外乱への応答は $`C_y`$ で、目標値への応答はさらに $`C_r`$ で決まる。前置フィルタは、ループが作る応答の形を目標値の側で整える道具である。目標値の動きに要る操作量を、対象のモデルから計算して先に出せば、ループの偏差を待たずに動かせる。これが 2 節の方法である。

## 2. 目標値のフィードフォワード — モデルの逆で先回りする

1 章 3 節では、台車を 1 m/s で走らせるのに要る力 $`u_0 = cr`$ を前もって計算して出した。7 章 3 節のとおり、これは要る力を偏差からではなく目標値から作ったことにあたる。この節では、この考え方を、目標値が時間とともに動く場合に広げる。例は、モータの角度（電圧から角度まで $`P(s) = K/\{s(Ts + 1)\}`$、$`K`$ = 50 (rad/s)/V、$`T`$ = 0.05 s。巻線のインダクタンスは無視する）を、決めた形で 10 rad 回す動きとする。

### モデルの逆

**方針**: 角度が目標値に一致する（$`\theta_\mathrm{m}(t) = r(t)`$）としてモータの式に入れ、そのとき要る電圧を逆に求める。

**導出**: モータの角度の式は $`T\ddot\theta_\mathrm{m} + \dot\theta_\mathrm{m} = Kv`$（4 章 6 節）である。$`\theta_\mathrm{m} = r`$ を入れて $`v`$ について解くと

$$
v_\mathrm{ff}(t) = \frac{T\ddot r(t) + \dot r(t)}{K}
$$

となる。初めに角度と角速度が目標値と同じ（止まった所から動き始める）なら、この電圧を加えたときの微分方程式の解は $`\theta_\mathrm{m} = r`$ である。ラプラス変換で書くと $`V_\mathrm{ff}(s) = \{(Ts^2 + s)/K\}R(s) = P(s)^{-1}R(s)`$ で、対象の伝達関数の逆数を目標値に掛けている ∎

このように、対象のモデル $`\tilde P(s)`$（11 章 3 節の記号）の逆 $`\tilde P(s)^{-1}`$ を目標値に掛けて操作量を作るフィードフォワードを **目標値フィードフォワード** という。モデルが正しければ、フィードバックが無くても制御量は目標値どおりに動く。

$`\tilde P^{-1}`$ は分子の次数が分母より 2 高い（6 章 2 節のプロパーでない）ので、目標値の 2 階の微分 $`\ddot r`$ が要る。段差の目標値は $`\dot r`$ が限りなく大きくなるので使えない。ここでは、目標値を、角加速度 500 rad/s² で 0.1 s 加速し、50 rad/s で 0.1 s 回り、0.1 s で減速して止まる形にする（角速度の形が台形になるので、台形の速度の目標という）。

```fig
e14_ff_inv
```

電圧は、角速度の分 $`\dot r/K`$（逆起電力と釣り合う電圧。最大 1 V）と、角加速度の分 $`T\ddot r/K`$（慣性を加速する電圧。±0.5 V）の和で、最大 1.5 V である。前の章の例は、この式の一部にあたる。

- 1 章 3 節の決めた力 $`u_0 = cr`$ は、台車の速度のモデル $`1/(ms + c)`$ の逆 $`ms + c`$ のうち、$`s`$ = 0 の値 $`c`$ だけを使ったものである。目標値が一定なら $`\dot r`$ = 0 なので、これで足りる。
- 6 章 5 節で足した電圧 $`K_\mathrm{f}\dot r`$（$`K_\mathrm{f}`$ = 0.021 V·s/rad）は、角速度の分 $`\dot r/K`$（$`1/K`$ = 0.02 V·s/rad）にほぼ等しい。

### フィードバックと組み合わせる

フィードフォワードだけでは開ループ制御なので、モデルの誤差や外乱による偏差は直せない（1 章 3 節）。そこで、フィードバックの制御器 $`C(s)`$ と並べて、$`U = C(s)(R - Y) + \tilde P(s)^{-1}R`$ とする。

**方針**: 偏差 $`E = R - Y`$ を、目標値 $`R`$ と、本当の対象とモデルの比 $`P/\tilde P`$ で表す。

**導出**: $`Y = PU = PC(R - Y) + P\tilde P^{-1}R`$ なので、$`Y`$ の項を左辺に集めて $`(1 + PC)Y = (PC + P\tilde P^{-1})R`$ である。$`E = R - Y`$ に入れて通分すると、分子は $`(1 + PC) - PC - P\tilde P^{-1} = 1 - P/\tilde P`$ なので

$$
E(s) = \frac{1}{1 + P(s)C(s)}\left(1 - \frac{P(s)}{\tilde P(s)}\right)R(s) = S(s)\left(1 - \frac{P(s)}{\tilde P(s)}\right)R(s)
$$

となる ∎

- モデルが正しい（$`P = \tilde P`$）なら、どんな目標値の動きにも偏差は 0 で、フィードバックは目標値のためには働かない。
- フィードバックだけ（フィードフォワードなし）なら $`E = SR`$ である。両方を使うと、フィードフォワードだけのときの偏差 $`(1 - P/\tilde P)R`$ が、フィードバックで $`S`$ 倍に縮む。
- 閉ループの特性方程式は $`1 + PC = 0`$ のままで、フィードフォワードは安定性を変えない。輪の外の道だからである。

フィードバックの制御器は、10 章 3 節の PD（$`K_\mathrm{P}`$ = 0.84 V/rad、$`K_\mathrm{D}`$ = 0.02 V·s/rad）とする。目標値に段差が無いので、D 動作は偏差に掛ける（段差で操作量が跳ねる微分キックは起きない。10 章 6 節）。フィードフォワードの式の項を 1 つずつ足して比べる。

- フィードバックだけ: 回っている間に要る 1 V を、P の分が偏差から作るので、偏差は 1 ÷ 0.84 = 1.19 rad になる（10 章 1 節の $`e_\infty = u_\infty/K_\mathrm{P}`$ と同じ考え方）。最大の偏差は 1.39 rad で、目標値が止まった 0.3 s から 0.2 s 後に、やっと 0.01 rad 以内に入る。
- 角速度の分だけを足す（6 章 5 節の形）: 回っている間の偏差は消えるが、加速と減速の間は角加速度の分 0.5 V が足りず、0.5 ÷ 0.84 = 0.595 rad の偏差が残る。
- 両方の分を足す: 偏差はどの時刻でも 0（数値計算で 0.0001 rad 以下）になる。
- モデルの誤差（図の (b)）: 負荷の分だけ慣性モーメントが 1.5 倍（$`T`$ = 0.075 s）だと、フィードフォワードだけでは最大 1.08 rad ずれるが、フィードバックを合わせると 0.31 rad に縮む。電源の電圧が下がって電圧の効きが 0.8 倍（$`K`$ = 40 (rad/s)/V）になると、フィードフォワードだけでは止まった後も 2.00 rad ずれたままだが、フィードバックを合わせると最大 0.34 rad で、止まった後は 0 に戻る。

### 段差の目標値と前置フィルタ

目標値が段差で変わるとき、$`\tilde P^{-1}R`$ は限りなく大きな操作量を求める。そこで、目標値をまず前置フィルタ $`G_\mathrm{f}(s)`$ に通してなめらかにし、フィルタの出力 $`R_\mathrm{m} = G_\mathrm{f}R`$ を、フィードフォワードとフィードバックの両方の目標値にする。$`U = C(R_\mathrm{m} - Y) + \tilde P^{-1}G_\mathrm{f}R`$ で、上の導出の $`R`$ を $`R_\mathrm{m}`$ に置き換えると、偏差は $`R_\mathrm{m} - Y = S(1 - P/\tilde P)R_\mathrm{m}`$ である。モデルが正しければ、制御量は $`G_\mathrm{f}R`$ にちょうど一致する。$`\tilde P^{-1}G_\mathrm{f}`$ がプロパーになるように $`G_\mathrm{f}`$ を選べば、操作量は有限である。

温度の板では、モデル $`\tilde P = 1.25e^{-20s}/(500s + 1)`$ の逆はむだ時間の逆 $`e^{+20s}`$ を含み、20 s 先の値を使うので作れない（11 章 3 節）。そこで、前置フィルタにも同じむだ時間を入れて $`G_\mathrm{f}(s) = e^{-20s}/(\lambda s + 1)`$ とする。むだ時間が打ち消し合い

$$
\tilde P(s)^{-1}G_\mathrm{f}(s) = \frac{500s + 1}{1.25(\lambda s + 1)}
$$

となる。これは 11 章 3 節の IMC の $`Q(s)`$ そのものである。フィードバックの制御器は、1 節の (b) の PI（10 W/K・160 s）のままにする。

λ = 20 s では、制御量は 20 s 遅れて動き始め、時定数 20 s で行き過ぎずに目標値に近づく（2 % 整定時間 98 s）。始めにヒータの電力を 500/(1.25 × 20) = 20 W 増やし、それが 0.8 W まで減っていく。フィードバックの PI は外乱への応答を受け持つので、外乱の IAE は 1 節の (b) と同じ 160 K·s のままである。本当のむだ時間が 25 s のときや定常ゲインが 1.3 倍のときも、行き過ぎ量は 6.9 %・5.7 % にとどまり、1 節の (b) の 19.3 % より小さい。

## 3. 外乱のフィードフォワード — 測れる外乱を打ち消す

1 章 3 節では、坂の角度が前もって分かれば、決めた力に坂の力の分を足せばよいが、角度の見込みが違うと速度がずれることを見た。外乱の大きさをセンサで測れるなら、その値から操作量を作って足し、外乱が制御量に現れる前に打ち消せる。

### 測った外乱から操作量を作る

外乱 $`d`$ が、対象の中の伝達関数 $`P_d(s)`$ を通って制御量に現れるとする（$`Y = PU + P_dD`$）。外乱を測った値を $`\hat d`$ とし、モデル $`\tilde P`$・$`\tilde P_d`$ を使って、操作量に $`-\{\tilde P_d(s)/\tilde P(s)\}\hat D`$ を足す。

**方針**: 目標値を 0、測った値を正しい（$`\hat d = d`$）として、外乱から制御量までの伝達関数を、フィードフォワードの道とフィードバックの輪の両方を通して書く。

**導出**: $`U = -CY - (\tilde P_d/\tilde P)D`$ なので

$$
Y = PU + P_dD = -PCY - P\frac{\tilde P_d}{\tilde P}D + P_dD
$$

である。$`Y`$ の項を左辺に集めて両辺を $`1 + PC`$ で割ると

$$
Y(s) = S(s)\left(P_d(s) - P(s)\frac{\tilde P_d(s)}{\tilde P(s)}\right)D(s)
$$

となる ∎

モデルが正しければ、外乱は制御量に現れない。括弧の中は、フィードフォワードだけのとき（開ループ）に残る分で、フィードバックがそれを $`S`$ 倍に縮める。2 節と同じく、閉ループの特性方程式は変わらない。外乱を測った値から、その影響を打ち消す操作量を作って足すことを **外乱フィードフォワード** という。外乱が操作量と同じ所から入る（$`P_d = P`$）なら、足すのは測った外乱の符号を変えた $`-\hat d`$ だけである。$`\tilde P_d/\tilde P`$ が、まだ来ていない外乱の値を使う形（外乱のほうが操作量より速く制御量に届く）になるときは、作れる部分だけを足し、残りはフィードバックに任せる。

1 章の台車（$`m`$ = 1 kg、$`c`$ = 2 N·s/m、目標 1 m/s）に、傾きのセンサを載せて、坂の力を測る。坂の力は操作量（押す力）と同じ所に入るので、足す力は測った角度 $`\hat\varphi`$ から $`mg\sin\hat\varphi`$ である（7 章 2 節の向きでは $`d = -mg\sin\varphi`$）。本当の坂が 4°（0.684 N）で、センサが 1° 小さく 3°（0.513 N）と読む場合を比べる（図の (b)）。

## 4. カスケード制御 — 内側のループで速い乱れを抑える

3 節の方法は、外乱そのものを測れることが前提だった。外乱が測れなくても、外乱が通っていく途中の量（モータの電流や角速度、ヒータの電力）なら測れることがある。

### 輪を入れ子にする

対象を、途中の量 $`y_2`$ で 2 つに分ける。操作量 $`u`$ から $`y_2`$ までを $`P_2(s)`$、$`y_2`$ から制御量 $`y_1`$ までを $`P_1(s)`$ とする（添字の 2 が内側、1 が外側）。$`y_2`$ を測ってその目標値 $`r_2`$ に合わせる輪を作り、$`y_1`$ を目標値 $`r_1`$ に合わせる制御器 $`C_1(s)`$ の出力を、$`r_2`$ として渡す。このように、途中の量を制御する輪を内側に入れ、外側の制御器がその目標値を決める構成を **カスケード制御** という。途中の量を制御する輪を **内側のループ**（**マイナーループ**）、制御量を目標値に合わせる輪を **外側のループ** という。

```fig
e14_casc_bd
```

モータの角度では、電圧から電流（電気の遅れ、時定数 0.5 ms）、電流から角速度（機械の遅れ）、角速度から角度（積分）の順に信号が伝わる（2 章 3 節）。電流・角速度・角度を測り、内側から電流のループ、角速度のループ、角度のループと 3 段に入れ子にするのが、モータの位置決めでよく使われる構成である。ヒータでは、ヒータの電力を測って指令に合わせる輪を内側に、温度の輪を外側に置く。

### 内側に入る外乱を内側で止める

**方針**: 外乱 $`d_2`$ が内側の対象の入口に入る（$`y_2 = P_2(u + d_2)`$）とする。内側のループの式から $`y_2`$ を求め、それを外側の式に入れて、$`d_2`$ から $`y_1`$ までの伝達関数を、内側のループが無い場合と比べる。

**導出**: 内側は $`u = C_2(r_2 - y_2)`$ なので、7 章 2 節と同じ手順で

$$
Y_2 = G_2R_2 + S_2P_2D_2, \qquad G_2 = \frac{P_2C_2}{1 + P_2C_2}, \quad S_2 = \frac{1}{1 + P_2C_2}
$$

である（$`G_2`$ は内側の閉ループ伝達関数、$`S_2`$ は内側の感度関数）。外側は $`Y_1 = P_1Y_2`$、$`R_2 = C_1(R_1 - Y_1)`$ なので、$`Y_1 = P_1G_2C_1(R_1 - Y_1) + P_1S_2P_2D_2`$ で、$`Y_1`$ について解くと

$$
Y_1 = \frac{P_1G_2C_1}{1 + P_1G_2C_1}R_1 + \frac{P_1S_2P_2}{1 + P_1G_2C_1}D_2
$$

となる。内側のループが無く、1 つの制御器 $`C`$ が $`y_1`$ だけを見て $`u`$ を出す場合は、同じ手順で $`D_2`$ の係数が $`P_1P_2/(1 + P_1P_2C)`$ になる ∎

内側のループがあると、$`d_2`$ は外側の輪に届く前に $`S_2`$ 倍に縮む。内側のループのゲインが大きい角周波数、つまり内側のバンド幅より遅い乱れは、外側の制御量に現れる前に内側で打ち消される。

モータの角度を止めておく所に、負荷トルク 0.01 N·m が加わる場合で比べる（巻線のインダクタンスを含めた式。電源 12 V）。負荷トルクは電流と角速度の間に入る。

- 角度の PID だけ（10 章 5 節。0.84 V/rad・$`T_\mathrm{I}`$ = 0.168 s・$`T_\mathrm{D}`$ = 0.0238 s）: 最大 1.05 rad ずれる。
- 角速度のループを内側に置く 2 段（角速度の PI は 10 章 5 節の 0.1 V/(rad/s)・0.05 s、角度は比例 20 /s）: 0.20 rad。
- さらに電流のループを内側に置く 3 段（電流の PI は 5 V/A・0.5 ms、角速度の PI は 0.5 A/(rad/s)・4 ms、角度は比例 200 /s。値はどれも例の値）: 0.002 rad。

3 段では、電流が 0.5 ms で変わるので、電流のループを速く（閉ループの時定数 0.2 ms）でき、その外の角速度のループも速くできる。負荷トルクは、角度がほとんど動かないうちに、角速度のループの積分が電流を 0.5 A 増やして支える。もう 1 つの利点は、途中の量に上限を置けることである。角速度の制御器が出す電流の指令を、決めた上限（例 1 A）で切れば、軸が何かに当たって止められても、電流はその上限を超えない（図の (b)）。角度の PID だけでは、止められている間に積分がたまって電圧が上がり、電流は 12 V ÷ 2 Ω = 6 A に向かう（[電源と周辺の制御シリーズ 13 章 4 節](../periph/13_モータを回す.md#電流を測って守る)の拘束）。

ヒータの電力は、同じデューティ比でも電源の電圧の 2 乗に比例する（[電源と周辺の制御シリーズ 14 章 4 節](../periph/14_熱を扱う.md#交流の-1-周期を単位に入れ切りする)のように、交流の周期を単位に入れ切りする場合）。商用電源の電圧が 100 V から 90 V に下がると、電力は 0.81 倍になり、60 °C を保っていた 28 W は 22.7 W に減る（−5.3 W の外乱）。温度の PI（10 W/K・160 s）だけでは、むだ時間の後に気づいて直すので、0.55 K 下がる。ヒータの電力を 1 s ごとに測り、指令に合わせてデューティ比を直す内側のループ（閉ループの時定数 2 s）を置くと、温度が動く前に電力が戻り、下がるのは 0.03 K で済む（図の (c)）。電源の電圧を測ってデューティ比を $`(100/V)^2`$ 倍に直す外乱フィードフォワードでも打ち消せるが、内側のループは、ヒータの抵抗が温度や年月で変わる場合も、測った電力で直す。

```fig
e14_casc_dist
```

角度・角速度・電流のように、測った量のそれぞれにゲインを掛けて足し合わせる制御（状態フィードバック。詳しくは 18 章）でも、同じ閉ループの極を作れる。カスケード制御は、それを内側から 1 つずつ PI で決め、途中の量に上限を置きやすい形にしたものと言える。

### 内側を外側より速くする

内側のループが遅いと、外側から見て余分な遅れになる。どれだけ速ければよいかを求める。

**方針**: 内側の閉ループ $`G_2`$ を、時定数 $`T_2`$ の一次遅れ $`1/(T_2s + 1)`$ で近づける。外側の対象が角速度から角度への積分 $`P_1 = 1/s`$、外側の制御器が比例 $`C_1 = K_\mathrm{P1}`$ のとき、外側の特性方程式を 4 章 1 節の二次遅れの標準形と比べる。

**導出**: $`1 + P_1G_2C_1 = 1 + K_\mathrm{P1}/\{s(T_2s + 1)\} = 0`$ の分母を払うと $`T_2s^2 + s + K_\mathrm{P1} = 0`$ で、$`T_2`$ で割ると $`s^2 + s/T_2 + K_\mathrm{P1}/T_2 = 0`$ である。標準形 $`s^2 + 2\zeta\omega_\mathrm{n}s + \omega_\mathrm{n}^2`$ と比べて $`\omega_\mathrm{n} = \sqrt{K_\mathrm{P1}/T_2}`$、$`2\zeta\omega_\mathrm{n} = 1/T_2`$ なので

$$
\zeta = \frac{1}{2\sqrt{K_\mathrm{P1}T_2}} = \frac{1}{2}\sqrt{\frac{1/T_2}{K_\mathrm{P1}}}
$$

となる ∎

$`K_\mathrm{P1}`$ は、外側の一巡伝達関数 $`K_\mathrm{P1}/s`$ のゲインが 1 になる角周波数、つまり外側のゲイン交差角周波数のおよその値で、$`1/T_2`$ は内側のバンド幅である。内側が外側の何倍速いかで、減衰比が決まる。

| 内側の速さ $`1/T_2`$ ÷ 外側の $`K_\mathrm{P1}`$ | 1 | 2 | 4 | 10 |
|---|---|---|---|---|
| 減衰比 $`\zeta`$（式） | 0.50 | 0.71 | 1.0 | 1.6 |
| 行き過ぎ量（式） | 16.3 % | 4.3 % | 0 % | 0 % |
| モータの 2 段（$`T_2`$ = 0.01 s）で $`K_\mathrm{P1}`$ を 100・50・25・10 /s にした数値計算 | 17.2 % | 4.2 % | 0 % | 0 % |

内側を外側の 4 倍以上速くすると、外側の応答は振動しない。内側が遅いほど、外側から見た遅れ（9 章 6 節の、小さな遅れはむだ時間のように位相を遅らせること）が大きくなり、行き過ぎる。目安として、内側のバンド幅を外側の交差角周波数の 3〜10 倍にとることが多い。調整は内側から順に行い、内側を決めてから外側を決める。

## 5. むだ時間の補償 — スミス予測器

むだ時間があるループでは、測った値が遅れて届くので、制御器は古い値に応え続ける（1 章 5 節）。位相が $`\omega L`$ だけ遅れるので、制御器を強くするほど余裕が減る（9 章 6 節）。むだ時間の前の制御量を測れればこの問題は無いが、測れない。そこで、それをモデルで計算する。

### モデルで、むだ時間の前の制御量を作る

モデルを、むだ時間の無い部分 $`\tilde P_0(s)`$ と、むだ時間 $`\tilde L`$ に分けて $`\tilde P(s) = \tilde P_0(s)e^{-\tilde Ls}`$ と書く（温度の板では $`\tilde P_0 = 1.25/(500s + 1)`$、$`\tilde L`$ = 20 s）。制御器が出した操作量 $`u`$ をモデルに入れ、むだ時間の無いモデルの出力 $`\tilde y_0`$（$`\tilde Y_0 = \tilde P_0U`$）と、それを $`\tilde L`$ 遅らせたもの $`\tilde y_0(t - \tilde L)`$ を計算する。測った値に、この 2 つの差を足した

$$
y_\mathrm{p}(t) = y(t) + \tilde y_0(t) - \tilde y_0(t - \tilde L)
$$

を、制御器 $`C(s)`$ に戻す。モデルが正しく外乱も無ければ、$`y(t)`$ は $`\tilde y_0(t - \tilde L)`$ に等しいので、$`y_\mathrm{p}`$ は $`\tilde y_0(t)`$、つまり、むだ時間の前の制御量になる。このように、モデルで計算したむだ時間の前の制御量を戻す構成を **スミス予測器** という（スミスが 1957 年に示した）。

```fig
e14_smith_bd
```

**方針**: モデルが正しい（$`\tilde P_0 = P_0`$、$`\tilde L = L`$）として、目標値から制御量までの伝達関数と、閉ループの特性方程式を求める。

**導出**: 対象は $`Y = P_0e^{-Ls}U`$ なので、$`Y_\mathrm{p} = P_0e^{-Ls}U + P_0U - P_0e^{-Ls}U = P_0U`$ である。$`U = C(R - Y_\mathrm{p}) = C(R - P_0U)`$ から $`U = \{C/(1 + P_0C)\}R`$ で、制御量は

$$
Y(s) = e^{-Ls}\,\frac{P_0(s)C(s)}{1 + P_0(s)C(s)}\,R(s)
$$

となる。分母の $`1 + P_0(s)C(s)`$ にむだ時間が無いので、閉ループの特性方程式 $`1 + P_0C = 0`$ にもむだ時間は無い ∎

むだ時間が輪の外へ出て、目標値への応答は、むだ時間の無い対象 $`P_0`$ を $`C`$ で制御した応答を、$`L`$ だけ遅らせたものになる。$`C`$ は、むだ時間を気にせずに決められる。ただし 13 章 5 節のとおり、むだ時間より前に制御量を動かすことはどの方法でもできない。スミス予測器も、応答がむだ時間だけ遅れることは変えない。

### 内部モデル制御との関係

スミス予測器も 11 章 3 節の IMC も、制御器の中にモデルを持つ。2 つの関係を調べる。

**方針**: スミス予測器の式を、11 章 3 節と同じく、$`R - Y`$ に掛かる 1 つの伝達関数にまとめ、IMC の $`Q/(1 - \tilde PQ)`$ と比べる。

**導出**: $`U = C(R - Y_\mathrm{p}) = C(R - Y - \tilde P_0U + \tilde P_0e^{-\tilde Ls}U)`$ の $`U`$ の項を左辺に集めると $`\{1 + C\tilde P_0(1 - e^{-\tilde Ls})\}U = C(R - Y)`$ なので、$`R - Y`$ に掛かる伝達関数は $`C/\{1 + C\tilde P_0(1 - e^{-\tilde Ls})\}`$ である。一方、IMC で $`Q = C/(1 + \tilde P_0C)`$ とおくと

$$
1 - \tilde P Q = 1 - \frac{\tilde P_0e^{-\tilde Ls}C}{1 + \tilde P_0C} = \frac{1 + \tilde P_0C - \tilde P_0Ce^{-\tilde Ls}}{1 + \tilde P_0C}
$$

なので、$`Q/(1 - \tilde PQ) = C/\{1 + C\tilde P_0(1 - e^{-\tilde Ls})\}`$ となり、同じ伝達関数になる ∎

スミス予測器は、$`Q = C/(1 + \tilde P_0C)`$ とした IMC である。逆に、11 章 3 節の $`Q = (Ts + 1)/\{K(\lambda s + 1)\}`$ からは、$`1 - \tilde P_0Q = 1 - 1/(\lambda s + 1) = \lambda s/(\lambda s + 1)`$ なので $`C = Q/(1 - \tilde P_0Q) = (Ts + 1)/(K\lambda s)`$、つまり $`K_\mathrm{P} = T/(K\lambda)`$・$`T_\mathrm{I} = T`$ の PI が出てくる。11 章 3 節で、むだ時間を近似して PI にした IMC を、近似せずに使うと、この PI のスミス予測器になる。このとき $`P_0C = 1/(\lambda s)`$ なので、目標値への応答はちょうど $`e^{-Ls}/(\lambda s + 1)`$ である。

### 温度の板で比べる

```fig
e14_smith_resp
```

目標値を 1 K 上げると、λ = 20 s のスミス予測器（PI は 20 W/K・500 s）は行き過ぎ量 0 %・2 % 整定時間 98 s、λ = 10 s（40 W/K・500 s）は 0 %・59 s で、1 節の (a)（4.1 %・122 s）・(b)（19.3 %・367 s）より速く、行き過ぎない。始めにヒータの電力を 20 W・40 W 増やす。

ところが、−10 W の外乱には、λ = 10 s でも偏差の面積が 375 K·s で、1 節の (b) の 160 K·s より大きく、0.05 K に戻るまで 1390 s かかる。面積を求めて、理由を調べる。

**方針**: 11 章 1 節と同じく、積分の始めと終わりの値から面積を求める。まず制御器が見る $`y_\mathrm{p}`$ の面積を求め、$`y`$ と $`y_\mathrm{p}`$ の差の面積を足す。モデルは正しいとする。

**導出**: 落ち着いた後は $`y`$ も $`y_\mathrm{p}`$ も 0 で、操作量は外乱を打ち消す $`-d`$ になっている。$`C`$ の P の分は 0 に戻るので、変わったのは I の分で、$`K_\mathrm{I}\int_0^\infty(0 - y_\mathrm{p})\,dt = -d`$、つまり $`\int y_\mathrm{p}\,dt = d/K_\mathrm{I}`$ である。次に、$`y = y_\mathrm{p} - \{\tilde y_0(t) - \tilde y_0(t - L)\}`$ の括弧の面積を求める。$`\tilde y_0`$ は 0 から始まるので、時刻 $`\tau`$ までの面積は $`\int_0^\tau \tilde y_0\,dt - \int_0^{\tau - L}\tilde y_0\,dt = \int_{\tau - L}^{\tau}\tilde y_0\,dt`$ で、$`\tau`$ を大きくすると $`L\tilde y_0(\infty)`$ に近づく。$`\tilde y_0(\infty) = K \times (-d)`$ なので

$$
\int_0^\infty y\,dt = \frac{d}{K_\mathrm{I}} + KLd
$$

となる ∎

PI だけなら面積は $`d/K_\mathrm{I}`$ である（11 章 1 節）。スミス予測器では、そこに $`KLd`$ が加わる。予測器は、出した操作量がむだ時間の後に効くことを知っているので、外乱で温度が下がっても、その分を直す操作量を出した時点で、$`y_\mathrm{p}`$ の上では偏差が消えたとみなす。本当の温度が戻るまでのむだ時間 $`L`$ の間のずれが、面積 $`KLd`$ として残る。温度の板では $`KL`$ = 25 K·s/W なので、10 W の外乱で 250 K·s で、これだけで (b) の 160 K·s を超える。さらに、目標値への応答を整えた PI（$`T_\mathrm{I}`$ = 500 s）の零点が板の遅い極を打ち消しているので、外乱によるずれは板の時定数 500 s でしか戻らない（11 章 3 節）。

むだ時間が時定数よりずっと短い温度の板では、外乱にはスミス予測器より PI のほうが強い。目標値への応答だけなら、2 節の前置フィルタとフィードフォワードでも同じ $`e^{-Ls}/(\lambda s + 1)`$ を作れる。スミス予測器が役に立つのは、むだ時間が時定数と同じくらいかそれより長く、PI では積分を強くできない対象（物を運ぶ時間が長い装置など）である。

### むだ時間のずれに弱い

スミス予測器は、むだ時間のモデルが正しいことを使って、むだ時間を輪の外へ出した。本当のむだ時間 $`L`$ がモデルの $`\tilde L`$ と違うと、輪の中にむだ時間が戻ってくる。

**方針**: $`P_0`$ は正しく、むだ時間だけが違う（$`L \ne \tilde L`$）として、閉ループの特性方程式を書く。$`P_0C = 1/(\lambda s)`$ の場合に、9 章 4 節のナイキストの安定判別法で、安定であるための条件を求める。

**導出**: $`Y = P_0e^{-Ls}U`$ と $`U = C(R - Y - P_0U + P_0e^{-\tilde Ls}U)`$ から、$`U`$ の係数は $`1 + CP_0(1 + e^{-Ls} - e^{-\tilde Ls})`$ で、これが 0 になる $`s`$ が閉ループの極である。$`CP_0 = 1/(\lambda s)`$ を入れて $`\lambda s`$ を掛け、$`\lambda s + 1`$ で割ると

$$
1 + G(s) = 0, \qquad G(s) = \frac{e^{-Ls} - e^{-\tilde Ls}}{\lambda s + 1}
$$

である（$`\lambda s + 1 = 0`$ の根 $`-1/\lambda`$ は左半平面にあるので、割っても右半平面の根の数は変わらない）。$`G(s)`$ は安定なので、9 章 4 節のとおり、$`G(j\omega)`$ の線図が −1 の点を回らなければ閉ループは安定で、どの $`\omega`$ でも $`|G(j\omega)| < 1`$ ならそうなる。分子の大きさは $`|e^{-j\omega L} - e^{-j\omega\tilde L}| = |1 - e^{-j\omega(\tilde L - L)}| = 2|\sin\{\omega(L - \tilde L)/2\}|`$ で、$`|\sin x| \le |x|`$ から $`\omega|L - \tilde L|`$ 以下である。分母の大きさ $`\sqrt{1 + (\omega\lambda)^2}`$ は $`\omega\lambda`$ より大きい。したがって $`|G(j\omega)| < |L - \tilde L|/\lambda`$ で

$$
|L - \tilde L| \le \lambda \quad \Rightarrow \quad \text{安定}
$$

となる ∎

これは十分な条件で、外れても不安定になるとは限らない。それでも、λ を小さくして速くするほど、むだ時間の読み誤りに弱くなることが分かる。PI と違い、本当のむだ時間がモデルより短い側に外れても不安定になりうる。

```fig
e14_smith_robust
```

λ = 10 s では、本当のむだ時間が 0〜52 s の範囲で安定で、1 節の (b) の PI（55 s まで）とほぼ同じ程度に強い。λ = 5 s にすると、本当のむだ時間が 5.8〜12.5 s（モデルより短い）、27〜39 s、46 s 以上のどれでも、振動が大きくなり続ける。スミス予測器を使うときは、むだ時間を測り直せるようにしておき（物を運ぶ速さが変わる装置なら、速さからむだ時間を計算し直す）、λ を、むだ時間が変わりうる幅より大きくとる。

## 6. 構成の選び方

この章の構成は、何を測れるか、何を前もって知っているかで選ぶ。輪の外に道を足す構成（2 自由度制御・フィードフォワード）は、閉ループの特性方程式を変えないので、安定性を確かめ直さなくてよい。輪の形を変える構成（カスケード制御・スミス予測器）は、閉ループの極そのものを変えるので、余裕を確かめ直す。

```fig
e14_choose
```

| 困っていること | 構成 | 要るもの | この章の例 | 弱いところ |
|---|---|---|---|---|
| 外乱を抑えると、目標値への応答が行き過ぎる | 2 自由度制御（前置フィルタ・目標値の重み） | 制御器の式を変えるだけ | 温度の板: 行き過ぎ 19.3 % → 2.6 %、外乱の IAE は 160 K·s のまま | 目標値への応答しか変わらない |
| 目標値が決まった形で動き、偏差が残る | 目標値フィードフォワード | 対象のモデル、なめらかな目標値（または前置フィルタ） | モータ: 最大の偏差 1.39 rad → 0（慣性モーメントが 1.5 倍でも 0.31 rad） | モデルの誤差の分はフィードバックに任せる。操作量の上限 |
| 外乱を測れる | 外乱フィードフォワード | 外乱のセンサ、外乱の通り道のモデル | 台車: 0.932 → 0.983 m/s。温度の板: 0.74 K → 0 | 測れない外乱には効かない |
| 途中の量を測れる。速い乱れが途中に入る。途中の量に上限を置きたい | カスケード制御 | 途中の量のセンサ、内側を外側の 4 倍以上速くできること | モータ: 負荷トルクで 1.05 rad → 0.002 rad。ヒータ: 0.55 K → 0.03 K | 内側を速くできないと効かない。調整する値が増える |
| むだ時間が長い | スミス予測器 | むだ時間を含む正確なモデル | 温度の板: 目標値で 2 % 整定時間 367 s → 59 s | 遅い対象の外乱には強くならない。むだ時間のずれに弱い |

構成は組み合わせて使う。モータの位置決めの装置では、3 段のカスケードの内側のループに、目標値フィードフォワードの角速度の分と角加速度の分をそれぞれ足し込むことが多い。温度の板なら、ヒータの電力のループを内側に置き、周りの温度のフィードフォワードと、前置フィルタとフィードフォワードによる目標値への応答の整形を、PI の外側のループに足せる。

```fig
e14_whole
```

どの構成も、センサかモデルを足して、フィードバックだけでは届かない所を補う。足した分だけ、測る量と調整する値が増え、モデルがずれたときの振る舞いを確かめる手間も増える。まずフィードバックだけで余裕のある制御器を作り、足りない所があるときに、この章の表から構成を 1 つずつ足していく。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 2 自由度制御 | $`U = C_r(s)R - C_y(s)Y`$。$`G_{yr} = PC_r/(1 + PC_y)`$、$`G_{yd} = P/(1 + PC_y)`$。外乱・ノイズ・安定性は $`C_y`$ で、目標値への応答はさらに $`C_r`$ で決まる。積分は両方に同じものを入れる |
| 前置フィルタ・フィードフォワード制御 | 目標値の形を整えるためにループの前に置く伝達関数 $`G_\mathrm{f}`$（目標値の重み $`b`$ は $`(bT_\mathrm{I}s + 1)/(T_\mathrm{I}s + 1)`$）／偏差を待たず、前もって分かる信号から輪の外の道で操作量を出す制御 |
| 目標値フィードフォワード | モデルの逆 $`\tilde P^{-1}`$ を目標値に掛ける。モータは $`v_\mathrm{ff} = (T\ddot r + \dot r)/K`$。フィードバックと合わせると $`E = S(1 - P/\tilde P)R`$。段差の目標値は前置フィルタを通す（温度の板では 11 章の $`Q(s)`$） |
| 外乱フィードフォワード | 測った外乱に $`-\tilde P_d/\tilde P`$ を掛けて足す。残りは $`S(P_d - P\tilde P_d/\tilde P)D`$。台車の坂、温度の板の周りの温度、電池の電圧 |
| カスケード制御・内側のループ（マイナーループ）・外側のループ | 途中の量を制御する輪を内側に入れ、外側の制御器がその目標値を決める構成。内側に入る外乱は $`S_2`$ 倍に縮む。途中の量に上限を置ける |
| 内側と外側の速さ | 内側を一次遅れ $`1/(T_2s + 1)`$ とすると、外側の減衰比は $`\zeta = 1/(2\sqrt{K_\mathrm{P1}T_2})`$。内側を 4 倍以上速くすると振動しない（目安は 3〜10 倍） |
| スミス予測器 | 測った値に $`\tilde y_0(t) - \tilde y_0(t - \tilde L)`$ を足して、むだ時間の前の制御量を戻す。むだ時間が輪の外へ出て $`Y = e^{-Ls}P_0C/(1 + P_0C)R`$。$`Q = C/(1 + \tilde P_0C)`$ の IMC と同じ。外乱の面積は $`d/K_\mathrm{I} + KLd`$。$`|L - \tilde L| \le \lambda`$ なら安定 |
| 構成の選び方 | 輪の外に足す（2 自由度・フィードフォワード）と安定性は変わらない。輪の形を変える（カスケード・スミス予測器）と、余裕を確かめ直す |

この章までは、制御器を連続時間の伝達関数として扱ってきた。次章では、これをマイコンで一定の間隔ごとに計算する形に直し、測ってから出すまでの間隔が、ループにどんな遅れを加えるかを調べる。
