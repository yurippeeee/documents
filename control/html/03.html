Chapter 03

一次遅れの応答 — 時定数・ゲイン・むだ時間

この章で扱う問い. 2 章では、台車の速度・RC 回路・DC モータ・温度の板・水槽の式が、どれも \(T\dot y + y = Ku\) という同じ形になった（水槽は線形化した式）。2 章ではその応答を数値計算で描いたが、この章では式のまま解き、\(T\) と \(K\) が応答の何を決めるのかを調べる。そのうえで、1 章で数値計算に任せた比例制御の振る舞い（比例ゲインを上げると速くなり、偏差が減る）を、式で確かめる。

この章では次の 3 つの問いに答える。

  1. この形の対象に入力を急に加えると、出力はどう動くのか。\(T\) と \(K\) を、測った応答のどこから読めるのか。
  2. 入力が短いパルスや一定の速さで増える入力のとき、また、出力が遅れて動き始めるとき（むだ時間）、応答はどうなるのか。測った応答から、モデルの値をどう求めるのか。
  3. この形の対象を比例制御すると、なぜ応答が速くなり、偏差が減るのか。その式は、1 章の数値と一致するのか。

答えの道具は、微分方程式を直接解いて得る指数関数の式、入力をステップに分けて応答を足す重ね合わせ、そしてステップ応答の 63 % の点と接線である。

この章で学ぶこと. 節ごとに、新しく出てくる用語と、読み終えたときに説明できるようになることを並べる。全部を説明できれば、この章は理解できている（まとめは 7 節）。

1. 一次遅れの式 — 前の章のモデルに共通する形

2 章で作ったモデルのうち、ばねの無い台車の速度、RC 回路、インダクタンス \(L_\mathrm{a}\) を無視した DC モータ、温度の板、動作点のまわりで線形化した水槽の 5 つは、出力を \(y\)、入力を \(u\) と書き直すと、どれも次の形になる。

\[ T\dot y + y = Ku \]

\(T\) と \(K\) は対象ごとに決まる正の定数である。5 つの対象の値を並べる（どれも 2 章の例の値）。

\(T\) は 0.05 s から 500 s まで 1 万倍も違い、\(K\) の単位もまちまちである。各対象に入力を急に加え、その後は一定に保ったときの出力を、2 章の方法で数値で解き、対象ごとの目盛で並べる。

目盛の数字は違うが、曲線はまったく同じ形をしている。まず、この形の式が何を言っているかを読む（同じ形になる理由は、2 節で式を解くと分かる）。

時定数と定常ゲイン

式を、出力の変わる速さについて解く。

\[ \dot y = \frac{Ku - y}{T} \]

入力 \(u\) を一定に保ったときに、この式が言っていることを 2 つに分ける。

  • 出力が変わらなくなる（\(\dot y\) = 0 になる）のは、\(y = Ku\) のときだけである（2 章 5 節の平衡点）。\(y\) が \(Ku\) より小さければ \(\dot y\) > 0 で増え、大きければ減るので、出力はいつも \(Ku\) へ向かって動く。入力を一定に保って出力が落ち着いたときの、出力の変化と入力の変化の比 \(K\) を定常ゲインという。単位は（出力の単位）÷（入力の単位）で、モータの 50 (rad/s)/V は、1 V あたり 50 rad/s で回り続けることを表す。
  • 変わる速さは、落ち着く値までの残り \(Ku - y\) を \(T\) で割った値である。今の速さのまま変わり続けたとすると、残りをちょうど時間 \(T\) で埋める。この \(T\) を時定数という。単位は秒である（左辺の \(T\dot y\) と \(y\) の単位がそろうため）。残りが減ると、速さも同じ割合で減るので、出力は落ち着く値に近づくほどゆっくりになる。

階数が 1 の微分方程式 \(T\dot y + y = Ku\) で表される対象を一次遅れという。出力が入力の変化に遅れてついていき、その遅れ方が 1 階（一次）の式で決まることからの名前である。

次の図の (a) は、止まっているモータに 12 V を加えたときの角速度（2 章の方法で数値で解いた曲線）の上の 4 つの時刻で、その時刻の変わる速さを傾きとする直線（接線）を引いたものである。

  • どの時刻の接線も、ちょうど \(T\) = 0.05 s 後に、落ち着く値 600 rad/s に届く。始めは残りが 600 rad/s で、変わる速さ（角加速度）は 600 ÷ 0.05 = 12000 rad/s² である。0.05 s では残りが 221 rad/s に減り、変わる速さも 4415 rad/s² に減る。
  • (b) のブロック線図のとおり、一次遅れは、加え合わせ点で落ち着く値 \(Ku\) から今の出力 \(y\) を引き、その差の \(1/T\) 倍の速さで出力を直す仕組みと同じ形をしている。出力が引き出し点から戻って自分を直すので、1 章 4 節のフィードバック制御と同じく、信号の流れが輪になっている。2 章 3 節で見た、モータの中の逆起電力を通した流れもその一例である（角速度が上がると逆起電力が増えて電流が減り、角速度の増える速さが落ちる）。

2. ステップ応答 — 時定数の読み方

1 節では、式の形から、出力が落ち着く値へ、残りに比例した速さで近づくことを読んだ。この節では式を解き、近づき方を時刻の関数として求める。入力には、最も基本の、急に変えてその後は一定に保つ入力を使う。

時刻 0 まで 0 で、時刻 0 に \(\Delta u\) に変わり、その後は \(\Delta u\) のまま保つ入力を、高さ \(\Delta u\) のステップ入力という（階段の 1 段の形から）。高さが入力の単位で 1 のものを単位ステップという。出力が落ち着いている状態からステップ入力を加えたときの、出力の動きをステップ応答という。ここでは、時刻 0 に \(y\) = 0 で落ち着いているとする（温度の板なら周りと同じ温度、水槽なら動作点の水位）。

方針: 落ち着く値 \(K\Delta u\) からのずれに注目する。ずれの式は入力を含まない簡単な形になるので、それを解いてから \(y\) に戻す。

導出: \(t \ge 0\) では \(u = \Delta u\) なので、式は \(T\dot y + y = K\Delta u\) である。ずれを \(\delta y = y - K\Delta u\) とおく（2 章 6 節と同じ書き方）。\(K\Delta u\) は一定なので \(\delta\dot y = \dot y\) で、式に \(y = \delta y + K\Delta u\) を入れると \(T\,\delta\dot y + \delta y + K\Delta u = K\Delta u\)、つまり

\[ T\,\delta\dot y + \delta y = 0 \]

となる。両辺に \(e^{t/T}/T\) を掛けると、左辺は \((\delta\dot y + \delta y/T)\,e^{t/T}\) で、これは積の微分の公式から \(\delta y\,e^{t/T}\) を微分したものに等しい。したがって

\[ \frac{d}{dt}\left(\delta y\,e^{t/T}\right) = 0 \]

で、\(\delta y\,e^{t/T}\) は時間によらず一定であり、\(t\) = 0 での値 \(\delta y(0)\) に等しい。よって \(\delta y(t) = \delta y(0)\,e^{-t/T}\) である。初期値は \(y(0)\) = 0 なので \(\delta y(0) = -K\Delta u\) で、\(y = \delta y + K\Delta u\) に戻すと

\[ y(t) = K\Delta u\left(1 - e^{-t/T}\right) \qquad (t \ge 0) \]

となる ∎

途中の \(\delta y(t) = \delta y(0)\,e^{-t/T}\) は、初期値が 0 でなくても成り立つ。始めの値が \(y(0)\) なら

\[ y(t) = K\Delta u + \{y(0) - K\Delta u\}\,e^{-t/T} \]

で、落ち着く値との差が \(e^{-t/T}\) 倍に縮んでいく（3 節の方形波で使う）。どんな解も「\(\delta y\,e^{t/T}\) が一定」を満たすので、解はこの 1 つに限られる。2 章 6 節でオイラー法の刻み幅を 0 に近づけた極限 \(\delta y(0)\,e^{-t/T}\) は、ここで求めた式そのものである。モータの例（\(T\) = 0.05 s、\(K\Delta u\) = 600 rad/s）では、刻み幅 \(T\)/1000 の 4 次のルンゲ・クッタ法で解いた値と、この式の差は 10⁻¹¹ rad/s 以下だった。

63 % の点と接線

\(e^{-1}\) = 0.368 なので、\(t = T\) で出力は落ち着く値の 1 − 0.368 = 63.2 % に届く。その後も、\(T\) が経つごとに、残りが 0.368 倍に減る。モータに 12 V を加えたときの値を並べる。

届いた割合 \(1 - e^{-t/T}\)63.2 %86.5 %95.0 %98.2 %99.3 %

逆に、落ち着く値の割合 \(p\) に届く時刻は、\(1 - e^{-t/T} = p\) を \(t\) について解いて \(t = T\ln\{1/(1 - p)\}\) である。50 % には 0.693\(T\)、90 % には 2.30\(T\)、95 % には 3.00\(T\)、99 % には 4.61\(T\) で届く。

図から、ステップ応答の曲線から時定数を読む方法が 2 つ得られる。

  1. 落ち着く値の 63.2 % に届く時刻を読む。それが \(T\) である。
  2. \(t\) = 0 での接線を引き、落ち着く値の高さに届く時刻を読む。\(t\) = 0 の傾きは、式から \(\dot y(0) = (K\Delta u - 0)/T\) なので、接線はちょうど \(t = T\) で \(K\Delta u\) に届く（1 節の接線の性質の、\(t\) = 0 の場合）。

95 % に届くまでの \(3T\) は、ほぼ落ち着いたとみなす目安にされることが多い。例の対象では、モータ 0.15 s、RC 回路 0.3 s、台車の速度 1.5 s、水槽 150 s、温度の板 1500 s（25 分）である。

時定数と定常ゲインの役割

  • (a) 回す物の慣性モーメント \(J\) を変えると、\(T = JR_\mathrm{a}/K_\mathrm{t}^2\) だけが変わる。落ち着く値は同じで、近づく速さだけが変わる。時刻は式に \(t/T\) の形でしか現れないので、\(T\) を 2 倍にすると、同じ形の曲線が時間の向きに 2 倍に引き伸ばされる。
  • (b) 電圧 \(\Delta u\) を変えると、落ち着く値だけが変わる。どの曲線も同じ 0.05 s に、それぞれの落ち着く値の 63.2 % に届く。式には \(K\) と \(\Delta u\) が積 \(K\Delta u\) でしか現れないので、\(K\) を変えたときも同じである。

つまり、時定数は時間の目盛を、定常ゲインと入力の高さは出力の目盛を決める。横軸を \(t/T\)、縦軸を \(y/(K\Delta u)\) にすると、どの一次遅れのステップ応答も \(1 - e^{-t/T}\) の 1 本の曲線になる。1 節の図で 5 つの対象の曲線が同じ形だったのは、このためである。

下の図で、対象を選び、時定数と定常ゲインを変えると、ステップ応答と、接線・63.2 % の点・95 % の点が表示される。時刻を動かすか「再生」を押すと、その時刻の対象の様子（台車の走り方、モータの回り方、板の温まり方など）と、その時刻の接線が表示される。曲線を残して比べることや、横軸を \(t/T\)、縦軸を \(y/(K\Delta u)\) にして重ねることもできる。

3. いろいろな入力への応答 — インパルス・ランプ・重ね合わせ

実際の入力は、ステップとは限らない。一次遅れの式は線形で時不変なので、2 章 1 節の重ね合わせの原理が使える。入力をいくつかのステップの和に分ければ、応答もそれぞれのステップ応答の和になる。時刻 \(t_0\) に加えるステップの応答は、時不変なので、時刻 0 のステップの応答を \(t_0\) だけ遅らせたものである。

パルス — 2 つのステップの差

一定の値 \(\Delta u\) を時間 \(t_\mathrm{w}\) の間だけ加え、その後 0 に戻す入力（パルス）は、時刻 0 の高さ \(\Delta u\) のステップと、時刻 \(t_\mathrm{w}\) の高さ \(-\Delta u\) のステップの和である。応答も 2 つのステップ応答の和で、\(0 \le t < t_\mathrm{w}\) では 1 つ目だけ、\(t \ge t_\mathrm{w}\) では

\[ y(t) = K\Delta u\left(1 - e^{-t/T}\right) - K\Delta u\left(1 - e^{-(t - t_\mathrm{w})/T}\right) = K\Delta u\left(e^{t_\mathrm{w}/T} - 1\right)e^{-t/T} \]

である。台車を 2 N で 1 s だけ押すと、速度は 1 s で 0.865 m/s まで上がり、その後は時定数 0.5 s で減る（2 s で 0.117 m/s）。

インパルス応答 — 短く強いパルスの極限

台車をハンマーで叩くように、ごく短い時間に強い力を加える場合を考える。力と時間の積（パルスの面積）を 0.2 N·s に保ったまま、幅を 0.4 s・0.2 s・0.1 s・0.05 s と狭め、高さを 0.5 N・1 N・2 N・4 N と高くする。次の図の (a) のとおり、速度の最大値は 0.138・0.165・0.181・0.190 m/s と増え、幅が狭いほど 1 本の曲線に近づく。その極限を求める。

方針: パルスの応答の式で、面積 \(\Delta u\,t_\mathrm{w}\) を一定に保ったまま \(t_\mathrm{w}\) を 0 に近づける。

導出: \(e^{t_\mathrm{w}/T}\) をテイラー展開すると \(e^{t_\mathrm{w}/T} - 1 = (t_\mathrm{w}/T)\{1 + t_\mathrm{w}/(2T) + \cdots\}\) なので、\(t \ge t_\mathrm{w}\) での応答は

\[ y(t) = \frac{K}{T}\,(\Delta u\,t_\mathrm{w})\left\{1 + \frac{t_\mathrm{w}}{2T} + \cdots\right\}e^{-t/T} \]

である。\(\Delta u\,t_\mathrm{w}\) を一定に保って \(t_\mathrm{w}\) を 0 に近づけると、波かっこの中は 1 に近づき、この式が使えない \(0 \le t < t_\mathrm{w}\) の区間も 0 に縮む。したがって、応答は \((K/T)(\Delta u\,t_\mathrm{w})\,e^{-t/T}\) に近づく ∎

面積が 1 のパルスの幅を 0 に近づけた極限の入力に対する応答をインパルス応答といい、この章では \(g(t)\) と書く（極限の入力そのものは、5 章で単位インパルスとして厳密に扱う）。一次遅れのインパルス応答は

\[ g(t) = \frac{K}{T}\,e^{-t/T} \]

である。台車では \(K/T = (1/c)/(m/c) = 1/m\) なので、0.2 N·s で叩くと、速度は 0.2 ÷ 1 = 0.2 m/s に跳び、時定数 0.5 s で減っていく。力 × 時間（力積）が運動量（質量 × 速度）を変える、という力学の関係と一致する。

図の (b) のとおり、\(g(t)\) は単位ステップ応答 \(K(1 - e^{-t/T})\) を微分したもの（各時刻の傾き）に等しい。面積 1 のパルス（高さ \(1/t_\mathrm{w}\)）の応答は、単位ステップ応答から、それを \(t_\mathrm{w}\) だけ遅らせたものを引き、\(t_\mathrm{w}\) で割ったものである。\(t_\mathrm{w}\) を 0 に近づけると、これはその時刻の傾きになるからである。インパルス応答は、ある瞬間に加えた入力の影響が、その後どう消えていくかを表す。一次遅れでは、影響が \(T\) ごとに 0.368 倍に減る。どんな入力も細いパルスの並びとみなせるので、その応答はインパルス応答を重ね合わせて求められる（畳み込み。5 章 6 節）。

ランプ応答 — 時定数だけ遅れてついていく

モータに 12 V を急に加えると、始めは逆起電力が 0 なので、巻線に約 12 V ÷ 2 Ω = 6 A の電流が流れる（2 章 3 節）。電源と巻線を守るため、電圧を 0 V から一定の速さで上げて回し始めることが多い（電源と周辺の制御シリーズ 13 章 3 節）。時刻 0 から一定の速さ \(\alpha\) で増える入力 \(u = \alpha t\) をランプ入力（ランプは傾斜の意味）、その応答をランプ応答という。電圧を 0.5 s かけて 12 V にするなら、\(\alpha\) = 24 V/s である。

方針: 入力と同じく時間に比例して増える解（直線）を 1 つ探し、初期値に合わせるために、2 節と同じ \(e^{-t/T}\) に比例する項を足す。

導出: 直線 \(y_\mathrm{p} = K\alpha(t - T)\) を式の左辺に入れると、\(T\dot y_\mathrm{p} + y_\mathrm{p} = TK\alpha + K\alpha(t - T) = K\alpha t\) で、右辺の \(Ku = K\alpha t\) に等しい。ずれ \(\delta y = y - y_\mathrm{p}\) は、\(y\) の式と \(y_\mathrm{p}\) の式の差から \(T\,\delta\dot y + \delta y = 0\) を満たすので、2 節の導出と同じく \(\delta y(t) = \delta y(0)\,e^{-t/T}\) である。初期値 \(y(0)\) = 0 から \(\delta y(0) = 0 - y_\mathrm{p}(0) = K\alpha T\) で、

\[ y(t) = K\alpha\left(t - T + Te^{-t/T}\right) \]

となる ∎

\(t\) が \(T\) の数倍を超えると \(e^{-t/T}\) の項は消え、\(y \approx K\alpha(t - T)\) になる。これは、入力に \(K\) を掛けた直線 \(K\alpha t\) を、時間の向きにちょうど \(T\) だけ遅らせたもので、値で見ると \(K\alpha T\) だけ下にある。モータでは \(K\alpha T\) = 50 × 24 × 0.05 = 60 rad/s で、0.5 s の角速度は 600 rad/s ではなく 540 rad/s である。0.5 s で電圧を上げるのを止めると、入力は「ランプ」から「0.5 s 遅れたランプ」を引いたものになり、角速度はそこから時定数 0.05 s で 600 rad/s に近づく（0.535 s で 570 rad/s）。

電流は、2 章 3 節の一次の式の導出で使った \(i = (v - K_\mathrm{t}\omega_\mathrm{m})/R_\mathrm{a}\) で求まる。\(v = \alpha t\) と、ランプ応答の式に \(K = 1/K_\mathrm{t}\) を入れた \(K_\mathrm{t}\omega_\mathrm{m} = \alpha(t - T + Te^{-t/T})\) を入れると、\(i = \alpha T(1 - e^{-t/T})/R_\mathrm{a} = 0.6\,(1 - e^{-t/T})\) A で、0.6 A を超えない。12 V を急に加えたときの 1/10 である。0.6 A は、角速度を 1 秒に 1200 rad/s ずつ上げるのに要るトルク \(J\) × 1200 rad/s² = 0.012 N·m を、トルク定数 0.02 N·m/A で割った値に等しい。

方形波 — ステップの並び

一定の周期で入れ切りを繰り返す入力（方形波）は、高さ \(+\Delta u\) と \(-\Delta u\) のステップが交互に並んだものである。幅 \(t_\mathrm{w}\) のパルスを、周期 \(2t_\mathrm{w}\) で繰り返すと考えてもよい。入れ切りを続けて往復が一定になったとき、出力がどの範囲を往復するかを求める。

方針: 往復が一定になった後は、下端 \(y_\mathrm{min}\) から上端 \(y_\mathrm{max}\) へ、上端から下端へと、同じ動きを繰り返す。入れている間と切っている間のそれぞれで、2 節の式（始めの値が 0 でない場合）を使い、2 つの式を連立させる。

導出: 入れている \(t_\mathrm{w}\) の間、出力は \(y_\mathrm{min}\) から \(K\Delta u\) へ向かうので、\(y_\mathrm{max} = K\Delta u + (y_\mathrm{min} - K\Delta u)\,e^{-t_\mathrm{w}/T}\) である。切っている \(t_\mathrm{w}\) の間は 0 へ向かうので、\(y_\mathrm{min} = y_\mathrm{max}\,e^{-t_\mathrm{w}/T}\) である。2 つ目を 1 つ目に入れると \(y_\mathrm{max}(1 - e^{-2t_\mathrm{w}/T}) = K\Delta u\,(1 - e^{-t_\mathrm{w}/T})\) で、左辺の \(1 - e^{-2t_\mathrm{w}/T} = (1 - e^{-t_\mathrm{w}/T})(1 + e^{-t_\mathrm{w}/T})\) を使って両辺を \(1 - e^{-t_\mathrm{w}/T}\) で割ると

\[ y_\mathrm{max} = \frac{K\Delta u}{1 + e^{-t_\mathrm{w}/T}}, \qquad y_\mathrm{min} = \frac{K\Delta u\,e^{-t_\mathrm{w}/T}}{1 + e^{-t_\mathrm{w}/T}} \]

となる ∎

RC 回路（\(T\) = 0.1 s）に、0 V と 1 V を繰り返す電圧を加えた場合を図に示す。

周期が時定数より十分に長い（周期 2 s、\(t_\mathrm{w}\) = 10\(T\)）と、出力は半周期ごとにほぼ落ち着き、ステップ応答が交互に並ぶ。周期が時定数と同じ程度（周期 0.2 s、\(t_\mathrm{w}\) = \(T\)）だと、落ち着く前に入力が変わり、出力は 0.269〜0.731 V の間を往復する。周期が短い（周期 0.02 s、\(t_\mathrm{w}\) = 0.1\(T\)）と、出力は入力の平均 0.5 V のまわりで 0.475〜0.525 V しか動かない。一次遅れは、時定数より速い変化をならす。RC 回路を、速い揺れを除くフィルタに使うのはこのためである（組み込み回路シリーズ 3 章 2 節）。温度の板（時定数 500 s）が、80 W のヒータを 1 s 入れて 1 s 切ることを繰り返しても、上の式で 0.1 K しか揺れないのも同じ理由である（電源と周辺の制御シリーズ 14 章 4 節）。

下の図で、対象と入力の種類を選ぶと、入力をステップに分けたもの（上の段。増えるステップは緑、減るステップは赤）、それぞれのステップの応答（中の段）、その和（下の段）が表示される。下の段の破線は、微分方程式を細かい刻み幅で解いた応答で、和と重なる。

4. むだ時間 — 遅れて動き始める

1 章 5 節では、測った速度が 0.1 s 遅れて制御器に届くと、比例制御の台車が振動した。シャワーでは、つまみで混ぜたお湯がシャワーの口に届くまで 2 s かかった。これらの遅れは、一次遅れとは性質が違う。入力の変化が、形を変えずに、一定の時間だけ遅れて出力に現れる。このような遅れをむだ時間といい、その長さを \(L\) [s] と書く。むだ時間だけの対象の式は

\[ y(t) = u(t - L) \]

である。むだ時間は、次のような所で生まれる。

  • 物が運ばれる時間: ホースや配管を流れる液体の温度や濃度、ベルトコンベアで運ばれる材料。長さ ÷ 速さが \(L\) になる。
  • 測る・伝える・計算する時間: 一定の時間だけ回転を数えて速度を求めるセンサ（数える時間の半分ほど古い値になる。1 章 5 節）、値をならす計算、無線で送る時間、マイコンが計算する時間。
  • 熱が伝わる時間: 温度の板では、ヒータの熱が板の中を伝わってセンサに届き、センサ自身が温まるまでに時間がかかる。この遅れを、ここでは \(L\) = 20 s のむだ時間として扱う（例の値。センサの置き場所と貼り方で変わる。電源と周辺の制御シリーズ 14 章 2 節）。

図の (b) のとおり、数値積分でむだ時間を扱うには、刻みごとの値を配列に貯めておき、\(L\) を刻み幅で割った個数だけ前の値を取り出す。このシリーズのデモも、この方法でむだ時間を計算している。

一次遅れとの違い

台車への力の指令が、無線で 0.5 s 遅れて届く場合（例の値）で、むだ時間と一次遅れの違いを比べる。

  • (a) むだ時間は、入力の形を変えずに、そのまま \(L\) だけずらす。ずれている間、出力には入力の変化がまったく現れない。
  • (b) 一次遅れは、入力が変わった瞬間から出力が動き始めるが、角が丸まって形が変わる。
  • (c) 両方が重なると、\(L\) の間は何も起きず、その後は一次遅れの形で動く。

一次遅れの出力が、さらにむだ時間 \(L\) だけ遅れて現れる対象を一次遅れ＋むだ時間という。式は

\[ T\dot y(t) + y(t) = Ku(t - L) \]

である。時不変なので、ステップ応答は 2 節のステップ応答を \(L\) だけ遅らせたもので、\(t < L\) では 0、\(t \ge L\) では \(y(t) = K\Delta u\,(1 - e^{-(t - L)/T})\) である。むだ時間を一次遅れの前に置いても（入力が遅れて届く）、後に置いても（出力が遅れて測られる）、入力から出力までの関係は同じである。後に置くと、測られる値 \(z(t) = y(t - L)\) は、一次遅れの式を \(L\) 前の時刻で書いた \(T\dot z(t) + z(t) = Ku(t - L)\) を満たし、前に置いたときと同じ式になるからである（初期値が 0 のとき）。

温度の板で、ヒータの電力を 0 W から 40 W に変えると、センサの読みは 20 s の間 25 °C のまま動かず、その後 0.1 K/s の傾きで上がり始め、520 s（\(L + T\)）で上がり幅 50 K の 63.2 % の 56.6 °C に届く（図の (d)）。むだ時間の間、制御器は、入力を変えた結果を何も見ることができない。1 章 5 節の台車が行き過ぎたのは、このためだった。6 節で、むだ時間があると比例制御の応答がどう変わるかを見る。

5. ステップ応答からモデルを求める

1〜4 節では、\(K\)・\(T\)・\(L\) の値が分かっているとして応答を求めた。実際の機器では、熱容量・熱抵抗・センサの遅れなどを、図面から正確に求めることは難しい。そこで逆に、測った応答から値を求める。測った入力と出力から、モデルの値を求めることを同定という。ステップ応答を使う方法は、入力を 1 回変えて待つだけなので、最も手軽である（正弦波を使う方法は 8 章 6 節）。

読み取りの手順

温度の板で、一次遅れ＋むだ時間のモデルを求める手順を示す（図の番号は手順の番号）。

  1. 入力を一定に保ち、出力が落ち着くのを待って、始めの値を記録する（ヒータ 0 W で 25.0 °C）。
  2. 入力を \(\Delta u\) だけ変え（40 W）、出力が落ち着くまで記録を続ける。記録の長さは、時定数の 5 倍以上にする（5 倍で止めると、2 節の表のとおり、まだ上がり幅の 0.7 % が残っている）。例では 4000 s（8 倍）記録した。
  3. 定常ゲイン: 落ち着いた値から始めの値を引き、\(\Delta u\) で割る。(75.0 − 25.0) K ÷ 40 W = 1.25 K/W。
  4. むだ時間: 曲線が最も急な所で接線を引き、接線が始めの値の高さを横切る時刻を読む（20 s）。一次遅れ＋むだ時間では、最も急なのは動き始めの \(t = L\) なので、この接線は時刻 \(L\) に始めの値を通る。
  5. 時定数: 上がり幅の 63.2 % に届く時刻から \(L\) を引く（56.6 °C に 520 s → 500 s）。接線が落ち着いた値の高さに届く時刻から \(L\) を引いても、時定数が得られる（1 節の接線の性質）。

ノイズ・記録の長さ・遅れの重なり

  • (a) 測った値には観測ノイズが混じる（例: 標準偏差 0.3 K）。落ち着いた値は最後の 500 s の平均で読み、63.2 % に届く時刻は、前後の点を平均してならした曲線で読む。接線は、ノイズで点ごとの傾きが大きく揺れるので、最も急な 100 s の点に直線を当てはめて引く。図の記録からは、\(K\) = 1.249 K/W、\(L\) = 18 s、\(T\) = 502 s と読めた（本当の値は 1.25 K/W・20 s・500 s）。3 つの値のうち、むだ時間が最も読み誤りやすい。当てはめた直線は、曲がり始めた部分の点も含むので、本当の接線より傾きが小さく、少し上を通る。そのため、始めの値の高さを横切る時刻が早めに出る。
  • (b) 記録を 1000 s（時定数の 2 倍）で止め、その時の 68.0 °C を落ち着いた値とみなすと、定常ゲインを 1.07 K/W（14 % 小さい）、時定数を 392 s（22 % 短い）と読み誤る。まだ上がっている途中の値を、落ち着いた値と見誤ったからである。
  • (c) 一次遅れの出力が次の一次遅れの入力になる対象（時定数 400 s の板に、時定数 100 s の遅れでしか温まらないセンサを付けた場合。例の値）は、ステップ応答が S 字形になる。むだ時間が無いのに、接線で読むと 50 s の見かけのむだ時間が現れる。接線から読んだ時定数（635 s）と 63.2 % から読んだ時定数（463 s）が食い違うのは、対象が一次遅れ＋むだ時間の形でないしるしである。実際の対象の多くは、このように遅れが重なっている。一次遅れ＋むだ時間は、それらをまとめて近似するモデルとして使われ、11 章のステップ応答法の出発点になる（11 章 2 節）。

図で読むほかに、測った点とモデルの曲線の差の 2 乗の和が最も小さくなるように、\(K\)・\(T\)・\(L\) を計算機で探す方法がある（最小二乗法。統計学シリーズ 18 章 2 節）。すべての点を使うので、何点かを選んで読むより、ノイズの影響を受けにくい。

下の図で、\(K\)・\(T\)・\(L\) のつまみを動かして、モデルの曲線をノイズのある記録に合わせる（始めは、わざとずらした値にしてある）。差の 2 乗の平均の平方根（曲線から点までの、ならした距離）が表示される。「図で読む」は手順 3〜5 で値を読み、「自動で合わせる」は最小二乗法で値を探す。本当の対象・ノイズの大きさ・記録の長さも変えられる。

6. 一次遅れを P 制御する — 1 章の振る舞いを式で確かめる

1 章 4・5 節では、台車の速度を比例制御すると、応答が速くなり、定常偏差が小さくなることを、数値計算で見た。台車の速度は一次遅れなので、この章の式で、その理由と数値を確かめる。まず一般の一次遅れで式を導き、次に 1 章の台車にあてはめる。

比例制御した一次遅れの式

一次遅れの制御対象 \(T\dot y + y = Ku\) の操作量 \(u\) を、比例制御 \(u = K_\mathrm{P}(r - y)\) で決める（1 章の決めた操作量 \(u_0\) は、後で足す）。目標値 \(r\) は、時刻 0 に 0 から \(r\) に変わり、その後は一定とする。

方針: 比例制御の式を一次遅れの式の \(u\) に代入し、\(y\) について整理すると、また一次遅れの形になることを示す。そのうえで 2 節の結果を使う。

導出: 代入すると \(T\dot y + y = KK_\mathrm{P}(r - y)\) である。\(y\) の項を左辺に集めると \(T\dot y + (1 + KK_\mathrm{P})\,y = KK_\mathrm{P}\,r\) で、両辺を \(1 + KK_\mathrm{P}\) で割ると

\[ \frac{T}{1 + KK_\mathrm{P}}\,\dot y + y = \frac{KK_\mathrm{P}}{1 + KK_\mathrm{P}}\,r \]

となる。これは、目標値 \(r\) を入力、制御量 \(y\) を出力とする一次遅れの式で、その時定数と定常ゲインは

\[ T_\mathrm{cl} = \frac{T}{1 + KK_\mathrm{P}}, \qquad K_\mathrm{cl} = \frac{KK_\mathrm{P}}{1 + KK_\mathrm{P}} \]

である（添字の cl は閉ループを表す）。2 節の結果から \(y(t) = K_\mathrm{cl}\,r\,(1 - e^{-t/T_\mathrm{cl}})\) で、落ち着いた後に残る偏差は \(e_\infty = r - K_\mathrm{cl}\,r = r/(1 + KK_\mathrm{P})\) である。単位ステップの目標値（\(r\) = 1）なら \(1/(1 + KK_\mathrm{P})\) になる ∎

\(K\) と \(K_\mathrm{P}\) の積 \(KK_\mathrm{P}\) は単位を持たない数（台車では (m/s)/N × N/(m/s)）で、比例制御の強さを表す。比例制御は、時定数を開ループ（\(K_\mathrm{P}\) = 0）の \(1/(1 + KK_\mathrm{P})\) 倍にし、落ち着いた後に残る偏差も、目標値の \(1/(1 + KK_\mathrm{P})\) にする。閉ループも一次遅れなので、応答は \(1 - e^{-t/T_\mathrm{cl}}\) の形で単調に近づき、目標値を越えることはない。1 章 5 節の (a) で、遅れが無ければどの比例ゲインでも目標値を越えなかったのは、このためである。

台車では \(K = 1/c\)、\(T = m/c\) なので、\(T_\mathrm{cl} = m/(c + K_\mathrm{P})\) となる。力の式で見ると、比例制御の力 \(K_\mathrm{P}(r - y) = K_\mathrm{P}r - K_\mathrm{P}y\) の後ろの項は、減衰の力 \(cy\) と同じく速度に比例して後ろへ引くので、台車の式は \(m\dot y + (c + K_\mathrm{P})\,y = K_\mathrm{P}r\) になる。台車は、減衰係数が \(c + K_\mathrm{P}\) に増えたのと同じ速さで落ち着く（前の項 \(K_\mathrm{P}r\) があるので、落ち着く先は速度 0 ではない）。

1 章の台車にあてはめる

1 章では、決めた力 \(u_0 = cr\) を足した比例制御 \(u = u_0 + K_\mathrm{P}(r - y)\) を使い、外乱である上り坂の力 \(d\) を、台車を後ろへ引く向きに測った（1 章 3 節。前向きを正にとる場合は符号が逆になる）。台車の式は \(T\dot y + y = K(u - d)\) である。

方針: 上と同じく代入して整理する。\(u_0 = cr = r/K\) を使う。

導出: 代入すると \(T\dot y + y = Ku_0 + KK_\mathrm{P}(r - y) - Kd = r + KK_\mathrm{P}(r - y) - Kd\) である。\(y\) の項を左辺に集めて \(1 + KK_\mathrm{P}\) で割ると

\[ \frac{T}{1 + KK_\mathrm{P}}\,\dot y + y = r - \frac{Kd}{1 + KK_\mathrm{P}} \]

となる。時定数は上と同じ \(T_\mathrm{cl}\) で、落ち着く速度は右辺の値である。定常偏差は \(e_\infty = Kd/(1 + KK_\mathrm{P})\) で、\(K = 1/c\) を入れて分母と分子に \(c\) を掛けると \(e_\infty = d/(c + K_\mathrm{P})\) になる ∎

この \(e_\infty\) は、1 章 4 節で力の釣り合いから求めた式と同じである。95 % に届く時間は \(3T_\mathrm{cl} = 3m/(c + K_\mathrm{P})\)、\(u_0\) を足さないときの定常偏差は上の結果から \(r/(1 + KK_\mathrm{P}) = cr/(c + K_\mathrm{P})\) で、これも 1 章 4 節の式と一致する。1 章の例の値（\(m\) = 1 kg、\(c\) = 2 N·s/m、\(r\) = 1 m/s、3° の坂で \(d\) = 0.513 N）を入れる。

むだ時間がある場合

1 章 5 節の (b) では、測った速度が 0.1 s 遅れて届くと、\(K_\mathrm{P}\) = 8 N/(m/s) で速度が 1.30 m/s まで行き過ぎ、20 N/(m/s) では振れが大きくなり続けた。このとき制御器が使うのは \(L\) 前の速度なので、式は

\[ T\dot y(t) + y(t) = r + KK_\mathrm{P}\{r - y(t - L)\} - Kd \]

となる。左辺の \(y(t)\) と右辺の \(y(t - L)\) は別の時刻の値なので、2 つをまとめて 1 つの一次遅れの式にすることはできない。この式の解は \(e^{-t/T_\mathrm{cl}}\) の形にはならず、振動することがある。

一方、落ち着いた後は \(y(t - L) = y(t)\) なので、落ち着く値と定常偏差の式は、むだ時間があってもそのまま成り立つ（落ち着く場合に限る）。どの比例ゲインで振動し始め、どこから振れが大きくなり続けるかは、この章の式からは分からない。正弦波がループを回るときの遅れとして考える必要があり、9 章 6 節で求める。

7. まとめ

項目内容
一次遅れ・時定数・定常ゲイン\(T\dot y + y = Ku\) で表される対象（台車の速度・RC 回路・モータ・温度の板・線形化した水槽）／変わる速さ ＝ 残り ÷ \(T\)。どの時刻の接線も \(T\) 後に落ち着く値に届く／落ち着いたときの出力の変化 ÷ 入力の変化
ステップ入力・単位ステップ・ステップ応答時刻 0 に \(\Delta u\) に変えて保つ入力／高さ 1 のもの／その応答 \(y = K\Delta u(1 - e^{-t/T})\)。\(T\) で 63.2 %、\(3T\) で 95.0 %
重ね合わせで求める応答パルスはステップ 2 つの差。方形波は交互のステップで、往復は \(K\Delta u/(1 + e^{-t_\mathrm{w}/T})\) まで。時定数より速い変化はならされる
インパルス応答面積 1 のパルスの幅を 0 に近づけた入力の応答。\(g(t) = (K/T)e^{-t/T}\) で、単位ステップ応答の傾きに等しい
ランプ入力・ランプ応答一定の速さ \(\alpha\) で増える入力／\(K\alpha(t - T + Te^{-t/T})\)。\(T\) だけ遅れ、\(K\alpha T\) だけ下をついていく
むだ時間・一次遅れ＋むだ時間形を変えずに \(L\) だけ遅らせる \(y(t) = u(t - L)\)／\(T\dot y(t) + y(t) = Ku(t - L)\)。計算は過去の値を配列に貯めて取り出す
同定測った入力と出力からモデルの値を求めること。ステップ応答の落ち着いた値から \(K\)、接線から \(L\)、63.2 % の時刻から \(T\)。記録は時定数の 5 倍以上。重なった遅れは見かけのむだ時間になる
一次遅れの比例制御閉ループも一次遅れで \(T_\mathrm{cl} = T/(1 + KK_\mathrm{P})\)、単位ステップへの定常偏差 \(1/(1 + KK_\mathrm{P})\)。目標値を越えない。1 章の値と一致。むだ時間があると振動しうるが、この式では表せない（9 章）

一次遅れの比例制御は、むだ時間が無ければ振動しなかった。次章では、2 階の微分方程式で表される対象（ばね・ダンパ付きの台車と、モータの角度）を扱う。2 階の式では、むだ時間が無くても応答が振動しうる。その振動の速さと減り方を、2 つの値（固有角周波数と減衰比。4 章で定義する）で読む。
