Chapter 05

ラプラス変換 — 微分方程式を代数に変える

この章で扱う問い. 3・4 章では、一次遅れと二次遅れの微分方程式を、ステップ・ランプ・パルスといった入力の形ごとに工夫して解いた。6 章からは、制御器と制御対象をつないだ、階数の高い式を扱う。入力や式が変わるたびに解き方を考え直していては、先へ進めない。

この章では次の 3 つの問いに答える。

  1. 微分を含む式を、掛け算と足し算だけの式（代数の式）に変えるには、時間の関数を何に変えればよいのか。
  2. 代数の式で求めた答えを、どうやって時間の関数に戻すのか。その答えは 3・4 章の答えと一致するのか。
  3. 時間の関数に戻さずに、応答の最終値や初期値、入力と応答の関係を読むことはできるのか。

答えの道具は、時間の関数を複素数 \(s\) の関数に変えるラプラス変換、分数を簡単な分数の和に分ける部分分数分解、最終値の定理と初期値の定理、そして入力と応答を結ぶ畳み込みである。

この章で使う既出の用語（定義は各リンク先）. 制御対象・制御器・目標値（01 章 1 節）、ブロック線図・加え合わせ点・引き出し点（01 章 2 節）、フィードバック制御（閉ループ制御）・比例制御・比例ゲイン・定常偏差（01 章 4 節）、不安定（01 章 5 節）、微分方程式・階数・初期値・線形・重ね合わせの原理・時不変・減衰係数（02 章 1 節）、ばね定数（02 章 2 節）、トルク定数（02 章 3 節）、刻み幅・ルンゲ・クッタ法（02 章 6 節）、一次遅れ・時定数・定常ゲイン（03 章 1 節）、ステップ入力・単位ステップ・ステップ応答（03 章 2 節）、インパルス応答・ランプ入力・ランプ応答（03 章 3 節）、むだ時間・一次遅れ＋むだ時間（03 章 4 節）、二次遅れ・固有角周波数・減衰比（04 章 1 節）、特性方程式・特性根・過減衰・臨界減衰・不足減衰・減衰固有角周波数（04 章 2 節）

1. なぜ変換するのか — 微分を掛け算に

3 章と 4 章では、入力の形と式の階数ごとに、違う工夫で微分方程式を解いた。

ステップ入力には落ち着く値からのずれに注目し、ランプ入力には直線の解を探し、パルスはステップ 2 つに分け、二次遅れでは指数関数を仮定して初期値に合わせた。どれも、答えの形に見当をつけてから確かめる方法である。式の階数が上がったり、入力の形が複雑になったりすると、見当がつけにくくなる。この章では、どの入力にも同じ手順で使える方法を作る。手がかりは、4 章 2 節で使った指数関数の性質にある。

指数関数では、微分は掛け算になる

定数 \(s\)（4 章の \(\lambda\) と同じく、複素数でもよい）について、\(e^{st}\) を微分すると \(se^{st}\) になる。\(e^{st}\) の形の関数では、微分することは \(s\) を掛けることと同じである。その逆の積分は、\(s\) で割ることと同じである（\(\int e^{st}dt = e^{st}/s\) ＋ 定数）。そこで、入力が \(e^{st}\) の形のとき、微分方程式がどうなるかを調べる。

方針: 一次遅れ \(T\dot y + y = Ku\) に \(u = e^{st}\) を加えたとき、出力も同じ \(e^{st}\) に比例する形 \(y = Ae^{st}\)（\(A\) は定数）で式を満たせるかを調べる。

導出: \(\dot y = sAe^{st}\) なので、式に入れると \(TsAe^{st} + Ae^{st} = Ke^{st}\) である。\(e^{st}\) はどの時刻でも 0 でないので、両辺をこれで割って \((Ts + 1)A = K\) となる。\(Ts + 1 \ne 0\) なら \(A = K/(Ts + 1)\) である ∎

微分方程式が、\(A\) についての 1 次方程式（代数の式）になった。式の中の微分 \(d/dt\) を、\(s\) に置き換えた形である。台車とばね・ダンパ \(m\ddot y + c\dot y + ky = u\)（\(y\) は位置、\(c\) は減衰係数、\(k\) はばね定数）でも、同じ手順で \((ms^2 + cs + k)A = 1\) となる。一定の入力は \(s = 0\) の \(e^{st}\) なので、\(A = 1/k\) = 0.04 m/N となり、4 章 1 節の定常ゲインと一致する。\(Ts + 1\) と \(ms^2 + cs + k\) は、4 章 2 節の特性方程式の左辺の \(\lambda\) を \(s\) に置き換えたものである。\(s\) が特性根に等しいと、これらが 0 になって \(A\) は決まらない。その \(s\) では、入力が無くても \(e^{st}\) が式を満たす（4 章 2 節の自由な動き）からである。

例として、止まっている DC モータ（\(T\) = 0.05 s、\(K\) = 50 (rad/s)/V）に、12 V から時定数 0.1 s で下がっていく電圧 \(u = 12e^{-10t}\) V を加える（例の値）。\(s = -10\) なので \(A\) = 50 ÷ (1 − 0.5) = 100 で、\(y = 1200e^{-10t}\) rad/s が式を満たす。ただし、これは時刻 0 に 1200 rad/s で回っている場合の解である。止まっている（\(y(0) = 0\) の）モータでは、差 \(y - 1200e^{-10t}\) が入力の無い式 \(T\dot y + y = 0\) を満たすので、3 章 2 節のとおり \(e^{-t/T} = e^{-20t}\) に比例する。初期値 0 に合わせて \(y(t) = 1200e^{-10t} - 1200e^{-20t}\) となる（図の (b)）。

入力に比例する部分は代数で求まったが、初期値に合わせる部分（自由な動き）は、別に求めて足す必要があった。実際の入力は \(e^{st}\) の形とは限らず、時刻 0 から加わり、初期値もある。そこで、次の手順を作る。

時間の関数を \(s\) の関数に変える計算（ラプラス変換。2 節。図の \(Y\)・\(U\) は、出力 \(y\) と入力 \(u\) を変換した関数）を使うと、微分は「\(s\) を掛けて初期値を引く」計算になる（3 節）。微分方程式は、入力と初期値を含んだ 1 つの代数の式になり、それを解いてから時間の関数に戻す（4 節）。掛け算を対数で足し算に変えて計算し、最後に元に戻すのと同じ考え方である（図の (b)）。戻さずに最終値や初期値を読む方法（5 節）と、3 章 3 節で予告した畳み込み（入力を細いパルスの並びとみなして応答を足し合わせる計算）が掛け算になること（6 節）も示す。

2. 定義と基本の変換

時刻 0 から後の関数 \(f(t)\)（\(t \ge 0\)）に対して、

\[ F(s) = \int_0^\infty f(t)\,e^{-st}\,dt \]

で決まる \(s\) の関数 \(F(s)\) を、\(f(t)\) の ラプラス変換 といい、\(F(s) = \mathcal{L}[f(t)]\) と書く。時間の関数を小文字、その変換を大文字で書く（入力 \(u\) の変換は \(U(s)\)、出力 \(y\) の変換は \(Y(s)\)）。\(s\) は複素数の変数で、\(s = \sigma + j\omega\)（\(\sigma\)・\(\omega\) は実数）と書く。\(e^{st} = e^{\sigma t}e^{j\omega t}\) の \(\sigma\) は増え方・減り方を、\(\omega\) は揺れの角周波数 [rad/s] を表すので、\(s\) を 複素周波数 という（単位は 1/s）。

2 つの約束をしておく。

  • 積分の下端の 0 は、時刻 0 の瞬間に加わるもの（3 章 3 節の、幅を 0 に近づけたパルス。この節の最後で単位インパルスとして定義する）も含むように、0 の直前から積分する。3 節の公式に出てくる初期値 \(f(0)\) も、入力を加える直前の値である。
  • 積分が有限の値になるのは、\(\sigma\) が \(f(t)\) の増え方より大きいときである。この章で扱う関数は、\(\sigma\) を十分に大きくとれば有限になる。そうして求めた \(F(s)\) の式は、その後は、分母が 0 になる所を除くすべての \(s\) で使う。

重みを付けた面積

\(s\) が実数（\(\omega = 0\)）のとき、\(F(s)\) は、\(f(t)\) に重み \(e^{-st}\) を掛けた曲線の下の面積である。

単位ステップ（\(t \ge 0\) で 1）では \(F(s) = \int_0^\infty e^{-st}dt = 1/s\) で、\(s\) = 0.5、1、2 /s では面積は 2、1、0.5 s になる。\(s\) を大きくするほど重みは速く減り、時刻 0 に近い所の \(f(t)\) だけが面積に効く（5 節で使う）。\(F(s)\) は 1 つの数ではなく、\(s\) ごとに値を持つ関数である。増え続ける \(e^{0.5t}\) でも、\(s > 0.5\) なら重みの減り方が勝って、面積は \(1/(s - 0.5)\) と有限になる（図の (c)）。

指数関数 \(e^{st}\) の形と s 平面

\(s\) を、横軸に \(\sigma\)、縦軸に \(\omega\) をとった複素平面の点で表す。この平面を s 平面 という（4 章 2 節の根の平面と同じ平面である）。オイラーの公式 \(e^{j\theta} = \cos\theta + j\sin\theta\)（DSP シリーズ 2 章 1 節）から \(e^{st} = e^{\sigma t}(\cos\omega t + j\sin\omega t)\) で、その実部は \(e^{\sigma t}\cos\omega t\) である。s 平面の点ごとに、この実部の波形を描く。

  • 横の位置 \(\sigma\) が、振れ幅の変わり方を決める。虚軸より左（\(\sigma < 0\)）では \(e^{\sigma t}\) で減り、右（\(\sigma > 0\)）では増え続け、虚軸の上（\(\sigma = 0\)）では変わらない。\(|\sigma|\) が大きいほど速く変わる。
  • 縦の位置 \(\omega\) が、揺れの速さを決める。実軸の上（\(\omega = 0\)）では揺れず、実軸から離れるほど速く揺れる。\(\omega\) の符号を変えた点（共役な点）の実部は、同じ波形になる。4 章 2 節で、特性根の実部が振幅の縮む速さを、虚部が揺れの角周波数を決めたのと同じ見方である。

基本の変換

積分は和と定数倍に分けて計算できるので、定数 \(b_1\)・\(b_2\) について

\[ \mathcal{L}[b_1 f_1(t) + b_2 f_2(t)] = b_1F_1(s) + b_2F_2(s) \]

が成り立つ（変換の線形性）。基本の変換は、指数関数の変換と、この性質から求まる。

方針: \(e^{\lambda t}\)（\(\lambda\) は複素数の定数）の変換を、定義の積分から直接求める。

導出: \(e^{\lambda t}e^{-st} = e^{-(s-\lambda)t}\) なので

\[ \mathcal{L}[e^{\lambda t}] = \int_0^\infty e^{-(s-\lambda)t}dt = \left[\frac{-e^{-(s-\lambda)t}}{s - \lambda}\right]_0^\infty = \frac{1}{s - \lambda} \]

である。上端で 0 になるのは、\(|e^{-(s-\lambda)t}| = e^{-(\sigma - \mathrm{Re}\,\lambda)t}\) が、\(\sigma > \mathrm{Re}\,\lambda\) のとき 0 に近づくからである ∎

s 平面の点 \(\lambda\) が \(e^{\lambda t}\) の形を決め（上の図）、変換 \(1/(s - \lambda)\) は、\(s\) がちょうどその点 \(\lambda\) に来ると分母が 0 になる。\(\lambda = 0\) とおくと単位ステップの \(1/s\)、\(\lambda = -1/T\) とおくと 3 章の \(e^{-t/T}\) の変換 \(1/(s + 1/T) = T/(Ts + 1)\) を得る。

\(\lambda = \pm j\omega_0\)（\(\omega_0\) は正の定数。\(s\) の虚部 \(\omega\) と区別するため、信号の角周波数を \(\omega_0\) と書く）とおき、\(\cos\omega_0 t = (e^{j\omega_0 t} + e^{-j\omega_0 t})/2\)、\(\sin\omega_0 t = (e^{j\omega_0 t} - e^{-j\omega_0 t})/(2j)\) に線形性を使う。分母を \((s - j\omega_0)(s + j\omega_0) = s^2 + \omega_0^2\) で通分すると、分子はそれぞれ \(2s\) と \(2j\omega_0\) になるので

\[ \mathcal{L}[\cos\omega_0 t] = \frac{1}{2}\left(\frac{1}{s - j\omega_0} + \frac{1}{s + j\omega_0}\right) = \frac{s}{s^2 + \omega_0^2}, \qquad \mathcal{L}[\sin\omega_0 t] = \frac{1}{2j}\left(\frac{1}{s - j\omega_0} - \frac{1}{s + j\omega_0}\right) = \frac{\omega_0}{s^2 + \omega_0^2} \]

である。\(t\) の変換は、部分積分で \(\int_0^\infty te^{-st}dt = [-te^{-st}/s]_0^\infty + (1/s)\int_0^\infty e^{-st}dt = 1/s^2\) である。さらに、時間の関数に \(e^{\lambda t}\)（\(\lambda\) は定数。複素数でもよい）を掛けると、\(\int_0^\infty e^{\lambda t}f(t)e^{-st}dt = \int_0^\infty f(t)e^{-(s - \lambda)t}dt\) なので、変換は \(F(s - \lambda)\) になる（\(s\) が \(\lambda\) だけずれる）。\(t\) に \(e^{\lambda t}\) を掛けると \(1/(s - \lambda)^2\) に、\(\cos\omega_0 t\)・\(\sin\omega_0 t\) に \(e^{\sigma_0 t}\)（\(\sigma_0\) は実数）を掛けると表の最後の行になる。まとめると次の表になる。

単位インパルス

3 章 3 節では、面積 1 のパルスの幅を 0 に近づけた極限の入力に対する応答を、インパルス応答と呼んだ。その極限の入力を 単位インパルス といい、\(\delta(t)\) と書く（デルタ関数 ともいう）。\(t \ne 0\) では 0 で、面積は 1 である。幅 \(t_\mathrm{w}\)・高さ \(1/t_\mathrm{w}\) のパルスの変換は \((1/t_\mathrm{w})\int_0^{t_\mathrm{w}} e^{-st}dt = (1 - e^{-st_\mathrm{w}})/(st_\mathrm{w})\) である。\(e^{-st_\mathrm{w}} = 1 - st_\mathrm{w} + (st_\mathrm{w})^2/2 - \cdots\) を入れると \(1 - st_\mathrm{w}/2 + \cdots\) となり、\(t_\mathrm{w}\) を 0 に近づけると 1 に近づく（\(s\) = 2 /s では、幅 0.5 s で 0.632、0.1 s で 0.906、0.05 s で 0.952）。したがって \(\mathcal{L}[\delta(t)] = 1\) である。時刻 \(t_0\) に加わる単位インパルスは \(\delta(t - t_0)\) と書く。

下の図で、s 平面の点 \(\lambda\) をドラッグする（またはつまみで実部 \(\sigma_0\) と虚部 \(\omega_0\) を変える）と、\(e^{\lambda t}\) の実部の波形、複素平面の上で回る \(e^{\lambda t}\) の点、変換の式が変わる。

3. 微分・積分・時間のずれの公式

1 節では、\(e^{st}\) の形の関数で、微分が \(s\) を掛けることになった。どんな関数でもそうなるのかを、変換の定義から確かめる。

微分

方針: \(\dot f(t)\) の変換の積分を、部分積分（\(\int \dot f\,g\,dt = [fg] - \int f\dot g\,dt\)）で、\(f(t)\) の変換の積分に直す。

導出: \(g = e^{-st}\) とすると \(\dot g = -se^{-st}\) なので

\[ \mathcal{L}[\dot f(t)] = \int_0^\infty \dot f(t)e^{-st}dt = \Big[f(t)e^{-st}\Big]_0^\infty + s\int_0^\infty f(t)e^{-st}dt \]

である。\(\sigma\) が十分に大きければ \(f(t)e^{-st}\) は \(t \to \infty\) で 0 になるので、右辺の第 1 項は \(0 - f(0)\) である。したがって

\[ \mathcal{L}[\dot f(t)] = sF(s) - f(0) \]

となる。\(\dot f\) にもう一度この式を使うと、\(\mathcal{L}[\ddot f] = s\mathcal{L}[\dot f] - \dot f(0) = s^2F(s) - sf(0) - \dot f(0)\) である ∎

初期値が 0 なら、微分は \(s\) を掛けることと同じで、1 節で \(e^{st}\) について見たことが、どんな関数にも成り立つ。初期値は、引く項として式に入る。下の図は、200 rad/s で回っているモータに 12 V を加えたときの角速度 \(y = 600 - 400e^{-20t}\) rad/s で、\(s\) = 20 /s での値を面積で確かめたものである。

一次遅れ \(T\dot y + y = Ku\) の両辺を変換すると、線形性と微分の公式から \(T\{sY(s) - y(0)\} + Y(s) = KU(s)\) で、\(Y(s)\) について解くと

\[ Y(s) = \frac{K}{Ts + 1}U(s) + \frac{T}{Ts + 1}y(0) \]

である。第 1 項は入力から決まる部分、第 2 項は初期値から決まる部分で、1 節で別々に求めた 2 つが 1 つの式にまとまった。台車とばね・ダンパ \(m\ddot y + c\dot y + ky = u\) では、同じように

\[ (ms^2 + cs + k)Y(s) = U(s) + (ms + c)y(0) + m\dot y(0) \]

となる。どちらも、\(Y(s)\) に掛かるのは、特性方程式の左辺の \(\lambda\) を \(s\) にした多項式である。

積分

方針: 時刻 0 から積分した関数を \(h(t) = \int_0^t f(\tau)\,d\tau\) とおくと、\(\dot h = f\)、\(h(0) = 0\) なので、微分の公式を \(h\) に使う。

導出: \(h\) の変換を \(H(s)\) とすると、\(F(s) = \mathcal{L}[\dot h] = sH(s) - h(0) = sH(s)\) なので

\[ \mathcal{L}\left[\int_0^t f(\tau)\,d\tau\right] = \frac{F(s)}{s} \]

である ∎

時刻 0 から積み上げる積分は、\(s\) で割ることになる。例えば、モータの回転角 \(\theta_\mathrm{m}\) は角速度 \(\omega_\mathrm{m}\) を積み上げたものなので、それぞれの変換を \(\Theta_\mathrm{m}(s)\)・\(\Omega_\mathrm{m}(s)\) と書くと \(\Theta_\mathrm{m}(s) = \Omega_\mathrm{m}(s)/s\) である（初期の角度が 0 のとき）。ブロック線図の積分の箱は、変換すると「\(1/s\) を掛ける」箱になり、線図をそのまま代数で解けるようになる。

図の (a) は、3 章 1 節の一次遅れの線図を、変換した信号で書いたものである（初期値 0）。引き出し点で取り出した \(Y\) を、加え合わせ点で \(KU\) から引く。積分の箱の入力 \(\dot y\) の変換は \(sY(s)\) で、ループを一周する式 \(sY = (KU - Y)/T\) を \(Y\) について解くと \((Ts + 1)Y = KU\) となり、微分方程式を変換した式と一致する。(b) は 4 章 6 節のモータの位置の比例制御（フィードバック制御）で、角速度を角度にする積分の箱が 1 つ加わる。解くと \((Ts^2 + s + KK_\mathrm{P})Y = KK_\mathrm{P}R\) で、左辺の多項式は、4 章 6 節の特性方程式 \(T\lambda^2 + \lambda + KK_\mathrm{P} = 0\) の左辺と同じである。線図をまとめる手順は 7 章 1 節で扱う。

時間のずれ — むだ時間

むだ時間 \(L\) だけの対象は、入力をそのまま \(L\) だけ遅らせる（3 章 4 節）。遅らせた関数 \(f(t - L)\) の変換を求める。\(t < 0\) では \(f(t) = 0\) とし、遅らせた関数は \(t < L\) で 0 である。

方針: 積分の変数を、遅らせる前の時刻 \(\tau = t - L\) に置き換える。

導出: \(t < L\) では \(f(t - L) = 0\) なので、積分は \(t = L\) から始まる。\(\tau = t - L\) とおくと \(t = \tau + L\)、\(dt = d\tau\) で、\(t = L\) は \(\tau = 0\) にあたる。\(e^{-s(\tau + L)} = e^{-Ls}e^{-s\tau}\) の \(e^{-Ls}\) は \(\tau\) によらないので積分の外に出せて

\[ \mathcal{L}[f(t - L)] = \int_L^\infty f(t - L)e^{-st}dt = \int_0^\infty f(\tau)e^{-s(\tau + L)}d\tau = e^{-Ls}F(s) \]

となる ∎

むだ時間は、変換に \(e^{-Ls}\) を掛けることになる。図の (b) のとおり、遅らせた関数に重み \(e^{-st}\) を掛けた曲線は、元の曲線を \(L\) だけ右へずらし、高さを \(e^{-sL}\) 倍したものである。3 章 4 節の一次遅れ＋むだ時間の温度の板（\(K\) = 1.25 K/W、\(T\) = 500 s、\(L\) = 20 s）に 40 W のステップを加えたときの読みの上がり幅は、\(e^{-20s} \times 50/\{s(500s + 1)\}\) である。3 章 3 節のパルス（高さ \(\Delta u\)、幅 \(t_\mathrm{w}\)）は、ステップと、\(t_\mathrm{w}\) だけ遅らせた負のステップの和なので、その変換は \(\Delta u(1 - e^{-t_\mathrm{w}s})/s\) で、2 節で積分から求めた式（高さ \(1/t_\mathrm{w}\) の場合）と一致する。

4. 微分方程式を解く — 部分分数分解

逆ラプラス変換

変換した式から求めた \(Y(s)\) を、時間の関数 \(y(t)\) に戻す。\(F(s)\) から \(f(t)\) を求めることを 逆ラプラス変換 といい、\(f(t) = \mathcal{L}^{-1}[F(s)]\) と書く。\(t \ge 0\) で連続な 2 つの関数の変換が等しければ、2 つの関数も等しいことが知られている（レルヒの定理。証明は省く）。そのため、2 節の表を右から左へ引けば、時間の関数に戻せる。ところが、代数で求めた \(Y(s)\) は、表にある形とは限らない分数である。そこで、表にある簡単な分数の和に分けてから戻す。

手順 — モータのステップ応答

止まっているモータ（\(T\) = 0.05 s、\(K\) = 50 (rad/s)/V）に 12 V を加える。3 章 2 節で解いた問題を、この章の道具で解き直す。

① では 3 節の式に \(y(0) = 0\) と、ステップの変換 \(U(s) = 12/s\) を入れ、② で \(Y(s)\) について解く。③ で、分母を因数に分けた簡単な分数の和に書き直す。このように書き直すことを 部分分数分解 という。分母の根 \(\lambda_1, \lambda_2, \ldots, \lambda_n\) がすべて異なり、分子の次数が分母の次数より低いとき、

\[ Y(s) = \frac{A_1}{s - \lambda_1} + \frac{A_2}{s - \lambda_2} + \cdots + \frac{A_n}{s - \lambda_n} \]

と書ける。係数 \(A_i\) を、根 \(\lambda_i\) での 留数 という。表から \(1/(s - \lambda_i)\) は \(e^{\lambda_i t}\) なので、④ で

\[ y(t) = A_1e^{\lambda_1 t} + A_2e^{\lambda_2 t} + \cdots + A_ne^{\lambda_n t} \]

となる。留数は次のように求める。

方針: 両辺に \((s - \lambda_i)\) を掛けてから \(s = \lambda_i\) とおき、ほかの項を消す。

導出: 両辺に \((s - \lambda_i)\) を掛けると、右辺の \(i\) 番目の項は \(A_i\) になり、ほかの項は \(A_j(s - \lambda_i)/(s - \lambda_j)\) になる。\(s = \lambda_i\) とおくと、根がすべて異なるので分母 \(\lambda_i - \lambda_j\) は 0 でなく、ほかの項は分子が 0 になって消える。左辺は、\(Y(s)\) の分母の因数 \((s - \lambda_i)\) を約した式に \(s = \lambda_i\) を入れた値になるので

\[ A_i = \Big[(s - \lambda_i)Y(s)\Big]_{s = \lambda_i} \]

である ∎

モータの例では \(A_1 = [12000/(s + 20)]_{s=0}\) = 600、\(A_2 = [12000/s]_{s=-20}\) = −600 で、\(y(t) = 600 - 600e^{-20t}\) rad/s となる。3 章 2 節の \(K\Delta u(1 - e^{-t/T})\) と一致する。掛けた因数を隠して、残りの式に根を入れる計算なので、ヘヴィサイドの被覆法とも呼ばれる（DSP シリーズ 5 章 4 節の逆 Z 変換と同じ計算）。分子の次数が分母の次数以上のときは、先に割り算をして多項式の部分を取り出す（取り出した部分は、時刻 0 のインパルスなどに戻る）。この章の応答の例では、分子の次数はいつも分母より低い。

分母の根はどこから来るか

1 節の例（12 V から時定数 0.1 s で下がる電圧）も同じ手順で解ける。\(U(s) = 12/(s + 10)\) なので \(Y(s) = 50 \times 12/\{(0.05s + 1)(s + 10)\} = 12000/\{(s + 10)(s + 20)\}\) で、留数は −10 で 1200、−20 で −1200 になり、1 節の答え \(1200e^{-10t} - 1200e^{-20t}\) が一度に求まる。初期値が 0 のとき、\(Y(s)\) の分母は「特性方程式の左辺の多項式」×「入力の変換の分母」である。入力から来た根 −10 の項は入力に比例する部分、特性根 −20 の項は自由な動きにあたる。ステップ応答では、入力から来た根 0 の項が、落ち着く値になる。

重根 — ランプ応答

3 章 3 節では、モータの電圧を 24 V/s で上げた。\(t\) の変換は \(1/s^2\) なので \(U(s) = 24/s^2\) で、\(Y(s) = 50 \times 24/\{s^2(0.05s + 1)\} = 24000/\{s^2(s + 20)\}\) となる。根 0 が 2 つ重なっている（重根）ので、項を \(A_1/s^2 + A_2/s + A_3/(s + 20)\) とおく。

  • \(A_1\): 両辺に \(s^2\) を掛けて \(s = 0\) とおくと、\(A_1 = [24000/(s + 20)]_{s=0}\) = 1200。
  • \(A_3\): 同じく \(A_3 = [24000/s^2]_{s=-20}\) = 60。
  • \(A_2\): \(s\) を掛けても \(A_1/s\) が残るので、この方法では求まらない。両辺に \(s^2(s + 20)\) を掛けた \(24000 = A_1(s + 20) + A_2s(s + 20) + A_3s^2\) の \(s^2\) の係数を比べると \(0 = A_2 + A_3\) なので、\(A_2\) = −60。

表から \(1/s^2\) は \(t\) なので、\(y(t) = 1200t - 60 + 60e^{-20t}\) rad/s である。3 章 3 節の \(K\alpha(t - T + Te^{-t/T})\) で \(\alpha\) = 24 V/s とおいたもの（\(K\alpha\) = 1200、\(K\alpha T\) = 60）と一致する。同じ根が 2 つ重なると \(te^{\lambda t}\) の項が現れる。4 章 3 節の臨界減衰（\(\zeta\) = 1）の台車（\(c\) = 10 N·s/m）を 1 N で押す場合も、特性根 −5 が重なり、\(Y(s) = 1/\{s(s + 5)^2\} = 0.04/s - 0.04/(s + 5) - 0.2/(s + 5)^2\) から \(y(t) = 0.04\{1 - (1 + 5t)e^{-5t}\}\) m となって、4 章 3 節の式と一致する。

共役な複素数の根 — 台車のステップ応答

4 章 3 節の台車（\(m\) = 1 kg、\(c\) = 2 N·s/m、\(k\) = 25 N/m）を 1 N で押し続ける。初期値 0 で 3 節の式に \(U(s) = 1/s\) を入れると、位置の変換は \(Y(s) = 1/\{s(s^2 + 2s + 25)\}\) [m] である。分母の根は 0 と \(-1 \pm j4.899\) である。後の 2 つは、4 章 2 節の特性根 \(-\zeta\omega_\mathrm{n} \pm j\omega_\mathrm{d}\)（固有角周波数 \(\omega_\mathrm{n}\) = 5 rad/s、減衰比 \(\zeta\) = 0.2 の不足減衰で、\(\omega_\mathrm{d}\) = 4.899 rad/s は減衰固有角周波数）である。

方針: 根がすべて異なるので、複素数の根でも留数の式がそのまま使える。共役な 2 つの項を足して、実数の関数にする。

導出: \(A_1 = [1/(s^2 + 2s + 25)]_{s=0}\) = 0.04 である。\(\lambda_2 = -1 + j4.899\) の留数は、分母の残りが \(s(s - \bar\lambda_2)\)（\(\bar\lambda_2\) は共役な根）なので、\(A_2 = 1/\{\lambda_2(\lambda_2 - \bar\lambda_2)\} = 1/\{(-1 + j4.899)(j9.798)\} = 1/(-48 - j9.798) = -0.02 + j0.00408\) である。\(Y(s)\) の係数は実数なので、\(s\) を共役な数に置き換えると値も共役になり、\(\bar\lambda_2\) の留数 \(A_3\) は \(A_2\) の共役である。ある数とその共役の和は実部の 2 倍なので、\(A_2 = a_\mathrm{r} + ja_\mathrm{i}\)、\(\lambda_2 = \sigma_0 + j\omega_0\) と書くと

\[ A_2e^{\lambda_2 t} + \bar A_2e^{\bar\lambda_2 t} = 2\,\mathrm{Re}\left[(a_\mathrm{r} + ja_\mathrm{i})e^{\sigma_0 t}(\cos\omega_0 t + j\sin\omega_0 t)\right] = 2e^{\sigma_0 t}(a_\mathrm{r}\cos\omega_0 t - a_\mathrm{i}\sin\omega_0 t) \]

である。\(a_\mathrm{r}\) = −0.02、\(a_\mathrm{i}\) = 0.00408、\(\sigma_0\) = −1、\(\omega_0\) = 4.899 を入れて

\[ y(t) = 0.04 - e^{-t}(0.04\cos 4.899t + 0.00816\sin 4.899t) = 0.04\left\{1 - e^{-t}(\cos 4.899t + 0.204\sin 4.899t)\right\}\ \text{m} \]

となる ∎

4 章 3 節で微分方程式を直接解いた式と一致する。共役な根の組は、根の実部 −1 で振幅が縮み、虚部 4.899 rad/s で揺れる項になる。2 節の s 平面の図で見た形そのものである。

初期値は分子に入る — 台車を引いて離す

4 章 2 節では、同じ台車を 4 cm 引いて静かに離した（\(y(0)\) = 0.04 m、\(\dot y(0)\) = 0、\(u\) = 0）。3 節の式で \(U(s) = 0\) とすると、\((s^2 + 2s + 25)Y(s) = (s + 2) \times 0.04\) で、

\[ Y(s) = \frac{0.04(s + 2)}{s^2 + 2s + 25} = 0.04\left\{\frac{s + 1}{(s + 1)^2 + 4.899^2} + \frac{1}{4.899} \cdot \frac{4.899}{(s + 1)^2 + 4.899^2}\right\} \]

である（分母を \((s + 1)^2 + 24\) と平方の形にし、分子を \((s + 1) + 1\) に分けた）。表の \(e^{\sigma_0 t}\cos\omega_0 t\) と \(e^{\sigma_0 t}\sin\omega_0 t\) の形なので、\(y(t) = 0.04e^{-t}(\cos 4.899t + 0.204\sin 4.899t)\) m で、0.64 s に −2.11 cm となる 4 章 2 節の動きと一致する。分母はステップ応答と同じなので、根も、揺れの角周波数と縮み方も同じで、分子（留数）だけが変わる。

どの例でも、応答は分母の根ごとの項 \(A_ie^{\lambda_i t}\)（重根では \(te^{\lambda_i t}\) なども）の和になった。根の位置が項の形を決め、留数が項の大きさを決める。入力と初期値は分子と、入力から来る根だけを変え、特性根は変えない。特性根の実部がすべて負なら、自由な動きの項は時間とともに消え、入力から来る項（ステップなら一定の値）だけが残る。4 章 3 節の過減衰のモータ（\(L_\mathrm{a}\) を含む）のステップ応答 \(600 - 606.2e^{-20.2t} + 6.19e^{-1980t}\) rad/s も、根 0・−20.2・−1980 の 3 つの項に分けて求められる。6 章では、分母の根を極と呼び、その位置から応答を読む。

下の図で、例を選ぶか s 平面の根をドラッグすると、部分分数の各項の時間波形（根と同じ色）と、その和、微分方程式を数値で解いた応答が表示される。

5. 最終値の定理と初期値の定理

応答が最後にどの値に落ち着くか、動き始めにどう動くかだけを知りたいことは多い（7 章では、定常偏差をこれで求める）。そのたびに部分分数に分けて時間の関数に戻すのは手間がかかるので、\(Y(s)\) から直接読む方法を導く。

最終値の定理

方針: 4 節の部分分数の形で、\(t \to \infty\) でどの項が残るかを調べる。

導出: \(Y(s)\) の分母に \(s = 0\) の根が 1 つあれば、その項を \(A_0/s\) と書き、ほかの根の項を \(A_ie^{\lambda_i t}\)（重根では \(t^ke^{\lambda_i t}\) も）と書くと、\(y(t) = A_0 + \sum_i A_ie^{\lambda_i t} + \cdots\) である。ほかの根の実部がすべて負なら、\(|e^{\lambda_i t}| = e^{(\mathrm{Re}\,\lambda_i)t}\) は 0 に近づき（\(t^k\) が掛かっていても、指数関数の減り方が勝つので 0 に近づく）、\(y(t)\) は \(A_0\) に近づく。\(A_0\) は留数の式から \([sY(s)]_{s=0}\) なので

\[ \lim_{t\to\infty} y(t) = \lim_{s\to 0} sY(s) \]

となる。\(s = 0\) の根が無ければ \(A_0\) = 0 で、両辺とも 0 である ∎

これを 最終値の定理 という。使える条件は、\(sY(s)\) の分母の根の実部がすべて負であることである。モータのステップ応答では \(sY(s) = 12000/(s + 20)\) で、分母の根は −20、\(s \to 0\) で 600 rad/s となる。台車のステップ応答では \(sY(s) = 1/(s^2 + 2s + 25)\) で、0.04 m となる。どちらも 4 節で時間の関数に戻した値と一致する。条件を満たさないのに使うと、誤った値が出る。

  • (c) \(\sin 5t\) の \(sY(s) = 5s/(s^2 + 25)\) は \(s \to 0\) で 0 になるが、\(\sin 5t\) は −1 と 1 の間を揺れ続け、落ち着かない。分母の根 \(\pm j5\) の実部が 0 だからである。増え続ける \(e^{0.5t}\) でも、\(sY(s) = s/(s - 0.5)\) は \(s \to 0\) で 0 になる。
  • (d) 4 章 6 節のモータの位置の比例制御を、巻線のインダクタンス \(L_\mathrm{a}\) を含めた式で考える。4 章 1 節の \(L_\mathrm{a}J\ddot\omega_\mathrm{m} + R_\mathrm{a}J\dot\omega_\mathrm{m} + K_\mathrm{t}^2\omega_\mathrm{m} = K_\mathrm{t}v\)（\(K_\mathrm{t}\) はトルク定数）に、\(\omega_\mathrm{m} = \dot y\)（\(y = \theta_\mathrm{m}\)）と比例制御 \(v = K_\mathrm{P}(r - y)\) を入れると、\(L_\mathrm{a}J\dddot y + R_\mathrm{a}J\ddot y + K_\mathrm{t}^2\dot y + K_\mathrm{t}K_\mathrm{P}y = K_\mathrm{t}K_\mathrm{P}r\) である。初期値 0、目標値 1 rad のステップ（\(R(s) = 1/s\)）で変換すると \(sY(s) = K_\mathrm{t}K_\mathrm{P}/(L_\mathrm{a}Js^3 + R_\mathrm{a}Js^2 + K_\mathrm{t}^2s + K_\mathrm{t}K_\mathrm{P})\) で、どの \(K_\mathrm{P}\) でも \(s \to 0\) で 1 rad になる。ところが \(K_\mathrm{P}\) = 50 V/rad では、分母の根が \(2.46 \pm j223\) と −2005 で、実部が正の根がある。角度は周期 28 ms で揺れながら、振れ幅を 0.28 s ごとに 2 倍に増やしていく（4 章 6 節で、40 V/rad を超えると揺れが大きくなり続けると述べた場合。根は 40 V/rad でちょうど \(\pm j200\) を通る）。不安定な応答では、最終値の定理の値は意味を持たない。最終値の定理を使う前に、\(sY(s)\) の分母の根の実部がすべて負であることを確かめる。

初期値の定理

方針: 同じく部分分数の形で、\(s \to \infty\) での \(sY(s)\) と、\(t \to 0\) での \(y(t)\) を比べる。

導出: 根がすべて異なるとき、\(sY(s) = \sum_i A_is/(s - \lambda_i)\) で、\(s \to \infty\) では \(s/(s - \lambda_i) \to 1\) なので \(sY(s) \to \sum_i A_i\) である。一方、\(y(t) = \sum_i A_ie^{\lambda_i t}\) は \(t \to 0\) で \(\sum_i A_i\) に近づく。重根の項 \(A/(s - \lambda)^k\)（\(k \ge 2\)）は、\(s\) を掛けても \(s \to \infty\) で 0 になり、対応する \(t^{k-1}e^{\lambda t}\) も \(t \to 0\) で 0 になるので、結論は変わらない。したがって

\[ y(0^+) = \lim_{s\to\infty} sY(s) \]

である ∎

これを 初期値の定理 という。\(y(0^+)\) は時刻 0 の直後の値で、インパルスが加わると、直前の値 \(y(0)\) と違うことがある。3 節の微分の公式と組み合わせると、動き始めの傾きも分かる。\(\mathcal{L}[\dot y] = sY(s) - y(0)\) に初期値の定理を使うと、\(\dot y(0^+) = \lim_{s\to\infty} s\{sY(s) - y(0)\}\) である。

  • モータのステップ応答: \(s \cdot sY(s) = 12000s/(s + 20) \to 12000\) rad/s² で、3 章 1 節の始めの角加速度と一致する。
  • 台車のステップ応答: 位置も速度も始めは 0 で、加速度は \(s^3Y(s) = s^2/(s^2 + 2s + 25) \to 1\) m/s² である。押す力 1 N を質量 1 kg で割った値である。
  • 一次遅れのインパルス応答: \(Y(s) = K/(Ts + 1)\) から \(y(0^+) = K/T\) である。3 章 3 節で、台車を 0.2 N·s で叩くと速度が 0.2 m/s に跳んだのは、\(K/T = 1/m\) = 1 (m/s)/(N·s) だからである。直前の \(y(0)\) は 0 で、インパルスが加わった直後に跳ぶ。

重みを付けた平均として見る

2 つの定理には、2 節の「重みを付けた面積」から見た意味がある。\(s\) が正の実数のとき、\(sY(s) = \int_0^\infty y(t)\,se^{-st}dt\) で、重み \(se^{-st}\) の面積は \(s\int_0^\infty e^{-st}dt = 1\) である。つまり \(sY(s)\) は、\(y(t)\) を、時刻 \(1/s\) のあたりに重みを置いて平均した値である。

\(s\) を小さくすると、重みは遠い未来まで広がり、平均は、\(y(t)\) が落ち着くならその値に近づく。\(s\) を大きくすると、時刻 0 の直後だけを平均するようになる。\(\sin 5t\) の長い時間の平均は 0 なので、最終値の定理は、落ち着かない \(\sin 5t\) にも 0 を返したのである。

下の図で例を選ぶと、\(sY(s)\) の分母の根、時間の応答と最終値の定理の値、実数の \(s\) に対する \(sY(s)\) の曲線が表示される。モータの位置の比例制御では、比例ゲインを動かして、根が虚軸を越える所で応答が落ち着かなくなる（定理の値は 1 rad のまま変わらない）ことを確かめられる。

6. 畳み込み — 入力と応答の関係を掛け算に

入力を細いパルスの和とみなす

3 章 3 節では、どんな入力も細いパルスの並びとみなせて、その応答はインパルス応答を重ね合わせて求められると述べた。その計算を式にする。インパルス応答を \(g(t)\) と書き（3 章 3 節と同じ）、初期値は 0 とする。

方針: 入力 \(u(t)\) を幅 \(\Delta\tau\) の細い帯に分け、各帯をインパルスとみなして応答を足し合わせる。帯を細くした極限を積分で書く。

導出: \(k\) 番目の帯の中ほどの時刻を \(\tau_k\) とすると、その帯は、面積がほぼ \(u(\tau_k)\Delta\tau\) のパルスである。帯が細ければ、その応答は、インパルス応答を面積の倍にして \(\tau_k\) だけ遅らせた \(u(\tau_k)\Delta\tau\,g(t - \tau_k)\) に近い（線形なので面積の倍、時不変なので \(\tau_k\) 遅れ）。時刻 \(t\) の出力は、\(\tau_k\) が \(t\) より前のすべての帯の応答の和なので

\[ y(t) \approx \sum_{\tau_k < t} g(t - \tau_k)\,u(\tau_k)\,\Delta\tau \]

で、\(\Delta\tau\) を 0 に近づけると

\[ y(t) = \int_0^t g(t - \tau)\,u(\tau)\,d\tau \]

となる ∎

この積分を、\(g\) と \(u\) の 畳み込み といい、\((g * u)(t)\) と書く。変数を \(\tau' = t - \tau\) に置き換えると \(\int_0^t g(\tau')u(t - \tau')\,d\tau'\) とも書けるので、\(g\) と \(u\) を入れ替えてもよい。初期値が 0 なら、線形で時不変な対象の応答は、インパルス応答 1 つから、どんな入力についても求まる。

図は、ばねの無い台車の速度（\(T\) = 0.5 s、\(K\) = 0.5 (m/s)/N。インパルス応答 \(g(t) = (K/T)e^{-t/T} = e^{-2t}\) (m/s)/(N·s)）を、1 s かけて 0 から 2 N に上げ、次の 1 s で 0 に戻す力で押した場合である。帯の幅を 0.5 s、0.25 s、0.1 s と細くすると、1.5 s の速度は 0.643、0.653、0.656 m/s となり、微分方程式を数値で解いた 0.657 m/s に近づく。

裏返してずらす

2 つ目の形 \(y(t) = \int_0^t g(\tau)\,u(t - \tau)\,d\tau\) は、別の見方を与える。\(u(t - \tau)\) を \(\tau\) の関数として見ると、入力を時間の向きに裏返し、\(t\) だけ右へずらしたものである。\(\tau\) 秒前の入力 \(u(t - \tau)\) に、重み \(g(\tau)\) を掛けて足し合わせるので、インパルス応答は、対象がどれだけ前の入力を、どれだけ覚えているかを表す重みである。台車の速度の \(g(\tau) = e^{-2\tau}\) は、0.5 s 前の入力を 0.37 倍、1 s 前の入力を 0.14 倍の重みで覚えている。時刻 \(t\) が進むと、裏返した入力が右へずれ、重なる部分の積の面積が、その時刻の出力になる。

変換すると掛け算になる

方針: 畳み込みの変換を 2 重の積分として書き、積分の順序を入れ替えて、内側の積分を時間のずれの公式（3 節）の形にする。

導出: 定義から

\[ \mathcal{L}[(g * u)(t)] = \int_0^\infty\left\{\int_0^t g(t - \tau)\,u(\tau)\,d\tau\right\}e^{-st}dt \]

である。積分する範囲は、\(0 \le \tau \le t\) を満たす \((\tau, t)\) の三角形の領域である（下の図の (a)）。先に \(\tau\) を固定して、\(t\) を \(\tau\) から \(\infty\) まで積分するように順序を入れ替えると

\[ \mathcal{L}[(g * u)(t)] = \int_0^\infty u(\tau)\left\{\int_\tau^\infty g(t - \tau)\,e^{-st}dt\right\}d\tau \]

となる。内側の積分は、\(g\) を \(\tau\) だけ遅らせた関数の変換なので、時間のずれの公式から \(e^{-s\tau}G(s)\) である（\(G(s)\) は \(g(t)\) の変換）。\(G(s)\) は \(\tau\) によらないので外に出せて

\[ \mathcal{L}[(g * u)(t)] = G(s)\int_0^\infty u(\tau)\,e^{-s\tau}d\tau = G(s)U(s) \]

となる ∎

初期値が 0 なら \(Y(s) = G(s)U(s)\) で、時間の世界の畳み込みが、\(s\) の世界では掛け算になる。一次遅れでは、3 章 3 節の \(g(t) = (K/T)e^{-t/T}\) の変換は \((K/T)/(s + 1/T) = K/(Ts + 1)\) で、3 節で微分方程式を変換して得た式（初期値 0）の、\(U(s)\) に掛かる \(K/(Ts + 1)\) と一致する。図の (b) のとおり、微分方程式・インパルス応答・\(G(s)\) は、同じ対象の 3 つの表し方である。台車とばね・ダンパでは \(G(s) = 1/(ms^2 + cs + k)\)、むだ時間だけの対象では \(g(t) = \delta(t - L)\)、\(G(s) = e^{-Ls}\) である。6 章では、この \(G(s)\) を伝達関数と呼ぶ。

下の図で対象と入力を選び、時刻を動かす（または再生する）と、裏返してずらした入力とインパルス応答の積が描かれ、その面積が、その時刻の出力として応答の曲線を描いていく。

7. まとめ

項目内容
ラプラス変換・複素周波数・s 平面\(F(s) = \int_0^\infty f(t)e^{-st}dt\)／\(s = \sigma + j\omega\)。\(\sigma\) が増え方・減り方、\(\omega\) が揺れの角周波数を表す／\(s\) を表す複素平面。点 \(\lambda\) の位置が \(e^{\lambda t}\) の形を決める
基本の変換\(e^{\lambda t} \leftrightarrow 1/(s - \lambda)\)。そこから単位ステップ \(1/s\)、\(\cos\omega_0 t\)・\(\sin\omega_0 t\)。\(t \leftrightarrow 1/s^2\)。\(e^{\lambda t}\) を掛けると \(s\) が \(s - \lambda\) にずれる
単位インパルス（デルタ関数）面積 1 のパルスの幅を 0 に近づけた極限 \(\delta(t)\)。変換は 1
微分・積分・時間のずれ\(sF(s) - f(0)\)、\(s^2F(s) - sf(0) - \dot f(0)\)／\(F(s)/s\)／\(e^{-Ls}F(s)\)。初期値は引く項として入り、積分の箱は \(1/s\)、むだ時間は \(e^{-Ls}\) になる
逆ラプラス変換・部分分数分解・留数\(F(s)\) から \(f(t)\) を求めること（表を逆に引く）／分母の因数ごとの簡単な分数の和に書き直すこと／\(1/(s - \lambda_i)\) の係数 \(A_i = [(s - \lambda_i)F(s)]_{s=\lambda_i}\)。応答は \(\sum A_ie^{\lambda_i t}\) で、重根は \(te^{\lambda t}\)、共役な組は減衰振動
最終値の定理\(\lim_{t\to\infty} y(t) = \lim_{s\to 0} sY(s)\)。\(sY(s)\) の分母の根の実部がすべて負のときだけ使える
初期値の定理\(y(0^+) = \lim_{s\to\infty} sY(s)\)。微分の公式と合わせると、動き始めの傾きが分かる
畳み込み\((g * u)(t) = \int_0^t g(t - \tau)u(\tau)d\tau\)。初期値 0 の応答はインパルス応答と入力の畳み込みで、変換すると \(Y(s) = G(s)U(s)\)

3・4 章の答えは、すべてこの章の手順で、変換・代数・部分分数分解・表の逆引きという同じ流れで求め直せた。次章では、\(Y(s) = G(s)U(s)\) の \(G(s)\) を伝達関数と呼び、その分母の根（極）と分子の根（零点）を s 平面に描いて、応答の形・安定性・行き過ぎを、時間の関数に戻さずに読む。
