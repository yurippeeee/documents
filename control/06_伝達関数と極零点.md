## 1. 伝達関数 — 入力から出力への比

5 章 3 節で見たとおり、微分方程式をラプラス変換して解いた出力の変換 $`Y(s)`$ は、入力から決まる部分と初期値から決まる部分の和になる。5 章 6 節では、初期値が 0 なら $`Y(s) = G(s)U(s)`$ と、入力の変換 $`U(s)`$ に 1 つの関数 $`G(s)`$ を掛けた形になることを、畳み込みから示した。この節では、この $`G(s)`$ を微分方程式から直接求め、名前を付ける。

### 微分方程式から伝達関数へ

入力 $`u`$ と出力 $`y`$ が、次の形の線形で時不変な微分方程式で結ばれているとする。$`a_i`$・$`b_i`$ は定数で、$`a_n \ne 0`$ とする（右辺の高い次の係数は 0 でもよい）。$`y^{(i)}`$ は、$`y`$ を $`i`$ 回微分したもので、$`n`$ は式の階数である。

$$
a_n y^{(n)} + \cdots + a_1\dot y + a_0 y = b_n u^{(n)} + \cdots + b_1\dot u + b_0 u
$$

4 章の二次遅れは、$`n`$ = 2 で $`b_2 = b_1`$ = 0 の場合にあたる。

**方針**: すべての初期値（$`y`$・$`u`$ と、それらの $`n - 1`$ 回までの微分の、時刻 0 の値）を 0 として両辺をラプラス変換し、$`Y(s)`$ と $`U(s)`$ の比を求める。

**導出**: 微分の公式 $`\mathcal{L}[\dot f] = sF(s) - f(0)`$（5 章 3 節）を $`f = y^{(i-1)}`$ に使うと、$`\mathcal{L}[y^{(i)}] = s\,\mathcal{L}[y^{(i-1)}] - y^{(i-1)}(0)`$ で、初期値が 0 なので $`\mathcal{L}[y^{(i)}] = s\,\mathcal{L}[y^{(i-1)}]`$ である。これを $`i`$ = 1, 2, … と繰り返すと、$`\mathcal{L}[y^{(i)}] = s^iY(s)`$ となる。$`u`$ も同じである。変換の線形性（5 章 2 節）から、左辺の変換は $`(a_ns^n + \cdots + a_1s + a_0)Y(s)`$、右辺の変換は $`(b_ns^n + \cdots + b_1s + b_0)U(s)`$ になる。両辺を、左辺の多項式と $`U(s)`$ で割って

$$
\frac{Y(s)}{U(s)} = \frac{b_ns^n + \cdots + b_1s + b_0}{a_ns^n + \cdots + a_1s + a_0}
$$

となる ∎

右辺は複素周波数 $`s`$ の多項式の分数で、微分方程式の係数だけで決まり、入力がどんな形でも変わらない。すべての初期値を 0 としたときの、出力のラプラス変換と入力のラプラス変換の比を、その対象の**伝達関数**という。この章では $`G(s)`$ と書く。

$$
G(s) = \frac{Y(s)}{U(s)}, \qquad Y(s) = G(s)\,U(s)
$$

分母の多項式は、微分方程式の左辺の $`y^{(i)}`$ を $`s^i`$ に置き換えたもの、分子の多項式は、右辺の $`u^{(i)}`$ を $`s^i`$ に置き換えたものである。逆に、伝達関数の $`s^i`$ を $`i`$ 回の微分に戻せば、微分方程式が書ける。入力に単位インパルス（変換は 1。5 章 2 節）を加えると $`Y(s) = G(s)`$ で、そのときの出力はインパルス応答 $`g(t)`$ なので、伝達関数はインパルス応答のラプラス変換 $`G(s) = \mathcal{L}[g(t)]`$ でもある。5 章 6 節の $`G(s)`$ は、伝達関数そのものだった。


図の (a) は、巻線のインダクタンス $`L_\mathrm{a}`$ を含めた DC モータの式（4 章 1 節）を、項ごとに置き換えたものである。電圧 $`v`$ から角速度 $`\omega_\mathrm{m}`$ までの伝達関数は、例の値で $`2 \times 10^6/(s^2 + 2000s + 40000)`$ である。1 章 2 節で予告したとおり、これからはブロック線図の箱の中に伝達関数を書く（図の (b)）。入る矢印の信号の変換に、箱の伝達関数を掛けたものが、出る矢印の信号の変換である。図の (c) のとおり、同じ伝達関数に単位インパルスを入れても単位ステップを入れても（ほかのどんな入力でも）、$`Y(s) = G(s)U(s)`$ を逆ラプラス変換すれば応答が求まる。

### 初期値は比に入らない

5 章 3 節の台車とばね・ダンパの式 $`(ms^2 + cs + k)Y(s) = U(s) + (ms + c)y(0) + m\dot y(0)`$（$`y`$ は位置）のとおり、初期値が 0 でなければ、$`Y(s)`$ には入力に比例しない項が加わる。式が線形なので、応答は、初期値を 0 として入力だけを加えた応答と、入力を 0 として初期値から始めた動きの和になる（2 章 1 節の重ね合わせの原理と同じ考え方で、代入して確かめられる）。台車を 2 cm 引いて静かに離すと同時に、一定の力で押し始める場合で、応答をこの 2 つの部分に分ける。

```fig
e06_ic
```

- 入力による部分（初期値 0 の応答。伝達関数で決まる）は、力を 1 N から 2 N にすると、そのまま 2 倍になる（最初の山は 6.11 cm と 12.2 cm）。
- 初期値による部分（入力 0 の自由な動き。4 章 2 節）は、力によらず同じで、0.64 s に −1.05 cm まで行き過ぎてから 0 に戻る。
- 2 つの和である実際の位置は、力を 2 倍にしても 2 倍にならない（最初の山は 5.05 cm と 11.2 cm）。

出力と入力の比が入力によらず決まるのは、初期値による部分を除いたときだけである。これが、伝達関数を、初期値をすべて 0 として定義する理由である。初期値による部分の分母も同じ多項式なので（5 章 3 節）、その形も、2 節で見るように伝達関数の分母の根で決まる。

## 2. 極と零点

伝達関数の分母と分子は $`s`$ の多項式なので、因数に分けられる。5 章 4 節では、応答の変換 $`Y(s)`$ の分母の根の位置が項の形を決め、留数が項の大きさを決めた。伝達関数そのものの根に名前を付ける。

### 分母の根と分子の根

伝達関数の分母の多項式を 0 とおいた方程式の根を**極**、分子の多項式を 0 とおいた方程式の根を**零点**という。ここでは、分母と分子に共通の因数が無い（約分してある）とする（共通の因数がある場合は 6 節）。極を $`p_1, p_2, \ldots`$、零点を $`z_1, z_2, \ldots`$ と書くと、伝達関数は

$$
G(s) = \beta\,\frac{(s - z_1)(s - z_2)\cdots}{(s - p_1)(s - p_2)\cdots}
$$

と書ける。$`\beta`$ は、分子の最も高い次の係数を分母の最も高い次の係数で割った定数である。例えば $`G(s) = 7.5(s + 2)/\{(s + 3)(s^2 + 2s + 5)\}`$ では、$`s^2 + 2s + 5 = 0`$ の根が $`-1 \pm j2`$ なので、極は −3 と $`-1 \pm j2`$、零点は −2、$`\beta`$ = 7.5 である。$`s`$ が極に近づくと分母が 0 に近づくので $`|G(s)|`$ は限りなく大きくなり、零点では $`G(s)`$ = 0 になる。$`|G(s)|`$ を s 平面（5 章 2 節）の上の高さとして描くと、極は高い柱に、零点はくぼみになる。

```fig
e06_pz_surface
```

極を ×、零点を ○ で s 平面に描いたものを、極と零点の配置図と呼ぶ（図の (b)）。係数が実数の多項式が $`s = p`$ で 0 になるとき、その式の両辺の共役をとると、係数は共役をとっても変わらず、共役は和と積に分けてとれるので、$`s = \bar p`$ でも 0 になる。複素数の極と零点は共役な組で現れ、配置図は実軸について上下対称になる。

### 極は特性根と同じもの

4 章 2 節では、入力の無い式に $`y = e^{\lambda t}`$ を入れて特性方程式を作り、その根（特性根）の位置から応答を読んだ。伝達関数の極との関係を確かめる。

**方針**: 1 節で求めた分母の多項式の作り方と、特性方程式の作り方を比べる。

**導出**: 1 節のとおり、伝達関数の分母は、微分方程式の左辺の $`y^{(i)}`$ を $`s^i`$ に置き換えた多項式である。一方、入力の無い式 $`a_ny^{(n)} + \cdots + a_0y = 0`$ に $`y = e^{\lambda t}`$ を入れると、$`y^{(i)} = \lambda^ie^{\lambda t}`$ なので $`(a_n\lambda^n + \cdots + a_0)e^{\lambda t} = 0`$ となり、特性方程式は左辺の $`y^{(i)}`$ を $`\lambda^i`$ に置き換えた多項式を 0 とおいたものである。2 つの多項式は文字が違うだけなので、分母を 0 とおいた方程式の根、つまり極は、特性根に等しい ∎

例の台車の極 $`-1 \pm j4.90`$ は、4 章 2 節の特性根そのものである。したがって、4 章 2 節で根の平面について読んだことは、そのまま s 平面の極について成り立つ。不足減衰の共役な極の組 $`-\zeta\omega_\mathrm{n} \pm j\omega_\mathrm{d}`$（$`\omega_\mathrm{d}`$ は減衰固有角周波数）は、原点から固有角周波数 $`\omega_\mathrm{n}`$ の距離にあり、負の実軸となす角 $`\psi`$ は $`\cos\psi = \zeta`$ を満たし、実部が振幅の縮む速さを、虚部が揺れの角周波数を決める。初期値による部分（1 節）も同じ特性根の項でできているので、極は、入力に対する応答と初期値からの動きの両方の形を決める。

### 次数とプロパー

分母の多項式の次数（極の数）を、伝達関数の**次数**という。共通の因数が無ければ、微分方程式の階数（2 章 1 節）に等しい。台車とばね・ダンパは 2 次、$`L_\mathrm{a}`$ を無視したモータの角速度は 1 次、$`L_\mathrm{a}`$ を含めると 2 次である。

分子の次数が分母の次数以下の伝達関数を**プロパー**、分子の次数が分母の次数より小さい伝達関数を**厳密にプロパー**という。分子と分母の次数の差で、入力を急に変えた瞬間の出力が変わる。

```fig
e06_proper
```

- 厳密にプロパー（(a)。分子 0 次・分母 1 次）: ステップ応答は 0 から連続に動き始める。1 節の表の対象は、どれもこれにあたる。質量や熱容量のために、出力は入力の変化に遅れてしか動けない。
- プロパーだが厳密でない（(b)。どちらも 1 次）: $`(0.1s + 1)/(0.5s + 1) = 0.2 + 0.8/(0.5s + 1)`$ と、定数と厳密にプロパーな部分に分けられ、入力の 0.2 倍が遅れずに出力に現れる。ステップ応答は時刻 0 に 0.2 へ跳ぶ。
- プロパーでない（(c)。分子 1 次・分母 0 次）: $`0.1s + 1`$ は入力の変わる速さを出力に通す。ステップ入力の微分は単位インパルスなので、ステップ応答は時刻 0 に高さが限りなく大きいパルスを含む。

プロパーでない伝達関数は、入力の速い変化ほど大きく出力に通すので、測った値に混じる観測ノイズ（1 章 4 節）を大きくする。偏差の変わる速さを使う制御器（10 章の D 動作）を、そのままの形ではなく、プロパーな形に直して使う（10 章 6 節）のはこのためである。

## 3. 極の位置と応答の形

### 極ごとの項に分ける

5 章 4 節の部分分数分解を、伝達関数そのものに使う。極 $`p_i`$ がすべて異なり、$`G(s)`$ が厳密にプロパーなら、留数 $`A_i = [(s - p_i)G(s)]_{s=p_i}`$ を使って

$$
G(s) = \frac{A_1}{s - p_1} + \cdots + \frac{A_n}{s - p_n}, \qquad g(t) = A_1e^{p_1t} + \cdots + A_ne^{p_nt}
$$

となる。インパルス応答は、極ごとの指数関数 $`e^{p_it}`$ の和である。各項の形（減り方・揺れ方）は極の位置だけで決まり、大きさ $`A_i`$ は、ほかの極と零点の位置も含めた式で決まる。単位ステップの入力では $`Y(s) = G(s)/s`$ で、極 0 の留数が $`G(0)`$、極 $`p_i`$ の留数が $`A_i/p_i`$ なので

$$
y(t) = G(0) + \frac{A_1}{p_1}e^{p_1t} + \cdots + \frac{A_n}{p_n}e^{p_nt}
$$

である（$`p_i`$ に 0 が無いとき）。ステップ応答も、最終値 $`G(0)`$ に近づく形は、同じ極の項で決まる。

```fig
e06_terms
```

2 節の例 $`G(s) = 7.5(s + 2)/\{(s + 3)(s^2 + 2s + 5)\}`$ では、留数は −3 で −0.9375、$`-1 \pm j2`$ で $`0.469 \mp j1.406`$ で、インパルス応答は

$$
g(t) = -0.9375\,e^{-3t} + 2.965\,e^{-t}\cos(2t - 71.6^\circ)
$$

である。極 −3 の項は時定数 1/3 s で速く消え、0.5 s 後には始めの 0.22 倍になる。その後の応答は、極の組 $`-1 \pm j2`$ の、周期 $`2\pi/2`$ = 3.14 s で揺れながら $`e^{-t}`$ で縮む項だけでできている。

### 共役な極の組は減衰振動になる

共役な極の組を $`\sigma_0 \pm j\omega_0`$（$`\omega_0 > 0`$）と書く。2 つの項の和を、実数の形に直す。

**方針**: 係数が実数の伝達関数では、共役な極の留数も共役になる（5 章 4 節）。共役な 2 つの項の和は 1 つの項の実部の 2 倍なので、留数を大きさと偏角で書いて、オイラーの公式を使う。

**導出**: 極 $`p = \sigma_0 + j\omega_0`$ の留数を $`A = |A|e^{j\angle A}`$ と書く（$`\angle A`$ は $`A`$ の偏角）。もう 1 つの項は $`\bar Ae^{\bar pt}`$ で、1 つ目の項の共役なので、和は

$$
Ae^{pt} + \bar Ae^{\bar pt} = 2\,\mathrm{Re}\left[|A|e^{j\angle A}e^{\sigma_0t}e^{j\omega_0t}\right] = 2|A|\,e^{\sigma_0t}\cos(\omega_0t + \angle A)
$$

となる ∎

極の組は、角周波数 $`\omega_0`$ で揺れ、振幅が $`e^{\sigma_0t}`$ で変わる項を作る。二次遅れなら $`\sigma_0 = -\zeta\omega_\mathrm{n}`$、$`\omega_0 = \omega_\mathrm{d}`$ で、4 章 2 節の自由な動きと同じである。極の位置と項の形をまとめる。

| 極の位置 | 項の形 | インパルス応答の振る舞い |
|---|---|---|
| 負の実軸の上 $`p < 0`$ | $`e^{pt}`$ | 揺れずに減る。時定数 $`1/|p|`$（−20 なら 0.05 s） |
| 原点 0 | 一定の値 | 減らずに残る（積分。ステップ応答は一定の速さで増え続ける） |
| 正の実軸の上 $`p > 0`$ | $`e^{pt}`$ | 揺れずに増え続ける（+6.77 なら 0.102 s ごとに 2 倍） |
| 実部が負の組 $`\sigma_0 \pm j\omega_0`$ | $`e^{\sigma_0t}\cos(\omega_0t + \angle A)`$ | 揺れながら減る |
| 虚軸の上の組 $`\pm j\omega_0`$ | $`\cos(\omega_0t + \angle A)`$ | 同じ振幅で揺れ続ける |
| 実部が正の組 | $`e^{\sigma_0t}\cos(\omega_0t + \angle A)`$ | 揺れながら増え続ける |
| 重なった極（重根） | $`te^{pt}`$ など（5 章 4 節） | 実部が負なら減る。実部が 0 なら $`t`$ に比例して増える |

### 位置から読む速さ・揺れ・行き過ぎ

極の組 $`\sigma_0 \pm j\omega_0`$ だけをもち、最終値が 1 の二次遅れ $`G(s) = \omega_\mathrm{n}^2/(s^2 + 2\zeta\omega_\mathrm{n}s + \omega_\mathrm{n}^2)`$ で、4 章 4 節の指標を極の位置で書き直す。$`\omega_\mathrm{n} = \sqrt{\sigma_0^2 + \omega_0^2}`$、$`\zeta = -\sigma_0/\omega_\mathrm{n}`$ である。

- 実部 $`\sigma_0`$（虚軸からの距離）: 包絡線 $`e^{\sigma_0t}`$ の減り方を決める。2 % 整定時間の目安 $`4/(\zeta\omega_\mathrm{n})`$ は $`4/|\sigma_0|`$ である。
- 虚部 $`\omega_0`$（実軸からの距離）: 揺れの周期 $`2\pi/\omega_0`$ とピーク時間 $`t_\mathrm{p} = \pi/\omega_0`$ を決める。
- 負の実軸となす角 $`\psi`$: 行き過ぎ量を決める。4 章 4 節の $`M_\mathrm{p} = e^{-\pi\zeta/\sqrt{1 - \zeta^2}}`$ の指数は、$`\zeta = -\sigma_0/\omega_\mathrm{n}`$、$`\sqrt{1 - \zeta^2} = \omega_0/\omega_\mathrm{n}`$ を入れると $`\pi\sigma_0/\omega_0`$ になるので、$`M_\mathrm{p} = e^{\pi\sigma_0/\omega_0}`$ である。これは、包絡線 $`e^{\sigma_0t}`$ のピーク時間 $`\pi/\omega_0`$ での値で、比 $`\sigma_0/\omega_0 = -1/\tan\psi`$ だけで決まる。
- 原点からの距離 $`\omega_\mathrm{n}`$: 角を保ったまま原点から遠ざけると、同じ形の応答が速く起きる（4 章 1 節の時間の目盛）。

## 4. 安定性 — 極が左半平面にあること

1 章 5 節では、振れが大きくなり続けて目標値に戻らない状態を不安定と呼び、正確な定義をこの節に残した。3 節では、実部が正の極の項は大きくなり続けることを見た。この節で安定を定義し、それが極の位置だけで決まることを示す。

### 有界入力有界出力安定

すべての時刻で、大きさがある一定の値 $`u_\mathrm{max}`$ を越えない信号（$`|u(t)| \le u_\mathrm{max}`$）を**有界**な信号という。有界などんな入力に対しても出力が有界になる対象を**安定**といい、正確には**有界入力有界出力安定**（BIBO 安定。bounded-input bounded-output の頭文字）という。安定でない対象を**不安定**という。

s 平面の、実部が負の部分を**左半平面**、実部が正の部分を**右半平面**という。虚軸の上の点は、どちらにも含めない。

伝達関数が多項式の分数で、プロパーで、分母と分子に共通の因数が無いとき、次のことが成り立つ。

> 安定 ⟺ すべての極が左半平面にある

**方針**: 「すべての極が左半平面にあれば安定」は、出力を畳み込み（5 章 6 節）で書き、入力の大きさの上限 $`u_\mathrm{max}`$ とインパルス応答の絶対値の積分で、出力の大きさを上から押さえて示す。「左半平面に無い極が 1 つでもあれば不安定」は、出力が有界でなくなる有界な入力を 1 つ示す。

**導出**: すべての極の実部が負のとき、畳み込みの式 $`y(t) = \int_0^t g(\tau)u(t - \tau)\,d\tau`$ と $`|u| \le u_\mathrm{max}`$ から

$$
|y(t)| \le \int_0^t |g(\tau)|\,|u(t - \tau)|\,d\tau \le u_\mathrm{max}\int_0^\infty |g(\tau)|\,d\tau
$$

である。3 節の形 $`g(t) = \sum_i A_ie^{p_it}`$ で、$`|e^{p_it}| = e^{(\mathrm{Re}\,p_i)t}`$ なので $`|g(t)| \le \sum_i |A_i|e^{(\mathrm{Re}\,p_i)t}`$ である。$`\mathrm{Re}\,p_i < 0`$ なら $`\int_0^\infty e^{(\mathrm{Re}\,p_i)t}dt = 1/|\mathrm{Re}\,p_i|`$ なので、$`\int_0^\infty |g|\,dt \le \sum_i |A_i|/|\mathrm{Re}\,p_i|`$ は有限であり、$`|y(t)|`$ は $`u_\mathrm{max}`$ にこの有限の値を掛けた値を越えない（重根の項 $`t^ke^{pt}`$ も、$`\int_0^\infty t^ke^{(\mathrm{Re}\,p)t}dt = k!/|\mathrm{Re}\,p|^{k+1}`$ が有限なので同じ。厳密にプロパーでないときは、定数の部分が入力をそのまま通すだけなので、これも有界である）。

左半平面に無い極があるときは、次の 2 つの場合に分ける。

- 実部が正の極 $`p`$ があるとき: 単位ステップ（有界）を入れると、ステップ応答には 3 節の $`(A/p)e^{pt}`$ の項が含まれる。共通の因数を約分してあるので $`A \ne 0`$ で、この項の大きさ $`|A/p|e^{(\mathrm{Re}\,p)t}`$ は限りなく大きくなる。実部が最も大きい極の項が、ほかのどの項よりも速く大きくなるので、和も限りなく大きくなる。
- 実部が 0 の極 $`\pm j\omega_0`$ があるとき: 入力を $`\cos\omega_0t`$（$`\omega_0`$ = 0 なら単位ステップ。どちらも有界）にすると、入力の変換 $`s/(s^2 + \omega_0^2)`$ も同じ $`\pm j\omega_0`$ に根をもつので、$`Y(s) = G(s)U(s)`$ の分母では根が重なる。重根の項は $`te^{\pm j\omega_0t}`$ の形（5 章 4 節）で、振幅が時間に比例して大きくなり続ける ∎

この結果は、零点の位置によらない。また、むだ時間 $`e^{-Ls}`$ が掛かっても、出力が $`L`$ だけ遅れるだけなので、安定かどうかは変わらない（ただし、むだ時間がフィードバックのループの中にあると、ループ全体の伝達関数は多項式の分数にならない。その安定は 9 章で調べる）。離散時間での同じ結果は、[DSP シリーズ 6 章 5 節](../dsp/06_伝達関数_極零点_安定性.md#安定性の定理と導出-この章のクライマックス)にある。

### 安定限界

左半平面に無い極がすべて虚軸の上にあり、しかも重なっていない状態を**安定限界**という。インパルス応答は減りも増えもせず（一定の値か、一定の振幅の揺れ）、自由な動きは続くが大きくはならない。ただし、上の導出のとおり、虚軸の上の極と同じ角周波数の入力で出力が限りなく大きくなるので、定義のうえでは安定ではない（不安定に含める）。パラメータを少しずつ変えて、安定な対象が不安定になるときは、極が左半平面から右半平面へ移る途中で虚軸を横切るので、その瞬間に安定限界を通る。

```fig

```

- 安定（台車とばね・ダンパ。極 $`-1 \pm j4.90`$）: インパルス応答は減り、$`\int_0^\infty |g|\,dt`$ = 0.129 m/N である。導出の式から、1 N 以下のどんな力でも、位置は 12.9 cm を越えない。振幅 1 N・角周波数 5 rad/s の正弦波の力を加え続けても、揺れは 10 cm に落ち着く。
- 安定限界（ダンパを外した台車。極 $`\pm j5`$）: インパルス応答は同じ振幅で揺れ続ける。同じ正弦波の力では、揺れが時間に比例して大きくなり、10 s で約 1 m に達する。原点に極をもつモータの角度も安定限界で、一定の電圧を加え続けると、角度は 1 V あたり 1 秒に 50 rad ずつ増え続ける。角度を決めた値で止めるには、4 章 6 節のように角度を測って電圧を直す必要がある。
- 不安定（倒立振子。極 ±6.77）: どんなに小さな押し方でも、+6.77 の極の項 $`e^{6.77t}`$ が 0.102 s ごとに 2 倍になり、角度は大きくなり続ける（線形化した式が合う範囲を出るまで）。

## 5. 零点の影響 — 行き過ぎと逆応答

3 節で見たとおり、極は応答に現れる項の形を決め、零点は各項の大きさを通して応答を変える。零点を 1 つ加えると応答がどう変わるかを、4 章 6 節のモータの位置の比例制御（$`K_\mathrm{P}`$ = 0.21 V/rad、$`L_\mathrm{a}`$ を無視）で調べる。この伝達関数 $`G_0(s) = 210/(s^2 + 20s + 210)`$ の極は $`-10 \pm j10.49`$、行き過ぎ量は 5.0 % である。極と最終値を変えずに、実数の零点 $`z_1`$（0 でない）を加えた

$$
G(s) = \left(1 - \frac{s}{z_1}\right)G_0(s)
$$

を考える。$`s = z_1`$ で $`G(s)`$ = 0 になり、$`G(0) = G_0(0)`$ = 1 のままである。例えば、偏差に比例した電圧に加えて、目標値の変わる速さに比例した電圧 $`K_\mathrm{f}\dot r`$ も足すと（14 章で扱う目標値のフィードフォワードの一種。$`K_\mathrm{f}`$ は例として置く係数）、目標値から角度までの伝達関数は $`K(K_\mathrm{f}s + K_\mathrm{P})/(Ts^2 + s + KK_\mathrm{P})`$ になり、極を変えずに零点 $`-K_\mathrm{P}/K_\mathrm{f}`$ だけが加わる。

### 応答は、零点の無い応答とその微分の和

**方針**: $`G(s)`$ を、$`G_0(s)`$ と、それに $`s`$ を掛けたものに分ける。$`s`$ を掛けることは、初期値が 0 なら時間の世界で微分することなので（5 章 3 節）、ステップ応答を、零点の無いステップ応答とその微分で表す。

**導出**: 零点の無いときのステップ応答を $`y_0(t)`$ とすると、$`Y_0(s) = G_0(s)/s`$ である。零点のあるときは

$$
Y(s) = \left(1 - \frac{s}{z_1}\right)\frac{G_0(s)}{s} = Y_0(s) - \frac{1}{z_1}\,sY_0(s)
$$

である。$`y_0(0)`$ = 0 なので、微分の公式から $`sY_0(s) = \mathcal{L}[\dot y_0]`$ で、逆ラプラス変換すると

$$
y(t) = y_0(t) - \frac{1}{z_1}\,\dot y_0(t)
$$

となる ∎

$`y_0`$ が上がっていく間は $`\dot y_0 > 0`$ である。

- 零点が左半平面（$`z_1 < 0`$）なら、$`-1/z_1 > 0`$ で、上がっていく間に正の山が足される。速く上がり、行き過ぎが増える。零点が原点に近い（$`|z_1|`$ が小さい）ほど、足される山は大きい。
- 零点が右半平面（$`z_1 > 0`$）なら、山が引かれる。動き始めは $`y_0`$ がまだ小さく $`\dot y_0`$ が大きいので、$`y`$ は初めに負の向きへ動く。
- 零点が極より十分に遠い（$`|z_1|`$ が大きい）と、足し引きされる量は小さく、零点はほとんど効かない。


動き始めの傾きは、初期値の定理（5 章 5 節）で確かめられる。$`\dot y(0^+) = \lim_{s\to\infty}s\{sY(s) - y(0)\} = \lim_{s\to\infty}sG(s) = -\omega_\mathrm{n}^2/z_1`$（$`\omega_\mathrm{n}^2`$ = 210）で、零点が無ければ 0（水平に動き始める）、$`z_1`$ = 10 なら、目標を 1 rad 変えたとき −21 rad/s で、初めは目標と逆の向きへ動く。零点の位置を変えたときの値を並べる（細かい刻み幅で数値計算して求めた）。

零点が、極の原点からの距離（固有角周波数 $`\omega_\mathrm{n}`$ = 14.5 rad/s）より数倍以上遠ければ、効き目は小さい。極と同じ程度の距離まで近づくと、左半平面では行き過ぎが、右半平面では逆向きの動きが大きくなる。

### 逆応答と非最小位相

出力が初めに、やがて向かう向きとは逆の向きへ動いてから向きを変える応答を**逆応答**という。安定で、右半平面に実数の零点を 1 つ（一般に奇数個）もつ対象のステップ応答は、逆応答になることが知られている。上の式と図は、その 1 つの例である。

零点がすべて左半平面にあり、極もすべて左半平面にあって、むだ時間を含まない伝達関数を**最小位相**という。右半平面に零点か極をもつもの、またはむだ時間を含むものを**非最小位相**という。名前は、正弦波を入れたときの出力の遅れ（位相。8 章で定義する）が、同じ大きさの応答をもつ伝達関数の中で、最小位相のものが最も小さいことによる。右半平面の零点とむだ時間は、どちらも入力を変えた直後の出力の反応を遅らせ（初めに逆へ動く、またはしばらく動かない）、制御をどこまで速くできるかの限りを決める（13 章 5 節）。

零点と逆応答は、身近な機器にも現れる。

```fig
e06_zero_example
```

- (a) 左半平面の零点の例: 台車とばね・ダンパの、ばねとダンパの付け根（2 章 2 節の壁）を入力 $`u`$ だけ動かす場合（路面の段差が車体に伝わる場合など）。台車に働く力は $`k(u - y) + c(\dot u - \dot y)`$ なので $`m\ddot y + c\dot y + ky = c\dot u + ku`$ で、$`G(s) = (cs + k)/(ms^2 + cs + k)`$ は零点 $`-k/c`$ = −12.5 をもつ。ダンパが付け根の動きの速さも伝えるので、力で押す場合（零点なし）の 52.7 % より大きく、57.2 % 行き過ぎる。
- (b) 右半平面の零点の例: ボイラのドラム（湯と蒸気をためる胴）の水位。給水を増やすと、冷たい水が入って湯の中の蒸気の泡がつぶれ、水位はいったん下がってから、増えた水の分だけ上がっていく。速く逆向きに効く経路 $`-K_1/(T_1s + 1)`$ と、遅く正しい向きに効く経路（水がたまる積分）$`K_2/s`$ の和で表すと、$`G(s) = \{(K_2T_1 - K_1)s + K_2\}/\{s(T_1s + 1)\}`$ で、$`K_1 > K_2T_1`$ なら零点 $`K_2/(K_1 - K_2T_1)`$ は正になる。例の値（$`K_1`$ = 20 mm/(kg/s)、$`T_1`$ = 10 s、$`K_2`$ = 0.5 (mm/s)/(kg/s)）では零点は +0.033 /s で、給水を 1 kg/s 増やすと、水位は 13.9 s 後に 8.1 mm 下がり、39 s 後に元の高さへ戻ってから上がり続ける。

一般に、速く逆向きに効く経路と、遅く正しい向きに効く経路が並んでいると、右半平面の零点が生まれる。2 章 5 節の倒立振子でも、力から台車の位置までの伝達関数は、分子が $`2s^2 - 65.40`$ で、零点 $`\pm\sqrt{32.70}`$ = ±5.72 の片方が右半平面にある（32.70 は、重力の加速度 9.81 m/s² を振子の長さ 0.3 m で割った値）。倒立振子を立てたまま台車を右へ運ぶには、台車を先に少し左へ動かして振子を右へ傾けなければならない（手のひらに立てたほうきを運ぶときと同じ。立てる方法は 18 章）。

下の図で、零点の位置（つまみか s 平面の ○ のドラッグ）を変えると、零点の無いステップ応答、それに足し引きされる微分の項、その和が表示され、行き過ぎ量・逆へ動く量・動き始めの傾きが読める。

## 6. 支配極と近似

実際の対象には多くの極がある。2 節と 4 節で見たとおり、$`L_\mathrm{a}`$ を含むモータの角速度には 2 つ、その位置の比例制御には 3 つの極がある。3 節の和 $`g(t) = \sum_iA_ie^{p_it}`$ のうち、実部の大きさが大きい極の項は速く消え、虚軸に最も近い極の項が最後まで残る。応答の中で最も長く残り、応答のおおよその形を決める、虚軸に最も近い極（またはその共役な組）を**支配極**という。支配極だけを残した次数の低い伝達関数で、元の伝達関数を近似できる場合がある。

### 遠い極は、小さく速く消える項を足す

台車とばね・ダンパに、力を出す装置（アクチュエータ）の遅れ（時定数 $`1/\omega_\mathrm{a}`$ の一次遅れ。例の値）が加わり、伝達関数が $`G(s) = \omega_\mathrm{a}/\{(s + \omega_\mathrm{a})(s^2 + 2s + 25)\}`$ になったとする。$`\omega_\mathrm{a}/(s + \omega_\mathrm{a})`$ は定常ゲイン 1 なので、最終値は台車だけの 0.04 m/N と同じである。極の組 $`p = -1 + j4.90`$（原点からの距離 5 rad/s）と、遠い極 $`-\omega_\mathrm{a}`$ の項が、$`\omega_\mathrm{a}`$ でどう変わるかを調べる。

**方針**: ステップ応答 $`Y(s) = G(s)/s`$ を部分分数分解し、遠い極 $`-\omega_\mathrm{a}`$ の留数と、極の組の留数を、台車だけのとき（$`\omega_\mathrm{a}/(s + \omega_\mathrm{a})`$ が無いとき）と比べる。

**導出**: 遠い極の留数は

$$
\left[(s + \omega_\mathrm{a})\frac{\omega_\mathrm{a}}{s(s + \omega_\mathrm{a})(s^2 + 2s + 25)}\right]_{s=-\omega_\mathrm{a}} = \frac{\omega_\mathrm{a}}{-\omega_\mathrm{a}(\omega_\mathrm{a}^2 - 2\omega_\mathrm{a} + 25)} = -\frac{1}{\omega_\mathrm{a}^2 - 2\omega_\mathrm{a} + 25}
$$

で、最終値 1/25 との比は $`-25/(\omega_\mathrm{a}^2 - 2\omega_\mathrm{a} + 25)`$ である。$`\omega_\mathrm{a}`$ が 5 rad/s より十分に大きければ、これはおよそ $`-(5/\omega_\mathrm{a})^2`$ で小さい。極の組の留数は、台車だけのときの留数に $`\omega_\mathrm{a}/(p + \omega_\mathrm{a}) = 1/(1 + p/\omega_\mathrm{a})`$ を掛けたものになり、$`|p|/\omega_\mathrm{a}`$ が小さければ 1 に近い ∎

遠い極は、$`|p|/\omega_\mathrm{a}`$ の 2 乗程度の小さな項を足し、その項は時定数 $`1/\omega_\mathrm{a}`$ で速く消える。極の組の項もほとんど変わらない。ただし、$`\omega_\mathrm{a}/(p + \omega_\mathrm{a})`$ の偏角のぶんだけ揺れの位相がずれ、応答は、台車だけの応答をおよそ $`1/\omega_\mathrm{a}`$ だけ遅らせた形になる（$`\omega_\mathrm{a}/(s + \omega_\mathrm{a}) = 1/(1 + s/\omega_\mathrm{a})`$ は、$`|s|`$ が $`\omega_\mathrm{a}`$ より十分小さい所では $`1 - s/\omega_\mathrm{a}`$ に近く、むだ時間 $`1/\omega_\mathrm{a}`$ の $`e^{-s/\omega_\mathrm{a}}`$ も同じ $`1 - s/\omega_\mathrm{a}`$ に近い）。3 章 5 節で、重なった遅れが見かけのむだ時間になったのも、この働きである。

$`\omega_\mathrm{a}`$ = 3 rad/s では、遠いはずの極が極の組（原点から 5 rad/s）より原点に近く、近似は成り立たない。$`\omega_\mathrm{a}`$ = 50 rad/s（極の組の 10 倍）では、差は主に 0.02 s の遅れで、行き過ぎ量はほとんど同じである。減衰比 0.2〜0.7 の極の組で同じ計算をすると、遠い極が原点から 10 倍離れていれば、差の最大は最終値の 4.6〜7.5 % で、行き過ぎ量の差は 0.3 ポイント以下だった。支配極の近似を使うときは、捨てる極が、支配極より原点から十分に遠いことを確かめる。2 章 3 節で $`L_\mathrm{a}`$ を無視したモータの一次の式は、−20.2 の支配極だけを残し、100 倍近く遠い −1980 の極を捨てた近似だった（4 章 3 節）。

### ループの中の遅れを捨てると

4 章 6 節では、モータの位置の比例制御を、$`L_\mathrm{a}`$ を無視した二次遅れの式で設計した。4 節で求めた $`L_\mathrm{a}`$ を含む 3 次の式と比べる。

$`K_\mathrm{P}`$ = 0.21 V/rad では、3 次の式の支配極 $`-10.05 \pm j10.54`$ は二次遅れの極 $`-10 \pm j10.49`$ とほとんど同じで、行き過ぎ量は 5.01 % と 5.00 %、角度の差は 0.0017 rad 以下である。捨てた極 −1980 は、支配極より原点から 136 倍遠い。ところが 10 V/rad では、3 次の式の支配極は $`-7.54 \pm j100.1`$ で、二次遅れの $`-10 \pm j99.5`$ より虚軸に近く、行き過ぎ量は 78.8 %（二次遅れでは 72.9 %）、2 % 整定時間は 0.51 s（0.38 s）と差が開く。40 V/rad では、3 次の式は安定限界で揺れ続けるのに、二次遅れの式は安定と答える。

アクチュエータの遅れを足した台車では、極の組は動かず、項の大きさだけが変わった。フィードバックのループの中にある遅れを捨てると、閉ループの極そのものが動くので、捨てた極が遠くても、支配極の減衰比が小さいときは、近似の誤差が大きくなる。比例ゲインを上げて支配極が原点から遠ざかり、捨てた極との距離の比が 136 倍から 20 倍に縮むと、近似が崩れ始める。ループの中の小さな遅れが安定をどれだけ損なうかは、9 章で位相の遅れとして調べる。

### 極零相殺

零点が極に近いと、その極の留数 $`A_i = [(s - p_i)G(s)]_{s=p_i}`$ には零点の因数 $`(p_i - z_j)`$ が掛かるので、留数は小さくなり、その極の項はほとんど消える。零点と極が一致すると、分母と分子の共通の因数として約分され、その極は伝達関数から消える。これを**極零相殺**という。

```fig
e06_cancel
```

- (a) 遅い極 −1 と速い極 −10 をもち、零点 $`-z`$ を −1 の近くに置いた $`G(s) = 10(s + z)/\{z(s + 1)(s + 10)\}`$（最終値 1）: $`z`$ = 1 では −1 の極が相殺され、$`10/(s + 10)`$ と同じ速い応答（2 % 整定時間 0.39 s）になる。$`z`$ = 1.1 では、−1 の極の項の大きさは最終値の 10 % にすぎないが、時定数 1 s でゆっくり消えるので、2 % 整定時間は 1.62 s と 4 倍に延びる。小さな項でも、遅い極の項は整定時間を延ばす。
- (b) 右半平面の極 +1 を、近くの零点で消そうとした場合: $`G(s) = (s - z)/\{(s - 1)(s + 2)\}`$ で、零点 $`z`$ を極 +1 に合わせたつもりが 1 % ずれて 0.99 になると、ステップ応答の $`e^t`$ の項の大きさは $`(1 - z)/3`$ = 0.0033 しかない。それでも 0.69 s ごとに 2 倍になり、5.7 s で 1 を越え、8 s で約 10 になる。ぴったり一致させても、極が伝達関数から見えなくなるだけで、対象の中の自由な動き（4 章 2 節）には $`e^t`$ の項が残り、初期値やわずかな乱れから大きくなる。右半平面の極は、零点で打ち消して安定にすることはできない。

下の図で、例（遠い極・ループの中の遅れ・極零相殺・右半平面の極の打ち消し損ない）を選び、極や零点をドラッグすると、元の伝達関数のステップ応答と、支配極だけを残した近似（最終値をそろえたもの）、両者の差、捨てた極や打ち消し損なった極の項の大きさが表示される。モータの位置の比例制御では、比例ゲインを動かして、近似が崩れていく様子を確かめられる。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 伝達関数 | 初期値をすべて 0 としたときの、出力と入力のラプラス変換の比 $`G(s) = Y(s)/U(s)`$。微分方程式の $`y^{(i)}`$・$`u^{(i)}`$ を $`s^i`$ に置き換えた多項式の分数で、インパルス応答の変換に等しい。初期値による部分は入力に比例しないので比に入れない |
| 極・零点 | 分母の根 $`p_i`$／分子の根 $`z_i`$。$`|G(s)|`$ は極で限りなく大きく、零点で 0。極は特性根と同じもので、応答の項 $`e^{p_it}`$ の形を決める |
| 次数・プロパー・厳密にプロパー | 分母の次数（極の数。微分方程式の階数）／分子の次数 ≤ 分母の次数／分子の次数 < 分母の次数。実際の対象は厳密にプロパー |
| 極の位置と応答 | 実部が減り方（整定時間の目安 $`4/|\sigma_0|`$）、虚部が揺れの角周波数（ピーク時間 $`\pi/\omega_0`$）、負の実軸となす角が行き過ぎ量 $`e^{\pi\sigma_0/\omega_0}`$、原点からの距離が時間の目盛を決める |
| 安定（有界入力有界出力安定）・不安定 | 有界などんな入力にも出力が有界／そうでないこと。安定 ⟺ すべての極が左半平面（実部が負）にある。零点の位置によらない |
| 左半平面・右半平面・安定限界 | 実部が負／正の部分（虚軸は含まない）／左半平面に無い極がすべて虚軸の上にあり重ならない状態。揺れ続け、同じ角周波数の入力で限りなく大きくなる。モータの位置の比例制御（$`L_\mathrm{a}`$ を含む）は 40 V/rad で安定限界 |
| 逆応答・最小位相・非最小位相 | 初めに逆の向きへ動く応答。右半平面の実数の零点で生じる／極と零点がすべて左半平面にあり、むだ時間を含まない伝達関数／右半平面に零点か極をもつか、むだ時間を含むもの |
| 支配極 | 虚軸に最も近く、項が最も長く残る極。原点から十分に遠い極（10 倍で差は数 %）を捨てて近似できる。ループの中の遅れを捨てると極そのものが動くので注意 |
| 極零相殺 | 近い極と零点で、その極の項が小さくなり、一致すると約分されて消えること。遅い極の小さな項は整定時間を延ばす。右半平面の極は打ち消せない |

次章では、制御対象と制御器をつないだフィードバック系の伝達関数を、ブロック線図の結合から求める。フィードバックをかけると閉ループの極が動くことを、この章の 4・6 節で見た。7 章では、その極を決める式と、目標値に対する偏差・外乱・対象の変化への強さを、伝達関数で計算する。
