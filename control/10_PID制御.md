# 10. PID 制御 — 3 つの動作の役割

> **この章で扱う問い.**
> 1〜9 章では、偏差に比例した操作量を出す比例制御を使ってきた。比例制御は、台車の速度に偏差を残し（3 章 6 節）、測った値が遅れると比例ゲインを上げるほど振動し（1 章 5 節・9 章 6 節）、モータの角度を 0.4 s より速く落ち着かせることもできなかった（4 章 6 節）。7 章 3・4 節では、偏差を時間で積分した値に比例する操作量を足すと、偏差が消えることを見た。この章では、偏差の積分と、偏差の変わる速さを使う 2 つの働きを、比例の働きと並べて調べる。

## 1. P 動作 — 偏差に比例した操作量

1 章 4 節では、偏差に比例した量で操作量を決める比例制御を作った。制御器の中で、偏差 $`e`$ に比例した操作量 $`K_\mathrm{P}e`$ を出す働きを **P 動作** という（P は「比例」を表す proportional の頭文字）。比例制御は、P 動作だけを使う制御である。この章でも、1 章 6 節の例の対象（台車・DC モータ・温度の板）を、前の章と同じ値で使う。制御器のゲインの値は、どれも計算のための例の値である。

P 動作が使うのは、偏差の今の値だけである。偏差の波形からは、ほかにも量を取り出せる。4 章 6 節のモータの角度の比例制御（偏差の波形が見やすいように、比例ゲインを 4 章 6 節の 4 倍の 0.84 V/rad にする）で、目標を 1 rad 変えた後の偏差を例に、ある時刻 $`t_1`$ で取り出せる 3 つの量を並べる。

```fig
e10_views
```

今の値のほかに、時刻 0 から $`t_1`$ までの面積（偏差の積分）と、$`t_1`$ での傾き（偏差の微分）がある。面積は、過去の偏差がどれだけたまったかを表し、傾きは、偏差がこの先どちらへ動くかを表す。この章では、面積に比例した操作量を出す働き（2 節の I 動作。I は「積分」の integral）と、傾きに比例した操作量を出す働き（3 節の D 動作。D は「微分」の derivative）を、P 動作に足していく。その前に、P 動作だけでは何が足りないかを、前の章の例でまとめる。

### 今の偏差だけで決めることの限界

```fig
e10_p_limits
```

図の 4 つの例には、2 種類の限界が現れている。1 つ目は、(a) と (d) の、偏差が残ることである。

**方針**: 落ち着いた状態で、操作量がある一定の値を出し続けなければならない場合を考える（台車なら抵抗に打ち勝つ力、負荷のかかったモータなら負荷を支える電圧）。その値を P 動作の式に入れて、偏差を求める。

**導出**: 落ち着いた後に出し続ける必要のある操作量を $`u_\infty`$ とする。P 動作だけなら $`u = K_\mathrm{P}e`$ なので、落ち着いた後の偏差 $`e_\infty`$ は $`u_\infty = K_\mathrm{P}e_\infty`$ を満たし、$`e_\infty = u_\infty/K_\mathrm{P}`$ である。$`u_\infty`$ が 0 でなければ、$`K_\mathrm{P}`$ をどれだけ大きくしても $`e_\infty`$ は 0 にならない ∎

(a) の台車では、0.8 m/s で走り続けるのに抵抗と釣り合う 1.6 N が要るので、$`K_\mathrm{P}`$ = 8 N/(m/s) なら 1.6 ÷ 8 = 0.2 m/s の偏差が残る（7 章 3 節）。(d) のモータでは、負荷トルク 0.01 N·m を支える電圧 1 V が要るので、$`K_\mathrm{P}`$ = 0.21 V/rad なら 1 ÷ 0.21 = 4.76 rad ずれる（7 章 4 節）。

2 つ目は、(b) と (c) の、比例ゲインを上げると揺れることである。(b) のモータの角度の閉ループは $`T\ddot\theta_\mathrm{m} + \dot\theta_\mathrm{m} + KK_\mathrm{P}\theta_\mathrm{m} = KK_\mathrm{P}r`$（4 章 6 節。$`T`$ = 0.05 s、$`K`$ = 50 (rad/s)/V）で、$`K_\mathrm{P}`$ は $`\theta_\mathrm{m}`$ の係数、つまり台車のばねにあたる係数だけを大きくし、$`\dot\theta_\mathrm{m}`$ の係数（減衰にあたる係数）は 1 のまま変えない。ばねだけを強くした台車と同じで、速く揺れるようになるが、揺れの減り方は速くならない。極の実部は −10 のままで、2 % 整定時間は 0.4 s 前後から縮まない。(c) の台車は、測った速度が遅れて届くので、比例ゲインを上げると、遅れた値に強く応えて行き過ぎる（9 章 6 節）。

P 動作だけでは、偏差が残ることと、強くすると揺れることの両方を、1 つの比例ゲインで釣り合わせるしかない。2 節の I 動作は 1 つ目の限界に、3 節の D 動作は 2 つ目の限界に答える。

## 2. I 動作 — 偏差をためて定常偏差を消す

偏差を時刻 0 から積分した値に比例する操作量を出す働きを **I 動作** という。

$$
u_\mathrm{I}(t) = K_\mathrm{I}\int_0^t e(\tau)\,d\tau
$$

係数 $`K_\mathrm{I}`$ を **積分ゲイン** という。単位は「操作量の単位 ÷（偏差の単位 × s）」で、台車の速度では N/((m/s)·s) = N/m、モータの角度では V/(rad·s) である。P 動作と I 動作を足した $`u = K_\mathrm{P}e + K_\mathrm{I}\int e\,dt`$ を PI 制御と呼ぶ。伝達関数は $`C(s) = K_\mathrm{P} + K_\mathrm{I}/s`$ で、7 章 3・4 節で偏差を消すのに使った制御器である。

### 偏差が 0 になる理由

**方針**: 閉ループが安定で、目標値と外乱が一定なら、十分に時間がたつと、ループの中の信号はすべて一定の値に落ち着く。I の分も一定になることを、I の分の変わる速さで書く。

**導出**: $`u_\mathrm{I}`$ を時間で微分すると、積分の上端の微分なので $`\dot u_\mathrm{I}(t) = K_\mathrm{I}e(t)`$ である。落ち着いた後は $`u_\mathrm{I}`$ が一定なので $`\dot u_\mathrm{I}`$ = 0 で、$`K_\mathrm{I} \ne 0`$ なので $`e`$ = 0 である ∎

この導出は、制御対象の式も、外乱の大きさも使っていない。落ち着いた後に要る操作量 $`u_\infty`$ がいくらであっても、I の分がそれを出し続け、P の分 $`K_\mathrm{P}e`$ は 0 になる。1 章では台車に「決めた力」$`u_0 = cr`$ を前もって計算して足したが、I 動作は、その値を偏差から自動で探し当て、坂などで要る力が変わっても探し直す。伝達関数で見ると、制御器の $`1/s`$ で一巡伝達関数の原点の極が 1 つ増え、制御系の型が 1 つ上がる（7 章 3 節）。積分が制御器の側にあるので、操作量に入る外乱によるずれも消える（7 章 4 節）。決めた力を足さずに台車の速度を PI 制御し、途中で上り坂に入る場合を示す。

```fig

```

$`K_\mathrm{I}`$ = 25 N/m は、7 章 3 節で使った値である。偏差が残っている間 I の分が増え続け、平らな道では 2 N、坂では 2.51 N（抵抗 2 N と坂の力 0.513 N の和）に届いたところで、P の分が 0 のまま台車を押し続ける。

### 遅れて効く — 行き過ぎと振動

図の (b) の 0.33 s で、速度は初めて 1 m/s に届き、偏差は 0 になる。ところがこのとき I の分は、それまでの偏差をためて 2.57 N になっていて、要る 2 N を越えている。台車はまだ加速し、1.042 m/s まで行き過ぎる。I の分は、偏差が負になって初めて減り始める。I 動作は過去の偏差の積み重ねで動くので、偏差が 0 になってもすぐには止まらない。I 動作を強くすると、これがどう変わるかを、閉ループの極で調べる。

**方針**: 台車の速度 $`P(s) = K/(Ts + 1)`$（$`K`$ = 0.5 (m/s)/N、$`T`$ = 0.5 s）と $`C(s) = K_\mathrm{P} + K_\mathrm{I}/s`$ から、閉ループの特性方程式 $`1 + P(s)C(s) = 0`$ を作り、2 つの極の和と積を係数から読む。

**導出**: $`1 + P(s)C(s) = 0`$ の分母を払うと $`(Ts + 1)s + K(K_\mathrm{P}s + K_\mathrm{I}) = 0`$、つまり $`Ts^2 + (1 + KK_\mathrm{P})s + KK_\mathrm{I} = 0`$ である。例の値を入れて 2 倍すると

$$
s^2 + (2 + K_\mathrm{P})s + K_\mathrm{I} = 0
$$

となる。2 次方程式の根の和は $`s`$ の係数の符号を変えたもの、積は定数の項なので、2 つの極の和は $`-(2 + K_\mathrm{P})`$、積は $`K_\mathrm{I}`$ である。極が共役な複素数の組なら、実部はどちらも $`-(2 + K_\mathrm{P})/2`$ で、原点からの距離は $`\sqrt{K_\mathrm{I}}`$ である ∎

$`K_\mathrm{P}`$ = 8 N/(m/s) では、実部は $`K_\mathrm{I}`$ によらず −5 である。比例だけのときの閉ループの極は 1 つで −10（3 章 6 節。$`(Ts + 1) + KK_\mathrm{P} = 0`$ の根）だったので、I 動作を足すと、極が 1 つ増えて、虚軸に近づく。$`K_\mathrm{I}`$ = 25 N/m では極は −5 に重なり（減衰比 1）、$`K_\mathrm{I}`$ を上げると、極は実部 −5 のまま上下に離れて、減衰比が下がる。さらに、目標値から速度までの伝達関数 $`K(K_\mathrm{P}s + K_\mathrm{I})/\{Ts^2 + (1 + KK_\mathrm{P})s + KK_\mathrm{I}\}`$ には零点 $`-K_\mathrm{I}/K_\mathrm{P}`$ があり、6 章 5 節のとおり行き過ぎを増やす。極が重なる $`K_\mathrm{I}`$ = 25 N/m でも 4.2 % 行き過ぎるのは、零点 −3.125 のためである。

### 周波数で見る — 低い角周波数のゲインと位相の遅れ

PI の制御器に $`s = j\omega`$ を入れると $`C(j\omega) = K_\mathrm{P} + K_\mathrm{I}/(j\omega) = K_\mathrm{P} - jK_\mathrm{I}/\omega`$ で、ゲインは $`\sqrt{K_\mathrm{P}^2 + (K_\mathrm{I}/\omega)^2}`$、位相は $`-\arctan\{K_\mathrm{I}/(K_\mathrm{P}\omega)\}`$ である。$`\omega`$ が $`K_\mathrm{I}/K_\mathrm{P}`$ より十分に低ければ、ゲインは $`K_\mathrm{I}/\omega`$ に近づき（−20 dB/dec の漸近線）、位相は −90° に近づく。十分に高ければ、ゲインは $`K_\mathrm{P}`$、位相は 0° に近づく。

```fig
e10_pi_bode
```

一巡伝達関数で見ると、I 動作は低い角周波数のゲインを限りなく大きくする。ゆっくり変わる外乱や目標値の変化に対しては、ループのゲインが限りなく大きいので、偏差が残らない。その代わりに、ゲインが 1 になるゲイン交差角周波数のあたりで位相を遅らせ、位相余裕（9 章 5 節）を減らす。台車の速度では、比例だけの 104.5° が、$`K_\mathrm{I}`$ = 25 N/m で 82.9°、100 N/m で 52.6° になる。時間の世界で見た「遅れて効くので行き過ぎる」ことを、周波数の世界では「位相が遅れるので余裕が減る」と読む。

## 3. D 動作 — 変化を先読みして振動を抑える

偏差の変わる速さ $`\dot e = de/dt`$ に比例した操作量を出す働きを **D 動作** という。

$$
u_\mathrm{D}(t) = K_\mathrm{D}\,\frac{de}{dt}
$$

係数 $`K_\mathrm{D}`$ を **微分ゲイン** という。単位は「操作量の単位 ÷（偏差の単位 / s）」で、モータの角度では V/(rad/s) = V·s/rad である。偏差が一定なら D の分は 0 なので、D 動作だけでは偏差を消せない。D 動作は P 動作と組み合わせて使う。P 動作と D 動作を足したものを PD 制御と呼ぶ。

### 少し先の偏差を予想する

P の分と D の分の和は $`K_\mathrm{P}e + K_\mathrm{D}\dot e = K_\mathrm{P}\{e + (K_\mathrm{D}/K_\mathrm{P})\dot e\}`$ と書ける。偏差を時刻 $`t`$ のまわりで 1 次まで展開すると $`e(t + \Delta) \approx e(t) + \Delta\,\dot e(t)`$ なので、波かっこの中は、今の点で引いた接線で予想した、$`K_\mathrm{D}/K_\mathrm{P}`$ 先の偏差である。PD 制御は、今の偏差ではなく、少し先の偏差に比例ゲインを掛けて操作量を決める。

```fig
e10_d_predict
```

モータの角度の PD 制御（$`K_\mathrm{P}`$ = 0.84 V/rad、$`K_\mathrm{D}`$ = 0.02 V·s/rad。この値の選び方は次の小節）では、$`K_\mathrm{D}/K_\mathrm{P}`$ = 0.0238 s で、0.04 s の時点の接線から予想した 0.0238 s 後の偏差 0.300 rad は、本当の値 0.323 rad に近い。角度が目標へ速く近づく間は、偏差が速く減っていく（$`\dot e < 0`$）ので、D の分は負になり、偏差が 0 になる前に電圧の合計を負にしてブレーキをかける（0.075 s、偏差はまだ 0.21 rad）。比例だけでは、偏差が 0 になるまで加速する電圧を出し続けるので、大きく行き過ぎる。

### 目標値を段差で変えるとき

目標値を段差で変えると、偏差もその瞬間に段差で跳ぶ。段差の変わる速さは限りなく大きいので、偏差をそのまま微分すると、操作量に限りなく大きな一瞬の山が出る（実際の大きさと避け方は 6 節）。この章では、5 節までの計算とデモで、目標値が段差で変わる瞬間には微分を効かせず、測った制御量の変わる速さに微分を掛ける。目標値が一定の間は $`e = r - y`$ から $`\dot e = -\dot y`$ なので、D 動作の働きは変わらない。

### 減衰を増やす — モータの角度

4 章 6 節では、比例制御だけではモータの角度を 0.4 s より速く落ち着かせられないことを見た。D 動作を足すと、閉ループの式のどの係数が変わるかを調べる。

**方針**: 4 章 6 節のモータの角度の式 $`T\ddot\theta_\mathrm{m} + \dot\theta_\mathrm{m} = Kv`$（$`T`$ = 0.05 s、$`K`$ = 50 (rad/s)/V）に、P の分と D の分の和の電圧を入れ、二次遅れの標準形（4 章 1 節）と比べる。

**導出**: 目標値 $`r`$ が一定の間は $`\dot e = -\dot\theta_\mathrm{m}`$ なので、電圧は $`v = K_\mathrm{P}(r - \theta_\mathrm{m}) - K_\mathrm{D}\dot\theta_\mathrm{m}`$ である。これを入れて $`\theta_\mathrm{m}`$ と $`\dot\theta_\mathrm{m}`$ の項を左辺に集めると

$$
T\ddot\theta_\mathrm{m} + (1 + KK_\mathrm{D})\,\dot\theta_\mathrm{m} + KK_\mathrm{P}\,\theta_\mathrm{m} = KK_\mathrm{P}\,r
$$

となる。4 章 1 節の $`a_2 = T`$、$`a_1 = 1 + KK_\mathrm{D}`$、$`a_0 = b_0 = KK_\mathrm{P}`$ として

$$
\omega_\mathrm{n} = \sqrt{\frac{KK_\mathrm{P}}{T}}, \qquad \zeta = \frac{1 + KK_\mathrm{D}}{2\sqrt{KK_\mathrm{P}T}}, \qquad -\zeta\omega_\mathrm{n} = -\frac{1 + KK_\mathrm{D}}{2T}
$$

である（3 つ目は極の実部）∎

$`K_\mathrm{D}`$ は $`\dot\theta_\mathrm{m}`$ の係数、つまり減衰にあたる係数だけを増やす。比例制御のとき 1 だったこの係数は、2 章 3 節の逆起電力が角速度に比例してトルクを減らすことから来ていた。D 動作は、目標値が一定の間は $`-K_\mathrm{D}\dot\theta_\mathrm{m} = -K_\mathrm{D}\omega_\mathrm{m}`$、つまり角速度に比例した電圧を引くので、逆起電力をもう 1 つ足したのと同じ働きをする。$`K_\mathrm{D} = 1/K`$ = 0.02 V·s/rad にすると係数は 2 になり、極の実部は −10 から −20 へ動く。そのうえで、減衰比を 4 章 6 節と同じ 0.690（行き過ぎ量 5 %）にそろえるには、$`\zeta = 2/(2\sqrt{2.5K_\mathrm{P}})`$ = 0.690 から $`K_\mathrm{P}`$ = 0.84 V/rad とする。極は $`-20 \pm j21.0`$、固有角周波数は 29.0 rad/s である。

### ノイズを大きくする

D 動作は、偏差の変わる速さに比例するので、測った値の小さく速い揺れも大きく通す。角度の読みに、標準偏差 $`\sigma`$ = 0.002 rad の観測ノイズが混じり（例の値）、1 ms ごとに測る場合を考える。マイコンは、微分を、今の読みと 1 回前の読みの差を測る間隔 $`\Delta t`$ = 1 ms で割って求める。

**方針**: 読みに混じるノイズの値 $`n_k`$（$`k`$ 回目）が、回ごとに独立で、標準偏差が $`\sigma`$ だとする。P の分と D の分に現れる揺れの標準偏差を、ノイズの式から求める。

**導出**: P の分のノイズは $`K_\mathrm{P}n_k`$ なので、標準偏差は $`K_\mathrm{P}\sigma`$ である。D の分のノイズは $`K_\mathrm{D}(n_k - n_{k-1})/\Delta t`$ で、独立な 2 つの値の差の分散は、それぞれの分散の和 $`2\sigma^2`$ である（[統計学シリーズ 6 章 5 節](../stats/06_確率変数と期待値.md#和の分散-最重要)）。したがって標準偏差は $`\sqrt{2}K_\mathrm{D}\sigma/\Delta t`$ で、P の分の $`\sqrt{2}K_\mathrm{D}/(K_\mathrm{P}\Delta t)`$ 倍である ∎

例の値では、P の分の揺れは 0.84 × 0.002 = 0.0017 V、D の分の揺れは 1.414 × 0.02 × 0.002 ÷ 0.001 = 0.057 V で、約 34 倍になる。


正弦波で見ると、D 動作の伝達関数は $`K_\mathrm{D}s`$ で、ゲインは $`K_\mathrm{D}\omega`$ と角周波数に比例して大きくなる（8 章 4 節の微分）。分子の次数が分母より高いのでプロパーでなく、6 章 2 節で見たとおり、速く揺れる入力ほど大きく出力に通す。観測ノイズは、動かしたい制御量の変化より速く揺れることが多い（7 章 6 節）ので、D 動作はノイズを大きくして操作量に出す。操作量が細かく揺れると、モータの電流やヒータの電力が揺れて、音・熱・部品の傷みの元になる。6 節で、この揺れを抑える式を扱う。

## 4. PID の式 — 並列形と標準形

P・I・D の 3 つの動作を足して操作量を決める制御を **PID 制御** という。

$$
u(t) = K_\mathrm{P}\,e(t) + K_\mathrm{I}\int_0^t e(\tau)\,d\tau + K_\mathrm{D}\,\frac{de}{dt}
$$

3 つの動作のゲインを別々に書いたこの形を **並列形** という。同じ制御器を、比例ゲインをくくり出して

$$
u(t) = K_\mathrm{P}\left(e(t) + \frac{1}{T_\mathrm{I}}\int_0^t e(\tau)\,d\tau + T_\mathrm{D}\,\frac{de}{dt}\right)
$$

と書いた形を **標準形** という（4 章 1 節の「二次遅れの標準形」とは別のものである）。$`T_\mathrm{I}`$ [s] を **積分時間**、$`T_\mathrm{D}`$ [s] を **微分時間** という。2 つの形の係数を比べると、$`K_\mathrm{I} = K_\mathrm{P}/T_\mathrm{I}`$、$`K_\mathrm{D} = K_\mathrm{P}T_\mathrm{D}`$ で、逆に $`T_\mathrm{I} = K_\mathrm{P}/K_\mathrm{I}`$、$`T_\mathrm{D} = K_\mathrm{D}/K_\mathrm{P}`$ である。

```fig
e10_forms
```

並列形は、3 つの働きを独立に足したり外したりしやすい（$`K_\mathrm{I}`$ = 0 で I 動作が無くなる）。標準形は、$`K_\mathrm{P}`$ が全体の強さを決め、$`T_\mathrm{I}`$ と $`T_\mathrm{D}`$ が時間の単位をもつので、対象の時定数やむだ時間と比べやすい（例えば温度の板の $`T_\mathrm{I}`$ = 40 s・$`T_\mathrm{D}`$ = 10 s は、むだ時間 20 s の 2 倍と半分で、[電源と周辺の制御シリーズ 14 章 3 節](../periph/14_熱を扱う.md#調整の目安)でジーグラとニコルスの目安から決めた値である。目安の理由は 11 章 2 節で扱う）。標準形で I 動作を外すには、$`T_\mathrm{I}`$ を限りなく大きくする。2 つの時間には、次の意味がある。

```fig
e10_ti_td
```

- 積分時間: 偏差が時刻 0 から 1 で一定なら、P の分は $`K_\mathrm{P}`$、I の分は $`K_\mathrm{P}t/T_\mathrm{I}`$ で、$`t = T_\mathrm{I}`$ で I の分が P の分に追いつく。$`T_\mathrm{I}`$ が短いほど I 動作は強い。
- 微分時間: 偏差が一定の速さ $`\alpha`$ で増える（ランプ入力の形の）とき、P の分は $`K_\mathrm{P}\alpha t`$、D の分は $`K_\mathrm{P}T_\mathrm{D}\alpha`$ で、和は $`K_\mathrm{P}\alpha(t + T_\mathrm{D})`$ である。P の分が $`T_\mathrm{D}`$ 後に出す値を、今出す。3 節の「$`K_\mathrm{D}/K_\mathrm{P}`$ 先の偏差の予想」の $`K_\mathrm{D}/K_\mathrm{P}`$ が、$`T_\mathrm{D}`$ である。

この章の例の値を、2 つの形で並べる。

| 対象と制御器 | $`K_\mathrm{P}`$ | $`K_\mathrm{I}`$ | $`K_\mathrm{D}`$ | $`T_\mathrm{I}`$ | $`T_\mathrm{D}`$ |
|---|---|---|---|---|---|
| 台車の速度、PI（2 節） | 8 N/(m/s) | 25 N/m | — | 0.32 s | — |
| モータの速度、PI（5 節） | 0.1 V/(rad/s) | 2 V/rad | — | 0.05 s | — |
| モータの角度、PD（3 節） | 0.84 V/rad | — | 0.02 V·s/rad | — | 0.0238 s |
| モータの角度、PID（5 節） | 0.84 V/rad | 5 V/(rad·s) | 0.02 V·s/rad | 0.168 s | 0.0238 s |
| 温度の板、PID（5 節） | 24 W/K | 0.6 W/(K·s) | 240 W·s/K | 40 s | 10 s |

### 伝達関数と周波数応答

PID の制御器の伝達関数は、積分が $`1/s`$、微分が $`s`$ を掛けることなので（5 章 3 節）

$$
C(s) = K_\mathrm{P} + \frac{K_\mathrm{I}}{s} + K_\mathrm{D}s = K_\mathrm{P}\,\frac{T_\mathrm{I}T_\mathrm{D}s^2 + T_\mathrm{I}s + 1}{T_\mathrm{I}s}
$$

である。極は原点の 1 つ（I 動作）で、零点は分子の 2 次式の 2 つの根である。分子の次数 2 が分母の次数 1 より高いので、プロパーでない。周波数応答を、実部と虚部に分けて求める。

**方針**: 並列形の $`C(s)`$ に $`s = j\omega`$ を入れ、$`1/j = -j`$ を使って、実部と虚部に分ける。

**導出**: $`C(j\omega) = K_\mathrm{P} + K_\mathrm{I}/(j\omega) + K_\mathrm{D}j\omega = K_\mathrm{P} + j(K_\mathrm{D}\omega - K_\mathrm{I}/\omega)`$ である。実部はどの角周波数でも $`K_\mathrm{P}`$ で、虚部は $`\omega`$ とともに負の大きな値から正の大きな値へ増え、$`K_\mathrm{D}\omega = K_\mathrm{I}/\omega`$、つまり $`\omega_0 = \sqrt{K_\mathrm{I}/K_\mathrm{D}} = 1/\sqrt{T_\mathrm{I}T_\mathrm{D}}`$ で 0 になる。したがってゲイン $`|C(j\omega)| = \sqrt{K_\mathrm{P}^2 + (K_\mathrm{D}\omega - K_\mathrm{I}/\omega)^2}`$ は $`\omega_0`$ で最小の $`K_\mathrm{P}`$ になり、位相 $`\arctan\{(K_\mathrm{D}\omega - K_\mathrm{I}/\omega)/K_\mathrm{P}\}`$ は −90° から +90° へ増えて、$`\omega_0`$ で 0° を通る ∎

```fig
e10_pid_bode
```

ゲインは、低い角周波数では I 動作の $`K_\mathrm{I}/\omega`$（−20 dB/dec）、中ほどでは P 動作の $`K_\mathrm{P}`$、高い角周波数では D 動作の $`K_\mathrm{D}\omega`$（+20 dB/dec）の漸近線にそった谷の形になる。モータの角度の PID では $`\omega_0`$ = 15.8 rad/s で、零点は −7.18 と −34.8（分子 $`0.004s^2 + 0.168s + 1`$ の根）である。$`T_\mathrm{I}`$ が $`T_\mathrm{D}`$ より十分に大きいと、2 つの零点はほぼ $`-1/T_\mathrm{I}`$ と $`-1/T_\mathrm{D}`$ になり、谷の底に P 動作だけが効く平らな区間ができる。$`T_\mathrm{I} \le 4T_\mathrm{D}`$ では分子の判別式 $`T_\mathrm{I}^2 - 4T_\mathrm{I}T_\mathrm{D}`$ が 0 以下になり、零点は重なるか共役な組になる（温度の板の 40 s と 10 s はちょうど $`T_\mathrm{I} = 4T_\mathrm{D}`$ で、零点は −0.05 /s に重なる）。位相は、I 動作が低い角周波数を最大 90° 遅らせ、D 動作が高い角周波数を最大 90° 進める。制御器を進み補償と遅れ補償の組み合わせとして見る見方は、13 章で扱う（[13 章 4 節](13_ループ整形.md#進み遅れ補償と-pid-の関係)）。

## 5. 制御対象ごとの効き方 — 速度・位置・温度

同じ PID でも、どの動作が要るかは制御対象で違う。例の 3 つの対象で、目標値を変えたときと、操作量に入る外乱が加わったときの応答を比べる。どの計算も操作量の上限・下限を考えていない（上限があるときの問題は [11 章 4 節](11_PIDの調整.md#飽和と積分のワインドアップ)）が、例の変化の大きさは、不安定になる例を除いて、操作量が実際に出せる範囲（モータは ±12 V、ヒータは 0〜80 W）に収まるように選んだ。D 動作は 3 節で決めたとおり、測った制御量の変わる速さに掛ける。

### モータの速度 — PI

電圧から角速度までは一次遅れ $`50/(0.05s + 1)`$ である。止まっているモータの目標を 100 rad/s にし、0.3 s に負荷トルク 0.01 N·m（電圧に換算して −1 V。7 章 4 節）を加える。

```fig
e10_cmp_speed
```

- 比例だけ（$`K_\mathrm{P}`$ = 0.1 V/(rad/s)）: 1 節のとおり、100 rad/s 近くで回り続ける電圧を偏差から作るので、偏差 16.7 rad/s が残る（定常偏差 $`100/(1 + 50 \times 0.1)`$）。負荷がかかると、さらに 8.3 rad/s 下がる。偏差を小さくしようと $`K_\mathrm{P}`$ を 0.5 V/(rad/s) に上げると、偏差は 3.8 rad/s に減るが、目標を変えた瞬間の電圧が 50 V になり、電源の 12 V では出せない。
- PI（$`K_\mathrm{I}`$ = 2 V/rad を足す。$`T_\mathrm{I}`$ = 0.05 s）: 偏差は消え、負荷がかかっても、いったん 93.3 rad/s まで下がった後、0.09 s で 100 ± 2 rad/s に戻る。I の分が、100 rad/s を保つ 2 V と、負荷を支える 1 V を出す。$`T_\mathrm{I}`$ をモータの時定数と同じ 0.05 s にすると、制御器の零点 −20 がモータの極 −20 と打ち消し合い（6 章 6 節の極零相殺）、一巡伝達関数は $`100/s`$ になって、目標値への応答は時定数 0.01 s の一次遅れになる。負荷への応答には、打ち消したモータの極が残るので、戻るのにはモータの時定数の数倍かかる。
- D 動作は要らない。一次遅れの対象は、むだ時間が無ければ比例ゲインを上げても揺れないので、D 動作で減衰を増やす必要が無い。比例だけの制御（$`K_\mathrm{P}`$ = 0.1 V/(rad/s)）に D 動作を足すと、モータの式 $`T\dot\omega_\mathrm{m} + \omega_\mathrm{m} = Kv`$（$`T`$ = 0.05 s、$`K`$ = 50 (rad/s)/V）から、閉ループの式は $`(T + KK_\mathrm{D})\dot\omega_\mathrm{m} + (1 + KK_\mathrm{P})\omega_\mathrm{m} = KK_\mathrm{P}r`$ になり、慣性を増やしたのと同じで、遅くなるだけである（$`K_\mathrm{D}`$ = 0.002 V·s/rad で、閉ループの時定数が 0.0083 s から 0.025 s に延びる）。

### モータの角度 — PD と PID

電圧から角度までは、積分を含む $`1000/\{s(s + 20)\}`$ である。目標を 1 rad 変え、1.0 s に負荷トルク 0.01 N·m を加える。

```fig
e10_cmp_pos
```

- 比例だけ（$`K_\mathrm{P}`$ = 0.21 V/rad）: 対象の中の積分のおかげで目標値への偏差は残らないが、負荷トルクを支える 1 V を偏差から作るので、4.76 rad ずれる。
- PD（$`K_\mathrm{P}`$ = 0.84 V/rad、$`K_\mathrm{D}`$ = 0.02 V·s/rad）: 3 節のとおり、行き過ぎ量 5.0 % のまま 2 倍速く落ち着く。$`K_\mathrm{P}`$ が 4 倍なので、負荷のずれも 1/4 の 1.19 rad に減るが、0 にはならない。
- PID（さらに $`K_\mathrm{I}`$ = 5 V/(rad·s)。$`T_\mathrm{I}`$ = 0.168 s）: I の分が負荷を支える 1 V を出し、ずれは 0.56 s で ±0.02 rad に戻る。代わりに、目標値への行き過ぎ量は 30.4 % に増える。2 節で見たとおり、I 動作は極を 1 つ増やし（ここでは −8.87）、目標値から角度までの伝達関数に零点 $`-K_\mathrm{I}/K_\mathrm{P}`$ = −5.95 を加えるからである。6 節で、外乱への応答を変えずに、この行き過ぎを減らす方法を述べる。

角度の制御では、D 動作が速さと行き過ぎを決め、I 動作は負荷のような外乱があるときに要る。負荷が無く、軸を止めておくのに電圧が要らない対象なら、PD で足りる。

### 温度の板 — PI と PID（むだ時間あり）

```fig
e10_cmp_plate
```

- 比例だけ（$`K_\mathrm{P}`$ = 24 W/K）: 60 °C を保つのに要る 28 W（35 K ÷ 1.25 K/W）を偏差から作るので、$`35/(1 + 1.25 \times 24)`$ = 1.13 K 低い 58.87 °C に落ち着き、周りの温度が下がると偏差は 1.45 K に増える。[電源と周辺の制御シリーズ 14 章 3 節](../periph/14_熱を扱う.md#比例だけでは目標に届かない)で、比例だけのときの偏差が 1.13 K になった値と同じである。
- PI: 偏差は消える。ただし、むだ時間があるので、I 動作を強くはできない。PID と同じ 24 W/K・$`T_\mathrm{I}`$ = 40 s の PI では、振れが大きくなり続ける（図の (c)）。12 W/K・$`T_\mathrm{I}`$ = 80 s に弱めると、0.66 K 下がった後、125 s で 60 ± 0.1 °C に戻る。
- PID（24 W/K・40 s・$`T_\mathrm{D}`$ = 10 s）: D 動作が、むだ時間で遅れた分を先読みで補い、同じ 24 W/K・40 s で落ち着く。下がり幅は 0.41 K、戻るまで 52 s で、弱めた PI より小さく速い。一巡伝達関数で見ると、D 動作がゲイン交差角周波数（約 0.06 rad/s）のあたりの位相を進めるので、同じ 24 W/K・40 s の PI では −3.2° と負になる位相余裕が、PID では 33° 残る（弱めた PI は 35°）。

温度の板では、D 動作が強い P 動作と I 動作を使えるようにする。ただし 3 節で見たとおり、D 動作は読みのノイズを大きくする。この例の $`K_\mathrm{D}`$ = 240 W·s/K では、1 s ごとに読む温度の 0.01 K の差が 2.4 W の電力の変化になる。むだ時間が熱時定数よりずっと短いこの板では、弱めた PI で足りることも多い（[電源と周辺の制御シリーズ 14 章 3 節](../periph/14_熱を扱う.md#調整の目安)の「穏やかな値」）。

### どの対象に、どの動作が要るか

| 対象（伝達関数） | P だけのとき | I 動作 | D 動作 | よく使う組み合わせ |
|---|---|---|---|---|
| モータの速度・台車の速度（一次遅れ。型 0） | 偏差が残る（100 rad/s の目標に 16.7 rad/s） | 要る。偏差と外乱のずれを消す | 要らない。遅くするだけ | PI |
| モータの角度（積分＋一次遅れ。型 1） | 目標値への偏差は残らない。負荷で 4.76 rad ずれる。上げると揺れ、0.4 s より速くならない | 負荷のような外乱があれば要る | 要る。減衰を増やし、速く落ち着かせる | PD・PID |
| 温度の板（一次遅れ＋むだ時間） | 偏差が残る（1.13 K）。上げると揺れる | 要る。むだ時間のため強くはできない | 位相を進めて P・I を強くできるが、ノイズを大きくする | PI（PID） |

まとめると、I 動作は「落ち着いた後に一定の操作量が要る」対象と外乱に、D 動作は「ループの遅れのために揺れる」対象に効く。どちらも、効かせすぎると別の問題（I は行き過ぎと振動、D はノイズ）を生む。それぞれをどれだけ強くするかの決め方は、11 章で扱う（[11 章 1 節](11_PIDの調整.md#調整で決めること-速さ-行き過ぎ-外乱-ノイズ)）。

下の図で、対象と制御器の種類を選び、$`K_\mathrm{P}`$・$`T_\mathrm{I}`$・$`T_\mathrm{D}`$ と外乱の有無を変えると、制御量の応答と、操作量を P・I・D の分に分けた波形が表示される。時刻を動かす（「再生」を押す）と、その時刻のモータの軸や板の様子と、P・I・D の分の大きさを並べた棒が表示される。

## 6. 微分の実際 — 不完全微分と測定値の微分

3 節で見たとおり、D 動作には 2 つの問題がある。観測ノイズを大きくすること（伝達関数がプロパーでないこと）と、目標値の段差を微分すると操作量に限りなく大きな山が出ることである。実際の PID は、この 2 つを、微分の式を少し変えて避ける。

### 不完全微分 — 微分を一次遅れで丸める

D 動作の $`K_\mathrm{P}T_\mathrm{D}s`$ に、時定数 $`T_\mathrm{D}/N`$ の一次遅れを掛けた

$$
C_\mathrm{D}(s) = \frac{K_\mathrm{P}T_\mathrm{D}s}{1 + (T_\mathrm{D}/N)s}
$$

を D 動作として使う。これを **不完全微分** という（$`N`$ は正の定数）。分子と分母の次数がどちらも 1 なので、プロパーである。$`N`$ の意味を、伝達関数の形から読む。

**方針**: $`N`$ を含む因数 $`1/\{1 + (T_\mathrm{D}/N)s\}`$ は、折れ点角周波数 $`N/T_\mathrm{D}`$ の一次遅れである（8 章 4 節）。その折れ点より低い角周波数と高い角周波数で、$`C_\mathrm{D}(j\omega)`$ がどうなるかを調べる。段差を入れたときの応答は、出力の変換を 5 章 2 節の表の形に直して求める。

**導出**: $`\omega \ll N/T_\mathrm{D}`$ では $`(T_\mathrm{D}/N)j\omega`$ が 1 より十分に小さいので、$`C_\mathrm{D}(j\omega) \approx K_\mathrm{P}T_\mathrm{D}j\omega`$ で、理想の微分と同じである。$`\omega \gg N/T_\mathrm{D}`$ では分母の 1 を捨てて $`C_\mathrm{D}(j\omega) \approx K_\mathrm{P}T_\mathrm{D}j\omega/\{(T_\mathrm{D}/N)j\omega\} = K_\mathrm{P}N`$ で、ゲインは $`K_\mathrm{P}N`$ で頭打ちになる。高さ 1 の段差（変換 $`1/s`$）を入れると、出力の変換は $`C_\mathrm{D}(s)/s = K_\mathrm{P}T_\mathrm{D}/\{1 + (T_\mathrm{D}/N)s\} = K_\mathrm{P}N/\{s + N/T_\mathrm{D}\}`$ なので、出力は $`K_\mathrm{P}N\,e^{-Nt/T_\mathrm{D}}`$ である（5 章 2 節の $`e^{\lambda t}`$ の変換）。高さ $`K_\mathrm{P}N`$ から時定数 $`T_\mathrm{D}/N`$ で減り、面積は $`K_\mathrm{P}N \times T_\mathrm{D}/N = K_\mathrm{P}T_\mathrm{D}`$ で、理想の微分の限りなく高い山と同じである ∎

```fig

```

$`N`$ は、「微分として働く角周波数の上限 $`N/T_\mathrm{D}`$」と「速い揺れを P の分の何倍まで通すか」を同時に決める。モータの角度（$`T_\mathrm{D}`$ = 0.0238 s）で $`N`$ = 10 なら、420 rad/s までは微分として働き、それより速いノイズは $`K_\mathrm{P}`$ の 10 倍より大きくしない。$`N`$ には 5〜20 程度の値が使われることが多い（目安）。

$`N`$ を小さくすると、ノイズはより小さくなるが、D 動作の先読みが遅れる。モータの角度の PD（3 節の値、1 ms ごとに測り、読みのノイズ 0.002 rad）では、電圧の揺れの標準偏差は、$`N`$ なしの 0.058 V から、$`N`$ = 10 で 0.015 V、$`N`$ = 2 で 0.005 V に減る。このモータでは、ゲイン交差角周波数 29 rad/s が $`N/T_\mathrm{D}`$ より十分に低いので、$`N`$ = 2 まで下げても応答はほとんど変わらない（行き過ぎ量 5.0 % → 1.7 %、位相余裕 69° → 60°）。むだ時間のある温度の板では、事情が違う。


温度の板の PID（24 W/K・40 s・10 s）で、読みに標準偏差 0.05 K のノイズが混じり（例の値）、1 s ごとに読む場合、$`N`$ なしでは電力の揺れの標準偏差が 22 W にもなり、ヒータが出せない負の電力や 80 W を超える電力を求める。$`N`$ = 10 で 8.2 W、$`N`$ = 2 で 3.6 W に減る。一方、位相余裕は $`N`$ なしの 33° から、$`N`$ = 10 で 32°、$`N`$ = 2 で 17°、$`N`$ = 1 で 0.3° に減る。周りの温度が下がった後に ±0.1 K に戻るまでの時間は、$`N`$ なしの 52 s と $`N`$ = 10 の 50 s はほとんど変わらないが、$`N`$ = 2 では 163 s に延び、$`N`$ = 1 では揺れが続く。1 章 6 節で予告した「偏差を小さくすることと、観測ノイズに反応しないことの釣り合い」は、D 動作では $`N`$ の選び方に現れる。

### 測定値の微分 — 目標値の段差を微分しない

目標値を段差で変えると、偏差も段差で跳ぶ。偏差を微分すると、不完全微分でも、D の分は高さ $`K_\mathrm{P}N`$ × 段差の山になる。目標値を段差で変えたときに、D 動作が操作量に出す一瞬の大きな山を **微分キック** という。モータの角度の PID（5 節の値、$`N`$ = 10）で目標を 1 rad 変えると、電圧は 0.84 × 10 × 1 = 8.4 V だけ跳ね、P の分と合わせて 9.2 V になる。温度の板の PID で目標を 2 K 上げると、D の分が 24 × 10 × 2 = 480 W だけ跳ね、P の分 24 × 2 = 48 W と、60 °C を保つのに出していた 28 W と合わせて 556 W を求める。80 W のヒータでは出せない。理想の微分なら山は限りなく高く、刻みごとの差で計算すると、1 ms ごとなら 20.8 V、0.1 ms ごとなら 201 V と、刻みを細かくするほど高くなる。

そこで、D 動作を偏差ではなく、測った制御量 $`y`$ の変わる速さに掛ける。

$$
u(t) = K_\mathrm{P}\,e(t) + K_\mathrm{I}\int_0^t e(\tau)\,d\tau - K_\mathrm{D}\,\frac{dy}{dt}
$$

D 動作を測った制御量だけに掛けるこの方法を **測定値微分** という（微分の動作が、偏差を作る加え合わせ点より前、測った値の側にあるので、**微分先行型** ともいう）。3 節で決めた「段差の瞬間には微分を効かせない」方法は、これである。

**方針**: 偏差の微分と測定値の微分で、閉ループの極（特性方程式）が同じかどうかと、目標値から制御量までの伝達関数がどう違うかを、ブロック線図で調べる。

**導出**: 目標値を 0 にすると、どちらの形も操作量は $`u = -(K_\mathrm{P} + K_\mathrm{I}/s + K_\mathrm{D}s)Y`$ で、一巡伝達関数は同じ $`P(s)C(s)`$ である。したがって特性方程式 $`1 + P(s)C(s) = 0`$ と閉ループの極は同じで、外乱や観測ノイズへの応答も同じである。違うのは目標値の通り道だけで、偏差の微分では目標値に $`C(s) = K_\mathrm{P} + K_\mathrm{I}/s + K_\mathrm{D}s`$ が掛かり、測定値の微分では $`K_\mathrm{P} + K_\mathrm{I}/s`$ だけが掛かる。目標値から制御量までの伝達関数は、前者が $`PC/(1 + PC)`$、後者は $`P(K_\mathrm{P} + K_\mathrm{I}/s)/(1 + PC)`$ で、分子の零点が違う ∎

モータの角度の PID では、偏差の微分の零点は $`C(s)`$ の零点 −7.18 と −34.8、測定値の微分の零点は $`K_\mathrm{P}s + K_\mathrm{I}`$ の根 −5.95 だけである。6 章 5 節のとおり、原点に近い零点ほど行き過ぎを増やすので、$`N`$ = 10 の計算では、行き過ぎ量は偏差の微分で 21.7 %、測定値の微分で 29.3 % になる。測定値の微分は、微分キックを消す代わりに、目標値への応答を少し遅くする。

### 比例の目標値の重み

測定値の微分にしても、P の分 $`K_\mathrm{P}(r - y)`$ は目標値の段差で $`K_\mathrm{P}`$ × 段差だけ跳ね、I 動作で加わった零点が行き過ぎを生む。そこで、P の分の目標値にだけ重み $`b`$（0 から 1 の定数）を掛けて

$$
u(t) = K_\mathrm{P}\{b\,r(t) - y(t)\} + K_\mathrm{I}\int_0^t \{r(\tau) - y(\tau)\}\,d\tau - K_\mathrm{D}\,\frac{dy}{dt}
$$

とする。$`b`$ を **目標値の重み** と呼ぶ。目標値を 0 にしたときの式は変わらないので、測定値の微分と同じ理由で、閉ループの極と外乱への応答は $`b`$ によらない。目標値から制御量までの伝達関数の分子は $`P(bK_\mathrm{P} + K_\mathrm{I}/s)`$ になり、零点は $`-K_\mathrm{I}/(bK_\mathrm{P})`$ と、$`b`$ を小さくするほど原点から遠ざかる。落ち着いた後は I 動作が偏差を 0 にするので、$`b`$ を変えても目標値に届く。

モータの角度の PID（$`N`$ = 10、測定値の微分）では、$`b`$ = 1 で 29.3 %・0.40 s の行き過ぎ量と 2 % 整定時間が、$`b`$ = 0.5 で 0 %・0.34 s、$`b`$ = 0 で 0 %・0.49 s になる。目標を変えた瞬間の電圧の跳びは $`bK_\mathrm{P}`$ × 段差で、0.84 V・0.42 V・0 V である。負荷トルクへの応答は、どの $`b`$ でも同じである。温度の板の PID で目標を 2 K 上げる場合も、$`b`$ = 1 では行き過ぎ 1.73 K で、電力は 100 W を求めるが、$`b`$ = 0.5 では 0.62 K・最大 76 W で、80 W のヒータの範囲に収まる。目標値への応答と外乱への応答を別々に決める考え方は、14 章で一般に扱う（2 自由度制御。[14 章 1 節](14_フィードフォワードとカスケード.md#2-自由度制御-目標値への応答と外乱への応答を分ける)）。

### 1 回ごとの計算 — C のコード

マイコンは、一定の時間 $`\Delta t`$ ごとに制御量を測り、PID の式で操作量を計算して出す。積分と微分を、$`\Delta t`$ ごとの足し算と差に置き換える。考え方は、2 章 6 節で微分方程式を刻み幅 $`\Delta t`$ で数値計算したのと同じである（置き換え方の違いと、$`\Delta t`$ の選び方は 15 章で扱う）。

**方針**: I の分は、$`\Delta t`$ ごとに $`K_\mathrm{I}\Delta t\,e`$ を足す。D の分は、不完全微分の式を微分方程式に戻し、変わる速さを「今の値と 1 回前の値の差 ÷ $`\Delta t`$」で置き換えて、今の D の分について解く。

**導出**: $`C_\mathrm{D}(s)`$ を $`-y`$ に掛ける測定値微分の D の分を $`d`$ とすると、$`\{1 + (T_\mathrm{D}/N)s\}D(s) = -K_\mathrm{P}T_\mathrm{D}sY(s)`$ で、時間の式に戻すと $`(T_\mathrm{D}/N)\dot d + d = -K_\mathrm{P}T_\mathrm{D}\dot y`$ である。$`k`$ 回目の値に添字 $`k`$ を付け、$`\dot d \approx (d_k - d_{k-1})/\Delta t`$、$`\dot y \approx (y_k - y_{k-1})/\Delta t`$ を入れると

$$
\frac{T_\mathrm{D}}{N}\cdot\frac{d_k - d_{k-1}}{\Delta t} + d_k = -K_\mathrm{P}T_\mathrm{D}\,\frac{y_k - y_{k-1}}{\Delta t}
$$

である。両辺に $`N\Delta t`$ を掛けて $`d_k`$ の項を左辺に集めると $`(T_\mathrm{D} + N\Delta t)\,d_k = T_\mathrm{D}d_{k-1} - K_\mathrm{P}T_\mathrm{D}N(y_k - y_{k-1})`$ で、$`a = T_\mathrm{D}/(T_\mathrm{D} + N\Delta t)`$ とおいて両辺を $`T_\mathrm{D} + N\Delta t`$ で割ると

$$
d_k = a\,d_{k-1} - aK_\mathrm{P}N\,(y_k - y_{k-1})
$$

となる ∎

$`a`$ は 0 と 1 の間にあるので、$`\Delta t`$ をどう選んでも $`d_k`$ は発散しない。$`N`$ を限りなく大きくすると $`aN \to T_\mathrm{D}/\Delta t`$ で、$`d_k = -K_\mathrm{P}T_\mathrm{D}(y_k - y_{k-1})/\Delta t`$ と、差で求めた理想の微分になる。次の関数は、目標値の重み・I 動作・測定値の不完全微分を含む PID の 1 回分の計算である（C99）。

```c
typedef struct {
    float kp, ti, td, n, b;  /* K_P、T_I [s]（0 で I なし）、T_D [s]（0 で D なし）、N、目標値の重み b */
    float dt;                /* 呼ぶ間隔 Δt [s] */
    float i, d, y1;          /* I の分、D の分、1 回前の測った値 */
} pid_ctl_t;

/* 制御を始めるときに 1 回呼ぶ。y: そのときの測った値 */
void pid_start(pid_ctl_t *c, float y)
{
    c->i = 0.0f;  c->d = 0.0f;  c->y1 = y;
}

/* Δt ごとに 1 回呼ぶ。r: 目標値、y: 測った値。戻り値: 操作量 */
float pid_step(pid_ctl_t *c, float r, float y)
{
    float p = c->kp * (c->b * r - y);                     /* P の分（目標値の重み b） */
    if (c->td > 0.0f) {                                   /* D の分（測った値の不完全微分） */
        float a = c->td / (c->td + c->n * c->dt);
        c->d = a * c->d - a * c->kp * c->n * (y - c->y1);
    }
    c->y1 = y;
    float u = p + c->i + c->d;
    if (c->ti > 0.0f)                                     /* I の分（次の回のために足す） */
        c->i += c->kp * c->dt / c->ti * (r - y);
    return u;
}

/* 使い方の例（モータの角度、Δt = 1 ms）。read_angle()・set_voltage() は、この章で仮に置く関数 */
static pid_ctl_t pid = { .kp = 0.84f, .ti = 0.168f, .td = 0.0238f, .n = 10.0f, .b = 0.5f, .dt = 0.001f };

void control_tick(float target)            /* 始めに pid_start(&pid, read_angle()) を呼び、その後 1 ms ごとに呼ぶ */
{
    float y = read_angle();                /* 角度を測る [rad] */
    set_voltage(pid_step(&pid, target, y)); /* 電圧を出す [V]（上限の扱いは 11 章 4 節） */
}
```

I の分は、今回の操作量を計算した後に、今回の偏差の分を足す。こうすると、今回の操作量は、前の回までにためた I の分だけを使う。1 ms ごとに呼ぶ周期を守る方法は 16 章 1 節で扱う。

テストでは、ホストのコンピュータで、本文のコードをそのままコンパイルし（`gcc -std=c99`、アドレスと未定義動作の検査付き）、次のことを確かめた。P の分と目標値の重み $`b`$ の値、一定の偏差で I の分が 1 回ごとに $`K_\mathrm{P}\Delta t/T_\mathrm{I}`$ × 偏差ずつ増えること、測った値の段差で D の分が $`-aK_\mathrm{P}N`$ × 段差になり、その後 1 回ごとに $`a`$ 倍に減ること、目標値を段差で変えても D の分が 0 のままであること、$`N`$ を大きくすると差で求めた微分に近づくこと。さらに、モータの角度の模型（電圧を 1 ms の間保って厳密に進める）につないで 1 ms ごとに呼ぶと、PD で行き過ぎ量 4.33 %・2 % 整定時間 0.199 s、PID（$`b`$ = 1）で 29.4 %・0.396 s、$`b`$ = 0.5 で 0 %・0.337 s、負荷トルクでのずれの最大は 1.051 rad だった。連続時間の計算（4.32 %・0.200 s、29.3 %・0.396 s、0 %・0.340 s、1.046 rad）との小さな差は、1 ms ごとに計算した値を次の回まで保つことによる遅れのためで、同じ計算を倍精度で行った結果とは表示の桁まで一致した。

このコードは、電圧やヒータの電力の上限を考えていない。上限に張り付いている間に I の分がたまり続ける問題（ワインドアップ）とその対策は 11 章 4 節で、整数での計算や、呼ぶ周期を守る方法など、マイコンに載せるための書き直しは 15・16 章で扱う（[16 章 2 節](16_マイコンでの実装.md#離散-pid-のコード-位置形と速度形)）。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| P 動作 | 偏差に比例した操作量 $`K_\mathrm{P}e`$。今の偏差だけを見る。落ち着いた後に要る操作量 $`u_\infty`$ の分、$`e_\infty = u_\infty/K_\mathrm{P}`$ の偏差が残る。上げると揺れ、モータの角度では減衰が増えない |
| I 動作・積分ゲイン | 偏差の積分に比例した操作量 $`K_\mathrm{I}\int e\,dt`$／その係数 $`K_\mathrm{I}`$。落ち着けば $`\dot u_\mathrm{I} = K_\mathrm{I}e = 0`$ から偏差は 0。過去の偏差で動くので行き過ぎ、低い角周波数のゲインを上げて位相を最大 90° 遅らせる（台車: 位相余裕 104.5° → 82.9°） |
| D 動作・微分ゲイン | 偏差の変わる速さに比例した操作量 $`K_\mathrm{D}\dot e`$／その係数 $`K_\mathrm{D}`$。$`K_\mathrm{D}/K_\mathrm{P}`$ 先の偏差を予想する。モータの角度で減衰の係数を $`1 + KK_\mathrm{D}`$ にし、2 % 整定時間を 0.414 s から 0.207 s にする。ノイズは $`\sqrt{2}K_\mathrm{D}\sigma/\Delta t`$ に大きくなる |
| PID 制御・並列形・標準形 | 3 つの動作の和で操作量を決める制御／$`K_\mathrm{P}e + K_\mathrm{I}\int e\,dt + K_\mathrm{D}\dot e`$／$`K_\mathrm{P}(e + \int e\,dt/T_\mathrm{I} + T_\mathrm{D}\dot e)`$ |
| 積分時間・微分時間 | $`T_\mathrm{I} = K_\mathrm{P}/K_\mathrm{I}`$: 一定の偏差で I の分が P の分に追いつく時間／$`T_\mathrm{D} = K_\mathrm{D}/K_\mathrm{P}`$: P の分を先取りする時間 |
| 周波数応答 | $`C(j\omega) = K_\mathrm{P} + j(K_\mathrm{D}\omega - K_\mathrm{I}/\omega)`$。ゲインは谷の形で、$`\omega_0 = 1/\sqrt{T_\mathrm{I}T_\mathrm{D}}`$ で最小の $`K_\mathrm{P}`$。位相は −90° から +90° |
| 対象ごとの効き方 | 一次遅れ（速度）は PI、積分を含む角度は PD・PID、むだ時間のある温度は PI（PID）。I は一定の操作量が要るとき、D はループの遅れで揺れるときに効く |
| 不完全微分 | $`K_\mathrm{P}T_\mathrm{D}s/\{1 + (T_\mathrm{D}/N)s\}`$。$`N/T_\mathrm{D}`$ まで微分として働き、速い揺れは $`K_\mathrm{P}N`$ 倍で頭打ち。$`N`$ が小さいほどノイズに強いが、先読みが遅れる（温度の板で位相余裕 33° → $`N`$ = 2 で 17°） |
| 微分キック・測定値微分（微分先行型） | 目標値の段差で D 動作が出す一瞬の大きな山（電圧・電力の合計で、モータ 9.2 V、温度の板 556 W）／D 動作を測った値だけに掛ける方法。閉ループの極は同じで、目標値の通り道の零点だけが変わる |
| 目標値の重み | P の分の目標値に掛ける $`b`$。目標値への跳びと行き過ぎを減らし（モータの PID: 29.3 % → $`b`$ = 0.5 で 0 %）、外乱への応答は変えない |

この章では、PID の 3 つの動作が何をするかを、ゲインの値を与えて調べた。次章では、そのゲインを決める手順（ジーグラ・ニコルスの方法、モデルに基づく調整）と、操作量の上限・手動と自動の切り替えのような、現場で起きる問題を扱う。
