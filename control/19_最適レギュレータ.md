# 19. 最適レギュレータ — 評価関数とリッカチ方程式

> **この章で扱う問い.**
> 18 章では、閉ループの極を望む位置に置く状態フィードバックのゲイン $`F`$ を求めた。極配置は、置いた極に合うゲインを答えるが、極をどこに置けばよいかは答えない。極を左へ遠く置くほど振子は速く立つが、要る力が大きくなり、近くに置くと台車が大きく動いた（18 章 6 節）。この章では、状態の大きさと入力の大きさを 1 つの数にまとめ、その数を最も小さくするゲインを求める。
>
> この章では次の 3 つの問いに答える。
>
> 1. 「状態を速く 0 に戻したい」と「入力を小さくしたい」の釣り合いを、どう 1 つの数で表すのか。その数を最も小さくするゲインは、どう求めるのか。
> 2. 釣り合いを決める重みは、どう選べばよいのか。倒立振子では、18 章の極配置と比べて何が違うのか。
> 3. その数を最も小さくするように決めたゲインには、モデルの誤差に対してどれだけの余裕があるのか。
>
> 答えの道具は、状態と入力の 2 乗に重みを掛けて積分した評価関数、平方完成で導くリッカチ方程式とその解から決まる最適なゲイン、許せる最大値から重みを決めるブライソンの規則、入力の点で切ったループのナイキスト線図である。

## 1. 評価関数 — 状態の大きさと入力の大きさを重みで比べる

18 章 6 節では、倒立振子の 4 つの極を同じ点 $`-\omega_\mathrm{p}`$ に置き、$`\omega_\mathrm{p}`$ を変えて比べた。極を遠くへ置くほど速く立つが、力の上限で飽和しやすく、近くに置くと台車がレールからはみ出しそうになる。どこを選ぶかは、「速く戻したい」と「力を小さくしたい」の釣り合いで決まる。この節では、その釣り合いを 1 つの数で表す。

### 2 乗の面積で測る

まず、状態変数が 1 つの対象で考える。2 章 2 節のばねの無い台車（質量 $`m`$ = 1 kg、減衰係数 $`c`$ = 2 N·s/m）の速度 $`v`$ は $`m\dot v + cv = u`$、つまり

$$
\dot v = -2v + u
$$

に従う（この章の値は、断りが無ければすべて例の値である）。1 m/s で走っている台車を、押す力 $`u`$ [N] で止めることを考える。状態は速度 $`v`$ だけで、状態フィードバック（18 章 1 節）は $`u = -Fv`$（状態フィードバックゲイン $`F`$ [N/(m/s)] は 1 行 1 列の行列、つまり数）である。閉ループは $`\dot v = -(2 + F)v`$ なので、$`v(0)`$ = 1 m/s から放すと、速度は $`v(t) = e^{-(2 + F)t}`$ [m/s]、力は $`u(t) = -Fe^{-(2 + F)t}`$ [N] である。$`F`$ = 0 なら、押さずに摩擦だけで、時定数 0.5 s で止まっていく（3 章 1 節）。$`F`$ を大きくすると速く止まるが、大きな力が要る。

```fig
e19_area
```

図は、$`F`$ = 0・1・8 N/(m/s) のときの速度と力（上の段）と、それぞれの 2 乗（下の段）である。止まるまでの速度の「大きさ」を 1 つの数で表すのに、2 乗の面積 $`\int_0^\infty v^2\,dt`$ を使う。力も同じく $`\int_0^\infty u^2\,dt`$ で表す。

- 2 乗するので、正のずれも負のずれも同じように数える。
- 大きなずれほど重く数える。2 倍のずれは 4 倍に数える。
- 長く続くずれほど大きく数える。一瞬だけの大きなずれより、ゆっくり残るずれの方が大きくなることもある。
- 2 乗の積分は計算しやすく、それを最も小さくするゲインを 2・3 節で式として求められる。

この台車では $`\int_0^\infty v^2\,dt = \int_0^\infty e^{-2(2 + F)t}dt = 1/\{2(2 + F)\}`$、$`\int_0^\infty u^2\,dt = F^2/\{2(2 + F)\}`$ で、$`F`$ = 0・1・8 N/(m/s) では、速度の面積が 0.25・0.167・0.05 m²/s、力の面積が 0・0.167・3.2 N²·s である。$`F`$ を大きくすると速度の面積は減り、力の面積は増える。

### 評価関数と重み

速度の面積と力の面積は単位が違い、片方を減らすと片方が増える。そこで、それぞれに 0 以上の数を掛けて足した

$$
J = \int_0^\infty \left(Qx^2 + Ru^2\right)dt \qquad (1)
$$

で、2 つをまとめて比べる（$`x`$ は状態で、この台車では $`x = v`$）。制御のよしあしを表す 1 つの数を**評価関数**といい、この章の $`J`$ は小さいほどよいと決める。$`Q`$ と $`R`$ を**重み**という。$`Q`$ を大きくするほど状態のずれを嫌い、$`R`$ を大きくするほど大きな入力を嫌う。$`J`$ は、2 章 3 節のモータの慣性モーメント $`J`$ とは別のものであり、$`R`$ はモータの巻線の抵抗 $`R_\mathrm{a}`$ とは別のものである。$`R`$ は正にする。0 では、どんな大きな入力も許すことになるからである。

状態変数が $`n`$ 個のときは、状態ベクトル $`x`$（17 章 1 節）の要素どうしの積に重みを掛けて足す。$`n`$ 行 $`n`$ 列の行列 $`Q`$ の ($`i`$, $`j`$) 要素を $`q_{ij}`$ として

$$
J = \int_0^\infty \left(x^\mathsf{T}Qx + Ru^2\right)dt, \qquad x^\mathsf{T}Qx = \sum_{i=1}^n\sum_{j=1}^n q_{ij}\,x_ix_j
$$

と書く（$`^\mathsf{T}`$ は 17 章 2 節の転置で、$`x^\mathsf{T}`$ は $`x`$ を横に並べた 1 行 $`n`$ 列の行列）。$`x^\mathsf{T}Qx`$ は、行列の掛け算 $`x^\mathsf{T}(Qx)`$ を計算した 1 行 1 列の行列、つまり数である。$`Q`$ を状態の**重み行列**という（入力が複数のときは、入力のベクトル $`u`$ にも $`u^\mathsf{T}Ru`$ の重み行列 $`R`$ を使う。この章の例は、入力が 1 つで、$`R`$ は数である）。

```fig
e19_quad
```

- $`Q`$ が対角の行列なら、$`x^\mathsf{T}Qx = q_{11}x_1^2 + \cdots + q_{nn}x_n^2`$ で、状態変数ごとの 2 乗に重みを掛けて足したものである。この章の例は、すべて対角の $`Q`$ を使う。
- 対角の外の $`q_{12}x_1x_2`$ と $`q_{21}x_2x_1`$ は同じ積を数えるので、$`q_{ij} = q_{ji}`$（転置しても変わらない、対称な行列）にそろえる。
- 状態がどんな値でも $`x^\mathsf{T}Qx \ge 0`$ になるように選ぶ。負になる向きがあると、その向きのずれが大きいほど $`J`$ が小さくなってしまう。対角の $`Q`$ なら、要素がすべて 0 以上であればよい。0 の要素は、その状態変数の大きさを評価しないことを表す。

図の (b) のとおり、台車とばね・ダンパの状態 $`(p, \dot p)`$ で $`x^\mathsf{T}Qx`$ が 1 になる点を結ぶと、楕円になる。$`q_{11}`$ を 4 倍にすると、位置の向きの幅が半分になり、半分のずれで同じ大きさに数えられる。対角の外の要素は、楕円を斜めに傾ける。

状態方程式 $`\dot x = Ax + Bu`$ と初めの状態 $`x(0)`$ が決まると、入力 $`u(t)`$ の決め方ごとに $`J`$ の値が 1 つ決まる。線形の状態方程式の対象で、2 乗の評価関数を最も小さくする入力を求め、それで状態を 0 へ戻す制御を、**最適レギュレータ**（**LQR**。linear quadratic regulator の略）という。レギュレータは、状態を決まった値（ここでは 0）に保つ制御のことである。2・3 節で、$`J`$ を最も小さくする入力が、状態フィードバック $`u = -Fx`$ の形になることを示す。

### 重みが釣り合いの点を選ぶ

```fig
e19_tradeoff
```

図は、台車で $`F`$ を 0 から大きくしていったときの、速度の面積（横軸）と力の面積（縦軸）の組である。$`F`$ を大きくするほど、点は曲線の上を左上へ進む。重みを決めると、$`J = Q\int v^2\,dt + R\int u^2\,dt`$ が同じ値になる組は、傾き $`-Q/R`$ の直線の上に並び、$`J`$ が小さいほど直線は左下にある。したがって $`J`$ が最も小さい点は、傾き $`-Q/R`$ の直線を左下から近づけて、曲線に初めて触れる点である。

- $`Q/R`$ = 5 (N/(m/s))² の直線は、$`F`$ = 1 N/(m/s) の点で曲線に触れる。
- $`Q/R`$ = 96 (N/(m/s))² の直線は、$`F`$ = 8 N/(m/s) の点で触れる。状態を重く見るほど、大きなゲインが選ばれる。
- $`Q`$ と $`R`$ を同じ倍率で変えても、直線の傾きは変わらないので、選ばれる $`F`$ も変わらない。$`F`$ を決めるのは比 $`Q/R`$ である。

重みを決めることは、速く止めることと力を小さくすることの釣り合いの点を、この曲線の上に 1 つ選ぶことである。図では、入力を $`u = -Fv`$ の形に限って比べた。2 節では、入力の形を限らずに $`J`$ を最も小さくし、触れる点を式で求める。

## 2. 1 次の系で解く — 最適ゲインの式

状態変数が 1 つの対象

$$
\dot x = ax + bu
$$

（$`a`$・$`b`$ は定数で、$`b \ne 0`$）で、評価関数 (1) を最も小さくする入力を求める。1 節の台車では $`a`$ = −2 /s、$`b`$ = 1 /kg である。入力 $`u(t)`$ は、時間のどんな関数でもよいとする。

**方針**: ある定数 $`X`$ を選び、$`Xx^2`$ を時間で微分した量を被積分関数に足して引く。$`u`$ を含む項を「$`u`$ に何かを足したものの 2 乗」にまとめ（平方完成）、残りの $`x^2`$ の項が消えるように $`X`$ を選ぶ。

**導出**: $`x(t)`$ を、ある入力 $`u(t)`$ を加えたときの状態とする。$`Xx^2`$ を微分すると、状態方程式から $`\dfrac{d}{dt}(Xx^2) = 2Xx\dot x = 2aXx^2 + 2bXxu`$ である。被積分関数にこれを足して引くと

$$
Qx^2 + Ru^2 = -\frac{d}{dt}(Xx^2) + (Q + 2aX)x^2 + Ru^2 + 2bXxu
$$

である。$`F = bX/R`$ とおくと、$`u`$ を含む 2 つの項は $`Ru^2 + 2bXxu = R(u^2 + 2Fxu) = R(u + Fx)^2 - RF^2x^2`$ とまとめられ（$`R(u + Fx)^2 = Ru^2 + 2RFxu + RF^2x^2`$ で、$`RF = bX`$）、$`RF^2 = b^2X^2/R`$ なので

$$
Qx^2 + Ru^2 = -\frac{d}{dt}(Xx^2) + \left(2aX - \frac{b^2}{R}X^2 + Q\right)x^2 + R(u + Fx)^2
$$

となる。ここで $`X`$ を、括弧の中が 0 になる

$$
2aX - \frac{b^2}{R}X^2 + Q = 0 \qquad (2)
$$

の解に選ぶ。両辺を 0 から ∞ まで積分する。1 つ目の項の積分は $`Xx(0)^2 - Xx(\infty)^2`$ で、状態を 0 に戻す入力（$`x(\infty)`$ = 0）だけを考えると $`Xx(0)^2`$ である。したがって

$$
J = Xx(0)^2 + \int_0^\infty R\,(u + Fx)^2\,dt
$$

となる。1 つ目の項は入力によらない。$`R > 0`$ なので 2 つ目の項は 0 以上で、0 になるのは、すべての時刻で $`u = -Fx`$ のときに限る。$`J`$ を最も小さくする入力は $`u = -Fx`$ で、そのときの $`J`$ は $`Xx(0)^2`$ である ∎

(2) は $`X`$ の 2 次方程式で、解の公式から $`X = \dfrac{R}{b^2}\left(a \pm \sqrt{a^2 + b^2Q/R}\right)`$ の 2 つの解がある。$`u = -Fx`$ の閉ループは $`\dot x = (a - bF)x`$ で、極は $`a - bF = a - b^2X/R = \mp\sqrt{a^2 + b^2Q/R}`$ である。導出では $`x(\infty)`$ = 0 を使ったので、閉ループが安定になる + の解を選ぶ（− の解では、極が正になり、状態が増え続けて $`J`$ が限りなく大きくなる）。まとめると、最適なゲインと、そのときの閉ループの極と $`J`$ は

$$
F = \frac{a + \sqrt{a^2 + b^2Q/R}}{b}, \qquad a - bF = -\sqrt{a^2 + \frac{b^2Q}{R}}, \qquad J_\mathrm{min} = \frac{RF}{b}\,x(0)^2
$$

である（$`X = RF/b`$）。$`F`$ と極は比 $`Q/R`$ だけで決まり、1 節の図で読んだことと合う。

台車（$`a`$ = −2 /s、$`b`$ = 1 /kg）では $`F = -2 + \sqrt{4 + Q/R}`$ である。

- $`Q/R`$ = 5 (N/(m/s))² では $`F`$ = 1 N/(m/s)、閉ループの極は −3 /s である。
- $`Q/R`$ = 96 (N/(m/s))² では $`F`$ = 8 N/(m/s)、極は −10 /s で、1 節の図の触れる点と一致する。1 章 4 節の比例制御で台車の速度に使った比例ゲイン $`K_\mathrm{P}`$ = 8 N/(m/s) は、この重みの最適なゲインにあたる（目標の速度 $`r`$ からのずれ $`x = v - r`$ も同じ式 $`\dot x = -2x + u'`$ に従う。$`u'`$ は目標の速度を保つ力 $`cr`$ からの差）。
- $`Q/R`$ を 0 に近づけると $`F`$ は 0、極は −2 /s（押さない台車）に近づく。台車はひとりでに止まるので、力を嫌うなら押さないのがよい。
- $`Q/R`$ が大きいと $`F \approx \sqrt{Q/R}`$ で、$`Q/R`$ を 100 倍にすると、ゲインも極の位置もほぼ 10 倍になる。

```fig
e19_valley
```

図の (a) は、入力を $`u = -Fv`$ の形に限って、$`F`$ を変えたときの $`J`$（$`R`$ = 1 とした値）である。$`J`$ は谷の形をしていて、谷の底は上の式の $`F`$ にあり、底の高さは $`J_\mathrm{min} = RFx(0)^2/b`$（$`Q/R`$ = 5 で 1、96 で 8）と一致する。(b) は $`Q/R`$ = 96 で、$`F`$ を 4 と 16 にしたときの、最適な入力 $`-8v`$ との差の 2 乗 $`R(u + 8v)^2`$ である。その面積 1.33 と 1.78 が、導出の式のとおり、$`J`$ の最小値 8 からの増え分（$`J`$ = 9.33 と 9.78）に一致する。

### 不安定な対象では、極が鏡に映した位置より左へ移る

$`a > 0`$ の対象は、押さなければ状態が $`e^{at}`$ で増えていく。17 章 5 節では、減衰係数を負にした台車の軌跡が外へ広がるのを見た。ここでは、ばねの無い台車の減衰係数を −2 N·s/m にした仮の台車（押さなくても速さが増えていく。$`a`$ = +2 /s）を考える。最適なゲインは $`F = 2 + \sqrt{4 + Q/R}`$ で、閉ループの極は $`-\sqrt{4 + Q/R}`$ である。

- 閉ループの極は $`a^2`$ だけで決まり、$`a`$ の符号によらない。同じ重みなら、$`a`$ = −2 の台車と同じ位置に来る。ゲインは $`2a/b`$ = 4 N/(m/s) だけ大きい。
- $`Q/R`$ を 0 に近づけても、$`F`$ は 4 N/(m/s) より小さくならず、極は −2 /s より右へ行かない。−2 は、対象の極 +2 を虚軸について鏡に映した位置である。状態をほとんど嫌わない重みでも、状態が増え続けると $`J`$ が限りなく大きくなるので、0 へ戻すことはやめられない。
- 力の面積 $`\int u^2\,dt`$ だけを比べると、極を鏡の位置 −2 に置くのが最も小さい。極を −2 より右（遅い側）に置いても、力の面積は増える（図の (c)。極を $`-\sigma`$ に置くと、$`\int u^2\,dt = (2 + \sigma)^2x(0)^2/(2\sigma)`$ で、$`\sigma`$ = 2 で最小）。不安定な対象では、ゆっくり戻すほど力が少なくて済むとは限らない。

## 3. リッカチ方程式と最適ゲイン

状態変数が $`n`$ 個で入力が 1 つの対象 $`\dot x = Ax + Bu`$ と、評価関数 $`J = \int_0^\infty (x^\mathsf{T}Qx + Ru^2)\,dt`$（$`Q`$ は対称で、どんな $`x`$ でも $`x^\mathsf{T}Qx \ge 0`$。$`R > 0`$）で、2 節と同じ道筋をたどる。

**方針**: 2 節の $`Xx^2`$ の代わりに、対称な $`n`$ 行 $`n`$ 列の定数の行列 $`X`$ を使った $`x^\mathsf{T}Xx`$ の微分を足して引き、$`u`$ を含む項を 2 乗にまとめる。行列の積の転置は $`(N_1N_2)^\mathsf{T} = N_2^\mathsf{T}N_1^\mathsf{T}`$（掛ける順番が逆になる）であることと、1 行 1 列の行列（数）は転置しても同じであることを使う。

**導出**: $`x^\mathsf{T}Xx = \sum_i\sum_j X_{ij}x_ix_j`$（$`X_{ij}`$ は $`X`$ の ($`i`$, $`j`$) 要素）の各項を積の微分で微分すると $`X_{ij}(\dot x_ix_j + x_i\dot x_j)`$ なので、$`\dfrac{d}{dt}(x^\mathsf{T}Xx) = \dot x^\mathsf{T}Xx + x^\mathsf{T}X\dot x`$ である。$`\dot x^\mathsf{T}Xx`$ は数なので転置しても同じで、$`(\dot x^\mathsf{T}Xx)^\mathsf{T} = x^\mathsf{T}X^\mathsf{T}\dot x = x^\mathsf{T}X\dot x`$（$`X`$ は対称）である。したがって

$$
\frac{d}{dt}(x^\mathsf{T}Xx) = 2x^\mathsf{T}X\dot x = 2x^\mathsf{T}XAx + 2x^\mathsf{T}XBu
$$

である。同じ理由で $`x^\mathsf{T}XAx = x^\mathsf{T}A^\mathsf{T}Xx`$ なので、$`2x^\mathsf{T}XAx = x^\mathsf{T}(A^\mathsf{T}X + XA)x`$ と書ける。被積分関数にこれを足して引くと

$$
x^\mathsf{T}Qx + Ru^2 = -\frac{d}{dt}(x^\mathsf{T}Xx) + x^\mathsf{T}(A^\mathsf{T}X + XA + Q)x + Ru^2 + 2x^\mathsf{T}XBu
$$

である。1 行 $`n`$ 列の行列 $`F = R^{-1}B^\mathsf{T}X`$（$`R`$ は数なので $`R^{-1} = 1/R`$）をとると、$`Fx = B^\mathsf{T}Xx/R`$ は数で、$`x^\mathsf{T}XB = (B^\mathsf{T}Xx)^\mathsf{T} = RFx`$ である。$`u`$ を含む 2 つの項は、2 節と同じく $`Ru^2 + 2R(Fx)u = R(u + Fx)^2 - R(Fx)^2`$ とまとめられ、$`R(Fx)^2 = R(Fx)^\mathsf{T}(Fx) = x^\mathsf{T}F^\mathsf{T}RFx = x^\mathsf{T}XBR^{-1}B^\mathsf{T}Xx`$（$`F^\mathsf{T} = XBR^{-1}`$）なので

$$
x^\mathsf{T}Qx + Ru^2 = -\frac{d}{dt}(x^\mathsf{T}Xx) + x^\mathsf{T}\left(A^\mathsf{T}X + XA - XBR^{-1}B^\mathsf{T}X + Q\right)x + R(u + Fx)^2
$$

となる。$`X`$ を、括弧の中の行列が 0 になる

$$
A^\mathsf{T}X + XA - XBR^{-1}B^\mathsf{T}X + Q = 0 \qquad (3)
$$

の解に選び、0 から ∞ まで積分すると、状態を 0 に戻す入力について

$$
J = x(0)^\mathsf{T}Xx(0) + \int_0^\infty R\,(u + Fx)^2\,dt
$$

となる。2 つ目の項は 0 以上で、0 になるのはすべての時刻で $`u = -Fx`$ のときに限る ∎

(3) を**リッカチ方程式**という。2 節の (2) は、$`n`$ = 1 のリッカチ方程式（$`A = a`$、$`B = b`$）である。導出から、次のことが分かる。

- $`J`$ を最も小さくする入力は、状態フィードバック $`u = -Fx`$、$`F = R^{-1}B^\mathsf{T}X`$ である。導出では入力の形を何も限っていない。過去の状態や時刻から入力を決めるどんな方法も、この状態フィードバックより $`J`$ を小さくできない。$`J`$ の最小値は $`x(0)^\mathsf{T}Xx(0)`$ である。
- $`F`$ は初めの状態 $`x(0)`$ によらない。どの状態から放しても、同じ $`F`$ が最適である。
- (3) は、$`X`$ の要素についての 2 次の連立方程式で、解はいくつもある。導出は $`x(\infty)`$ = 0 を使ったので、$`A - BF`$ を安定にする解を選ぶ。対象が可制御（18 章 2 節）で、不安定なモードと虚軸の上の固有値のモードがすべて $`x^\mathsf{T}Qx`$ に現れる（そのモードだけで動くと $`x^\mathsf{T}Qx`$ が 0 でない）なら、そのような解はただ 1 つで、対称で、どんな $`x`$ でも $`x^\mathsf{T}Xx \ge 0`$ であることが知られている（証明は省く）。

### 台車とばね・ダンパで解く

## 4. 重みの選び方

最適レギュレータで設計者が決めるのは、重み $`Q`$ と $`R`$ である。3 節の結果から、まず 2 つのことが分かる。

- $`Q`$ と $`R`$ をどちらも同じ数倍しても、$`F`$ は変わらない。例えば 25 倍の重み $`25Q`$・$`25R`$ では、元の解 $`X`$ を 25 倍した $`25X`$ を (3) に入れると、どの項も元の 25 倍になる（$`XBR^{-1}B^\mathsf{T}X`$ の項は 25 × 25 ÷ 25 倍）ので、$`25X`$ が新しい重みの解である。$`F = R^{-1}B^\mathsf{T}X`$ は 25 ÷ 25 = 1 倍で変わらない。効くのは重みの比だけで、$`J`$ の値そのものに意味は無い。
- $`x^\mathsf{T}Qx`$ は、単位の違う量（台車の位置 [m] と振子の角度 [rad] など）の 2 乗を足す。重みは、単位と大きさをそろえる役目ももつ。

### ブライソンの規則

各状態変数と入力に、「普段の動きで、ここまでなら許せる」という最大値 $`x_{i,\mathrm{max}}`$・$`u_\mathrm{max}`$ を決め、重みを

$$
Q = \mathrm{diag}\!\left(\frac{1}{x_{1,\mathrm{max}}^2}, \ldots, \frac{1}{x_{n,\mathrm{max}}^2}\right), \qquad R = \frac{1}{u_\mathrm{max}^2}
$$

とする方法を、**ブライソンの規則**という。$`J`$ の各項は $`(x_i/x_{i,\mathrm{max}})^2`$ と $`(u/u_\mathrm{max})^2`$ になり、どの量も「許せる最大値の何倍か」で数えられる。大きさを問わない状態変数は、重みを 0 にする（最大値を限りなく大きくすることにあたる）。この規則は出発点を与えるもので、得られた $`F`$ で応答を計算し、許せる値を超える量があれば重みを直す。

### 倒立振子の重みを決める

18 章 4 節の倒立振子（状態 $`x = \begin{bmatrix} p & \dot p & \varphi & \dot\varphi \end{bmatrix}^\mathsf{T}`$、17 章 2 節の $`A`$・$`B`$）に使う。許せる最大値を、台車の位置 0.5 m（台車が走れる範囲。例の値）、力 5 N（18 章 4 節の力の上限）、振子の角度 10°（0.1745 rad。最初の案）とし、速度と角速度は評価しない。最初の案の重みは

$$
Q = \mathrm{diag}\!\left(\frac{1}{0.5^2},\ 0,\ \frac{1}{0.1745^2},\ 0\right) = \mathrm{diag}(4,\ 0,\ 32.8,\ 0), \qquad R = \frac{1}{5^2} = 0.04
$$

（単位は 1/m²・1/rad²・1/N²）で、(3) を解くと $`F = \begin{bmatrix} -10.00 & -9.253 & -48.87 & -6.485 \end{bmatrix}`$（単位は 18 章 4 節と同じ N/m、N/(m/s)、N/rad、N/(rad/s)）になる。

18 章 4 節と同じく、10° 傾けて静かに放す試験で確かめる（17 章 2 節の線形でない状態方程式を、4 次のルンゲ・クッタ法、刻み幅 1 ms で解く。刻み幅を 0.25 ms にしても、この章の値は変わらない）。初めの状態は角度だけが 0 でないので、初めの力は $`-f_3\varphi(0)`$ = 48.87 × 0.1745 = 8.53 N で、上限の 5 N を大きく超える。初めの力は角度のゲイン $`f_3`$ で決まり、$`f_3`$ を大きくしているのは角度の重みである。角度を許せる最大値を 30° に広げると $`f_3`$ = −33.40 N/rad で初めの力は 5.83 N、角度を評価しない（重み 0）と $`f_3`$ = −30.19 N/rad で 5.27 N になる。

角度を評価しなくても、振子は立つ。$`J`$ が限りなく大きくならないためには、台車の位置が 0 に戻らなければならない。振子が倒れていくと台車は戻れないので、$`J`$ を最も小さくする入力は、振子も立て直す。式の上では、台車の位置には、振子の傾きのモードも含めてすべてのモードが現れる（17 章 3 節で、力から台車の位置までの伝達関数の極は 0・0・±6.77 のすべてだった）ので、3 節の最後の条件を満たす。

この章では、10° から立て直すときの力が上限に近いことを重く見て、角度を評価しない重みを倒立振子の例とする（20・21 章もこの重みと $`F`$ を使う）。

$$
Q = \mathrm{diag}(4,\ 0,\ 0,\ 0), \qquad R = 0.04, \qquad F = \begin{bmatrix} -10.00 & -6.896 & -30.19 & -4.925 \end{bmatrix}
$$

閉ループの極は $`-6.65 \pm j0.40`$ と $`-2.88 \pm j2.55`$ である。10° から放すと、初めの 5.27 N が最大の力で、振子は −5.3° まで反対側へ行き過ぎてから 1.85 s で ±0.2° に収まり、台車は 13.3 cm まで動いて 1.22 s で ±1 cm に収まる。上限 5 N を超えるのは初めの 5 ms だけで、上限があっても応答はほとんど変わらない。

## 6. 最適レギュレータの安定余裕

ここまでは、モデルが正しいとして設計し、確かめた。実際には、台車を押す力が計算した値と違ったり（モータの力の定数の誤差など）、計算と測定に時間がかかって力が遅れたりする。9 章では、一巡伝達関数のナイキスト線図が −1 の点からどれだけ離れているかで、こうした誤差への余裕を測った。状態フィードバックのループにも、同じ考え方を使う。

### 入力の点でループを切る

```fig
e19_cut
```

図のブロック線図のとおり、状態フィードバックのループを、入力 $`u`$ の所で切る。切った所から入れた信号は、対象を通って状態 $`(sI - A)^{-1}B`$ 倍になり（17 章 3 節。初めの状態を 0 としたラプラス変換）、$`F`$ を掛けられ、加え合わせ点で負の符号を付けて戻ってくる。ループを一周する間に掛かる伝達関数は $`F(sI - A)^{-1}B`$ で、これがこのループの一巡伝達関数（7 章 2 節）である。7 章では、制御器 $`C(s)`$ と制御対象 $`P(s)`$ の積 $`P(s)C(s)`$ が一巡伝達関数だった。ここでは、入力から $`Fx`$ までを 1 つの対象とみて、制御器は 1 と考えればよい。閉ループの極が、この一巡伝達関数で決まることを確かめる。

**方針**: 閉ループの極は $`A - BF`$ の固有値である（18 章 1 節）。固有値の定義 $`(sI - (A - BF))v = 0`$（$`v \ne 0`$）を、$`Fv`$ という 1 つの数についての式に書き直す。$`s`$ は $`A`$ の固有値でないとする。

**導出**: $`s`$ が $`A - BF`$ の固有値で $`v`$ がその固有ベクトルなら、$`(sI - A)v = -BFv`$ である。$`w = Fv`$（数）とおく。$`s`$ は $`A`$ の固有値でないので $`sI - A`$ に逆行列があり、$`v = -(sI - A)^{-1}Bw`$ である。左から $`F`$ を掛けると $`w = -F(sI - A)^{-1}Bw`$、つまり $`\{1 + F(sI - A)^{-1}B\}w = 0`$ である。$`w = 0`$ なら $`(sI - A)v = 0`$ から $`v = 0`$ となって固有ベクトルであることに反するので、$`w \ne 0`$ で、$`1 + F(sI - A)^{-1}B = 0`$ である。逆に $`1 + F(sI - A)^{-1}B = 0`$ なら、$`v = (sI - A)^{-1}B`$（$`B \ne 0`$ なので 0 でない）について $`(sI - A + BF)v = B + BF(sI - A)^{-1}B = B\{1 + F(sI - A)^{-1}B\} = 0`$ で、$`s`$ は $`A - BF`$ の固有値である ∎

閉ループの極は $`1 + F(sI - A)^{-1}B = 0`$ の根で、7 章 2 節の $`1 + P(s)C(s) = 0`$ と同じ形である。したがって、一巡伝達関数の周波数伝達関数 $`F(j\omega I - A)^{-1}B`$ のナイキスト線図と、9 章 4 節のナイキストの安定判別法がそのまま使える。開ループの極は $`A`$ の固有値で、倒立振子では右半平面の +6.77 が 1 つあるので、閉ループが安定なのは、線図とその鏡像が −1 の点を反時計回りに 1 回まわるときである（原点の固有値 0 の 2 つは、9 章 4 節のとおり小さな半円で迂回する）。

### −1 を中心とする円に入らない

最適レギュレータの $`F`$ では、ナイキスト線図に特別な性質がある。

**方針**: リッカチ方程式 (3) に $`-sX + sX`$（= 0）を加えて $`sI - A`$ と $`-sI - A^\mathsf{T}`$ を作り、左から $`B^\mathsf{T}(-sI - A^\mathsf{T})^{-1}`$、右から $`(sI - A)^{-1}B`$ を掛ける。そこに $`s = j\omega`$ を入れ、絶対値の 2 乗の形にする。

**導出**: $`-(-sI - A^\mathsf{T})X - X(sI - A) = sX + A^\mathsf{T}X - sX + XA = A^\mathsf{T}X + XA`$ なので、(3) は

$$
(-sI - A^\mathsf{T})X + X(sI - A) + XBR^{-1}B^\mathsf{T}X = Q
$$

と書ける。入力から各状態変数までの伝達関数を縦に並べた $`G(s) = (sI - A)^{-1}B`$（$`n`$ 行 1 列）を使うと、転置の規則から $`G(-s)^\mathsf{T} = B^\mathsf{T}(-sI - A^\mathsf{T})^{-1}`$ である。上の式に左から $`G(-s)^\mathsf{T}`$、右から $`G(s)`$ を掛けると、$`(-sI - A^\mathsf{T})^{-1}(-sI - A^\mathsf{T})`$ と $`(sI - A)(sI - A)^{-1}`$ は単位行列 $`I`$ になるので

$$
B^\mathsf{T}XG(s) + G(-s)^\mathsf{T}XB + G(-s)^\mathsf{T}XBR^{-1}B^\mathsf{T}XG(s) = G(-s)^\mathsf{T}QG(s)
$$

である。$`B^\mathsf{T}X = RF`$、$`XB = F^\mathsf{T}R`$ を入れる。$`FG(s) = F(sI - A)^{-1}B`$ は数（一巡伝達関数）で、$`G(-s)^\mathsf{T}F^\mathsf{T} = \{FG(-s)\}^\mathsf{T} = FG(-s)`$ なので、左辺は $`RFG(s) + RFG(-s) + RFG(-s)FG(s)`$ になる。両辺に $`R`$ を足して左辺をまとめると

$$
R\{1 + FG(-s)\}\{1 + FG(s)\} = R + G(-s)^\mathsf{T}QG(s)
$$

となる。$`s = j\omega`$ とおく。$`A`$・$`B`$・$`F`$ は実数なので、$`FG(-j\omega)`$ と $`G(-j\omega)`$ は $`FG(j\omega)`$ と $`G(j\omega)`$ の共役な複素数である。$`G(j\omega) = G_\mathrm{r} + jG_\mathrm{i}`$（$`G_\mathrm{r}`$・$`G_\mathrm{i}`$ は実数のベクトル）と書くと、右辺の第 2 項は $`(G_\mathrm{r} - jG_\mathrm{i})^\mathsf{T}Q(G_\mathrm{r} + jG_\mathrm{i}) = G_\mathrm{r}^\mathsf{T}QG_\mathrm{r} + G_\mathrm{i}^\mathsf{T}QG_\mathrm{i}`$（$`Q`$ は対称なので $`G_\mathrm{r}^\mathsf{T}QG_\mathrm{i} = G_\mathrm{i}^\mathsf{T}QG_\mathrm{r}`$ で、$`j`$ の付いた 2 つの項は打ち消し合う）で、$`x^\mathsf{T}Qx \ge 0`$ から 0 以上である。左辺は、共役な複素数どうしの積なので $`R|1 + FG(j\omega)|^2`$ である。$`R > 0`$ で割って

$$
|1 + F(j\omega I - A)^{-1}B| \ge 1
$$

がすべての $`\omega`$ で成り立つ ∎

$`|1 + F(j\omega I - A)^{-1}B|`$ は、ナイキスト線図の点と −1 の点の距離である。最適レギュレータのナイキスト線図は、−1 を中心とする半径 1 の円の中に入らない。重み $`Q`$・$`R`$ をどう選んでも、これは変わらない。

```fig
e19_disk
```

図を使って、この性質から余裕を読む。線図が −1 の点を回る回数は、点を動かしても、点が線図を横切らない限り変わらない（9 章 4 節の偏角の原理で、回る回数が変わるのは、点が線図の上を通るときだけである）。

- 台車を押す力が、計算した値の $`k`$ 倍（$`k > 0`$。この節だけで使う倍率の記号で、台車のばね定数とは別のもの）になると、一巡伝達関数は $`k`$ 倍になる。$`kF(j\omega I - A)^{-1}B = -1`$ は $`F(j\omega I - A)^{-1}B = -1/k`$ と同じなので、$`k`$ 倍した線図が −1 を回る回数は、元の線図が $`-1/k`$ を回る回数と同じである。$`k > 1/2`$ なら $`-1/k`$ は −2 と 0 の間にあり、円の中にある。線図は円に入らないので、$`-1/k`$ を回る回数は −1 を回る回数と同じで、閉ループは安定なままである。力が 1/2 倍より大きければ、何倍になっても安定である。
- 位相余裕は、ゲイン交差角周波数での位相が −180° より何度進んでいるかだった（9 章 5 節）。ゲイン交差角周波数では、ゲインが 1 なので、線図の点は単位円（原点を中心とする半径 1 の円）の上にある。単位円と −1 を中心とする円は $`-1/2 \pm j\sqrt{3}/2`$（−1 を原点のまわりに ±60° 回した点）で交わり、単位円のうち −1 から ±60° より内側の弧は円の中にある。線図はそこに来られないので、単位円を横切る点の位相は、−180° から 60° 以上離れている。したがって、位相余裕は 60° 以上である。

```fig
e19_nyq
```

倒立振子の例では、線図は負の実軸を、位相交差角周波数 $`\omega_\mathrm{pc}`$ = 4.87 rad/s で −2.21 の所で横切る。力が 1/2.21 = 0.452 倍より小さくなると、この点が −1 より右へ来て不安定になり、0.452 倍から上なら何倍でも安定である。9 章 5 節のゲイン余裕は、ゲインを上げる向きの余裕だった。開ループに不安定な極がある倒立振子では、上げる向きには限りが無く、下げる向きに 0.452 倍（−6.9 dB）までの余裕がある。単位円を横切るのは $`\omega_\mathrm{gc}`$ = 17.7 rad/s で、位相余裕は 60.1° である。極配置では、線図が円の中に入ることがある。図の (b) の極配置（2 組の極を $`-3 \pm j3`$ に置いたもの）は、5.14 rad/s で −1 から 0.536 の所を通り、力が 0.639 倍まで下がると不安定になり、位相余裕は 42.5° しかない。18 章 4 節の極配置（−4 を 4 つ）は円にわずかに入り（−1 からの距離は最小 0.909）、力の下限は 0.491 倍、位相余裕は 56.8° である。(c) は、−1 からの距離 $`|1 + F(j\omega I - A)^{-1}B|`$ をデシベルで描いたもので、最適レギュレータはどの角周波数でも 0 dB 以上である。

この余裕は、モデルの $`A`$・$`B`$ に入れた誤差のうち、入力の点での力の大きさと位相のずれについてのものである。ほかの誤差について、次のことに注意する。

- むだ時間は、ゲインを変えずに位相を $`\omega L`$ 遅らせる（9 章 6 節）。許されるむだ時間は位相余裕を $`\omega_\mathrm{gc}`$ で割ったもので、倒立振子の例では 1.049 rad ÷ 17.7 rad/s = 59.2 ms である（線形化した式に遅れを入れた数値計算では 59.3 ms で不安定になる）。速いループほど短くなり、18 章 4 節の極配置（56.8°、14.5 rad/s）の 68.3 ms より短い。60° の保証は、むだ時間の長さを保証しない。
- 保証は、すべての状態を誤差なく、遅れなく測れる場合のものである。測れない状態を推定して使う（20 章）と、この保証は無くなる。推定した状態で使うときは、余裕を改めて確かめる。
- マイコンで、サンプリング周期 $`T_\mathrm{s}`$ ごとに計算して入力を保つと、およそ $`T_\mathrm{s}/2`$ のむだ時間と同じ位相の遅れが加わる（15 章 2 節）。

下の図で、制御器（最適レギュレータの例、位置の重みを変えた最適レギュレータ、極配置）を選び、力の倍率とむだ時間を変えると、入力の点で切った一巡伝達関数のナイキスト線図と −1 を中心とする円、−1 の点を回る回数、振子を 2° 傾けて放したときの動きが表示される。線図が −1 の点を反時計回りに 1 回まわらなくなると、振子が倒れることを確かめられる。

| 安定余裕 | 入力の点で切った一巡伝達関数 $`F(sI - A)^{-1}B`$ について $`\lvert 1 + F(j\omega I - A)^{-1}B \rvert \ge 1`$。力が 1/2 倍から何倍になっても安定、位相余裕 60° 以上。例は 0.452 倍〜、60.1°（17.7 rad/s）、許されるむだ時間 59.2 ms。推定した状態・むだ時間には保証が無い |

次章では、測れるのが台車の位置と振子の角度だけのときに、測れない速度と角速度を、モデルと測った値から推定する方法を扱い、推定した状態とこの章の $`F`$ で倒立振子を立てる。
