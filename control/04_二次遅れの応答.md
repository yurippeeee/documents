# 04. 二次遅れの応答 — 減衰比と固有角周波数

> **この章で扱う問い.**
> 3 章で見た一次遅れの出力は、ステップ入力に対して、落ち着く値を越えずに近づき、その速さは時定数 1 つで決まった。一方、2 章の台車とばね・ダンパは、1 N の力で押し続けると 6.11 cm まで行き過ぎ、約 1.28 s の周期で揺れながら 4 cm に落ち着いた。この揺れは、2 階の微分方程式のどこから生まれるのか。
>
> この章では次の 3 つの問いに答える。
>
> 1. 2 階の微分方程式で表される対象は、どんな条件で振動し、どんな条件で振動しないのか。揺れの速さと減り方は、式のどの係数で決まるのか。
> 2. 応答の速さと行き過ぎを、どんな数値で表すのか。その数値は、式の係数からどう求めるのか。
> 3. フィードバックが 2 階の式を生むのはどんなときか。そのとき、比例ゲインで応答の形はどう変わるのか。
>
> 答えの道具は、式の係数を 2 つにまとめた標準形、指数関数を仮定して得る特性方程式とその根、速さと行き過ぎの指標、そして位置と速度を 1 つの点で表す位相平面である。

## 1. 二次遅れの標準形 — ばね・質量・ダンパから

2 章 2 節の台車の式 $`m\ddot p + c\dot p + kp = u`$ には、質量 $`m`$・減衰係数 $`c`$・ばね定数 $`k`$ の 3 つの係数がある。2 章では、ダンパを外すと揺れが減らず、ダンパを強くすると揺れなくなることを数値計算で見た。この節では式を書き直し、応答の形を決める量を 2 つにまとめる。

### 標準形

台車の式のように、出力 $`y`$ とその 1 階・2 階の微分にそれぞれ定数を掛けて足したものが、入力 $`u`$ の定数倍に等しい式

$$
a_2\ddot y + a_1\dot y + a_0 y = b_0 u
$$

で入力と出力が結ばれる対象を**二次遅れ**という（$`a_2`$ と $`a_0`$ は正とする）。式が 2 階で、出力が入力の変化に遅れてついていくので、こう呼ぶ。どの項も 1 次で係数が一定なので、この式は線形で時不変である（2 章 1 節）。両辺を $`a_2`$ で割り、係数を次の形にそろえたものを、二次遅れの標準形という。

$$
\ddot y + 2\zeta\omega_\mathrm{n}\dot y + \omega_\mathrm{n}^2 y = \omega_\mathrm{n}^2 K u
$$

$`\omega_\mathrm{n}`$ [rad/s] を**固有角周波数**、$`\zeta`$（単位なし）を**減衰比**という。$`K`$ は 3 章の一次遅れと同じく定常ゲインで、入力が一定の値 $`u`$ のまま出力が落ち着いたとき、$`\dot y = \ddot y = 0`$ なので $`y = Ku`$ である。この落ち着く値を、以下、最終値と呼ぶ。元の式の係数から 3 つの量を求める。

**方針**: $`a_2`$ で割った式の係数を、標準形の係数と 1 つずつ比べる。

**導出**: $`a_2`$ で割ると $`\ddot y + (a_1/a_2)\dot y + (a_0/a_2)y = (b_0/a_2)u`$ である。$`y`$ の係数から $`\omega_\mathrm{n}^2 = a_0/a_2`$ で、$`a_2`$ と $`a_0`$ は正なので $`\omega_\mathrm{n} = \sqrt{a_0/a_2}`$ である。$`\dot y`$ の係数から $`2\zeta\omega_\mathrm{n} = a_1/a_2`$ なので、$`\zeta = a_1/(2a_2\omega_\mathrm{n}) = a_1/(2\sqrt{a_0a_2})`$ である。$`u`$ の係数から $`\omega_\mathrm{n}^2K = b_0/a_2`$ なので、$`K = b_0/(a_2\omega_\mathrm{n}^2) = b_0/a_0`$ である ∎

台車では $`a_2 = m`$、$`a_1 = c`$、$`a_0 = k`$、$`b_0 = 1`$ なので

$$
\omega_\mathrm{n} = \sqrt{\frac{k}{m}}, \qquad \zeta = \frac{c}{2\sqrt{mk}}, \qquad K = \frac{1}{k}
$$

である。例の値（$`m`$ = 1 kg、$`c`$ = 2 N·s/m、$`k`$ = 25 N/m）では、$`\omega_\mathrm{n}`$ = 5 rad/s、$`\zeta`$ = 2 ÷ (2 × 5) = 0.2、$`K`$ = 0.04 m/N（4 cm/N）である。1 N で押し続けた台車が 4 cm に落ち着いたのは、$`K`$ × 1 N だからである。$`\zeta`$ の単位は、$`c`$ の N·s/m = kg/s と、$`\sqrt{mk}`$ の $`\sqrt{\text{kg} \times \text{kg/s}^2}`$ = kg/s が打ち消し合って、無くなる。

2 章 3 節の DC モータも、巻線のインダクタンス $`L_\mathrm{a}`$ を含めると二次遅れになる。負荷トルクを 0 とすると、機械の式から $`i = J\dot\omega_\mathrm{m}/K_\mathrm{t}`$（$`K_\mathrm{t}`$ はトルク定数）で、これを電気の式に入れて両辺に $`K_\mathrm{t}`$ を掛けると $`L_\mathrm{a}J\ddot\omega_\mathrm{m} + R_\mathrm{a}J\dot\omega_\mathrm{m} + K_\mathrm{t}^2\omega_\mathrm{m} = K_\mathrm{t}v`$ となる。$`a_2 = L_\mathrm{a}J`$、$`a_1 = R_\mathrm{a}J`$、$`a_0 = K_\mathrm{t}^2`$、$`b_0 = K_\mathrm{t}`$ として上の式に入れると、例の値で $`\omega_\mathrm{n} = K_\mathrm{t}/\sqrt{L_\mathrm{a}J}`$ = 0.02 ÷ (1 × 10⁻⁴) = 200 rad/s、$`\zeta = R_\mathrm{a}J/(2K_\mathrm{t}\sqrt{L_\mathrm{a}J})`$ = 2 × 10⁻⁵ ÷ (4 × 10⁻⁶) = 5、$`K = 1/K_\mathrm{t}`$ = 50 (rad/s)/V で、$`K`$ は 2 章の一次の式の値と同じである。抵抗・コイル・コンデンサを直列にした回路（RLC 回路）のコンデンサの電圧も、同じ形の式になる（[組み込み回路シリーズ 3 章 5 節](../circuit/03_過渡応答とフィルタ.md#rlc-回路と共振)。そこで使う Q 値は $`1/(2\zeta)`$ に当たる）。

### 固有角周波数は時間の目盛、減衰比は形

標準形の 2 つの係数の役割を分ける。

**方針**: 時間を $`1/\omega_\mathrm{n}`$ を単位として測り直し（$`\tau = \omega_\mathrm{n}t`$）、式から $`\omega_\mathrm{n}`$ が消えることを示す。

**導出**: $`y`$ を $`\tau`$ の関数とみて、$`\tau`$ での微分を $`'`$ で表す。$`d\tau/dt = \omega_\mathrm{n}`$ なので、$`\dot y = (dy/d\tau)(d\tau/dt) = \omega_\mathrm{n}y'`$ である。これをもう一度 $`t`$ で微分すると、同じように $`d\tau/dt = \omega_\mathrm{n}`$ が掛かって $`\ddot y = \omega_\mathrm{n}^2 y''`$ である。標準形に入れると $`\omega_\mathrm{n}^2y'' + 2\zeta\omega_\mathrm{n} \cdot \omega_\mathrm{n}y' + \omega_\mathrm{n}^2y = \omega_\mathrm{n}^2Ku`$ で、両辺を $`\omega_\mathrm{n}^2`$ で割って

$$
y'' + 2\zeta y' + y = Ku
$$

となる ∎

この式には $`\zeta`$ と $`K`$ しか無い。同じ形の入力（例えば一定の力で押し続ける）に対する応答は、横軸を $`\omega_\mathrm{n}t`$ にとると、$`\zeta`$ だけで形が決まる。

図の (a) で $`\omega_\mathrm{n}`$ を 2 倍にすると、同じ形の応答が半分の時間で起き、(b) のように横軸を $`\omega_\mathrm{n}t`$ にすると 3 本は重なる。$`\omega_\mathrm{n}`$ は時間の目盛を決め（一次遅れの時定数と同じ役割。3 章 2 節）、$`\zeta`$ は応答の形を決める。$`\zeta`$ = 0 のときは、$`y = A\cos\omega_\mathrm{n}t`$（$`A`$ は定数）が入力の無い式 $`\ddot y + \omega_\mathrm{n}^2 y = 0`$ を満たす（$`\ddot y = -\omega_\mathrm{n}^2A\cos\omega_\mathrm{n}t`$ を入れると確かめられる）。減衰の無い対象は、角周波数 $`\omega_\mathrm{n}`$ で揺れ続ける。2 章 2 節でダンパを外した台車の周期 1.26 s は、$`2\pi/5`$ = 1.257 s である。$`\omega_\mathrm{n}`$ は入力によらず対象の $`m`$ と $`k`$ だけで決まるので、「固有」と呼ぶ。$`\zeta`$ が何に対する比なのかは、2 節で分かる。

## 2. 特性方程式の根 — 振動するかしないか

入力が 0 のときの二次遅れの動き（以下、自由な動き）を求める。3 節で、一定の入力に対する応答も、この動きから組み立てる。

### 指数関数を仮定する

**方針**: 一次遅れでは、出力の落ち着く値からのずれが $`e^{-t/T}`$ の形で縮んだ（3 章 2 節）。指数関数は微分しても自分の定数倍なので、微分を含む式に入れると、すべての項が同じ関数の定数倍になる。そこで $`y = e^{\lambda t}`$（$`\lambda`$ は定数で、複素数でもよい）とおいて入力の無い標準形に入れ、式を満たす $`\lambda`$ を求める。

**導出**: $`\dot y = \lambda e^{\lambda t}`$、$`\ddot y = \lambda^2e^{\lambda t}`$ を $`\ddot y + 2\zeta\omega_\mathrm{n}\dot y + \omega_\mathrm{n}^2y = 0`$ に入れると、$`(\lambda^2 + 2\zeta\omega_\mathrm{n}\lambda + \omega_\mathrm{n}^2)e^{\lambda t} = 0`$ である。$`e^{\lambda t}`$ はどの時刻でも 0 にならないので、

$$
\lambda^2 + 2\zeta\omega_\mathrm{n}\lambda + \omega_\mathrm{n}^2 = 0
$$

を満たす $`\lambda`$ なら、$`y = e^{\lambda t}`$ は解である ∎

この $`\lambda`$ の方程式を、もとの微分方程式の**特性方程式**といい、その根を**特性根**という。特性方程式は、微分方程式の左辺の $`\ddot y`$・$`\dot y`$・$`y`$ を $`\lambda^2`$・$`\lambda`$・1 に置き換えたもので、入力には関係しない。一次遅れ $`T\dot y + y = Ku`$ の特性方程式は $`T\lambda + 1 = 0`$ で、特性根 $`\lambda = -1/T`$ は 3 章の $`e^{-t/T}`$ の指数と一致する。2 次方程式の解の公式から

$$
\lambda = -\zeta\omega_\mathrm{n} \pm \omega_\mathrm{n}\sqrt{\zeta^2 - 1}
$$

である。根号の中の $`\zeta^2 - 1`$ の符号で、根の種類が 3 つに分かれる（$`\zeta`$ は 0 以上とする。負の場合は、この節の後半で扱う）。

### 3 つの場合

$`\zeta > 1`$ の場合、根は異なる 2 つの実数 $`\lambda_1 = -\omega_\mathrm{n}(\zeta - \sqrt{\zeta^2 - 1})`$、$`\lambda_2 = -\omega_\mathrm{n}(\zeta + \sqrt{\zeta^2 - 1})`$ で、$`\sqrt{\zeta^2 - 1} < \zeta`$ なので、どちらも負である。$`e^{\lambda_1t}`$ と $`e^{\lambda_2t}`$ はどちらも解で、式が線形なので、それぞれを定数倍して足した $`y = Ae^{\lambda_1t} + Be^{\lambda_2t}`$（$`A`$・$`B`$ は定数）も解である（2 章 1 節の重ね合わせの原理と同じく、代入すると確かめられる）。2 つの式 $`A + B = y(0)`$、$`\lambda_1A + \lambda_2B = \dot y(0)`$ は $`\lambda_1 \ne \lambda_2`$ なので解け、どんな初期値にも合わせられる。初期値を決めると解は 1 つに決まる（2 章 1 節）ので、これがすべての解である。出力は振動せず、2 つの指数関数の和として 0 に近づく。この場合を**過減衰**という。

$`\zeta = 1`$ の場合、根は重なった 1 つの実数 $`\lambda = -\omega_\mathrm{n}`$ で、$`e^{-\omega_\mathrm{n}t}`$ のほかに $`te^{-\omega_\mathrm{n}t}`$ も解である。$`y = te^{-\omega_\mathrm{n}t}`$ とおくと $`\dot y = (1 - \omega_\mathrm{n}t)e^{-\omega_\mathrm{n}t}`$、$`\ddot y = (\omega_\mathrm{n}^2t - 2\omega_\mathrm{n})e^{-\omega_\mathrm{n}t}`$ で、$`\ddot y + 2\omega_\mathrm{n}\dot y + \omega_\mathrm{n}^2y`$ の $`e^{-\omega_\mathrm{n}t}`$ の係数は $`(\omega_\mathrm{n}^2t - 2\omega_\mathrm{n}) + (2\omega_\mathrm{n} - 2\omega_\mathrm{n}^2t) + \omega_\mathrm{n}^2t = 0`$ となるからである。すべての解は $`y = (A + Bt)e^{-\omega_\mathrm{n}t}`$ で、振動しない。この場合を**臨界減衰**という。

$`0 \le \zeta < 1`$ の場合、$`\sqrt{\zeta^2 - 1} = j\sqrt{1 - \zeta^2}`$ なので、根は共役な 2 つの複素数

$$
\lambda = -\zeta\omega_\mathrm{n} \pm j\omega_\mathrm{d}, \qquad \omega_\mathrm{d} = \omega_\mathrm{n}\sqrt{1 - \zeta^2}
$$

である。オイラーの公式 $`e^{j\theta} = \cos\theta + j\sin\theta`$（[DSP シリーズ 2 章 1 節](../dsp/02_複素指数関数とオイラーの公式.md#オイラーの公式の導出)）から、$`e^{\lambda t} = e^{-\zeta\omega_\mathrm{n}t}(\cos\omega_\mathrm{d}t \pm j\sin\omega_\mathrm{d}t)`$ である。これは複素数の値をとる解だが、式の係数はすべて実数なので、解の実部と虚部はそれぞれ別々に式を満たす（$`y = y_\mathrm{re} + jy_\mathrm{im}`$ を入れると、左辺の実部と虚部がそれぞれ 0 になる）。したがって $`e^{-\zeta\omega_\mathrm{n}t}\cos\omega_\mathrm{d}t`$ と $`e^{-\zeta\omega_\mathrm{n}t}\sin\omega_\mathrm{d}t`$ は実数の解で、すべての解は

$$
y = e^{-\zeta\omega_\mathrm{n}t}(A\cos\omega_\mathrm{d}t + B\sin\omega_\mathrm{d}t)
$$

である。出力は角周波数 $`\omega_\mathrm{d}`$ で揺れながら、振幅が $`e^{-\zeta\omega_\mathrm{n}t}`$ で縮む。$`\omega_\mathrm{d}`$ を**減衰固有角周波数**といい、$`0 < \zeta < 1`$ の場合を**不足減衰**という。$`\zeta`$ = 0 では $`\omega_\mathrm{d} = \omega_\mathrm{n}`$ で、振幅は縮まない（1 節の揺れ続ける場合）。

複素数の根の解 $`e^{\lambda t}`$ は、下の図（例の台車の根 $`\lambda = -1 + j4.90`$）のように、複素平面の上で回りながら原点へ縮む点である。回る速さが虚部 $`\omega_\mathrm{d}`$、縮む速さが実部 $`-\zeta\omega_\mathrm{n}`$ で決まる。共役な根の解は逆向きに回り、2 つを足して 2 で割ると虚部が打ち消し合って、実部の $`e^{-\zeta\omega_\mathrm{n}t}\cos\omega_\mathrm{d}t`$ だけが残る。図の (b) の破線 $`\pm e^{-t}`$ のように、揺れる波形の山と谷の外側に沿って、振幅の変わり方を示す曲線を包絡線と呼ぶ。

### 減衰比の意味

台車では $`\zeta = c/(2\sqrt{mk})`$ なので、振動するかしないかの境目 $`\zeta`$ = 1 は、減衰係数が $`2\sqrt{mk}`$ のときである。例の台車では 2 × √25 = 10 N·s/m で、2 章 2 節の (c) で行き過ぎずに近づいた $`c`$ = 10 N·s/m は、ちょうど臨界減衰だった。$`\zeta`$ は、実際の減衰係数 $`c`$ を、臨界減衰になる減衰係数 $`2\sqrt{mk}`$ で割った比である。これが減衰比という名前の由来である。

### 特性方程式の根の平面

特性根を、横軸に実部、縦軸に虚部をとった複素平面の点で表す。この章では、この平面を特性方程式の根の平面（以下、根の平面）と呼ぶ。6 章では、同じ平面を s 平面と呼び、応答の形を読む中心の道具にする。

**方針**: 複素数の根 $`\lambda = -\zeta\omega_\mathrm{n} \pm j\omega_\mathrm{d}`$ の、原点からの距離と、負の実軸となす角を求める。

**導出**: 距離の 2 乗は $`(\zeta\omega_\mathrm{n})^2 + \omega_\mathrm{d}^2 = \zeta^2\omega_\mathrm{n}^2 + \omega_\mathrm{n}^2(1 - \zeta^2) = \omega_\mathrm{n}^2`$ なので、距離は $`\omega_\mathrm{n}`$ である。負の実軸となす角を $`\psi`$ とすると、$`\cos\psi`$ は実部の大きさ ÷ 距離 $`= \zeta\omega_\mathrm{n}/\omega_\mathrm{n} = \zeta`$ である ∎

$`\zeta`$ が負（台車では $`c`$ が負。外から揺れにエネルギーを注ぎ込むことに当たる）なら、根の実部 $`-\zeta\omega_\mathrm{n}`$ が正になり、振幅 $`e^{-\zeta\omega_\mathrm{n}t}`$ は時間とともに大きくなり続ける。1 章 5 節で見た不安定である。台車のダンパの $`c`$ は負にならないが、フィードバックをかけた系では、ループ全体の特性根の実部が正になることがある。根の実部の符号と安定の関係は、[6 章 4 節](06_伝達関数と極零点.md#安定性-極が左半平面にあること)で一般に示す。下の図では、実部が正の側を薄い赤で塗る。

- $`\omega_\mathrm{n}`$ を一定にして $`\zeta`$ を 0 から 1 へ増やすと、2 つの根は半径 $`\omega_\mathrm{n}`$ の円の上を、虚軸から負の実軸へ動き、$`\zeta`$ = 1 で $`-\omega_\mathrm{n}`$ に重なる。さらに増やすと実軸の上で 2 つに分かれ、一方は 0 へ、もう一方は左の遠くへ動く。
- 実部 $`-\zeta\omega_\mathrm{n}`$ は振幅の縮む速さを、虚部 $`\omega_\mathrm{d}`$ は揺れの角周波数を表す。根が虚軸から左へ離れるほど速く縮み、実軸から離れるほど速く揺れる。

## 3. ステップ応答の形

二次遅れに、時刻 0 から一定の入力を加え続けたときの応答（ステップ応答）を式で求める。入力は単位ステップ（$`t \ge 0`$ で $`u`$ = 1）、初期値は $`y(0) = \dot y(0) = 0`$ とする。出力の最終値は、1 節のとおり $`K`$ である。

**方針**: 最終値からのずれ $`\delta y = y - K`$ に注目する。ずれは入力の無い式を満たすので、2 節の解を、ずれの初期値 $`\delta y(0) = -K`$、$`\delta\dot y(0) = 0`$ に合わせる。

**導出**: $`K`$ は一定なので $`\delta\dot y = \dot y`$、$`\delta\ddot y = \ddot y`$ で、標準形に $`y = K + \delta y`$ と $`u`$ = 1 を入れると $`\delta\ddot y + 2\zeta\omega_\mathrm{n}\delta\dot y + \omega_\mathrm{n}^2(K + \delta y) = \omega_\mathrm{n}^2K`$ となり、$`\omega_\mathrm{n}^2K`$ が両辺で消えて、入力の無い式になる。不足減衰では、2 節から $`\delta y = e^{-\zeta\omega_\mathrm{n}t}(A\cos\omega_\mathrm{d}t + B\sin\omega_\mathrm{d}t)`$ である。$`t`$ = 0 とおくと $`\delta y(0) = A = -K`$ である。微分すると

$$
\delta\dot y = e^{-\zeta\omega_\mathrm{n}t}\left[(\omega_\mathrm{d}B - \zeta\omega_\mathrm{n}A)\cos\omega_\mathrm{d}t - (\zeta\omega_\mathrm{n}B + \omega_\mathrm{d}A)\sin\omega_\mathrm{d}t\right]
$$

なので、$`\delta\dot y(0) = \omega_\mathrm{d}B - \zeta\omega_\mathrm{n}A = 0`$ から $`B = \zeta\omega_\mathrm{n}A/\omega_\mathrm{d} = -K\zeta/\sqrt{1 - \zeta^2}`$ である。$`y = K + \delta y`$ に戻して

$$
y(t) = K\left[1 - e^{-\zeta\omega_\mathrm{n}t}\left(\cos\omega_\mathrm{d}t + \frac{\zeta}{\sqrt{1 - \zeta^2}}\sin\omega_\mathrm{d}t\right)\right]
$$

となる。さらに、2 節の角 $`\psi`$（$`\cos\psi = \zeta`$、$`\sin\psi = \sqrt{1 - \zeta^2}`$）を使うと、かっこの中は $`(\sin\psi\cos\omega_\mathrm{d}t + \cos\psi\sin\omega_\mathrm{d}t)/\sqrt{1 - \zeta^2} = \sin(\omega_\mathrm{d}t + \psi)/\sqrt{1 - \zeta^2}`$ なので

$$
y(t) = K\left[1 - \frac{e^{-\zeta\omega_\mathrm{n}t}}{\sqrt{1 - \zeta^2}}\sin(\omega_\mathrm{d}t + \psi)\right]
$$

とも書ける ∎

$`\sin`$ は −1 と 1 の間にあるので、応答は 2 本の曲線 $`K(1 \pm e^{-\zeta\omega_\mathrm{n}t}/\sqrt{1 - \zeta^2})`$ の間で、上の曲線と下の曲線に交互に触れながら揺れる。この 2 本が、ステップ応答の包絡線である。包絡線と最終値の差は、時定数 $`1/(\zeta\omega_\mathrm{n})`$ の一次遅れと同じ速さで縮む。

```fig
e04_step
```

例の台車（1 N で押す）では $`y`$ = 4 cm × [1 − $`e^{-t}`$(cos 4.90$`t`$ + 0.204 sin 4.90$`t`$)] で、包絡線は 4 × (1 ± 1.02 $`e^{-t}`$) cm、包絡線の時定数は 1 s である。この式の値は、2 章で細かい刻み幅で数値計算した位置と、表示の桁まで一致する。図の (b) のとおり、ステップ応答は、最終値 4 cm から、2 節の「4 cm 引いて離した」自由な動きを引いたもの（自由な動きを上下に裏返して 4 cm 持ち上げたもの）である。

ほかの 2 つの場合も、同じ手順で求まる。臨界減衰では $`\delta y = (A + Bt)e^{-\omega_\mathrm{n}t}`$ に $`\delta y(0) = A = -K`$、$`\delta\dot y(0) = B - \omega_\mathrm{n}A = 0`$ を合わせて $`B = -\omega_\mathrm{n}K`$、過減衰では $`A + B = -K`$、$`\lambda_1A + \lambda_2B = 0`$ を解いて $`A = -K\lambda_2/(\lambda_2 - \lambda_1)`$、$`B = K\lambda_1/(\lambda_2 - \lambda_1)`$ となり、

$$
y = K\left[1 - (1 + \omega_\mathrm{n}t)e^{-\omega_\mathrm{n}t}\right] \ (\zeta = 1), \qquad y = K\left[1 - \frac{\lambda_2e^{\lambda_1t} - \lambda_1e^{\lambda_2t}}{\lambda_2 - \lambda_1}\right] \ (\zeta > 1)
$$

である。1 節のとおり、横軸を $`\omega_\mathrm{n}t`$ にとれば、応答の形は $`\zeta`$ だけで決まる。

```fig

```

- $`\zeta`$ が小さいほど大きく行き過ぎ、長く揺れる。$`\zeta`$ = 0 では 0 と $`2K`$ の間を往復し続ける。
- $`\zeta \ge 1`$ では行き過ぎない。そのうち $`\zeta`$ = 1 が最も速く、最終値の 98 % に届くのは $`\omega_\mathrm{n}t`$ = 5.83 で、$`\zeta`$ = 2 の 14.9 の 4 割である。
- $`\zeta`$ が 0.7 前後では、わずかに行き過ぎる（$`\zeta`$ = 0.7 で 4.6 %）代わりに、臨界減衰より早く最終値に近づく。最終値の 90 % に届くのは $`\omega_\mathrm{n}t`$ = 2.63 で、臨界減衰の 3.89 より早い。

### 過減衰は 2 つの一次遅れの和

過減衰の応答は、2 つの指数関数の和である。$`\zeta`$ が 1 より十分に大きいときの根の大きさを求める。$`\lambda_1 = -\omega_\mathrm{n}(\zeta - \sqrt{\zeta^2 - 1})`$ に $`(\zeta + \sqrt{\zeta^2 - 1})/(\zeta + \sqrt{\zeta^2 - 1})`$（= 1）を掛けると、分子は $`(\zeta - \sqrt{\zeta^2 - 1})(\zeta + \sqrt{\zeta^2 - 1}) = \zeta^2 - (\zeta^2 - 1) = 1`$ になるので、$`\lambda_1 = -\omega_\mathrm{n}/(\zeta + \sqrt{\zeta^2 - 1})`$ である。$`\zeta`$ が大きいと $`\sqrt{\zeta^2 - 1} \approx \zeta`$ なので、$`\lambda_1 \approx -\omega_\mathrm{n}/(2\zeta)`$、$`\lambda_2 \approx -2\zeta\omega_\mathrm{n}`$ で、2 つの根は大きく離れる。

1 節のモータ（$`\zeta`$ = 5、$`\omega_\mathrm{n}`$ = 200 rad/s）では、根は −20.2 と −1980 で、時定数にすると 49.5 ms と 0.505 ms である。12 V を加えたときの角速度は、3 節の過減衰の式で、最終値 $`K`$ を 50 × 12 = 600 rad/s として

$$
\omega_\mathrm{m}(t) = 600 - 606.2\,e^{-20.2t} + 6.19\,e^{-1980t}\ \ \text{[rad/s]}
$$

である。速い項は数 ms で消え、残りは時定数 49.5 ms の一次遅れとほとんど同じである。近似の時定数 $`2\zeta/\omega_\mathrm{n} = R_\mathrm{a}J/K_\mathrm{t}^2`$ = 0.05 s は、2 章 3 節で $`L_\mathrm{a}`$ を無視して導いた一次の式の時定数そのものである。

2 章 3 節で 2 つの式の角速度の差が最大 5.6 rad/s だったのは、この速い項と、遅い根の近似の差である。2 章のデモで $`L_\mathrm{a}`$ を 50 mH にすると角速度が一度行き過ぎたのは、$`\omega_\mathrm{n}`$ = 28.3 rad/s、$`\zeta`$ = 0.71 の不足減衰になるからである。

## 4. 速さと行き過ぎの指標 — 立ち上がり時間・行き過ぎ量・整定時間

制御系に求める性能は、「どれだけ速く目標値に近づくか」「どれだけ行き過ぎてよいか」で書くことが多い。ステップ応答の形を数で表すために、次の指標を決める。どれも、出力が落ち着く値（最終値）を基準にして測る。

- **立ち上がり時間** $`t_\mathrm{r}`$: 出力が最終値の 10 % から 90 % まで上がるのにかかる時間。
- **ピーク時間** $`t_\mathrm{p}`$: 出力が最初の山（最大）に達する時刻。
- **行き過ぎ量** $`M_\mathrm{p}`$: 最初の山が最終値を越えた分の、最終値に対する割合（(最初の山の値 − 最終値) ÷ 最終値 × 100 %）。
- **整定時間**: 出力が最終値の ±何 % かの幅に入り、その後は出なくなる時刻。この章では ±2 % の幅で測った 2 % 整定時間 $`t_{2\%}`$ を使う。

```fig
e04_indices
```

例の台車では、$`t_\mathrm{r}`$ = 0.241 s、$`t_\mathrm{p}`$ = 0.641 s、$`M_\mathrm{p}`$ = 52.7 %、$`t_{2\%}`$ = 3.92 s である（細かい刻み幅のルンゲ・クッタ法で解いた応答から読んだ）。不足減衰の二次遅れでは、このうち $`t_\mathrm{p}`$ と $`M_\mathrm{p}`$ は式で求まる。

### ピーク時間と行き過ぎ量

**方針**: 山では出力の速度が 0 になる。3 節のステップ応答を微分して 0 になる時刻を求め、最初の山の時刻と値を得る。

**導出**: $`\dot y = \delta\dot y`$ なので、3 節の導出の $`\delta\dot y`$ の式に $`A = -K`$、$`B = -K\zeta\omega_\mathrm{n}/\omega_\mathrm{d}`$ を入れると、$`\cos`$ の係数は $`\omega_\mathrm{d}B - \zeta\omega_\mathrm{n}A = -K\zeta\omega_\mathrm{n} + K\zeta\omega_\mathrm{n} = 0`$、$`\sin`$ の係数は $`-(\zeta\omega_\mathrm{n}B + \omega_\mathrm{d}A) = K(\zeta^2\omega_\mathrm{n}^2 + \omega_\mathrm{d}^2)/\omega_\mathrm{d} = K\omega_\mathrm{n}^2/\omega_\mathrm{d}`$ なので、

$$
\dot y(t) = \frac{K\omega_\mathrm{n}^2}{\omega_\mathrm{d}}e^{-\zeta\omega_\mathrm{n}t}\sin\omega_\mathrm{d}t
$$

である。$`\dot y`$ は $`\sin\omega_\mathrm{d}t`$ = 0、つまり $`t = n\pi/\omega_\mathrm{d}`$（$`n`$ = 1, 2, …）で 0 になる。$`0 < t < \pi/\omega_\mathrm{d}`$ では $`\dot y > 0`$、その後しばらくは $`\dot y < 0`$ なので、最初の山は $`t_\mathrm{p} = \pi/\omega_\mathrm{d}`$ である。3 節の式に入れると、$`\cos\pi = -1`$、$`\sin\pi = 0`$ なので $`y(t_\mathrm{p}) = K(1 + e^{-\zeta\omega_\mathrm{n}\pi/\omega_\mathrm{d}})`$ で、

$$
t_\mathrm{p} = \frac{\pi}{\omega_\mathrm{n}\sqrt{1 - \zeta^2}}, \qquad M_\mathrm{p} = e^{-\pi\zeta/\sqrt{1 - \zeta^2}} \times 100\ \%
$$

となる ∎

行き過ぎ量は $`\zeta`$ だけで決まり、$`\omega_\mathrm{n}`$ によらない（1 節のとおり、$`\omega_\mathrm{n}`$ は時間の目盛だけを変える）。例の台車では、$`t_\mathrm{p}`$ = π ÷ 4.90 = 0.641 s、$`M_\mathrm{p}`$ = $`e^{-0.641}`$ = 52.7 % で、最初の山は 4 × 1.527 = 6.11 cm である。2 章 2 節の 6.11 cm（0.64 s）は、この式の値である。山と谷は $`t = n\pi/\omega_\mathrm{d}`$（$`n`$ = 1, 2, …）に交互に現れ、最終値からのずれは 1 つ進むごとに $`M_\mathrm{p}`$ 倍（台車では 0.527 倍）になる。

逆に、許せる行き過ぎ量から $`\zeta`$ を決めるには、$`M_\mathrm{p}`$ の式を $`\zeta`$ について解く。両辺の対数をとると $`\ln(M_\mathrm{p}/100\,\%) = -\pi\zeta/\sqrt{1 - \zeta^2}`$ で、2 乗して分母を払うと $`(1 - \zeta^2)\ln^2(M_\mathrm{p}/100\,\%) = \pi^2\zeta^2`$ である。$`\zeta^2`$ について解き、$`\zeta`$ は正、対数は負であることから

$$
\zeta = \frac{-\ln(M_\mathrm{p}/100\,\%)}{\sqrt{\pi^2 + \ln^2(M_\mathrm{p}/100\,\%)}}
$$

を得る。行き過ぎ量 5 % なら $`-\ln 0.05`$ = 2.996 で、$`\zeta`$ = 2.996 ÷ √(9.870 + 8.974) = 0.690 である。

### 整定時間の目安

**方針**: 応答は包絡線の内側にあるので、包絡線と最終値の差が最終値の 2 % になる時刻を求め、目安とする。

**導出**: 3 節の 2 つ目の式から、$`|y - K| \le Ke^{-\zeta\omega_\mathrm{n}t}/\sqrt{1 - \zeta^2}`$ である。右辺が $`0.02K`$ になる時刻は、$`e^{-\zeta\omega_\mathrm{n}t} = 0.02\sqrt{1 - \zeta^2}`$ の対数をとって $`t = (\ln 50 + \ln(1/\sqrt{1 - \zeta^2}))/(\zeta\omega_\mathrm{n})`$ である。$`\ln 50`$ = 3.91 で、$`\zeta \le 0.7`$ では 2 つ目の対数は 0〜0.34 なので、分子は 3.9〜4.3 になる ∎

そこで、2 % 整定時間の目安として

$$
t_{2\%} \approx \frac{4}{\zeta\omega_\mathrm{n}}
$$

を使う。例の台車では 4 ÷ (0.2 × 5) = 4 s で、実際の 3.92 s に近い。整定時間を決めるのは特性根の実部 $`-\zeta\omega_\mathrm{n}`$、つまり根が虚軸からどれだけ左にあるかである。ただし、これは包絡線から求めた目安で、実際の応答は包絡線より内側を通るので、実際の値とは少し違う（下の表と図）。

### 立ち上がり時間

1 節のとおり、横軸を $`\omega_\mathrm{n}t`$ にとった応答の形は $`\zeta`$ だけで決まるので、$`\omega_\mathrm{n}t_\mathrm{r}`$ も $`\zeta`$ だけで決まる。式の形では求まらないので、数値計算で求めた値（下の表）を使う。$`\zeta`$ が 0.3〜0.8 の範囲では、$`\omega_\mathrm{n}t_\mathrm{r} \approx 0.6 + 2.16\zeta`$ が 6 % 以内で合う（表の値と比べて確かめた）。$`\zeta`$ が同じなら、立ち上がり時間は $`\omega_\mathrm{n}`$ に反比例し、根が原点から離れるほど短い。

## 5. 位相平面 — 位置と速度の軌跡で見る

2 章 2 節で見たとおり、2 階の式の解を 1 本に決めるには、初めの位置と速度の 2 つが要る。ある時刻の位置と速度が分かれば、その後の動きは（入力が決まっていれば）決まる。そこで、位置と速度を 1 つの点で表して、動きを追う。

横軸に出力（台車の位置 $`p`$）、縦軸にその速度（$`\dot p`$）をとった平面を**位相平面**という。各時刻の位置と速度は位相平面の 1 点になり、時間がたつと点が動いて曲線を描く。この曲線を軌跡と呼ぶ。

```fig
e04_phase_time
```

図は、3 節の台車のステップ応答（1 N で押す）を、時間の波形と位相平面に並べたものである。

- 点は原点（止まった台車）から出発し、右上へ動く。速度は 0.28 s に最大の 15.1 cm/s になる。
- 軌跡が横軸（$`\dot p`$ = 0）を横切る所が、波形の山と谷である。0.64 s に 6.11 cm（最初の山）、1.28 s に 2.89 cm（谷）、1.92 s に 4.58 cm を通り、最終値 4 cm（平衡点）からの距離は、横切るたびに 0.527 倍になる（4 節の $`M_\mathrm{p}`$）。
- 上半分（$`\dot p > 0`$）では位置が増えるので右へ、下半分では左へ動く。このため軌跡は時計回りに回る。
- 同じ点からの動きは 1 つに決まるので、2 本の軌跡が交わることはない。

### 渦巻き・楕円・結節

入力の無い台車の軌跡が、減衰比でどんな形になるかを、エネルギーから調べる。台車の運動のエネルギー $`m\dot p^2/2`$ と、ばねにたまったエネルギー $`kp^2/2`$ の和を $`E`$ とする。

**方針**: $`E`$ を時間で微分し、入力の無い台車の式を使って $`\ddot p`$ を消す。

**導出**: $`dE/dt = m\dot p\ddot p + kp\dot p = \dot p(m\ddot p + kp)`$ である。$`u`$ = 0 の式 $`m\ddot p + c\dot p + kp = 0`$ から $`m\ddot p + kp = -c\dot p`$ なので、

$$
\frac{dE}{dt} = -c\dot p^2
$$

である ∎

- $`c`$ = 0（$`\zeta`$ = 0）では $`E`$ が一定で、$`m\dot p^2/2 + kp^2/2 = E`$ は位相平面の楕円である。軌跡は閉じた楕円の上を回り続ける。速度の振れ幅は位置の振れ幅の $`\sqrt{k/m} = \omega_\mathrm{n}`$ 倍で、4 cm から離すと 20 cm/s になる。
- $`c > 0`$ では、動いている間（$`\dot p \ne 0`$）$`E`$ が減り続け、軌跡は内側の楕円へと渡っていく。不足減衰では、回りながら原点へ近づく渦巻きになる。
- 過減衰では、回らずに原点へ近づく。初めの位置と速度を $`\dot p(0) = \lambda_1p(0)`$ に選ぶと、$`p = p(0)e^{\lambda_1t}`$ は式とこの初期値を満たすので、これが解である。いつでも $`\dot p = \lambda_1p`$ なので、点は直線 $`\dot p = \lambda_1p`$ の上を原点へ進む（$`\lambda_2`$ も同じ）。ほかの初期値では、速い根の $`e^{\lambda_2t}`$ の項が先に消えるので、軌跡は遅い根の直線 $`\dot p = \lambda_1p`$ に沿って原点に入る。この形を結節と呼ぶ。

```fig
e04_phase_map
```

位相平面では、応答の速さと行き過ぎが 1 枚に表れる。原点のまわりを何周するかが揺れの回数、渦の詰まり方が減り方である。17 章では、位置と速度を並べたものをベクトルとして扱い、過減衰の 2 本の直線を行列の固有ベクトルの向きとして見直す（[17 章 5 節](17_状態空間モデル.md#状態の動き-行列指数関数と位相平面)）。

下の図で、位相平面の上をドラッグして初めの位置と速度を選ぶと、軌跡と、位置・速度の時間の波形が同時に描かれる。減衰比・固有角周波数と、力を加えるかどうかも変えられる。前に描いた軌跡は薄い色で残る。

## 6. フィードバックで二次遅れが生まれる — モータの位置の P 制御

ここまでの二次遅れは、台車とばねのように、対象そのものが 2 階の式で表されるものだった。1 階の式で表される対象でも、フィードバックをかけると、閉じたループ全体が二次遅れになることがある。DC モータの軸の角度を目標の角度に合わせる制御（例えば、ロボットの腕の関節を決めた角度まで回す）を例にする。

### 閉ループの式

2 章 3 節の一次の式（$`L_\mathrm{a}`$ を無視し、負荷トルクは 0）$`T\dot\omega_\mathrm{m} + \omega_\mathrm{m} = Kv`$ を使う（$`T`$ = 0.05 s、$`K`$ = 50 (rad/s)/V）。制御量は軸の回転角 $`\theta_\mathrm{m}`$ [rad] で、角速度を時間で積分したもの（$`\dot\theta_\mathrm{m} = \omega_\mathrm{m}`$）である。目標値は目標の角度 $`r`$ [rad]、操作量はモータに加える電圧 $`v`$ で、測った角度との偏差に比例した電圧を加える比例制御 $`v = K_\mathrm{P}(r - \theta_\mathrm{m})`$ を考える（比例ゲイン $`K_\mathrm{P}`$ の単位は V/rad）。負荷が無ければ、止まっているモータに電圧は要らないので、1 章の台車の決めた力 $`u_0`$ に当たるものは足さない。

```fig
e04_motor_bd
```

**方針**: $`\omega_\mathrm{m} = \dot\theta_\mathrm{m}`$ を使って一次の式を $`\theta_\mathrm{m}`$ の式に直し、比例制御の式を入れて、標準形と比べる。

**導出**: $`\omega_\mathrm{m} = \dot\theta_\mathrm{m}`$、$`\dot\omega_\mathrm{m} = \ddot\theta_\mathrm{m}`$ を一次の式に入れると $`T\ddot\theta_\mathrm{m} + \dot\theta_\mathrm{m} = Kv`$ である。$`v = K_\mathrm{P}(r - \theta_\mathrm{m})`$ を入れ、$`\theta_\mathrm{m}`$ の項を左辺に移すと

$$
T\ddot\theta_\mathrm{m} + \dot\theta_\mathrm{m} + KK_\mathrm{P}\theta_\mathrm{m} = KK_\mathrm{P}r
$$

で、2 階の式になる。1 節の $`a_2 = T`$、$`a_1 = 1`$、$`a_0 = b_0 = KK_\mathrm{P}`$ として

$$
\omega_\mathrm{n} = \sqrt{\frac{KK_\mathrm{P}}{T}}, \qquad \zeta = \frac{1}{2\sqrt{KK_\mathrm{P}T}}
$$

であり、目標値 $`r`$ から $`\theta_\mathrm{m}`$ までの定常ゲインは $`b_0/a_0`$ = 1 である ∎

図の (b) のブロック線図では、引き出し点で取り出した角度を、加え合わせ点で目標値から引いて偏差を作る。ループの中には、電圧を角速度に変える一次遅れと、角速度を角度にためる積分の 2 つがあり、それぞれが式の階数を 1 つずつ増やした。定常ゲインが 1 なので、角度は目標値に一致して止まり、定常偏差は残らない。3 章 6 節で見た速度の比例制御では定常偏差が残ったのと違い、止まった軸を保つのに電圧が要らないからである。ただし、軸に一定の負荷トルク $`\tau_\mathrm{L}`$（外乱）がかかると、止まったまま $`\tau_\mathrm{L}`$ を支えるトルクを出す電圧が要り、それを偏差から作るので、偏差が残る。2 章の一次の式で $`\dot\omega_\mathrm{m} = \omega_\mathrm{m}`$ = 0 とおくと $`KK_\mathrm{P}(r - \theta_\mathrm{m}) = (R_\mathrm{a}/K_\mathrm{t}^2)\tau_\mathrm{L}`$ で、例の負荷トルク 0.01 N·m なら、下で求める $`K_\mathrm{P}`$ = 0.21 V/rad で偏差は 5000 × 0.01 ÷ (50 × 0.21) = 4.76 rad にもなる（偏差を消す方法は [10 章 2 節](10_PID制御.md#i-動作-偏差をためて定常偏差を消す)）。

### 比例ゲインと特性根

$`K_\mathrm{P}`$ を変えると、$`\omega_\mathrm{n}`$ は $`\sqrt{K_\mathrm{P}}`$ に比例して大きくなり、$`\zeta`$ は $`1/\sqrt{K_\mathrm{P}}`$ に比例して小さくなる。特性方程式 $`T\lambda^2 + \lambda + KK_\mathrm{P} = 0`$ の根で見ると、次のようになる。

- $`K_\mathrm{P}`$ = 0 では $`\lambda(T\lambda + 1) = 0`$ で、根は 0 と $`-1/T`$ = −20 である。
- $`K_\mathrm{P}`$ を上げると 2 つの根は実軸の上で近づき、$`\zeta`$ = 1 となる $`K_\mathrm{P} = 1/(4KT)`$ = 0.1 V/rad で −10 に重なる。
- さらに上げると、根は $`-10 \pm j\omega_\mathrm{d}`$ に分かれ、虚部だけが大きくなる。実部は $`-\zeta\omega_\mathrm{n} = -1/(2T)`$ = −10 のまま変わらない。

```fig
e04_motor_kp
```

図の (b) のとおり、$`K_\mathrm{P}`$ を上げると角度は速く動き始めるが、根が重なる 0.1 V/rad を超えると目標を行き過ぎ、その量は $`K_\mathrm{P}`$ とともに増える。

### 行き過ぎ量 5 % 以下にする比例ゲイン

行き過ぎ量を 5 % 以下にするには、4 節から $`\zeta \ge 0.690`$ が要る。$`\zeta = 1/(2\sqrt{KK_\mathrm{P}T})`$ を $`K_\mathrm{P}`$ について解くと $`K_\mathrm{P} = 1/(4KT\zeta^2)`$ で、$`\zeta`$ が大きいほど $`K_\mathrm{P}`$ は小さいので、

$$
K_\mathrm{P} \le \frac{1}{4 \times 50 \times 0.05 \times 0.690^2} = 0.210\ \text{V/rad}
$$

である。$`K_\mathrm{P}`$ = 0.21 V/rad では、$`\omega_\mathrm{n}`$ = 14.5 rad/s、$`\zeta`$ = 0.690、根は $`-10 \pm j10.5`$ で、$`t_\mathrm{r}`$ = 0.145 s、$`t_\mathrm{p}`$ = 0.300 s、$`M_\mathrm{p}`$ = 5.0 %、$`t_{2\%}`$ = 0.414 s（目安の式では 4 ÷ 10 = 0.4 s）である。目標を 1 rad 変えたときの電圧は、始めの 0.21 V が最大である。

```fig
e04_motor_design
```

図のとおり、$`K_\mathrm{P}`$ を上げても、根の実部が −10 のままなので、$`t_{2\%}`$ は 0.35〜0.41 s からほとんど縮まず、行き過ぎ量だけが増える（$`K_\mathrm{P}`$ = 1 V/rad で 35.1 %、10 V/rad で 72.9 %）。比例制御だけでは、このモータの角度を 0.4 s より速く落ち着かせることはできない。根の実部を左へ動かすには、角速度に比例した電圧を加えて減衰を増やす（[10 章 3 節](10_PID制御.md#d-動作-変化を先読みして振動を抑える)）。ゲインを変えたときの根の動きは、[12 章](12_根軌跡.md#閉ループの極はゲインで動く)で根軌跡として調べる。

この節のモデルは、2 章で $`L_\mathrm{a}`$ を無視した一次の式から作った。$`L_\mathrm{a}`$ を含めると閉ループは 3 階の式になる。$`K_\mathrm{P}`$ = 0.21 V/rad では 2 つの式の角度の差は 0.0017 rad 以下で、行き過ぎ量は 5.01 % とほとんど同じだが、$`K_\mathrm{P}`$ = 10 V/rad では 78.8 %（二次遅れの式では 72.9 %）と差が開き、40 V/rad を超えると揺れが大きくなり続ける（この境目の求め方は [9 章 2 節](09_安定性と安定余裕.md#特性方程式の係数で判定する-ラウスの方法)）。

下の図で比例ゲインと目標の角度を変えると、モータの軸が回る絵、角度と電圧の波形、根の平面の特性根が同時に変わる。$`L_\mathrm{a}`$ を含めた 3 階の式の応答も重ねられる。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 二次遅れ・標準形 | $`a_2\ddot y + a_1\dot y + a_0y = b_0u`$ で表される対象／$`\ddot y + 2\zeta\omega_\mathrm{n}\dot y + \omega_\mathrm{n}^2y = \omega_\mathrm{n}^2Ku`$ |
| 固有角周波数・減衰比 | $`\omega_\mathrm{n} = \sqrt{a_0/a_2}`$（減衰が無いときの揺れの角周波数。時間の目盛）／$`\zeta = a_1/(2\sqrt{a_0a_2})`$（応答の形）。台車は $`\sqrt{k/m}`$ = 5 rad/s、$`c/(2\sqrt{mk})`$ = 0.2 |
| 特性方程式・特性根 | $`y = e^{\lambda t}`$ を入れて得る $`\lambda^2 + 2\zeta\omega_\mathrm{n}\lambda + \omega_\mathrm{n}^2 = 0`$／その根 $`-\zeta\omega_\mathrm{n} \pm \omega_\mathrm{n}\sqrt{\zeta^2 - 1}`$ |
| 過減衰・臨界減衰・不足減衰 | $`\zeta > 1`$: 異なる 2 つの負の実根、指数関数 2 つの和／$`\zeta = 1`$: 重根、行き過ぎない中で最も速い／$`0 < \zeta < 1`$: 共役な複素根、揺れながら縮む |
| 減衰固有角周波数 | $`\omega_\mathrm{d} = \omega_\mathrm{n}\sqrt{1 - \zeta^2}`$。根の虚部で、揺れの角周波数。振幅は実部の $`e^{-\zeta\omega_\mathrm{n}t}`$ で縮む。根は原点から $`\omega_\mathrm{n}`$ の距離にあり、$`\cos\psi = \zeta`$ |
| ステップ応答 | $`y = K[1 - e^{-\zeta\omega_\mathrm{n}t}\sin(\omega_\mathrm{d}t + \psi)/\sqrt{1 - \zeta^2}]`$。最終値からのずれは自由な動きと同じ式に従う |
| 立ち上がり時間・ピーク時間 | 10 % → 90 % の時間 $`\omega_\mathrm{n}t_\mathrm{r} \approx 0.6 + 2.16\zeta`$（0.3〜0.8）／$`t_\mathrm{p} = \pi/\omega_\mathrm{d}`$ |
| 行き過ぎ量・整定時間 | $`M_\mathrm{p} = e^{-\pi\zeta/\sqrt{1 - \zeta^2}}`$ × 100 %（5 % で $`\zeta`$ = 0.690）／±2 % に入って出なくなる時刻、目安 $`t_{2\%} \approx 4/(\zeta\omega_\mathrm{n})`$ |
| 位相平面 | 横に位置、縦に速度。不足減衰は渦巻き、減衰が無いと楕円、過減衰は遅い根の直線に沿って入る結節 |
| 位置の比例制御 | 一次遅れ ＋ 積分のループで二次遅れになる。$`\omega_\mathrm{n} = \sqrt{KK_\mathrm{P}/T}`$、$`\zeta = 1/(2\sqrt{KK_\mathrm{P}T})`$。行き過ぎ量 5 % 以下は $`K_\mathrm{P} \le`$ 0.21 V/rad。根の実部は −10 のままで、整定時間は約 0.4 s より縮まない |
