# 13. ループ整形 — 位相進み補償と位相遅れ補償

> **この章で扱う問い.**

> 3. 形を整えれば、どこまでも速く、余裕をもって制御できるのか。何がその限りを決めるのか。

> 答えの道具は、感度関数を一巡伝達関数のゲインで近似する式、零点と極を 1 つずつもつ 2 つの補償器と最大位相進みの式、そして感度関数のゲインの対数を角周波数で積分すると 0 になるという関係である。

## 1. 一巡伝達関数の形で性能を決める

7 章 6 節では、台車の速度の比例制御（$`K_\mathrm{P}`$ = 8 N/(m/s)）で、1 rad/s の正弦波の外乱は 0.22 倍に縮み、50 rad/s の観測ノイズは 0.16 倍しか制御量に現れないことを見た。8 章 3 節では、この分担を、感度関数 $`S(s)`$ と閉ループ伝達関数 $`G_{yr}(s)`$ のゲインのボード線図で読んだ。2 つの関数は、どちらも一巡伝達関数 $`P(s)C(s)`$ だけで決まる（7 章 2・5 節）。この節では、$`|S(j\omega)|`$ と $`|G_{yr}(j\omega)|`$ を一巡伝達関数のゲイン $`|P(j\omega)C(j\omega)|`$ で近似する式を導き、一巡伝達関数のボード線図のどの部分がどの性能を決めるのかを整理する。この章のフィードバック系は、目標値を制御器の前の加え合わせ点にだけ入れる、7 章 2 節の基本の形とする。

### ループのゲインが大きい所と小さい所

$`S = 1/(1 + PC)`$ と $`G_{yr} = PC/(1 + PC)`$ の大きさは、分母 $`1 + P(j\omega)C(j\omega)`$ の大きさで決まる。これを $`|P(j\omega)C(j\omega)|`$ で挟む。

**方針**: 複素数 $`a`$・$`b`$ の和の大きさについての三角不等式 $`\bigl||a| - |b|\bigr| \le |a + b| \le |a| + |b|`$ を、$`a = 1`$、$`b = P(j\omega)C(j\omega)`$ に使う。

**導出**: 角周波数 $`\omega`$ を 1 つ決め、$`|P(j\omega)C(j\omega)|`$ を $`|PC|`$ と略す。三角不等式から $`\bigl||PC| - 1\bigr| \le |1 + PC| \le |PC| + 1`$ である。$`|S| = 1/|1 + PC|`$ なので、各辺の逆数をとると不等号の向きが入れ替わる（$`|PC| \ne 1`$ とする）。$`|G_{yr}| = |PC|/|1 + PC|`$ は、それにさらに $`|PC|`$ を掛けたものである。したがって

$$
\frac{1}{|PC| + 1} \le |S| \le \frac{1}{\bigl||PC| - 1\bigr|}, \qquad \frac{|PC|}{|PC| + 1} \le |G_{yr}| \le \frac{|PC|}{\bigl||PC| - 1\bigr|}
$$

である。$`|PC| \gg 1`$ のときは、両端の 1 を $`|PC|`$ に比べて捨てて、$`|S| \approx 1/|PC|`$、$`|G_{yr}| \approx 1`$ となる。$`|PC| \ll 1`$ のときは、$`|PC|`$ を 1 に比べて捨てて、$`|S| \approx 1`$、$`|G_{yr}| \approx |PC|`$ となる ∎

$`|PC|`$ が 10（20 dB）なら、$`|S|`$ は 1/11 と 1/9 の間にあり、$`1/|PC|`$ との差は 1 dB より小さい。$`|PC|`$ が 0.1（−20 dB）なら、$`|G_{yr}|`$ と $`|PC|`$ の差が 1 dB より小さい。dB で言い直すと、ループのゲインが高い所では $`|S|`$ の dB は $`|PC|`$ の dB の符号を変えたもの、ループのゲインが低い所では $`|G_{yr}|`$ の dB は $`|PC|`$ の dB そのものである。台車では $`P(s)C(s) = 4/(0.5s + 1)`$ で（7 章 3 節）、1 rad/s では $`|PC|`$ = 3.58 なので $`|S|`$ は 1/4.58 = 0.218 と 1/2.58 = 0.388 の間にあり（実際は 0.222）、50 rad/s では $`|PC|`$ = 0.160 なので $`|G_{yr}|`$ は 0.138 と 0.190 の間にある（実際は 0.157）。

ループの外から入る信号ごとに、この近似の意味を読む。

- 制御量に入る外乱は $`S`$ 倍になって制御量に現れ、目標値の変化は $`S`$ 倍の偏差を残す（7 章 4・5 節）。ゆっくり変わる外乱を抑え、目標値に追従させたい角周波数では、$`|PC|`$ を大きくする。外乱を 1/10 以下に縮めたい角周波数では、$`|PC|`$ を 20 dB 以上にする。
- 観測ノイズは $`G_{yr}`$ 倍で制御量に現れる（7 章 2 節）。ノイズが多い速い角周波数では、$`|PC|`$ を小さくする。
- 観測ノイズから操作量までの伝達関数は、目標値と外乱を 0 として 7 章 2 節の $`U = CE`$、$`E = -(Y + N)`$、$`Y = PU`$ から $`U`$ を求めると、$`-C(s)/\{1 + P(s)C(s)\} = -C(s)S(s)`$ である。$`|PC| \ll 1`$ の所では $`S \approx 1`$ なので、速いノイズは、制御器のゲイン $`|C(j\omega)|`$ のまま操作量に現れる。モータの電圧やヒータの電力を細かく揺らす元になる（10 章 3 節）。
- 対象のモデルに入れていない速い動き（モータの巻線のインダクタンスによる極、センサや計算の遅れ）は、速い角周波数で位相を遅らせる（9 章 6 節）。その角周波数で $`|PC|`$ が十分に小さければ、位相がどれだけ遅れても、ナイキスト線図の点は原点の近くにあり、−1 の点には近づかない。

### 交差のまわり — 速さと余裕

ゲインの線は、高い所から低い所へ移る途中で 0 dB を横切る。横切る角周波数が、9 章 5 節のゲイン交差角周波数 $`\omega_\mathrm{gc}`$ である（この章では、ゲインの線が 0 dB を横切るあたりを単に**交差**と呼ぶ）。交差のまわりでは $`|PC| \approx 1`$ なので、上の近似は使えない。$`S`$ と $`G_{yr}`$ の大きさは、位相で決まる。

**方針**: $`\omega_\mathrm{gc}`$ では $`|PC| = 1`$ で、位相は $`-180° + \phi_\mathrm{m}`$（$`\phi_\mathrm{m}`$ は位相余裕。9 章 5 節）なので、$`P(j\omega_\mathrm{gc})C(j\omega_\mathrm{gc}) = e^{j(-180° + \phi_\mathrm{m})} = -e^{j\phi_\mathrm{m}}`$ である。これを $`|1 + PC|`$ に入れる。

**導出**: $`1 + PC = 1 - e^{j\phi_\mathrm{m}} = (1 - \cos\phi_\mathrm{m}) - j\sin\phi_\mathrm{m}`$ なので、大きさの 2 乗は $`(1 - \cos\phi_\mathrm{m})^2 + \sin^2\phi_\mathrm{m} = 2 - 2\cos\phi_\mathrm{m}`$ である。半角の公式 $`1 - \cos\phi_\mathrm{m} = 2\sin^2(\phi_\mathrm{m}/2)`$ から、これは $`4\sin^2(\phi_\mathrm{m}/2)`$ に等しく、$`0° < \phi_\mathrm{m} < 180°`$ では $`|1 + PC| = 2\sin(\phi_\mathrm{m}/2)`$ である。$`|PC| = 1`$ なので $`|S|`$ と $`|G_{yr}|`$ は等しく

$$
|S(j\omega_\mathrm{gc})| = |G_{yr}(j\omega_\mathrm{gc})| = \frac{1}{2\sin(\phi_\mathrm{m}/2)}
$$

となる ∎

| 位相余裕 $`\phi_\mathrm{m}`$ | 90° | 60° | 45° | 30° | 20° |
|---|---|---|---|---|---|
| $`|S(j\omega_\mathrm{gc})| = |G_{yr}(j\omega_\mathrm{gc})|`$ | 0.707（−3.0 dB） | 1（0 dB） | 1.31（2.3 dB） | 1.93（5.7 dB） | 2.88（9.2 dB） |

- 位相余裕が 90° より小さければ、$`\omega_\mathrm{gc}`$ での $`|G_{yr}|`$ は $`1/\sqrt 2`$（−3 dB）より大きく、その先では $`|G_{yr}| \approx |PC|`$ で下がっていく。したがって閉ループのバンド幅（8 章 6 節）は $`\omega_\mathrm{gc}`$ の少し上にある。交差角周波数を上げれば、バンド幅も上がり、立ち上がり時間（目安は $`2/\omega_\mathrm{b}`$。8 章 6 節）が短くなる。
- 位相余裕が 60° より小さければ、$`\omega_\mathrm{gc}`$ のあたりで $`|S|`$ も $`|G_{yr}|`$ も 1 を越えて山を作る。$`|G_{yr}|`$ の山は共振ピークで、目標値のステップに対して行き過ぎる（8 章 6 節）。$`|S|`$ の山は、その角周波数の外乱を、フィードバックの無いときより大きくすることを表す。

モータの位置の比例制御（$`P(s) = 1000/\{s(s + 20)\}`$ rad/V、6 章 1 節。巻線のインダクタンス $`L_\mathrm{a}`$ は無視）で確かめる。比例ゲインを 0.21・0.84・4 V/rad にすると、$`\omega_\mathrm{gc}`$ は 9.49・25.8・61.7 rad/s、位相余裕は 64.6°・37.8°・18.0° になる。

$`\omega_\mathrm{gc}`$ での $`|S|`$ と $`|G_{yr}|`$ は、式のとおり 0.935・1.54・3.20 である。閉ループのバンド幅は 14.8・41.2・96.5 rad/s（$`\omega_\mathrm{gc}`$ の 1.56〜1.60 倍）、立ち上がり時間は 0.145・0.048・0.018 s で、交差を上げるほど速い。一方、行き過ぎ量は 5.0・31.5・60.5 % と増える。

位相余裕は、交差のまわりのゲインの線の傾きで決まる。8 章 5 節のとおり、最小位相の一巡伝達関数では、折れ点から離れた所で、ゲインの傾きが −20 dB/dec なら位相はおよそ −90°、−40 dB/dec ならおよそ −180° である。モータの位置のゲインの線は、20 rad/s の折れ点より下では −20 dB/dec、上では −40 dB/dec である。0.21 V/rad では交差が折れ点より下にあって位相余裕が 64.6° 残るが、4 V/rad では交差が折れ点の 3 倍上にあり、18.0° しか残らない。位相余裕を残すには、交差の前後のある幅（例えば交差の 1/3 倍から 3 倍まで）で、ゲインの傾きを −20 dB/dec 程度にしておく。オペアンプの中の位相補償で、利得の線を −20 dB/dec の傾きで 0 dB に横切らせるのも、同じ考え方である（[組み込み回路シリーズ 7 章 3 節](../circuit/07_オペアンプ内部.md#なぜ-−20-db-decade-にするのか)）。

### 望ましい形

ここまでの結果を、要求ごとに並べる。

| 要求 | 決めるのは一巡伝達関数のどこか | 理由 |
|---|---|---|
| 目標値への追従・外乱の抑え | 遅い変化の角周波数で、ゲインが大きいこと | $`|S| \approx 1/|PC|`$ |
| 定常偏差 | $`\omega \to 0`$ での傾き（型）と高さ | 7 章 3 節 |
| 速さ | 交差角周波数 $`\omega_\mathrm{gc}`$ | 閉ループのバンド幅は $`\omega_\mathrm{gc}`$ の少し上 |
| 余裕・行き過ぎ | 交差での位相（交差のまわりの傾きを −20 dB/dec 程度に） | $`|S(j\omega_\mathrm{gc})| = 1/\{2\sin(\phi_\mathrm{m}/2)\}`$ |
| 観測ノイズ・モデルに無い速い動き | 速い角周波数で、ゲインが小さいこと | $`|G_{yr}| \approx |PC|`$、操作量のノイズは $`|C|`$ 倍 |

## 2. 位相遅れ補償 — 低い周波数のゲインを上げる

1 節の台車の速度の比例制御（$`K_\mathrm{P}`$ = 8 N/(m/s)）では、遅い角周波数のループのゲインは $`P(0)C(0)`$ = 4（12.0 dB）しかない。目標値の 1 m/s に 0.2 m/s の偏差が残り（定常偏差 1/(1 + 4)。7 章 3 節）、ゆっくり変わる外乱は 1/5 にしか縮まない。定常偏差を 0.025 m/s 以下にするには、$`1/\{1 + P(0)C(0)\} \le 0.025`$ から、$`P(0)C(0)`$ を 39 以上にする必要がある。比例ゲインを 10 倍の 80 N/(m/s) にすれば $`P(0)C(0)`$ = 40 になるが、ゲインの線全体が 20 dB 上がるので、交差角周波数も 7.75 rad/s から 80.0 rad/s に上がる。50 rad/s の観測ノイズが制御量に現れる割合は 0.157 から 0.833 に増え、1 章 4 節の観測ノイズ（0.01 s ごとに変わる、標準偏差 0.02 m/s の値）による速度の揺れは、標準偏差で 0.0036 m/s から 0.0112 m/s に増える。遅い角周波数のゲインだけを上げ、交差より上の形を変えない補償器を作る。

### 遅れ補償器

次の伝達関数の補償器を考える。

$$
C_\mathrm{lag}(s) = \frac{s + \omega_\mathrm{z1}}{s + \omega_\mathrm{p1}} \qquad (0 < \omega_\mathrm{p1} < \omega_\mathrm{z1})
$$

零点 $`-\omega_\mathrm{z1}`$ と、それより原点に近い極 $`-\omega_\mathrm{p1}`$ を 1 つずつもつ（4 節で 2 種類の補償器をつなぐので、この補償器の折れ点角周波数には 1、3 節の補償器には 2 の番号を付ける）。$`s = j\omega`$ を入れると、ゲインは、$`\omega`$ が 0 に近いとき $`\omega_\mathrm{z1}/\omega_\mathrm{p1}`$、限りなく大きいとき 1 である。ゲインの漸近線は、$`\omega_\mathrm{p1}`$ までは $`20\log_{10}(\omega_\mathrm{z1}/\omega_\mathrm{p1})`$ dB の水平な線、$`\omega_\mathrm{p1}`$ から $`\omega_\mathrm{z1}`$ までは −20 dB/dec、$`\omega_\mathrm{z1}`$ より上は 0 dB である（8 章 4 節の一次遅れと一次進みの組み合わせ）。位相は、極の因数の遅れが零点の因数の進みより低い角周波数で始まるので、どの角周波数でも負である。

この補償器を交差より十分に低い角周波数に置くと、交差での位相とゲインがどれだけ変わるかを求める。

**方針**: 位相を、零点の因数と極の因数の角度の差で書き、$`\omega`$ が $`\omega_\mathrm{z1}`$ より十分に高いときの近似を求める。

**導出**: $`\angle C_\mathrm{lag}(j\omega) = \arctan(\omega/\omega_\mathrm{z1}) - \arctan(\omega/\omega_\mathrm{p1})`$ である。$`x > 0`$ では $`\arctan x = 90° - \arctan(1/x)`$ なので、これは $`\arctan(\omega_\mathrm{p1}/\omega) - \arctan(\omega_\mathrm{z1}/\omega)`$ と書ける。$`\omega \gg \omega_\mathrm{z1} > \omega_\mathrm{p1}`$ では arctan の中が小さく、$`\arctan y \approx y`$（rad）なので

$$
\angle C_\mathrm{lag}(j\omega) \approx -\frac{\omega_\mathrm{z1} - \omega_\mathrm{p1}}{\omega}\ \text{[rad]}
$$

である。ゲインは $`\sqrt{\omega^2 + \omega_\mathrm{z1}^2}/\sqrt{\omega^2 + \omega_\mathrm{p1}^2}`$ で、$`\omega \gg \omega_\mathrm{z1}`$ では 1 に近づく ∎

零点を交差角周波数の 1/10 に置き（$`\omega_\mathrm{gc} = 10\omega_\mathrm{z1}`$）、遅い角周波数のゲインを 10 倍にする（$`\omega_\mathrm{p1} = \omega_\mathrm{z1}/10`$）と、交差での位相の遅れは 0.9 ÷ 10 = 0.09 rad、つまり 5.2°（近似しない値は 5.1°）で、ゲインの変化は 0.04 dB である。遅れが最も大きいのは、対数の目盛で 2 つの折れ点の真ん中の $`\sqrt{\omega_\mathrm{z1}\omega_\mathrm{p1}}`$ で、10 倍のとき 54.9° になるが、そこは交差から十分に離れている。

零点より原点に近い所に極をもつ $`C_\mathrm{lag}(s)`$ のような補償器を**位相遅れ補償器**といい、これを制御器に直列に入れて、交差のまわりの形をほとんど変えずに遅い角周波数のゲインを上げることを**位相遅れ補償**という。名前は、補償器の位相がどの角周波数でも遅れていることによる。欲しいのはゲインの形で、位相の遅れは、交差から離すことで小さくしている代償である。

### 設計の手順

1. 遅れ補償器を入れる前の制御器（ここでは比例ゲイン）を、交差角周波数と位相余裕の仕様に合わせて決める。遅れ補償器は交差で位相を 5° ほど遅らせるので、余裕の小さいループでは、その分を見込んでおく。
2. 定常偏差や外乱の仕様から、遅い角周波数で要るループのゲインを求め、上げる倍率 $`\omega_\mathrm{z1}/\omega_\mathrm{p1}`$ を決める。
3. 零点 $`\omega_\mathrm{z1}`$ を交差角周波数の 1/10 程度に置き、極を $`\omega_\mathrm{p1} = \omega_\mathrm{z1}`$ ÷ 倍率 に置く。
4. 余裕と、時間の応答を確かめる（この節の終わりで見る、遅い極が残す尾）。

$$

$$

である。$`P(0)C(0)`$ = 4 × 10 = 40 で、定常偏差は 1/41 = 0.024 m/s になる。

## 3. 位相進み補償 — 交差周波数で位相を足す

1 節のモータの位置の比例制御を速くする。0.21 V/rad では、交差角周波数 9.49 rad/s、行き過ぎ量 5.0 %、2 % 整定時間 0.414 s である。比例ゲインを 1.08 V/rad に上げて交差を約 3 倍の 30 rad/s にすると、対象の位相は 30 rad/s で −90° − arctan(30/20) = −146.3° なので、位相余裕は 33.7° しか残らず、行き過ぎ量は 36.7 % になる。1 節で見たとおり、交差が 20 rad/s の折れ点より上に出て、ゲインの線の傾きが −40 dB/dec の所で 0 dB を横切るからである。交差のまわりでだけゲインの傾きを緩め、位相を進める補償器を作る。

### 進み補償器と最大位相進み

次の伝達関数の補償器を考える。

$$
C_\mathrm{lead}(s) = \frac{1 + s/\omega_\mathrm{z2}}{1 + s/\omega_\mathrm{p2}}, \qquad \alpha = \frac{\omega_\mathrm{p2}}{\omega_\mathrm{z2}} > 1
$$

零点 $`-\omega_\mathrm{z2}`$ と、それより原点から遠い極 $`-\omega_\mathrm{p2}`$ を 1 つずつもち、$`\alpha`$ は 2 つの折れ点角周波数の比である。ゲインは、$`\omega`$ が 0 に近いとき 1、限りなく大きいとき $`\alpha`$ で、漸近線は、$`\omega_\mathrm{z2}`$ までは 0 dB、$`\omega_\mathrm{z2}`$ から $`\omega_\mathrm{p2}`$ までは +20 dB/dec、$`\omega_\mathrm{p2}`$ より上は $`20\log_{10}\alpha`$ dB である。位相は、零点の因数の進みが極の因数の遅れより低い角周波数で始まるので、どの角周波数でも正で、2 つの折れ点の間で山を作る。山の高さと位置を求める。

**方針**: 位相は、零点の因数の角度から極の因数の角度を引いたものである。その正接を、正接の加法定理で 1 つの式にし、それが最も大きくなる角周波数を求める。位相は 0° と 90° の間にあり、その範囲では正接が大きいほど角度も大きいからである。

**導出**: $`x = \omega/\omega_\mathrm{z2}`$ とおくと $`\omega/\omega_\mathrm{p2} = x/\alpha`$ なので、位相は $`\phi = \arctan x - \arctan(x/\alpha)`$ である。$`\tan(A - B) = (\tan A - \tan B)/(1 + \tan A\tan B)`$ から

$$
\tan\phi = \frac{x - x/\alpha}{1 + x^2/\alpha} = \frac{(\alpha - 1)x}{\alpha + x^2}
$$

である。$`x`$ で微分すると、分子は $`(\alpha - 1)(\alpha + x^2) - (\alpha - 1)x \cdot 2x = (\alpha - 1)(\alpha - x^2)`$ なので、$`\tan\phi`$ は $`x < \sqrt\alpha`$ で増え、$`x > \sqrt\alpha`$ で減り、$`x = \sqrt\alpha`$ で最も大きい。そこでは $`\tan\phi = (\alpha - 1)\sqrt\alpha/(2\alpha) = (\alpha - 1)/(2\sqrt\alpha)`$ である。正弦に直すため、$`1 + \tan^2\phi = 1 + (\alpha - 1)^2/(4\alpha) = (\alpha + 1)^2/(4\alpha)`$ から $`\cos\phi = 2\sqrt\alpha/(\alpha + 1)`$ を求め、$`\sin\phi = \tan\phi\cos\phi`$ を計算する。角周波数は $`\omega = \sqrt\alpha\,\omega_\mathrm{z2} = \sqrt{\omega_\mathrm{z2}\omega_\mathrm{p2}}`$ で、そこでのゲインは $`|1 + j\sqrt\alpha|/|1 + j/\sqrt\alpha| = \sqrt{1 + \alpha}/\sqrt{1 + 1/\alpha} = \sqrt\alpha`$ である。まとめると

$$
\omega_\mathrm{c} = \sqrt{\omega_\mathrm{z2}\,\omega_\mathrm{p2}}, \qquad \sin\phi_\mathrm{max} = \frac{\alpha - 1}{\alpha + 1}, \qquad |C_\mathrm{lead}(j\omega_\mathrm{c})| = \sqrt\alpha
$$

となる ∎

位相の山の頂の値 $`\phi_\mathrm{max}`$ を**最大位相進み**といい、山の頂の角周波数を $`\omega_\mathrm{c}`$ と書く（c は中心の意味。$`\phi_\mathrm{max}`$ は 9 章 5 節の位相余裕 $`\phi_\mathrm{m}`$ とは別の量である）。$`\log\omega_\mathrm{c}`$ は $`\log\omega_\mathrm{z2}`$ と $`\log\omega_\mathrm{p2}`$ の平均なので、$`\omega_\mathrm{c}`$ は、対数の目盛で 2 つの折れ点のちょうど真ん中にある。$`\alpha`$ ごとの値を並べる。

| $`\alpha`$ | 2 | 3 | 4 | 5 | 10 | 20 | 100 |
|---|---|---|---|---|---|---|---|
| 最大位相進み $`\phi_\mathrm{max}`$ | 19.5° | 30.0° | 36.9° | 41.8° | 54.9° | 64.8° | 78.6° |
| $`\omega_\mathrm{c}`$ でのゲイン $`\sqrt\alpha`$ | 3.0 dB | 4.8 dB | 6.0 dB | 7.0 dB | 10.0 dB | 13.0 dB | 20.0 dB |
| 高い角周波数のゲイン $`\alpha`$ | 6.0 dB | 9.5 dB | 12.0 dB | 14.0 dB | 20.0 dB | 26.0 dB | 40.0 dB |

$`\alpha`$ を大きくするほど位相は進むが、増え方は鈍く、90° には届かない。一方、高い角周波数のゲインは $`\alpha`$ 倍になり、1 節で見たとおり、速い観測ノイズがその倍率で操作量に現れる。$`\alpha`$ = 10 で 54.9° を得るのにノイズは 10 倍、$`\alpha`$ = 100 で 78.6° を得るのに 100 倍で、位相を足すほど割に合わなくなる。

零点より原点から遠い所に極をもつ $`C_\mathrm{lead}(s)`$ のような補償器を**位相進み補償器**といい、これを制御器に直列に入れて、交差のまわりの位相を進めることを**位相進み補償**という。1 節の言葉で言えば、$`\omega_\mathrm{z2}`$ から $`\omega_\mathrm{p2}`$ までの間だけ、ゲインの線の傾きを +20 dB/dec 緩める補償器で、対象の傾きが −40 dB/dec の所に置けば、交差のまわりの傾きを −20 dB/dec に戻せる。

```fig

```

### 設計の手順

位相の山の頂を交差に合わせ、交差で足りない位相を足す。

1. 速さの仕様から交差角周波数 $`\omega_\mathrm{gc}`$ を決め、そこでの対象の位相から、比例制御のときの位相余裕 $`180° + \angle P(j\omega_\mathrm{gc})`$ を求める。
2. 仕様の位相余裕との差を、足りない位相とする。後で遅れ補償器を足すなら 5° ほど、モデルに無い遅れがあればその分も加えておく。最大位相進みの式を $`\alpha`$ について解いた $`\alpha = (1 + \sin\phi_\mathrm{max})/(1 - \sin\phi_\mathrm{max})`$ に、足りない位相を $`\phi_\mathrm{max}`$ として入れ、$`\alpha`$ を求める。
3. 山の頂を交差に合わせ、$`\omega_\mathrm{z2} = \omega_\mathrm{gc}/\sqrt\alpha`$、$`\omega_\mathrm{p2} = \sqrt\alpha\,\omega_\mathrm{gc}`$ とする。
4. 交差で進み補償器のゲインは $`\sqrt\alpha`$ なので、ループのゲインが交差で 1 になるように、制御器の全体のゲインを $`K_\mathrm{c} = 1/\{\sqrt\alpha\,|P(j\omega_\mathrm{gc})|\}`$ とする。制御器は $`C(s) = K_\mathrm{c}C_\mathrm{lead}(s)`$ である（12 章 1 節の書き方 $`C(s) = K_\mathrm{c}C_0(s)`$ で、$`C_0 = C_\mathrm{lead}`$）。
5. 余裕と応答を確かめ、制御器の高い角周波数のゲイン $`K_\mathrm{c}\alpha`$ が大きすぎないか（操作量のノイズと、目標値の段差に対する操作量）を確かめる。

### 例: モータの位置を 3 倍速くする

仕様を、交差角周波数 30 rad/s、位相余裕 60° 以上とする（例の値）。

1. 比例制御の位相余裕は 180° − 146.3° = 33.7° である。
2. 足りない位相は 60° − 33.7° = 26.3° で、$`\alpha`$ = (1 + sin 26.3°)/(1 − sin 26.3°) = 2.59 である。切りのよい $`\alpha`$ = 3（$`\phi_\mathrm{max}`$ = 30°）にする。
3. $`\omega_\mathrm{z2}`$ = 30/√3 = 17.3 rad/s、$`\omega_\mathrm{p2}`$ = 30√3 = 52.0 rad/s。
4. $`|P(j30)|`$ = 1000/(30 × √(30² + 20²)) = 0.925 なので、$`K_\mathrm{c}`$ = 1/(√3 × 0.925) = 0.625 V/rad。

$$
C(s) = 0.625\,\frac{1 + s/17.3}{1 + s/52.0}\ \text{V/rad}
$$


5. 確かめる: 図の (a) のとおり、進み補償器はゲインの線を交差のまわりで持ち上げて傾きを緩め、位相の山を交差に重ねる。比例ゲインを 1.08 V/rad にした場合と同じ 30 rad/s で交差し、位相余裕は 33.7° + 30° = 63.7° になる。(b) のステップ応答は、行き過ぎ量 5.1 %、2 % 整定時間 0.123 s で、0.21 V/rad の比例制御とほぼ同じ行き過ぎのまま、3.4 倍速く落ち着く。(c) のとおり、閉ループの極は、比例ゲイン 1.08 V/rad のときの $`-10 \pm j31.3`$ から、$`-27.9 \pm j35.1`$ と −16.1 に移る。12 章 4 節で見たとおり、零点 −17.3 が根軌跡を左へ引き寄せた。実軸の上の極 −16.1 は零点 −17.3 の近くにあるので、その項は小さい（6 章 6 節）。$`L_\mathrm{a}`$ を含めた対象（6 章 4 節）でも、位相余裕は 62.9°、ゲイン余裕は 35.4 dB ある。高い角周波数のゲインは $`K_\mathrm{c}\alpha`$ = 1.87 V/rad で、目標を 1 rad 変えた瞬間の電圧は 1.87 V と、12 V の電源に十分収まる。

## 4. 進み遅れ補償と PID の関係

2 節の遅れ補償器は交差より十分に低い角周波数で、3 節の進み補償器は交差のまわりで、ボード線図を整える。働く角周波数の範囲が重ならないので、2 つを直列につなげば、両方の効き目がほぼそのまま得られる。

$$
C(s) = K_\mathrm{c}\,\frac{s + \omega_\mathrm{z1}}{s + \omega_\mathrm{p1}} \cdot \frac{1 + s/\omega_\mathrm{z2}}{1 + s/\omega_\mathrm{p2}} \qquad (\omega_\mathrm{p1} < \omega_\mathrm{z1} < \omega_\mathrm{z2} < \omega_\mathrm{p2})
$$

遅れ補償器と進み補償器を直列につないだ補償器を**進み遅れ補償器**といい、これを制御器にして、遅い角周波数のゲインと交差のまわりの位相を同時に整えることを**進み遅れ補償**という（6 節で設計する）。補償器のゲインの漸近線は、$`\omega_\mathrm{p1}`$ から $`\omega_\mathrm{z1}`$ までは −20 dB/dec で下がり、$`\omega_\mathrm{z2}`$ から $`\omega_\mathrm{p2}`$ までは +20 dB/dec で上がり、その外は水平である。

### PID を 2 つの補償器に分ける

10 章 4 節の PID 制御も、零点と極で見ると、この形をしている。

**方針**: 10 章 6 節の不完全微分を入れた PD・PI・PID の伝達関数を、それぞれ 1 つの分数にまとめ、分子と分母を因数に分けて、遅れ補償器と進み補償器の形と比べる。

**導出**: 3 つの形を順に調べる。

- 不完全微分の PD: $`K_\mathrm{P}\{1 + T_\mathrm{D}s/(1 + (T_\mathrm{D}/N)s)\}`$ を通分すると、分子は $`1 + (T_\mathrm{D}/N)s + T_\mathrm{D}s = 1 + (1 + 1/N)T_\mathrm{D}s`$、分母は $`1 + (T_\mathrm{D}/N)s`$ である。したがって、$`K_\mathrm{P}`$ と、$`\omega_\mathrm{z2} = N/\{(N + 1)T_\mathrm{D}\}`$、$`\omega_\mathrm{p2} = N/T_\mathrm{D}`$ の進み補償器の積で、折れ点の比は $`\alpha = N + 1`$ である。
- PI: $`K_\mathrm{P}\{1 + 1/(T_\mathrm{I}s)\} = K_\mathrm{P}(s + 1/T_\mathrm{I})/s`$ は、$`K_\mathrm{P}`$ と、$`\omega_\mathrm{z1} = 1/T_\mathrm{I}`$、$`\omega_\mathrm{p1} = 0`$ の遅れ補償器の積である。
- 不完全微分の PID: 3 つの項 $`1`$、$`1/(T_\mathrm{I}s)`$、$`T_\mathrm{D}s/\{1 + (T_\mathrm{D}/N)s\}`$ を、分母 $`T_\mathrm{I}s\{1 + (T_\mathrm{D}/N)s\}`$ で通分する。分子は $`T_\mathrm{I}s\{1 + (T_\mathrm{D}/N)s\} + \{1 + (T_\mathrm{D}/N)s\} + T_\mathrm{I}T_\mathrm{D}s^2`$ で、$`s`$ の次数ごとにまとめると

$$
C(s) = K_\mathrm{P}\,\frac{T_\mathrm{I}(1 + 1/N)T_\mathrm{D}s^2 + (T_\mathrm{I} + T_\mathrm{D}/N)s + 1}{T_\mathrm{I}s\{1 + (T_\mathrm{D}/N)s\}}
$$

である。分子の 2 次式の根が実数 $`-z_1`$・$`-z_2`$（$`0 < z_1 < z_2`$）なら、分子は $`T_\mathrm{I}(1 + 1/N)T_\mathrm{D}(s + z_1)(s + z_2)`$、分母は $`T_\mathrm{I}(T_\mathrm{D}/N)s(s + N/T_\mathrm{D})`$ と書ける。係数の比は $`(1 + 1/N)N = N + 1`$ なので

$$
C(s) = K_\mathrm{P}(N + 1)\,\frac{s + z_1}{s} \cdot \frac{s + z_2}{s + N/T_\mathrm{D}}
$$

となる ∎

1 つ目の分数は、原点に極を置いた遅れ補償器、2 つ目の分数は、折れ点 $`z_2`$ と $`N/T_\mathrm{D}`$ の進み補償器（低い角周波数のゲインが 1 になるように書いた $`C_\mathrm{lead}`$ に、定数 $`z_2/(N/T_\mathrm{D})`$ を掛けたもの）である。不完全微分の PID は、遅れ補償器の極を原点に置いた進み遅れ補償器にほかならない。

10 章 5 節のモータの位置の PID（$`K_\mathrm{P}`$ = 0.84 V/rad、$`T_\mathrm{I}`$ = 0.168 s、$`T_\mathrm{D}`$ = 0.0238 s）に、10 章 6 節の $`N`$ = 10 を入れると、$`z_1`$ = 7.21、$`z_2`$ = 31.5 rad/s で、極は 0 と −420 である。遅れ補償器の部分は $`(s + 7.21)/s`$、進み補償器の部分は折れ点 31.5 と 420 rad/s で、$`\alpha`$ = 13.3、山の中心 √(31.5 × 420) = 115 rad/s、最大位相進み 59.4° である。

```fig

```

一巡伝達関数の交差は 27.8 rad/s、位相余裕は 58.8° で、交差での位相は、進み補償器の部分が +37.7°、遅れ補償器の部分が −14.5° である。進みの山の中心 115 rad/s は交差の約 4 倍上にあり、山の頂の 59.4° のうち 37.7° しか使っていない。3 節の手順のように山の中心を交差に合わせれば、同じ 37.7° は $`\alpha`$ = 4.1 で得られる。PID が進み遅れ補償の特別な場合だというのは、次の 3 点である。

- 遅れ補償器の極が原点に固定されている（$`\omega_\mathrm{p1}`$ = 0）。遅い角周波数のゲインが限りなく大きく、型が 1 つ上がるので、一定の外乱による偏差が 0 になる（7 章 4 節）。$`\omega_\mathrm{p1} > 0`$ の遅れ補償器では、偏差は小さくなるが 0 にはならない。
- 進み補償器の部分の $`\alpha`$ が $`N`$ で決まり（D 動作だけなら $`\alpha = N + 1`$）、山の位置は $`T_\mathrm{D}`$ と $`N`$ で決まる。山の中心が交差に合うとは限らない。
- 決める値が、不完全微分の PID の 4 つ（$`K_\mathrm{P}`$・$`T_\mathrm{I}`$・$`T_\mathrm{D}`$・$`N`$）に対し、進み遅れ補償器は 5 つ（$`K_\mathrm{c}`$ と 4 つの折れ点）である。

補償器と PID の対応を並べる。

| 補償器 | 零点と極 | PID の言葉 |
|---|---|---|
| 遅れ補償器で $`\omega_\mathrm{p1}`$ = 0 | 零点 $`-\omega_\mathrm{z1}`$、極は原点 | PI 制御（$`T_\mathrm{I} = 1/\omega_\mathrm{z1}`$） |
| 進み補償器で $`\omega_\mathrm{p2}`$ を限りなく大きく | 零点 $`-\omega_\mathrm{z2}`$ だけ | PD 制御（$`T_\mathrm{D} = 1/\omega_\mathrm{z2}`$） |
| 進み補償器 | 零点 $`-\omega_\mathrm{z2}`$、極 $`-\omega_\mathrm{p2}`$ | 不完全微分の PD（$`N = \alpha - 1`$、$`T_\mathrm{D} = N/\omega_\mathrm{p2}`$） |
| 進み遅れ補償器で $`\omega_\mathrm{p1}`$ = 0 | 零点 2 つ、極は原点と $`-\omega_\mathrm{p2}`$ | 不完全微分の PID |

3 節の進み補償器（$`\alpha`$ = 3、$`\omega_\mathrm{p2}`$ = 52.0 rad/s、$`K_\mathrm{c}`$ = 0.625 V/rad）は、$`N`$ = 2、$`T_\mathrm{D}`$ = 2/52.0 = 0.0385 s、$`K_\mathrm{P}`$ = 0.625 V/rad の不完全微分の PD と同じものである。

根軌跡（12 章 4 節）で見ると、進み補償器は、零点と、それより左の極を足す。零点が軌跡を左へ引き寄せ、遠くの極は、軌跡を遠くで曲げ戻すだけである。遅れ補償器は、原点の近くに極と零点の組を足す。組から離れた点では、極からの矢印と零点からの矢印の角度がほとんど同じで打ち消し合うので、交差に対応する閉ループの極はほとんど動かず、組の近くに遅い極が 1 つ増える（2 節の尾）。

## 5. 速さと余裕の限界 — 水床効果と右半平面の零点

2〜4 節の補償器で、ボード線図の形はかなり自由に整えられる。この節では、それでも越えられない限りを調べる。交差を上げると何が足りなくなるのか、遅い角周波数で感度関数を下げることに代償は無いのか、対象そのものが限りを決めることはあるのか、の 3 つである。

### 交差を上げると位相が足りなくなる

3 節の手順で、モータの位置の交差角周波数を上げていく。$`L_\mathrm{a}`$ を含めた対象 $`P(s) = 2 \times 10^6/\{s(s + 20.2)(s + 1980)\}`$ rad/V（6 章 4 節）の位相は $`-90° - \arctan(\omega/20.2) - \arctan(\omega/1980)`$ で、200 rad/s で −180° に届く（9 章 5 節）。比例制御で残る位相余裕は、30 rad/s で 33.1°、60 rad/s で 16.9°、100 rad/s で 8.5° である。進み補償器で最大位相進みを足すと、$`\alpha`$ = 3 なら 30 rad/s で 63.1°、60 rad/s で 46.9°、100 rad/s で 38.5° になり、$`\alpha`$ = 10 なら 100 rad/s でも 63.4° 残る（下の図の (a)）。$`\alpha`$ を大きくすれば、位相だけは足せる。代わりに、制御器の高い角周波数のゲインが増える。

**方針**: 3 節の手順 4 の $`K_\mathrm{c}`$ から、高い角周波数のゲイン $`K_\mathrm{c}\alpha`$ を $`\omega_\mathrm{gc}`$ で表す。対象のゲインは、20 rad/s より十分に高い角周波数では簡単な形になる。

**導出**: $`L_\mathrm{a}`$ を無視した対象のゲインは $`|P(j\omega)| = 1000/\{\omega\sqrt{\omega^2 + 400}\}`$ で、$`\omega \gg 20`$ では $`\sqrt{\omega^2 + 400} \approx \omega`$ なので $`|P(j\omega)| \approx 1000/\omega^2`$ である。手順 4 から $`K_\mathrm{c} = 1/\{\sqrt\alpha\,|P(j\omega_\mathrm{gc})|\} \approx \omega_\mathrm{gc}^2/(1000\sqrt\alpha)`$ なので、高い角周波数のゲインは

$$
K_\mathrm{c}\alpha \approx \frac{\sqrt\alpha\,\omega_\mathrm{gc}^2}{1000}\ \text{V/rad}
$$

である ∎

対象のゲインが −40 dB/dec で下がる所で交差させるには、制御器が交差でそれを打ち消すゲインをもたなければならない。そのため、交差角周波数を 2 倍にすると、高い角周波数のゲインは 4 倍になる。1 節のとおり、速い観測ノイズはこのゲインで操作量に現れ、目標値を段差で変えた瞬間の操作量も、このゲイン × 段差になる。$`\alpha`$ = 3 では、60 rad/s で 6.5 V/rad、300 rad/s では 156 V/rad で、目標を 0.1 rad 変えるだけで 15.6 V を求め、12 V の電源では出せない（図の (b)。値は $`L_\mathrm{a}`$ を含めて計算した）。さらに、マイコンで計算すると、測ってから出すまでの遅れが位相を遅らせる（[15 章 2 節](15_サンプリングと離散化.md#零次ホールドとサンプリングの遅れ)）。交差を上げるほど位相が足りなくなり、位相を足すほど高い角周波数のゲインが増えて、ノイズと操作量の上限にぶつかる。

### 感度関数の山 — −1 の点との距離

1 節で、位相余裕が小さいと、交差のあたりで $`|S|`$ が 1 を越えて山を作ることを見た。感度関数のゲインの最大値

$$
M_\mathrm{s} = \max_\omega |S(j\omega)|
$$

を**最大感度**という。$`|1 + P(j\omega)C(j\omega)|`$ は、ナイキスト線図の点 $`P(j\omega)C(j\omega)`$ と −1 の点との距離なので（9 章 5 節）、$`1/M_\mathrm{s}`$ は、線図と −1 の点との最も近い距離である。11 章 1 節で、余裕を 1 つの数にまとめた評価指標として使った値でもある。$`M_\mathrm{s}`$ が小さいことは、ゲイン余裕と位相余裕が両方とも残っていることを保証する。

**方針**: ナイキスト線図は、−1 を中心とする半径 $`1/M_\mathrm{s}`$ の円の外を通る。線図が負の実軸を横切る点と、単位円を横切る点が、その円の外にある条件を書く。

**導出**: 位相交差角周波数の点は、負の実軸の上の $`-10^{-g_\mathrm{m}/20}`$ にあり（$`g_\mathrm{m}`$ はゲイン余裕 [dB]。9 章 5 節）、−1 との距離は $`1 - 10^{-g_\mathrm{m}/20}`$ である。これが $`1/M_\mathrm{s}`$ 以上なので $`10^{-g_\mathrm{m}/20} \le 1 - 1/M_\mathrm{s}`$、両辺の逆数をとって $`10^{g_\mathrm{m}/20} \ge M_\mathrm{s}/(M_\mathrm{s} - 1)`$ である。ゲイン交差角周波数の点は、単位円の上の $`-e^{j\phi_\mathrm{m}}`$ にあり、1 節の導出のとおり −1 との距離は $`2\sin(\phi_\mathrm{m}/2)`$ である。これが $`1/M_\mathrm{s}`$ 以上なので

$$
10^{g_\mathrm{m}/20} \ge \frac{M_\mathrm{s}}{M_\mathrm{s} - 1}, \qquad \phi_\mathrm{m} \ge 2\arcsin\frac{1}{2M_\mathrm{s}}
$$

となる ∎

| 最大感度 $`M_\mathrm{s}`$ | 1.2 | 1.4 | 1.7 | 2.0 |
|---|---|---|---|---|
| −1 の点との最も近い距離 $`1/M_\mathrm{s}`$ | 0.83 | 0.71 | 0.59 | 0.50 |
| ゲイン余裕の下限 | 6.0 倍（15.6 dB） | 3.5 倍（10.9 dB） | 2.4 倍（7.7 dB） | 2.0 倍（6.0 dB） |
| 位相余裕の下限 | 49.2° | 41.8° | 34.2° | 29.0° |

逆向きは成り立たない。9 章 5 節で、測った速度が 0.1 s 遅れる台車の比例制御（8 N/(m/s)）は、位相余裕が 60.1° あるのに 29.8 % 行き過ぎた。$`M_\mathrm{s}`$ は 2.03（距離 0.49、14.5 rad/s）で、位相余裕が同じ 60° の二次遅れの形のループ（9 章 5 節）の 1.34（距離 0.75）よりずっと大きい。むだ時間の位相の遅れが交差より上で急に増え、線図が単位円の内側で −1 の点に近づくからである。位相余裕は単位円の上の 1 点しか見ないが、最大感度は線図全体と −1 の点との距離を見る。$`M_\mathrm{s}`$ は 1.2〜2.0 程度に収めることが多い（目安）。

### 水床効果 — 感度を下げると、別の所で上がる

1 節のモータの位置の比例制御では、比例ゲインを 0.21・0.84・4 V/rad と上げると、$`|S| < 1`$ の角周波数の範囲（外乱を縮める範囲）は広がったが、最大感度も 1.28・1.81・3.35 と高くなった。これは、ゲインの選び方の問題ではなく、どの制御器でも避けられないことを示す。

**方針**: 一巡伝達関数の分母と分子の次数の差が 2 以上で、開ループの極がすべて左半平面か虚軸の上にあり、閉ループが安定なとき、$`\ln|S(j\omega)|`$ を $`\omega`$ について 0 から ∞ まで積分した値を求める。$`S`$ の分母と分子を、閉ループの極と開ループの極の因数に分けると、$`\ln|S|`$ は因数ごとの対数の和と差になる。因数の組ごとの積分を、実部の大きさで微分する方法で求め、最後に 12 章 3 節の「閉ループの極の和は変わらない」を使う。

**導出**: 一巡伝達関数を、分母の最も高い次の係数を 1 にした分数 $`P(s)C(s) = b(s)/a(s)`$（$`a`$ は $`n`$ 次、$`b`$ は $`m`$ 次、$`n - m \ge 2`$）と書く（12 章 1 節の書き方で、ゲインは $`b`$ に含める）。$`S = 1/(1 + b/a) = a(s)/\{a(s) + b(s)\}`$ で、分子 $`a(s)`$ の根は開ループの極 $`p_1, \ldots, p_n`$、分母 $`a(s) + b(s)`$ の根は閉ループの極 $`q_1, \ldots, q_n`$ である（どちらも最も高い次の係数は 1）。したがって

$$
\ln|S(j\omega)| = \sum_{i=1}^{n}\bigl(\ln|j\omega - p_i| - \ln|j\omega - q_i|\bigr)
$$

である。開ループの極と閉ループの極を 1 つずつ組にして、組ごとに積分する。

- (i) 実数の極 $`p = -a`$（$`a \ge 0`$）と $`q = -b`$（$`b > 0`$）の組では、$`\ln|j\omega + a| - \ln|j\omega + b| = \frac{1}{2}\ln\{(\omega^2 + a^2)/(\omega^2 + b^2)\}`$ である。この 0 から ∞ までの積分を $`F(a)`$ とおくと、$`a = b`$ では被積分関数が 0 なので $`F(b) = 0`$ である。$`a`$ で微分すると、$`\int_0^\infty d\omega/(\omega^2 + a^2) = \pi/(2a)`$ を使って $`dF/da = \int_0^\infty a/(\omega^2 + a^2)\,d\omega = \pi/2`$ で、$`a`$ によらない。したがって $`F(a) = (\pi/2)(a - b)`$ である。
- (ii) 共役な極の組 $`-\sigma \pm j\nu`$ の 2 つの因数の対数の和は、$`\frac{1}{2}\ln\{\sigma^2 + (\omega - \nu)^2\} + \frac{1}{2}\ln\{\sigma^2 + (\omega + \nu)^2\}`$ である。これを $`\nu`$ で微分して 0 から ∞ まで積分すると、$`\frac{1}{2}\bigl[\ln\{(\sigma^2 + (\omega + \nu)^2)/(\sigma^2 + (\omega - \nu)^2)\}\bigr]_0^\infty`$ = 0 になる（$`\omega = 0`$ でも ∞ でも、対数の中は 1）。したがって積分の値は $`\nu`$ によらず、$`\nu`$ = 0、つまり実部の大きさ $`\sigma`$ の実数の極 2 つと同じである。

(i) と (ii) から、どの極にも実部の大きさ $`|\mathrm{Re}\,p_i|`$・$`|\mathrm{Re}\,q_i|`$ を当てはめて

$$
\int_0^\infty \ln|S(j\omega)|\,d\omega = \frac{\pi}{2}\left(\sum_{i=1}^{n}|\mathrm{Re}\,p_i| - \sum_{i=1}^{n}|\mathrm{Re}\,q_i|\right)
$$

となる。どの極も左半平面か虚軸の上にあるので $`|\mathrm{Re}\,p_i| = -\mathrm{Re}\,p_i`$、$`|\mathrm{Re}\,q_i| = -\mathrm{Re}\,q_i`$ で、12 章 3 節のとおり $`n - m \ge 2`$ なら閉ループの極の和は開ループの極の和に等しい。したがって

$$
\int_0^\infty \ln|S(j\omega)|\,d\omega = 0
$$

である ∎

$`\ln|S|`$ は $`|S|`$ の dB に比例する（dB の値 = 8.69 × $`\ln|S|`$）ので、$`|S|`$ の dB を、対数でない目盛の角周波数に対して描くと、0 dB の線より下の面積と上の面積が等しい。$`|S| < 1`$ の所を広げたり深くしたりすると、$`|S| > 1`$ の所の面積が同じだけ増える。どこかの角周波数で感度関数のゲインを下げると、別の角周波数で上がるこの性質を**水床効果**という（水を入れたベッドの一か所を押し下げると、別の所が盛り上がることから）。

```fig
e13_waterbed
```

上の面積は、速い角周波数へ薄く広げることもできるはずである。しかし、1 節のとおり速い角周波数ではループのゲインを小さく保つ必要があり、$`|PC| \ll 1`$ の所では $`|S| \approx 1`$（$`\ln|S| \approx 0`$）なので、そこでは面積を受け持てない。面積を受け持てるのは交差のまわりの狭い範囲だけなので、山が高くなる。一方、遅れ補償器で遅い角周波数の $`|S|`$ を下げても、ふつうの目盛では遅い角周波数の幅が狭いので、下げた面積は小さい。0.21 V/rad の比例制御に 2 節の遅れ補償器（零点 1 rad/s、極 0.1 rad/s）を入れると、下の面積は 10.2 から 10.9 に 6 % 増えるだけで、最大感度は 1.28 から 1.32 にしか上がらない。遅れ補償で位相余裕がほとんど減らなかったことを、面積で見たものである。

導出の条件の外では、次のようになる。台車（遅れなし）は $`n - m = 1`$ で、積分は負になり（$`-(\pi/2) \times 8 = -4\pi`$。12 章 3 節のとおり、閉ループの極の和が開ループの極の和より 8 だけ左へずれるから）、$`|S|`$ はどの角周波数でも 1 以下である。しかし実際の対象には、測る遅れやモデルに無い速い極があるので、十分に速い角周波数では $`n - m \ge 2`$ と同じ形になる。むだ時間を含むループでも積分が 0 になることは、複素関数の積分を使って示されている（ここでは数値で確かめた。測った速度が 0.1 s 遅れる台車で、0 から 10⁶ rad/s までの積分は 0.0001 以下）。開ループに右半平面の極があると、上の導出でその極の $`|\mathrm{Re}\,p_i|`$ が $`+\mathrm{Re}\,p_i`$ になるので、積分は右半平面の極の実部の和の $`\pi`$ 倍と正になり、0 dB より上の面積のほうが大きくなる（倒立振子のような不安定な対象。18 章）。

### 右半平面の零点とむだ時間

対象が非最小位相（6 章 5 節）なら、制御器では越えられない限りがある。8 章 5 節で見たとおり、右半平面の零点 $`z`$（$`z > 0`$）の因数とむだ時間 $`L`$ は、ゲインを変えずに位相だけを遅らせる因数に分けられ、その遅れは $`2\arctan(\omega/z)`$ と $`\omega L`$ [rad] である。この遅れは、制御器で取り戻せない。右半平面の零点を制御器の右半平面の極で打ち消すと、約分した極が閉ループの極として残り（7 章 2 節。閉ループの極は約分する前の式から求める）、閉ループが不安定になる。むだ時間を打ち消す $`e^{+Ls}`$ は、$`L`$ 先の未来の値を使うので作れない（11 章 3 節）。

**方針**: 一巡伝達関数を、最小位相の部分と、ゲインを変えずに位相だけを遅らせる部分に分ける。最小位相の部分は、1 節のとおり交差のまわりの傾きを −20 dB/dec にすると、位相がおよそ −90° になる。位相余裕は 180° − 90° − （遅らせる部分の遅れ）なので、望む位相余裕 $`\phi_\mathrm{m}`$ から交差角周波数の上限を求める。

**導出**: 位相余裕は、右半平面の零点では $`90° - 2\arctan(\omega_\mathrm{gc}/z)`$、むだ時間では $`90° - (180°/\pi)\omega_\mathrm{gc}L`$ である。これが $`\phi_\mathrm{m}`$ 以上である条件は

$$
\omega_\mathrm{gc} \le z\tan\frac{90° - \phi_\mathrm{m}}{2}, \qquad \omega_\mathrm{gc} \le \frac{\pi}{180°} \cdot \frac{90° - \phi_\mathrm{m}}{L}
$$

で、$`\phi_\mathrm{m}`$ = 45° なら $`\omega_\mathrm{gc} \le 0.41z`$、$`\omega_\mathrm{gc} \le 0.79/L`$ である ∎

どちらも、最小位相の部分の位相を −90° とおいた見積もりで、目安である。交差を上げられる限りは、右半平面の零点の位置と、むだ時間の逆数で決まり、制御器の作り方によらない。

- 台車（測った速度の遅れ 0.1 s）: $`\omega_\mathrm{gc}`$ ≤ 7.9 rad/s。9 章 6 節の 8 N/(m/s) は 7.75 rad/s・位相余裕 60.1°、12 N/(m/s) は 11.8 rad/s・31.8° である。
- 温度の板（むだ時間 20 s）: $`\omega_\mathrm{gc}`$ ≤ 0.039 rad/s。9 章 6 節の 12 W/K は 0.0299 rad/s・59.5°、24 W/K は 0.0600 rad/s・23.2° である。
- ボイラの水位（6 章 5 節。$`G(s) = (-15s + 0.5)/\{s(10s + 1)\}`$ mm/(kg/s)、右半平面の零点 $`z`$ = 0.033 /s）: $`\omega_\mathrm{gc}`$ ≤ 0.014 rad/s。

ボイラを比例制御（給水の流量 = $`K_\mathrm{c}`$ × 水位の偏差。$`K_\mathrm{c}`$ [(kg/s)/mm] は例の値）すると、$`K_\mathrm{c}`$ = 0.02 では交差 0.0104 rad/s・位相余裕 66.7° で、水位の目標を上げると、初めに目標の変化の 18.8 % だけ逆へ下がってから、245 s で 2 % の幅に入る。0.04 にすると、交差は 0.024 rad/s に上がるが、位相余裕は 40.8° に減り、逆への動きは 45 %、行き過ぎは 30 % になる（$`K_\mathrm{c}`$ が 1/15 = 0.067 を越えると不安定）。見積もり（位相余裕 45° で 0.014 rad/s）は控えめな値だが、交差をその 2 倍近くにすると、このように逆への動きも行き過ぎも大きくなる。右半平面の零点の因数の遅れは交差の上昇とともに速く増え、制御器では取り戻せないので、補償器を工夫しても、見積もりから大きく離れた速さにはできない。

## 6. 設計の例 — モータの位置制御

1〜5 節の道具で、モータの角度の制御器を設計する。10 章の PD 制御（交差 29 rad/s、2 % 整定時間 0.207 s）の 2 倍の速さをねらい、一定の速さで回る目標にも小さな偏差で追従させる。仕様は次の 4 つとする（どれも例の値）。

1. ゲイン交差角周波数 60 rad/s。
2. 位相余裕 50° 以上（$`L_\mathrm{a}`$ を含めた対象で）。
3. 1 rad/s で回り続ける目標への定常偏差（定常速度偏差）が 0.002 rad 以下。7 章 3 節の表から、$`\lim_{s\to 0}sP(s)C(s) \ge`$ 500 /s である。
4. 目標の角度を 1 rad 変えた瞬間の電圧が 12 V を超えない。つまり、制御器の高い角周波数のゲインが 12 V/rad 以下。

設計には $`L_\mathrm{a}`$ を無視した $`P(s) = 1000/\{s(s + 20)\}`$ を使い、$`L_\mathrm{a}`$ の分は位相の遅れとして見込む。

**手順 1 — 進み補償器（3 節）**: 60 rad/s での対象の位相は −90° − arctan 3 = −161.6° で、比例制御の位相余裕は 18.4° である。$`L_\mathrm{a}`$ を含めた対象の位相は −163.1° で、1.6° 遅れる。足りない位相は、50° − 18.4° = 31.6° に、$`L_\mathrm{a}`$ の 1.6° と、手順 2 で足す遅れ補償器の分 5° を加えた 38.1° で、$`\alpha`$ = (1 + sin 38.1°)/(1 − sin 38.1°) = 4.23 である。余裕をもたせて $`\alpha`$ = 5（$`\phi_\mathrm{max}`$ = 41.8°）にする。$`\omega_\mathrm{z2}`$ = 60/√5 = 26.8 rad/s、$`\omega_\mathrm{p2}`$ = 60√5 = 134.2 rad/s、$`|P(j60)|`$ = 1000/(60 × √(60² + 20²)) = 0.264 なので、$`K_\mathrm{c}`$ = 1/(√5 × 0.264) = 1.70 V/rad である。高い角周波数のゲインは $`K_\mathrm{c}\alpha`$ = 8.49 V/rad で、仕様 4 を満たす。

**手順 2 — 遅れ補償器（2 節）**: 進み補償器だけでは $`\lim sP(s)C(s) = 50K_\mathrm{c}`$ = 84.9 /s（定常速度偏差 0.0118 rad）で、仕様 3 の 500 /s に足りない。倍率は 500 ÷ 84.9 = 5.9 以上なので、10 にする（849 /s、定常速度偏差 0.00118 rad）。零点は、まず 2 節の目安どおり $`\omega_\mathrm{gc}`$/10 = 6 rad/s、極は 0.6 rad/s に置く。

**手順 3 — 確かめる**: $`L_\mathrm{a}`$ を含めた対象で、交差は 60.7 rad/s、位相余裕は 53.4°、ゲイン余裕は 29.5 dB、最大感度は 1.39 で、仕様 1〜3 を満たす。しかし目標の 1 rad のステップへの応答は、行き過ぎ量 19.8 %、2 % 整定時間 0.19 s で、進み補償器だけのとき（11.4 %、0.083 s）よりかなり遅い。2 節で見たとおり、遅れ補償器の零点 −6 のすぐ左に閉ループの遅い極 −6.37 ができ、その項（最終値の 6.5 %、時定数 0.16 s）が尾を引くからである。

**手順 4 — 直す**: 尾の大きさは、遅い極と零点の近さで決まる。遅い極は、根軌跡の上で、遅れ補償器の零点を終点とする枝の上にあり（12 章 2 節。$`K_\mathrm{c}`$ を限りなく大きくすると、枝は開ループの零点で終わる）、そこでのループのゲインが大きいほど終点に近づく。遅れ補償器を原点に近づけるほど、そこでの一巡伝達関数のゲインは大きいので、遅い極は零点にいっそう近づき（零点からの距離の割合で見て）、項が小さくなる。倍率は 10 のまま、零点を 1.5 rad/s、極を 0.15 rad/s に下げると、遅い極は −1.52、その項は最終値の 1.6 % になり、行き過ぎ量 13.5 %、2 % 整定時間 0.107 s、位相余裕 57.3°、ゲイン余裕 29.8 dB、最大感度 1.35 になる。

$$
C(s) = 1.70\,\frac{s + 1.5}{s + 0.15} \cdot \frac{1 + s/26.8}{1 + s/134.2}\ \text{V/rad}
$$

代わりに、一定の速さで回る目標への偏差が 0.00118 rad に落ち着くまでの時間が延びる。偏差が 0.002 rad を下回るのは、零点 6 rad/s では 0.40 s 後だが、1.5 rad/s では 1.68 s 後である。目標値のステップへの尾を小さくするか、ランプへの偏差を早く小さくするかの釣り合いで、零点の位置を選ぶ。電圧の最大は、目標を 1 rad 変えた瞬間の 8.49 V で、12 V に収まる。10 章 3 節の観測ノイズ（標準偏差 0.002 rad、1 ms ごとに変わる値）による電圧の揺れは標準偏差 0.017 V で、10 章 6 節の不完全微分の PD（$`N`$ = 10）と同じ程度である。負荷トルク 0.01 N·m（電圧に換算して −1 V。7 章 4 節）による角度のずれは、遅れ補償器が遅い角周波数のゲインを 10 倍にしたので、1 ÷ (1.70 × 10) = 0.059 rad に収まる。

|---|---|---|---|---|---|---|
| 比例（0.21 V/rad。4 章 6 節） | 9.50 rad/s | 64.5° | 5.0 % | 0.412 s | 0.0952 rad | 0.21 V/rad |
| PD（10 章 3 節。D 動作は測った角度に掛ける） | 29.1 rad/s | 68.7° | 5.0 % | 0.205 s | 0.0238 rad | 限りなく大きい |
| 進み補償（3 節） | 30.2 rad/s | 62.9° | 5.5 % | 0.122 s | 0.0320 rad | 1.87 V/rad |
| 進み遅れ補償（この節） | 60.4 rad/s | 57.3° | 13.5 % | 0.107 s | 0.00118 rad | 8.49 V/rad |

交差を 2 倍にした分だけ、立ち上がりは速くなる（立ち上がり時間は進み補償の 0.045 s に対し 0.020 s）。行き過ぎ量は位相余裕 50° 台に見合う値まで増えたが、目標値への行き過ぎは、外乱への応答を変えずに目標値の通り道だけを整える方法（10 章 6 節の目標値の重みや、[14 章 1 節](14_フィードフォワードとカスケード.md#2-自由度制御-目標値への応答と外乱への応答を分ける)の 2 自由度制御）で減らせる。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 感度関数の近似 | $`|PC| \gg 1`$ で $`|S| \approx 1/|PC|`$、$`|PC| \ll 1`$ で $`|G_{yr}| \approx |PC|`$（三角不等式で挟む）。速いノイズは制御器のゲイン $`|C|`$ のまま操作量に現れる |
| 交差のまわり | $`|S(j\omega_\mathrm{gc})| = |G_{yr}(j\omega_\mathrm{gc})| = 1/\{2\sin(\phi_\mathrm{m}/2)\}`$。閉ループのバンド幅は $`\omega_\mathrm{gc}`$ の少し上（モータの位置の比例制御で 1.56〜1.60 倍）。交差のまわりの傾きを −20 dB/dec 程度にして位相余裕を残す |
| ループ整形 | 一巡伝達関数のゲインの線が、遅い角周波数で高く、交差のまわりで −20 dB/dec 程度の傾きで 0 dB を横切り、速い角周波数で低くなるように、制御器の零点と極を選ぶ設計の方法 |
| 位相遅れ補償 | $`(s + \omega_\mathrm{z1})/(s + \omega_\mathrm{p1})`$（$`\omega_\mathrm{p1} < \omega_\mathrm{z1}`$）を直列に入れ、遅い角周波数のゲインを $`\omega_\mathrm{z1}/\omega_\mathrm{p1}`$ 倍にする。零点を交差の 1/10 に置けば、交差での遅れは約 5°。閉ループに遅い極を作り、尾を残す（台車: 定常偏差 0.2 → 0.024 m/s、ノイズの揺れは変わらず、2 % 整定時間 2.74 s） |
| 位相進み補償・最大位相進み | $`(1 + s/\omega_\mathrm{z2})/(1 + s/\omega_\mathrm{p2})`$、$`\alpha = \omega_\mathrm{p2}/\omega_\mathrm{z2}`$ を直列に入れ、交差の位相を進める／$`\omega_\mathrm{c} = \sqrt{\omega_\mathrm{z2}\omega_\mathrm{p2}}`$ での $`\sin\phi_\mathrm{max} = (\alpha - 1)/(\alpha + 1)`$。山の頂を交差に合わせ、$`K_\mathrm{c} = 1/\{\sqrt\alpha|P(j\omega_\mathrm{gc})|\}`$。高い角周波数のゲインは $`\alpha`$ 倍（モータ: 30 rad/s で位相余裕 33.7° → 63.7°） |
| 進み遅れ補償と PID | 遅れ補償器と進み補償器の直列。不完全微分の PID は、遅れ補償器の極を原点に置いた進み遅れ補償器で、PD の部分は $`\alpha = N + 1`$ の進み補償器。山の位置は $`T_\mathrm{D}`$ と $`N`$ で決まり、交差に合うとは限らない |
| 最大感度 | $`M_\mathrm{s} = \max|S(j\omega)|`$。$`1/M_\mathrm{s}`$ がナイキスト線図と −1 の点との最短距離。ゲイン余裕 ≥ $`M_\mathrm{s}/(M_\mathrm{s} - 1)`$ 倍、位相余裕 ≥ $`2\arcsin\{1/(2M_\mathrm{s})\}`$。逆は成り立たない（台車、遅れ 0.1 s: 位相余裕 60.1° で $`M_\mathrm{s}`$ = 2.03） |
| 水床効果 | 次数の差 2 以上で開ループが安定なら $`\int_0^\infty \ln|S(j\omega)|\,d\omega = 0`$。どこかで感度を下げると別の所で上がる。速い角周波数は面積を受け持てないので、交差のまわりの山が高くなる |
| 速さの限り | 交差を上げるには、高い角周波数のゲインを $`\omega_\mathrm{gc}^2`$ に比例して上げる必要がある（モータ: $`\sqrt\alpha\,\omega_\mathrm{gc}^2/1000`$ V/rad）。右半平面の零点 $`z`$ とむだ時間 $`L`$ では、位相余裕 45° なら $`\omega_\mathrm{gc} \le 0.41z`$・$`0.79/L`$（目安） |
| 設計の手順 | 進み補償器で交差と位相余裕を、遅れ補償器で遅い角周波数のゲインを決め、モデルに無い遅れと遅れ補償器の分を見込む。時間の応答で尾を確かめて直す（モータ: 交差 60 rad/s・位相余裕 57.3°・定常速度偏差 0.00118 rad・最大 8.49 V） |

この章では、1 つのフィードバックの輪の形を整え、同じ制御器で目標値への追従と外乱の抑えを決めた。そのため、外乱を速く抑えようと交差を上げると、目標値への行き過ぎも増えた。次章では、目標値への応答と外乱への応答を別々に決める 2 自由度制御、測れる外乱を先に打ち消すフィードフォワード、内側に速いループを置くカスケード制御、むだ時間を補うスミス予測器を扱う。
