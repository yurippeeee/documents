# 00. 目次と学習の進め方

## このシリーズの狙い

統計学は、ひとことで言えば「**不確かな情報から、それでも間違いの少ない判断を下すための技術**」である。

世の中のデータには必ずばらつきがある。同じ薬を同じ量だけ飲んでも効き方は人によって違うし、
同じ広告を出しても売上は日によって上下する。
そのばらつきの中から「本当にある差」と「たまたま出た差」を見分けること——これが統計の仕事である。

このシリーズは全 26 章で、次の 3 つを同時に満たすことを目標にする。

1. **式をごまかさない。** 「こういう公式があります」で終わらせず、どこから来た式なのかを毎回導出する。
2. **意味を言葉で説明する。** 式が何を言っているのか、日常の言葉に翻訳する。
3. **手を動かせる。** 全章にブラウザ上で数値を動かせるデモを置く。分布の形が変わる、信頼区間が動く、p 値が変わる、を目で見る。

読み終えたとき、「教科書の公式を当てはめる人」ではなく、
「**目の前のデータに対して、どの道具をなぜ選ぶかを説明できる人**」になっていることを目指す。

## 読み方

- **順番に読むのが基本**。第 II 部の確率は第 III 部以降のすべての土台になる。
- 数式が続いて苦しくなったら、その節の**デモを先に触る**とよい。何を計算しているのかが先に分かると、式が読める。
- 各章の冒頭に「**この章がなぜ必要なのか**」を置いた。目的を見失ったらそこに戻る。

## 前提知識

- **必須**: 四則演算、平方根、Σ 記号の読み方（意味は 02 章で説明する）。
- **あると楽**: 微分・積分（連続分布で使う。使う箇所では都度説明する）、行列（19 章で使う。最低限は章内で説明する）。
- **不要**: 測度論。このシリーズは測度論を使わずに書いてある。

## 記法の約束

| 記号 | 意味 |
|---|---|
| $`X, Y`$ | 確率変数（大文字） |
| $`x, y`$ | 実現値・観測値（小文字） |
| $`\mu, \sigma^2`$ | 母集団のパラメータ（母平均・母分散）— **知りたいが分からない値** |
| $`\bar{x}, s^2`$ | 標本統計量（標本平均・不偏分散）— **手元のデータから計算できる値** |
| $`\hat{\theta}`$ | パラメータ $`\theta`$ の推定量（ハットは「推定値」の印） |
| $`n`$ | 標本サイズ |
| $`P(A)`$ | 事象 $`A`$ の確率 |
| $`E[X], V[X]`$ | $`X`$ の期待値・分散 |

> **この区別が全部の要である.** ギリシャ文字（$`\mu`$, $`\sigma`$）は**神様しか知らない真の値**、
> ラテン文字（$`\bar{x}`$, $`s`$）は**私たちが計算できる値**。
> 統計とは「ラテン文字からギリシャ文字を推し量る技術」だと思っておくと、この先の話がすべて一本の筋に見える。
