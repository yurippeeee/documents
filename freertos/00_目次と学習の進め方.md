# 00. 目次と学習の進め方

## このシリーズの狙い

**OS とは何をするものか**を、FreeRTOS という具体的な題材を通して理解する。

OS の教科書は数多くあるが、その多くは Linux や Windows のような大きな OS を扱う。
それらは強力だが、**中身が大きすぎて「OS の芯」が見えにくい**。
仮想記憶、ファイルシステム、ソケット、ユーザ空間とカーネル空間の分離——
どれも重要だが、どれも「OS の本質」ではなく「大きな OS が追加で持っている機能」である。

FreeRTOS は違う。カーネル本体は **C 言語で 1 万行に満たない**。
それでいて、OS が OS であるための中核——

- **複数の処理を、あたかも同時に走っているかのように見せる**（タスクとスケジューラ）
- **待っている処理を止め、条件が整ったら再開する**（ブロックと起床）
- **複数の処理が同じ資源を壊さないようにする**（排他制御）
- **時間を管理する**（ティック、タイマ、遅延）

——を、すべて備えている。

**大きな OS のカーネルも、この芯の部分は驚くほど同じ論理でできている。**
Linux の `schedule()` と FreeRTOS の `vTaskSwitchContext()` は、規模も複雑さも桁違いだが、
やっていることの骨格は同じである。だから FreeRTOS を読み切ると、
「OS とはこういうものだ」という感覚が手に入る。

> **このシリーズはハードウェア固有の話を扱わない.**
>
> FreeRTOS には **移植層（ポートレイヤ）** という部分があり、
> ここには CPU ごとのアセンブラが入っている。ARM Cortex-M の `PendSV` ハンドラ、
> RISC-V の `mret`、Xtensa のウィンドウレジスタ——**これらはキリがなく、しかも本質ではない**。
>
> このシリーズは**「移植層が何を約束してくれるか」という契約だけを定義**し、
> その中身には踏み込まない。契約さえ分かれば、カーネルのロジックは完全に追える。
> 実際、移植層は「レジスタを退避して、スタックポインタを差し替えて、復帰する」以上のことはしていない。

## 何を題材にするか

FreeRTOS のカーネル本体は、たった 5 つのソースファイルでできている。

| ファイル | 中身 | このシリーズの章 |
|---|---|---|
| `tasks.c` | タスク管理とスケジューラ。**カーネルの心臓** | 04〜10 |
| `queue.c` | キュー、セマフォ、ミューテックス（**全部これ 1 本**） | 11〜13 |
| `list.c` | 双方向リンクリスト。全データ構造の土台 | 07 |
| `timers.c` | ソフトウェアタイマ | 15 |
| `event_groups.c` | イベントグループ | 14 |
| `heap_N.c` | メモリ確保（5 つの実装から 1 つ選ぶ） | 16 |

このうち `tasks.c` と `queue.c` の 2 本が全体の 8 割を占める。
**この 2 本を読み切ることが、このシリーズの実質的なゴール**である。

## 全体構成

| 部 | 章 | 内容 |
|---|---|---|
| **第 I 部: なぜ OS が要るのか** | 01〜03 | OS なしの世界・タスクという抽象・FreeRTOS の地図 |
| **第 II 部: スケジューラの中核** | 04〜09 | 状態機械・コンテキストスイッチ・優先度・Ready リスト・ティック・アイドル |

## 読み方

**順番に読むのが基本**。特に 04〜07 章（状態機械・コンテキストスイッチ・優先度・Ready リスト）は、
以降の全章で前提になる。この 4 章さえ腹に落ちれば、残りは応用である。

一方で、**11 章（キュー）は早めに読んでもよい**。
FreeRTOS ではセマフォもミューテックスも「キューの特殊形」なので、
キューを理解すると 12〜13 章が一瞬で終わる。

### 目的別の近道

| 目的 | ルート |
|---|---|
| OS の芯だけ知りたい | 02 → 04 → 05 → 06 → 07 → 10 |
| とりあえず FreeRTOS を使いたい | 03 → 04 → 06 → 11 → 12 → 18 |
| バグに苦しんでいる | 17 → 18 → 19 → 21 |
| 応答時間を保証したい | 06 → 08 → 13 → 18 → 20 |
| 省メモリで作りたい | 14 → 16 → 17 |
| 他の OS へ移りたい | 02 → 04 → 11 → 22 |
| ぜんぶ | 01 → 22（推奨） |

## 前提知識

| 分野 | 必要な水準 |
|---|---|
| C 言語 | ポインタと構造体。関数ポインタが読めると楽 |
| 計算機の基礎 | スタック・レジスタ・割り込みが「何をするものか」 |
| データ構造 | リンクリストの操作。02〜07 章で必要な範囲は説明する |
| アセンブラ | **不要**。このシリーズでは扱わない |

## 記法の約束

| 表記 | 意味 |
|---|---|
| `xTaskCreate` | FreeRTOS の API はソースの表記そのままで書く |
| **タスク** | FreeRTOS の実行単位。他の OS の「スレッド」に相当する |
| **カーネル** | FreeRTOS のスケジューラとカーネルオブジェクトの実装本体 |
| **移植層** | CPU 依存部（`port.c` / `portmacro.h`）。**中身は扱わない** |
| ティック | カーネルが時間を刻む周期割り込み。既定で 1 ms |

> **バージョンについて.** このシリーズは FreeRTOS カーネル v10 系〜v11 系を想定している。
> v11 で SMP（マルチコア）対応が本体に取り込まれたが、
> **本シリーズは単一コアを前提に説明する**。SMP は 22 章で触れるにとどめる。
> 論理の骨格は v8 の頃からほとんど変わっていないので、多少バージョンが違っても読める。

> **ソースを手元に置いてほしい.** FreeRTOS は MIT ライセンスで公開されている。
> `git clone https://github.com/FreeRTOS/FreeRTOS-Kernel` で取得できる。
> このシリーズは**ソースを読むための地図**である。地図だけ見ても土地は分からない。
