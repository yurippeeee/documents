# 15. モード — 同じ 7 音で、中心の音を変える

> **この章で扱う問い.**
> 05〜14 章では、長音階と短音階を土台にした長調・短調の中で、和音と進行を組み立ててきた。この章では、長音階と同じ 7 つの音を使いながら、主音だけを別の音に選び直した音階を扱う。
>
> この章では次の 3 つの問いに答える。
>
> 1. 同じ 7 つの音でも、主音を変えると響きが変わるのはなぜか。

> 3. それぞれの音階らしさは、どの音と、どの和音から生まれるのか。
>
> 答えの道具は、05 章の全音・半音の並びと完全 5 度の連なり、07 章の五度圏である。

## 1. 中心の音を変えると響きが変わる

[05 章 2 節](05_長音階.md#長音階-全-全-半-全-全-全-半の並び)で、C から次の C まで白鍵だけを順に並べると、となりどうしの間隔が「全・全・半・全・全・全・半」になることを見た。この並びの音階が長音階で、ここでの主音は C である。

使う鍵を同じ 7 つの白鍵のままにして、今度は D から次の D までを並べてみる。

```fig
e15_shift
```

半音の間隔は、どちらも E–F と B–C の 2 か所にあり、鍵盤の上での位置は変わらない（[02 章 2 節](02_音名と鍵盤と五線.md#音名-7-つの文字と-♯-♭)）。変わるのは、主音から数えて何番目の間隔が半音か、である。C から数えると 3 番目と 7 番目の間隔が半音だが、D から数えると 2 番目と 6 番目になる。D からの並び「全・半・全・全・全・半・全」は、C からの並びの最初の「全」を最後へ回したものである。

```play
notes: C4 D4 E4 F4 G4 A4 B4 C5:2
mode: seq
label: 白鍵を C から C まで（C 長音階）
show: kbd staff
tempo: 112
```

```play
notes: D4 E4 F4 G4 A4 B4 C5 D5:2
mode: seq
label: 同じ白鍵を D から D まで
show: kbd staff
tempo: 112
```

並びが変わると、主音から見た音程が変わる。主音からそれぞれの音までの音程を、2 つの並べ方で比べると次のようになる。

| 主音からの度数 | 2 度 | 3 度 | 4 度 | 5 度 | 6 度 | 7 度 |
|---|---|---|---|---|---|---|
| C から（C–D, C–E, …） | 長 2 度 | 長 3 度 | 完全 4 度 | 完全 5 度 | 長 6 度 | 長 7 度 |
| D から（D–E, D–F, …） | 長 2 度 | **短 3 度** | 完全 4 度 | 完全 5 度 | 長 6 度 | **短 7 度** |

D から並べると、3 度と 7 度が短くなる。特に、主音の上の 3 度が短 3 度（D–F、半音 3）になることが大きい。[06 章 2 節](06_短音階.md#長音階と短音階の違い-主音から見た-3-度-6-度-7-度)で見たように、主音の上の 3 度が長 3 度か短 3 度かは、音階全体の響きの違いの中心になる。

ただし、上の 2 つを鳴らし比べても、D が中心に聞こえるとは限らない。音階を上がっていくだけでは、どの音が中心かを耳が決めにくいからである（C 長音階を聞き慣れていると、D から並べても C が中心のように聞こえることがある）。

中心の音をはっきりさせる方法として昔から使われてきたのが、主音を低い音で鳴らし続けることである。旋律の下で、同じ高さのまま途切れずに鳴らし続ける音を**ドローン**という。バグパイプの、旋律の下で鳴り続ける低い音がその例である。

```fig
e15_drone
```

ドローンが鳴っている間、旋律のどの音も、ドローンの音からの音程として聞こえる。旋律が D に来ると、ドローンの D と 1 オクターブ（または 2 オクターブ）の関係で重なり、倍音どうしが一致して溶け合う（[04 章 4 節](04_協和と不協和.md#倍音どうしのぶつかり-スペクトルで見る)）。そのため D が、旋律が戻って落ち着く中心として聞こえやすくなる。

```play
label: D のドローンの上で、白鍵を D から D まで上がって下がる
v1: D4 E4 F4 G4 A4 B4 C5 D5 C5 B4 A4 G4 F4 E4 D4:2
v2: D3:4 D3:4 D3:4 D3:4
show: kbd staff
timbre: organ
tempo: 112
```

```play
label: C のドローンの上で、白鍵を C から C まで上がって下がる
v1: C4 D4 E4 F4 G4 A4 B4 C5 B4 A4 G4 F4 E4 D4 C4:2
v2: C3:4 C3:4 C3:4 C3:4
show: kbd staff
timbre: organ
tempo: 112
```

使っている 7 つの鍵はまったく同じだが、ドローンで中心を決めると、響きの違いがはっきりする。D を中心にしたほうは、主音の上の 3 度が短 3 度なので、06 章の短音階に近い響きに聞こえる。

このように、ある長音階の 7 つの音をそのまま使い、7 つのうちのどれを主音にするかを決めて並べた音階を、まとめて**モード**（**旋法**）という。主音の決め方は 7 通りあるので、モードは 7 種類ある（元の長音階の主音のままのものも 1 つに数える）。なお「モード」は、ほかの音階から同じように主音を選び直したものや、中世ヨーロッパの教会音楽の旋法の体系を指すこともある。この章では、長音階から作る 7 つだけを扱う。

## 2. 7 つのモードの並び

白鍵の 7 つの音を 1 つずつ主音にすると、7 つのモードができる。C を主音にしたものを**イオニアン**（Ionian）、D を主音にしたものを**ドリアン**（Dorian）、E を**フリジアン**（Phrygian）、F を**リディアン**（Lydian）、G を**ミクソリディアン**（Mixolydian）、A を**エオリアン**（Aeolian）、B を**ロクリアン**（Locrian）という。

名前は古代ギリシャとその周りの地方や民族の名前から取られているが、古代ギリシャで同じ名前が指していた音階とは対応が異なる。クラシック音楽の本では、ドリア旋法・フリギア旋法のようにも呼ぶ。以下では、D を主音とするドリアンを「D ドリアン」のように、主音の音名を前に付けて呼ぶ。

```fig
e15_seven
```

- 7 つの並びは、どれも同じ「全・全・半・全・全・全・半」の輪を、違う位置から読んだものである。主音を白鍵 1 つ分右へずらすと、並びの先頭の 1 つが最後へ回る。そのため、図の「半」は斜めに並ぶ。
- 2 つの「半」の間には、片側に「全」が 2 つ（C–D–E）、反対側に「全」が 3 つ（F–G–A–B）ある。どのモードも、この 2 つの「半」が、主音から数えて何番目に来るかで区別できる。
- イオニアンの並びは長音階（05 章）そのものであり、エオリアンの並びは自然短音階（[06 章 1 節](06_短音階.md#自然短音階-長音階の第-6-音から始める)）と同じである。06 章で、C 長音階の第 6 音 A から並べて作った自然短音階は、A エオリアンのことである。

つまり、これまでの章で扱ってきた長音階と自然短音階は、7 つのモードのうちの 2 つである。

下の図で主音にする白鍵を選ぶと、7 つの白鍵の中での位置と、全・半の並び、主音の上の 3 度が表示され、ドローンの上で音階が鳴る。

## 3. 同じ主音で比べる — 明るさの順

2 節の 7 つのモードは、主音がすべて違う。主音の高さの違いに惑わされずに響きを比べるため、ここでは主音をそろえて比べる。

### どの音を主音にしても作れる

モードは全・半の並びで決まる。そのため、[05 章 3 節](05_長音階.md#どの音からでも作れる-♯-♭-が必要になる理由)で長音階をどの音からでも作ったのと同じように、並びを保てば、どの音を主音にしても同じモードが作れる。綴り方も同じで、7 つの文字を 1 回ずつ使う。

**例**: E ドリアンは、E からドリアンの並び（全・半・全・全・全・半・全）で音を選ぶと、E F♯ G A B C♯ D になる。白鍵だけの D ドリアンと全・半の並びは同じで、F と C が半音上がって F♯・C♯ になる。

```fig
e15_edorian
```

```play
label: E のドローンの上で、E ドリアンを上がって下がる
v1: E4 F#4 G4 A4 B4 C#5 D5 E5 D5 C#5 B4 A4 G4 F#4 E4:2
v2: E3:4 E3:4 E3:4 E3:4
show: kbd staff
timbre: organ
tempo: 112
```

### C の上に 7 つのモードを作る

同じ方法で、7 つのモードをすべて C の上に作り、C 長音階（C イオニアン）と比べる。比べるために、主音が同じ長音階の第$`n`$音（[05 章 4 節](05_長音階.md#音階の第-1-音〜第-7-音と呼び名)）より半音低い音を ♭$`n`$、半音高い音を ♯$`n`$と書くことにする。主音が C なら、♭3 は E♭、♯4 は F♯ である。

```fig
e15_onc
```

### 変わった音の数で並べる

C 長音階と違う音の数で、7 つを並べ直す。♯ が 1 つのリディアンを先頭にし、変化の無いイオニアン、♭ が 1 つのミクソリディアン、2 つのドリアン、3 つのエオリアン、4 つのフリジアン、5 つのロクリアンの順にする。それぞれの音を、主音 C から半音いくつ上かの位置に点で置くと、次のようになる。

```fig
e15_ladder
```

上の段から下の段へ移るたびに、ちょうど 1 つの音だけが半音下がり、ほかの 6 つの音は変わらない。下がる音は、順に F♯ → F、B → B♭、E → E♭、A → A♭、D → D♭、G → G♭ である。

### なぜ 1 音ずつ下がるのか

**方針**: 白鍵の 7 つの音は、完全 5 度ずつ積むと F C G D A E B と 1 列に並ぶ（[05 章 5 節](05_長音階.md#長音階の成り立ち-2-つのテトラコルドと完全-5-度の連なり)）。7 つのモードの音をこの列の上に置き、主音 C を固定したまま、となりの段へ移るときにどの音が入れ替わるかを調べる。

```fig
e15_chain
```

**導出**: 列を左右へ延ばしたものを、以下「5 度の列」と呼ぶ。5 度の列の上で右へ 1 つ進むと完全 5 度上（半音 7 つ上）の音、左へ 1 つ進むと完全 5 度下の音である。

1. 5 度の列では、文字が F C G D A E B の順に 7 つごとにくり返す。右へ 7 つ進むと同じ文字に ♯ が 1 つ増え（F → F♯）、左へ 7 つ進むと ♭ が 1 つ増える（B → B♭）。これは [07 章 3 節](07_調と五度圏.md#5-度上の調は-♯-が-1-つ増える)の ♯ の順・♭ の順と同じ並びである。
2. 白鍵の 7 つの音は、5 度の列のとなり合う 7 つ（F から B まで）である。また、2 つの音の音程は、5 度の列の上で何個離れているかで決まる（たとえば長 2 度は右へ 2 個: C → G → D。完全 4 度は左へ 1 個: C → F）。そのため、すべての音を同じ音程だけ移すと、5 度の列の上でもすべての音が同じ数だけ移り、となり合う 7 つはとなり合ったままで、主音がその中の左から何番目にあるかも変わらない。どの主音のモードも、白鍵のモードをこのように移したものである。白鍵では F・C・G・D・A・E・B がそれぞれ左から 1〜7 番目なので、主音が左から 1 番目ならリディアン、2 番目ならイオニアン、3 番目ならミクソリディアン、4 番目ならドリアン、5 番目ならエオリアン、6 番目ならフリジアン、7 番目ならロクリアンである（図の各段）。
3. 主音を C に固定し、C が左から$`k`$番目にあるモードを考える（$`k = 1, 2, \dots, 7`$）。このモードは、C から左へ$`k - 1`$個目の音から、右へ$`7 - k`$個目の音までの 7 つを使う。$`k`$を 1 つ増やして次の段へ移ると、使う 7 つは 5 度の列の上で 1 つ左へずれる。右端にあった「C から右へ$`7 - k`$個目の音」が抜け、左端に「C から左へ$`k`$個目の音」が新しく入る。
4. 抜ける音と入る音は、5 度の列の上で$`(7 - k) + k = 7`$個離れている。1. より、2 つは同じ文字で、入る音のほうが ♭ が 1 つ多い（または ♯ が 1 つ少ない）。高さで見ると、完全 5 度 7 回分は

$$
7 \times 7 = 49 = 4 \times 12 + 1
$$

半音、つまり 4 オクターブと半音 1 つである。オクターブの違いを除けば、入る音は抜ける音のちょうど半音下になる。
5. したがって、次の段のモードは、前の段のモードの音を 1 つだけ、同じ文字のまま半音下げたものであり、ほかの 6 つの音は変わらない ∎

$`k = 1, 2, \dots, 6`$を順に当てはめると、抜ける音と入る音は F♯ → F、B → B♭、E → E♭、A → A♭、D → D♭、G → G♭ となり、はしごの図と一致する。ロクリアン（$`k = 7`$）からさらに 1 つ左へずらすと、抜けるのは右端の C、つまり主音そのものになる。リディアンから 1 つ右へずらしても、左端の C が抜ける。主音を C に保ったまま作れるモードが 7 つで終わるのはこのためである。

5 度の列の左から 2 番目に主音があればイオニアン、つまり長音階である。そのため、各段の 7 つの音は、その段の左から 2 番目の音を主音とする長音階と同じ音になる。C リディアンはト長調（G メジャー）、C イオニアンはハ長調（C メジャー）、C ミクソリディアンはヘ長調（F メジャー）、C ドリアンは変ロ長調（B♭ メジャー）、C エオリアンは変ホ長調（E♭ メジャー）、C フリジアンは変イ長調（A♭ メジャー）、C ロクリアンは変ニ長調（D♭ メジャー）と同じ 7 音を使う。調号（[07 章 2 節](07_調と五度圏.md#調号-音階の-♯-♭-を最初にまとめて書く)）の数は ♯ 1 → 0 → ♭ 1 → ♭ 2 → ♭ 3 → ♭ 4 → ♭ 5 と 1 つずつ変わり、五度圏（[07 章 4 節](07_調と五度圏.md#五度圏-24-の調を-1-つの円に並べる)）の上を ♭ が増える向きへ 1 つずつ進む並びになっている。たとえば C ドリアンの音は、変ロ長調の調号（B♭・E♭）で書ける。

### 明るさの順

このように、同じ主音の 7 つのモードは、高い音の多いリディアンから、低い音の多いロクリアンまで、1 音ずつ半音下がる 1 列に並ぶ。主音が同じなら、音階の音が高いほど明るく、低いほど暗く聞こえる、という見方から、この並びを**明るさの順**と呼ぶ。上の 3 つ（リディアン・イオニアン・ミクソリディアン）は主音の上の 3 度が長 3 度で、下の 4 つ（ドリアン・エオリアン・フリジアン・ロクリアン）は短 3 度である。06 章 2 節で長 3 度の響きを明るい、短 3 度の響きを暗いと表したのとも合っている。ただし明るい・暗いは、音楽の文化と慣れにもとづく印象の言葉であり、音の物理だけで決まる性質ではない。

```play
label: C のドローンの上で C リディアン（いちばん上の段）
v1: C4 D4 E4 F#4 G4 A4 B4 C5 B4 A4 G4 F#4 E4 D4 C4:2
v2: C3:4 C3:4 C3:4 C3:4
show: kbd staff
timbre: organ
tempo: 112
```

```play
label: C のドローンの上で C ロクリアン（いちばん下の段）
v1: C4 Db4 Eb4 F4 Gb4 Ab4 Bb4 C5 Bb4 Ab4 Gb4 F4 Eb4 Db4 C4:2
v2: C3:4 C3:4 C3:4 C3:4
show: kbd staff
timbre: organ
tempo: 112
```

下の図で主音と段を選ぶと、はしごの上の位置、1 つ上の段から半音下がった音、同じ 7 音を使う長調が表示される。「上の段から順に 7 つ」を押すと、ドローンの上で 7 つのモードを明るい順に続けて鳴らす。

## 4. 特性音とモードらしい和音

### 特性音

3 節で見たように、主音の上の 3 度が長 3 度のモードは 3 つ、短 3 度のモードは 4 つある。主音の上の 3 度が長 3 度のモードは長音階に、短 3 度のモードは自然短音階に近い響きに聞こえる。

そこで、それぞれのモードを、主音の上の 3 度が同じ基本の音階（長 3 度なら長音階、短 3 度なら自然短音階）と比べる。比べたときに違っている音を、そのモードの**特性音**という。

```fig
e15_char
```

| モード | 比べる音階 | 特性音（主音が C のとき） | 主音からの音程 |
|---|---|---|---|
| リディアン | 長音階 | ♯4（F♯） | 増 4 度 |
| ミクソリディアン | 長音階 | ♭7（B♭） | 短 7 度 |
| ドリアン | 自然短音階 | 6（A） | 長 6 度 |
| フリジアン | 自然短音階 | ♭2（D♭） | 短 2 度 |
| ロクリアン | 自然短音階 | ♭2（D♭）・♭5（G♭） | 短 2 度・減 5 度 |

イオニアンとエオリアンは、比べる音階そのものなので特性音を持たない。ロクリアンの ♭2 はフリジアンと共通なので、ロクリアンだけが持つ音は ♭5（減 5 度）である。どの特性音も、3 節のはしごの上で、比べる音階の段（イオニアンまたはエオリアン）からそのモードの段まで進む間に、半音動く音である。

### 特性音を含む和音

モードの響きは、旋律だけでなく和音でも出せる。基本の形は、主和音（主音を根音とする和音。[09 章 3 節](09_ダイアトニックコード.md#ディグリーネーム-調によらない書き方)）と、特性音を含む和音を交互にくり返すことである。主和音へ何度も戻ることで主音が中心に聞こえ、もう一方の和音で特性音が鳴る。主音を C として、代表的な例を示す（ディグリーネームは、主音が同じ長音階を基準に ♭ を付ける）。

```fig
e15_progs
```

- **リディアン**: I → II（C → D）。II（D・F♯・A）の 3 度の音 F♯ が特性音 ♯4 である。
- **ミクソリディアン**: I → ♭VII（C → B♭）。♭VII（B♭・D・F）の根音 B♭ が特性音 ♭7 である。
- **ドリアン**: Im7 → IV7（Cm7 → F7）。IV7（F・A・C・E♭）の 3 度の音 A が特性音 6 である。
- **フリジアン**: Im → ♭II（Cm → D♭）。♭II（D♭・F・A♭）の根音 D♭ が特性音 ♭2 である。

ドリアンの IV7 は、[10 章 3 節](10_和音の機能.md#ドミナントが主和音へ戻りたがる理由-導音と三全音)の V7 と同じ種類のセブンスコードだが、ここでは次の和音へ解決させるためではなく、特性音 A を含む響きとして使っている。

```play
label: C ドリアン: Im7 → IV7（Cm7 → F7）をくり返す
chords: Cm7:4 F7:4 Cm7:4 F7:4 Cm7:4
key: C
bass: on
show: chords kbd staff
```

```play
label: C ミクソリディアン: I → ♭VII（C → B♭）をくり返す
chords: C:4 B♭:4 C:4 B♭:4 C:4
key: C
bass: on
show: chords kbd staff
```

### 特性音だけを替えて比べる

響きの違いが特性音から来ていることは、特性音だけを、比べる音階の音に替えると確かめられる。ドリアンの IV7（F・A・C・E♭）の A を、自然短音階の A♭ に替えると IVm7（F・A♭・C・E♭）になる。リディアンの II（D・F♯・A）の F♯ を、長音階の F に替えると IIm（D・F・A）になる。どちらも違うのは 1 つの音だけである。

```fig
e15_compare
```

```play
label: 比べる: C エオリアン（C 自然短音階）の Im7 → IVm7（Cm7 → Fm7）
chords: Cm7:4 Fm7:4 Cm7:4 Fm7:4 Cm7:4
key: C
bass: on
show: chords kbd staff
```

上の C ドリアンの例と聞き比べると、違うのは F7 と Fm7 の中の A と A♭ だけだが、F7 のほうは短調の中に明るい音が 1 つ差し込むように聞こえ、Fm7 のほうはふつうの短調の響きに聞こえる。

下の図でモードと主音を選ぶと、特性音と比べる音階の音が表示される。「特性音を含む旋律」と「比べる音階で同じ旋律」は、特性音のところだけが違う同じ旋律である。和音の進行も、特性音を替えた進行と聞き比べられる。

## 5. モードの使われ方

### 主音をどう示すか

長調の音楽では、V7 → I の解決が主音を強く示す。V7 の 3 度の音は導音で、主音の半音下から主音へ進む（10 章 3 節）。7 つのモードの主和音と第 7 音を比べると、次のようになる。

```fig
e15_tonic
```

第 7 音が主音の半音下にある、つまり導音を持つのは、イオニアンとリディアンだけである。ほかの 5 つは、第 7 音が主音の全音下（♭7）にある。V7 まで作れるのはイオニアンだけで、リディアンでは第 4 音が ♯4 なので、G・B・D の上に F が無い。そのため、イオニアン以外のモードの音だけでは、V7 → I の解決が作れない。作ろうとして導音を足すと、モードに無い音が入り、長調・短調の響きに近づく。

モードを土台にした音楽では、代わりに、ドローンを鳴らす、主和音へ何度も戻る、旋律を主音で終える、といった方法で主音を示すことが多い。4 節の、主和音と特性音を含む和音を交互にくり返す形も、その 1 つである。

ロクリアンは、主音の上の 5 度が完全 5 度ではなく減 5 度（三全音）なので、主和音が減三和音になる。減三和音は短三和音より一致する倍音が少なく、ぶつかる倍音が多い（[08 章 3 節](08_三和音.md#減三和音と増三和音)）。04 章の数え方では、C・E♭・G は一致 4 組・ぶつかり 10 組・粗さ 121、C・E♭・G♭ は一致 2 組・ぶつかり 16 組・粗さ 155 である。主和音そのものが落ち着いて聞こえにくいので、ロクリアンを曲全体の中心にした音楽は少ない。

```play
C4 Eb4 G4
mode: both
label: C・E♭・G（C エオリアンやドリアンの主和音、短三和音）
show: spec kbd
timbre: organ
```

```play
C4 Eb4 Gb4
mode: both
label: C・E♭・G♭（C ロクリアンの主和音、減三和音）
show: spec kbd
timbre: organ
```

### どんな音楽で使われるか

中世からルネサンスまでのヨーロッパの教会音楽（グレゴリオ聖歌など）は、旋法にもとづいて作られていた。17 世紀ごろから、長調・短調の 2 つを中心にした和声（05〜14 章で扱ったもの）が主流になった。19 世紀の終わりから 20 世紀にかけて、長調・短調とは違う響きを求めて、モードが再び多く使われるようになった。1950 年代の終わりごろには、和音を細かく変えずに 1 つのモードの上で長く即興演奏をするジャズ（モード・ジャズ）も現れた。

よく挙げられる例を、ジャンルの名前で示す（どのジャンルも、ここに挙げたモードだけを使うわけではない）。

| モード | 使われることが多い例 |
|---|---|
| リディアン | 映画音楽で、浮かぶような、不思議な感じを出したいとき。ジャズ |
| イオニアン | 長調の音楽の大部分（長音階そのもの） |
| ミクソリディアン | ロック、ブルースの影響を受けた音楽、ケルトなどの民謡 |
| ドリアン | ジャズ（モード・ジャズ）、ファンク、ロック、ケルトなどの民謡 |
| エオリアン | 短調の音楽（自然短音階そのもの）。ロックやポップスの ♭VI → ♭VII → Im |
| フリジアン | フラメンコなどスペインの音楽を思わせる響き、ヘヴィメタル |
| ロクリアン | 曲全体の中心として使われることは少ない |

次の旋律は、この章のために作った、D ドリアンの短い旋律である。D のドローンの上で、特性音 B（D から長 6 度）を長めに鳴らしている。

```play
label: D のドローンの上の、D ドリアンの旋律（この章のために作ったもの）
v1: D4 E4 F4 A4 B4:2 A4 G4 A4 F4 G4 E4 D4:4
v2: D3:4 D3:4 D3:4 D3:4
show: kbd staff
timbre: organ
tempo: 100
```

### ジャズの即興 — 和音ごとのモード

ジャズでは、和音ごとに、その上の旋律に使う音の集まりを決めて即興演奏をする考え方がある。調の中のダイアトニックセブンスコード（[11 章 2 節](11_セブンスコードとテンション.md#ダイアトニックセブンスコード)）の上では、その調の 7 つの音を、和音の根音から並べたモードを基本にする。ハ長調なら、どの和音の上でも白鍵の 7 つを使い、和音の根音を主音とみなして呼ぶ。

```fig
e15_jazz
```

ツーファイブワン（[12 章 1 節](12_コード進行と声部の動き.md#定番の進行を機能で読む)）の Dm7 → G7 → CM7 では、モードの呼び名が D ドリアン → G ミクソリディアン → C イオニアンと変わるが、使う音はどれも白鍵の 7 つである。呼び名が表しているのは、その和音が鳴っている間、どの音（和音の根音）を中心にして 7 つの音を聞くか、である。曲全体の主音は C のままである。

```play
label: Dm7 → G7 → CM7 の上で、各和音の根音から白鍵を並べる
v1: D4 E4 F4 G4 A4 B4 C5 D5 G4 A4 B4 C5 D5 E5 F5 G5 C5 D5 E5 F5 G5 A5 B5 C6
chords: Dm7:8 G7:8 CM7:8
key: C
show: chords kbd staff
tempo: 132
```

## 6. まとめ

| 項目 | 内容 |
|---|---|
| モード（旋法） | ある長音階の 7 つの音をそのまま使い、主音を選び直した音階。7 種類ある |
| ドローン | 旋律の下で同じ高さのまま鳴らし続ける音。主音を鳴らし続けると、どの音が中心かがはっきりする |
| 7 つの名前 | 白鍵の C D E F G A B を主音にしたものが、イオニアン・ドリアン・フリジアン・リディアン・ミクソリディアン・エオリアン・ロクリアン |
| 全・半の並び | 「全・全・半・全・全・全・半」の輪を、違う位置から読んだもの。イオニアン = 長音階、エオリアン = 自然短音階 |
| 明るさの順 | 同じ主音で、リディアン → イオニアン → ミクソリディアン → ドリアン → エオリアン → フリジアン → ロクリアン。1 段ごとに 1 音が半音下がる（5 度の列で 7 つ離れた同じ文字の音が入れ替わるため） |
| 同じ 7 音の長調 | 主音 C なら、ト長調・ハ長調・ヘ長調・変ロ長調・変ホ長調・変イ長調・変ニ長調。五度圏を ♭ が増える向きへ 1 つずつ |
| 特性音 | 主音の上の 3 度が同じ長音階・自然短音階と比べて違う音。リディアン ♯4、ミクソリディアン ♭7、ドリアン 6、フリジアン ♭2、ロクリアン ♭2・♭5 |
| モードらしい和音 | 主和音と、特性音を含む和音を交互にくり返す。I → II、I → ♭VII、Im7 → IV7、Im → ♭II |
| 主音の示し方 | 導音を持つのはイオニアンとリディアンだけ。モードの音楽では、ドローンや主和音へのくり返しで主音を示す。ロクリアンは主和音が減三和音 |
| 使われ方 | 曲全体の中心として（教会音楽、民謡、モード・ジャズ、ロック、映画音楽など）、和音ごとの音の集まりとして（ジャズの即興） |
