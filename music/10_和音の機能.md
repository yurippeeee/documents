## 1. 落ち着く和音と、戻りたがる和音

和音を 1 つずつ順に鳴らしていくときの、和音の並びを**コード進行**（**和音進行**）という。コード進行は、コードネームを矢印でつないで「C → F → G → C」と書くか、ディグリーネームで「I → IV → V → I」と書く。

ハ長調（C メジャー）の主和音 C（I）・下属和音 F（IV）・属和音 G（V）の 3 つだけを使い、並べる順番だけを変えた 3 つの進行を聞き比べる。どれも C から始まり、4 つ目の和音で止まる。

```fig
e10_ends
```

この章の再生カードでは、和音の根音を、いちばん低い音（ベース）としても重ねて鳴らす。

```play
label: (a) C → F → G → C（I → IV → V → I）
chords: C:1 F:1 G:1 C:2
key: C
bass: on
tempo: 40
show: chords staff
```

```play
label: (b) C → F → C → G（I → IV → I → V）
chords: C:1 F:1 C:1 G:2
key: C
bass: on
tempo: 40
show: chords staff
```

```play
label: (c) C → G → C → F（I → V → I → IV）
chords: C:1 G:1 C:1 F:2
key: C
bass: on
tempo: 40
show: chords staff
```

多くの人には、次のように聞こえる。

- (a) は、最後の C で、そこで終わったように落ち着く。
- (b) は、最後の G で止まると終わった感じがせず、次に C が来るのを待つように聞こえる。
- (c) も、最後の F で終わった感じはしない。ただし、(b) の G ほど強く、特定の和音を待つ感じはしない。

この聞こえ方には、長調・短調の音楽を聞き慣れていることも関わる（響きの感じ方に慣れが関わることは 04 章 1 節で触れた）。以下では、そうした音楽で広く共有されている聞こえ方を扱う。

(b) の最後に C を足すと、待っていた和音が来て落ち着く。

```play
label: (b) の最後に C を足す — C → F → C → G → C
chords: C:1 F:1 C:1 G:1 C:2
key: C
bass: on
tempo: 40
show: chords staff
```

このように、続きを求めて聞こえる和音から、落ち着いて聞こえる和音へ進むことを**解決**という。この例では、G が C へ解決した。

3 つの進行は同じ 3 つの和音でできていて、違いは「どの和音で止まったか」だけである。したがって、同じ調の和音には、進行の終わりになれる和音（C）と、ほかの和音へ進みたがる和音（G、F）があり、進みたがる強さも和音によって違う。3 つの進行はどれも C から出発しているので、G は出発点の C へ戻りたがっている、とも言える。2 節では、この違いを 7 つの和音すべてについて整理する。3 節では、G が C へ戻りたがる理由を、和音の中の音の動きから説明する。

## 2. トニック・サブドミナント・ドミナント

### 3 つの役割と、その代表の和音

進行の中で和音が受け持つ役割を、その和音の**機能**という。1 節の聞き比べから、機能を次の 3 つに分ける。

- **トニック**（**T**）: 落ち着いて聞こえ、進行の終わりになれる。代表は主和音 I（1 節の C）。
- **ドミナント**（**D**）: トニックへ強く進みたがる。代表は属和音 V（1 節の G）。
- **サブドミナント**（**SD**）: 終わりにはならないが、ドミナントほど強くはトニックを求めない。代表は下属和音 IV（1 節の F）。1 節の (a) の F のように、トニックからドミナントへ向かう途中に置かれることが多い。

3 つの名前は、代表の和音の根音の英語名から来ている。主音は英語で tonic、属音は dominant、下属音は subdominant といい、それぞれの音を根音とする和音が、トニック・ドミナント・サブドミナントの代表になっている。以下、例はハ長調で示すが、ディグリーネームで書いた関係は、どの長調でも同じである。

3 つの代表の和音を音階の上に並べると、音階の 7 つの音がすべて、少なくとも 1 つの和音に含まれる。

```fig
e10_primary
```

C は I と IV の両方に、G は I と V の両方に含まれ、残りの 5 つの音は 1 つの和音だけに含まれる（E は I に、F と A は IV に、B と D は V に）。

### 残りの 4 つの和音を、共通音で分ける

2 つの和音が 2 つの音を共有するとき（09 章 5 節）、続けて鳴らすと 3 つの音のうち 2 つがそのまま残り、1 つの音だけが動く。そのため響きの変わり方が小さく、似た和音に聞こえる。

```play
label: C → Am → C（I → VIm → I）。C と E が残り、G と A だけが入れ替わる
chords: C:1 Am:1 C:2
key: C
tempo: 40
show: chords kbd staff
```

これを使って、代表でない 4 つの和音（IIm・IIIm・VIm・VIIdim）の機能を決める。

**方針**: 4 つの和音のそれぞれについて、代表の 3 つの和音（I・IV・V）と共有する音を数え、2 つの音を共有する代表と同じ機能に入れる。

**導出**: ハ長調で数えると、次の表になる（太字は 2 つ以上の音を共有する組）。

| 和音 | 構成音 | I（C・E・G）と | IV（F・A・C）と | V（G・B・D）と |
|---|---|---|---|---|
| I（C） | C・E・G | **3** | 1（C） | 1（G） |
| IIm（Dm） | D・F・A | 0 | **2（F・A）** | 1（D） |
| IIIm（Em） | E・G・B | **2（E・G）** | 0 | **2（G・B）** |
| IV（F） | F・A・C | 1（C） | **3** | 0 |
| V（G） | G・B・D | 1（G） | 0 | **3** |
| VIm（Am） | A・C・E | **2（C・E）** | **2（A・C）** | 0 |
| VIIdim（Bdim） | B・D・F | 0 | 1（F） | **2（B・D）** |

- IIm は IV とだけ 2 つの音（F・A）を共有するので、SD に入る。
- VIIdim は V とだけ 2 つの音（B・D）を共有するので、D に入る。
- VIm は I と 2 つ（C・E）、IV とも 2 つ（A・C）の音を共有する。IIIm は I と 2 つ（E・G）、V とも 2 つ（G・B）の音を共有する。この 2 つの和音の機能は、この数え方だけでは 1 つに決まらない ∎

7 つの和音を、根音が 3 度ずつ上がる順に並べ直すと、この結果が 1 本の帯として見える。隣り合う 2 つの和音は、どれも 2 つの音を共有する。

```fig
e10_chain
```

SD の 2 つが左に、D の 2 つが右に集まり、VIm と IIIm は、I をはさんで、それぞれ SD・D との境目にある。ポピュラー音楽の解説の多くは、VIm と IIIm を、主和音 I と 2 つの音を共有する点を重く見て T に分類する。このシリーズもこれに従う。ただし、VIm は SD に近い面を、IIIm は D に近い面（V と同じく導音 B を含む）を持つ。

| 機能 | 代表 | 同じ機能のほかの和音 | ハ長調の例 |
|---|---|---|---|
| T（トニック） | I | VIm・IIIm | C（Am・Em） |
| SD（サブドミナント） | IV | IIm | F（Dm） |
| D（ドミナント） | V | VIIdim | G（Bdim） |

同じ機能の和音は、進行の中で似た働きをする。IIm は IV と同じように V の前に置くことができ、VIIdim は V と同じように I へ解決する。

```play

chords: F:1 G:1 C:2 r:1 Dm:1 G:1 C:2
key: C
bass: on
tempo: 40
show: chords staff
```

```play
label: D の 2 つの和音から I へ — G → C と Bdim → C
chords: G:1 C:2 r:1 Bdim:1 C:2
key: C
bass: on
tempo: 40
show: chords staff
```

T の 3 つの和音が、進行の最後で同じように落ち着くかどうかは、4 節で聞き比べる。

## 3. ドミナントが主和音へ戻りたがる理由 — 導音と三全音

### V の中の導音

V（G・B・D）の 3 度の音 B は、音階の第 7 音で、主音 C の半音下にある導音である（05 章 4 節）。V から I へ進むとき、B は、音階の中でいちばん小さい動きである半音 1 つで、調の中心の主音 C に着く。V のほかの 2 つの音のうち、根音 G は I にも含まれ（2 節）、5 度の音 D は全音 1 つ動けば I の C か E になる。

### 属七の和音 — V に 7 度の音を足す

V の上に、音階の音でもう 1 つ 3 度を重ねると F が加わり、G・B・D・F の 4 音の和音になる。このように、属和音 V に根音から短 7 度上の音を足した 4 音の和音を**属七の和音**といい、**V7** と書く。足した音は根音から 7 度上にあるので、**7 度の音**と呼ぶ（3 度の音・5 度の音と同じ呼び方）。コードネームでは根音の文字の後ろに 7 を付け、ハ長調の V7 は **G7** と書く。V 以外の和音に 7 度の音を足した 4 音の和音（セブンスコード）は、11 章で扱う。


多くの人には、V7 → I のほうが、V → I よりも強く C を待ってから解決するように聞こえる。以下、足した F と、もとからある B の組に注目する。

### 三全音が 3 度・6 度に変わる

B から F までは B・C・D・E・F の 5 文字で 5 度、半音 6 つなので減 5 度、つまり三全音である（03 章 3 節）。上下を入れ替えた F から B も、半音 6 つの増 4 度で、三全音である。長音階の 7 つの音の中で、三全音になる 2 つの音の組は、この B と F の 1 組だけである。三全音は、04 章 1 節の分類では不協和の音程である。

B と F は、どちらも I の音の半音となりにある。

- B（音階の第 7 音、導音）は、半音上がると C（主音）になる。
- F（音階の第 4 音、下属音）は、半音下がると E（音階の第 3 音、中音）になる。

長音階で、隣の音との間が半音なのは E–F と B–C の 2 か所だけである（05 章 2 節）。B と F は、その 2 か所の半音の、I に含まれない側の音になっている。

**方針**: B が半音上の C へ、F が半音下の E へ動くとき、2 つの音の間の音程がどう変わるかを、半音の数と度数で求める。2 つの音のどちらが下にあるかで、2 つの場合に分けて確かめる。

**導出**:

- **B が下、F が上の場合**: B–F は減 5 度（半音 6）である。下の B が半音 1 つ上がり、上の F が半音 1 つ下がるので、2 つの音の間は両側から半音 1 つずつ縮み、半音の数は$`6 - 1 - 1 = 4`$になる。文字も、下が B → C と 1 つ上がり、上が F → E と 1 つ下がるので、度数は$`5 - 1 - 1 = 3`$になる。半音 4 の 3 度なので、長 3 度 C–E である。
- **F が下、B が上の場合**: F–B は増 4 度（半音 6）である。下の F が半音 1 つ下がり、上の B が半音 1 つ上がるので、2 つの音の間は両側へ半音 1 つずつ広がり、半音の数は$`6 + 1 + 1 = 8`$、度数は$`4 + 1 + 1 = 6`$になる。半音 8 の 6 度なので、短 6 度 E–C である。

どちらの場合も、不協和の三全音が、不完全協和の長 3 度または短 6 度（04 章 1 節）に変わる。2 つの結果は互いの転回になっている（半音の和$`4 + 8 = 12`$、度数の和$`3 + 6 = 9`$。03 章 5 節）∎

### スペクトルで比べる

04 章 4 節のスペクトルで、三全音と、解決したあとの音程を比べる。

```fig
e10_spec
```

| 2 つの音 | 音程 | 一致する倍音 | ぶつかる倍音 | 粗さの合計 |
|---|---|---|---|---|
| B3・F4 → C4・E4 | 減 5 度 → 長 3 度 | 0 → 1 組 | 6 → 4 組 | 43 → 48 |
| F4・B4 → E4・C5 | 増 4 度 → 短 6 度 | 0 → 1 組 | 4 → 3 組 | 34 → 31 |

どちらの上下でも、一致する倍音が 0 組から 1 組になり、ぶつかる倍音の組は減る。一方、粗さの合計は、F が下の場合は少し減るが、B が下の場合はかえって少し増える。B が下の場合の粗さを、基音どうしの組とそれ以外の倍音の組に分けると、基音どうしの分は 5 から 16 に増え、それ以外の分は 37 から 33 に減っている。長 3 度 C4–E4 では 2 つの基音が半音 4 つまで近づくので、基音どうしの粗さが大きくなるのである（04 章 4 節で、C4 の上の長 3 度の粗さが短 7 度より大きくなることを見た）。

したがって、三全音の解決で、上下によらずに起きる変化は、一致する倍音ができることと、ぶつかる倍音の組が減ることである。04 章 4 節で見たように、協和の感じ方には粗さと一致の両方が効き、一致する倍音があると 2 つの音がまとまって聞こえやすくなる。

### 短調のドミナント — 和声的短音階の導音

短調で、自然短音階の音だけを使って作る V は、短三和音になる（09 章 4 節）。イ短調（A マイナー）では Em（E・G・B）で、その 3 度の音 G は主音 A の全音下にある。主音の半音下ではないので、導音ではない（05 章 4 節）。また Em は三全音も含まない。そのため Em → Am には、半音 1 つで主音へ進む音が無い。

和声的短音階は、第 7 音を半音上げて G♯ にし、導音を作った音階である（06 章 3 節）。この G♯ を使うと、V は長三和音 E（E・G♯・B）になり、7 度の音 D を足した V7 は E7（E・G♯・B・D）になる。E7 → Am では、次のように動く。

- 導音 G♯ が、半音上の主音 A へ進む。
- 7 度の音 D が、全音下の C（音階の第 3 音）へ進む。長調と違って全音なのは、短調では音階の第 4 音と第 3 音の間が全音だからである。
- 三全音は、G♯ が下なら減 5 度 G♯–D が半音$`6 - 1 - 2 = 3`$・度数$`5 - 1 - 1 = 3`$の短 3 度 A–C に、D が下なら増 4 度 D–G♯ が半音$`6 + 2 + 1 = 9`$・度数$`4 + 1 + 1 = 6`$の長 6 度 C–A になり、どちらも不完全協和に変わる。


```play

chords: Em:1 Am:2 r:1 E7:1 Am:2

bass: on

show: chords staff
```

短調の曲で、和声的短音階の第 7 音を使って V や V7 を作るのは、V に導音と三全音を持たせ、長調の V7 → I と同じように主和音へ強く解決させるためである。06 章 3 節と 09 章 4 節で 10 章に回した理由は、これである。

以上をまとめると、D の和音が T へ進みたがって聞こえるのは、次の 2 つが重なるからである（1 節で述べたように、聞き慣れていることも関わる）。

1. 導音が、半音という最も小さい動きで、調の中心の主音へ進める。
2. V7 では、不協和の三全音が、2 つの音の小さな動きで不完全協和の 3 度・6 度に変わる。

2 節で D に入れた VIIdim（B・D・F）も、導音 B と三全音 B–F を含むので、V7 と同じように I へ解決する。2 節で T に入れた IIIm（E・G・B）は、導音 B を含むが三全音は含まない。

## 4. 終止 — 進行の区切り

文章が句読点で区切られるように、音楽も、ひとまとまりに聞こえるいくつかの部分に分かれて進む。このひとまとまりを**フレーズ**という。フレーズの終わりで区切りを作る和音の進み方を**終止**という。終止は、フレーズの最後の 2 つの和音で、次の 4 つの形に分ける。

| 終止 | 最後の 2 つの和音 | 機能の動き |
|---|---|---|
| **全終止** | V（または V7）→ I | D → T |
| **偽終止** | V（または V7）→ VIm | D → T（I の代わりに VIm） |
| **変終止** | IV → I | SD → T |
| **半終止** | （いろいろな和音）→ V | → D |


- **全終止**は、いちばんはっきり終わって聞こえる。3 節の、導音から主音への動きと三全音の解決が、両方そろうからである。
- **偽終止**は、I が来ると思ったところに VIm が来て、終わりきらずに先へ続くように聞こえる。「偽」は、終わると見せかけることを表す。
- **変終止**は、終わって聞こえるが、全終止より穏やかである。IV（F・A・C）は導音 B も三全音も含まず、I へは C を残したまま F → E、A → G と動くだけだからである。賛美歌の最後の「アーメン」によく使われるので、アーメン終止とも呼ばれる。
- **半終止**は、D で止まるので解決していない。フレーズは区切れるが、続きを求めるように聞こえる。

### 偽終止で起きていること

偽終止の G7 → Am でも、三全音は全終止とまったく同じように解決している。VIm（A・C・E）は I と C・E の 2 つの音を共有していて（2 節）、それがちょうど、三全音の 2 つの音の解決先だからである。

```fig
e10_deceptive
```

上の 3 つの声部の動きは全終止と同じで、違うのはベースだけである。ベースが主音 C ではなく A へ進むので、和音は主和音にならず、終わった感じにならない。D の解決の働きは残したまま、終わりを先へ延ばすのが偽終止である。

### フレーズを区切る

半終止と全終止は、2 つのフレーズを組にするときによく使われる。1 つ目のフレーズを半終止で区切って続きを待たせ、2 つ目のフレーズを全終止で終える形である。

## 5. 機能で進行を組み立てる

### 機能の進み方

ここまでに聞いた機能の動きをまとめる。

- **D → T**: 3 節の解決。4 節の全終止・偽終止。
- **SD → D**: 1 節 (a) の F → G。2 節の Dm → G。
- **SD → T**: 4 節の変終止。
- **T → SD、T → D**: T は落ち着いた状態なので、どちらへも進める。1 節の 3 つの進行は、どれも C から F か G へ進んだ。

これらをつなぐと、T → SD → D → T のひと回りになる。これが機能の基本の流れで、SD を通らない T → D → T や、D を通らない T → SD → T も使われる。同じ機能どうしの進行（T → T、SD → SD など）もある。

一方、D → SD は、解決を待っている D から、解決しないまま SD へ移る動きである。クラシックの和声では避けるのが基本とされるが、ポピュラー音楽では V → IV → I のような形でよく使われる。

```fig
e10_flow
```

### 代理 — 同じ機能の和音に置き換える

進行の中のある和音を、同じ機能の別の和音に置き換えることを**代理**という。代理しても機能の並びは変わらないので、進行の流れは保たれ、響きの色合いだけが変わる。置き換える和音どうしは、2 節で見たように 2 つの音を共有するか（I と VIm・IIIm、IV と IIm、V と VIIdim）、V と V7 のように音を 1 つ足しただけの関係にある。

## 6. まとめ

| 項目 | 内容 |
|---|---|
| コード進行 | 和音を順に並べたもの |
| 解決 | 続きを求めて聞こえる和音から、落ち着いて聞こえる和音へ進むこと |
| 機能 | 進行の中での和音の役割。T（I・VIm・IIIm）、SD（IV・IIm）、D（V・V7・VIIdim）。代表の和音 I・IV・V と 2 つの音を共有するかで分ける |
| 属七の和音 | V に根音から短 7 度上の音（7 度の音）を足した 4 音の和音。ハ長調では G7 = G・B・D・F |
| 導音と三全音 | 導音 B は半音上の主音 C へ。三全音 B–F は、半音ずつの動きで長 3 度・短 6 度に変わる（不協和 → 不完全協和。一致する倍音 0 → 1 組） |
| 短調の D | 和声的短音階の導音（イ短調では G♯）で V・V7 を作り、導音と三全音を持たせる |
| 終止 | 全終止 V（V7）→ I、偽終止 V（V7）→ VIm、変終止 IV → I、半終止 … → V |
| 機能の流れ | 基本は T → SD → D → T。T からはどれへも、SD → D・T、D → T。D → SD はクラシックでは避ける |
| 代理 | 同じ機能の和音に置き換えること。機能の並びは変わらない |

ここまでで、1 つの調の 7 つの和音に機能という役割を与え、進行の区切り方と組み立て方を、機能の流れとして読めるようになった。次章では、V7 のように三和音に 3 度をもう 1 つ重ねた 4 音の和音を、ほかの和音にも広げ（セブンスコード）、さらに音を重ねるテンションを扱う。
