# 01. 音の正体 — 振動・周波数・倍音

> **この章で扱う問い.**
> 音楽理論は、「どの高さの音を、どう組み合わせると、どう聞こえるか」を整理したものである。その前に、組み合わせる材料である「音」そのものが何なのかを確かめておく。
>
> この章では次の 3 つの問いに答える。
>
> 1. 音とは、物理的には何か。
> 2. 音の「高さ」「大きさ」「音色」は、それぞれ何で決まるのか。
> 3. 1 つの音の中に、別の高さの成分が含まれているとはどういうことか。
>
> 3 つ目の答えである「倍音」は、03 章以降で「なぜこの組み合わせは気持ちよく響くのか」を説明するときの土台になる。

> **音の出し方.**
> 再生ボタン（▶）を押すと、その場で音が鳴る。音はページの中で計算して作っているので、音声ファイルは使っていない。
> 最初の 1 回は、ブラウザが音を出す準備をするため、わずかに遅れることがある。音量は端末側で小さめにしてから試すとよい。
> この章は最初の章なので、前提にする用語は無い。

## 1. 音は空気の圧力の波

太鼓の皮やスピーカーの振動板が前に出ると、すぐ前の空気が押し縮められて、圧力がわずかに上がる。後ろに下がると、空気が引き伸ばされて、圧力がわずかに下がる。
振動板が往復を続けると、圧力の高い所（**密**）と低い所（**疎**）が交互にでき、それが 1 秒に約 340 m の速さで周りへ伝わっていく。この圧力の変化の伝わりを**音波**という。耳の鼓膜は、届いた圧力の変化に合わせて振動し、それを脳が音として感じる。

```fig
e01_wave
```

ある 1 か所で、圧力が時間とともにどう変わるかを描いたグラフを**波形**という。以下では、波形の縦軸を「平均の圧力からのずれ」（上が圧力の高い側）、横軸を時間として描く。

### 正弦波 — いちばん単純な波

振動板が滑らかに往復を繰り返すと、波形は下の図のような規則正しい曲線になる。この形の波を**正弦波**（サイン波）といい、正弦波だけでできた音を**純音**という。正弦波は次の 2 つの量で決まる。

- **周期**$`T`$: 同じ形が 1 回繰り返すのにかかる時間
- **振幅**$`A`$: 平均からのずれの最大値

```fig
e01_sine
```

純音は、時報の「ポーン」や音叉の音に近い、飾りのない音である。

```play
440Hz
mode: chord
label: 純音（440 Hz の正弦波）
show: wave
timbre: sine
hold: 1.6
```

## 2. 高さは周波数で決まる

### 周波数

1 秒間に波が何回繰り返すかを**周波数**といい、単位は**ヘルツ**（Hz）である。1 回に$`T`$秒かかるなら、1 秒間には$`1/T`$回繰り返すので、周波数$`f`$は

$$
f = \frac{1}{T}
$$

である。たとえば周期が$`1/440`$秒（約 2.27 ミリ秒）の正弦波は 440 Hz である。

周波数が高いほど、音は**高く**聞こえる。人の耳に聞こえるのは、およそ 20 Hz から 20,000 Hz の範囲である（代表値。年齢とともに高い側が狭くなる）。
楽器をそろえる（**調律**する）ときの基準の音は、440 Hz にすることが多い（国際規格 ISO 16 の値。オーケストラなどでは 442 Hz に合わせることもある）。

```fig
e01_freq
```

```play
220Hz 440Hz 880Hz
mode: arp
label: 220 Hz → 440 Hz → 880 Hz
show: wave
timbre: sine
gap: 0.9
```

### 周波数が 2 倍の音 — オクターブ

上の 3 つの音は、どれも周波数が前の音の 2 倍である。高さははっきり違うのに、3 つとも「同じ音の高い版」のように似て聞こえる。周波数が 2 倍の関係にある 2 つの音の関係を**オクターブ**という（呼び名の由来は 02 章で説明する）。

似て聞こえる理由の 1 つは、2 つを同時に鳴らしたときの波の重なり方にある。

**方針**: 低い音の周期を$`T`$として、時間$`T`$が経ったときに、2 つの波がそろって最初の状態に戻ることを示す。

**導出**: 低い音の周波数を$`f`$とすると、高い音の周波数は$`2f`$で、周期は$`1/(2f) = T/2`$である。時間$`T`$の間に、低い波はちょうど 1 周期、高い波はちょうど 2 周期進むので、どちらも最初と同じ状態に戻る。したがって 2 つを足した波も、時間$`T`$ごとに同じ形を繰り返す。つまり合わせた波は、低い音と同じ周期を持つ 1 つの波になる ∎

一方、周波数の比が 2:1 のような単純な整数比でないと、合わせた波はなかなか同じ形に戻らない。

```fig
e01_octave
```

```play
220Hz 440Hz
mode: both
label: 220 Hz と 440 Hz（オクターブ）
show: wave
timbre: sine
window: 13.6
```

```play
220Hz 311.13Hz
mode: both
label: 220 Hz と 311 Hz（比が単純でない）
show: wave
timbre: sine
window: 13.6
```

「単純な整数比なら、合わせた波が短い周期で繰り返す」という性質は、04 章で「よく溶け合う音の組み合わせ」を説明するときに、もう一度使う。

## 3. 大きさは振幅で決まる

振幅が大きいほど、音は**大きく**聞こえる。周波数を変えずに振幅だけを変えると、高さは同じまま大きさだけが変わる。

```fig
e01_amp
```

音の大きさの変化は、振幅の比を対数で表した**デシベル**（dB）で表すことが多い。振幅が$`A_1`$から$`A_2`$に変わったときの変化は

$$
\Delta L = 20 \log_{10} \frac{A_2}{A_1}\ \text{[dB]}
$$

である。$`\log_{10} x`$は「10 を何乗すると$`x`$になるか」を表す（**常用対数**。$`\log_{10} 10 = 1`$、$`\log_{10} 100 = 2`$、$`\log_{10} 1 = 0`$）。

**例**: 振幅が 2 倍なら$`20 \log_{10} 2 = 20 \times 0.301 \approx 6.0`$ dB、10 倍なら$`20 \times 1 = 20`$ dB 大きくなる。半分なら$`20 \log_{10} 0.5 \approx -6.0`$ dB で、6 dB 小さくなる。

対数を使うのは、耳が大きさを「差」ではなく「比」で感じるからである。振幅を 2 倍にしたときの変化は、もとの振幅が小さくても大きくても、だいたい同じ程度に感じられる。人が「2 倍の大きさになった」と感じるのは、およそ +10 dB（振幅で約 3.2 倍）とされる（目安）。
高さについても、耳は周波数の差ではなく比で感じる。220 Hz → 440 Hz と 440 Hz → 880 Hz は、周波数の差は 220 Hz と 440 Hz で違うが、どちらも比は 2 倍で、同じ「1 オクターブ」の上がり方に聞こえる。02 章で高さに目盛を付けるときも、比を基準にする。

```play
notes: 440Hz:1@0.25 r:0.4 440Hz:1@0.5 r:0.4 440Hz:1@1
mode: seq
label: 同じ 440 Hz で、振幅を 1/4 → 1/2 → 1 と 2 倍ずつ大きくする
show: none
timbre: sine
tempo: 70
note: 1 段ごとに +6 dB。高さは変わらず、大きさだけが一定の割合で増える
```

下の図で周波数と振幅を変えると、10 ミリ秒分の波形と、周期・デシベルの値が表示される。鳴らしたままスライダーを動かすと、音もその場で変わる。

## 4. 音色は波の形で決まる

同じ 440 Hz、同じ大きさでも、ピアノ、オルガン、人の声は違って聞こえる。この違いを**音色**という。音色の違いは、波形の**形**の違いである。

```fig
e01_shapes
```

### どんな周期的な波も、正弦波の足し算で書ける

周期的な波は、形がどれほど複雑でも、周波数が$`f, 2f, 3f, \dots`$の正弦波を、それぞれ適当な振幅で足し合わせたものとして表せる（**フーリエ級数**。証明は省く）。ここで$`f`$は、元の波が 1 秒間に繰り返す回数、つまり元の波の周波数である。

- 周波数が$`f`$の成分を**基音**という。
- 周波数が$`f`$の整数倍の成分を**倍音**という。基音を第 1 倍音と数え、周波数が$`n f`$の成分を**第$`n`$倍音**と呼ぶ。

どの倍音も、基音の 1 周期の中にちょうど整数回だけ繰り返すので（第$`n`$倍音なら$`n`$回）、足し合わせた波も基音と同じ周期で繰り返す。2 節のオクターブの議論と同じ理由である。そのため、倍音をいくつ足しても、聞こえる高さは基音の高さのまま変わらない。変わるのは波の形、つまり音色である。

**例**: 基音に、振幅 1/2 の第 2 倍音、振幅 1/3 の第 3 倍音、…と、第$`n`$倍音を振幅$`1/n`$で足していくと、波形はのこぎりの歯のような形に近づく。

```fig
e01_sum
```

### スペクトル — どの倍音がどれだけ含まれているか

波を作っている成分の振幅を、倍音の番号（または周波数）ごとに棒で並べた図を**スペクトル**という。波形とスペクトルは同じ音の 2 通りの見方で、音色の違いはスペクトルで見ると比べやすい。

```fig
e01_spectrum
```

- **純音**: 基音だけで、倍音を含まない。
- **オルガン風**: 低い倍音が、いくつか同じくらいの強さで続く。
- **のこぎり波**: すべての倍音を含み、第$`n`$倍音の振幅は$`1/n`$である。明るく、はっきりした音になる。
- **奇数の倍音だけ**: 第 1, 3, 5, … 倍音だけを含む。クラリネットの低い音域は、奇数番目の倍音が強いことが知られている（代表的な例）。

ピアノの音は、高い倍音ほど弱く、しかも早く減衰する。そのため、鍵盤を押した直後は明るく、時間がたつと丸い音色に変わっていく。このシリーズの「ピアノ」の音は、この性質をまねて計算で作っている。

```play
440Hz
mode: chord
label: ピアノ風の音（440 Hz）
show: none
hold: 2.4
note: 押した直後は明るく、だんだん丸い音色に変わる
```

下の図で 8 つの倍音の振幅を変えると、波形とスペクトルが変わり、鳴らしたままなら音色も変わる。基音を 220 Hz に固定しているので、どの組み合わせでも高さは変わらないことを確かめられる。

## 5. 倍音列 — 1 つの音に含まれる高さの並び

基音の周波数を$`f`$とすると、倍音の周波数は$`f, 2f, 3f, 4f, \dots`$と、等しい間隔で並ぶ。この並びを**倍音列**という。

**例**: 基音が 110 Hz なら、倍音の周波数は 110, 220, 330, 440, 550, 660, 770, 880 Hz, … である。

この並びを、周波数そのものの目盛（等間隔）と、比の目盛で比べると、見え方が大きく違う。

```fig
e01_series
```

隣り合う倍音の周波数の比は、第$`n`$倍音と第$`n + 1`$倍音で$`(n+1)f / nf = (n+1)/n = 1 + 1/n`$である。$`n`$が大きいほど$`1/n`$が小さくなるので、比は$`2/1, 3/2, 4/3, 5/4, 6/5, \dots`$と、だんだん 1 に近づく。
耳は周波数の比で高さの違いを感じるので（3 節）、倍音列を低い方から順に聞くと、高くなるほど隣との高さの違いが小さく聞こえる。

| 倍音の番号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 周波数（基音 110 Hz） | 110 | 220 | 330 | 440 | 550 | 660 | 770 | 880 |
| 1 つ下の倍音との比 | — | 2:1 | 3:2 | 4:3 | 5:4 | 6:5 | 7:6 | 8:7 |
| 基音との関係 | 基音 | 1 オクターブ上 | | 2 オクターブ上 | | | | 3 オクターブ上 |

第 1・2・4・8 倍音は、基音から 1, 2, 3 オクターブ上の音である（2 倍ずつ）。その間に、第 3・5・6・7 倍音が入っている。
2:1, 3:2, 5:4 といった単純な比は、04 章で「よく溶け合って響く 2 つの音」の正体として、もう一度現れる。

下の図で倍音の番号を押すと、その倍音だけが鳴る。「1 から順に重ねる」を押すと、基音に倍音を 1 つずつ加えていく。重ねるにつれて、別々の音が加わるというより、1 つの音の音色が明るく変わっていくように聞こえる。耳は、倍音列の形にそろった成分を、1 つの音としてまとめて聞くからである。

## 6. まとめ

| 音の性質 | 物理的な正体 | 単位・目安 |
|---|---|---|
| 音 | 空気の圧力の変化が伝わる波（音波） | 1 秒に約 340 m で伝わる |
| 高さ | 周波数$`f = 1/T`$（1 秒あたりの繰り返しの回数） | Hz。基準の音は 440 Hz が多い。2 倍でオクターブ |
| 大きさ | 振幅 | dB。振幅 2 倍で +6 dB |
| 音色 | 波の形 = どの倍音がどれだけ含まれるか（スペクトル） | 基音$`f`$と第$`n`$倍音$`nf`$ |
| 倍音列 | $`f, 2f, 3f, \dots`$。隣どうしの比は 2:1, 3:2, 4:3, … | 耳は 1 つの音としてまとめて聞く |

耳は、高さも大きさも「比」で感じる。次章では、この性質に合わせて、オクターブの中を 12 段に区切って音に名前を付け、鍵盤と楽譜の上に並べる。
