# 13. ノンダイアトニックコード — 調の外の音を使う和音

> **この章で扱う問い.**
> 09 章では、1 つの調の音階の 7 音だけで和音（ダイアトニックコード）を作り、10〜12 章では、それらを機能に従って並べ、なめらかにつなぐ方法を見た。ところが実際の曲では、その 7 音に含まれない音を含む和音もよく使われる。
>
> この章では次の 3 つの問いに答える。
>
> 1. 調の 7 音に含まれない音を含む和音は、どう見分けるのか。
> 2. その音は、どこから来たと考えれば説明できるのか。
> 3. その和音は、前後の和音とどうつながるのか。
>
> 答えの道具は、10 章の導音と三全音、07 章の同主調である。

## 1. 調の外の音を含む和音

ハ長調（C メジャー）の音は、C 長音階の C D E F G A B の 7 つで、鍵盤では白鍵にあたる。09 章のダイアトニックコードは、この 7 音だけで作った和音である。12 の音のうち残りの 5 つ（C♯/D♭、D♯/E♭、F♯/G♭、G♯/A♭、A♯/B♭）は、ハ長調の音階に含まれない。これらを、ハ長調の**調の外の音**と呼ぶ。

調の外の音を 1 つ以上含む和音を、その調の**ノンダイアトニックコード**という（ダイアトニックコードではない和音、という意味）。

```fig
e13_keys
```

同じ根音の和音でも、構成音が 1 つ調の外の音に変わると、ノンダイアトニックコードになる。

```fig
e13_pairs
```

- Dm（D F A）の 3 度の音 F を半音上げて F♯ にし、7 度の音 C を足すと D7（D F♯ A C）になる。F♯ が調の外の音なので、D7 はハ長調のノンダイアトニックコードである。
- F（F A C）の 3 度の音 A を半音下げると Fm（F A♭ C）になる。A♭ が調の外の音である。

```play
label: ダイアトニックコードだけの進行（C → Dm → G → C）
chords: C Dm G C
key: C
show: chords kbd staff
```

```play
label: Dm の代わりに D7 を置く（調の外の音 F♯ を含む）
chords: C D7 G C
key: C
show: chords kbd staff
```

**見分け方.** 和音が調の外の音を含むかどうかは、コードネームから構成音を求め（08 章 4 節、11 章 1 節）、1 つずつ調の 7 音と高さを比べれば分かる。ハ長調なら、鍵盤で黒鍵になる音が調の外の音である。
五線では、調の外の音には必ず臨時記号が付く。ハ長調には調号が無いので、♯ か ♭ の付いた音を探せばよい。調号のある調では、調号の ♯・♭ を打ち消す ♮ の付いた音も調の外の音になる（たとえばト長調の F♮）。ただし逆は成り立たない。C♭ や E♯ のように、臨時記号が付いていても白鍵になる書き方があるからである（C♭ は B と、E♯ は F と同じ高さ。02 章 2 節）。

**別の調から見ると.** ある調の外の音も、別の調では調の音であることがある。D7 をト長調（G メジャー）の五線に、Fm をハ短調（C マイナー）の五線に書くと、どちらも臨時記号が要らない。

```fig
e13_otherkey
```

D7 はト長調の V7（属七の和音）、Fm はハ短調の IVm で、それぞれの調のダイアトニックコードである。ハ長調の曲に現れる調の外の音も、別の調の音階から借りてきた音と見れば、その調の中での働きで説明できる。2・3 節では、この見方で調の外の音がどこから来るのかを考え、4・5 節では、2 節の和音と深く関係する 2 種類の和音を扱う。この章では、長調（主にハ長調）の曲で考える。

## 2. セカンダリードミナント — ほかの和音へ向かうドミナント

### V7 → I の形を、ほかの和音へ向ける

10 章 3 節では、ハ長調の V7（G7 = G B D F）が I（C）へ進むとき、3 度の音 B（導音）が半音上の C へ、7 度の音 F が半音下の E へ動き、B–F の三全音が解決することを見た。

同じ形は、C 以外の和音へ向けても作れる。G（V）を、ト長調の主和音であるかのようにみなすと、ト長調の V7 は D7（D F♯ A C）である。D7 → G では、F♯ が半音上の G へ、C が半音下の B へ動く。動き方は G7 → C とまったく同じで、全体が完全 5 度上にずれているだけである。

```fig
e13_v7shift
```

このように、ダイアトニックコードの 1 つを X として、X を一時的に主和音とみなし、X を主和音とする調の V7 を X の直前に置いた和音を、X への**セカンダリードミナント**という。「X を主和音とみなしたときの V7」という意味で **V7/X** と書く（D7 は V7/V）。曲の主音は C のままで、G を主和音とみなすのは D7 → G の間だけである（主音そのものが移り、しばらくとどまる場合は 14 章で扱う）。

ディグリーネーム（09 章 3 節）で書くと、D7 は主音 C から数えて 2 番目の文字 D を根音とする 7（セブンス）の和音なので II7 である。II7 は和音そのもの（根音と種類）を、V7/V は和音の行き先を表す。再生カードの帯には、ディグリーネームが表示される。

X にできるのは、主和音になれる和音、つまり長三和音か短三和音である（長調の主和音は長三和音、短調の主和音は短三和音である。09 章 4 節）。ハ長調のダイアトニックコードでは IIm・IIIm・IV・V・VIm の 5 つで、減三和音の VIIdim は X にしない。I へ向かう V7 は、もとの V7 そのものである。

### V7/X の構成音

**V7/X の 3 度の音は、X の導音になる.**

**方針**: X の根音を基準にして、V7/X の 4 つの音が、それぞれ X の根音から何半音上にあるかを数える。

**導出**: X の根音を$`r`$とし、ほかの音を「$`r`$から何半音上か」で表す。X を主和音とする調の属音は、主音の完全 5 度上、つまり半音 7 つ上にあるので、V7/X の根音は$`r + 7`$である。属七の和音は、根音の上に長 3 度（半音 4）、完全 5 度（半音 7）、短 7 度（半音 10）の音を重ねた和音（10 章 3 節）なので、V7/X の 4 つの音は

$$
r + 7,\quad r + 7 + 4 = r + 11,\quad r + 7 + 7 = r + 14,\quad r + 7 + 10 = r + 17
$$

である。このうち 3 度の音$`r + 11`$は、1 オクターブ上の X の根音$`r + 12`$のちょうど半音下にある。したがって V7/X の 3 度の音は、X を主和音とする調の導音（主音の半音下の音）である ∎

```fig
e13_secderive
```

X が短三和音のときは、X を主和音とする短調の V7 を、和声的短音階の導音を使って作る（06 章 3 節、10 章 3 節）。ハ長調の 5 つの X について、V7/X を求めると次のようになる。

| 目標の和音 X | X を主和音とする調 | V7/X | ディグリーネーム | 構成音 | ハ長調の外の音 |
|---|---|---|---|---|---|
| Dm（IIm） | ニ短調 | A7 | VI7 | A C♯ E G | C♯（導音） |
| Em（IIIm） | ホ短調 | B7 | VII7 | B D♯ F♯ A | D♯（導音）・F♯ |
| F（IV） | ヘ長調 | C7 | I7 | C E G B♭ | B♭（7 度の音） |
| G（V） | ト長調 | D7 | II7 | D F♯ A C | F♯（導音） |
| Am（VIm） | イ短調 | E7 | III7 | E G♯ B D | G♯（導音） |

```fig
e13_secmap
```

- 5 つのうち 4 つでは、導音が調の外の音になる。ハ長調の 7 音のうち、半音下にも調の音があるのは F（半音下に E）と C（半音下に B）だけだからである（02 章 2 節: 文字の名前の付いた隣どうしで半音なのは E–F と B–C だけ）。D・E・G・A の半音下の C♯・D♯・F♯・G♯ は、どれも黒鍵である。
- V7/IV（C7）では、導音 E がもともとハ長調の音で、代わりに 7 度の音 B♭ が調の外の音になる。
- V7/IIIm（B7）では、導音 D♯ のほかに 5 度の音 F♯ も調の外の音である。

**解決のしかた.** V7/X → X では、10 章 3 節の V7 → I と同じく、導音が半音上の X の根音へ進み、7 度の音が X の 3 度の音へ下がって進む。7 度の音$`r + 17`$を 1 オクターブ下げた$`r + 5`$は、X が長三和音なら X の 3 度の音$`r + 4`$の半音 1 つ上、短三和音なら 3 度の音$`r + 3`$の半音 2 つ上にある。そのため 7 度の音は、D7 → G では C → B と半音、A7 → Dm では G → F と全音下がる。

VIm（Am）を V7/IIm（A7）に置き換えて、聞き比べる。A7 の C♯ は Dm の根音 D の半音下にあり、次の Dm へ向かう流れが生まれる。

## 3. 同主調からの借用 — サブドミナントマイナーなど

### ハ短調のダイアトニックコード

主音が同じ長調と短調を、同主調という（07 章 5 節）。ハ長調の同主調はハ短調（C マイナー）である。C 長音階と C 自然短音階では、主音から見た 3 度・6 度・7 度の音が違い（06 章 2 節）、ハ短調では E・A・B の代わりに E♭・A♭・B♭ を使う。

ハ短調のダイアトニックコード（09 章 4 節。自然短音階で作る）を、ハ長調のものと同じ番号で並べると次のようになる。ディグリーネームは、09 章のきまりどおり、同じ主音の長音階（C 長音階）を基準にして ♭ を付ける。

```fig
e13_parallel
```

同じ番号の和音どうしは同じ文字を使い、E・A・B のところだけが E♭・A♭・B♭ に変わる。ハ短調の 7 つの和音は、三和音でもセブンスコードでも、どれも E♭・A♭・B♭ のどれかを含む。つまりハ長調から見ると、7 つともノンダイアトニックコードである。

長調の曲の中で、同主調（同じ主音の短調）のダイアトニックコードを借りて使う和音を、**借用和音**という。ハ長調では、IVm（Fm）・♭VI（A♭）・♭VII（B♭）・IIm7(♭5)（Dm7(♭5)）・♭III（E♭）などがよく使われる。（同主調以外の調から和音を借りるという考え方もあるが、この章では扱わない。）

### IV → IVm → I

借用和音の代表は IVm である。IV → I と、IV と I の間に IVm をはさんだ IV → IVm → I を、声部（12 章 3 節）ごとの動きで比べる。

```fig
e13_ivm
```

- IV → I（F A C → E G C）: F → E が半音下、A → G が全音下に動き、C は動かない。
- IV → IVm → I: まず A が半音下がって A♭ になり、次に IVm → I で A♭ → G と F → E の 2 つの声部が半音下に動く。A → A♭ → G と、1 つの声部が半音ずつ下がっていく。

10 章 3 節の V7 → I でも、導音 B → C と 7 度の音 F → E の 2 つの声部が半音で動いた。半音で隣の音へ動く声部は、行き先の音へ引き寄せられるように聞こえる。IVm → I の A♭ → G は、この半音の動きを、下向きにもう 1 つ増やしている。

```play
label: I → IV → I
chords: C F C
key: C
show: chords kbd staff
```

```play
label: I → IV → IVm → I
chords: C F Fm C
key: C
show: chords kbd staff
```

IVm の響きは、IV に比べて暗い、切ないなどと言い表されることが多い（印象を表す言葉で、文化や慣れにもよる）。

### サブドミナントマイナー

IVm は、IV と同じように I や V の前に置かれ、SD（10 章 2 節）と同じ位置で使われる。このように、同主調の短調から借りた和音のうち、SD と同じ働きで使うものを、**サブドミナントマイナー（SDm）**という。IVm のほか、IIm7(♭5)・♭VIM7・♭VII7 も SDm として扱うことが多い。

```fig
e13_sdm
```

4 つとも A♭ を含む。A♭ は、I の 5 度の音であり V の根音でもある G の半音上にあるので、I や V へ進むときに、半音下の G へ動ける。ハ短調のダイアトニックセブンスコードのうち A♭ を含むのは、IIm7(♭5)・IVm7・♭VIM7・♭VII7 のちょうど 4 つで（ハ長調とハ短調のダイアトニックコードの図の、ハ短調の下の行）、SDm として扱う 4 つの和音と一致する。

借用和音を続けて使うこともある。I → ♭VI → ♭VII → I（C → A♭ → B♭ → C）では、根音が A♭ → B♭ → C と全音ずつ上がって I に着く。

```play
label: I → ♭VI → ♭VII → I（A♭ と B♭ をハ短調から借りる）
chords: C Ab Bb C
key: C
show: chords kbd staff
bass: on
```

## 4. 裏コード — 三全音を共有するドミナント

### 三全音は、転回しても三全音

G7 の 3 度の音 B と 7 度の音 F は、半音 6 つ離れた三全音である（03 章 3 節、10 章 3 節）。03 章 5 節の転回では、もとの音程と転回した音程の半音の数の和が 12 になった。三全音（半音 6）を転回すると$`12 - 6 = 6`$で、やはり三全音である。B を下にしても（B–F）、F を下にしても（F–B）、同じ半音 6 つの音程になる。

そこで、F を 3 度の音、B を 7 度の音とする属七の和音があれば、G7 と同じ三全音を、役割を入れ替えて持つことになる。そのような属七の和音がいくつあるかを求める。

**三全音を共有する属七の和音.**

**方針**: 根音を$`a`$とする属七の和音の 3 度の音と 7 度の音を$`a`$で表し、同じ 2 つの音を持つ属七の和音の根音$`b`$をすべて求める。

**導出**: 音の高さを半音の数で表し、12 違う数は 1 オクターブ違いの同じ名前の音なので同じとみなす（2 節の$`r`$とは別の文字を使う）。根音$`a`$の属七の和音の 3 度の音は$`a + 4`$、7 度の音は$`a + 10`$である。根音$`b`$の属七の和音が同じ 2 つの音を持つには、$`\{b + 4,\ b + 10\}`$が$`\{a + 4,\ a + 10\}`$と一致すればよい。一致のさせ方は次の 2 通りしかない。

- $`b + 4 = a + 4`$ かつ $`b + 10 = a + 10`$ のとき: $`b = a`$で、もとの和音そのものである。
- $`b + 4 = a + 10`$ かつ $`b + 10 = a + 4`$ のとき: 1 つ目の式から$`b = a + 6`$である。これを 2 つ目の式に入れると左辺は$`a + 16`$になり、右辺の$`a + 4`$と 12 違うので同じ音を表す。したがって 2 つ目の式も成り立つ。

したがって、三全音を共有する属七の和音は、もとの和音のほかに 1 つだけあり、その根音はもとの根音の半音 6 つ上、つまり三全音離れた音である ∎

G7 では$`a`$ = G なので、$`b`$は G の半音 6 つ上の C♯（= D♭）である。この和音はふつう D♭7 と書き、構成音は D♭ F A♭ C♭ である。F が 3 度の音、C♭ が 7 度の音で、C♭ は B と同じ高さ（異名同音）なので、G7 と三全音 B–F を共有する。7 度の音を C♭ と書くのは、根音 D♭ から文字を 7 つ数えると C になるからである（03 章 2 節の度数。実際の楽譜では、読みやすさのために B と書くことも多い）。

```fig
e13_tritone
```

ある属七の和音の代わりに、三全音を共有し、根音が三全音離れた属七の和音を置くとき、置いた和音をもとの和音の**裏コード**という。G7 の裏コードは D♭7 で、ディグリーネームでは ♭II7 と書く。10 章 5 節の言葉でいえば、V7 の代理である。

### 裏コードから I へ

V7 を裏コードに置き換えて、ツーファイブワン（12 章 1 節）の IIm7 → V7 → I と、IIm7 → ♭II7 → I を比べる。

```fig
e13_ura
```

- 三全音の 2 つの音は、G7 → C と同じく F → E（半音下）、C♭（= B）→ C（半音上）と動く。
- 残りの 2 つの音も、D♭ → C、A♭ → G と半音で下がる。D♭7 → C では、4 つの声部がすべて半音で動く。
- ベースは、IIm7 → V7 → I では D → G → C と、根音が 5 度下・4 度上へ進む強進行が 2 回続く。IIm7 → ♭II7 → I では D → D♭ → C と半音ずつ下がる。

```play
label: IIm7 → V7 → I（Dm7 → G7 → C）
chords: Dm7 G7 C
key: C
show: chords kbd staff
bass: on
```

```play
label: IIm7 → ♭II7 → I（Dm7 → D♭7 → C）
chords: Dm7 Db7 C
key: C
show: chords kbd staff
bass: on
```

上の導出では根音$`a`$を決めずに求めたので、どの属七の和音にも裏コードがある。2 節のセカンダリードミナントにも使え、たとえば V7/V（D7）の裏コードは A♭7 で、A♭7 → G でもベースが半音下がる。

下の図で目標の和音を選ぶと、そこへ向かうドミナント（V7 または V7/X）と、その裏コードが表示される。12 の音を半音ずつ円に並べると、裏コードの四角形はドミナントの四角形を円の中心のまわりに半周回したものになり、共有する三全音は、半周回すと両端が入れ替わる直径になる。

## 5. 経過的なディミニッシュ

### ベースを半音でつなぐ

I → IIm（C → Dm）のように、根音が全音離れた 2 つの和音の間に、根音が半音上の dim7（11 章 1 節）をはさむことがある。C → C♯dim7 → Dm では、ベースが C → C♯ → D と半音ずつ上がる。

```fig
e13_passing
```

このように、根音が全音離れた 2 つの和音の間に置き、ベースを半音ずつ進める dim7 を、**経過的なディミニッシュ**（**パッシングディミニッシュ**）という。「経過的」は、2 つの和音の間を通り過ぎるために置く、という意味である。C♯dim7 の構成音は C♯ E G B♭ で、C♯ と B♭ がハ長調の外の音である。

```play
label: I → IIm7 → IIIm7（ベースが全音ずつ上がる）
chords: C Dm7 Em7
key: C
show: chords kbd staff
bass: on
```

```play
label: 経過的なディミニッシュを入れる（ベースが半音ずつ上がる）
chords: C C#dim7 Dm7 D#dim7 Em7
key: C
show: chords kbd staff
bass: on
tempo: 120
```

### 次の和音へ進める理由

**C♯dim7 が Dm へ進む理由.**

**方針**: C♯dim7 の構成音を、2 節の V7/IIm（A7）の構成音と比べる。

**導出**: V7/IIm は A7（A C♯ E G）である。これにテンション ♭9（11 章 3 節。根音 A の短 9 度上の B♭）を足した A7(♭9) は、A C♯ E G B♭ である。ここから根音 A を省くと C♯ E G B♭ が残り、C♯dim7 の構成音と一致する。したがって C♯dim7 は、A7(♭9) から根音を省いた形の和音で、A7 の導音 C♯（D の半音下）と、A7 の 3 度の音と 7 度の音がつくる三全音 C♯–G を、そのまま含んでいる。このため C♯dim7 は、2 節の V7/IIm と同じく、Dm を一時的な主和音とみなしたドミナントとして Dm へ進む ∎

```fig
e13_dimrel
```

ハ長調の代表的な経過的なディミニッシュを、同じ見方でまとめると次のようになる。どれも、後の和音へ向かう V7/X に ♭9 を足し、根音を省いた形である。

| 前の和音 → 後の和音 | 経過的なディミニッシュ | 構成音 | 根音を省く前の和音 |
|---|---|---|---|
| I → IIm（C → Dm） | ♯Idim7（C♯dim7） | C♯ E G B♭ | A7(♭9)（V7/IIm に ♭9） |
| IIm → IIIm（Dm → Em） | ♯IIdim7（D♯dim7） | D♯ F♯ A C | B7(♭9)（V7/IIIm に ♭9） |
| IV → V（F → G） | ♯IVdim7（F♯dim7） | F♯ A C E♭ | D7(♭9)（V7/V に ♭9） |

根音が半音ずつ下がる向きに dim7 を置くこともある（例: IIIm7 → ♭IIIdim7 → IIm7、つまり Em7 → E♭dim7 → Dm7）。E♭dim7（E♭ G♭ A C）は Dm の導音 C♯ を含まないので、上の導出のようなドミナントとしては説明できず、ベースを半音でつなぐ働きが中心になる。

下の図では、ダイアトニックコードだけの進行 I → IIm7 → V7 → I → IV → I の一部を、この章の和音に置き換えられる。置き換えると、帯のディグリーネームと、調の外の音、ベースの動きが変わる。

## 6. まとめ

| 項目 | 内容 |
|---|---|
| ノンダイアトニックコード | 調の外の音（ハ長調では黒鍵の 5 音）を 1 つ以上含む和音。五線では、調の外の音に必ず臨時記号が付く |
| セカンダリードミナント | ダイアトニックコード X を一時的に主和音とみなしたときの V7。V7/X と書く。3 度の音が X の導音になる。ハ長調では A7・B7・C7・D7・E7（VI7・VII7・I7・II7・III7） |
| 借用和音 | 同主調（ハ長調ならハ短調）のダイアトニックコードを借りたもの。E♭・A♭・B♭ のどれかを含む |
| サブドミナントマイナー（SDm） | 借用和音のうち SD と同じ働きで使うもの。IVm・IIm7(♭5)・♭VIM7・♭VII7。どれも A♭ を含み、A♭ が G へ半音で下がる |
| 裏コード | 三全音を共有し、根音が三全音離れた属七の和音。G7 の裏コードは D♭7（♭II7）。D♭7 → C では 4 つの声部がすべて半音で動き、ベースが半音で I へ下がる |
| 経過的なディミニッシュ | 根音が全音離れた 2 つの和音の間に置き、ベースを半音ずつ進める dim7。♯Idim7（C♯dim7）は A7(♭9) から根音を省いた形で、Dm へのドミナントとして働く |

この章の和音は、どれも主音を C に保ったまま、別の調の音を一時的に借りるものだった。次章では、主音そのものが別の音へ移る転調を扱う。
