## 1. 定番の進行を機能で読む

10 章 5 節では、コード進行の和音ごとに機能を書き込んで、進行の流れを読んだ。この節では、名前の付いた定番の進行を、同じやり方で読む。セブンスコードは、7 度の音を除いた三和音と同じ機能として読む（IVM7 は IV と同じ SD、V7 は V と同じ D）。

ここで扱う 4 つの進行を、ハ長調で書く。

- **小室進行**: VIm–IV–V–I（Am–F–G–C）
- **ツーファイブワン**: IIm7–V7–IM7（Dm7–G7–CM7）。前半の IIm7–V7 の 2 つの和音の組を**ツーファイブ**と呼び、その後に IM7（または I）が続く 3 つの組をツーファイブワンと呼ぶ。ローマ数字の II と V を英語で読んだ名前で、ジャズで特によく使われる。
- **王道進行**: IVM7–V7–IIIm7–VIm（FM7–G7–Em7–Am）
- **カノン進行**: I–V–VIm–IIIm–IV–I–IV–V（C–G–Am–Em–F–C–F–G）。17 世紀ドイツの作曲家パッヘルベルの『カノン』の低音と同じ並びであることから、この名前で呼ばれる。

小室進行・王道進行・カノン進行は、日本のポピュラー音楽の解説で広く使われている呼び名で、国際的に共通の名前ではない。4 つの進行の和音に機能を書き込むと、次のようになる。

```fig
e12_famous
```

10 章 5 節の機能の進み方と照らし合わせる。

- 小室進行は T → SD → D → T で、機能の基本の流れそのものである。最初の T に、I の代わりに同じ T の VIm を使っている（代理）。
- ツーファイブワンは SD → D → T で、基本の流れの後半にあたる。SD に、IV ではなく IIm7 を使う。
- 王道進行は SD → D → T → T である。V7 から I ではなく同じ T の IIIm7 へ進み、VIm へ続く。最後の VIm から最初の IVM7 へ戻る動きは T → SD なので、繰り返して使える。
- カノン進行は T → D → T → T → SD → T → SD → D である。V → VIm は、10 章 5 節の例 3 と同じく、偽終止と同じ D → T の動きをフレーズの途中で使ったものである。最後の V は、繰り返すと最初の I へ進む（D → T）。

4 つとも、隣り合う和音の動きは T → SD・T → D・SD → D・SD → T・D → T と、同じ機能どうしの T → T だけでできている。D の次には必ず T が来ていて、D → SD は含まれない。

```

```

## 2. 根音の動き — 4 度・5 度・2 度・3 度

この節では、和音の根音が、次の和音の根音へどう動くかを見る。09 章 5 節で見たように、根音が$`d`$度上がる動きと$`9 - d`$度下がる動きは同じ文字に着くので、根音の動きは 2 度・3 度・4 度（4 度上 = 5 度下、4 度下 = 5 度上）の 3 種類にまとめられる。ダイアトニックコードどうしの共通音は、根音が 3 度動くと 2 つ、4 度動くと 1 つ、2 度動くと 0 で、共通音が少ないほど、和音が変わるときに入れ替わる音が多くなる。1 節の 4 つの進行の根音の動きを、この 3 種類で書き込むと次のようになる。

```fig
e12_rootmoves
```

4 度上の動き（太い矢印）は、どの進行にも現れる。V → I のほか、IIm7 → V7、IIIm7 → VIm、I → IV もこの動きである。

### 強進行 — 根音が 4 度上へ進む

根音が 4 度上（= 5 度下）へ進む動きを**強進行**という。V → I（G → C）、IIm → V（D → G）、IIIm → VIm（E → A）などがこれにあたる。逆向きの 4 度下（= 5 度上）への動きも、共通音の数は同じ 1 つである。2 つの向きで何が違うかを、前の和音の根音に注目して比べる。

```fig
e12_strong
```

- G → C（4 度上）: 前の根音 G は、次の和音 C・E・G の 5 度の音として残る。G は次の根音 C の倍音列（02 章 6 節）の第 3 倍音・第 6 倍音にあたり、前の和音の土台だった音が、次の根音の倍音の 1 つとして含まれる。
- C → G（4 度下）: 前の根音 C は、次の和音 G・B・D に含まれず、G の倍音列にも第 8 倍音までには現れない。逆に、次の根音 G のほうが、前の根音 C の第 3 倍音にあたる。

このように、4 度上へ進むときだけ、前の和音の根音が、次の根音の倍音の中に収まる。そのため次の和音が前の和音の土台として聞こえ、進んだ先に落ち着く感じが強くなる、と説明される。V7 → I では、10 章 3 節の導音と三全音の動きに、この根音の関係が加わっている。

```play
label: G → C（4 度上）と C → G（4 度下）
chords: G:2 C:4 r:2 C:2 G:4
key: C
bass: on
show: chords kbd staff
```

### 循環進行 — 強進行を続ける

05 章 5 節で見たように、長音階の 7 つの音は、完全 5 度の連なり F–C–G–D–A–E–B に並べられる。この並びを右から左へたどると、1 つ進むごとに 5 度下、つまり 4 度上へ進む。ダイアトニックコードの根音を 4 度上へ順にたどると、I → IV → VIIdim → IIIm → VIm → IIm → V → I（C → F → B → E → A → D → G → C）と、7 つの和音をすべて 1 回ずつ通って I に戻る。このうち IV → VIIdim（F → B）だけは、F の完全 4 度上の B♭ が音階に無いので、半音 6 つの増 4 度上になる。ほかの 6 つは、完全 4 度上の強進行である。

この並びの後半のように、強進行を続けて I へ戻る進行を**循環進行**という。VIm–IIm–V–I や IIIm–VIm–IIm–V–I がその例で、I まで来たら始めの和音へ戻って繰り返せる。I の後に VIm を置いた I–VIm–IIm–V を繰り返す形も、循環進行（循環コード）と呼ばれることが多い（I → VIm は 3 度下の動きで、どちらも T）。1 節のツーファイブワン IIm7–V7–IM7 は、循環進行の最後の 2 つの強進行にあたる。

### ベースの線 — 転回形で隣の音へ動かす

ここまでは根音の動きを見てきた。実際にいちばん低い所で聞こえる線は、各和音のベースの並びである。転回形を使うと、根音が跳んでも、ベースは隣の音へ動かせる。

## 3. 声部 — 和音を 4 本の線として見る

1・2 節の再生カードでは、三和音を、ベース（金色）とその上の 3 つの音（紫）の、合わせて 4 つの音で鳴らした。和音が変わると、4 つの音はそれぞれ次の和音のどれかの音へ移る。高いほうから 1 番目の音どうし、2 番目の音どうし、… をつないでいくと、コード進行は、何本かの旋律が同時に進むものとして見えてくる。この 1 本 1 本の旋律を**声部**という。

4 つの声部には、合唱の 4 つのパートにならって、高いほうから**ソプラノ**・**アルト**・**テノール**・**バス**という名前を付ける。各和音のベースは、バスの声部が受け持つ。三和音は 3 つの音しか無いので、4 つの声部で鳴らすときは 1 つの音を重複させる。基本形では根音を重複させることが多い。セブンスコードは、4 つの音を 1 つずつ受け持つか、5 度の音を省いて根音を重複させる（11 章 5 節）。

```fig
e12_voices
```

和音から和音へ進むときの、各声部の動き方を**声部進行**という。図の I–VIm–IIm–V–I では、上の 3 声部（ソプラノ・アルト・テノール）は同じ高さに留まるか隣の音へ動くだけで、バスだけが大きく跳んでいる。バスが根音を受け持っているので、2 節の根音の動きが、そのままバスの動きになる。

声部どうしの間隔は、11 章 5 節の音域の分け方と同じく、低い所を広く、高い所を狭くする。伝統的な和声では、上の 3 声部の隣どうしを 1 オクターブ以内にするのが目安とされ、バスとテノールの間は広くてもよい。各声部の音域は、図の右に示した程度が目安である（資料によって数音の違いがある）。

## 4. なめらかなつなぎ方 — 共通音を残し、近い音へ動く

### 共通音を保持し、ほかの声部は近い音へ

3 節の図の声部進行は、次の 2 つの規則で作った。バスはベースの線（2 節）で決まるので、規則は上の 3 声部に使う。

1. 前の和音と次の和音の共通音は、同じ声部で同じ高さのまま鳴らし続ける。これを**共通音の保持**という。
2. ほかの声部は、次の和音の構成音のうち、音階の上でいちばん近い音へ動かす。

規則を使わずに、各和音を基本形（根音・3 度の音・5 度の音を下から順に密集配置で積んだ形）のまま並べたものと比べる。

```fig
e12_smooth
```

上の 3 声部の動きは、規則どおりの上の図では合わせて 12 半音、基本形のままの下の図では 60 半音である。下では、上の 3 声部が毎回そろって同じ向きに 3〜7 半音ずつ跳んでいる。上の図は 3 節の再生カードと同じなので、下の図だけを再生カードにする。

```play
label: 各和音を基本形のまま並べる（上の 3 声部の動き 60 半音）
v1: G4:4 E4:4 A4:4 D4:4 G4:4
v2: E4:4 C4:4 F4:4 B3:4 E4:4
v3: C4:4 A3:4 D4:4 G3:4 C4:4
v4: C3:4 A2:4 D3:4 G2:4 C3:4
tempo: 120
show: kbd staff
```

規則 2 の「近い音」が、いつもすぐ近くにあることを確かめる。まず、根音の動きの 3 種類ごとに、上の 3 声部がどう動けるかをハ長調の例で見る。

```fig
e12_steps
```

**近い音へ動けることの確かめ.**

**方針**: 上の 3 声部が、和音の 3 つの音を 1 つずつ受け持つとする。前の和音の根音を 0 として、音階の音に上へ 0, 1, 2, … と番号を付け（7 つで同じ文字に戻るので、7 以上の番号からは 7 を引く）、前の和音の音を 0・2・4 番と書く。番号が 1 つ変わる動きは、音階の隣の音への 2 度の動きである。根音の動きの種類ごとに、前の和音の 3 つの番号を次の和音の番号へ 1 つずつ対応させ、各声部の番号がいくつ変わるかを調べる。

**導出**: 根音が音階の上で$`k`$個上の和音（$`k = 1`$なら 2 度上、$`k = 2`$なら 3 度上、…、$`k = 6`$なら 7 度上 = 2 度下）の音は、$`k`$・$`k+2`$・$`k+4`$番である。

- 根音が 3 度動く場合（$`k = 2`$ と$`k = 5`$）: $`k = 2`$ では次の和音が 2・4・6 番なので、2 と 4 を共通音として保持し、残る 0 が 6 へ移る（6 番は 0 番の 1 つ下の音）。$`k = 5`$ では 5・0・2 番なので、0 と 2 を保持し、4 が 5 へ移る。
- 根音が 4 度動く場合（$`k = 3`$ と$`k = 4`$）: $`k = 3`$ では 3・5・0 番なので、0 を保持し、2 → 3、4 → 5 と 2 つの声部が 1 つずつ上がる。$`k = 4`$ では 4・6・1 番なので、4 を保持し、0 → 6、2 → 1 と 2 つの声部が 1 つずつ下がる。
- 根音が 2 度動く場合（$`k = 1`$ と$`k = 6`$）: 共通音が無い。$`k = 1`$ では次の和音が 1・3・5 番である。0 の隣（6 と 1）のうち次の和音の音は 1 だけなので 0 → 1、2 の隣（1 と 3）で残っているのは 3 なので 2 → 3、最後に 4 → 5 となり、3 つとも 1 つずつ上がる。$`k = 6`$ では 6・1・3 番で、4 の隣（3 と 5）のうち次の和音の音は 3 だけなので 4 → 3、続いて 2 → 1、0 → 6 となり、3 つとも 1 つずつ下がる。

どの場合も、保持しない声部は番号が 1 つだけ変わる、つまり 2 度動く。長音階の 2 度は半音 1 つか 2 つである（05 章 2 節）。したがって、共通音を保持すれば、ほかの声部はすべて半音 2 つ以内の動きでつながる。また、根音が 2 度動く場合に、どの声部も 2 度以内で動かそうとすると、3 つの声部はすべて同じ向きに動くしかない ∎

### 2 度の動きと、連続 5 度・連続 8 度

導出の最後に見たように、根音が 2 度動くとき、上の 3 声部をすべて 2 度以内で動かすと、3 つとも同じ向きに動く。このとき何が起きるかを、IV → V で確かめる。

**方針**: 基本形の IV（バスに根音 F、上の 3 声部に F・A・C）から V へ、バスが F から G へ上がり、上の 3 声部も F → G、A → B、C → D と 2 度ずつ上がるとして、バスとの音程が変わるかどうかを調べる。

**導出**: F → G と C → D は、どちらも半音 2 つの上行で、バスの F → G と同じ大きさである。2 つの音が同じ大きさだけ上がると、2 つの音の間の音程は変わらない。したがって、F を受け持つ声部とバスは、オクターブの関係（F どうし）のまま G どうしへ動き、C を受け持つ声部とバスは、完全 5 度の関係（F と C。1 オクターブを足した 12 度）のまま G と D へ動く ∎

2 つの声部がどちらも動いて、完全 5 度から次の完全 5 度へ進むことを**連続 5 度**、完全 8 度から次の完全 8 度へ進むことを**連続 8 度**という。1 オクターブを足した複音程（12 度・15 度など）も同じに数え、同じ高さ（完全 1 度）どうしも連続 8 度に含める。

```fig
e12_parallel
```

04 章 4 節で見たように、完全 8 度（2:1）では上の音のすべての倍音が、完全 5 度（3:2）でも上の音の偶数番目の倍音が、下の音の倍音と一致し、2 つの音が 1 つにまとまって聞こえやすい。2 つの声部がこの関係のまま一緒に動くと、2 本の線ではなく、音色の違う 1 本の線のように聞こえやすくなる。4 つの声部で書く伝統的な和声では、それぞれの声部が独立した線として聞こえることを重んじるので、連続 5 度・連続 8 度を避ける習慣がある。

同じ向きに動くこと自体が問題なのではない。下の再生カードは、同じ旋律に、完全 5 度下の声部と 3 度下の声部をそれぞれ付けたものである。3 度は一致する倍音が少ないので、3 度のまま一緒に動く 2 つの声部は、2 本の線として聞き分けやすい。

```play
label: 完全 5 度のまま動く 2 つの声部（前半）と、3 度のまま動く 2 つの声部（後半）
v1: G4 A4 B4 C5 D5:2 r:2 G4 A4 B4 C5 D5:2
v2: C4 D4 E4 F4 G4:2 r:2 E4 F4 G4 A4 B4:2
tempo: 84
show: kbd staff
```

一方、ロックなどでは、根音と 5 度の音だけの和音を平行に動かして、厚みのある 1 本の線として聞かせる弾き方がよく使われる。連続 5 度・連続 8 度を避けるのは、声部の独立を重んじる書き方での習慣である。1・2 節の再生カードは和音の響きと進行を聞くためのもので、上の 3 つの音を、前の和音からの近さだけで自動的に選んでいる。そのため、小室進行の F → G のように、連続 5 度・連続 8 度を含む所がある。

連続を避けるには、根音が 2 度動く所で、上の 3 声部をバスと反対の向きへ動かす。図の右のように、IV → V でバスが上がるときは上の 3 声部を下げる。F → D の声部だけは 3 度動くが、上の 3 声部の動きの合計は、左と同じ 6 半音である。

```play
label: IV → V（前半: 上の 3 声部も上へ、後半: 上の 3 声部を下へ）
v1: F4:4 G4:4 r:2 F4:4 D4:4
v2: C4:4 D4:4 r:2 C4:4 B3:4
v3: A3:4 B3:4 r:2 A3:4 G3:4
v4: F2:4 G2:4 r:2 F2:4 G2:4
tempo: 120
show: kbd staff
```

### セブンスコードの場合 — ツーファイブワン

セブンスコードでも同じ規則が使える。11 章 5 節では、ツーファイブワンの根音とガイドトーン（3 度の音と 7 度の音）だけを取り出した。そこにもう 1 つの声部を加えて、4 つの声部で書く。

## 5. 進行を組み立てる手順

1〜4 節の内容は、進行を自分で組み立てるときの、次の 4 つの手順にまとめられる。

1. 機能の流れを決める（10 章 5 節の機能の進み方）。
2. 各機能の和音を選ぶ。同じ機能の和音で代理してもよい（1 節）。
3. ベースの線を決める。根音をそのまま使うか、転回形で隣の音へ動かすか（2 節）。
4. 上の 3 声部をつなぐ。共通音を保持し、ほかの声部は近い音へ動かす。根音が 2 度動く所では、上の 3 声部をバスと反対へ動かして、連続 5 度・連続 8 度を避ける（4 節）。

例として、T → T → SD → D → T の流れで、2 つ目の T に VIm、SD に IV を選び、ベースを根音のままとして組み立てる。

```fig
e12_worked
```

④で使った規則は、I → VIm と VIm → IV（3 度の動き）では共通音 2 つの保持、IV → V（2 度の動き）ではバスと反対への動き、V → I（強進行）では共通音 G の保持と 2 度ずつの動きである。

```play
label: I–VIm–IV–V–I（手順どおりに組み立てた 4 つの声部）
v1: E4:4 E4:4 F4:4 D4:4 E4:4
v2: C4:4 C4:4 C4:4 B3:4 C4:4
v3: G3:4 A3:4 A3:4 G3:4 G3:4
v4: C3:4 A2:4 F2:4 G2:4 C3:4
tempo: 120
show: kbd staff
```

下の図で、①機能の流れ、②各機能の和音、③各和音のベース（根音か 3 度の音か）、④上の 3 声部のつなぎ方を選ぶと、4 つの声部の進行が作られて表示され、▶ で鳴る。④を「基本形のまま」や「近い音へ（2 度以内を優先）」に替えると、動きの合計や、2 度の動きの所の連続 5 度・連続 8 度がどう変わるかを比べられる。

## 6. まとめ

| 項目 | 内容 |
|---|---|
| 定番の進行 | 小室進行 VIm–IV–V–I、ツーファイブワン IIm7–V7–IM7、王道進行 IVM7–V7–IIIm7–VIm、カノン進行 I–V–VIm–IIIm–IV–I–IV–V。どれも D の次に T が来る |
| 根音の動き | 2 度・3 度・4 度（= 5 度）の 3 種類。ダイアトニックコードどうしの共通音は 0・2・1 個（09 章 5 節） |
| 強進行 | 根音が 4 度上（= 5 度下）へ進む動き。前の根音が、次の根音の第 3 倍音にあたる |
| 循環進行 | 強進行を続けて I へ戻る進行（VIm–IIm–V–I など）。ツーファイブワンはその最後の部分 |
| ベースの線 | 転回形を使うと、根音が跳んでも、ベースを隣の音へ動かせる |
| 声部 | 和音の音を高さの順につないだ旋律。ソプラノ・アルト・テノール・バスの 4 つ |
| 共通音の保持 | 共通音は同じ声部で鳴らし続け、ほかの声部は近い音へ。ダイアトニックコードどうしなら半音 2 つ以内で動ける |
| 連続 5 度・連続 8 度 | 2 つの声部が完全 5 度・8 度のまま動くと、1 本の線のように溶け合って聞こえやすい。根音が 2 度動く所では、上の 3 声部をバスと反対へ |
| 組み立ての手順 | 機能の流れ → 和音 → ベースの線 → 上の 3 声部 |
