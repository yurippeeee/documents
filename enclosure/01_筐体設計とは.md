# 01. 筐体設計とは — 箱に求められる 7 つの仕事

> **この章のゴール.**
> 筐体（電子機器のケース）が何のためにあり、どんな要求を同時に満たさなければならないかを整理する。
> そして、要求どうしがぶつかること、作り方（製法）は主に**作る数**で決まることを、数字で確かめる。

この章では前提となる既出の用語は無い。単位は長さを mm、力を N（ニュートン）、応力を MPa（$`1\ \text{MPa} = 1\ \text{N/mm}^2`$）で書く。

## 1. 筐体の 7 つの仕事

筐体は「基板を入れる箱」だが、実際には次の 7 つの仕事を同時にしている。

```fig
e01_roles
```

| 仕事 | 内容 | 扱う章 |
|---|---|---|
| **保持** | 基板・電池・表示器などを決まった位置に固定する | [10 章](10_内部の収め方.md) |
| **保護** | 落下・衝撃・荷重から中身を守る | [02 章](02_力と変形の基礎.md)、[11 章](11_落下と衝撃.md) |
| **環境遮断** | 水・ほこりを入れない | [12 章](12_防水と防塵.md) |
| **放熱** | 中で出た熱を外へ逃がす | [13 章](13_熱設計.md) |
| **電磁遮蔽** | 不要な電波を出さない、外から受けない、静電気を逃がす | [14 章](14_EMCと筐体.md) |
| **安全** | 感電・火災・やけど・けがを防ぐ | [15 章](15_安全と規格.md) |
| **操作と外観** | ボタン・表示・コネクタを使えるようにし、製品の顔になる | [16 章](16_外観と操作部.md) |

回路や基板の設計では、筐体は「あとで入れる箱」と思われがちである。しかし上の表のどれか 1 つでも欠けると製品にならない。放熱できなければ部品が壊れ、防水できなければ屋外で使えず、安全規格を満たさなければ売ることができない。

## 2. 要求どうしはぶつかる

7 つの仕事は、互いに逆の方向を求めることが多い。代表的な組み合わせを挙げる。

```fig
e01_conflict
```

| ぶつかる要求 | なぜぶつかるか | よくある落としどころ |
|---|---|---|
| 放熱 ↔ 防水 | 熱を逃がすには空気を通したいが、水やほこりは通したくない | 密閉して壁から熱を逃がす。金属筐体にする。防水通気膜を使う |
| 電磁遮蔽 ↔ 軽さ・コスト | 遮蔽には導電性の壁が要るが、樹脂は電気を通さない | 樹脂の内側に導電塗装やめっきを施す。基板側で対策する |
| 強さ ↔ 薄さ・軽さ | 曲げにくさは板厚の 3 乗で効く（[02 章](02_力と変形の基礎.md)）ので、薄くすると急に弱くなる | 厚くする代わりにリブ（補強の壁）を立てる（[05 章](05_リブとボス.md)） |
| 外観 ↔ 作りやすさ | 継ぎ目やねじ穴を見せたくないが、組み立てには必要 | スナップフィット（[09 章](09_スナップフィット.md)）、ねじを裏面に集める |
| 安全 ↔ 開口 | 操作部やコネクタの穴から指や異物が入る | 穴の大きさと奥行きを制限する（[15 章](15_安全と規格.md)） |

要求がぶつかったとき、どちらかを諦めるのではなく、**形・材料・製法を変えて両方を満たす方法を探す**のが筐体設計である。そのためには、それぞれの要求が「どの物理量で決まっているか」を知っておく必要がある。このシリーズの各章はそれを 1 つずつ扱う。

## 3. 設計の流れ

筐体設計は、次の順に進むことが多い。

```fig
e01_flow
```

1. **要求の整理**: 使う場所（屋内・屋外、温度、水、落下の高さ）、作る数、目標コスト、守る規格を決める。
2. **構想設計**: 基板・電池・コネクタの配置と外形を決め、材料と製法を選ぶ。ここで大きな方向が決まる。
3. **詳細設計**: 肉厚、リブ、ボス、締結、公差、防水構造などを決める。
4. **試作と評価**: 3D プリンタや切削で形を作り、組み立てやすさ、強度、温度、防水、EMC を確かめる。
5. **量産準備**: 金型を作り、量産品で同じ評価を繰り返す。

量産する製品では、試作評価を段階に分けて呼ぶことが多い。

| 段階 | 目的 | 使う部品 |
|---|---|---|
| EVT（Engineering Validation Test） | 設計が機能・性能を満たすか | 試作品（3D プリント、切削） |
| DVT（Design Validation Test） | 量産と同じ材料・製法で、規格試験に通るか | 量産金型の初期成形品 |
| PVT（Production Validation Test） | 量産ラインで安定して作れるか | 量産ラインで作った製品 |

金型を作った後で形を変えるのは、時間も費用も大きい（[17 章](17_試作から量産へ.md)）。そのため、構想設計と詳細設計の段階で、作り方から来る制約を先に織り込んでおくことが大事である。

## 4. 製法は作る数で決まる

同じ形の筐体でも、作り方によって「最初にかかる費用」と「1 個あたりの費用」が大きく違う。

- **初期費用**$`F`$: 金型や治具、加工プログラムなど、作る数によらず最初に 1 回かかる費用。
- **変動費**$`v`$: 材料費や加工時間など、1 個作るごとにかかる費用。

$`N`$個作るときの総費用と、1 個あたりの費用は

$$
C(N) = F + vN, \qquad \frac{C(N)}{N} = \frac{F}{N} + v
$$

である。初期費用は個数で割られるので、作る数が多いほど 1 個あたりの負担は小さくなる。

### どこで製法が入れ替わるか

**方針**: 2 つの製法の総費用が等しくなる個数を求める。それより多く作るなら、初期費用が高く変動費が安いほうが得になる。

**導出**: 製法 1 が$`(F_1, v_1)`$、製法 2 が$`(F_2, v_2)`$で、$`F_1 < F_2`$、$`v_1 > v_2`$とする。総費用が等しくなる個数$`N^\ast`$は

$$
F_1 + v_1 N^\ast = F_2 + v_2 N^\ast \quad\Longrightarrow\quad N^\ast = \frac{F_2 - F_1}{v_1 - v_2}
$$

である。$`N > N^\ast`$なら製法 2 の総費用のほうが小さい ∎

**例**: 手のひら大の樹脂ケース 1 個について、次の値を仮に置く（代表的な桁を示すための例で、実際の見積もりは形状や業者で大きく変わる）。

| 製法 | 初期費用$`F`$ | 1 個あたり$`v`$ |
|---|---|---|
| 3D プリント（外注） | 0 円 | 5,000 円 |
| 注型（シリコン型で樹脂を流す） | 100,000 円 | 2,000 円 |
| 射出成形（アルミ簡易型） | 1,000,000 円 | 150 円 |
| 射出成形（鋼の量産型） | 3,000,000 円 | 80 円 |

- 3D プリントと注型が入れ替わるのは$`N^\ast = (100{,}000 - 0)/(5{,}000 - 2{,}000) \approx 33`$個。
- 注型とアルミ簡易型は$`N^\ast = (1{,}000{,}000 - 100{,}000)/(2{,}000 - 150) \approx 486`$個。
- アルミ簡易型と鋼の量産型は$`N^\ast = (3{,}000{,}000 - 1{,}000{,}000)/(150 - 80) \approx 28{,}600`$個。

数十個なら 3D プリント、数百個なら注型、数千〜数万個なら射出成形、という目安がここから出てくる。実際には、アルミの型は数万〜十数万回の成形で摩耗する、鋼の型は百万回以上もつ、といった寿命の差も判断に加わる。

作る数は、どの製法を選ぶかだけでなく、**形そのもの**を決める。射出成形を選べば、抜き勾配・肉厚の均一化・アンダーカットの回避など、金型から部品を取り出すための制約が形に加わる（[04 章](04_射出成形.md)）。板金を選べば、曲げと展開の制約が加わる（[06 章](06_板金.md)）。そのため、製法は構想設計の早い段階で決める。
