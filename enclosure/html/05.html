Enclosure Design 05 · リブとボス — 厚くせずに強くする

Chapter 05

リブとボス — 厚くせずに強くする

この章のゴール. 射出成形品は肉厚を均一に、できるだけ薄くしたい（04 章）。それでも剛性が要る場所には、リブ（薄い補強の壁）を立てる。 この章では、リブで剛性が何倍になるかを T 形断面の断面二次モーメントから計算し、リブの厚さを肉厚の半分程度にする理由を内接円の幾何で導く。 最後に、ねじを受けるボスと、それを支えるガセットの形の決め方を扱う。

この章で使う既出の用語（定義は各リンク先）. 曲げモーメント\(M\)、中立軸と図心、断面二次モーメント\(I\)（長方形\(bh^3/12\)）、曲げ応力\(\sigma = Mc/I\)、たわみ\(\delta = PL^3/(3EI)\)、剛性\(k = P/\delta\)、板厚の 3 乗則、ひずみ\(\varepsilon\)、フックの法則\(\sigma = E\varepsilon\)（02 章）。 肉厚\(t\)、均一肉厚の原則、ひけ、ボイド、反り、抜き勾配、ショートショット、エジェクタピン、冷却時間の式（04 章）。 ABS などの樹脂、密度\(\rho\)（03 章）。

1. 厚くせずに剛性を上げる

筐体の面がたわむときは、曲げで変形している。02 章の片持ちはりのたわみ\(\delta = PL^3/(3EI)\)と剛性\(k = P/\delta = 3EI/L^3\)が示すように、材料（\(E\)）と長さ（\(L\)）が同じなら、剛性は断面二次モーメント\(I\)に比例する。

幅\(b\)、厚さ\(t\)の板では\(I = bt^3/12\)なので、剛性は板厚の 3 乗に比例する。剛性を上げたいとき、まず思いつくのは板を厚くすることだが、射出成形では次の 3 つの理由で不利である。

  • 冷却時間が肉厚の 2 乗で延び、1 個あたりの費用が上がる（04 章 6 節）。
  • 材料が厚さに比例して増える。
  • 厚い部分は周りより遅れて固まり、ひけ・ボイド・反りが出やすい（04 章 4 節）。

そこで、板は薄いまま、板から垂直に薄い壁を立てる。この補強の壁をリブと呼ぶ。リブを立てた断面は T 字の形（T 形断面）になる。

図は、幅 20 mm の帯について、同じ材料で断面だけを変えて比べたものである（数値は 2 節で計算する）。2 mm の板にリブを 1 本足すと、材料は 18 % 増えるだけで、剛性はおよそ 10 倍になる。同じ材料の量を平らな板に使うと 2.36 mm 厚になるが、剛性は 1.6 倍にしかならない。リブ付きと同じ剛性を平らな板で得るには 4.3 mm 厚が必要で、材料は 1.8 倍、冷却時間は\((4.3/2)^2 \approx 4.6\)倍になる。

リブが効くのは、02 章で見たように、曲げでは中立軸から遠い材料ほど大きく伸び縮みして曲げに抵抗するからである。リブは材料を中立軸から遠くへ運ぶ。

リブは曲げの向きに沿って立てる。長さ方向にたわむ板なら、リブも長さ方向に走らせる。直角の向きに立てたリブは、その向きの曲げにはほとんど効かない。2 方向の曲げやねじれに抵抗させたいときは、リブを格子状に組む。

2. T 形断面の断面二次モーメント

断面二次モーメントと図心

断面を細かい面積\(dA\)に分け、それぞれの中立軸からの距離を\(y\)とすると、断面二次モーメントは

\[ I = \int y^2\,dA \]

である。長方形にこの積分を行うと\(bh^3/12\)になる（02 章）。\(y^2\)の重みが掛かるので、中立軸から遠い材料ほど\(I\)に大きく効く。

T 形断面の\(I\)を求めるには、まず中立軸の位置が要る。02 章で導いたとおり、曲げだけを受ける断面では\(\int y\,dA = 0\)となり、中立軸は断面の図心（面積の重心）を通る。断面の下端から測った高さを\(Y\)、図心の高さを\(\bar{Y}\)、断面積を\(A\)とすると、\(\int (Y - \bar{Y})\,dA = 0\)より\(\bar{Y} = \int Y\,dA / A\)である。

断面がいくつかの長方形からできているとき、長方形\(i\)の面積を\(A_i\)、その図心の高さを\(Y_i\)とすると、積分は長方形ごとの和に分けられて\(\bar{Y} = \sum A_i Y_i / \sum A_i\)となる。

平行軸の定理

各長方形の\(I\)は、その長方形自身の図心を通る軸のまわりなら\(bh^3/12\)で求まる。しかし T 形断面全体の中立軸は、各長方形の図心からずれている。ずれた軸のまわりの\(I\)を求めるのが平行軸の定理である。

方針: 長方形の図心からの距離\(y_c\)と、全体の中立軸からの距離\(y\)の関係\(y = y_c + d\)を\(I = \int y^2\,dA\)に代入して展開する。

導出: 長方形の図心が全体の中立軸から距離\(d\)だけ離れているとする。長方形の中の各点で\(y = y_c + d\)なので

\[ I = \int (y_c + d)^2\,dA = \int y_c^2\,dA + 2d\int y_c\,dA + d^2\int dA \]

である。第 1 項は長方形自身の図心まわりの断面二次モーメント\(I_c\)である。第 2 項の\(\int y_c\,dA\)は、長方形自身の図心から測った距離を面積について足したものなので、図心の定義（\(\int (Y - \bar{Y})\,dA = 0\)）により 0 である。第 3 項の\(\int dA\)は長方形の面積\(A\)である。よって

\[ I = I_c + A d^2 \]

である ∎

T 形断面全体では、板とリブのそれぞれについて\(I_c + A d^2\)を求めて足す。

数値例

幅\(b = 20\) mm、肉厚\(t = 2\) mm の板に、厚さ\(w = 1.2\) mm（\(0.6\,t\)）、高さ\(h = 6\) mm（\(3\,t\)）のリブを 1 本立てる。高さは板の下面（外観面）から測る。抜き勾配とリブの根元の R は無視して長方形とみなす。

（1）面積と図心の高さ:

  • 板: \(A_1 = bt = 20 \times 2 = 40\) mm²、図心の高さ\(Y_1 = t/2 = 1\) mm
  • リブ: \(A_2 = wh = 1.2 \times 6 = 7.2\) mm²、図心の高さ\(Y_2 = t + h/2 = 2 + 3 = 5\) mm
  • 全体: \(A = 40 + 7.2 = 47.2\) mm²
\[ \bar{Y} = \frac{A_1 Y_1 + A_2 Y_2}{A} = \frac{40 \times 1 + 7.2 \times 5}{47.2} = \frac{40 + 36}{47.2} = \frac{76}{47.2} \approx 1.610\ \text{mm} \]

（2）各部の\(I_c\)と距離\(d\):

  • 板: \(I_{c1} = bt^3/12 = 20 \times 2^3/12 = 160/12 \approx 13.33\) mm⁴、\(d_1 = \bar{Y} - Y_1 = 1.610 - 1 = 0.610\) mm、\(A_1 d_1^2 = 40 \times 0.610^2 \approx 14.89\) mm⁴
  • リブ: \(I_{c2} = wh^3/12 = 1.2 \times 6^3/12 = 259.2/12 = 21.60\) mm⁴、\(d_2 = Y_2 - \bar{Y} = 5 - 1.610 = 3.390\) mm、\(A_2 d_2^2 = 7.2 \times 3.390^2 \approx 82.73\) mm⁴

（3）合計:

\[ I = 13.33 + 14.89 + 21.60 + 82.73 \approx 132.6\ \text{mm}^4 \]

最も大きい項はリブの\(A_2 d_2^2\)である。リブの面積は板の 2 割に満たないが、中立軸から遠いので、リブの 2 項の合計\(21.60 + 82.73 = 104.3\) mm⁴ は\(I\)の約 8 割を占める。

同じ質量で何倍の剛性か

質量は断面積に比例する（長さと密度が同じなら）。比べる相手を 3 つ置く。

強さ（応力）はどうか

剛性と違い、強さはそれほど上がらない。曲げ応力\(\sigma = Mc/I\)（02 章）の\(c\)は中立軸から最も遠い点までの距離で、T 形断面ではリブの先端である。

  • リブ付き: \(c = (t + h) - \bar{Y} = 8 - 1.610 = 6.390\) mm、\(I/c = 132.6/6.390 \approx 20.7\) mm³
  • 2.36 mm の平らな板: \(c = 1.18\) mm、\(I/c = 21.91/1.18 \approx 18.6\) mm³

同じ曲げモーメントでの最大応力は\(M/(I/c)\)なので、リブ付きの最大応力は同じ質量の平らな板の\(18.6/20.7 \approx 0.90\)倍にしか下がらない。しかも最大応力が出るのは細いリブの先端である。リブの先端が引っ張られる向きに曲げると、先端から割れが始まりやすい。剛性を上げる目的でリブを使い、強さが要る場合は応力を別に確かめる。

3. リブの寸法の目安

項目目安（代表値）理由
リブの厚さ\(w\)肉厚\(t\)の 0.5〜0.6 倍（外観面でなければ 0.7 倍程度まで）根元の肉だまりを小さくし、ひけを防ぐ（4 節）
リブの高さ\(h\)\(3\,t\)以下高すぎると先端まで樹脂が届きにくく（ショートショット）、勾配で先端が細くなり、倒れやすい
リブの間隔根元どうしで\(2\,t\)以上狭いと金型の間の鋼が薄く細くなり、冷えにくく壊れやすい
根元の R\(0.25\,t\)〜\(0.5\,t\)応力集中を和らげる。大きくしすぎると肉だまりが増える（4 節）
抜き勾配片側 0.5° 程度抜けやすさ。先端が細くなるので付けすぎない

高いリブには抜き勾配の影響が大きく出る。根元の厚さ\(w\)、高さ\(h\)、片側の勾配\(\theta\)なら、先端の厚さは\(w - 2h\tan\theta\)である。\(w = 1.2\) mm、\(h = 6\) mm、\(\theta = 0.5°\)なら\(1.2 - 2 \times 6 \times \tan 0.5° = 1.2 - 12 \times 0.00873 \approx 1.10\) mm になる。剛性を足したいなら、1 本を高くするより、高さ\(3\,t\)以下のリブの本数を増やすほうがよい。

数値は成形業者や材料メーカーの設計ガイドに見られる代表的な値である。外観の要求（ひけを許すか）と材料で変わるので、業者の基準で確認する。

4. 厚いリブはなぜひけるか — 内接円

04 章で見たように、ひけは厚い部分が周りより遅れて固まり、縮むことで起きる。リブの根元では、板とリブが交わるので、板の肉厚\(t\)より厚い部分ができる。その「厚さ」を測る方法として、断面に入る最も大きい円（内接円）の直径\(D\)を使う。平らな板なら\(D = t\)である。\(D\)が\(t\)より大きいほど、その場所は周りより遅く固まる。

方針: 板の下面（外観面）を\(y = 0\)、板の上面を\(y = t\)とし、リブは\(|x| \le w/2\)、\(y \ge t\)の範囲にあるとする。対称性から内接円の中心は\(x = 0\)にある。最も大きい円は、下面に接し、リブの根元の 2 つの角\((\pm w/2,\ t)\)を通る。この条件から半径\(r\)を求める。

導出: 円が下面\(y = 0\)に接するので、中心は\((0, r)\)である。角\((w/2,\ t)\)が円周上にあるので、中心から角までの距離が\(r\)に等しい。横方向の差は\(w/2\)、縦方向の差は\(t - r\)なので、三平方の定理より

\[ \left(\frac{w}{2}\right)^2 + (t - r)^2 = r^2 \]

である。左辺を展開すると\(w^2/4 + t^2 - 2tr + r^2 = r^2\)。両辺から\(r^2\)を引いて\(w^2/4 + t^2 - 2tr = 0\)。\(2tr\)を移項して両辺を\(2t\)で割ると

\[ r = \frac{t^2 + w^2/4}{2t} = \frac{t}{2} + \frac{w^2}{8t}, \qquad D = 2r = t + \frac{w^2}{4t} \]

である。この円がリブの側面や板の上面からはみ出さないことは、\(w \le 2t\)なら成り立つ（円が\(y = t\)の高さで横に広がる幅がちょうど\(w\)で、それより上では狭くなるため）∎

板の肉厚に対する比は

\[ \frac{D}{t} = 1 + \frac{1}{4}\left(\frac{w}{t}\right)^2 \]

である。

リブの厚さ\(w/t\)0.50.60.81.0
交差部の\(D/t\)1.061.091.161.25

リブを肉厚と同じ厚さにすると、交差部は肉厚の 1.25 倍になる。冷却時間は厚さの 2 乗に比例するので（04 章）、交差部は周りの\(1.25^2 \approx 1.56\)倍の時間をかけて固まり、ひけが出る。\(w = 0.5\,t\)〜\(0.6\,t\)なら交差部は 1.06〜1.09 倍、固まる時間は\(1.06^2 \approx 1.13\)〜\(1.09^2 \approx 1.19\)倍で済む。これが「リブの厚さは肉厚の 0.5〜0.6 倍」の理由である。

根元の R の影響

根元の角に半径\(\rho\)の R を付けると、交差部はさらに厚くなる。同じ方法で、内接円が R の円弧に外から接する条件（中心どうしの距離 = \(r + \rho\)、R の中心は\((w/2 + \rho,\ t + \rho)\)）を解くと

\[ r = \frac{(w/2 + \rho)^2 + (t + \rho)^2 - \rho^2}{2(t + 2\rho)} \]

となる（\(\rho = 0\)で前の式に戻る）。\(t = 2\) mm、\(w = 1.2\) mm で計算すると、\(D/t\)は\(\rho = 0\)で 1.09、\(\rho = 0.5\) mm（\(0.25\,t\)）で 1.20、\(\rho = 1\) mm（\(0.5\,t\)）で 1.32 になる。R は応力集中を和らげるが、大きくするほどひけやすくなる。3 節の「\(0.25\,t\)〜\(0.5\,t\)」はこの両者の折り合いである。外観面のひけが特に問題になる場所では、リブを\(0.5\,t\)程度まで薄くし、R を小さめにする。

下の図でリブの高さ・厚さ・本数を変えると、断面の形、断面二次モーメント、同じ質量の平らな板との比、交差部の内接円の比\(D/t\)が表示される。

ひけの判定の目安（\(D/t\)が 1.1 以下なら少ない、1.2 を超えるとひけやすい）は、上の表から置いた目安であり、材料・外観の要求・成形条件で変わる。

5. ボス

ボスは、ねじを締め込んだり、ピンを差し込んだりするための円筒形の突起である。筐体どうしや基板をねじで留める場所に立てる（ねじの選び方と下穴の寸法は08 章）。ボスも板から立つ「厚い部分」なので、リブと同じくひけの原因になる。

項目目安（代表値）理由
外径ねじの呼び径\(d\)の 2〜2.5 倍ねじを締め込むとボスは内側から押し広げられる。外径が小さいと割れる
下穴ねじメーカーの推奨値（08 章）小さいと割れ、大きいとねじ山が浅く抜けやすい
下穴の深さボスの根元近くまで掘る根元の肉を減らし、ひけを防ぐ。ねじの長さより深くしておく
下穴の入口面取りまたは座ぐり（浅い段）ねじを入れやすく、入口の割れを防ぐ
根元の R\(0.25\,t\)〜\(0.5\,t\)応力集中を和らげる。大きすぎるとひける
抜き勾配外周 0.5° 程度、下穴は小さめ抜けやすさ。下穴の勾配はねじのかかりに影響する

外径を\(2\,d\)〜\(2.5\,d\)にすると、ボスの壁の厚さはリブの目安（\(0.5\,t\)〜\(0.6\,t\)）より厚くなることが多い。外観面のひけを抑えるには、下穴を根元まで深く掘る、ボスを外観面の裏に置かない、外観面にシボを付けてひけを目立たなくする、などを組み合わせる。

孤立したボスを避ける

高いボスを板の上に 1 本だけ立てると、次の問題が起きる。

  • ねじを締める力や横からの荷重で、根元に曲げモーメントがかかって折れやすい。
  • 細長い突起の先端まで樹脂が届きにくく、空気も逃げにくい（ショートショット、焼け）。
  • 冷え方が周りと違い、倒れたり傾いたりする。

そこで、ボスはリブで支える。近くに側壁があれば、ボスと側壁を薄いリブ（つなぎリブ）でつなぐ。側壁が遠ければ、ボスの周りに次の節のガセットを立てる。

ボスを側壁に直接くっつけてはいけない。ボスと壁が重なった部分が厚くなり、側壁の外観面に大きなひけが出る。ボスは壁から少し離して立て、リブでつなぐ。

6. ガセット

ガセットは、ボスや立ち壁の根元を支える三角形のリブである。根元にかかる曲げモーメントを、底の板へ広い範囲で逃がす。

  • 厚さ: リブと同じく肉厚の 0.5〜0.6 倍程度（代表値）。厚くするとガセットとボス・板の交差部がひける。
  • 高さ: ボスの高さより少し低くし、ボスの先端はねじの座面として平らに残す。
  • 配置: ボス 1 本に 2〜4 枚を放射状に配置する。ボスへの横荷重がかかる向きに合わせる。
  • 立ち壁の支え: 背の高い側壁、コネクタを受ける壁、ヒンジの壁などにも、壁と底板の角にガセットを入れる。壁が倒れる向きの剛性が上がる。

ガセットの根元はボスと同じく応力が集中するので、根元に R を付ける。ただしガセットとボス、ガセットと底板が交わる場所は肉だまりになりやすいので、R は小さめにする。
