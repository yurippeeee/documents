Chapter 16

外観と操作部 — 見た目と押し心地を数字で決める

この章のゴール. 筐体の見た目を決める要素（面、合わせ目、成形の跡、表面処理）を整理し、合わせ目のばらつきを目立たなくする見切りの考え方を身につける。 次に、ボタンの押し荷重を片持ちはりの式から計算し、表示窓・導光の全反射の条件を屈折率から導く。

この章で使う既出の用語（定義は各リンク先）. 片持ちはり、断面二次モーメント\(I = bh^3/12\)、曲げモーメント\(M\)、曲げ応力\(\sigma = Mc/I\)、たわみ\(\delta = PL^3/(3EI)\)、剛性\(k = P/\delta\)、ヤング率\(E\)、ひずみ\(\varepsilon\)とフックの法則\(\sigma = E\varepsilon\)（02 章）。 樹脂の種類（ABS, PC, PC/ABS, PP, POM）と金属の種類（アルミ板 A5052 など）（03 章）。 金型の固定側・可動側、パーティングライン、エジェクタピン、ゲート、ひけ、ウェルドライン、抜き勾配（04 章）。 公差、ワーストケース積み上げ、RSS（07 章）。許容ひずみ（09 章）。

1. 外観品質を決めるもの

人が製品を見て「きれい」「安っぽい」と感じる理由の多くは、次の 2 種類に分けられる。

  • 面の質: 面そのものの形（平らさ、曲面のつながり）と、表面の質感（つや、凹凸、色）。
  • 境目と跡: 部品どうしの合わせ目、成形でできる跡。人の目は、広い面よりも線や点の乱れに敏感である。

射出成形品（04 章）では、作り方そのものが表面に跡を残す。どの跡が、どこに、なぜできるかを知っておけば、「見える面に出さない」設計ができる。

跡・不良何か見える面に出さない方法
パーティングライン固定側と可動側の金型の合わせ目に残る細い線。わずかな段差やバリ（はみ出した薄い樹脂）になることがある稜線（面の角）や部品の合わせ目の位置に置く。広い平面の途中に置かない
ゲート跡樹脂の入口を切り離した跡。小さな突起や変色になる内側の面か、組み立て後に隠れる位置に置く。外面に置くなら目立たないゲート方式を業者と相談する
エジェクタ跡製品を押し出すピンの丸い跡。わずかな凹凸やつやの違いになる可動側（通常は内側）の面、リブやボスの上に置く
ひけ厚い部分が冷えて縮むときに表面がへこむ現象外面の裏にリブ・ボスを立てるときは根元を薄くする（05 章）
ウェルドライン2 つの流れがぶつかって合流した線。細い線や色むらとして見えるゲートの位置と数を変えて、合流点を目立たない場所に移す

外観面（意匠面という。製品の外から見える面）を最初に図面で指定し、それ以外の面に跡を集めるのが基本である。業者との打ち合わせでは「どの面が意匠面か」「ゲートとエジェクタをどこに置いてよいか」を図で渡す。

2. 見切り線 — ばらつきを目立たなくする合わせ目

隙間と段差

2 つの部品が接する境目を見切り（見切り線）という。見切りの見え方は、次の 2 つの量で決まる。

  • 隙間（ギャップ）: 2 つの部品の間の、面に沿った方向のすき間の幅。
  • 段差（フラッシュ）: 2 つの部品の表面の、面に垂直な方向の高さの差。

どちらも部品の寸法ばらつき（公差）の積み上げで決まるので、0 にはならない。

例: 上ケースと下ケースの外面を同じ高さにそろえる（段差の基準値 0 mm）。それぞれの外面の位置が合わせ面に対して\(\pm 0.1\) mm ばらつくとする（代表的な桁を示す仮の値）。ワーストケース積み上げ（07 章）では段差は

\[ 0 \pm (0.1 + 0.1) = 0 \pm 0.2\ \text{mm} \]

になり、RSS では\(\pm\sqrt{0.1^2 + 0.1^2} = \pm 0.14\) mm になる。基準値が 0 なので、上が出っ張る製品と下が出っ張る製品が混ざる。段差の向きが製品ごとに入れ替わると、指で触れたときにも目で見たときにも「合っていない」と感じられる。

わざと溝や段にする

方針: ばらつきを 0 にはできないので、ばらつきが見えても気にならない形にする。

  • 段付き見切り: 片方の部品をわざと一定量（例えば 0.3〜0.5 mm）引っ込める。段差は\(0.5 \pm 0.2\) mm なら 0.3〜0.7 mm の範囲になり、向きは常に同じである。段の大きさが少し変わっても、「デザインとしての段」に見える。
  • 溝付き見切り: 合わせ目に意図的な溝（V 溝やコの字の溝）を設ける。溝の影の中に隙間のばらつきが隠れる。
  • 面取り・R: 合わせ目の両側の角を少し落とす。角が鋭いままだと、わずかな段差でも光の反射ではっきり見える。

同じ考え方は、ボタンと穴の隙間、表示窓と枠の境目、電池ふたの合わせ目にも使える。隙間をただ小さく指定するより、隙間が多少変わっても均一に見える形にするほうが、量産で外観をそろえやすい。

3. 表面処理と印刷

表面処理の比較

意匠面の質感は、成形・加工のあとに施す表面処理、または金型の表面の仕上げで決まる。代表的なものを比べる。

処理対象何をするか長所注意点
シボ樹脂（金型側で加工）金型の表面に細かい凹凸の模様を付け、成形品に写す追加工程なし。傷・指紋・ひけ・ウェルドが目立ちにくい凹凸が深いほど抜き勾配を大きくする必要がある（業者のシボ見本で確認）
鏡面樹脂（金型側で研磨）金型を磨き、つやのある面を写す高級感、透明部品の透明度傷・ひけ・ウェルド・ほこりがすべて目立つ。金型の磨きに費用がかかる
塗装樹脂、金属塗料を吹き付けて乾かす色・つやの自由度が高い。成形の跡を隠せる工程が増え、ほこりの付着で不良が出る。はがれや摩耗の試験が要る
めっき金属、めっき用の樹脂（ABS など）金属の薄い膜を付ける金属の見た目、導電性樹脂のめっきは材料と前処理が限られる。厚みが部分によって変わる
アルマイトアルミ表面を電気化学的に酸化させて硬い膜を作る。染料で着色できる傷に強い、着色できる膜は電気を通しにくい（接地する面はマスクする。14 章）。合金によって色が変わる
ヘアライン金属一方向に細い研磨線を付ける金属らしい質感、小傷が目立ちにくい方向があるので、部品間で向きをそろえる

膜を付ける処理（塗装、めっき、アルマイト）は、厚みの分だけ寸法が変わる。はめあいや見切りの寸法は、処理後の寸法で考える。

印刷と刻印

文字や記号を表面に付ける方法も比べておく。

方法何をするか向く面注意点
シルク印刷網目の版を通してインクを押し出す平面曲面は苦手。インクの摩耗を試験する
パッド印刷柔らかいシリコンのパッドでインクを写し取って押し当てる曲面、凹んだ面大きな面の印刷には向かない

4. 二色成形とインサート成形

1 つの部品の中で、2 つの材料を一体にする成形法がある。

  • 二色成形: 1 つ目の材料を成形したあと、金型の一部を入れ替えて（または回転させて）2 つ目の材料を重ねて成形する。硬い樹脂と軟らかいエラストマー（ゴムのように伸び縮みする樹脂）を組み合わせて、滑り止めのグリップやボタンのシール部を作る。色の違う 2 つの樹脂で、文字や窓を作ることもある。
  • インサート成形: 金属の部品（ナット、端子、板金）や、先に作った樹脂部品を金型の中に置き、その周りに樹脂を流し込む。ねじ用のナットを埋め込む（08 章）、端子を樹脂で固定する、などに使う。

どちらも組み立て工程を減らし、すき間のない一体部品を作れる。その代わり、金型が複雑になって初期費用が上がる。2 つの材料が互いにくっつくか（接着性の組み合わせ）は材料メーカーの資料で確認し、くっつかない組み合わせでは、形で引っかける（アンダーカットや貫通穴に樹脂を回す）。

5. ボタンと押し心地

ボタンの種類

電子機器のボタンは、基板上のスイッチを外から押すための部品である。代表的な 3 種類を比べる。

種類構造長所注意点
ラバーキーシリコーンゴムの成形品。中央の柱の下に導電性の接点（カーボンなど）があり、基板の櫛形パターンを直接つなぐ。押すと薄いスカート部が座屈してクリック感が出る安い、防水しやすい、多数のキーを 1 部品にできる押し心地はやわらかめ。接点の抵抗が大きめ
ヒンジ付き樹脂ボタン筐体や枠と一体の薄い腕（ヒンジ）の先にボタンがあり、腕をたわませて基板上のタクトスイッチを押す部品が増えない。外観を筐体とそろえやすいヒンジが硬すぎると重く、薄すぎると割れる。押し荷重を計算で決める
メタルドーム薄い金属の皿形のばねを基板の接点の上に貼る。押すと皿が裏返ってクリック感が出るはっきりしたクリック感、薄い上に被せるシートや樹脂キーの設計と組み合わせて評価する

タクトスイッチ（タクタイルスイッチ）は、内部にメタルドームを持つ基板実装の小さなスイッチで、ヒンジ付きボタンの下によく使われる。

荷重とストローク、クリック率

押し心地は、押し込んだ距離と、そのとき指が受ける力の関係で表す。

  • ストローク: ボタンを押し込む距離 [mm]。
  • 荷重–ストローク曲線: 横軸にストローク、縦軸に押す力 [N] をとったグラフ。

メタルドームやラバーキーの曲線は、途中で山を越えて下がり、底で再び上がる。

  • 作動荷重\(F_1\): 曲線の山の力。ここを越えると、ばねが急に裏返る（座屈する）。
  • 戻り荷重\(F_2\): 山を越えたあとの谷の力。

力が\(F_1\)から\(F_2\)へ急に下がるので、指は「抜ける」感覚を受ける。これがクリック感である。その強さを表す量としてクリック率を次のように定義する。

\[ \text{クリック率} = \frac{F_1 - F_2}{F_1} \times 100\ [\%] \]

例: \(F_1 = 2.0\) N、\(F_2 = 1.1\) N なら、クリック率は\((2.0 - 1.1)/2.0 \times 100 = 0.9/2.0 \times 100 = 45\) % である。

クリック率が大きいほど「カチッ」とした感触になり、小さいほどやわらかい感触になる。部品メーカーのデータシートには、作動荷重とストローク、クリック率（または戻り荷重）が載っているので、その値で選ぶ。代表的には、メタルドームやタクトスイッチでクリック率 30〜50 % 程度の品種が多いが、品種によって大きく違うのでデータシートで確認する。

ヒンジ付きボタンでは、指が感じる力は「ヒンジをたわませる力」と「スイッチの力」の和になる。ヒンジが硬すぎると、スイッチのクリック感がヒンジの力に埋もれて分かりにくくなる。

6. ヒンジ式ボタンの押し荷重を求める

モデル

ヒンジを、根元が筐体に固定された長さ\(L\)、幅\(b\)、厚さ\(t\)の片持ちはり（02 章）とみなす。ボタンの頭は硬く、ヒンジの先端に付いていて、指の力\(P\)はヒンジの先端にかかると仮定する（ボタンの頭が長く、力の位置がヒンジの先端から離れる場合は、この仮定より柔らかくなる。厳密には有限要素解析や実測で確かめる）。

押し荷重とひずみの式

方針: 片持ちはりのたわみの式\(\delta = PL^3/(3EI)\)を\(P\)について解き、押し込み量\(\delta\)を与えたときの押し荷重を求める。次に、根元の曲げ応力からひずみを求め、\(P\)を消して\(\delta\)で表す。

導出: たわみの式の両辺に\(3EI\)を掛け、\(L^3\)で割ると

\[ \delta = \frac{PL^3}{3EI} \quad\Longrightarrow\quad 3EI\delta = PL^3 \quad\Longrightarrow\quad P = \frac{3EI\delta}{L^3} \]

長方形断面の\(I = bt^3/12\)を代入すると

\[ P = \frac{3E\delta}{L^3}\cdot\frac{bt^3}{12} = \frac{E b t^3 \delta}{4L^3} \]

根元の曲げモーメントは\(M = PL\)、断面の中立軸から表面までの距離は\(c = t/2\)なので、根元表面の曲げ応力は

\[ \sigma = \frac{Mc}{I} = \frac{PL \cdot (t/2)}{I} \]

ここに\(P = 3EI\delta/L^3\)を代入すると、\(I\)が約分されて

\[ \sigma = \frac{3EI\delta}{L^3}\cdot\frac{L t}{2I} = \frac{3E t \delta}{2L^2} \]

フックの法則\(\varepsilon = \sigma/E\)より

\[ \varepsilon = \frac{3 t \delta}{2L^2} \]

である ∎

2 つの式から次のことが分かる。

  • 押し荷重\(P\)は\(t^3\)に比例し、\(L^3\)に反比例する。ヒンジを 0.1 mm 厚くするだけで荷重は大きく変わる。
  • ひずみ\(\varepsilon\)は材料（\(E\)）によらず、形（\(t\), \(L\)）と押し込み量\(\delta\)だけで決まる。ヒンジを長くすると、荷重もひずみも下がる。

数値例

例: PC（\(E = 2300\) MPa、代表値）のヒンジで、\(L = 8\) mm、\(b = 4\) mm、\(t = 0.8\) mm、押し込み量\(\delta = 0.5\) mm とする。

  1. 断面二次モーメント: \(I = bt^3/12 = 4 \times 0.8^3 / 12 = 4 \times 0.512 / 12 = 0.1707\) mm⁴
  2. 押し荷重: \(P = 3EI\delta/L^3 = 3 \times 2300 \times 0.1707 \times 0.5 / 8^3 = 588.8 / 512 = 1.15\) N
  3. 剛性: \(k = P/\delta = 1.15 / 0.5 = 2.3\) N/mm
  4. 根元のひずみ: \(\varepsilon = 3t\delta/(2L^2) = 3 \times 0.8 \times 0.5 / (2 \times 64) = 1.2/128 = 0.0094\)（0.94 %）
  5. 根元の曲げ応力: \(\sigma = E\varepsilon = 2300 \times 0.009375 = 21.6\) MPa

ヒンジの下にタクトスイッチ（作動荷重 1.6 N の品種を仮定）があれば、スイッチが作動する瞬間に指が感じる力はおよそ\(1.15 + 1.6 = 2.75\) N になる（ヒンジの力は押し込み量に比例するので、スイッチに当たるまでの距離によって変わる）。

7. 表示窓と導光

全反射と臨界角

基板上の LED の光を筐体の表面まで運ぶ透明な部品を導光体（ライトパイプ）という。導光体は、光が材料の内側の面で全反射（境界で光がすべて反射し、外へ出ない現象）することを利用している。

光が屈折率\(n_1\)の材料から屈折率\(n_2\)の材料へ進むとき、境界の法線（面に垂直な線）からの入射角\(\theta_1\)と屈折角\(\theta_2\)の間にはスネルの法則

\[ n_1 \sin\theta_1 = n_2 \sin\theta_2 \]

が成り立つ。屈折率は、真空中の光の速さを材料中の光の速さで割った値で、空気はほぼ 1 である。

方針: 樹脂（\(n_1 = n\)）から空気（\(n_2 = 1\)）へ出る光で、屈折角がちょうど 90°（境界に沿って進む）になる入射角を求める。これより大きい入射角では屈折光が無くなり、全反射する。この境目の角を臨界角\(\theta_c\)という。

導出: スネルの法則に\(n_1 = n\)、\(n_2 = 1\)、\(\theta_1 = \theta_c\)、\(\theta_2 = 90^\circ\)を代入する。\(\sin 90^\circ = 1\)なので

\[ n \sin\theta_c = 1 \times 1 \quad\Longrightarrow\quad \sin\theta_c = \frac{1}{n} \quad\Longrightarrow\quad \theta_c = \arcsin\frac{1}{n} \]

である ∎

導光体によく使う樹脂の値（屈折率は代表値。グレードと波長で少し変わる）:

材料屈折率\(n\)\(\sin\theta_c = 1/n\)臨界角\(\theta_c\)
PMMA（アクリル）1.490.67142.2°
PC（ポリカーボネート）1.5850.63139.1°

屈折率が大きいほど臨界角は小さく、全反射しやすい。

まっすぐな導光体と 45° の反射面

まっすぐな部分: LED の光が端面から入ると、空気側の入射角が最大の 90° でも、樹脂の中での屈折角は\(\theta_c\)以下になる（スネルの法則を逆向きに使う）。この光が側面に当たるときの入射角は\(90^\circ - \theta_c\)以上である。これが\(\theta_c\)以上なら全反射するので、条件は

\[ 90^\circ - \theta_c \ge \theta_c \quad\Longrightarrow\quad \theta_c \le 45^\circ \quad\Longrightarrow\quad \frac{1}{n} \le \sin 45^\circ = \frac{1}{\sqrt{2}} \quad\Longrightarrow\quad n \ge \sqrt{2} \approx 1.414 \]

である。PMMA も PC もこれを満たすので、側面が滑らかでまっすぐなら、端面から入った光はすべて側面で全反射しながら進む。

45° の反射面: 横に並んだ LED の光を 90° 曲げるには、導光体の角を 45° に切った面で反射させる。軸に平行な光はこの面に 45° で当たる。45° は PMMA の臨界角 42.2° より大きいので全反射する。ただし、光が軸から\(\varphi\)だけ傾いていると入射角は\(45^\circ - \varphi\)に減り、\(45^\circ - \varphi < \theta_c\)になった光は外へ漏れる。漏れずに済む傾きは PMMA で\(45 - 42.2 = 2.8^\circ\)まで、PC で\(45 - 39.1 = 5.9^\circ\)までしかない。実際の LED の光は広がっているので、45° の反射面からは光の一部が漏れる。反射面の外側にアルミ蒸着や白い反射材を置く、反射面を 2 段に分けて角度を小さくする、などで補う。

曲げた導光体

方針: 導光体を円弧に曲げたとき、軸に平行に入った光が外側の壁に当たる入射角の最小値を求め、それが\(\theta_c\)以上になる条件を出す。

導出: 曲げの中心から内側の壁までの半径を\(R_i\)、外側の壁までを\(R_o = R_i + w\)（\(w\)は導光体の幅）とする。曲げの入口で中心から距離\(r\)（\(R_i \le r \le R_o\)）の位置を軸に平行に進む光は、外側の壁（半径\(R_o\)の円）に当たる。当たった点で、壁の法線は中心を向くので、中心から光の直線までの距離\(r\)と法線の長さ\(R_o\)で直角三角形ができ、入射角\(\theta\)は

\[ \sin\theta = \frac{r}{R_o} \]

を満たす。\(r\)が最も小さい\(r = R_i\)のとき入射角が最小になる。全反射の条件\(\sin\theta \ge \sin\theta_c = 1/n\)をこの最小の場合に当てはめると

\[ \frac{R_i}{R_i + w} \ge \frac{1}{n} \quad\Longrightarrow\quad n R_i \ge R_i + w \quad\Longrightarrow\quad (n - 1) R_i \ge w \quad\Longrightarrow\quad R_i \ge \frac{w}{n - 1} \]

である ∎

PMMA（\(n = 1.49\)）では\(R_i \ge w/0.49 = 2.04w\)、PC（\(n = 1.585\)）では\(R_i \ge w/0.585 = 1.71w\)となる。例えば幅 2 mm の PMMA の導光体なら、内側の曲げ半径を 4.1 mm 以上にする。これは軸に平行な光だけの条件なので、広がりのある光ではさらに大きな半径が要る。急な曲げしか置けないときは、曲げの外側に反射材を置く。

光漏れ

導光や表示窓で起きやすい不具合は光漏れである。

  • 隣への漏れ: 並んだ LED の光が隣の導光体や窓にも入り、消えているはずの表示が光る。
  • 筐体の透け: 白や薄い色の樹脂は光を通すので、LED の周りの筐体自体がぼんやり光る。
  • すき間からの漏れ: 導光体と穴のすき間から光が出て、輪郭がにじむ。

対策は、LED ごとに遮光壁（光を通さない壁。リブや黒いスポンジ）で囲む、筐体の内面を黒く塗る、肉を厚くする、導光体の出口以外の面に遮光の印刷をする、などである。外観の色が決まったら、量産と同じ色の樹脂で光らせて確かめる。

8. コネクタ開口、ラベルと刻印

コネクタ開口の見せ方

USB などのコネクタの穴は、基板上のコネクタの位置ばらつきと、筐体の穴の位置ばらつきの両方を受ける（07 章、10 章）。穴を小さく作ると、ばらつきによってプラグが穴の縁に当たる。穴を大きく作ると、穴とコネクタのすき間が不揃いに見える。

  • 穴の周りを少し凹ませた座ぐり（皿状のくぼみ）にする。プラグの位置決めを助け、すき間のばらつきが影の中に入る。
  • コネクタの金属の外殻と穴の縁の間を見えにくくするため、穴の奥に黒い縁や遮蔽の壁を設ける。
  • 穴の縁に小さな面取りを付け、プラグを差し込みやすくする。

ラベルと刻印

製品には、型番、定格、認証マーク、製造番号などの表示が要る。何を書くかは規格や法令で決まるので、15 章と各規格の原文で確認する。表示の付け方は次のように選ぶ。

  • 金型に彫る: 型番や材料の識別記号（リサイクル用の樹脂の記号など）など、全数で同じ内容。費用はかからないが、内容を変えるには金型の修正が要る。
  • レーザー刻印: 製造番号のように 1 台ごとに変わる内容。版が要らない。
  • ラベル: 印刷したシールを貼る。内容を変えやすい。はがれ・こすれ・熱への耐久性を、ラベル材料と使用環境で確かめる。ラベルを貼る面は、ラベルより一回り大きい浅いくぼみにすると、端がはがれにくく、外観も整う。
