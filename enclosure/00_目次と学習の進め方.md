# 00. 目次と学習の進め方

## このシリーズの狙い

電子機器の**筐体**（ケース）は、基板を入れる箱であると同時に、中身を落下・水・熱・電磁ノイズから守り、使う人の安全を確保し、操作と外観で製品の顔になる部品である。

回路や基板の設計に慣れたエンジニアでも、筐体を設計しようとすると「この厚さで割れないか」「金型から取り出せる形か」「ねじは何 N·m で締めるのか」「防水のパッキンはどれだけつぶすのか」といった、機械設計の問いに次々と出会う。このシリーズは、そうした問いに**物理量と式で答えられる**ようになることを目標にする。

- 各章の判断は、応力、たわみ、ひずみ、熱抵抗、遮蔽効果など、**数字で確かめられる量**に結びつける。
- 式は天下りに置かず、**方針 → 導出**の順に、途中式を飛ばさずに書く。
- 図と、数値を動かして確かめられる**ウィジェット**を各章に置く。

## 読む順番

- **順番に読むのが基本**である。特に [02 章](02_力と変形の基礎.md)の応力・ひずみ・片持ちはりの式は、05・08・09・11・16 章で繰り返し使う。
- **まず全体を知りたい**ときは、01 → 04 → 07 → 17 の順に読むと、要求の整理から量産までの流れがつかめる。
- **樹脂ケースを設計する**ときは、01 → 02 → 03 → 04 → 05 → 09 → 07 → 08 の順に読み、そのあと必要な「守る」章（11〜15）へ進む。
- **板金ケースを設計する**ときは、01 → 02 → 03 → 06 → 07 → 08 のあと、熱（13 章）と EMC（14 章）を読む。
- **防水・屋外機器**なら 12 章と 13 章を、**電源を扱う機器**なら 15 章を、早い段階で読む。

各章の冒頭には「この章で使う既出の用語」の欄があり、前の章で定義した用語と式にリンクしている。分からない用語が出てきたら、そのリンク先に戻る。

## 前提知識

- **高校の数学**: 一次方程式・連立方程式、累乗と平方根、三角関数（sin, cos, arcsin）、指数・対数（dB の計算）。
- **高校の物理**: 力とつり合い、速度と加速度、エネルギー、熱量、光の屈折、電磁気の基本。
- **電子回路と基板の基本**: 部品、基板、コネクタ、グラウンド、周波数。
- 機械設計の知識は前提にしない。機械の用語は、初めて出たところで定義する。

## 単位

本文は次の単位で書く。

| 量 | 単位 | 補足 |
|---|---|---|
| 長さ | mm | |
| 力 | N | 1 kgf ≒ 9.8 N |
| 応力・ヤング率 | MPa | $`1\ \text{MPa} = 1\ \text{N/mm}^2`$ |
| 質量 | g または kg | |
| 温度 | °C | 温度差は K と書くこともある（1 K = 1 °C の差） |

本文の数値（材料の物性、設計の目安、費用、期間）は**代表値**である。実際の設計では、材料メーカーのデータシート、加工業者の設計基準、規格の原文で必ず確認する。

## ウィジェットの使い方

各章のブラウザ版（`html/` フォルダの HTML）には、式の値を動かして確かめられる**ウィジェット**がある。Markdown のままでは表示されないので、HTML を開いて使う。

- **スライダー**を動かすと、グラフと数値の表がすぐに更新される。選択欄で材料などを切り替えられるものもある。
- グラフの線や点の色は、下の数値の表の ■ の色と対応している。
- 数値はウィジェットの中の式で計算した値で、本文の数値例と同じ式を使っている。本文の例と同じ値に合わせて、結果が一致することを確かめるとよい。
- 画面右上の切り替えで、ライト表示とダーク表示を選べる。
- [17 章](17_試作から量産へ.md)のチェックリストは、チェックの状態をそのブラウザの中にだけ保存する（他の端末や他の人とは共有されない）。
