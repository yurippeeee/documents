Embedded Black-box Testing

組み込みシステムを外からテストする

生成 AI にファームウェアを書かせる時代。動くコードはすぐ出るが、省電力の抜け・境界の取り違え・例外の未処理・認証の省略・長時間の劣化は、コードを読むだけでは分からない——動かして、外から測るしかありません。このシリーズは、ソースを見ずに機器を検証する道具箱です。電源の消費電流から状態を読み、ロジアナで信号を覗き、UART・I²C・SPI の会話を盗聴し、BLE・Wi-Fi・サブ GHz の電波を可視化し、USB 記述子を解き、レイテンシとジッタを測り、ファジングと堅牢性・セキュリティで追い込み、最後に HIL とハーネスと CI で「AI が直すたび自動で全部走る」仕組みへ育てます。全 20 章のデモ（LIVE・計 20 点）は ブラウザ上で実際に動きます——電流波形も、ボーレート推定も、BLE アドバタイズのデコードも、指で確かめられます。▶ まず「目次と学習の進め方」から

第 I 部 — 土台

白箱との違い、オラクル問題、刺激・観測・判定。以降の全章で使う考え方です。

CH 01ブラックボックステストとは中身を信じず外から確かめる。白箱/灰箱/黒箱、オラクル問題、観測点。▶ LIVE CH 02テスト設計の土台刺激・観測・判定の 3 段。再現性と記録。テストダブル（偽物）の威力。▶ LIVE

第 II 部 — 配線で触れる観測

電源・GPIO・シリアル・バス・アナログ・デバッグ。多くの機器で最初に効く技です。

CH 03電源と消費電流から状態を読む機器は電流でしゃべる。シャント/PPK2。スリープ落ちの欠陥がここに出る。▶ LIVE CH 04デジタル信号の観測ロジアナとオシロ。サンプリング 4〜10 倍則。プロトコルデコーダ。▶ LIVE CH 05UART とシリアルコンソール機器が漏らす一番のヒント。線探し、ボーレート推定、8N1 フレーム。▶ LIVE CH 06I²C と SPI周辺 IC との会話を盗聴し、偽センサで異常値を注入して反応を見る。▶ LIVE CH 07アナログ周辺とセンサADC・DAC・PWM。物理世界を電圧で模擬。境界・飽和・校正・フェイルセーフ。▶ LIVE CH 08デバッグポート経由の観測SWD/JTAG のグレーボックス。RTT/SWO で止めずに覗く。開発機 ≠ 製品。▶ LIVE

第 III 部 — 無線を見る・つつく

線がない相手を可視化する。BLE から独自サブ GHz、有線 USB まで。

CH 09BLE ① 仕組みと状況把握GAP と GATT。接続せずアドバタイズを聞き、bleak で GATT を並べる。▶ LIVE CH 10BLE ② 能動テストとファジングread/write/notify。4 軸ファジング。生存確認と接続の乱れへの耐性。▶ LIVE CH 11Wi-Fi とネットワークnmap・Wireshark・mitmproxy・curl。ポート・平文・認証認可・接続の乱れ。▶ LIVE CH 12サブGHz・独自無線と SDRRTL-SDR とウォーターフォール。変調解析。受信は自由・送信は規制。▶ LIVE CH 13USB とその他の有線記述子が語る正体。usbmon・Facedancer。CAN・RS-485 も同じ発想。▶ LIVE

第 IV 部 — 質を測る・追い込む

機能の正しさの先へ。速さと揺れ、想定外の入力、そして守り。

CH 14タイミングとリアルタイム性レイテンシ・ジッタ・デッドライン。分布で見る。観測が対象を乱す罠。▶ LIVE CH 15HIL — ハードウェア・イン・ザ・ループ実機はそのまま、周囲の世界を PC で模擬。時刻付きシナリオで自動化。▶ LIVE CH 16ファジングと堅牢性・長時間試験枯渇・電源環境ストレス・ソーク。生成 AI 製ファームが最も転ぶ領域。▶ LIVE CH 17セキュリティのブラックボックス攻撃面・秘密の漏れ・認証認可・通信保護・サイドチャネル。自己監査。▶ LIVE

第 V 部 — 仕組みにする

単発の手技を、繰り返し自動で回る仕組みへ。AI の反復修正に噛み合わせる。

CH 18テスト自動化ハーネスを作る三層設計・pytest・pyvisa/ppk2。ログと失敗アーティファクト。CI へ。▶ LIVE CH 19自作ツール作る/買うの判断。マイコンを注入・観測エージェントに。独自デコーダ。▶ LIVE CH 20テスト計画とケーススタディリスク×面、層のピラミッド、BLE 温度ロガーを計画から発見まで通す。▶ LIVE

対象はすべて自分（自社）の機器を前提に書いています。無線送信・セキュリティ試験には法規制があり、合法な範囲（自己所有・許可済み・シールド環境）で行うことが前提です。機材名・ツール名は代表例で、数値（サンプリング倍率・周波数・時間）は目安です。関連: フラッシュ・ファームの中身はバイナリ解析編、鍵とセキュア設計はPSA API 編・IoT セキュリティ編。／ GitHub Pages で配信。数式は KaTeX、20 点のデモはすべて Canvas / DOM 実装、41 点の図版はインライン SVG。すべてダーク/ライト対応で、外部 CDN への依存なし。
