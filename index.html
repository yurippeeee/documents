動いて理解する

数式を追うだけでは腑に落ちないことを、ブラウザ上で実際に動かしながら理解するためのノート集です。どのシリーズも、途中の式を省略せずに導出し、そのうえで直感的な言い換えと、値をいじれるデモを添えています。読みたいシリーズを選んでください。

このノートの方針

式を飛ばさない結論だけ書かず、途中の変形をすべて残す
先に「なぜ」を言う定義の前に、何が困っていて何を作りたいのか
動かせるものは動かす図で済ませずデモにする。Canvas 実装
自己完結外部 CDN 依存なし。数式は KaTeX を同梱
GitHub Pages で配信。ダーク／ライト対応。各シリーズは Markdown 原稿と、そこから生成した自己完結 HTML の両方をリポジトリに置いています。
