Chapter 05

マイコンの電源まわり — レギュレータ・負荷スイッチ・電源シーケンス・リセット

この章で扱う問い. 02〜04 章では、電源と電池の性質と、電池で動かすときの制御を見た。この章では、電源からマイコンと周辺へ電力を渡す途中の部品と、電源の電圧が変わるときのマイコンのふるまいを見る。電池や USB の電圧は、そのままではマイコンや周辺に合わないことが多い。周辺の電源は、使わない間は切りたい。電源を入れるとき、切るとき、電圧が下がったときには、マイコンが正しく止まり、正しく動き出さなければならない。

この章では次の 3 つの問いに答える。

  1. 電圧を作る回路（LDO とスイッチング電源）は、どの条件で何を選ぶのか。電池で間欠動作する機器では、何が選び方を決めるのか。
  2. 周辺の電源を入れ切りするとき、何が起きるのか。複数の電源と信号を、どの順番で入れ切りすればよいのか。
  3. 電源の電圧が上がるとき・下がるときに、マイコンはどうリセットされ、プログラムは何をすればよいのか。

答えの道具は、効率と静止電流から入力の平均電流を求める式、コンデンサの電流 \(i = C\,dv/dt\) と電荷の分け合い、POR・BOR のしきい値とヒステリシス、そして電源電圧の監視である。

この章で使う既出の用語（定義は各リンク先）. 機器・電源・負荷・周辺・センサ・マイコン・GPIO・ADC・割り込み（01 章 1 節）、電荷・容量・間欠動作・平均電流・電池寿命・リセット（01 章 4 節）、ウォッチドッグ（01 章 5 節）、起電力・端子電圧・内部抵抗・途切れ方・ノイズ・フラッシュメモリ（02 章 1 節）、VBUS（02 章 3 節）、車の電源（02 章 5 節）、公称容量（03 章 1 節）、終止電圧（03 章 2 節）、パルス負荷・パルスの底（03 章 4 節）、自己放電（03 章 5 節）、大容量コンデンサ（04 章 1 節）、低電池の判定・ヒステリシス（04 章 3 節）

1. 電圧を作る — LDO とスイッチング電源の選び方

電池の電圧は使うにつれて下がり（03 章 2 節）、USB の VBUS は 5 V、車の電源は 12 V 前後である。マイコンの多くは 1.8〜3.6 V の範囲で動き（代表値）、センサや無線の回路にもそれぞれ動く電圧の範囲がある。そこで、電源とマイコンの間に、入力の電圧が変わっても決めた電圧を出し続ける回路を置く。この回路をレギュレータという。レギュレータには大きく 2 つの方式がある（回路の中身は組み込み回路シリーズ 14 章・15 章）。

  • LDO: 入力と出力の間にトランジスタを直列に入れ、その抵抗を加減して出力の電圧を一定に保つ回路のうち、入力と出力の電圧の差が小さくても動くもの（Low Drop-Out の略）。出力は入力より低い電圧しか作れない。入力と出力の差がある値より小さくなると出力を保てなくなり、出力は入力からその値だけ低い電圧になる。この値をドロップアウト電圧といい、\(V_\mathrm{do}\) と書く（数十〜数百 mV で、電流が大きいほど大きい。代表値）。
  • スイッチング電源: スイッチを速く（数百 kHz〜数 MHz。代表値）入れ切りし、コイルとコンデンサで平らにならして電圧を変える回路。DC/DC コンバータともいう。出力を入力より低くする降圧、高くする昇圧、入力が出力より高くても低くても決めた電圧を作る昇降圧の方式がある。入れ切りによるさざ波と、まわりへのノイズ（02 章 1 節）が出る。

2 つを比べる物差しは、入力の電力のうち出力の電力として負荷に渡る割合である。これをレギュレータの効率といい、\(\eta\) と書く。入力の電圧と電流を \(V_\mathrm{in}\)・\(I_\mathrm{in}\)、出力の電圧と電流を \(V_\mathrm{out}\)・\(I_\mathrm{out}\) とすると、\(\eta = V_\mathrm{out} I_\mathrm{out} / (V_\mathrm{in} I_\mathrm{in})\) である。

方針: LDO は負荷の電流をトランジスタに通すだけなので、入力の電流は出力の電流にほぼ等しい。これを効率の式に入れる。

導出: LDO の入力の電流は、出力の電流に、LDO 自身が動くためのわずかな電流（2 節）を足したものである。わずかな電流を無視すると \(I_\mathrm{in} \approx I_\mathrm{out}\) なので、

\[ \eta = \frac{V_\mathrm{out} I_\mathrm{out}}{V_\mathrm{in} I_\mathrm{in}} \approx \frac{V_\mathrm{out} I_\mathrm{out}}{V_\mathrm{in} I_\mathrm{out}} = \frac{V_\mathrm{out}}{V_\mathrm{in}} \]

となる。入力の電力 \(V_\mathrm{in} I_\mathrm{out}\) と出力の電力 \(V_\mathrm{out} I_\mathrm{out}\) の差 \((V_\mathrm{in} - V_\mathrm{out}) I_\mathrm{out}\) は、LDO の中で熱になる ∎

スイッチング電源のスイッチは、入っているときは電圧がほぼ 0、切れているときは電流が 0 なので、電圧の差を熱にしない。効率は電圧の比によらず 85〜95 % 程度のことが多い（代表値）。3.3 V・100 mA を作る例で比べる。

5 V から作ると、LDO の効率は 3.3 ÷ 5 = 66 % で、0.17 W が熱になる。12 V からでは 27.5 % で 0.87 W になり、小さな部品では温度が大きく上がる（部品の発熱は 14 章 6 節）。効率 90 % のスイッチング電源なら、どちらも熱は 0.037 W で、12 V の入力の電流は 30.6 mA と、LDO の 100 mA の 3 割で済む。

LDO には、入力が \(V_\mathrm{out} + V_\mathrm{do}\) を下回ると出力を保てないという制約もある（03 章 2 節で、LDO を通す機器の終止電圧を \(V_\mathrm{need} + V_\mathrm{do}\) としたのはこのためである）。リチウムイオン電池（4.2〜3.0 V）から作る場合を図に示す。

3.3 V の LDO（\(V_\mathrm{do}\) = 0.2 V）は、電池が 3.5 V を下回ると出力が下がり始める。3.3 V が要る機器ではそこが電池の終わりで、03 章の模型では電池の容量の 88 % しか使えない。出力を 3.0 V にできる（マイコンと周辺が 3.0 V で動く）なら同じ LDO で 3.2 V まで使え（97 %）、昇降圧のスイッチング電源なら電池の終止電圧まで 3.3 V を保てる。

スイッチング電源の効率は、負荷の電流が小さいと下がる。スイッチを入れ切りする損失と制御の回路が使う電流は、負荷によらずにかかるからである。軽い負荷のときに入れ切りの回数を減らす動作（データシートでは PFM・バーストモードなどと呼ぶ）を持つものは、µA〜mA の負荷でも効率を保つが、さらに軽くなると下がる。一定の周波数で入れ切りを続ける動作（PWM モードなどと呼ぶ）は、さざ波の周波数が決まっていて扱いやすいが、軽い負荷では効率が大きく下がる。3.6 V から 1.8 V を作る例で、負荷の電流に対する効率を示す（2 節の模型で描いた代表的な形）。

LDO の効率は、負荷が数十 µA 以上ならほぼ \(V_\mathrm{out}/V_\mathrm{in}\) = 50 % で一定である。スイッチング電源は、mA の負荷では 90 % 近いが、µA の負荷では LDO を下回る。どちらが得かは、負荷の電流がどの範囲にどれだけの時間あるかで決まる（2 節）。ここまでを、条件ごとの選び方にまとめる。

条件（例）LDO の効率 \(V_\mathrm{out}/V_\mathrm{in}\) と熱選ぶもの
電流が小さく、電池でもない（USB の 5 V → 3.3 V、20 mA）66 %、0.034 WLDO（熱は小さく、部品が少なく、ノイズが小さい）
入力が出力よりずっと高い（車の 12 V → 3.3 V、100 mA）27.5 %、0.87 W降圧のスイッチング電源（入口の保護は 02 章 5 節）
入力が出力をまたぐ（リチウムイオン電池 4.2〜3.0 V → 3.3 V）3.5 V より下で出力が下がる昇降圧のスイッチング電源、または出力を 3.0 V に下げて LDO
入力が出力より低い（アルカリ乾電池 1 本 1.5〜0.9 V → 3.3 V）作れない昇圧のスイッチング電源
ノイズに弱い回路（ADC の基準・無線）—LDO、またはスイッチング電源の後に LDO

マイコンでする制御

  • 周辺だけに電力を渡すレギュレータは、入れ切りのピン（EN）を GPIO で操作し、使わない間は切る（3 節の負荷スイッチと同じ考え方）。出力が決めた電圧に達したことを知らせるピン（PG。パワーグッド）を持つものは、それを読んでから負荷を動かす（4 節）。
  • 動作の方式をピンで選べるスイッチング電源は、ADC で測る間や無線で送受信する間は一定の周波数の動作にし（さざ波の周波数が決まり、測定への影響を見積もりやすい。09 章）、眠る間は軽い負荷の動作にする。マイコンの中に LDO とスイッチング電源の両方を持ち、プログラムで選べるものもある（2 節の損得で選ぶ）。

2. 静止電流が効く条件

1 節の導出では、LDO 自身が使うわずかな電流を無視した。出力の電流が 0 のときにも、レギュレータが自分の回路を動かすために入力から GND へ流す電流を、静止電流といい、\(I_\mathrm{q}\) と書く。代表値で、静止電流の小さい LDO は 1 µA 前後（0.1 µA を切るものもある）、スイッチング電源は数百 nA〜数十 µA で、製品によって大きく違う（スイッチング電源のデータシートの値は、スイッチを止めた状態で測ったものもあるので、負荷が無いときの入力の電流を確かめる）。負荷が mA の間は無視できるが、01 章 4 節の間欠動作では、機器はほとんどの時間を µA の電流で眠っていて、その間は静止電流が眠りの電流と同じ桁になる。

例として、3.6 V の電池（塩化チオニルリチウム電池など。03 章 1 節）から 1.8 V を作り、マイコンと無線の回路に渡す機器を考える（1 節の効率の図と同じ例）。負荷（1.8 V の側）は、眠っている間 \(I_\mathrm{s}\) = 2 µA を流し、周期 \(T\) ごとに起きて \(I_\mathrm{a}\) = 6 mA を \(t_\mathrm{a}\) = 20 ms 流す。LDO の静止電流を \(I_\mathrm{q,L}\) = 1 µA、スイッチング電源の静止電流を \(I_\mathrm{q,S}\) = 10 µA とする（どれも例の値）。

方針: 01 章 4 節の式で負荷の平均電流を求め、LDO とスイッチング電源のそれぞれについて、出力の電流と入力の電流の関係から、入力（電池）の平均電流に直す。2 つの差の符号から、損得が入れ替わる所を求める。

導出: 負荷の平均電流は、01 章 4 節のとおり \(I_\mathrm{out,avg} = I_\mathrm{s} + (I_\mathrm{a} - I_\mathrm{s})\, t_\mathrm{a}/T\) である。LDO では、どの瞬間も \(I_\mathrm{in} = I_\mathrm{out} + I_\mathrm{q,L}\) なので、時間で平均して \(I_\mathrm{in,avg} = I_\mathrm{out,avg} + I_\mathrm{q,L}\) である。スイッチング電源では、入力の電力を、負荷に比例する部分と静止電流の部分に分けて \(V_\mathrm{in} I_\mathrm{in} = V_\mathrm{out} I_\mathrm{out}/\eta_0 + V_\mathrm{in} I_\mathrm{q,S}\) と表す（\(\eta_0\) は静止電流の分を除いた効率で、例では 90 %）。両辺を \(V_\mathrm{in}\) で割ると \(I_\mathrm{in} = k I_\mathrm{out} + I_\mathrm{q,S}\)（\(k = V_\mathrm{out}/(\eta_0 V_\mathrm{in})\)）で、\(k\) は一定なので \(I_\mathrm{in,avg} = k I_\mathrm{out,avg} + I_\mathrm{q,S}\) である。

スイッチング電源から LDO を引いた差は \((k I_\mathrm{out,avg} + I_\mathrm{q,S}) - (I_\mathrm{out,avg} + I_\mathrm{q,L}) = (I_\mathrm{q,S} - I_\mathrm{q,L}) - (1 - k)\, I_\mathrm{out,avg}\) である。\(k < 1\) かつ \(I_\mathrm{q,S} > I_\mathrm{q,L}\) のとき、これが負になる（スイッチング電源が得になる）のは、差を 0 とおいて \(I_\mathrm{out,avg}\) について解いた \(I^*\) より、\(I_\mathrm{out,avg}\) が大きいときである。\(I_\mathrm{out,avg}\) は \(T\) が長いほど小さいので、\(I^* > I_\mathrm{s}\) なら、\(I_\mathrm{s} + (I_\mathrm{a} - I_\mathrm{s})\, t_\mathrm{a}/T = I^*\) の \(I_\mathrm{s}\) を右辺に移し、両辺に \(T\) を掛けて \(I^* - I_\mathrm{s}\) で割った \(T^*\) より短い周期ではスイッチング電源が、長い周期では LDO が得になる。2 つの境目は

\[ I^* = \frac{I_\mathrm{q,S} - I_\mathrm{q,L}}{1 - k}, \qquad T^* = \frac{(I_\mathrm{a} - I_\mathrm{s})\, t_\mathrm{a}}{I^* - I_\mathrm{s}} \]

である ∎

例の値では \(k\) = 1.8 ÷ (0.9 × 3.6) = 0.556、\(I^*\) = 9 ÷ 0.444 = 20.3 µA、\(T^*\) = 119.96 µC ÷ 18.3 µA = 6.6 s である。1 節の効率の図で、LDO と軽い負荷の動作の曲線が交わる負荷の電流も、この \(I^*\) である。

周期 \(T\)負荷の平均電流LDO の入力スイッチング電源の入力（うち静止電流）得なほう
1 s122.0 µA123.0 µA77.8 µA（10 µA）スイッチング電源（37 % 少ない）
10 s14.0 µA15.0 µA17.8 µA（10 µA）LDO
60 s4.0 µA5.0 µA12.2 µA（10 µA）LDO（スイッチング電源は 2.4 倍）

周期が短い（よく起きる）間は、起きている間の電流が平均を決め、それを \(k\) 倍に減らすスイッチング電源が得になる。周期が \(T^*\) より長くなると、平均電流は眠りの電流と静止電流で決まり、60 s ではスイッチング電源の入力の 82 % が静止電流になる。したがって、間欠動作の機器のレギュレータは、効率の高さではなく、眠っている間の静止電流で選ぶことが多い。ほかの場合も確かめておく。\(k \ge 1\)（出力が入力に近い。3.6 V から 3.3 V なら \(k\) = 1.02）のときは、差の第 2 項が 0 以上になり、静止電流もスイッチング電源のほうが大きければ、どの周期でも LDO が得である。\(I_\mathrm{q,S} \le I_\mathrm{q,L}\) かつ \(k < 1\) なら、差は常に負で、どの周期でもスイッチング電源が得である。\(I^* \le I_\mathrm{s}\) なら、周期をいくら延ばしても負荷の平均電流が \(I^*\) を下回らないので、スイッチング電源が得である。

マイコンでする制御

  • 使う製品の値で \(I^*\) と \(T^*\) を求め、機器の周期と比べてレギュレータを選ぶ。電池寿命は、03 章 5 節の自己放電を足して見積もる。
  • 両方の方式を持つマイコンや、動作の方式を選べるスイッチング電源では、起きている間は効率の高い方式、眠る間は静止電流の小さい方式に切り替える。切り替えにかかる時間と電流はデータシートで確かめる。

下の図で、レギュレータの方式と静止電流、電池と出力の電圧、負荷の眠りと起きている間の電流、周期を変えると、入力の平均電流の内訳、電池寿命、周期に対する入力の平均電流のグラフと \(T^*\) が表示される。

3. 周辺の電源を切る — 負荷スイッチと突入電流

センサ・無線のモジュール・SD カードなどの周辺も、使っていない間に電流を流し続けることが多い（眠りの電流。製品によって µA〜mA。代表値）。マイコンが周辺の電源そのものを切れば、その電流は 0 になる。電源と周辺の間に入れて、マイコンが GPIO で入れ切りするスイッチを負荷スイッチという。P チャネルの MOSFET 1 個でも作れるが（組み込み回路シリーズ 05 章 8 節）、MOSFET とそれを入れ切りする回路をまとめた IC がよく使われる。負荷スイッチは周辺の電源のプラスの側に入れる。GND の側で切ると、周辺の GND がマイコンの GND から浮き、信号の線を通して電流が流れるからである（4 節）。

周辺の電源の入口には、ノイズを抑えるためのコンデンサがある（モジュールでは数 µF〜数十 µF のことが多い。代表値）。負荷スイッチを切っている間に、このコンデンサは空になる。電源を入れた瞬間に、負荷の側のコンデンサを充電するために流れる大きな電流を突入電流という。その大きさを、電圧が上がる速さで表す。

方針: コンデンサの電荷と電圧の関係 \(q = C v\) を時間で微分し、電流を電圧の変わる速さで表す。

導出: 容量 \(C\) のコンデンサの電圧が \(v\) のとき、たまっている電荷は \(q = C v\) である。電流は電荷の増える速さ \(i = dq/dt\) で、\(C\) は一定なので

\[ i = C \frac{dv}{dt} \]

となる。負荷の側の容量を \(C_\mathrm{L}\) とし、電圧が 0 から \(V\) まで時間 \(t_\mathrm{rise}\) をかけて一定の速さで上がるなら、\(dv/dt = V/t_\mathrm{rise}\) なので、その間の突入電流は \(I_\mathrm{inrush} = C_\mathrm{L} V/t_\mathrm{rise}\) である ∎

電圧が時間あたりに変わる量 \(dv/dt\) をスルーレート（立ち上がりの速さ）という。突入電流はスルーレートに比例し、ゆっくり立ち上げるほど小さい。

一気に入れる

例として、新しい CR2032（起電力 \(E\) = 3.0 V、内部抵抗 \(R_\mathrm{in}\) = 15 Ω）で直接動くマイコンが、3 mA で動きながらセンサのモジュールの電源を入れるとする。マイコンの電源の線にはコンデンサが合わせて \(C_\mathrm{A}\) = 10 µF、モジュールの入口には \(C_\mathrm{L}\) = 10 µF ある（どれも例の値）。以下、マイコン（と、マイコンと同じ電源で動く回路）が正しく動ける最低の電圧を、04 章 1 節と同じく \(V_\mathrm{min}\) と書き、例では 2.2 V とする。電源の電圧がこれを下回ると、多くのマイコンはリセットされる（01 章 4 節。しきい値の決め方は 5 節）。

GPIO で MOSFET を直接入れると、スイッチは 1 µs に満たない時間で入る（代表値）。その一瞬の電流はスイッチと配線の抵抗だけで決まり、A の桁になる。電池は内部抵抗のためにそれほどの電流を出せないので、\(C_\mathrm{L}\) を充電する電荷は、まずマイコンの側の \(C_\mathrm{A}\) から移る。

方針: 2 つのコンデンサの電圧がそろうまでの短い間は、電池から来る電荷を無視し、電荷の和が変わらないことを使う。

導出: 入れる前、\(C_\mathrm{A}\) は電圧 \(V_0\) で電荷 \(C_\mathrm{A} V_0\) を持ち、\(C_\mathrm{L}\) は空である。入れた後、2 つは同じ電圧 \(V_\mathrm{f}\) になり、電荷の和は \((C_\mathrm{A} + C_\mathrm{L}) V_\mathrm{f}\) である。電荷の和は変わらないので \(C_\mathrm{A} V_0 = (C_\mathrm{A} + C_\mathrm{L}) V_\mathrm{f}\)、つまり

\[ V_\mathrm{f} = V_0 \frac{C_\mathrm{A}}{C_\mathrm{A} + C_\mathrm{L}} \]

となる ∎

例では \(V_0\) = 3.0 − 0.003 × 15 = 2.955 V で、\(V_\mathrm{f}\) = 2.955 × 10/20 ≈ 1.48 V まで落ちる（この間に電池から来る電荷も入れて数値で解くと 1.50 V）。その後、電池が時定数 \(R_\mathrm{in}(C_\mathrm{A} + C_\mathrm{L})\) = 0.3 ms で両方を充電し直すが、約 0.2 ms の間 \(V_\mathrm{min}\) を下回り、マイコンはリセットされる。

ゆっくり入れる

方針: 時間 \(t_\mathrm{rise}\) をかけて立ち上げるとき、マイコンの側の電圧が、\(V_\mathrm{min}\) に余裕 \(V_\mathrm{mg}\) を足した値を割らない条件を求める。立ち上がりの間、電池はマイコンの電流 \(I_\mathrm{m}\) と突入電流を合わせて流す。02 章 1 節の端子電圧の式で電圧を求め、条件を \(t_\mathrm{rise}\) について解く。

導出: \(t_\mathrm{rise}\) が \(C_\mathrm{A}\) の時定数 \(R_\mathrm{in} C_\mathrm{A}\) より十分長ければ、マイコンの側の電圧は電池の端子電圧 \(V_\mathrm{A} = E - R_\mathrm{in}(I_\mathrm{m} + C_\mathrm{L} V/t_\mathrm{rise})\) に等しい（\(t_\mathrm{rise}\) が短いときは \(C_\mathrm{A}\) が電荷の一部を出すので、落ち込みはこれより小さい）。\(V_\mathrm{A} \ge V_\mathrm{min} + V_\mathrm{mg}\) の \(R_\mathrm{in} C_\mathrm{L} V/t_\mathrm{rise}\) を右辺に、\(V_\mathrm{min} + V_\mathrm{mg}\) を左辺に移すと \(R_\mathrm{in} C_\mathrm{L} V/t_\mathrm{rise} \le E - R_\mathrm{in} I_\mathrm{m} - V_\mathrm{min} - V_\mathrm{mg}\) である。右辺が正なら、両辺に \(t_\mathrm{rise}\) を掛けて右辺で割り、

\[ t_\mathrm{rise} \ge \frac{R_\mathrm{in} C_\mathrm{L} V}{E - R_\mathrm{in} I_\mathrm{m} - V_\mathrm{min} - V_\mathrm{mg}} \]

となる。右辺の分母が 0 以下なら、マイコンの電流だけで余裕を割っているので、どれだけゆっくり入れても足りない ∎

\(V\) を起電力 \(E\) で見積もり（大きめに見積もる側）、\(V_\mathrm{mg}\) = 0.1 V とすると、新しい電池では \(t_\mathrm{rise}\) ≥ 0.69 ms である。使い終わりに近い電池を寒い所で使い、\(E\) = 2.8 V、\(R_\mathrm{in}\) = 100 Ω になると（04 章 1 節の例）、14 ms 以上が要る。負荷スイッチの IC には、立ち上がりの時間が決まっているもの（数十 µs〜数 ms）や、外付けのコンデンサで延ばせるものがある（代表値）。

図の (a) は一気に入れた場合、(b) は 1 ms で立ち上げた場合である（新しい電池）。(b) の突入電流は 30 mA で、マイコンの側の電圧は 2.51 V までしか下がらない。マイコンの側に大容量コンデンサ（04 章 1 節）を足しても落ち込みは小さくなり、100 µF を足すと、一気に入れても 2.71 V にとどまる。

ほかに 2 つのことに気をつける。1 つ目に、1 回入れるたびに電源は \(C_\mathrm{L} V\) の電荷を出し、切った後に周辺がそれを使い切る。例では 30 µC で、60 s ごとに入れ切りすると平均 0.5 µA になる。周辺の眠りの電流がこれと起動にかかる電荷の分より小さいなら、切っても得をしない（損得は 08 章 3 節）。2 つ目に、切った後の \(C_\mathrm{L}\) は周辺が使う電流だけで放電するので、周辺が眠っていると、中途半端な電圧のまま長く残る。次に入れたとき、周辺が正しくリセットされずに動き出すことがある（5 節）。出力を抵抗で放電する機能を持つ負荷スイッチの IC もある。

マイコンでする制御

  • 入れる前に、その周辺へのピンを L か入力にしておき（4 節）、無線の送信やモータのような大きな動作と重ねずに入れる（04 章 2 節）。
  • 入れた後は、立ち上がりの時間と周辺が動き始めるまでの時間を待つか、電圧を確かめてから使う。入れた直後にリセットが起きたら（リセットの原因を記録しておく。6 節）、立ち上がりの時間かコンデンサが足りない。

下の図で、電源（電池の種類と状態）、マイコンの側と周辺の側の容量、立ち上がりの時間、マイコンの電流を変えると、両側の電圧と電流の波形、マイコンがリセットされるかが表示される。

4. 電源を入れる順番

機器の中の電源は 1 つとは限らない。マイコンの電源はいつも入れておき、センサや無線の電源は負荷スイッチで入れ切りする（3 節）。マイコンと違う電圧で動く周辺もあり、IC によっては中の回路と入出力のピンの電源を別に持つ。複数の電源を入れる順番と切る順番、その間に空ける時間、それに合わせて信号を動かす順番を決めたものを、電源シーケンスという（回路の側の実現方法は組み込み回路シリーズ 16 章 2 節）。順番を誤ると、次の 3 つのことが起きる。1 つ目に、電源の入っていない IC へ信号を出すと、IC のピンの保護ダイオード（組み込み回路シリーズ 19 章 2 節）を通って、信号の線から IC の電源の線へ電流が流れ込む（下の図で比べる）。2 つ目に、2 つの電源を持つ IC は、データシートの順番を守らないと、同じように中のダイオードに電流が流れ、まれに大きな電流が流れ続ける状態（ラッチアップ。組み込み回路シリーズ 11 章 5 節）になる。3 つ目に、複数の電源を同時に入れると、突入電流（3 節）が重なって、電源の電圧が大きく落ちる。

(a) では、マイコンが H（3.0 V）を出しているピンから、センサのピンの保護ダイオードを通って電流が流れ込み、センサの電源の線が 2.4 V 近くまで持ち上がる。流れ込む電流は、その電源の線につながったものが使う電流で決まり、数百 µA〜数 mA になることがある（代表値。ピンに流してよい電流はデータシートの絶対最大定格で確かめる）。センサは中途半端に動き出し、信号の線を L に引いたまま止まったり、電源を入れ直してもリセットされなかったりする。このような流れ込みは 08 章 4 節で詳しく扱う。(b) のように、電源を切っている間はピンを L か入力にしておけば、電流は流れない。逆に、周辺の電源が先に入り、電源の入っていないマイコンのピンに信号が来ることもある（組み込み回路シリーズ 19 章 2 節）。

したがって、順番は次の規則で決める。

  • 入れるとき: 電源が先、信号が後。電源が決めた電圧に達し、周辺が動き始めてから、ピンを使う設定にする。
  • 切るとき: 信号が先、電源が後。ピンを L か入力にしてから電源を切る。電源を切っても、電源の線のコンデンサが放電するまで電圧は残り、容量が大きく電流の小さい電源ほど遅く下がる。順番が大事なら、電圧を測って下がったのを確かめるか、出力を放電する負荷スイッチ（3 節）を使う。
  • 複数の電源の間: データシートの順番に従い、前の電源が立ち上がったのを確かめてから次を入れる。こうすれば突入電流も重ならない。

マイコンでする制御

電源シーケンスを手順の表として持ち、入れるときは表の順に、切るときは逆の順にたどる。次のコードはその一例である。rail_enable(rail, on)（負荷スイッチやレギュレータの EN を入れ切りする）、rail_good(rail)（その電源が決めた電圧に達したかを、PG のピンか ADC で確かめる）、pins_attach(rail, on)（その電源の周辺へのピンを使う設定にする／L か入力に戻す）、delay_ms() は、この章で仮に置く関数である（stdbool.h・stddef.h・stdint.h を使う）。

enum { RAIL_SENSOR, RAIL_RADIO };
typedef struct { int rail; uint16_t timeout_ms, settle_ms; } pwr_step_t;

/* 入れる順番。timeout_ms のうちに立ち上がらなければ失敗、立ち上がったら settle_ms 待つ（例の値） */
static const pwr_step_t SEQ[] = { { RAIL_SENSOR, 5, 2 }, { RAIL_RADIO, 10, 5 } };
#define N_SEQ (sizeof SEQ / sizeof SEQ[0])

/* 先頭から n 個を逆の順に切る。信号を先に外し、電源を後で切る */
static void power_down_n(size_t n)
{
    while (n-- > 0) {
        pins_attach(SEQ[n].rail, false);
        rail_enable(SEQ[n].rail, false);
    }
}

/* 順に入れる。立ち上がらない電源があれば、入れたものをすべて切って false を返す */
bool power_up(void)
{
    for (size_t k = 0; k < N_SEQ; k++) {
        rail_enable(SEQ[k].rail, true);
        for (uint16_t t = 0; !rail_good(SEQ[k].rail); t++) {
            if (t >= SEQ[k].timeout_ms) {
                power_down_n(k + 1);
                return false;
            }
            delay_ms(1);
        }
        delay_ms(SEQ[k].settle_ms);
        pins_attach(SEQ[k].rail, true);     /* 電源が入ってから信号をつなぐ */
    }
    return true;
}

void power_down(void) { power_down_n(N_SEQ); }

立ち上がらない電源があれば（負荷の短絡や部品の故障）、それまでに入れた電源を逆の順に切って false を返す。呼び出す側は、その周辺を使わずに動き続けるか、故障として記録する（01 章 3 節の「失敗したら」）。このコードは、仮に置いた関数をホストのコンピュータで差し替えて動かし、電源の立ち上がっていない周辺のピンをつながないこと、前の電源が立ち上がる前に次の電源を入れないこと、失敗したときにすべての電源とピンが切れていること、切る順が入れる順の逆であることを確かめてある。

5. 電源の立ち上がりと立ち下がり — POR と BOR

マイコンの電源電圧は、電源を入れるときは 0 V から上がり、電池が尽きるときや電源が途切れるときは下がる。その途中で \(V_\mathrm{min}\) を下回る電圧を通る。その電圧で CPU が動くと、命令やデータを読み誤り、思いがけない所へ分岐したり、フラッシュメモリを書き換えたりする。そこでマイコンは電源電圧を見張り、低すぎる間はリセットの状態に保つ。

  • パワーオンリセット（POR）: 電源を入れたとき、電源電圧がしきい値 \(V_\mathrm{POR}\) を超えるまでマイコンをリセットの状態に保ち、超えてからさらに決めた時間 \(t_\mathrm{POR}\)（電圧と発振器が落ち着くのを待つ。数百 µs〜数十 ms。代表値）の後に、プログラムを最初から実行させる働き。
  • ブラウンアウトリセット（BOR）: 動いている間に電源電圧がしきい値 \(V_\mathrm{BOR}\) を下回ったらリセットし、\(V_\mathrm{BOR} + V_\mathrm{hys}\) を上回るまでリセットの状態に保つ働き。上がるときと下がるときでしきい値を変えるのは 04 章 3 節のヒステリシスで、\(V_\mathrm{hys}\) は数十 mV〜0.1 V 程度である（代表値）。

図のように、短い落ち込みでも \(V_\mathrm{BOR}\) を割ればリセットされ、割らなければ何も起きない。名前は製品ごとに違い（BOD・PDR・SVS など）、\(V_\mathrm{POR}\) は製品で決まっていて、\(V_\mathrm{BOR}\) はいくつかの値から選べるもの（プログラムを書き込むときの設定で選ぶものが多い）がある。マイコンによっては \(V_\mathrm{POR}\) が \(V_\mathrm{min}\) より低く、BOR を使わないと、ゆっくり下がる電源で \(V_\mathrm{min}\) を割った後も CPU が動き続ける。電池が尽きかける間にフラッシュメモリの中身が壊れる失敗は、こうして起きることがある。BOR は、\(V_\mathrm{min}\) 以上のしきい値で使う。

ヒステリシスとリセットの繰り返し

BOR にヒステリシスがあるのは、リセットの間と動いている間でマイコンの電流が違い、電源電圧も違うからである。内部抵抗の大きい電池では、それがリセットの繰り返しを生む。

方針: リセットの間の電流 \(I_\mathrm{rst}\) と動いている間の電流 \(I_\mathrm{run}\)（\(I_\mathrm{run} > I_\mathrm{rst}\)）のそれぞれで、電源電圧が落ち着く値を 02 章 1 節の式で求め、リセットが解けた後にまたリセットされる条件を調べる。

導出: リセットの間、電源電圧は \(E - R_\mathrm{in} I_\mathrm{rst}\) に近づき、これが \(V_\mathrm{BOR} + V_\mathrm{hys}\) を超えればリセットが解ける。動き出すと電源電圧は \(E - R_\mathrm{in} I_\mathrm{run}\) に近づき、これが \(V_\mathrm{BOR}\) を下回れば、またリセットされる。両方が起きて繰り返すのは、2 つの不等式を \(E\) について並べた

\[ V_\mathrm{BOR} + V_\mathrm{hys} + R_\mathrm{in} I_\mathrm{rst} < E < V_\mathrm{BOR} + R_\mathrm{in} I_\mathrm{run} \]

のときである。このような \(E\) があるのは、左端が右端より小さいとき、つまり \(V_\mathrm{hys} < R_\mathrm{in}(I_\mathrm{run} - I_\mathrm{rst})\) のときに限る。\(V_\mathrm{hys} \ge R_\mathrm{in}(I_\mathrm{run} - I_\mathrm{rst})\) なら、どの \(E\) でも繰り返さない ∎

使い終わりに近い CR2032 を寒い所で使い（\(R_\mathrm{in}\) = 100 Ω）、\(I_\mathrm{run}\) = 3 mA、\(I_\mathrm{rst}\) = 0.1 mA とすると、\(R_\mathrm{in}(I_\mathrm{run} - I_\mathrm{rst})\) = 0.29 V で、ヒステリシスの代表値より大きい。\(V_\mathrm{BOR}\) = 2.2 V、\(V_\mathrm{hys}\) = 0.1 V なら、\(E\) が 2.31〜2.5 V の間で繰り返す（どれも例の値）。

(a) は \(E\) = 2.45 V で、電源の線の 100 µF の電圧が上がるとリセットが解け、動くと下がって、約 20 ms ごとにリセットを繰り返す。この間の平均の電流は約 1.9 mA で、眠りの電流（数 µA）の数百倍の速さで電池を使う。大容量コンデンサは動き出した直後の短い電流を受け持つが、電流が続けば電圧は \(E - R_\mathrm{in} I_\mathrm{run}\) まで下がるので、繰り返しは防げない。起動の直後に電圧を測っても、コンデンサが支えている間は低下が見えない。そこで (b) では、プログラムが起動の直後にリセットの原因を読み、BOR からの起動なら大きな仕事を始めずに眠る。続けて BOR から起動した回数を、リセットで消えない RAM の場所に数えておき（置き方は開発環境による。POR からの起動では 0 に戻す）、BOR が続くたびに眠る時間を 50 ms、100 ms、200 ms … と 2 倍に延ばし、大きな仕事を 1 回終えられたら回数を 0 に戻す。電池は眠りの間に休めるので、平均の電流は図の 1 秒で 0.26 mA、10 秒では約 45 µA と (a) の約 1/40 になり、眠る時間が延びるほど小さくなる。

フラッシュメモリの書き込み中に下がる

フラッシュメモリの書き込みには、数バイトの書き込みで数十 µs、ページ（数 KB）の消去で数 ms〜数十 ms かかり、その間は数 mA を使う（代表値）。その途中で BOR がかかると、書きかけのバイトや消しかけのページは、元の値でも新しい値でもない状態で残る（組み込み回路シリーズ 13 章 4 節）。BOR はマイコンを止めるだけで、書き込みを最後まで終わらせはしない。したがって、書き込みは、終えるまで電圧が保たれると分かっているときにだけ始める（6 節）。書き込みに、動作より高い電圧を要るマイコンもある。

BOR のしきい値を選ぶ

電池で直接動く機器では、BOR のしきい値が終止電圧（03 章 2 節）になる。単 3 形のアルカリ乾電池 2 本で直接動く機器で、選び方を示す。マイコンは 1.8 V 以上、温度センサは 2.4 V 以上で正しく動き、BOR のしきい値は 1.8・2.0・2.2・2.5 V から選べ、ずれは ±0.05 V とする（どれも例の値）。

1.8 V では、ずれで 1.75 V まで下がってからリセットされることがあり、マイコンの \(V_\mathrm{min}\) を割る。2.0 V なら最も低くても 1.95 V で、マイコンに 0.15 V の余裕があり、使える容量は 93 % である（03 章の模型。小さな電流）。2.5 V にするとセンサも BOR で守れるが、使える容量は 45 % に下がる。したがって、BOR のしきい値は、マイコン自身が正しく動ける電圧に、ずれとノイズの余裕を足した値から選び、それより高い電圧が要る周辺や動作は、6 節の監視で止める。無線の送信のようなパルス負荷では、パルスの底（03 章 4 節）が BOR に届いた所で機器が止まるので、パルスの底もしきい値と比べる。

マイコンでする制御

  • 起動したら、まずリセットの原因（POR・BOR・ウォッチドッグ・リセットのピン）を読んで記録する（6 節）。BOR からの起動なら、上の (b) のように眠る時間を延ばしながら様子を見る。
  • フラッシュメモリへの書き込みは、6 節の監視で許されたときだけ始める。データは、書きかけで止まっても前の値が残る形で置く（2 か所に交互に書き、書き終えた印を最後に書く、など）。

下の図で、電池の起電力と内部抵抗、電源の線の容量、マイコンの電流、BOR のしきい値とヒステリシス、BOR から起動したときに眠るかどうかを変えると、電源電圧とリセットの波形、リセットの回数と平均の電流が表示される。

6. 電源電圧を見張る

BOR は最後の守りで、マイコンを動作の途中で止める。無線の送信は途中で切れ、フラッシュメモリの書き込みは壊れる。電源の電圧を測るか比べるかして、下がりそうなことを BOR より前に知り、動作を変えることを、電源電圧の監視という。道具は 2 つある。1 つは、電圧をしきい値と比べ、下回った（上回った）ことを信号で知らせる回路で、これを電圧検出器という。マイコンの中に、電源電圧を見張って割り込みを出す電圧検出器を持つものが多く、外付けの IC もある。もう 1 つは ADC で測る方法である。

しきい値を積み上げる

監視のしきい値は、BOR から上へ積み上げて決める。5 節の単 3 形 2 本の機器（BOR 2.0 V）で示す。

  • 動作ごとの下限: 動作を始めてよい最低の電圧を、その動作に要る電圧に、動作の間に下がる分と余裕を足して決める。例では、センサは 2.4 V に余裕を足して 2.5 V、無線は送信の間の電圧の低下（03 章 4 節）を見込んで 2.4 V、フラッシュメモリの書き込みは 2.35 V とした。下回ったら始めず、0.1 V 高くなるまで戻さない（ヒステリシス）。
  • 警告: 電圧検出器のしきい値を 2.3 V にし、下回ったら割り込みで、新しい動作を止めて負荷を切る。このしきい値は、電源が突然途切れたとき（電池の接点が振動で離れた、USB のプラグを抜いた。02 章 1 節の途切れ方）に、BOR までに残る時間で決める。

方針: 電源が途切れると、マイコンの電源の線のコンデンサだけが電流を出す。電流が一定なら電圧は一定の速さで下がるので、警告から BOR までの時間が求まる。

導出: コンデンサの容量を \(C\)、マイコンと周辺の電流を \(I\) とすると、3 節の \(i = C\,dv/dt\) から、電圧の下がる速さは \(I/C\) である。警告のしきい値 \(V_\mathrm{warn}\) から \(V_\mathrm{BOR}\) までの差を、この速さで割って

\[ t = \frac{C\,(V_\mathrm{warn} - V_\mathrm{BOR})}{I} \]

となる ∎

\(C\) = 100 µF、\(I\) = 3 mA なら、2.3 V から 2.0 V まで 10 ms である。警告で負荷を切って電流を 0.3 mA に減らせば、残りの時間は 10 倍に延びる。この時間で、警告の前に始めていた動作を終える。フラッシュメモリへの書き込み 1 回は終えられるが、ページの消去（数十 ms）は終わらないことがある。そこで、消去は電圧に余裕のあるときに済ませておき、電圧が下がったときは、消去済みの場所に短い記録を書くだけにする。

図は、2.8 V で動いていた機器の電池の接点が 30 ms 離れた場合である。監視しない (a) では 26.7 ms で BOR にかかる。監視する (b) では 16.7 ms の警告で負荷を切り、接点が戻る 30 ms でも 2.26 V を保つので、リセットされない。なお、04 章 3 節の低電池の判定は、日の単位でゆっくり下がる電池の電圧から機器の動き方を変えるものだった。この節の監視は、ms の単位の落ち込みに間に合うように、動作ごとに始めてよいかを決める。役割が違うので、両方を使う。

マイコンでする制御

次のコードは、上のしきい値で、動作ごとに始めてよいかを決める。pvd_isr() は電圧検出器の割り込みで、pwr_update() は、起動の直後（それまでは、どの動作も許されない）と、周期的に（例: 1 秒ごとと、大きな動作の直前に）呼ぶ。vdd_read_mv()（ADC でマイコンの電源電圧を測る。09 章 2 節）・loads_cut()（負荷スイッチで周辺を切り、クロックを下げる）・irq_off()・irq_on()（割り込みを止める・戻す）は、この章で仮に置く関数である。

typedef enum { OP_SENSOR, OP_RADIO, OP_FLASH, OP_N } op_t;

/* 動作ごとの、始めてよい電源電圧の下限 [mV]（例の値）。戻すのは HYS_MV だけ高くなってから */
static const uint16_t START_MV[OP_N] = { 2500u, 2400u, 2350u };
#define HYS_MV 100u

static volatile bool allowed[OP_N];
static volatile uint16_t warn_count;    /* 電圧検出器の割り込みの回数（記録） */
static uint16_t min_mv = 0xFFFFu;       /* 測った中で最も低い電圧（記録） */

/* 電圧検出器の割り込み: 電源電圧が警告のしきい値を下回った */
void pvd_isr(void)
{
    for (int k = 0; k < OP_N; k++)
        allowed[k] = false;             /* 新しい動作を始めない */
    loads_cut();                        /* 電流を減らし、BOR までの時間を延ばす */
    warn_count++;
}

/* 周期的に呼ぶ。測った電圧で、動作ごとに始めてよいかを決める */
void pwr_update(void)
{
    uint16_t w0 = warn_count;
    uint16_t v = vdd_read_mv();
    if (v < min_mv)
        min_mv = v;
    irq_off();
    for (int k = 0; k < OP_N; k++) {
        if (v < START_MV[k])
            allowed[k] = false;
        else if (v >= START_MV[k] + HYS_MV && w0 == warn_count)
            allowed[k] = true;          /* 測る間に警告が来ていなければ戻す */
    }                                   /* 2 つのしきい値の間では、今の状態のまま */
    irq_on();
}

bool pwr_may_start(op_t op) { return allowed[op]; }

大きな動作の前には pwr_may_start() を見て、許されていなければ後に回す。pwr_update() は、測っている間に警告の割り込みが来たときに、その前の高い電圧で動作を許し直さないよう、警告の回数が測る前と同じときだけ戻す。テストでは、電圧を 1 mV ずつ下げ・上げて、どの動作も下限を下回った所で止まり、下限 + 0.1 V まで戻らないこと、警告で全部が止まって負荷が切られること、測っている間に警告が来たときは戻さないことを確かめた。

最後に、異常を記録する。リセットの原因ごとの回数（5 節）、警告の回数と最も低い電圧（コードの warn_count・min_mv）、そのとき何をしていたかを、リセットで消えない RAM に置き、フラッシュメモリへの書き込みが許されたときに書く。回収した機器の記録で、平均の電圧は高いのに警告が多ければ電池の接点を、BOR が多ければ電池と負荷の組み合わせを疑える。
