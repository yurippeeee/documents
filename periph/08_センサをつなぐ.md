# 08. センサをつなぐ — インタフェース・電源の入れ切り・バスの復旧

> **この章で扱う問い.**

## 1. センサの出力の形

センサ（01 章 1 節）は、測った量を、マイコンが読める信号にして出す。信号の形は大きく 3 つに分かれる。

- **アナログ出力**: 測った量を、電圧の大きさで表して出す形。温度に比例した電圧を出す IC、光の強さで電流が変わる素子に抵抗をつないだもの、温度で抵抗が変わる素子を抵抗と直列にした分圧（09 章）などがある。マイコンは ADC（01 章 1 節）で電圧を測り、量に直す。
- **デジタル出力**: センサの中で量を測って数値にし、決めた手順でビットの列として送る形。センサの中に ADC と、ずれを直す計算（校正。10 章）の回路を持つ。マイコンは通信の回路（2 節の I2C・SPI・UART）で数値を読む。
- **パルス出力**: 量を、パルスの幅・周期・数で表して出す形。マイコンは、幅や周期をタイマ（01 章 1 節）で測り、数をタイマか割り込みで数える。湿度や光の強さを周波数で表すセンサや、水や雨が決まった量だけ流れるたびにパルスを 1 つ出すメータがある。

このほか、人が近づいた・扉が開いたのように、しきい値を超えたかどうかだけを H・L で出すものは、GPIO の入力で読み、変化を割り込みで知る（スイッチの読み方は 11 章）。


### 長い配線とノイズ

3 つの形は、配線にノイズが乗ったときのふるまいが違う。アナログ出力では、線の上の電圧がそのまま値になる。12 ビットの ADC で基準の電圧を 3.0 V にすると、1 段の幅は 3.0 V ÷ 4096 = 0.73 mV で、1 °C あたり 10 mV を出す温度センサなら 0.073 °C の細かさで読める。ところが、配線にモータやリレーのノイズ（12・13 章）が 20 mV 乗ると、読みは 20 ÷ 10 = 2 °C ずれる。デジタル出力では、H と L のしきい値をまたぐほどのノイズでなければ値は変わらない。誤りを調べる値（CRC。[組み込み通信シリーズ 03 章 5 節](../comm/03_フレーミングと誤り検出.md#誤りに気づく-チェックサムと-crc)）を付けて送り、壊れた値に気づけるセンサもある。パルス出力では、ノイズで変わり目の時刻が少しずれるが、数えたパルスの数は変わらない。

```fig
e08_noise
```

したがって、配線が長い所やノイズの多い所では、アナログ出力を避け、デジタル出力かパルス出力を選ぶ。アナログ出力を使うなら、配線を短くし、ノイズの源から離す。

### パルスを測る時間

パルス出力の周波数を測る方法は 2 つある。決めた時間 $`T_\mathrm{g}`$ の間に来たパルスを数える方法と、1 つの周期の長さを、マイコンのクロックの刻み（周波数 $`f_\mathrm{clk}`$）で数える方法である。どちらが細かく測れるかを求める。

**方針**: どちらの方法でも、数えた数に ±1 の誤差が出る（数え始めと数え終わりが、パルスや刻みの変わり目とそろわないため）。数えた数から周波数を求め、±1 が周波数の何割にあたるかを比べる。

**導出**: 周波数 $`f`$ のパルスを時間 $`T_\mathrm{g}`$ の間数えると、数は $`N = f T_\mathrm{g}`$ で、周波数は $`N/T_\mathrm{g}`$ と求まる。$`N`$ が 1 ずれると周波数は $`1/T_\mathrm{g}`$ ずれるので、相対的な誤差は $`(1/T_\mathrm{g})/f = 1/(f T_\mathrm{g})`$ である。一方、周期 $`1/f`$ をクロックの刻みで数えると、数は $`M = f_\mathrm{clk}/f`$ で、周期は $`M/f_\mathrm{clk}`$ と求まる。$`M`$ が 1 ずれると周期の相対的な誤差は $`1/M = f/f_\mathrm{clk}`$ で、小さなずれでは、周波数（周期の逆数）の相対的な誤差も同じ大きさになる。2 つが等しくなるのは $`1/(f T_\mathrm{g}) = f/f_\mathrm{clk}`$ のときで、両辺に $`f\,T_\mathrm{g} f_\mathrm{clk}`$ を掛けると $`f_\mathrm{clk} = f^2 T_\mathrm{g}`$、すなわち

$$
f = \sqrt{f_\mathrm{clk}/T_\mathrm{g}}
$$

である。これより低い周波数では周期を測るほうが、高い周波数では数えるほうが誤差が小さい ∎

```fig
e08_pulse
```

例として 1 kHz のパルスを測る。0.1 s 数えると 100 個で、誤差は 1 % である。1 MHz の刻みで周期を測ると 1000 刻みになり、誤差は 0.1 % である。かかる時間は 1 周期の 1 ms にすぎない。数える方法で 0.1 % にするには 1 s 数える必要がある。2 つの方法が等しくなるのは $`\sqrt{10^6/0.1}`$ ≈ 3.2 kHz である。測る時間はタイマ（多くはマイコンも）が動いている時間なので、低い周波数を周期で測ると、電荷も少なくて済む。

### マイコンでする制御

- アナログ出力: 測るときだけセンサの電源を入れ、測った後に切る。基準の電圧の選び方と、比で測る方法は 09 章で扱う。
- デジタル出力: 誤りを調べる値があれば確かめ、答えない・値がありえないときの扱いを決めておく（10 章 6 節）。
- パルス出力: 低い周波数は周期を、高い周波数は数を測る。決まった量ごとのパルスを数えるだけなら、眠っている間も数え続けられるタイマを持つマイコンでは、パルスごとに起きなくてよい（製品による）。

## 2. インタフェースを選ぶ — I2C・SPI・UART

デジタル出力のセンサとマイコンをつなぐ通信の方式は、I2C・SPI・UART の 3 つが多い。同じセンサが I2C と SPI の両方を持ち、ピンで選べるものもある。この節では、選ぶのに要る性質と、5・6 節で使う I2C の線の動きを見る（線の電気的な性質は[組み込み回路シリーズ 20 章](../circuit/20_シリアル物理層.md#物理層を分ける-4-つの軸)、線の上のやり取りを観測して確かめる方法は[組み込みテストシリーズ 06 章](../embtest/06_I2CとSPI.md#mcu-周辺の-2-大バス)）。

### I2C

**I2C** は、**SDA**（データ）と **SCL**（クロック）の 2 本の線で、1 つのマイコンと何台ものセンサをつなぐ方式である。このように、1 組の線を何台もの装置で共有するつなぎ方を**バス**という。通信を始めてクロックを出す側を**マスタ**、呼ばれて答える側を**スレーブ**という（I2C の規格の新しい版では、それぞれコントローラ・ターゲットと呼ぶ）。マイコンがマスタ、センサがスレーブである。スレーブは、バスの上で自分を区別する 7 ビットの番号を持つ。これを**アドレス**という。マスタが最初にアドレスを送ると、そのアドレスのスレーブだけが答える。

SDA と SCL につなぐ出力は、どの装置も**オープンドレイン**である。オープンドレインは、L にするときはピンを GND につなぎ、H にするときはピンを離す（どこにもつながない）出力である。離した線を H にするのは、線と電源の間のプルアップ抵抗（07 章 3 節）である（回路は[組み込み回路シリーズ 19 章 5 節](../circuit/19_GPIO.md#オープンドレインとプルアップ)）。これに対し、H のときはピンを電源に、L のときは GND につなぐ普通の出力を、**プッシュプル**という。1 本の線を共有するとき、プッシュプルの 1 台が H を、別の 1 台が L を出すと、電源から GND へ大きな電流が流れる。オープンドレインなら、どの装置も L に引くか離すかしかしないので、1 台でも L に引けば線は L になり、ぶつかって大きな電流が流れることはない。

センサの中の、設定や測った値を置く番地のついた場所（レジスタ）から値を読むときの、線の動きを図に示す。

```fig
e08_i2cwave
```

- 何も送らない間、SDA と SCL はどちらも H である。SCL が H の間に SDA を H から L にすることを**開始条件**、L から H にすることを**停止条件**という。データのビットは SCL が L の間に変え、H の間は変えない。したがって、SCL が H の間の SDA の変化は、開始と停止の印として区別できる。
- 1 バイトは 8 ビットで、上の桁から送る。8 個のクロックの後の 9 個目のクロックで、受け手が SDA を L に引いて、受け取ったことを知らせる。これを **ACK** といい、L に引かない（SDA が H のまま）ことを **NACK** という。
- 読み出しでは、マスタがアドレスと書き込みの印（R/W = 0）、レジスタの番地を送り、開始条件をもう一度出して、アドレスと読み出しの印（R/W = 1）を送る。その後はスレーブが SDA を動かして値を送り、マスタが 1 バイトごとに ACK を返し、最後のバイトに NACK を返して、停止条件で終える。
- スレーブは、準備ができるまで SCL を L に引いて、マスタを待たせることができる。これを**クロックストレッチ**という。

図で紫に塗った所（ACK と、読み出しの値）では、スレーブが SDA を動かしている。6 節で見るとおり、この間にマスタが止まると、線が L のまま固まることがある。クロックの周波数は、100 kHz・400 kHz・1 MHz の区分がよく使われる（5 節）。

### SPI

**SPI** は、クロックの線（SCLK）、マスタからスレーブへのデータの線（MOSI）、スレーブからマスタへのデータの線（MISO）の 3 本と、スレーブごとに 1 本の選ぶ線（CS）でつなぐ方式である（製品によって SDI・SDO・CSB などとも書く）。マスタは相手の CS だけを L にし、SCLK を出しながら、MOSI で送り、MISO で受ける。線はプッシュプルなのでプルアップ抵抗が要らず、数 MHz〜数十 MHz で動く（代表値）。CS が H のスレーブは MISO を離すので、何台ものスレーブで MISO を共有できる。リセットの間はマイコンのピンが入力になって CS が浮くので、CS にはプルアップ抵抗を付けて、選ばない側に保つ（[組み込み回路シリーズ 20 章 3 節](../circuit/20_シリアル物理層.md#spi)）。

### UART

**UART** は、送る線（TX）と受ける線（RX）を交差させて 1 対 1 でつなぎ、クロックの線を持たずに、前もって決めた速さで 1 バイトずつ送る方式である（[組み込み通信シリーズ 02 章](../comm/02_UART.md#並列とシリアル-同期と非同期)）。何も送らない間、線を H にしておく。位置を測る GPS のモジュールや、空気中の粒子・二酸化炭素を測るモジュールのように、センサが自分の決めた間隔で値を送ってくるものが多い。

### 3 つを比べる

```fig
e08_ifaces
```

| | I2C | SPI | UART |
|---|---|---|---|
| 信号の線 | 2 本（SDA・SCL）。プルアップ抵抗が要る | 3 本 + スレーブごとに CS | 2 本（TX・RX） |
| 相手の選び方 | アドレス | CS の線 | 1 対 1 |
| 速さ（代表値） | 100 kHz・400 kHz・1 MHz | 数 MHz〜数十 MHz | 9600 bps〜1 Mbps 程度 |
| 届く距離（代表値） | 基板の中〜1 m 程度 | 基板の中（数十 cm まで） | 数 m まで |
| 線に電流が流れる間 | 線が L の間、プルアップ抵抗に流れる | 切り替わる瞬間だけ | 切り替わる瞬間だけ |
| 起こりやすい失敗 | 線の固まり（6 節）、立ち上がりの遅れ（5 節） | CS の浮き、MISO を離さないスレーブ | 速さの設定の違い、受けそこね |

1 回の読み出しにかかる時間と電荷を、例で比べる。6 バイトの値をレジスタから読むとする。I2C では、アドレス 2 回・番地・値 6 バイトの 9 バイトで、9 × 9 = 81 個のクロックに、開始と停止の分の約 3 個を足して約 84 個のクロックがかかる。SPI では、命令 1 バイトと値 6 バイトの 56 個のクロックに、CS を動かす時間を足す。UART のセンサは、決まった 32 バイトのまとまりを 9600 bps で送ってくるとする（1 バイトは 10 ビット）。読み出しの間、マイコンは 3 mA で起きているとし、I2C ではプルアップ抵抗に流れる電荷も足す（SDA と SCL がそれぞれ時間の半分 L とみなす）。どれも例の値である。

```fig
e08_readcost
```

I2C は 400 kHz にすると、100 kHz に比べて時間は 1/4、電荷は約 3/10 で済む。SPI は、その I2C よりさらに 1 桁以上小さい。UART は、センサが送り終えるまでの 33 ms を受け続けるので、マイコンが起きて待つと 100 µC になる。UART のセンサでは、受けたバイトをメモリへ移す仕事を DMA（周辺回路が CPU の代わりにメモリへ写す仕組み。[組み込み通信シリーズ 04 章](../comm/04_割り込みDMAリングバッファ.md)）に任せて軽い眠り（07 章 1 節）で待つか、送る間隔を延ばす設定にする。なお、センサが 1 回測るのにかかる時間（数 ms〜数十 ms のことが多い。代表値）は、この通信の時間より長いことが多いが、その間マイコンは眠って待てる（3 節）。

### マイコンでする制御

- 選び方: 基板の中で何台ものセンサを少ないピンでつなぐなら I2C、速く・多く読むなら SPI、モジュールが UART しか持たないなら UART にする。機器の外へ長い線で出すときは、どれも向かない（[組み込み回路シリーズ 20 章 8 節](../circuit/20_シリアル物理層.md#選び方)）。
- 同じアドレスのセンサを 2 個つなぐときは、アドレスを選ぶピンで変えるか、バスを分ける。
- 起動の直後に、各センサの決まった値のレジスタ（製品の ID など）を読み、つながって答えることを確かめる。
- 読み書きには時間の上限を決め、超えたら 6 節の手順でバスを戻す。

## 3. センサの電源を切る — 起動時間との釣り合い

センサが測っていない間に流す電流も、平均電流（01 章 4 節）に入る。多くのデジタル出力のセンサは、測っていない間に自分の回路を止めて待つ状態（この章では待機と呼ぶ）を持ち、その電流は 0.1 µA 前後〜数 µA である。レギュレータや LED を載せた基板（モジュール）では、数十 µA〜数 mA になることもある（どれも代表値）。アナログ出力のセンサや分圧の抵抗は、電源が入っている間ずっと電流を流す（09 章 4 節）。

使わない間、センサの電源を負荷スイッチ（05 章 3 節）で切り、測るときだけ入れることを、**電源の入れ切り**（**パワーゲーティング**）という。切っている間に残るのは、負荷スイッチの漏れ電流（07 章 3 節）だけである（4 節の逆流を防いだ場合）。その代わり、入れるたびに次のものがかかる。

- 突入電流: センサの入口のコンデンサ $`C_\mathrm{L}`$ を電圧 $`V`$ まで充電する電荷 $`C_\mathrm{L} V`$（05 章 3 節）。
- 起動: 電源を入れてから、センサが正しい値を測れるようになるまでの時間を、**センサの起動時間**といい、$`t_\mathrm{su}`$ と書く。センサの中の POR（05 章 5 節）が解け、中の回路と基準の電圧が落ち着くまでの時間で、温度・湿度・加速度のセンサで数 ms 程度、中のヒータで温めるガスのセンサや、ファンで空気を吸い込む粒子のセンサでは数十秒〜数分になる（代表値。製品で大きく違う）。マイコンの起床時間（07 章 1 節）とは別のものである。この間の電流を $`I_\mathrm{su}`$ とする。
- 設定の書き直し: 電源を切るとセンサのレジスタの設定は消えるので、入れるたびに書き直す。その通信にかかる電荷を $`Q_\mathrm{cfg}`$ とする。

この 3 つの和 $`Q_\mathrm{on} = C_\mathrm{L} V + I_\mathrm{su} t_\mathrm{su} + Q_\mathrm{cfg}`$ を、この章では**起動の電荷**という。07 章 5 節の起床の電荷にあたるものである。

```fig
e08_gatewave
```

### どちらが得か

周期 $`T`$ ごとに測る機器で、センサの電源を入れたまま待機させる場合を A、測るときだけ入れる場合を B とする。1 回の測定では、センサは時間 $`t_\mathrm{m}`$ の間、電流 $`I_\mathrm{m}`$ を流す。待機の電流を $`I_\mathrm{sb}`$、負荷スイッチを切っている間の漏れ電流を $`I_\mathrm{off}`$ とする。

**方針**: 07 章 5 節の損益分岐の眠りの長さと同じ考え方で、1 周期に流れる電荷を A と B で表し、B のほうが小さくなる周期の範囲を求める。B は、待機の電流が小さい代わりに、入れるたびの電荷が大きい側にあたる。

**導出**: A では、測る間に $`I_\mathrm{m} t_\mathrm{m}`$、残りの $`T - t_\mathrm{m}`$ の間に待機の電流が流れるので、1 周期の電荷は $`Q_\mathrm{A} = I_\mathrm{sb}(T - t_\mathrm{m}) + I_\mathrm{m} t_\mathrm{m}`$ である。B では、入れるたびに $`Q_\mathrm{on}`$ と $`I_\mathrm{m} t_\mathrm{m}`$ がかかる。漏れ電流は、周期の全体に流れるとみなす（入れている短い間の分だけ多めに数える）と、$`Q_\mathrm{B} = I_\mathrm{off} T + Q_\mathrm{on} + I_\mathrm{m} t_\mathrm{m}`$ である。$`Q_\mathrm{B} < Q_\mathrm{A}`$ の両辺から $`I_\mathrm{m} t_\mathrm{m}`$ を引き、右辺を展開した $`I_\mathrm{sb} T - I_\mathrm{sb} t_\mathrm{m}`$ のうち $`- I_\mathrm{sb} t_\mathrm{m}`$ を左辺へ、左辺の $`I_\mathrm{off} T`$ を右辺へ移すと、$`Q_\mathrm{on} + I_\mathrm{sb} t_\mathrm{m} < (I_\mathrm{sb} - I_\mathrm{off})\, T`$ となる。$`I_\mathrm{sb} > I_\mathrm{off}`$ なら、両辺を正の数 $`I_\mathrm{sb} - I_\mathrm{off}`$ で割って

$$
T > T_\mathrm{be} = \frac{Q_\mathrm{on} + I_\mathrm{sb}\, t_\mathrm{m}}{I_\mathrm{sb} - I_\mathrm{off}}
$$

となる。$`T_\mathrm{be}`$ より長い周期で測るなら切るほうが、短いなら入れたまま待機させるほうが得である。$`I_\mathrm{sb} \le I_\mathrm{off}`$ なら、どの周期でも切る得は無い ∎

$`T_\mathrm{be}`$ は、07 章 5 節の $`t_\mathrm{be}`$（眠りの長さの境目）と同じ形をしているが、ここでは測る周期の境目なので、大文字で書く。$`Q_\mathrm{A}`$ と $`Q_\mathrm{B}`$ を $`T`$ で割ると、それぞれの平均電流は $`I_\mathrm{A} = I_\mathrm{sb} + (I_\mathrm{m} - I_\mathrm{sb})\, t_\mathrm{m}/T`$、$`I_\mathrm{B} = I_\mathrm{off} + (Q_\mathrm{on} + I_\mathrm{m} t_\mathrm{m})/T`$ である。

例の値を入れる。$`C_\mathrm{L}`$ = 1 µF・$`V`$ = 3.0 V で 3.0 µC、$`t_\mathrm{su}`$ = 2 ms・$`I_\mathrm{su}`$ = 0.3 mA で 0.6 µC、$`Q_\mathrm{cfg}`$ = 0.4 µC で、$`Q_\mathrm{on}`$ = 4.0 µC とする。測る間は $`I_\mathrm{m}`$ = 0.6 mA・$`t_\mathrm{m}`$ = 10 ms、$`I_\mathrm{off}`$ = 0.05 µA とする（どれも例の値）。

| センサの待機の電流 $`I_\mathrm{sb}`$ | $`T_\mathrm{be}`$ | 周期 10 s の $`I_\mathrm{A}`$ / $`I_\mathrm{B}`$ | 周期 60 s の $`I_\mathrm{A}`$ / $`I_\mathrm{B}`$ |
|---|---|---|---|
| 2 µA | (4.0 + 0.02) µC ÷ 1.95 µA ≈ 2.1 s | 2.60 µA / 1.05 µA | 2.10 µA / 0.22 µA |
| 0.2 µA | (4.0 + 0.002) µC ÷ 0.15 µA ≈ 27 s | 0.80 µA / 1.05 µA | 0.30 µA / 0.22 µA |


待機の電流が 2 µA のセンサでは、60 s ごとに測るなら、切ると平均電流は約 1/10 になる。0.2 µA のセンサでは、60 s ごとでも差は 0.08 µA にすぎず、10 s ごとなら入れたままのほうが小さい。起動を待つ間マイコンが起きていると、その電流も $`Q_\mathrm{on}`$ に入る。3 mA で 2 ms 待つと 6 µC が加わって $`Q_\mathrm{on}`$ は 10 µC になり、0.2 µA のセンサの $`T_\mathrm{be}`$ は 67 s に延びる。したがって、切るかどうかは、測る周期と $`T_\mathrm{be}`$（おおよそ起動の電荷 ÷ 待機の電流）を比べて決まる。切るなら、起動を待つ間はマイコンも眠る。

電荷のほかに、次のことも比べる。

- 遅れ: B では、測るたびに $`t_\mathrm{su}`$ だけ遅れる。起動時間が数十秒のセンサは、切ると欲しいときに値が無い。
- 見張る仕事: 加速度センサの「動いたら割り込みで知らせる」働きのように、センサ自身が見張るもの（10 章 1 節）は、切ると見張れない。
- 最初の値: 電源を入れた直後の何回かの値が正しくないセンサもある。データシートで確かめ、捨てる回数を決める。
- 電源の落ち込みと逆流: 入れるたびの突入電流で、マイコンの電源の電圧が落ちる（05 章 3 節）。切っている間は、4 節の逆流に気をつける。

### マイコンでする制御

- データシートの待機の電流・起動時間・入口の容量から $`T_\mathrm{be}`$ を求め、測る周期と比べて決める。普段は 10 分ごと、何か起きたら 1 秒ごとのように周期が変わる機器では、周期に合わせて切り替える。
- 切るときは、電源を入れたら起動時間の間 RTC で眠り（07 章 1 節）、起きてから設定を書き直して測る。
- 入れた後の最初の通信で答えなければ、6 節の手順でバスを戻す。

## 4. 電源を切ったセンサへの逆流

05 章 4 節と 07 章 3 節で、電源を切ったセンサのピンへ H を出すと、センサのピンの保護ダイオード（[組み込み回路シリーズ 19 章 2 節](../circuit/19_GPIO.md#保護ダイオード-最重要)）を通って、センサの電源の線へ電流が流れ込むことを見た。このように、電源の入っていない IC へ、入出力のピンから保護ダイオードを通って電源の線へ電流が流れ込み、IC に電力を与えてしまうことを、この章では**逆流**という（ピンからの給電ともいう）。この節では、センサをつないだときに逆流が起きる道と、流れる電流を求め、防ぎ方を決める。

逆流の道は、主に 3 つある。

```fig
e08_backflow
```

- (a) マイコンの出力のピンが H のまま: UART の TX は何も送らない間 H、SPI の CS は選ばない間 H である。
- (b) I2C のプルアップ抵抗を、いつも入っている電源（マイコンの電源）につないでいる: マイコンのピンを入力にしても、プルアップ抵抗から SDA と SCL を通って流れ込む。
- (c) (b) で、同じバスに電源を入れたままのセンサがいる: 電源を切ったセンサが線を引き下げ、ほかのセンサとも通信できなくなることがある（下で求める）。

### 流れる電流と線の電圧

**方針**: 電源を切ったセンサの電源の線につながった回路が使う電流を、抵抗 $`R_\mathrm{x}`$ を流れる電流とみなす。電流の源（電圧 $`V_\mathrm{DD}`$ と、その源の抵抗 $`R_\mathrm{s}`$）→ 保護ダイオード（電流が流れている間、電圧 $`V_\mathrm{F}`$ が落ちる）→ センサの電源の線 → $`R_\mathrm{x}`$ → GND を 1 本の道として、電流と電圧を求める。

**導出**: 道に沿って電圧を足すと、$`V_\mathrm{DD} = R_\mathrm{s} I + V_\mathrm{F} + R_\mathrm{x} I`$ である。$`V_\mathrm{F}`$ を左辺へ移し、両辺を $`R_\mathrm{s} + R_\mathrm{x}`$ で割って、

$$
I = \frac{V_\mathrm{DD} - V_\mathrm{F}}{R_\mathrm{s} + R_\mathrm{x}}, \qquad V_\mathrm{r} = R_\mathrm{x} I, \qquad V_\mathrm{bus} = V_\mathrm{r} + V_\mathrm{F}
$$

となる。$`V_\mathrm{r}`$ はセンサの電源の線の電圧、$`V_\mathrm{bus}`$ は信号の線の電圧である。(a) のプッシュプルの出力では、$`R_\mathrm{s}`$ は出力の抵抗（数十 Ω。[組み込み回路シリーズ 19 章 3 節](../circuit/19_GPIO.md#出力ドライバは-mosfet-である)）である。(b) では SDA と SCL の 2 本のプルアップ抵抗 $`R_\mathrm{p}`$ から並列に流れ込むので、$`R_\mathrm{s} = R_\mathrm{p}/2`$ である ∎

実際の回路の電流は電圧によって変わり、抵抗 1 本では表せないが、桁を見るにはこれで足りる。$`V_\mathrm{DD}`$ = 3.0 V、$`V_\mathrm{F}`$ = 0.5 V、$`R_\mathrm{p}`$ = 4.7 kΩ（$`R_\mathrm{s}`$ = 2.35 kΩ）、出力の抵抗を 40 Ω とする（どれも例の値）。

| センサの電源の線（$`R_\mathrm{x}`$） | (b) プルアップから: $`I`$・$`V_\mathrm{r}`$・$`V_\mathrm{bus}`$ | (a) H の出力から: $`I`$・$`V_\mathrm{r}`$ |
|---|---|---|
| 100 kΩ（ほとんど止まっている） | 24 µA・2.44 V・2.94 V | 25 µA・2.50 V |
| 10 kΩ（半端に動く） | 202 µA・2.02 V・2.52 V | 249 µA・2.49 V |
| 1 kΩ（LED やレギュレータを載せたモジュール） | 746 µA・0.75 V・1.25 V | 2.40 mA・2.40 V |

表と図から、4 つのことが分かる。

1. 電流: 24 µA〜2.4 mA で、深い眠りの電流（07 章の例で 2 µA）の 12〜1200 倍である。
2. 半端な電圧: センサの電源の線が 0.75〜2.5 V にとどまる。センサの POR は、電源が 0 V 近くから上がることを前提にしたものが多く、半端な電圧から電源を入れ直すと、正しくリセットされずに動き出し、SDA を L に引いたまま止まることがある（6 節）。
3. バスが止まる: (c) では、$`V_\mathrm{bus}`$ が、ほかの装置が H と読む電圧の下限 $`V_\mathrm{IH}`$（0.7 $`V_\mathrm{DD}`$ = 2.1 V とする。[組み込み回路シリーズ 19 章 4 節](../circuit/19_GPIO.md#しきい値)）を下回ると、線が H にならず、電源を入れたままのセンサとも通信できない。$`V_\mathrm{F} + (V_\mathrm{DD} - V_\mathrm{F})\,R_\mathrm{x}/(R_\mathrm{s} + R_\mathrm{x}) \ge V_\mathrm{IH}`$ を $`R_\mathrm{x}`$ について解くと（両辺から $`V_\mathrm{F}`$ を引き、$`R_\mathrm{s} + R_\mathrm{x}`$ を掛けて $`R_\mathrm{x}`$ の項を左辺にまとめ、正の数 $`V_\mathrm{DD} - V_\mathrm{IH}`$ で割る）、$`R_\mathrm{x} \ge (V_\mathrm{IH} - V_\mathrm{F})\,R_\mathrm{s}/(V_\mathrm{DD} - V_\mathrm{IH})`$ = 1.6 × 2.35 kΩ ÷ 0.9 ≈ 4.2 kΩ である。逆流で 0.38 mA 以上を使う（$`R_\mathrm{x}`$ が 4.2 kΩ より小さい）センサが 1 つでもあると、バス全体が止まる。
4. 部品を傷める: (a) で $`R_\mathrm{x}`$ が小さいと、ピンに流してよい電流（データシートの絶対最大定格）を超え、ラッチアップ（[組み込み回路シリーズ 11 章 5 節](../circuit/11_CMOSロジック.md#ラッチアップ)）を起こすおそれがある。

### 防ぎ方

```fig
e08_bfgood
```

- プルアップ抵抗は、センサと同じ、切る側の電源につなぐ。切るとプルアップ抵抗も電源を失い、線は 0 V になるので、(b) の道が無くなる。
- 切っている間、そのセンサへのマイコンの出力のピンは L かアナログの設定（07 章 3 節）にし、H を出さない。センサの出力（SPI の MISO、センサの割り込みの線）を受けるピンは、切っている間は浮いた入力（07 章 3 節）になるので、アナログの設定にする。
- 切るセンサと、電源を入れたままのセンサを同じバスにしない。切るセンサは別のバスにまとめるか、データシートに「電源を切ってもピンが線を引き下げない」と書かれたものを選ぶ。
- 順番は 05 章 4 節の電源シーケンスのとおり、入れるときは電源が先・信号が後、切るときは信号が先・電源が後にする。

切っている間と、入れた後のピンの扱いを、方式ごとにまとめる。

| 線 | 切っている間のマイコンのピン | 入れた後（起動時間の後） |
|---|---|---|
| I2C の SDA・SCL（プルアップは切る側の電源） | L かアナログの設定 | 線が H になったのを確かめてから I2C の回路に戻す（6 節） |
| SPI の SCLK・MOSI | L | SPI の回路に戻す |
| SPI の CS（プルアップは切る側の電源） | L | H にしてから使う（電源を入れたときの CS の電圧で I2C か SPI かを決めるセンサもあるので、データシートで確かめる） |
| SPI の MISO、センサの割り込みの線 | アナログの設定 | 入力に戻す |
| UART の TX | L | H に戻してから UART の回路に戻す |
| UART の RX | アナログの設定 | UART の回路に戻し、最初に届く半端なバイトは捨てる |

UART の TX を L にしておくと、相手には長い 0（ブレーク。[組み込み通信シリーズ 02 章 3 節](../comm/02_UART.md#受信の仕組み-立ち下がりで合わせ-ビットの中央で読む)）に見えるが、相手の電源は切れているので問題にならない。入れた後は、相手が起動を終える前に H に戻す。

### マイコンでする制御

- 07 章 3 節の眠る間のピンの表に、センサの電源を切っている間の設定を加え、電源を切る関数の中で、切る前にまとめて設定する。
- 眠りの電流が見積もりより大きいときは、切ったはずのセンサの電源の線の電圧を測る。数百 mV 以上残っていれば、どこかから逆流している。

## 5. プルアップ抵抗を選ぶ — 速さと電流

I2C の線は、L にするときはオープンドレインの出力が速く引き下げるが、H に戻すときは、プルアップ抵抗が線の容量を充電して上げる。線の容量は、つながった装置のピン、基板の配線、コネクタとケーブルの容量の合計で、これを**バス容量**といい、$`C_\mathrm{b}`$ と書く。代表値で、ピン 1 本あたり数 pF〜10 pF、基板の配線で 1 cm あたり 1 pF 前後、ケーブルで 1 m あたり 50〜100 pF である。マイコンとセンサ 3 個に、基板の配線 20 cm なら 60 pF ほどで、余裕を見て 100 pF とする（例の値）。オシロで測るときは、プローブの容量（10 pF 前後。代表値）も足される（[組み込みテストシリーズ 04 章 6 節](../embtest/04_デジタル信号の観測.md#プローブの当て方)）。

線の電圧が L から H へ変わるときに、決めた 2 つの電圧の間を通るのにかかる時間を、**立ち上がり時間**という。I2C の規格は、立ち上がり時間 $`t_\mathrm{r}`$ を、電源の電圧 $`V_\mathrm{DD}`$ の 30 % から 70 % までの時間と決めている。30 % と 70 % は、L と読める上限 $`V_\mathrm{IL}`$ = 0.3 $`V_\mathrm{DD}`$ と、H と読める下限 $`V_\mathrm{IH}`$ = 0.7 $`V_\mathrm{DD}`$ である。

**方針**: プルアップ抵抗 $`R_\mathrm{p}`$ がバス容量 $`C_\mathrm{b}`$ を充電するときの電圧の式から、30 % と 70 % に届く時刻を求めて引く。

**導出**: 時刻 0 に線を離すと、電圧は $`v(t) = V_\mathrm{DD}(1 - e^{-t/(R_\mathrm{p} C_\mathrm{b})})`$ で上がる（[組み込み回路シリーズ 03 章 1 節](../circuit/03_過渡応答とフィルタ.md#rc-回路の過渡応答)）。$`v(t) = a V_\mathrm{DD}`$（$`0 < a < 1`$）となる時刻を求める。両辺を $`V_\mathrm{DD}`$ で割ると $`1 - e^{-t/(R_\mathrm{p} C_\mathrm{b})} = a`$、移項して $`e^{-t/(R_\mathrm{p} C_\mathrm{b})} = 1 - a`$ である。両辺の自然対数をとって $`-t/(R_\mathrm{p} C_\mathrm{b}) = \ln(1 - a)`$、両辺に $`-R_\mathrm{p} C_\mathrm{b}`$ を掛けて $`t = R_\mathrm{p} C_\mathrm{b} \ln\{1/(1 - a)\}`$ となる。$`a`$ = 0.3 では $`R_\mathrm{p} C_\mathrm{b} \ln(1/0.7) = 0.3567\, R_\mathrm{p} C_\mathrm{b}`$、$`a`$ = 0.7 では $`R_\mathrm{p} C_\mathrm{b} \ln(1/0.3) = 1.2040\, R_\mathrm{p} C_\mathrm{b}`$ なので、

$$
t_\mathrm{r} = R_\mathrm{p} C_\mathrm{b} \left( \ln\frac{1}{0.3} - \ln\frac{1}{0.7} \right) = R_\mathrm{p} C_\mathrm{b} \ln\frac{7}{3} \approx 0.8473\, R_\mathrm{p} C_\mathrm{b}
$$

となる ∎

[組み込み回路シリーズ 19 章 5 節](../circuit/19_GPIO.md#プルアップ抵抗の決め方)の $`1.2\, R C_\mathrm{b}`$ は、0 から 70 % まで（L から、H と読めるまで）の時間で、規格の $`t_\mathrm{r}`$ とは測る区間が違う。

プルアップ抵抗の値は、2 つの条件で挟まれる。

- 上限（速さ）: $`0.8473\, R_\mathrm{p} C_\mathrm{b} \le t_\mathrm{r,max}`$ の両辺を $`0.8473\, C_\mathrm{b}`$ で割って、$`R_\mathrm{p} \le t_\mathrm{r,max}/(0.8473\, C_\mathrm{b})`$。$`C_\mathrm{b}`$ = 100 pF なら、100 kHz で 11.8 kΩ、400 kHz で 3.54 kΩ、1 MHz で 1.42 kΩ である。
- 下限（L に引ける電流）: 線を L に引いている装置には、$`(V_\mathrm{DD} - V_\mathrm{OL})/R_\mathrm{p}`$ の電流が流れ込む。これが $`I_\mathrm{OL}`$ 以下であるために、両辺に $`R_\mathrm{p}`$ を掛けて $`I_\mathrm{OL}`$ で割り、$`R_\mathrm{p} \ge (V_\mathrm{DD} - V_\mathrm{OL})/I_\mathrm{OL}`$。$`V_\mathrm{DD}`$ = 3.0 V なら、100 kHz・400 kHz で 867 Ω、1 MHz で 130 Ω である。

### 電流との釣り合い

線が L の間、プルアップ抵抗には約 $`V_\mathrm{DD}/R_\mathrm{p}`$ が流れる。2.2 kΩ なら 1.36 mA、4.7 kΩ なら 0.64 mA である。通信の間だけなら、2 節の図のとおり 1 回の読み出しで 1 µC に満たない。問題は、線が L のまま眠ったときである。2.2 kΩ の線が 1 本 L のままだと 1.36 mA が流れ続け、CR2032（220 mAh）は 220 ÷ 1.36 ≈ 161 時間、約 7 日で尽きる。線は、マイコンが通信を途中でやめたとき、スレーブが線を離さないとき（6 節）、逆流で引き下げられたとき（4 節）に L のまま残る。

抵抗を小さくすると速く上がるが、L の間の電流が増える。電池で動く機器では、範囲の中で上限に余裕を残した大きめの値を選ぶ。$`C_\mathrm{b}`$ = 100 pF なら、400 kHz で 2.2 kΩ（$`t_\mathrm{r}`$ = 186 ns、上限の 62 %）、100 kHz で 4.7 kΩ（398 ns）〜 10 kΩ（847 ns）が目安になる。2 節の比較のとおり、速くできるなら、通信の時間が縮む分、1 回の読み出しの電荷はかえって減ることが多い。

次の 3 つも確かめる。

- マイコンの内蔵のプルアップ（数十 kΩ。07 章 3 節）は大きすぎる。40 kΩ に 100 pF では $`t_\mathrm{r}`$ = 3.39 µs で、100 kHz の上限 1000 ns も満たさない。外付けの抵抗を使う。
- プルアップ抵抗を載せたモジュールを何枚もつなぐと、抵抗が並列になる。2.2 kΩ が 3 枚なら 733 Ω で、L のときの電流は (3.0 − 0.4) V ÷ 733 Ω = 3.5 mA と、$`I_\mathrm{OL}`$ の 3 mA を超える。合成を求め、余分な抵抗は外す。
- 立ち上がりが遅いと、クロックが設定より遅くなることがある。SCL が実際に H になったのを見てから H の時間を数え始める I2C の回路が多いからである。

### マイコンでする制御

- 装置の数と配線の長さからバス容量を見積もり、上の 2 つの条件で範囲を求め、上限に余裕を残した値を選ぶ。作った基板では、SCL の立ち上がりをオシロで測って確かめる。
- 眠る前に、SDA と SCL が H であることを読んで確かめる。L なら 6 節の手順で戻してから眠る。
- 切るセンサのプルアップ抵抗は、センサと同じ電源につなぐ（4 節）。

## 6. バスが止まったら — I2C の復旧

I2C のバスは、どれか 1 台が線を L に引いたままだと、ほかの全部の装置が通信できない。SDA か SCL が L のまま戻らず、マスタが開始条件を出せなくなった状態を、**バスの固まり**という。最も多いのは、読み出しの途中でマイコンがリセットされた場合である。

```fig
e08_hang
```

図のように、マイコンは、スレーブが値のビットを SDA に出している途中で、ウォッチドッグ（01 章 5 節）や BOR（05 章 5 節）、デバッガの操作でリセットされることがある。スレーブはリセットされていないので、送りかけのバイトの残りを、クロックが来るのを待ちながら出し続ける。いま出しているビットが 0 なら、SDA は L のままである。リセットから戻ったマスタは、SCL が H の間に SDA を H から L にする開始条件を作れない。ほかにも、ノイズで SCL に余分な変わり目が入ってスレーブがビットを数え違えたとき、スレーブ自身が止まって SCL を L に引いたままになったとき、半端な電圧から起動したセンサが正しくリセットされなかったとき（4 節）、電源を切ったセンサが線を引き下げているとき（4 節の (c)）にも、固まる。

### クロックで送り出させる

SDA が L のときは、マスタが SCL を L・H と動かして、スレーブに送りかけのバイトを送り終えさせる。スレーブは、クロックの立ち下がりごとに次のビットを出し、1 のビットや、8 ビットを出し終えた後の ACK の位置では SDA を離す。ACK の位置でマスタは SDA を L に引かないので、スレーブはそれを NACK と受け取り、次のバイトを送らない。送りかけのバイトの残りは多くて 8 ビットで、スレーブがアドレスへの ACK を返している途中だった場合でも、ACK を終えるのに 1 個、続く値の 8 ビットに 8 個で、9 個のクロックまでに SDA は離される。SDA が H になったら、マスタは SCL を H にしたまま SDA を L・H と動かす。これは開始条件と停止条件を続けて出すことにあたり、スレーブは途中のバイトを捨てて、次の開始条件を待つ状態に戻る。I2C の規格書も、SDA が L のまま戻らないときは 9 個のクロックを送り、それでも戻らなければ、装置のリセットのピンか電源の入れ直しで戻す手順を示している。

SCL が L のままのときは、クロックを送れない。スレーブが待たせているだけなら、データシートに書かれた最長の時間を待てば離される。それより長く続くなら、センサの電源を負荷スイッチで切って入れ直し、センサの POR で戻す。電源を入れ直せる設計にしておくことが、最後の手段になる。

固まったバスを、マスタが決めた手順で使える状態に戻すことを、**バスの復旧**という。手順をまとめる。

```fig

```

### マイコンでする制御

マイコンの I2C の回路は、決まった形の通信しか出せないものが多いので、復旧の間はピンを GPIO にして、プログラムで線を動かす（I2C の回路自身がこの手順を持つマイコンもある）。次のコードは、その一例である。`i2c_hw_on()`・`scl_out()`・`sda_out()`・`scl_in()`・`sda_in()`・`sens_power()`・`delay_us()` は、この章で仮に置く関数で、`scl_out(true)`・`sda_out(true)` は線を離す（オープンドレインの H）、`false` は L に引くことを表す。プルアップ抵抗はセンサと同じ切る側の電源にある（4 節）とする（`stdbool.h`・`stdint.h` を使う）。

```c
typedef enum { BUS_OK, BUS_CLOCKED, BUS_REPOWERED, BUS_DEAD } bus_t;
#define HALF_US 5                  /* クロックの半周期 [µs]（100 kHz 相当。例の値） */

/* SCL を離し、H になるのを最大 1 ms 待つ（スレーブが L に引いて待たせる間を待つ） */
static bool scl_release(void)
{
    scl_out(true);
    for (int t = 0; t < 1000; t++) {
        if (scl_in())
            return true;
        delay_us(1);
    }
    return false;
}

/* SDA が H になるまで、クロックを最大 9 回送る。H になったら、SCL を H のまま
   SDA を L・H と動かし、開始条件と停止条件を続けて出す（スレーブを待つ状態に戻す） */
static bool clock_out(void)
{
    for (int k = 0; k < 9 && !sda_in(); k++) {
        scl_out(false);  delay_us(HALF_US);
        if (!scl_release())
            return false;
        delay_us(HALF_US);
    }
    if (!sda_in())
        return false;
    sda_out(false);  delay_us(HALF_US);   /* 開始条件 */
    sda_out(true);   delay_us(HALF_US);   /* 停止条件 */
    return sda_in() && scl_in();
}

/* 起動の直後と、読み書きが時間の上限を超えたときに呼ぶ */
bus_t i2c_recover(void)
{
    i2c_hw_on(false);                     /* ピンを GPIO（オープンドレイン）にする */
    sda_out(true);
    bus_t r = sda_in() ? BUS_OK : BUS_CLOCKED;
    if (!scl_release() || !clock_out()) { /* SCL が L のまま、または 9 回で戻らない */
        sens_power(false);  delay_us(10000);   /* センサとプルアップを切る（4 節） */
        sens_power(true);   delay_us(5000);    /* 起動時間を待つ（例の値） */
        r = (scl_release() && clock_out()) ? BUS_REPOWERED : BUS_DEAD;
    }
    i2c_hw_on(true);
    return r;
}
```

SDA が H になった所で、SCL を L に戻さずに開始条件と停止条件を出すのは、SCL をもう一度下げると、スレーブが次のビットを出し、それが 0 なら SDA を再び L に引くからである。線が固まっていないとき（`BUS_OK`）も、開始条件と停止条件を 1 回出すので、途中のバイトを待っているスレーブが残らない。そこで、リセットの原因によらず、起動の直後に 1 回呼ぶ。`BUS_CLOCKED`・`BUS_REPOWERED` なら、センサの設定を最初から書き直し（電源を入れ直したなら、3 節の起動時間を待つ）、回数と原因を記録する。`BUS_DEAD` なら、配線の短絡やセンサの故障を疑い、そのセンサを使わずに動き続ける（15 章 5 節）。

このコードは、スレーブの動き（クロックの立ち下がりで次のビットを出し、ACK の位置で NACK を受けたら送るのをやめ、開始条件と停止条件で待つ状態に戻る）をホストのコンピュータで模して確かめた。読み出しの途中の値 256 通り × ビットの位置 8 通りのすべてでクロックは 8 回以内、アドレスへの ACK の途中からは値が 0x00 のときに 9 回で戻ること、書き込みの途中ではクロックを送らずに戻ること、SCL を L に保つスレーブは電源の入れ直しで戻ること、SDA が GND に短絡していれば `BUS_DEAD` を返し、どの場合も最後に I2C の回路に戻すことを確かめてある。

もう 1 つ気をつける。書き込みの途中で止まったスレーブに、停止条件がバイトの区切りで届くと、それまでに受け取ったバイトを書き込むメモリの IC がある。書き込みは、途中で止まっても前の値が残る形で置く（05 章 5 節）。

下の図で、マイコンがリセットされたときのスレーブの状態（読み出しの途中の値とビットの位置、ACK の途中、SCL を L に保つ、SDA の短絡）を選び、クロックを 1 回ずつ送るか、復旧の手順を通して動かすと、SDA と SCL の波形と、スレーブの状態が表示される。

| SPI・UART | クロック・2 本のデータ・スレーブごとの CS でつなぐ速い方式／TX と RX を交差させ、決めた速さで送る 1 対 1 の方式 |

| 条件 | 気をつけること | マイコンでする制御 |
|---|---|---|
| 配線が長い・ノイズが多い（1 節） | アナログ出力はノイズがそのまま値の誤差になる | デジタル出力かパルス出力を選ぶ。パルスは周波数で測り方を選ぶ |

| I2C を速く・少ない電流で使う（5 節） | 抵抗が大きいと立ち上がりが遅く、小さいと L の間の電流が大きい。L のまま眠ると電池が尽きる | 範囲の中で余裕を残した大きめの値を選ぶ。眠る前に線が H かを確かめる |
