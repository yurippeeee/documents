# 00. 目次と学習の進め方 — 動かして理解する組み込み通信

## このシリーズについて

マイコンを内蔵した機器（組み込み機器）が、ケーブルや電波を使って外の機器やインターネットとデータをやり取りする仕組みを、下の層から順に積み上げて説明する。対象は、組み込みの通信は初めてだが、C 言語・2 進数と 16 進数・簡単な電気回路などの技術者としての基礎がある人である。

方針は 3 つある。

1. **下の層から順に積み上げる.** 1 本の信号線の上のビット（UART）から始めて、バイトの列の区切り方、取りこぼさない受け取り方、応答と再送の手順を作り、その上にインターネット（IP・TCP・TLS・MQTT）と BLE を重ねる。
2. **図とデモで確かめる.** 各節に図を置き、各章には値を変えて結果を確かめられるデモ（▶ の付いた図）を 2〜4 個置いている。数値はすべて計算して確かめてある。
3. **実装まで書く.** 載せている C のコードは、PC 上でコンパイルしてテストしたものである。マイコンのレジスタに依存する所は、その章で仮に置いた関数として示す。

## 表記のきまり

- 通信の速さの k・M は 1000 倍・100 万倍（1 kbps = 1000 bps）、メモリの大きさの KB は 1024 バイトとする（01 章）。
- 16 進数は `0x41`、バイトの列は `41 42 43` のように書く。ビットの番号は最下位を 0 とする。
- 電流・処理時間・メモリの使用量など、製品によって違う値は「代表値」と書く。実際の値はデータシートで確かめること。
