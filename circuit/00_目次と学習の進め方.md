# 00. 目次と学習の進め方

## このシリーズの狙い

**組み込み機器の回路を、「読めて、選べて、直せる」ようになる。**

組み込みのソフトウェアエンジニアが回路で困るのは、たいてい次の場面である。

| 場面 | 必要な知識 |
|---|---|
| 回路図を渡されたが読めない | 記号と基本素子（01〜03 章） |
| 「プルアップ抵抗は何 kΩ？」と聞かれた | I2C の物理層（19・20 章） |
| センサの値がノイズだらけ | アナログ信号調整と ADC（08・17 章） |
| 電源が不安定で MCU がリセットする | LDO・デカップリング（14・16 章） |
| 部品表の型番が読めない | 各 IC の方式と選定基準（各章） |
| **なぜこの IC はこう動くのか** | **IC の内部回路**（07・11・13・14・17 章） |

このシリーズは、**素子の基礎から、IC の内部回路の仕組みまで**を一本で通す。

> **「IC の中身を知る必要があるのか」という問いについて.**
>
> ある。理由は 3 つ。
>
> 1. **データシートの数値の意味が分かる。**
>    「オフセット電圧 ±2 mV」「PSRR 60 dB」「INL ±1 LSB」——
>    これらは内部回路の構造から出てくる値である。中身を知らないと、
>    どの数値が効くのか判断できない。
>
> 2. **失敗の原因が分かる。**
>    「LDO が発振した」「ADC の値が飛ぶ」「I2C が立ち上がらない」——
>    どれも内部の等価回路を知っていれば説明がつく。
>
> 3. **選定ができる。**
>    同じ「ADC」でも、SAR と ΔΣ とパイプラインではまったく違うものである。
>    中身を知らないと、カタログのスペックだけで選ぶことになる。

## このシリーズの方針

| 方針 | 内容 |
|---|---|
| **動くデモを最優先** | 全章に、値を変えると波形や特性が変わるデモを置いた（計 32 点） |
| **式は導出する** | 結果だけでなく、どこから来た式かを示す |
| **理想と現実を分ける** | 「教科書の式」と「実際に効いてくる寄生成分」を必ず並べる |
| **数値の感覚を持つ** | 「だいたいどれくらいか」を覚えられるように、具体値を多く出す |
| **失敗例を挙げる** | 実際に起きる事故と、その原因 |

## 全体構成

| 部 | 章 | 内容 |
|---|---|---|
| **第 I 部: 電気と素子** | 01〜04 | 電圧電流抵抗・受動素子の実際・過渡応答とフィルタ・ダイオード |
| **第 II 部: トランジスタ** | 05〜06 | MOSFET・バイポーラと使い分け |
| **第 III 部: アナログ IC** | 07〜10 | オペアンプの内部・応用と制約・コンパレータと発振・リファレンス |
| **第 IV 部: デジタル IC** | 11〜13 | CMOS ロジック・タイミングと消費電力・メモリセル |
| **第 V 部: 電源 IC** | 14〜16 | LDO・スイッチングレギュレータ・電源設計の実際 |
| **第 VI 部: データ変換 IC** | 17〜18 | ADC の方式・DAC の方式 |
| **第 VII 部: インタフェース** | 19〜22 | GPIO・シリアル物理層・アイソレータ・パワーとモータ |
| **第 VIII 部: 実装** | 23〜25 | 基板とシグナルインテグリティ・EMC・測定とデバッグ |

## 章一覧

**第 I 部 — 電気と素子**

| 章 | タイトル | ひとことで言うと |
|---|---|---|
| 01 | 電圧・電流・抵抗 | 回路を読むための最小限。分圧とキルヒホッフ |
| 02 | 受動素子の実際 | 理想の R・L・C は存在しない。ESR と ESL が支配する |
| 03 | 過渡応答とフィルタ | RC の時定数。すべての「なまり」の正体 |
| 04 | ダイオードと PN 接合 | 指数関数で効く素子。整流・保護・基準電圧 |

**第 II 部 — トランジスタ**

| 章 | タイトル | ひとことで言うと |
|---|---|---|
| 05 | MOSFET | 電圧で開閉するスイッチ。すべての IC の基本部品 |
| 06 | バイポーラと使い分け | 電流で駆動する素子。アナログではまだ現役 |

**第 III 部 — アナログ IC**

| 章 | タイトル | ひとことで言うと |
|---|---|---|
| 07 | オペアンプの内部回路 | 差動対 → 利得段 → 出力段。中を知れば仕様が読める |
| 08 | オペアンプの応用と現実の制約 | 仮想短絡と、それが破れるところ |
| 09 | コンパレータ・発振回路・PLL | 比較する・振らせる・同期させる |
| 10 | 電圧リファレンスと温度センサ | バンドギャップ。なぜ 1.2 V なのか |

**第 IV 部 — デジタル IC**

| 章 | タイトル | ひとことで言うと |
|---|---|---|
| 11 | CMOS ロジック | インバータ 1 個からすべてが作られる |
| 12 | タイミング・消費電力・メタステーブル | 「なぜか動かない」の物理的な原因 |
| 13 | メモリ IC の中身 | SRAM 6T・DRAM 1T1C・NOR/NAND のセル構造 |

**第 V 部 — 電源 IC**

| 章 | タイトル | ひとことで言うと |
|---|---|---|
| 14 | LDO の内部回路 | 誤差アンプ + パストランジスタ。発振の理由 |
| 15 | スイッチングレギュレータ | インダクタに貯めて配る。Buck / Boost の動作 |
| 16 | 電源設計の実際 | デカップリング・シーケンス・保護・熱 |

**第 VI 部 — データ変換 IC**

| 章 | タイトル | ひとことで言うと |
|---|---|---|
| 17 | ADC の方式と内部回路 | SAR / ΔΣ / パイプライン / フラッシュ |

**第 VII 部 — インタフェース**

| 章 | タイトル | ひとことで言うと |
|---|---|---|

| 20 | シリアルインタフェースの物理層 | UART / SPI / I2C / CAN / RS-485 / USB / LVDS |
| 21 | アイソレータ・レベルシフタ・ドライバ | 電位を切り離す・つなぎ変える |
| 22 | パワーデバイスとモータドライバ | H ブリッジ・ゲートドライバ・デッドタイム |

**第 VIII 部 — 実装**

| 章 | タイトル | ひとことで言うと |
|---|---|---|
| 23 | 基板設計とシグナルインテグリティ | 配線は抵抗ではなく伝送線路である |

## 読み方

**01〜05 章は飛ばさないこと。** 特に **02 章（受動素子の実際）** と
**05 章（MOSFET）** は、以降の全章の前提になる。

一方、**第 III 部以降は興味のあるところから読んでよい**。
IC の章はそれぞれ独立している。

### 目的別の近道

| 目的 | ルート |
|---|---|
| 回路図を読めるようになりたい | 01 → 02 → 04 → 05 → 11 |
| センサの値をきれいに取りたい | 03 → 08 → 17 → 24 |
| 電源トラブルを解決したい | 02 → 14 → 15 → 16 → 25 |
| 通信が不安定な原因を探したい | 19 → 20 → 23 → 24 |
| IC の内部を理解したい | 05 → 07 → 11 → 14 → 17 |
| 基板を設計する | 02 → 16 → 23 → 24 |
| モータを回したい | 05 → 15 → 22 |
| ぜんぶ | 01 → 25（推奨） |

## 前提知識

| 分野 | 必要な水準 |
|---|---|
| 数学 | 四則演算と指数。微分の意味（変化率）が分かると楽 |
| 物理 | 不要。必要な範囲は本文で説明する |
| 複素数 | 03 章で使うが、必要な範囲は説明する |

## 記法の約束

| 表記 | 意味 |
|---|---|
| $`V`$、$`I`$、$`R`$ | 電圧 [V]、電流 [A]、抵抗 [Ω] |
| $`v(t)`$、$`i(t)`$ | 時間の関数としての電圧・電流（小文字は瞬時値） |
| $`Z`$ | インピーダンス [Ω]（複素数） |
| $`\omega`$ | 角周波数 $`\omega = 2\pi f`$ [rad/s] |
| $`\tau`$ | 時定数 [s] |
| GND | 基準電位（0 V） |
| $`V_{CC}`$ / $`V_{DD}`$ | 電源電圧（慣習: バイポーラは CC、MOS は DD） |

> **注意: 数値は「桁の感覚」を掴むためのものである.**
>
> 本文中の具体的な数値（順方向電圧、閾値電圧、寄生容量など）は、
> **代表的な値の目安**である。実際の部品は品種・温度・プロセスで大きく変わる。
>
> **設計に使う値は、必ず対象部品のデータシートで確認すること。**
