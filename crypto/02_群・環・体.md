# 02. 群・環・体 — 「計算できる世界」の分類学

> **なぜ抽象代数が出てくるのか.**
> [01 章](01_合同算術とユークリッドの互除法.md#剰余類と-mathbbzm)で、$`m`$で割った余りだけを考える世界$`\mathbb{Z}_m`$を作った。この先には似た世界がいくつも出てくる。多項式の世界、8 ビットのまとまりであるバイトの世界、楕円曲線上の点の世界である。
> どれも「要素の集合と、その上の演算」でできていて、**同じ規則で動いている**。
>
> 毎回ゼロから性質を調べ直すのは無駄なので、共通の骨組みに名前を付けておく。
> それが**群・環・体**という 3 つの言葉である。
> 分類の基準は「演算がいくつあるか」と「それぞれの演算を打ち消せるか」の 2 つだけである。
>
> - **群**: 演算が 1 つ。その演算は必ず打ち消せる
> - **環**: 演算が 2 つ。足し算は必ず打ち消せるが、掛け算は打ち消せる保証がない
> - **体**: 演算が 2 つ。0 で割る場合を除き、どちらも必ず打ち消せる
>
> 「打ち消せる」の正確な意味は 1 節の定義で与える。
> ゴールは**体**である。誤り訂正も暗号も体の上で計算するからこそ、連立方程式が解け、多項式が因数分解でき、逆算ができる。

> **この章で使う既出の用語（定義は各リンク先）.**
> 除法の原理と$`a \bmod m`$、合同$`a \equiv b \pmod m`$、$`\mathbb{Z}_m`$（[01 章 1 節](01_合同算術とユークリッドの互除法.md#合同とは-時計の算数)）、
> $`\mathbb{Z}_m`$の足し算・引き算・掛け算と「計算の途中でいつでも余りを取ってよい」こと（[01 章 2 節](01_合同算術とユークリッドの互除法.md#合同式の演算-足し算-引き算-掛け算は-そのまま-できる)）、
> 最大公約数$`\gcd`$と互いに素（[01 章 3 節](01_合同算術とユークリッドの互除法.md#最大公約数とユークリッドの互除法)）、
> 乗法逆元$`a^{-1}`$と、その存在条件「$`a`$が法$`m`$で逆元を持つ$`\iff \gcd(a, m) = 1`$」（[01 章 5 節](01_合同算術とユークリッドの互除法.md#逆元が存在する条件)）。

## 1. 群 (Group)

### 定義

集合$`G`$の 2 つの要素$`a, b`$から 1 つの値を決める規則を**2 項演算**といい、記号$`\ast`$を使って$`a \ast b`$と書く。足し算や掛け算が代表例である。決まった値が$`G`$に入るかどうかは、下の条件 1 で確かめる。

集合$`G`$と 2 項演算$`\ast`$が次の 4 条件を満たすとき、組$`(G, \ast)`$を**群**という。

| # | 名前 | 条件 | 意味 |
|---|---|---|---|
| 1 | **閉性** | $`a, b \in G \Rightarrow a \ast b \in G`$ | 演算の結果が$`G`$の外に出ない |
| 2 | **結合律** | $`(a \ast b) \ast c = a \ast (b \ast c)`$ | 3 つ以上を演算するとき、どこから計算しても同じ |
| 3 | **単位元** | ある$`e \in G`$があって、すべての$`a \in G`$で$`a \ast e = e \ast a = a`$ | 演算しても相手を変えない要素がある |
| 4 | **逆元** | 各$`a \in G`$に対し、$`a \ast b = b \ast a = e`$となる$`b \in G`$がある | どの要素も打ち消せる |

さらに、すべての$`a, b`$で$`a \ast b = b \ast a`$が成り立つとき、この性質を**交換律**といい、交換律を満たす群を**可換群**という。アーベル群は可換群の別名である。
要素のことを**元**（げん）ともいう。単位元・逆元の「元」はこの意味である。

単位元と逆元は演算ごとに決まる。足し算なら単位元は$`0`$、$`a`$の逆元は$`-a`$である。掛け算なら単位元は$`1`$で、$`a`$の逆元は掛けて 1 になる数である。普通の数なら$`1/a`$、$`\mathbb{Z}_m`$なら 01 章の乗法逆元である。
引き算と割り算は独立した演算ではなく、逆元との演算の略記として扱う。$`a - b`$は「$`a`$に$`b`$の足し算の逆元$`-b`$を足すこと」、$`a \div b`$は「$`a`$に$`b`$の掛け算の逆元を掛けること」である。
冒頭で「打ち消せる」と呼んだのは、この逆元が必ず存在することを指す。

要素が有限個なら、演算の結果をすべて並べた**演算表**で条件を確かめられる。行に左側の要素、列に右側の要素を取り、交点に$`a \ast b`$を書く。

左の表は 4 条件をすべて満たす。右の表では$`2 \times 3 = 6 \equiv 0`$のように集合の外の 0 が出て閉性が破れ、2, 3, 4 の行に 1 が無いので逆元の条件も破れる。

結合律は演算表を一目見ても分からず、3 つの要素のすべての組で確かめる必要がある。ただし$`\mathbb{Z}_m`$の足し算と掛け算では、その必要はない。たとえば足し算では

$$
\bigl((a + b) \bmod m + c\bigr) \bmod m = (a + b + c) \bmod m = \bigl(a + (b + c) \bmod m\bigr) \bmod m
$$

である。左の等号は、$`(a + b) \bmod m \equiv a + b`$の両辺に$`c`$を足しても合同が保たれ（01 章 2 節）、合同な数は余りが等しい（01 章 1 節）ことによる。右の等号も同様である。何回演算しても同じ議論ができるので、$`\mathbb{Z}_m`$での計算結果は「整数として計算してから$`m`$で割った余り」に等しい。したがって整数の足し算と掛け算が満たす結合律・交換律・分配律は、$`\mathbb{Z}_m`$でもそのまま成り立つ。

### 単位元と逆元はただ 1 つ

**方針**: 単位元が 2 つ、またはある要素の逆元が 2 つあると仮定し、結合律と単位元の性質を使って 2 つが等しいことを示す。

**導出**: 単位元$`e`$と$`e'`$があるとすると

$$
e = e \ast e' = e'
$$

である。左の等号は$`e'`$が単位元であること、右の等号は$`e`$が単位元であることによる。
次に、$`a`$の逆元$`b`$と$`c`$があるとする。$`b \ast a = e`$と$`a \ast c = e`$を使うと

$$
b = b \ast e = b \ast (a \ast c) = (b \ast a) \ast c = e \ast c = c
$$

である。3 つ目の等号で結合律を使った ∎

そこで、$`a`$のただ 1 つの逆元を$`a^{-1}`$と書く。演算が足し算のときは$`-a`$と書く。逆元について次の 2 つがよく使われる。

- $`(a^{-1})^{-1} = a`$。$`a^{-1} \ast a = a \ast a^{-1} = e`$は「$`a`$が$`a^{-1}`$の逆元である」とも読めるからである。
- $`(a \ast b)^{-1} = b^{-1} \ast a^{-1}`$。結合律を使うと$`(a \ast b) \ast (b^{-1} \ast a^{-1}) = a \ast (b \ast b^{-1}) \ast a^{-1} = a \ast e \ast a^{-1} = a \ast a^{-1} = e`$であり、逆の順に演算しても同様に$`e`$になるからである。

### 例で確かめる

**例 1: 整数と足し算$`(\mathbb{Z}, +)`$** — 群である。
整数どうしの和は整数なので閉性を満たし、結合律も成り立つ。単位元は$`0`$、$`a`$の逆元は$`-a`$である。
引き算$`5 - 3`$は$`5 + (-3)`$の略記であり、逆元があるから引ける。

**例 2: 整数と掛け算$`(\mathbb{Z}, \times)`$** — 群では**ない**。
単位元$`1`$はあるが、$`2 \times b = 1`$となる整数$`b`$が無いので条件 4 が破れる。
掛け算を打ち消す割り算が、整数の中ではできない。

**例 3: $`\mathbb{Z}_m`$と足し算** — 群である。
結果は$`m`$で割った余りなので$`\mathbb{Z}_m`$に入り、閉性を満たす。結合律は上で見たとおり成り立つ。単位元は$`0`$である。
$`a \neq 0`$の逆元は$`m - a`$である。$`a + (m - a) = m \equiv 0`$だからである。$`0`$の逆元は$`0`$である。
法 12 で$`5`$の逆元は$`7`$であり、時計を 5 時間進めてから 7 時間進めると元に戻る。

**例 4: $`\mathbb{Z}_m`$から 0 を除いた集合と掛け算** — **$`m`$が素数のときだけ**群になる。
$`0`$を除くのは、どんな$`x`$でも$`0 \times x = 0 \neq 1`$で、$`0`$が逆元を持たないからである。

- $`m`$が素数$`p`$のとき: 01 章 5 節より、$`1, \dots, p-1`$のどの$`a`$も逆元$`a^{-1}`$を持つ。閉性は次のように確かめる。$`a \neq 0`$、$`b \neq 0`$で$`ab \equiv 0`$だったとすると、両辺に$`a^{-1}`$を掛けて$`b \equiv a^{-1} \cdot 0 = 0`$となり、$`b \neq 0`$に矛盾する。よって積は 0 にならず、集合の中に留まる。単位元は$`1`$である。もし$`a^{-1} = 0`$なら$`a \cdot a^{-1} = 0`$となって 1 にならないので、$`a^{-1}`$は 0 ではなく、集合の中にある。結合律は$`\mathbb{Z}_p`$の掛け算として成り立つ。
- $`m`$が合成数のとき: $`m = st`$、$`1 < s, t < m`$と書ける。$`s \times t = m \equiv 0`$なので、0 でない 2 つの積が集合の外に出て閉性が破れる。また$`\gcd(s, m) = s \neq 1`$なので、01 章 5 節より$`s`$は逆元を持たない。$`m = 12`$なら$`3 \times 4 \equiv 0`$で、2 は逆元を持たない。

**記法**: $`\mathbb{Z}_m`$の要素のうち掛け算の逆元を持つもの、すなわち$`m`$と互いに素な要素だけを集めた集合を$`\mathbb{Z}_m^\ast`$と書く。
たとえば$`\mathbb{Z}_{12}^\ast = \{1, 5, 7, 11\}`$、$`\mathbb{Z}_5^\ast = \{1, 2, 3, 4\}`$である。$`m`$が素数$`p`$なら 0 以外の全部なので$`\mathbb{Z}_p^\ast = \{1, 2, \dots, p-1\}`$で、要素数は$`p-1`$である。
定義の小節の演算表の左は$`\mathbb{Z}_5^\ast`$の演算表である。以後の章でもこの記法を使う。

**$`\mathbb{Z}_m^\ast`$は、$`m`$が素数でなくても、掛け算について常に群である。**

**方針**: 4 条件を順に確かめる。閉性には、前の小節の「積の逆元は逆元を逆の順に掛けたもの」を使う。

**導出**: $`a, b \in \mathbb{Z}_m^\ast`$とする。
閉性: $`ab`$に$`b^{-1}a^{-1}`$を掛けると$`a(bb^{-1})a^{-1} = aa^{-1} = 1`$になるので、$`ab`$は逆元を持ち、$`\mathbb{Z}_m^\ast`$に入る。
結合律: $`\mathbb{Z}_m`$の掛け算として成り立つ。
単位元: $`1 \cdot 1 = 1`$なので$`1`$は逆元を持ち、$`\mathbb{Z}_m^\ast`$に入る。
逆元: $`a^{-1}`$の逆元は$`a`$なので、$`a^{-1}`$も逆元を持ち、$`\mathbb{Z}_m^\ast`$に入る ∎

> **例 4 が本シリーズの分岐点である.** 素数を法にするか、合成数を法にするかで世界の性質が変わる。
> 素数なら割り算まで自由にできる豊かな世界、すなわち 3 節で定義する体になり、これが誤り訂正符号と暗号の舞台になる。

ここまでの例をまとめる。

| 集合と演算 | 閉性 | 結合律 | 単位元 | 逆元 | 群か |
|---|---|---|---|---|---|
| $`(\mathbb{Z}, +)`$ | ✓ | ✓ | ✓ $`0`$ | ✓ $`-a`$ | 群 |
| $`(\mathbb{Z}, \times)`$ | ✓ | ✓ | ✓ $`1`$ | ✗ 2 など | 群でない |
| $`\mathbb{Z}_m`$と足し算 | ✓ | ✓ | ✓ $`0`$ | ✓ $`m - a`$ | 群 |
| $`\mathbb{Z}_7`$から 0 を除いた集合と掛け算 | ✓ | ✓ | ✓ $`1`$ | ✓ | 群 |
| $`\mathbb{Z}_{12}`$から 0 を除いた集合と掛け算 | ✗ $`3 \times 4 \equiv 0`$ | ✓ | ✓ $`1`$ | ✗ 2 など | 群でない |
| $`\mathbb{Z}_{12}^\ast`$と掛け算 | ✓ | ✓ | ✓ $`1`$ | ✓ | 群 |

下の図で集合と演算の組と法を変えると、演算表と 4 条件の判定が表示される。図では法を$`n`$と書く。条件が破れるときは、破れる例を 1 つ示す。「$`\mathbb{Z}_n`$と引き算」を選ぶと、$`n \ge 3`$では結合律と単位元が破れることも確かめられる。

### 部分群 — 群の中にある小さな群

群$`G`$の部分集合$`H`$が、$`G`$と同じ演算でそれ自身も群になっているとき、$`H`$を$`G`$の**部分群**という。
群の定義は 4 条件だが、条件 2 の結合律は$`G`$の演算がもともと満たしているので、$`G`$の要素だけを使う$`H`$では自動的に成り立つ。
したがって部分群かどうかは次の 3 つを確かめればよい。

| # | 条件 | 確かめること |
|---|---|---|
| 1 | 閉じている | $`h_1, h_2 \in H \Rightarrow h_1 \ast h_2 \in H`$ |
| 2 | 単位元を含む | $`G`$の単位元$`e`$が$`H`$に入っている |
| 3 | 逆元を含む | $`h \in H \Rightarrow h^{-1} \in H`$ |

**例: 足し算の群$`\mathbb{Z}_8 = \{0,1,\dots,7\}`$、単位元は$`0`$**。

- $`H = \{0, 4\}`$は部分群である。$`0+0=0`$、$`0+4=4`$、$`4+4=8\equiv0`$でどれも$`H`$の中にあり、閉じている。単位元$`0`$を含む。$`0`$の逆元は$`0`$、$`4`$の逆元は$`4`$で、どちらも$`H`$の中にある。
- $`H = \{0, 1\}`$は部分群でない。$`1+1 = 2`$が$`H`$に入っておらず、閉じていない。
- $`H = \{0, 1, 2\}`$も部分群でない。$`1+2=3`$が$`H`$に入っていない。$`3`$を足して$`\{0,1,2,3\}`$にしても$`2+3=5`$が入っておらず、閉じるまで要素を足していくと$`\mathbb{Z}_8`$全体になる。

$`\mathbb{Z}_8`$の部分群は$`\{0\}`$、$`\{0,4\}`$、$`\{0,2,4,6\}`$、$`\mathbb{Z}_8`$自身の 4 つしかない。要素数はそれぞれ$`1, 2, 4, 8`$で、どれも$`8`$の約数である。
これが偶然でないことを、この節の後半のラグランジュの定理で示す。

**例: 掛け算の群$`\mathbb{Z}_5^\ast = \{1,2,3,4\}`$、単位元は$`1`$**。$`H = \{1, 4\}`$は部分群である。$`4\cdot4 = 16\equiv1`$なので閉じており、$`1`$を含み、$`4`$の逆元は$`4`$自身である。

### 群の位数と巡回群

群$`G`$の要素の個数を**群の位数**といい$`|G|`$と書く。$`|\mathbb{Z}_8| = 8`$、$`|\mathbb{Z}_5^\ast| = 4`$である。

要素$`g`$を$`k`$個並べて演算したものを$`g^k`$と書く。演算が掛け算なら本当のべき乗であり、
演算が足し算なら$`g + g + \cdots + g = k \cdot g`$のことである。以下この章では、演算の種類によらずこの略記を使う。

$`g, g^2, g^3, \dots`$を作っていって$`G`$の全要素が現れるなら、$`g`$を**生成元**、$`G`$を**巡回群**という。

**例**: $`\mathbb{Z}_5^\ast`$で$`g = 2`$とすると

$$
2^1 = 2,\quad 2^2 = 4,\quad 2^3 = 8 \equiv 3,\quad 2^4 = 16 \equiv 1
$$

$`\{2,4,3,1\}`$と全要素が出た。よって$`2`$は生成元で、$`\mathbb{Z}_5^\ast`$は巡回群である。
一方$`g = 4`$とすると$`4^1 = 4`$、$`4^2 = 16 \equiv 1`$、$`4^3 \equiv 4`$、…と 4 と 1 しか出ないので、4 は生成元でない。

### 要素の位数 — 単位元になるまでに要素を何個並べるか

群全体の位数とは別に、1 つの要素についても位数を定義する。

**定義**: 要素$`a`$を$`d`$個並べて演算した結果
$$
\underbrace{a \ast a \ast \cdots \ast a}_{a\ \text{が}\ d\ \text{個}} = a^d
$$
が初めて単位元$`e`$になる最小の正整数$`d`$を**$`a`$の位数**という。演算が掛け算なら$`a^d = 1`$、
足し算なら$`d \cdot a = 0`$となる最小の$`d`$である。

$`d = 1`$は$`a`$を 1 個だけ置いた状態なので、位数$`1`$の要素は$`e`$自身だけである。

**計算手順**: $`a`$を 1 個、2 個、3 個、…と増やしながら値を書き、初めて$`e`$になったところの個数を読む。

**例 A: 掛け算の群$`\mathbb{Z}_5^\ast`$、単位元は$`1`$**

| $`a`$ | 1 個 | 2 個 | 3 個 | 4 個 | 初めて 1 になる個数 = 位数 |
|---|---|---|---|---|---|
| $`1`$ | $`1`$ | | | | $`1`$ |
| $`2`$ | $`2`$ | $`2\cdot2=4`$ | $`4\cdot2=8\equiv3`$ | $`3\cdot2=6\equiv1`$ | $`4`$ |
| $`3`$ | $`3`$ | $`3\cdot3=9\equiv4`$ | $`4\cdot3=12\equiv2`$ | $`2\cdot3=6\equiv1`$ | $`4`$ |
| $`4`$ | $`4`$ | $`4\cdot4=16\equiv1`$ | | | $`2`$ |

**例 B: 足し算の群$`\mathbb{Z}_8`$、単位元は$`0`$**。各マスは$`a`$をその個数だけ足した合計で、8 以上なら 8 で割った余りを$`\equiv`$の右に書く。

| a | 1 個 | 2 個 | 3 個 | 4 個 | 5 個 | 6 個 | 7 個 | 8 個 | 初めて 0 になる個数 = 位数 |
|---|---|---|---|---|---|---|---|---|---|
| 0 | 0 |  |  |  |  |  |  |  | 1 |
| 1 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 ≡ 0 | 8 |
| 2 | 2 | 4 | 6 | 8 ≡ 0 |  |  |  |  | 4 |
| 3 | 3 | 6 | 9 ≡ 1 | 12 ≡ 4 | 15 ≡ 7 | 18 ≡ 2 | 21 ≡ 5 | 24 ≡ 0 | 8 |
| 4 | 4 | 8 ≡ 0 |  |  |  |  |  |  | 2 |
| 5 | 5 | 10 ≡ 2 | 15 ≡ 7 | 20 ≡ 4 | 25 ≡ 1 | 30 ≡ 6 | 35 ≡ 3 | 40 ≡ 0 | 8 |
| 6 | 6 | 12 ≡ 4 | 18 ≡ 2 | 24 ≡ 0 |  |  |  |  | 4 |
| 7 | 7 | 14 ≡ 6 | 21 ≡ 5 | 28 ≡ 4 | 35 ≡ 3 | 42 ≡ 2 | 49 ≡ 1 | 56 ≡ 0 | 8 |

**位数$`d`$の要素$`a`$について、$`a, a^2, \dots, a^d`$の$`d`$個は互いに異なる。**
理由は次のとおり。もし$`i < j \le d`$で$`a^i = a^j`$だったとする。$`a^j = a^i \ast a^{j-i}`$なので、$`a^i = a^i \ast a^{j-i}`$の両辺に左から$`a^i`$の逆元を演算すると$`e = a^{j-i}`$となる。
ところが$`1 \le j-i < d`$なので、$`d`$が$`e`$になる最小の個数であることに反する。

**要素の位数が群の位数$`|G|`$に等しい要素が生成元である。** $`d = |G|`$なら、上の$`|G|`$個の異なる要素が群の全要素だからである。
例 B では$`1, 3, 5, 7`$が位数$`8`$で生成元であり、位数$`4`$の$`2`$は$`\{2,4,6,0\}`$しか作れない。

> **これが後で効く場面.** 生成元のべき乗で全要素を作れるという性質は、次の 2 か所でそのまま使われる。
> - **離散対数問題**（[17 章](17_DHと楕円曲線暗号.md)）: $`g^x = y`$から$`x`$を求めるのが難しい、という暗号の土台
> - **LFSR の最長周期**（[13 章](13_ストリーム暗号とLFSR.md)）: 生成元を使うと周期が最大になる

### 要素が生成する部分群

位数$`d`$の要素$`a`$のべき乗をすべて集めた集合を

$$
\langle a \rangle = \{a, a^2, \dots, a^d\} \qquad (a^d = e)
$$

と書き、$`a`$が生成する部分群と呼ぶ。上で見たとおり要素数は$`d`$である。

**方針**: この集合が部分群だと分かれば、次のラグランジュの定理を当てはめて「要素の位数$`d`$は群の位数$`|G|`$を割り切る」が言える。それがこの節の最後の帰結につながる。
そのために、部分群の 3 条件を 1 つずつ確かめる。

1. 閉じている。$`\langle a \rangle`$の 2 要素$`a^i, a^j`$を演算すると$`a^i \ast a^j = a^{i+j}`$である。$`i+j \le d`$ならこれは集合の中にある。
   $`i+j > d`$なら$`a^{i+j} = a^d \ast a^{i+j-d} = e \ast a^{i+j-d} = a^{i+j-d}`$で、$`1 \le i+j-d \le d`$なのでやはり集合の中にある。
2. 単位元を含む。$`e = a^d`$が集合の中にある。
3. 逆元を含む。$`a^i \ast a^{d-i} = a^d = e`$なので$`a^i`$の逆元は$`a^{d-i}`$であり、これも集合の中にある。$`i = d`$のときは$`e`$の逆元が$`e`$自身である。

**例**: $`\mathbb{Z}_5^\ast`$の$`4`$は位数$`2`$で$`\langle 4 \rangle = \{4, 1\}`$である。これは部分群の例で確かめた$`\{1,4\}`$そのものである。
$`\mathbb{Z}_8`$の$`2`$は位数$`4`$で$`\langle 2 \rangle = \{2,4,6,0\}`$である。$`2+6 = 8\equiv 0`$、$`4+6=10\equiv2`$のように閉じており、$`0`$を含み、$`2`$と$`6`$、$`4`$と$`4`$が互いに逆元である。

### ラグランジュの定理

**ラグランジュの定理**: 有限群$`G`$の部分群$`H`$の位数$`|H|`$は、$`|G|`$を割り切る。

つまり部分群の要素数は$`|G|`$の約数にしかなれない。$`\mathbb{Z}_8`$に要素数$`3`$や$`5`$の部分群が存在せず、
要素数$`1,2,4,8`$の 4 つしかなかったのはこのためである。

**導出の方針**: $`G`$全体を「$`H`$と同じ大きさの塊」に重なりなく切り分けられることを示す。塊の個数を$`k`$とすれば$`|G| = k \times |H|`$となり、$`|H|`$が$`|G|`$を割り切る。
以下 4 段階で示す。例として$`G = \mathbb{Z}_8`$、$`H = \{0,4\}`$を並走させる。

**段階 1: 塊の作り方**。$`G`$の要素$`g`$を 1 つ選び、$`H`$の各要素に$`g`$を演算したものを集めた集合を$`gH = \{g \ast h \mid h \in H\}`$と書く。$`H`$を$`g`$だけずらしたコピーである。
例では演算が足し算なので$`gH = \{g + h \mid h \in H\}`$であり、これを$`g + H`$とも書く。
$`0 + H = \{0, 4\}`$、$`1 + H = \{1, 5\}`$、$`2 + H = \{2, 6\}`$、$`3 + H = \{3, 7\}`$、$`4 + H = \{4, 8 \equiv 0\} = \{0,4\}`$、$`5 + H = \{5, 9 \equiv 1\} = \{1,5\}`$、…となる。

**段階 2: どの塊も要素数はちょうど$`|H|`$**。$`H`$の異なる 2 つの要素$`h_1 \ne h_2`$は、$`g`$を演算した後も異なる。
背理法で示す。仮に$`g \ast h_1 = g \ast h_2`$だったとすると、両辺の左から$`g^{-1}`$を演算して$`h_1 = h_2`$となり、$`h_1 \ne h_2`$と矛盾する。
よって$`H`$の$`|H|`$個の要素は$`gH`$の$`|H|`$個の互いに異なる要素に写り、$`gH`$の要素数は$`|H|`$である。例ではどの塊も 2 個である。

**段階 3: 2 つの塊は「完全に同じ」か「共通要素なし」のどちらか**。一部だけ重なることは起きない。
2 つの塊$`gH`$と$`g'H`$に共通の要素$`x`$が 1 個でもあったとする。$`x`$は$`gH`$の要素なので$`H`$のある要素$`h_1`$を使って$`x = g \ast h_1`$と書け、
同時に$`g'H`$の要素でもあるので$`H`$のある要素$`h_2`$を使って$`x = g' \ast h_2`$とも書ける。同じ$`x`$を 2 通りに書いただけなので
$$
g \ast h_1 = g' \ast h_2
$$
両辺の右から$`h_1^{-1}`$を演算すると$`g = g' \ast h_2 \ast h_1^{-1}`$である。これを$`gH`$の任意の要素$`g \ast h`$に代入すると
$$
g \ast h = g' \ast (h_2 \ast h_1^{-1} \ast h)
$$
括弧の中は$`H`$の要素どうしの演算である。$`H`$は閉じていて逆元を含むので、括弧の中は$`H`$の要素である。よって$`g \ast h`$は$`g'H`$の要素であり、$`gH`$のすべての要素は$`g'H`$に含まれる。
$`g`$と$`g'`$の役割を入れ替えれば$`g'H`$のすべての要素も$`gH`$に含まれる。したがって$`gH = g'H`$である。
例では$`4 + H = \{0,4\}`$と$`0 + H = \{0,4\}`$は共通要素$`0`$を持ち、実際に完全に一致している。$`0 + H`$と$`1 + H`$は共通要素がない。

**段階 4: すべての要素がどれかの塊に入る**。$`e \in H`$なので$`g = g \ast e \in gH`$である。つまり$`g`$は自分の塊$`gH`$に入っている。

段階 3 と 4 から、$`G`$は互いに共通要素を持たない塊たちに完全に切り分けられる。同じ塊は 1 つと数える。段階 2 からどの塊も大きさは$`|H|`$である。塊の個数を$`k`$とすると$`|G| = k|H|`$ ∎
例では$`\mathbb{Z}_8`$が$`\{0,4\}, \{1,5\}, \{2,6\}, \{3,7\}`$の 4 塊に切り分けられ、$`8 = 4 \times 2`$である。

**$`H`$が部分群でないと段階 3 が壊れる。** 段階 3 で「括弧の中が$`H`$の要素」と言えたのは$`H`$が閉じているからである。
部分群でない$`H = \{0,1\}`$で同じ塊を作ると$`0 + H = \{0,1\}`$、$`1 + H = \{1,2\}`$となり、共通要素$`1`$を持つのに一致しない。
塊が中途半端に重なるので「同じ大きさの塊で重なりなく切り分ける」ことができず、$`|G| = k|H|`$は成り立たない。定理が部分群にしか適用できないのはこのためである。2 つの場合を並べると次のようになる。

### 帰結 — どの要素も |G| 個並べると単位元に戻る（後で使う重要事実）

本シリーズで実際に使うのは、ラグランジュの定理から出る次の帰結である。

**帰結**: 有限群$`G`$の任意の要素$`a`$について、$`a^{|G|} = e`$。

**方針**: $`a`$の位数$`d`$が$`|G|`$を割り切ることをラグランジュの定理から引き出し、$`|G| = dk`$と書く。すると$`a^{|G|}`$は$`a^d = e`$を$`k`$回演算したものになり、$`e`$になる。

**導出**: $`a`$の位数を$`d`$とする。$`\langle a \rangle = \{a, \dots, a^d\}`$は要素数$`d`$の部分群であった。
ラグランジュの定理より$`d`$は$`|G|`$を割り切るので、整数$`k`$があって$`|G| = dk`$である。
$`a`$を$`dk`$個並べて演算するのは、「$`a`$を$`d`$個」のまとまりを$`k`$回繰り返すことなので

$$
a^{|G|} = a^{dk} = \underbrace{a^d \ast a^d \ast \cdots \ast a^d}_{k\ \text{個}} = \underbrace{e \ast e \ast \cdots \ast e}_{k\ \text{個}} = e \qquad \blacksquare
$$

```fig
e02_period
```

**例: 掛け算**。$`\mathbb{Z}_5^\ast`$は$`|G|=4`$である。$`a = 4`$は位数$`d = 2`$で、$`4 = 2 \times 2`$、$`4^4 = 4^2 \cdot 4^2 = 1 \cdot 1 = 1`$となる。
$`a = 2`$は位数$`d = 4 = |G|`$で、$`k = 1`$、$`2^4 \equiv 1`$は例 A の表のとおりである。

**例: 足し算**。$`\mathbb{Z}_8`$は$`|G|=8`$である。$`a = 2`$は位数$`d = 4`$で、$`8 = 4 \times 2`$。帰結は「$`2`$を 8 個足すと$`0`$」で、実際$`8 \cdot 2 = 16 \equiv 0`$である。

> **これがフェルマーの小定理の正体である.** $`p`$を素数とすると、$`G = \mathbb{Z}_p^\ast`$は位数$`p-1`$の群なので、帰結をそのまま当てはめると、$`p`$で割り切れない整数$`a`$について
>
> $$a^{p-1} \equiv 1 \pmod p$$
>
> が出る。[15 章](15_数論の道具.md)でオイラーの定理に広げ、[16 章](16_RSA.md)の RSA の心臓部になるが、その本質はこの群論の一般定理であり、数論の特別な魔法ではない。

## 2. 環 (Ring)

### 定義

集合$`R`$に足し算$`+`$と掛け算$`\times`$の 2 つの演算があり、次の 3 つを満たすとき**環**という。

1. $`(R, +)`$が可換群である。単位元を$`0`$、$`a`$の逆元を$`-a`$と書く
2. 掛け算が閉性と結合律を満たし、単位元$`1`$を持つ
3. 分配律$`a(b+c) = ab + ac`$、$`(a+b)c = ac + bc`$が成り立つ

さらに掛け算が交換律$`ab = ba`$を満たすとき**可換環**という。

条件 1 により引き算はいつでもできるが、掛け算の逆元は要求していないので、割り算ができない要素があってもよい。

### 例

- 整数全体$`\mathbb{Z}`$: 可換環。2 による割り算はできない
- $`\mathbb{Z}_m`$: どの$`m`$でも可換環。足し算は 1 節の例 3 のとおり可換群で、掛け算の結合律・交換律と分配律は 1 節の定義の小節で見たとおり整数から引き継ぐ
- 係数が整数の多項式全体$`\mathbb{Z}[x]`$: 可換環。係数を 0 と 1 に限り$`1 + 1 = 0`$として計算する多項式全体も可換環で、[04 章](04_多項式と既約多項式.md)の主役になる
- $`n \times n`$行列全体、ただし$`n \ge 2`$: 環だが可換でない。たとえば$`A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}`$、$`B = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}`$なら$`AB = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}`$、$`BA = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}`$で、$`AB \neq BA`$である

環では割り算ができない要素があってもよいことを、$`\mathbb{Z}_4`$の演算表で確かめる。

```fig

```

足し算の表は各行に 0 がちょうど 1 回あり、どの要素も足し算の逆元を持つ。掛け算の表では 2 の行に 1 が無く、2 には掛け算の逆元が無い。さらに$`2 \times 2 = 4 \equiv 0`$で、0 でない 2 つの要素の積が 0 になっている。

### 零因子 — 環で起きる厄介ごと

$`a \neq 0`$、$`b \neq 0`$なのに$`ab = 0`$となる$`a, b`$を**零因子**という。
$`\mathbb{Z}_4`$の 2 は零因子である。$`\mathbb{Z}_{12}`$では$`3 \times 4 = 12 \equiv 0`$なので、3 と 4 が零因子である。

普通の数では「$`ab = 0`$なら$`a=0`$または$`b=0`$」が成り立つが、零因子があるとこれが崩れる。その結果、次の 2 つの当たり前の式変形が使えなくなる。

- **両辺を同じ数で割る**: $`ax = ay`$から$`x = y`$とできない。[01 章 2 節](01_合同算術とユークリッドの互除法.md#合同式の演算-足し算-引き算-掛け算は-そのまま-できる)の失敗例$`2 \times 3 \equiv 2 \times 9 \pmod{12}`$は、差を取ると$`2 \times 9 - 2 \times 3 = 2 \times (9 - 3) = 2 \times 6 = 12 \equiv 0`$で、零因子の組 2 と 6 が原因である。
- **積が 0 なら因子のどちらかが 0**: $`x^2 = 1`$を$`(x - 1)(x + 1) = 0`$と変形しても、$`x - 1 = 0`$または$`x + 1 = 0`$とは結論できない。$`\mathbb{Z}_8`$では$`x = 1, 3, 5, 7`$の 4 つが$`x^2 \equiv 1`$を満たす。$`x = 3`$なら$`(x - 1)(x + 1) = 2 \times 4 = 8 \equiv 0`$で、2 と 4 が零因子である。

このため、普通の数と同じ手順では方程式を解けない。3 節の体は、零因子が無い世界である。

### $`\mathbb{Z}_m`$では、逆元を持たない要素は零因子である

$`\mathbb{Z}_{12}`$の 0 以外の要素を、01 章の存在条件$`\gcd(a, 12) = 1`$で 2 つに分けると、次のようになる。

```fig

```

逆元を持たない要素は、どれも零因子になっている。一般に次が成り立つ。

**定理**: $`m \ge 2`$とする。$`\mathbb{Z}_m`$の 0 以外の要素は、「逆元を持つ」か「零因子である」かのどちらか一方である。

**方針**: $`d = \gcd(a, m)`$が 1 のときと 1 より大きいときに分ける。$`d = 1`$なら逆元を持ち、零因子でないことを示す。$`d > 1`$なら、掛けると 0 になる相手を作る。

**導出**: $`a`$を$`\mathbb{Z}_m`$の 0 以外の要素とし、$`d = \gcd(a, m)`$とおく。

（$`d = 1`$の場合）01 章 5 節より$`a`$は逆元$`a^{-1}`$を持つ。$`ab \equiv 0`$とすると、両辺に$`a^{-1}`$を掛けて$`b \equiv 0`$となる。よって$`a`$に掛けて 0 になる 0 以外の要素は無く、$`a`$は零因子でない。

（$`d > 1`$の場合）01 章 5 節より$`a`$は逆元を持たない。$`b = m/d`$とおくと、$`d \ge 2`$より$`1 \le b < m`$なので$`b`$は 0 以外の要素であり、

$$
ab = a \cdot \frac{m}{d} = \frac{a}{d} \cdot m \equiv 0 \pmod m
$$

である。$`a/d`$は整数なので、右辺は$`m`$の倍数である。よって$`a`$は零因子である ∎

下の図で法$`m`$を変えると、0 以外の各要素について、$`m`$との最大公約数と、逆元または掛けて 0 になる相手が表示される。

## 3. 体 (Field)

### 定義

可換環$`F`$で、$`0 \neq 1`$であり、**0 以外のすべての要素が掛け算の逆元を持つ**ものを**体**という。要素が有限個の体を**有限体**という。

$`0 \neq 1`$を条件に入れるのは、要素が$`0`$だけの集合$`\{0\}`$を除くためである。$`\{0\}`$で$`0 + 0 = 0`$、$`0 \times 0 = 0`$と定めると環の条件をすべて満たし、$`1 = 0`$となる。0 以外の要素が無いので、逆元の条件も形の上では満たしてしまう。

言い換えれば、体は四則演算が自由にできる世界である。
演算そのものは環と同じく$`+`$と$`\times`$の 2 つであり、$`-`$と$`\div`$は 1 節で述べたとおり逆元との演算の略記である。
その 2 つが 0 での割り算を除いてどちらも打ち消せるので、$`+ - \times \div`$がいつでも実行でき、結果が必ず$`F`$の中に留まる。

### 体には零因子が無い

**定理**: 体$`F`$で$`ab = 0`$なら、$`a = 0`$または$`b = 0`$である。

**方針**: $`a \ne 0`$の場合に$`b = 0`$を示す。$`a`$は逆元を持つので、$`ab = 0`$の両辺に$`a^{-1}`$を掛ける。その前に、どの要素に 0 を掛けても 0 になることを確かめておく。

**導出**: まず$`F`$の任意の要素$`x`$について$`x \cdot 0 = 0`$である。$`0 = 0 + 0`$なので、分配律より$`x \cdot 0 = x \cdot (0 + 0) = x \cdot 0 + x \cdot 0`$となり、両辺に$`x \cdot 0`$の足し算の逆元を足すと$`0 = x \cdot 0`$が得られる。
次に$`ab = 0`$、$`a \neq 0`$とする。両辺に左から$`a^{-1}`$を掛けると

$$
b = 1 \cdot b = (a^{-1} a) b = a^{-1}(ab) = a^{-1} \cdot 0 = 0
$$

である ∎

この定理から、体では「$`ax = ay`$かつ$`a \neq 0`$なら$`x = y`$」が成り立つ。$`a(x - y) = 0`$で$`a \neq 0`$なので$`x - y = 0`$だからである。2 節で使えなくなった 2 つの式変形が、体ではどちらも使える。

さらに、**体$`F`$の 0 以外の要素全体は、掛け算について可換群をなす**。
閉性は、0 以外の 2 つの積が定理より 0 でないことによる。結合律と交換律は可換環の条件から成り立つ。単位元$`1`$は、$`0 \neq 1`$なので 0 以外の要素である。
$`a \neq 0`$の逆元$`a^{-1}`$も 0 でない。もし$`a^{-1} = 0`$なら$`1 = a a^{-1} = a \cdot 0 = 0`$となり、$`0 \neq 1`$に矛盾するからである。
$`F = \mathbb{Z}_p`$なら、この群が 1 節の$`\mathbb{Z}_p^\ast`$である。

### 例

| 集合 | 体か | 理由 |
|---|---|---|
| 有理数$`\mathbb{Q}`$、実数$`\mathbb{R}`$、複素数$`\mathbb{C}`$ | ✓ | おなじみの体。要素は無限個 |
| 整数$`\mathbb{Z}`$ | ✗ | 2 に掛け算の逆元が無い |
| $`\mathbb{Z}_p`$、$`p`$は素数 | ✓ | 有限体。[03 章](03_有限体GFp.md)の主役 |
| $`\mathbb{Z}_m`$、$`m`$は合成数 | ✗ | 零因子があり、逆元を持たない要素がある |

### 定理: $`\mathbb{Z}_m`$が体 $`\iff`$ $`m`$が素数

$`m \ge 2`$とする。

**方針**: $`\mathbb{Z}_m`$はどの$`m`$でも可換環で、$`m \ge 2`$なら$`0 \neq 1`$である。したがって体であるための条件は「0 以外のすべての要素が掛け算の逆元を持つ」ことだけである。
逆元を持つ条件は 01 章で$`\gcd(a, m) = 1`$と分かっているので、「$`1 \le a \le m-1`$のすべてで$`\gcd(a,m)=1`$」と「$`m`$が素数」が同じことを示せばよい。両方向を別々に示す。

**導出**:

（$`\Leftarrow`$）$`m = p`$が素数とする。$`1 \le a \le p-1`$について、$`\gcd(a, p)`$は$`p`$の約数なので 1 か$`p`$であり、$`0 < a < p`$なので$`p`$は$`a`$を割り切らない。よって$`\gcd(a,p) = 1`$であり、[01 章 5 節](01_合同算術とユークリッドの互除法.md#逆元が存在する条件)の定理より$`a`$は逆元を持つ。

（$`\Rightarrow`$）対偶「$`m`$が合成数なら体でない」を示す。$`m`$が合成数なら$`m = st`$、$`1<s,t<m`$と書ける。
このとき$`s`$は$`m`$を割り切るので$`\gcd(s,m) = s \neq 1`$であり、$`s`$は逆元を持たない。よって$`\mathbb{Z}_m`$は体でない ∎

法を 2 から 13 まで変えて、0 以外のどの要素が逆元を持つかを並べると、定理のとおりになっている。

```fig
e02_primestrip
```

> **ここまでで分かったこと.**
> 素数個の要素を持つ世界$`\mathbb{Z}_p`$は、有限なのに四則演算が完全にできる。
> 有限個しか数が無いのに、割り算が破綻しない。
>
> この「有限で、四則演算が完備」という性質こそが、
> 誤り訂正で連立方程式を解いて誤り位置を特定できる理由（[11 章](11_リードソロモン符号.md)）であり、
> 暗号で逆算が定義できる理由（[16 章](16_RSA.md)）である。

### 標数 (characteristic)

体$`F`$で、1 を$`n`$個足した和$`\underbrace{1 + 1 + \cdots + 1}_{n\ \text{個}}`$が$`0`$になる最小の正整数$`n`$を、$`F`$の**標数**という。そのような$`n`$が無ければ標数は 0 とする。以下、1 を$`n`$個足した和を$`n \cdot 1`$と書く。

- $`\mathbb{Q}, \mathbb{R}, \mathbb{C}`$: 標数 0。1 を何個足しても 0 にならない
- $`\mathbb{Z}_p`$: 標数$`p`$。$`p \cdot 1 = p \equiv 0`$で、$`1 \le n < p`$では$`n \cdot 1 = n \neq 0`$である

```fig
e02_char
```

**定理**: 有限体の標数は素数である。

**方針**: 3 段階で示す。段階 1 で、有限体では$`n \cdot 1 = 0`$となる正整数$`n`$が必ずあることを示す。段階 2 で、標数が 1 でないことを示す。段階 3 は背理法で、標数$`n`$が合成数$`ab`$だと仮定し、$`a \cdot 1`$と$`b \cdot 1`$の積が 0 になることを導く。体には零因子が無いのでどちらかが 0 になるが、$`a, b`$は$`n`$より小さいので標数の最小性に反する。

**導出**:

**段階 1**: $`1 \cdot 1, 2 \cdot 1, 3 \cdot 1, \dots`$はすべて$`F`$の要素だが、$`F`$は有限なので、どこかで同じ値が 2 回現れる。$`i < j`$で$`i \cdot 1 = j \cdot 1`$とすると、両辺から$`i \cdot 1`$を引いて$`(j - i) \cdot 1 = 0`$となる。よって$`n \cdot 1 = 0`$となる正整数$`n`$があり、標数はその最小値として正の整数に決まる。

**段階 2**: $`1 \cdot 1 = 1`$で、体の定義より$`1 \neq 0`$なので、標数は 1 ではない。

**段階 3**: 標数$`n`$が合成数$`n = ab`$、$`1<a,b<n`$だとする。分配律で展開すると、$`1 \times 1 = 1`$が$`ab`$個現れるので

$$
(a \cdot 1)(b \cdot 1) = \underbrace{(1 + \cdots + 1)}_{a\ \text{個}}\,\underbrace{(1 + \cdots + 1)}_{b\ \text{個}} = (ab) \cdot 1 = n \cdot 1 = 0
$$

である。体には零因子が無いので$`a \cdot 1 = 0`$または$`b \cdot 1 = 0`$だが、$`a, b < n`$なので、標数が$`n \cdot 1 = 0`$となる最小の正整数であることに矛盾する。

以上より、標数は 2 以上の整数で、合成数でもないので素数である ∎

> **標数 2 の世界が本シリーズの主戦場である.**
> 標数 2 の体では$`1 + 1 = 0`$である。すると任意の要素$`a`$について$`a + a = (1 + 1)a = 0 \cdot a = 0`$なので$`-a = a`$、すなわち$`a`$の足し算の逆元は$`a`$自身である。
> したがって$`b`$を引くことは$`-b = b`$を足すことに等しく、**足し算と引き算が同じ**になる。最小の例が次節の$`\mathrm{GF}(2)`$である。
> CRC（[09 章](09_巡回符号とCRC.md)）も AES（[14 章](14_ブロック暗号とAES.md)）も、この性質の上に成り立っている。

## 4. GF(2) — 最小の体を作ってみる

$`p = 2`$として$`\mathbb{Z}_2 = \{0, 1\}`$を作る。これを$`\mathrm{GF}(2)`$と書く。GF は Galois Field の頭文字で、ガロア体は有限体の別名である。
一般に素数$`p`$について$`\mathbb{Z}_p`$を$`\mathrm{GF}(p)`$と書き、括弧の中は要素数を表す。$`\mathrm{GF}(p)`$は[03 章](03_有限体GFp.md)で詳しく扱う。

$`2`$は素数なので、3 節の定理より$`\mathrm{GF}(2)`$は体である。0 以外の要素は 1 だけで、$`1 \times 1 = 1`$より$`1^{-1} = 1`$である。$`1 + 1 = 2 \equiv 0`$なので標数は 2 である。

$`\mathrm{GF}(2)`$の足し算と掛け算は、ビットの論理演算と同じ表になる。

- 足し算は **XOR**（排他的論理和）と同じである。XOR は 2 つのビットが異なるとき 1、同じとき 0 を返す演算で、記号$`\oplus`$で表す。
- 掛け算は **AND**（論理積）と同じである。AND は両方が 1 のときだけ 1 を返す。

```fig
e02_gf2
```

XOR と AND は CPU が 1 命令で実行する最も基本的な演算である。CPU は 1 命令で 8 ビットや 64 ビットをまとめて処理するので、$`\mathrm{GF}(2)`$の足し算を桁数の分だけ同時に行える。
ハードウェアで CRC（[09 章](09_巡回符号とCRC.md)）やパリティ検査（[07 章](07_線形符号.md)）が高速に動くのは、この一致のおかげである。

さらに標数 2 なので$`-1 = 1`$であり、$`a - b = a + b = a \oplus b`$である。符号理論の式で引き算の記号がほとんど出てこないのはこのためである。

## 5. まとめ — 3 つの言葉の関係

```fig
e02_hierarchy
```

内側の囲みほど条件が多く、できることが増える。体は可換環でもあり、可換環は環でもある。また、環の足し算だけを見ると可換群であり、体の 0 以外の要素を掛け算だけで見ても可換群である。

| 構造 | 演算の数 | 逆元が必ずある演算 | 本シリーズでの例 |
|---|---|---|---|
| **群** | 1 つ | その演算 | 楕円曲線上の点（[17 章](17_DHと楕円曲線暗号.md)）、$`\mathbb{Z}_p^\ast`$と掛け算、$`\mathbb{Z}_m`$と足し算 |
| **環** | 2 つ（足し算と掛け算） | 足し算だけ。掛け算の逆元は無い要素があってよい | 多項式（[04 章](04_多項式と既約多項式.md)）、$`\mathbb{Z}_m`$ |
| **体** | 2 つ（足し算と掛け算） | 足し算と、0 以外の要素の掛け算 | $`\mathrm{GF}(p)`$（[03 章](03_有限体GFp.md)）、$`\mathrm{GF}(2^m)`$（[05 章](05_拡大体GF2m.md)） |
