# 02. 群・環・体 — 「計算できる世界」の分類学

> **なぜ抽象代数が出てくるのか.**
> [01 章](01_合同算術とユークリッドの互除法.md#合同とは-時計の算数)で$`\mathbb{Z}_m`$（$`m`$で割った余りだけを考える合同算術の世界）を作った。ところがこの先、似たような世界がいくつも出てくる:
> 多項式の世界、バイト（8 ビットのまとまり）の世界、楕円曲線上の点の世界——
> どれも「要素の集合 + 演算」でできていて、**似た規則で動いている**。
>
> 毎回ゼロから性質を調べ直すのは無駄なので、**共通の骨組みに名前を付けておく**。
> それが**群・環・体**という 3 つの言葉である。
>
> 身構える必要はない。要するに「演算がいくつあって、それぞれ元に戻せるか」で分類しているだけである
> （どの場合も、演算の結果が世界の外に出ないこと、カッコの付け方を気にしなくてよいことは前提とする。正確な条件は各節の定義に書く）:
> - **群**: 演算が **1 つ**（足し算でも掛け算でもよい）。その演算は必ず**元に戻せる**
> - **環**: 演算が **2 つ**（足し算と掛け算）。足し算は必ず元に戻せるが、掛け算は元に戻せる保証がない
> - **体**: 演算が **2 つ**。どちらも必ず元に戻せる（0 で割る以外）
>
> ここで「元に戻せる」とは、**逆元**（打ち消す相手）が必ず存在するという意味である。
> 引き算と割り算は独立の演算ではなく、$`a - b`$は$`a + (-b)`$（足し算の逆元を足す）、$`a \div b`$は$`a \times b^{-1}`$（掛け算の逆元を掛ける）の略記として扱う。
>
> ゴールは**体**である。誤り訂正も暗号も「体の上で計算する」からこそ、
> 連立方程式が解け、多項式が因数分解でき、逆算ができる。

## 1. 群 (Group)

### 定義

集合$`G`$と、その上の 2 項演算$`\ast`$（2 つの要素から 1 つを作る規則）が次の 4 条件を満たすとき、
$`(G, \ast)`$を**群**という。

| # | 名前 | 条件 | 日常語で言うと |
|---|---|---|---|
| 1 | **閉性** | $`a, b \in G \Rightarrow a \ast b \in G`$ | 計算しても世界の外に出ない |
| 2 | **結合律** | $`(a\ast b)\ast c = a \ast (b \ast c)`$ | カッコの付け方を気にしなくてよい |
| 3 | **単位元** | ある$`e`$があって全ての$`a`$で$`a \ast e = e \ast a = a`$ | 「何もしない」要素がある |
| 4 | **逆元** | 各$`a`$に対し$`a \ast a^{-1} = e`$なる$`a^{-1}`$がある | 元に戻す操作が必ずある |

さらに$`a \ast b = b \ast a`$（**交換律**）が成り立つとき**可換群**という（**アーベル群**は同じものの別名）。

単位元と逆元は演算ごとに決まる。足し算なら単位元は$`0`$（$`a + 0 = a`$）で$`a`$の逆元は$`-a`$（$`a + (-a) = 0`$）、
掛け算なら単位元は$`1`$（$`a \times 1 = a`$）で$`a`$の逆元は$`1/a`$（$`a \times 1/a = 1`$）。

### 例で確かめる

**例 1: 整数と足し算$`(\mathbb{Z}, +)`$** — 群である。
閉性 ✓（整数どうしの和は整数）、結合律 ✓、単位元は$`0`$、$`a`$の逆元は$`-a`$ ✓
演算は足し算 1 つだけで、「引き算」は$`-a`$を足すことである（$`5 - 3 = 5 + (-3)`$）。逆元があるから引ける。

**例 2: 整数と掛け算$`(\mathbb{Z}, \times)`$** — 群では**ない**。
単位元$`1`$はあるが、$`2`$の逆元$`1/2`$が整数でない（条件 4 が破れる）。
掛け算 1 つを演算とみなしたとき、それを打ち消す「割り算」が整数の中でできないからである。

**例 3: $`\mathbb{Z}_m`$と足し算** — 群である。
（$`\mathbb{Z}_m`$は[01 章](01_合同算術とユークリッドの互除法.md#直感-時計の文字盤)で定義した法$`m`$の世界$`\{0, 1, \dots, m-1\}`$。$`m`$以上の数は$`m`$で割った余りに置き換える。
具体例として$`m = 5`$なら$`\mathbb{Z}_5 = \{0,1,2,3,4\}`$であり、$`5`$は$`0`$と同じものとして扱う。）
単位元$`0`$、$`a`$の逆元は$`m - a`$（$`a + (m-a) = m \equiv 0`$）✓
たとえば法 12 で$`5`$の逆元は$`7`$（$`5+7=12\equiv 0`$）。時計を 5 時間進めてから 7 時間進めると元に戻る。

**例 4: $`\mathbb{Z}_m`$の 0 以外と掛け算** — **$`m`$が素数のときだけ**群になる。
$`0`$を除くのは、$`0`$には掛け算の逆元（$`0 \times x = 1`$となる$`x`$）が存在しないからである。
[01 章](01_合同算術とユークリッドの互除法.md#定義と存在条件)で見たとおり、逆元が存在するのは$`\gcd(a,m)=1`$のとき。
$`m`$が素数ならすべての$`a \in \{1,\dots,m-1\}`$がこれを満たす ✓
$`m`$が合成数だと、$`m`$と共通因数を持つ要素が逆元を持てない ✗

**記法**: $`\mathbb{Z}_m`$のうち掛け算の逆元を持つ要素（$`m`$と互いに素な要素）だけを集めた集合を$`\mathbb{Z}_m^\ast`$と書く。
これは掛け算について常に群になる。$`m`$が素数$`p`$なら$`0`$以外の全部なので$`\mathbb{Z}_p^\ast = \{1, 2, \dots, p-1\}`$（要素数$`p-1`$）。
たとえば$`\mathbb{Z}_5^\ast = \{1,2,3,4\}`$、$`\mathbb{Z}_{12}^\ast = \{1,5,7,11\}`$。以後の章でもこの記法を使う。

> **例 4 が本シリーズの分岐点である.** 「素数を法にするか、合成数を法にするか」で世界の性質が変わる。
> 素数なら割り算まで自由にできる豊かな世界（＝体）になり、これが誤り訂正符号の舞台になる。

### 位数と巡回群

群$`G`$の要素の個数を**位数**といい$`|G|`$と書く。

要素$`g`$を繰り返し演算して$`g, g^2, g^3, \dots`$と作ったとき、
これで$`G`$の全要素が現れるなら$`g`$を**生成元**、$`G`$を**巡回群**という。
（ここで$`g^k`$は「$`g`$に演算を$`k`$回施したもの」の略記である。演算が掛け算なら本当のべき乗、
演算が足し算なら$`g + g + \cdots + g`$（$`k`$個）のこと。以下この章では、演算の種類によらずこの略記を使う。）

**例**: 集合$`\mathbb{Z}_5^\ast = \{1,2,3,4\}`$（例 4 の記法。$`\mathbb{Z}_5 = \{0,1,2,3,4\}`$から$`0`$を除いたもの）、演算は$`\bmod 5`$の掛け算。
例 4 のとおりこれは群である。$`g = 2`$とすると

$$
2^1 = 2,\quad 2^2 = 4,\quad 2^3 = 8 \equiv 3,\quad 2^4 = 16 \equiv 1
$$

$`\{2,4,3,1\}`$と全要素が出た。よって$`2`$は生成元で、この群は巡回群 ✓

### 要素の位数 — 単位元になるまでに要素を何個並べるか

群全体の位数とは別に、**1 つの要素**についても位数を定義する。

**定義**: 要素$`a`$を$`d`$個並べて演算した結果
$$
\underbrace{a \ast a \ast \cdots \ast a}_{a\ \text{が}\ d\ \text{個}}
$$
が初めて単位元$`e`$になる$`d`$（最小の正整数）を**$`a`$の位数**という。演算が掛け算ならこれは$`a^d = e`$、
足し算なら$`a + a + \cdots + a = d \cdot a = 0`$である。

$`d = 1`$は$`a`$を 1 個だけ置いた状態（演算なし）なので、位数$`1`$の要素は$`e`$自身だけである。

**計算手順**: $`a`$を 1 個、2 個、3 個、…と増やしながら値を書き、初めて$`e`$になったところの個数を読む。

**例 A（掛け算の群$`\mathbb{Z}_5^\ast`$、単位元は$`1`$）**:

| $`a`$ | 1 個 | 2 個 | 3 個 | 4 個 | 初めて 1 になる個数 = 位数 |
|---|---|---|---|---|---|
| $`2`$ | $`2`$ | $`2\cdot2=4`$ | $`4\cdot2=8\equiv3`$ | $`3\cdot2=6\equiv1`$ | $`4`$ |
| $`4`$ | $`4`$ | $`4\cdot4=16\equiv1`$ | | | $`2`$ |
| $`1`$ | $`1`$ | | | | $`1`$ |

**例 B（足し算の群$`\mathbb{Z}_8`$、単位元は$`0`$）**:

| $`a`$ | 1 個 | 2 個 | 3 個 | 4 個 | 5 個 | 6 個 | 7 個 | 8 個 | 初めて 0 になる個数 = 位数 |
|---|---|---|---|---|---|---|---|---|---|
| $`1`$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | $`8\equiv0`$ | $`8`$ |
| $`2`$ | 2 | 4 | 6 | $`8\equiv0`$ | | | | | $`4`$ |
| $`3`$ | 3 | 6 | $`9\equiv1`$ | $`12\equiv4`$ | $`15\equiv7`$ | $`18\equiv2`$ | $`21\equiv5`$ | $`24\equiv0`$ | $`8`$ |
| $`4`$ | 4 | $`8\equiv0`$ | | | | | | | $`2`$ |

（各マスは「$`a`$をその個数だけ足した合計」を書き、8 以上なら 8 で割った余りを$`\equiv`$の右に書いた。）
| $`0`$ | 0 | | | | | | | | $`1`$ |

**要素の位数が群の位数$`|G|`$に等しい要素**が生成元である。理由: 要素の位数が$`d`$なら$`a, a^2, \dots, a^d`$は互いに異なる
（もし$`i < j \le d`$で$`a^i = a^j`$なら、$`a^{j-i} = e`$となり$`j - i < d`$が位数の最小性に反する）。
$`d = |G|`$なら、この$`|G|`$個の異なる要素が群の全要素である。
例 B では$`1`$と$`3`$（要素の位数$`8`$）が生成元で、$`2`$（要素の位数$`4`$）は$`\{2,4,6,0\}`$しか作れない。

> **これが後で効く場面.** 「生成元のべき乗で全要素を作れる」という性質は:
> - **離散対数問題**（[17 章](17_DHと楕円曲線暗号.md)）: $`g^x = y`$から$`x`$を求めるのが難しい、という暗号の土台
> - **LFSR の最長周期**（[13 章](13_ストリーム暗号とLFSR.md)）: 生成元を使うと周期が最大になる
> にそのまま使われる。

### ラグランジュの定理とその帰結（後で使う重要事実）

まず言葉を 1 つ。群$`G`$の部分集合$`H`$が、同じ演算でそれ自身も群になっているとき、$`H`$を$`G`$の**部分群**という。
例: 足し算の群$`\mathbb{Z}_8`$の中で$`H = \{0, 4\}`$は部分群である（$`4 + 4 = 8 \equiv 0`$なので足し算で閉じており、単位元$`0`$を含み、$`4`$の逆元は$`4`$自身）。

**ラグランジュの定理**: 有限群$`G`$の部分群$`H`$の位数$`|H|`$は、$`|G|`$を割り切る。

**この定理が言っていること**: 「$`H`$の要素数は、$`|G|`$の約数にしかなれない」ということである。$`H`$は$`G`$の**任意の部分集合**ではなく、**部分群**（演算で閉じていて、単位元と逆元を含む）でなければならない。
たとえば$`\mathbb{Z}_8`$の中で要素数 3 の部分群を作ろうとしても、作れない。$`H = \{0, 1, 2\}`$を取ると$`1 + 2 = 3 \notin H`$で閉じていないので部分群ではない。
$`3`$を足して$`\{0,1,2,3\}`$にしても$`2+3=5 \notin H`$、さらに足していくと結局$`\mathbb{Z}_8`$全体になる。
$`\{0, 2, 4\}`$も$`2 + 4 = 6 \notin H`$で閉じていない。$`8`$の約数でない要素数の部分集合は、必ずどこかで閉じていない——それがこの定理の主張である。
実際$`\mathbb{Z}_8`$の部分群は$`\{0\}, \{0,4\}, \{0,2,4,6\}, \mathbb{Z}_8`$の 4 つだけで、要素数$`1, 2, 4, 8`$はすべて$`8`$の約数になっている。

**導出の方針**: $`G`$全体を「$`H`$と同じ大きさの塊」に重なりなく切り分けられることを示す。塊の個数を$`k`$とすれば$`|G| = k \times |H|`$となり、$`|H|`$が$`|G|`$を割り切る。以下、4 段階で示す。例として$`G = \mathbb{Z}_8`$（足し算）、$`H = \{0,4\}`$を並走させる。

**段階 1（塊の作り方）**: $`G`$の要素$`g`$を 1 つ選び、$`H`$の各要素に$`g`$を演算したものを集めた集合を$`gH = \{g \ast h \mid h \in H\}`$と書く。$`H`$を$`g`$だけ「ずらしたコピー」である。
例では演算が足し算なので$`gH = \{g + h \mid h \in H\}`$で、
$`0H = \{0, 4\}`$、$`1H = \{1, 5\}`$、$`2H = \{2, 6\}`$、$`3H = \{3, 7\}`$、$`4H = \{4, 8 \equiv 0\} = \{0,4\}`$、$`5H = \{5, 9 \equiv 1\} = \{1,5\}`$、…となる。

**段階 2（どの塊も要素数はちょうど$`|H|`$）**: $`H`$の異なる 2 つの要素$`h_1 \ne h_2`$は、$`g`$を演算した後も異なる（$`g \ast h_1 \ne g \ast h_2`$）ことを示す。
背理法で示す。もし仮に$`g \ast h_1 = g \ast h_2`$になったとすると、両辺の左から$`g`$の逆元$`g^{-1}`$を演算して$`h_1 = h_2`$となり、$`h_1 \ne h_2`$と矛盾する。
（ここでの「$`g \ast h_1 = g \ast h_2`$」は事実ではなく、「もしそうだったら矛盾する」という仮定である。）
よって$`H`$の$`|H|`$個の要素は$`gH`$の$`|H|`$個の互いに異なる要素に写り、$`gH`$の要素数は$`|H|`$。例ではどの塊も 2 個である。

**段階 3（2 つの塊は「完全に同じ」か「共通要素なし」のどちらか）**: 一部だけ重なる、ということが起きないことを示す。
2 つの塊$`gH`$と$`g'H`$に共通の要素$`x`$が 1 個でもあったとする。$`x`$は$`gH`$の要素なので$`H`$のある要素$`h_1`$を使って$`x = g \ast h_1`$と書け、
同時に$`g'H`$の要素でもあるので$`H`$のある要素$`h_2`$を使って$`x = g' \ast h_2`$とも書ける。同じ$`x`$を 2 通りに書いただけなので
$$
g \ast h_1 = g' \ast h_2
$$
両辺の右から$`h_1^{-1}`$を演算すると$`g = g' \ast h_2 \ast h_1^{-1}`$。これを$`gH`$の任意の要素$`g \ast h`$に代入すると
$$
g \ast h = g' \ast (h_2 \ast h_1^{-1} \ast h)
$$
括弧の中は$`H`$の要素どうしの演算なので、$`H`$が群であることから$`H`$の要素である。よって$`g \ast h`$は$`g'H`$の要素、つまり$`gH`$のすべての要素は$`g'H`$に含まれる。
$`g`$と$`g'`$の役割を入れ替えれば$`g'H`$のすべての要素も$`gH`$に含まれる。したがって$`gH = g'H`$（完全に同じ塊）。
例では$`4H = \{0,4\}`$と$`0H = \{0,4\}`$は共通要素$`0`$を持ち、実際に完全に一致している。$`0H`$と$`1H`$は共通要素がない。

**段階 4（すべての要素がどれかの塊に入る）**: $`e \in H`$なので$`g = g \ast e \in gH`$。つまり$`g`$は自分の塊$`gH`$に入っている。

段階 3 と 4 から、$`G`$は互いに共通要素を持たない塊たちに完全に切り分けられ（同じ塊は 1 つと数える）、段階 2 からどの塊も大きさは$`|H|`$。塊の個数を$`k`$とすると$`|G| = k|H|`$ ∎
例では$`\mathbb{Z}_8`$が$`\{0,4\}, \{1,5\}, \{2,6\}, \{3,7\}`$の 4 塊に切り分けられ、$`8 = 4 \times 2`$である。

**部分群でないと何が壊れるか**: 段階 3 で「括弧の中$`h_2 \ast h_1^{-1} \ast h`$が$`H`$の要素」と言えたのは、$`H`$が群だからである。
部分群でない$`H = \{0,1\}`$（$`1+1 = 2 \notin H`$で閉じていない）で同じ塊を作ると$`0H = \{0,1\}`$、$`1H = \{1,2\}`$となり、共通要素$`1`$を持つのに一致しない。
$`H = \{0,1,2\}`$でも$`0H = \{0,1,2\}`$、$`1H = \{1,2,3\}`$で同じことが起きる。
塊が中途半端に重なって「同じ大きさの塊で重なりなく切り分ける」ことができず、$`|G| = k|H|`$は成り立たない。
だから要素数 3 の「塊」で$`\mathbb{Z}_8`$を割り切れないのは当然で、定理はそのような$`H`$についてはそもそも何も主張していない。

本シリーズで実際に使うのは、そこから出る次の帰結である。

**帰結**: 有限群$`G`$の任意の要素$`a`$について、$`a^{|G|} = e`$（単位元）。

**導出**: $`a`$の位数を$`d`$とする（前節の定義: $`a^d = e`$となる最小の$`d`$）。$`a`$から作れる要素の集合を
$`\langle a \rangle = \{a, a^2, \dots, a^d = e\}`$と書く（前項で見たとおり$`d`$個は互いに異なる）。これは部分群である:
$`a^i \ast a^j = a^{i+j}`$で、$`i + j > d`$なら$`a^{i+j} = a^{i+j-d}`$（$`a^d = e`$）と集合内に戻るので閉じており、単位元$`e = a^d`$を含み、$`a^i`$の逆元$`a^{d-i}`$も含む。
ラグランジュの定理より要素数$`d`$は$`|G|`$を割り切るので$`|G| = dk`$と書けて

$$
a^{|G|} = a^{dk} = (a^d)^k = e^k = e \qquad \blacksquare
$$

例: $`G = \mathbb{Z}_5^\ast`$（位数$`4`$）で$`a = 4`$。例 A より位数は$`d = 2`$、$`\langle 4 \rangle = \{4, 1\}`$で$`4 = 2 \times 2`$。実際$`4^4 = (4^2)^2 = 1^2 = 1`$。

> **これがフェルマーの小定理の正体である.** $`G = \mathbb{Z}_p^\ast`$（位数$`p-1`$）に適用すると
>
> $$a^{p-1} \equiv 1 \pmod p$$
>
> が即座に出る。[15 章](15_数論の道具.md)で RSA を作るときの心臓部だが、**その本質はこの群論の一般定理**であり、
> 数論の特別な魔法ではない。

## 2. 環 (Ring)

### 定義

集合$`R`$に**2 つの**演算（$`+`$ と $`\times`$）があり、次を満たすとき**環**という:

1. $`(R, +)`$が**可換群**（単位元を$`0`$、逆元を$`-a`$と書く）
2. $`\times`$が**結合律**を満たし、**単位元$`1`$**を持つ
3. **分配律**: $`a(b+c) = ab + ac`$、$`(a+b)c = ac + bc`$

$`ab = ba`$が成り立てば**可換環**。

要するに「**足し算と掛け算の 2 つの演算があり、足し算は必ず元に戻せる（引き算ができる）が、掛け算は元に戻せる保証がない（割り算ができない要素があるかもしれない）世界**」である。

### 例

- $`\mathbb{Z}`$（整数全体）: 可換環 ✓（割り算はできない）
- $`\mathbb{Z}_m`$（任意の$`m`$）: 可換環 ✓
- **多項式全体**$`\mathbb{Z}[x]`$や$`\mathrm{GF}(2)[x]`$: 可換環 ✓（[04 章](04_多項式と既約多項式.md)の主役）
- $`n \times n`$行列: 環だが**非可換**（$`AB \neq BA`$）

### 零因子 — 環で起きる厄介ごと

$`a \neq 0`$、$`b \neq 0`$なのに$`ab = 0`$となる$`a,b`$を**零因子**という。

**例**: $`\mathbb{Z}_{12}`$で$`3 \times 4 = 12 \equiv 0`$。$`3`$も$`4`$も 0 でないのに積が 0。

> **なぜこれが問題なのか.** 普通の数の感覚では「$`ab = 0`$なら$`a=0`$または$`b=0`$」だが、それが崩れる。
> すると$`ax = ay \Rightarrow x = y`$という**当たり前の式変形が使えなくなる**（[01 章](01_合同算術とユークリッドの互除法.md#合同式の演算-足し算-引き算-掛け算は-そのまま-できる)§2 の割り算の失敗はこれ）。
> 方程式が解けず、因数分解も一意でなくなる。
>
> 次節の「体」は、この厄介ごとが起きない世界、つまり 0 以外のすべての要素が逆元を持つ環である。

## 3. 体 (Field)

### 定義

環$`F`$のうち、**0 以外のすべての要素が乗法逆元を持つ**もの（かつ可換）を**体**という。

言い換えれば「**四則演算が完全に自由にできる世界**」。
演算そのものは環と同じく$`+`$と$`\times`$の 2 つで、$`-`$と$`\div`$は§1 で述べたとおり逆元との演算の略記である。
その 2 つが（0 除算を除いて）どちらも元に戻せるので、$`+ - \times \div`$がいつでも実行でき、結果が必ず世界の中に留まる。

### 例

| 集合 | 体か | 理由 |
|---|---|---|
| 有理数$`\mathbb{Q}`$、実数$`\mathbb{R}`$、複素数$`\mathbb{C}`$ | ✓ | おなじみの体（無限個の要素） |
| 整数$`\mathbb{Z}`$ | ✗ | 2 の逆元が無い |
| $`\mathbb{Z}_p`$（$`p`$素数） | ✓ | **有限体**。次章の主役 |
| $`\mathbb{Z}_m`$（$`m`$合成数） | ✗ | 零因子があり逆元を持たない要素がある |

### 定理: $`\mathbb{Z}_m`$が体 $`\iff`$ $`m`$が素数

**導出**:

（$`\Leftarrow`$）$`m = p`$が素数なら、$`1 \le a \le p-1`$のすべてで$`\gcd(a,p) = 1`$
（$`p`$の約数は 1 と$`p`$のみで、$`a < p`$だから）。
[01 章](01_合同算術とユークリッドの互除法.md#定義と存在条件)の定理より逆元が存在 ✓

（$`\Rightarrow`$）$`m`$が合成数なら$`m = ab`$（$`1<a,b<m`$）と書ける。
このとき$`a`$は$`m`$と共通因数$`a`$を持つので$`\gcd(a,m) = a \neq 1`$、よって$`a`$は逆元を持たない ✗ ∎

> **ここまでで分かったこと.**
> **素数個の要素を持つ世界$`\mathbb{Z}_p`$は、有限なのに四則演算が完全にできる。**
> これは驚くべきことである。有限個しか数が無いのに、割り算が破綻しない。
>
> この「有限 + 四則演算完備」という性質こそが:
> - 誤り訂正で**連立方程式を解いて誤り位置を特定できる**理由（[11 章](11_リードソロモン符号.md)）
> - 暗号で**逆算が定義できる**理由（[16 章](16_RSA.md)）
> である。

### 標数 (characteristic)

体$`F`$で$`\underbrace{1 + 1 + \cdots + 1}_{n\ \text{個}} = 0`$となる最小の正整数$`n`$を**標数**という
（そんな$`n`$が無ければ標数 0）。

- $`\mathbb{Q}, \mathbb{R}, \mathbb{C}`$: 標数 0（1 を何回足しても 0 にならない）
- $`\mathbb{Z}_p`$: 標数$`p`$

**定理**: 有限体の標数は必ず素数。

**導出**: 標数$`n`$が合成数$`n = ab`$（$`1<a,b<n`$）だとする。
体の中で$`(\underbrace{1+\cdots+1}_{a})(\underbrace{1+\cdots+1}_{b})`$を分配法則で展開すると、$`1 \times 1 = 1`$が$`a \times b = ab`$個現れるので$`\underbrace{1+\cdots+1}_{ab} = 0`$。
体には零因子が無い（逆元があるので、$`xy=0`$かつ$`x \neq 0`$なら$`y = x^{-1}xy = 0`$）ので、
どちらかの因子が 0。しかし$`a, b < n`$なので標数の最小性に矛盾 ∎

> **標数 2 の世界が本シリーズの主戦場である.**
> $`\mathrm{GF}(2) = \{0, 1\}`$は標数 2。ここでは$`1 + 1 = 0`$、つまり **足し算 = XOR** になる（次節）。
> そして$`a + a = 0`$より$`-a = a`$（$`a`$の逆元は$`a`$自身）、したがって$`b`$を引くこと$`= (-b)`$を足すこと$`= b`$を足すこと、すなわち**足し算と引き算が同じ**という、実装上きわめて便利な性質が生まれる。
> CRC（[09 章](09_巡回符号とCRC.md)）も AES（[14 章](14_ブロック暗号とAES.md)）も、この性質の上に成り立っている。

## 4. GF(2) — 最小の体を作ってみる

$`p = 2`$として$`\mathbb{Z}_2 = \{0, 1\}`$を作る。これを$`\mathrm{GF}(2)`$と書く（Galois Field の頭文字）。

**加法表**（$`\bmod 2`$）:

| $`+`$ | 0 | 1 |
|---|---|---|
| **0** | 0 | 1 |
| **1** | 1 | 0 |

**乗法表**:

| $`\times`$ | 0 | 1 |
|---|---|---|
| **0** | 0 | 0 |
| **1** | 0 | 1 |

体の条件を確認する: 0 以外の要素は 1 だけで、$`1 \times 1 = 1`$なので$`1^{-1} = 1`$ ✓ 体である。

> **この 2 つの表の正体.**
> 加法表を見比べてほしい——これは **XOR**（排他的論理和: 2 つのビットが異なるとき 1、同じとき 0）そのものである。
> 乗法表は **AND**（両方 1 のときだけ 1）そのもの。
>
> XOR と AND はコンピュータの演算回路（CPU）が最も基本的な命令として 1 手で実行する演算なので、**GF(2) の四則演算はそのまま 1 命令で実行できる**。
> ハードウェアで CRC（[09 章](09_巡回符号とCRC.md)）やパリティ検査（[07 章](07_線形符号.md)）が高速に動くのは、この一致のおかげである。
>
> さらに標数 2 の性質$`1+1=0`$から、**$`a - b = a + b`$（引き算と足し算が同じ）**。
> 符号理論の式で引き算の記号がほとんど出てこないのはこのためである。

## 5. まとめ — 3 つの言葉の関係

$$
\text{群} \xrightarrow{\ \text{演算をもう 1 つ足す}\ } \text{環} \xrightarrow{\ \text{その演算も元に戻せるようにする}\ } \text{体}
$$

右に行くほど条件が増え、できることが増える。体は環でもあり、環の足し算部分は群でもある。

| 構造 | 演算の数 | 足し算を戻せる（引き算） | 掛け算を戻せる（割り算） | 本シリーズでの例 |
|---|---|---|---|---|
| **群** | 1 つ | ✓（唯一の演算は必ず戻せる） | —（演算が 1 つしかない） | 楕円曲線上の点（[17 章](17_DHと楕円曲線暗号.md)）、$`\mathbb{Z}_p^\ast`$（こちらは掛け算 1 つの群） |
| **環** | 2 つ | ✓ | ✗（保証されない） | 多項式$`\mathrm{GF}(2)[x]`$（[04 章](04_多項式と既約多項式.md)）、$`\mathbb{Z}_m`$ |
| **体** | 2 つ | ✓ | ✓（0 以外） | $`\mathrm{GF}(p)`$（[03 章](03_有限体GFp.md)）、$`\mathrm{GF}(2^m)`$（[05 章](05_拡大体GF2m.md)） |
