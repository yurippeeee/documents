## 1. オイラーの φ 関数

### 定義

正の整数$`n`$について、$`1`$以上$`n`$以下の整数のうち$`n`$と互いに素（$`\gcd = 1`$）なものの個数を$`\varphi(n)`$と書き、**オイラーの φ 関数**という。[03 章 3 節](03_有限体GFp.md#原始元の個数)では$`n = p-1`$の場合に使った。$`n \geq 2`$なら$`n`$自身は$`\gcd(n,n) = n \neq 1`$なので数えない。$`\varphi(1) = 1`$である。

**例**: $`\varphi(10)`$。$`1`$から$`10`$のうち、$`2, 4, 6, 8, 10`$は 2 を、$`5, 10`$は 5 を 10 と共通に持つので除く。

```fig
e15_coprime
```

残る$`1, 3, 7, 9`$の 4 個なので$`\varphi(10) = 4`$である。

[01 章 5 節](01_合同算術とユークリッドの互除法.md#逆元が存在する条件)より、法$`n`$で逆元を持つのは$`n`$と互いに素な数だけである。したがって$`\varphi(n)`$は、法$`n`$の世界で逆元を持つ要素の個数、つまり[02 章 1 節](02_群・環・体.md#例で確かめる)の$`\mathbb{Z}_n^\ast`$の要素数である（$`n \ge 2`$では$`0`$も$`n`$も$`n`$と互いに素でないので、$`1`$〜$`n`$で数えても$`0`$〜$`n-1`$で数えても同じになる）。

### 計算公式

$`n`$が大きいと 1 つずつ数えるのは大変なので、素因数分解から求める公式を作る。素数、素数のべき、互いに素な数の積、一般の$`n`$の順に進む。

**(a) $`p`$が素数**: $`\varphi(p) = p-1`$。$`1, \dots, p-1`$はどれも$`p`$で割り切れないので、すべて$`p`$と互いに素である。

**(b) $`p`$が素数、$`k \geq 1`$**: $`\varphi(p^k) = p^k - p^{k-1}`$

**方針**: $`p^k`$と互いに素でない数を数えて、全体の$`p^k`$個から引く。

**導出**: $`p^k`$の素因数は$`p`$だけなので、$`p^k`$と共通の素因数を持つのは$`p`$の倍数に限る。$`1`$から$`p^k`$までの$`p`$の倍数は$`p, 2p, \dots, p^{k-1}\cdot p`$の$`p^{k-1}`$個なので、$`\varphi(p^k) = p^k - p^{k-1}`$である ∎

```fig

```

**(c) 乗法性**: $`m`$と$`n`$が互いに素なら$`\varphi(mn) = \varphi(m)\,\varphi(n)`$

**方針**: $`1`$から$`mn`$までを、横に$`m`$個ずつ並べた$`n`$行の表に書く。同じ列の数は$`m`$で割った余りが同じなので、$`m`$と互いに素かどうかは列ごとに決まる。残った列の中で、$`n`$と互いに素な数を数える。

```fig
e15_table
```

**導出**: 表の$`r`$列目（$`r = 1, \dots, m`$）には$`r, r+m, r+2m, \dots, r+(n-1)m`$の$`n`$個が並ぶ。

1. **列ごとに$`m`$との関係が決まる**: 列の数$`r + km`$から$`m`$の$`k`$倍を引くと$`r`$になるので、互除法の補題（[01 章 3 節](01_合同算術とユークリッドの互除法.md#互除法の原理)）と同じ理屈で$`r + km`$と$`m`$の公約数は$`r`$と$`m`$の公約数と一致し、$`\gcd(r + km, m) = \gcd(r, m)`$である。したがって$`m`$と互いに素な数は、$`\gcd(r, m) = 1`$の列に全部入っており、そのような列は$`\varphi(m)`$本ある。
2. **1 本の列の中では、$`n`$で割った余りが全部違う**: 同じ列の 2 つの数$`r + km`$と$`r + k'm`$（$`0 \le k < k' \le n-1`$）の$`n`$で割った余りが同じだったとすると、差$`(k'-k)m`$が$`n`$で割り切れる。$`m`$と$`n`$は互いに素なので、$`m`$は法$`n`$で逆元$`m^{-1}`$を持つ（[01 章 5 節](01_合同算術とユークリッドの互除法.md#逆元が存在する条件)）。$`(k'-k)m \equiv 0 \pmod n`$の両辺に$`m^{-1}`$を掛けると$`k' - k \equiv 0 \pmod n`$となるが、$`0 < k'-k < n`$なので$`n`$の倍数にはなれず、矛盾する。よって$`n`$個の余りは互いに異なり、$`0, 1, \dots, n-1`$がちょうど 1 回ずつ現れる。
3. **列の中で数える**: 互除法の補題より$`\gcd(x, n) = \gcd(x \bmod n, n)`$なので、$`x`$が$`n`$と互いに素であることは、$`x`$を$`n`$で割った余りが$`n`$と互いに素であることと同じである。手順 2 より 1 本の列の余りは$`0`$〜$`n-1`$を 1 回ずつ取るので、$`n`$と互いに素な数はどの列にもちょうど$`\varphi(n)`$個ある。
4. **合わせる**: $`mn`$の素因数は$`m`$の素因数か$`n`$の素因数なので、$`x`$が$`mn`$と互いに素であることは、$`x`$が$`m`$とも$`n`$とも互いに素であることと同じである。手順 1 の$`\varphi(m)`$本の列それぞれに手順 3 の$`\varphi(n)`$個があるので、合計は$`\varphi(m)\varphi(n)`$個である ∎

**例**: $`m = 3`$、$`n = 5`$（上の図）。3 と互いに素な列は 1 列目と 2 列目の$`\varphi(3) = 2`$本で、どちらの列も 5 で割った余りが$`0`$〜$`4`$を 1 回ずつ取り、そのうち 5 と互いに素な$`\varphi(5) = 4`$個が残る。合計$`2 \times 4 = 8 = \varphi(15)`$で、実際に$`1, 2, 4, 7, 8, 11, 13, 14`$の 8 個である。

**$`m`$と$`n`$が互いに素でないと成り立たない**: $`m = n = 2`$なら$`\varphi(4) = 2`$だが、$`\varphi(2)\varphi(2) = 1`$である。$`1`$〜$`4`$を 2 列の表に並べると 1 列目は$`1, 3`$で、2 で割った余りがどちらも 1 になり、手順 2 が崩れる。

**(d) 一般形**: $`n = p_1^{e_1} p_2^{e_2} \cdots p_r^{e_r}`$（$`p_1, \dots, p_r`$は異なる素数）と素因数分解できるとき

$$
\varphi(n) = \prod_{i=1}^{r}\bigl(p_i^{e_i} - p_i^{e_i-1}\bigr) = n\prod_{i=1}^{r}\left(1 - \frac{1}{p_i}\right)
$$

**導出**: $`p_1^{e_1}`$と残りの積$`p_2^{e_2}\cdots p_r^{e_r}`$は共通の素因数を持たないので互いに素であり、(c) より$`\varphi(n) = \varphi(p_1^{e_1})\,\varphi(p_2^{e_2}\cdots p_r^{e_r})`$である。残りの積にも同じことを繰り返すと$`\varphi(n) = \varphi(p_1^{e_1}) \cdots \varphi(p_r^{e_r})`$となり、各因子に (b) を使うと左の形になる。さらに$`p_i^{e_i} - p_i^{e_i - 1} = p_i^{e_i}(1 - 1/p_i)`$と書き直し、$`p_i^{e_i}`$を全部掛けると$`n`$になるので、右の形になる ∎

**例**: $`\varphi(10) = 10(1 - \tfrac12)(1 - \tfrac15) = 4`$、$`\varphi(12) = 12(1-\tfrac12)(1-\tfrac13) = 4`$。

**RSA で使う場合**: $`n = pq`$（$`p, q`$は異なる素数）は、(c) と (a) から

$$
\boxed{\varphi(pq) = (p-1)(q-1)}
$$

下の図で$`m`$と$`n`$を変えると、$`1`$から$`mn`$までを$`m`$列に並べた表で、$`m`$と互いに素な列と、その中で$`n`$とも互いに素な数が色分けされ、$`\varphi(mn)`$と$`\varphi(m)\varphi(n)`$が比べられる。$`m`$と$`n`$が互いに素でないと、列の中で$`n`$で割った余りが重なり、2 つが一致しなくなる。

### φ(n) を知ることと素因数分解は同じ難しさ

$`n = pq`$は公開されるが、$`\varphi(n) = (p-1)(q-1)`$を計算するには$`p, q`$を知る必要がある。
逆に$`\varphi(n)`$が分かれば$`p, q`$も求まる。$`\varphi(n) = (p-1)(q-1) = pq - (p + q) + 1 = n - (p + q) + 1`$を$`p+q`$について解くと$`p + q = n - \varphi(n) + 1`$で、$`pq = n`$と合わせると、$`p, q`$は 2 次方程式

$$
t^2 - (n - \varphi(n) + 1)\,t + n = 0
$$

の 2 つの解である（解と係数の関係: 2 つの解の和が$`p+q`$、積が$`pq`$）。**例**: $`n = 143`$、$`\varphi(n) = 120`$なら$`p + q = 24`$で、$`t^2 - 24t + 143 = 0`$を解くと$`t = 11, 13`$である（$`11 \times 13 = 143`$）。

```fig
e15_asym
```

つまり$`\varphi(n)`$を求めることと$`n`$を素因数分解することは、一方ができれば他方もできる、同じ難しさの問題である。

- 鍵を作る人は$`p, q`$を自分で選んだので、$`\varphi(n)`$をすぐに計算できる。
- 攻撃者は$`n`$しか知らないので、素因数分解しないと$`\varphi(n)`$が分からない。

この非対称性が RSA の仕組みの中心である（[16 章](16_RSA.md)）。

## 2. オイラーの定理

### 定理

$`\gcd(a,n)=1`$のとき

$$
\boxed{a^{\varphi(n)} \equiv 1 \pmod n}
$$

**例**: $`n = 10`$、$`a = 3`$なら$`\varphi(10) = 4`$で、$`3^4 = 81 = 8 \times 10 + 1 \equiv 1 \pmod{10}`$である。

### Z_n^* は掛け算について群になる

**方針**: $`n`$と互いに素な余りの集合$`\mathbb{Z}_n^\ast`$が、掛け算について群の 4 条件を満たすことを確かめる。閉性と逆元は、[01 章 5 節](01_合同算術とユークリッドの互除法.md#逆元が存在する条件)の「逆元を持つ$`\iff \gcd = 1`$」を両方向に使って示す。

**導出**:
- 閉性: $`a, b \in \mathbb{Z}_n^\ast`$とし、法$`n`$での逆元を$`a^{-1}, b^{-1}`$とする。$`(ab)(b^{-1}a^{-1}) = a(bb^{-1})a^{-1} = aa^{-1} = 1`$なので、$`ab`$は逆元$`b^{-1}a^{-1}`$を持つ。逆元を持つので$`\gcd(ab, n) = 1`$であり、$`ab \bmod n \in \mathbb{Z}_n^\ast`$である。
- 結合律と単位元$`1`$は、整数の掛け算からそのまま成り立つ。
- 逆元: $`a \in \mathbb{Z}_n^\ast`$の逆元$`a^{-1}`$は、$`a^{-1} a = 1`$なので$`a`$を逆元に持つ。逆元を持つので$`\gcd(a^{-1}, n) = 1`$であり、$`a^{-1}`$も$`\mathbb{Z}_n^\ast`$の中にある ∎

この群の要素数（群の位数）は、1 節で見たとおり$`\varphi(n)`$である。

### 導出（02 章の群の定理の当てはめ）

**方針**: [02 章 1 節](02_群・環・体.md#帰結-どの要素も-g-個並べると単位元に戻る-後で使う重要事実)のラグランジュの定理の帰結「有限群$`G`$の任意の要素$`a`$について$`a^{|G|} = e`$」を、$`G = \mathbb{Z}_n^\ast`$に当てはめる。

**導出**: $`G = \mathbb{Z}_n^\ast`$は掛け算の群で、単位元は$`1`$、$`|G| = \varphi(n)`$である。$`\gcd(a, n) = 1`$なら$`a \bmod n \in G`$なので、帰結より$`a^{\varphi(n)} \equiv 1 \pmod n`$ ∎

```fig
e15_euler
```

図は$`\mathbb{Z}_{10}^\ast = \{1, 3, 7, 9\}`$の各要素を、自分自身で掛け続けたものである。3 と 7 は 4 回掛けて初めて 1 に戻り（位数 4）、9 は 2 回で戻る（位数 2）。位数がどれも$`|G| = 4`$の約数なので、どの要素も 4 乗すると 1 になる。

**系（フェルマーの小定理）**: $`n=p`$が素数なら$`\varphi(p)=p-1`$なので、$`p`$で割り切れない$`a`$について$`a^{p-1}\equiv1 \pmod p`$である。

02 章でフェルマーの小定理をラグランジュの定理の帰結として導いたが、同じ議論を$`\mathbb{Z}_n^\ast`$に当てはめたものがオイラーの定理である。数論の定理に見えるが、中身は「有限の群では、要素を群の位数だけ掛けると単位元に戻る」という群の性質である。

## 3. 中国剰余定理 (CRT)

### 定理

$`m_1,\dots,m_r`$が**どの 2 つも互いに素**（$`i \neq j`$なら$`\gcd(m_i, m_j) = 1`$）のとき、$`M = m_1 m_2 \cdots m_r`$とおくと、連立合同式

$$
x \equiv a_1 \pmod{m_1},\quad \dots,\quad x \equiv a_r \pmod{m_r}
$$

は、$`0 \le x < M`$の範囲に**ただ 1 つの解**を持つ。言い換えると、$`0`$〜$`M-1`$の$`M`$個の整数と、余りの組$`(x \bmod m_1, \dots, x \bmod m_r)`$の$`M`$通りが、1 対 1 に対応する。

### 2 つの法で見る

$`m_1 = 3`$、$`m_2 = 5`$とし、$`0`$〜$`14`$の各$`x`$を、行が$`x \bmod 3`$、列が$`x \bmod 5`$のマスに書き込む。

```fig
e15_crtgrid
```

$`x`$を 1 増やすと行も列も 1 つずつ進む（端まで来たら反対側に戻る）ので、数は斜めに並んでいく。15 個のマスがちょうど 1 回ずつ埋まり、空きも重なりも無い。どのマス（余りの組）にも、それを余りに持つ$`x`$がただ 1 つある、というのが中国剰余定理の主張である。1 節の表で「1 本の列の中では$`n`$で割った余りが全部違う」と示したのは、この対応の一部を見たものである。

法が互いに素でないと、こうはならない。$`m_1 = 2`$、$`m_2 = 4`$なら$`x`$と$`x + 4`$が同じマスに入り、余りの組$`(0, 1)`$のように一度も埋まらないマスが残る（この節のデモで確かめられる）。

### 導出（解を実際に作る）

**方針**: 「法$`m_i`$では余り 1、ほかの法では余り 0」になる数$`e_i`$を$`i`$ごとに作る。$`e_i`$を$`a_i`$倍して足せば、どの法で見ても欲しい余りになる。解が存在することを示したら、個数を数えて一意性を示す。

**存在**: $`M_i = M/m_i`$（$`m_i`$以外の$`r-1`$個の積）とおく。$`M_i`$の素因数はすべて$`m_i`$以外の$`m_j`$から来るので、$`M_i`$は$`m_i`$と共通の素因数を持たず、$`\gcd(M_i, m_i)=1`$である。[01 章 5 節](01_合同算術とユークリッドの互除法.md#逆元が存在する条件)より、法$`m_i`$での逆元$`N_i = M_i^{-1} \bmod m_i`$が存在する。$`e_i = M_i N_i`$とおくと
- 法$`m_i`$では$`e_i = M_i N_i \equiv 1`$（$`N_i`$の定義）。
- 法$`m_j`$（$`j \neq i`$）では、$`M_i`$が$`m_j`$を因数に持つので$`e_i \equiv 0`$。

そこで

$$
\boxed{x = \sum_{i=1}^{r} a_i M_i N_i \bmod M}
$$

とおく。法$`m_j`$で見ると、$`i \ne j`$の項は$`a_i e_i \equiv 0`$、$`i = j`$の項は$`a_j e_j \equiv a_j`$なので、和は$`a_j`$と合同である。最後に$`M`$で割った余りを取っても、$`M`$は$`m_j`$の倍数なので法$`m_j`$での余りは変わらず、$`x \equiv a_j \pmod{m_j}`$である。

**一意性**: 存在の証明から、余りの組$`(a_1, \dots, a_r)`$（$`0 \le a_i < m_i`$）のどれにも、$`0`$〜$`M-1`$の中に対応する$`x`$が少なくとも 1 つある。余りの組は$`m_1 m_2 \cdots m_r = M`$通りで、$`x`$の候補も$`M`$個である。$`M`$個の数をそれぞれ自分の余りの組に割り当て、$`M`$通りの組がどれも 1 回以上使われるのだから、どの組もちょうど 1 回ずつ使われる。したがって解は$`0 \le x < M`$にただ 1 つである ∎

### 実例

$$
x \equiv 2 \pmod 3, \quad x \equiv 3 \pmod 5, \quad x \equiv 2 \pmod 7
$$

$`M = 105`$、$`M_1=35`$、$`M_2=21`$、$`M_3=15`$である。

- $`N_1 = 35^{-1} \bmod 3`$: $`35\equiv2`$で、$`2\cdot2=4\equiv1`$なので$`N_1=2`$
- $`N_2 = 21^{-1}\bmod 5`$: $`21\equiv1`$なので$`N_2=1`$
- $`N_3 = 15^{-1}\bmod 7`$: $`15\equiv1`$なので$`N_3=1`$

したがって$`e_1 = 35 \cdot 2 = 70`$、$`e_2 = 21`$、$`e_3 = 15`$である。


$$
x = 2\cdot70 + 3\cdot21 + 2\cdot15 = 140+63+30 = 233 \equiv 23 \pmod{105}
$$

**検算**: $`23 = 3\cdot7+2`$、$`23=5\cdot4+3`$、$`23=7\cdot3+2`$で、3 つとも満たしている。

下の図で 2 つの法と余りを変えると、余りの組のマスに数を書き込んだ表と、上の手順で作った解が表示される。法が互いに素でないときは、空きのマスと、2 つ以上の数が入るマスができる。

### CRT による RSA の高速化

RSA の復号$`m = c^d \bmod n`$（$`n=pq`$）は、大きな数のべき乗なので重い。法$`n`$の計算を、法$`p`$の計算と法$`q`$の計算に分けると速くなる。
1. $`m_p = c^{\,d \bmod (p-1)} \bmod p`$を計算する。
2. $`m_q = c^{\,d \bmod (q-1)} \bmod q`$を計算する。
3. CRT で$`m \equiv m_p \pmod p`$、$`m \equiv m_q \pmod q`$を満たす$`m`$を求める。

**指数を$`d \bmod (p-1)`$に減らしてよい理由**: $`d`$を$`p-1`$で割って$`d = (p-1)t + (d \bmod (p-1))`$と書く。
- $`c`$が$`p`$で割り切れないとき: フェルマーの小定理より$`c^{p-1} \equiv 1 \pmod p`$なので、$`c^d = (c^{p-1})^t \cdot c^{\,d \bmod (p-1)} \equiv c^{\,d \bmod (p-1)} \pmod p`$である。
- $`c`$が$`p`$で割り切れるとき: 両辺とも$`0 \pmod p`$である（$`d`$は$`(p-1)(q-1)`$と互いに素なので$`d \bmod (p-1)`$は 0 にならず、右辺も$`c`$を 1 回以上掛けている）。

法$`q`$についても同じである。

```fig
e15_rsacrt
```

**例**（[16 章 3 節](16_RSA.md#crt-を使った復号-高速化)と同じ数値）: $`p = 61`$、$`q = 53`$、$`d = 2753`$、$`c = 2790`$なら、$`d \bmod 60 = 53`$、$`d \bmod 52 = 49`$で、$`m_p = 2790^{53} \bmod 61 = 4`$、$`m_q = 2790^{49} \bmod 53 = 12`$である。CRT で組み立てると$`m = 65`$になる。

**速くなる理由**: $`n`$を$`2k`$ビットとすると、2 つの効果が重なる。
- 1 回の掛け算（筆算の方法）の手間はビット数の 2 乗に比例するので、法が$`k`$ビットになると約$`1/4`$になる。
- べき乗に必要な掛け算の回数は指数のビット数に比例する（[01 章 6 節](01_合同算術とユークリッドの互除法.md#繰り返し二乗法-巨大なべき乗を現実的な時間で)）。指数が$`2k`$ビットの$`d`$から$`k`$ビットの$`d \bmod (p-1)`$になるので、約$`1/2`$になる。

合わせて 1 本あたり$`1/4 \times 1/2 = 1/8`$で、それを$`p`$側と$`q`$側の 2 本行うので$`2/8 = 1/4`$、全体で約 4 倍速くなる（最後に CRT で組み立てる手間は、べき乗に比べて小さい）。実際の RSA の実装（OpenSSL など）はこの方法を使っている。

**フォールト攻撃の危険**: 電源やクロックに瞬間的な異常を与えて$`m_p`$の計算だけを誤らせると、$`m_q`$は正しいまま、誤った結果$`m'`$が出力される。$`m'`$と正しい$`m`$は、法$`q`$では等しく（どちらも$`m_q`$と合同）、法$`p`$では異なる。つまり$`m' - m`$は$`q`$の倍数だが$`p`$の倍数ではないので、$`\gcd(m' - m, n) = q`$となり、秘密の素数$`q`$が分かってしまう（**Bellcore 攻撃**）。

```fig
e15_fault
```

**例**: 上の例で$`m_p`$が 4 ではなく 5 に化けると、CRT の結果は$`m' = 2079`$になる。$`m' - m = 2014 = 2 \times 19 \times 53`$で、$`\gcd(2014, 3233) = 53 = q`$である。

署名（[18 章](18_ハッシュ・MAC・デジタル署名.md)）の場合は、正しい値を知らなくても同じことができる。署名$`s`$は署名対象の値$`h`$から$`s = h^d \bmod n`$として作り、公開鍵$`e`$で$`s^e \equiv h`$と確かめられる。誤った署名$`s'`$では、$`s'^{\,e}`$は法$`q`$では$`h`$に戻るが法$`p`$では戻らないので、$`\gcd(s'^{\,e} - h, n) = q`$となる。そのため実装では、計算結果を公開鍵で検算してから出力する必要がある。

## 4. 位数と原始根

### 位数

$`\gcd(a,n)=1`$のとき、$`a^k \equiv 1 \pmod n`$となる最小の正整数$`k`$を$`a`$の**位数**という。群$`\mathbb{Z}_n^\ast`$での要素の位数（[02 章 1 節](02_群・環・体.md#要素の位数-単位元になるまでに要素を何個並べるか)）と同じものである。

**性質**: 位数は$`\varphi(n)`$を割り切る。$`a`$のべき全体$`\langle a \rangle`$は、要素数が$`a`$の位数に等しい部分群で（02 章 1 節）、ラグランジュの定理より部分群の要素数は群の要素数$`\varphi(n)`$を割り切るからである。2 節の図で、位数 4 と 2 がどちらも$`\varphi(10) = 4`$の約数になっていたのはこのためである。

### 原始根

位数がちょうど$`\varphi(n)`$の$`a`$を、法$`n`$の**原始根**という。$`a, a^2, \dots, a^{\varphi(n)}`$が、$`n`$と互いに素な余りをすべて尽くすということである。$`n = p`$が素数のときは[03 章 3 節](03_有限体GFp.md#原始元-生成元-と離散対数)の原始元と同じもので、ここでは一般の$`n`$に広げている。

```fig
e15_orders
```

**存在定理**（証明は省き、事実として使う）: 原始根が存在するのは、$`n`$が$`1, 2, 4, p^k, 2p^k`$（$`p`$は奇素数、$`k \ge 1`$）のいずれかの形のときに限る。
たとえば$`n = 8`$には原始根が無い。図のとおり$`\mathbb{Z}_8^\ast = \{1, 3, 5, 7\}`$の要素はどれも 2 乗すると 1 になる（$`9, 25, 49`$はどれも 8 で割って 1 余る）ので、位数は最大でも 2 で、$`\varphi(8) = 4`$に届かない。

**個数**: 原始根が存在するときは$`\varphi(\varphi(n))`$個ある。原始根$`g`$を 1 つ取ると、$`n`$と互いに素な余りはすべて$`g^k`$（$`1 \le k \le \varphi(n)`$）と書ける。
$`g^k`$の位数は$`\varphi(n)/\gcd(k, \varphi(n))`$である（[03 章 3 節](03_有限体GFp.md#原始元の個数)の段階 3 の議論で、$`p-1`$を$`\varphi(n)`$に置き換えたもの）。位数が$`\varphi(n)`$になるのは$`\gcd(k, \varphi(n)) = 1`$のときで、そのような$`k`$は$`\varphi(\varphi(n))`$個ある。
**例**: $`n = 10`$なら$`\varphi(10) = 4`$、$`\varphi(4) = 2`$で、原始根は$`3`$と$`7`$の 2 個である（2 節の図）。

下の図で$`n`$と$`a`$を変えると、$`\mathbb{Z}_n^\ast`$の要素を円周上に並べ、各要素$`x`$から$`ax \bmod n`$へ矢印を引いた図が表示される。矢印をたどると、どの輪も同じ長さ（$`a`$の位数）になり、輪の数は$`\varphi(n)`$を位数で割った数になる。1 を含む輪が$`\langle a \rangle`$で、ほかの輪は、[02 章 1 節](02_群・環・体.md#ラグランジュの定理)のラグランジュの定理の証明で群を切り分けた、同じ大きさの塊に当たる。

## 5. 離散対数問題 (DLP)

### 定義

$`p`$を素数、$`g`$を法$`p`$の原始根とする。$`1 \le y \le p-1`$が与えられたとき

$$
g^x \equiv y \pmod p
$$

を満たす$`x`$（$`0 \leq x < p - 1`$）を求める問題を**離散対数問題**（DLP）という。$`g`$は原始根なので、どの$`y`$にもこのような$`x`$がただ 1 つある（[03 章 3 節](03_有限体GFp.md#原始元-生成元-と離散対数)の離散対数）。

**例**: $`p = 23`$、$`g = 5`$（位数 22 で原始根。[17 章](17_DHと楕円曲線暗号.md)の例と同じ）。$`y = 8`$なら、$`5^0, 5^1, \dots`$と順に計算していくと$`5^6 = 15625 = 679 \times 23 + 8`$なので$`x = 6`$である。

### 難しさの非対称性

| 方向 | 計算量 | 2048 ビットの$`p`$での実際の時間 |
|---|---|---|
| $`x`$から$`y = g^x`$ | 掛け算$`O(\log x)`$回（繰り返し二乗法、[01 章 6 節](01_合同算術とユークリッドの互除法.md#繰り返し二乗法-巨大なべき乗を現実的な時間で)） | ミリ秒 |
| $`y`$から$`x`$ | 最良の方法でも準指数時間（次の小節） | 現実的に不可能 |

```fig
e15_dlscatter
```

$`x`$から$`y`$へは$`g`$を掛けていくだけだが、$`y`$の値は$`1`$〜$`p-1`$を不規則に飛び回る。$`y`$の大小や近さは$`x`$の手がかりにならないので、逆向きには何らかの探索が必要になる。

### 知られているアルゴリズムと準指数時間

アルゴリズムの速さを、$`p`$の桁数で比べる。$`p`$の桁数は$`\ln p`$に比例する。計算量が$`(\ln p)^c`$の形なら**多項式時間**、$`p^{c} = e^{c \ln p}`$の形なら**指数時間**という。その中間の

$$
L_p[\alpha, c] = \exp\!\left(c\,(\ln p)^{\alpha}(\ln\ln p)^{1-\alpha}\right) \qquad (0 < \alpha < 1)
$$

の形を**準指数時間**という。$`\alpha = 0`$を代入すると$`\exp(c \ln\ln p) = (\ln p)^c`$（多項式時間）、$`\alpha = 1`$を代入すると$`\exp(c \ln p) = p^c`$（指数時間）になるので、$`\alpha`$はその間のどこにあるかを表し、0 に近いほど速い。

| 手法 | 計算量 | 備考 |
|---|---|---|
| 総当たり | $`O(p)`$ | $`g^0, g^1, \dots`$を順に計算して比べる |
| Baby-step Giant-step | $`O(\sqrt p)`$ | 必要なメモリも$`O(\sqrt p)`$（次の小節） |
| Pollard の ρ 法 | $`O(\sqrt p)`$ | メモリはほとんど要らない |
| Index Calculus（数体ふるい法による改良版） | 準指数時間$`L_p[1/3, c]`$ | $`\mathbb{Z}_p^\ast`$では有効（下の「楕円曲線暗号への接続」） |

$`O(\sqrt p) = O(e^{(\ln p)/2})`$は指数時間で、$`L_p[1/3, c]`$よりずっと遅い。

### Baby-step Giant-step — 総当たりの平方根まで減らす

**方針**: $`m = \lceil \sqrt{p-1}\, \rceil`$（$`\sqrt{p-1}`$以上の最小の整数）とし、求める$`x`$を$`m`$で割って$`x = jm + i`$（$`0 \le i, j < m`$）と書く。$`g^i`$の$`m`$個を先に表にしておけば、$`j`$を$`m`$通り試すだけで済む。

**導出**: $`g^x = g^{jm + i} = (g^m)^j g^i`$なので、$`g^x \equiv y`$の両辺に$`(g^{m})^{-j}`$を掛けた

$$
g^i \equiv y \cdot (g^{-m})^j \pmod p
$$

と同じである。
1. **baby step**: $`g^0, g^1, \dots, g^{m-1}`$を計算して表に保存する（掛け算$`m`$回）。
2. **giant step**: $`j = 0, 1, 2, \dots`$について$`y \cdot (g^{-m})^j`$を計算し（1 回ごとに$`g^{-m}`$を 1 回掛ける）、表に同じ値があるか調べる。$`g^i`$と一致したら$`x = jm + i`$である。

$`j`$は多くとも$`m`$通りなので、掛け算は合わせて$`2m \approx 2\sqrt{p}`$回程度で済む。その代わり、表に$`m`$個の値を保存するメモリが要る ∎

**例**: $`p = 23`$、$`g = 5`$、$`y = 8`$。$`m = \lceil\sqrt{22}\,\rceil = 5`$である。

```fig
e15_bsgs
```

baby step の表は$`g^0, \dots, g^4 = 1, 5, 2, 10, 4`$である。$`g^5 = 20`$で、その逆元は$`g^{-5} = 15`$（$`20 \times 15 = 300 = 13 \times 23 + 1`$）である。giant step は$`j = 0`$で$`8`$（表に無い）、$`j = 1`$で$`8 \times 15 = 120 \equiv 5`$で、表の$`g^1`$と一致する。よって$`x = 1 \times 5 + 1 = 6`$である。

下の図で素数と$`y`$を変えると、$`g^x`$の値の並びと、baby step・giant step の手順、総当たりとの掛け算の回数の比較が表示される。

### ポーリッヒ・ヘルマン法 — CRT で小さな問題に分ける

**方針**: 群の要素数$`p-1`$が小さな素数の積に分解できるとき、$`x`$を$`p-1`$で割った余りを直接求める代わりに、$`p-1`$の素因数ごとの余りを別々に求め、3 節の中国剰余定理で組み立てる。素因数$`q`$についての余りは、両辺を$`(p-1)/q`$乗して位数$`q`$の小さな部分群に移すと、$`q`$通りを調べるだけで分かる。

**例**: $`p = 23`$、$`g = 5`$、$`y = 8`$。$`p - 1 = 22 = 2 \times 11`$なので、$`x \bmod 2`$と$`x \bmod 11`$を別々に求める。

```fig
e15_ph
```

- **$`x \bmod 2`$**: 両辺を$`22/2 = 11`$乗すると$`(g^{11})^x \equiv y^{11}`$である。$`g^{11} = 5^{11} \equiv 22 \equiv -1`$、$`y^{11} = 8^{11} \equiv 1`$なので$`(-1)^x \equiv 1`$、つまり$`x`$は偶数で$`x \equiv 0 \pmod 2`$である。$`g^{11}`$の位数は 2 なので、$`(g^{11})^x`$は$`x`$を 2 で割った余りだけで決まる。
- **$`x \bmod 11`$**: 両辺を$`22/11 = 2`$乗すると$`(g^2)^x \equiv y^2`$である。$`g^2 = 25 \equiv 2`$、$`y^2 = 64 \equiv 18`$で、2 の位数は 11 なので、$`2^x \equiv 18`$は$`x`$を 11 で割った余りだけで決まる。$`2^1, 2^2, \dots`$と調べると$`2^6 = 64 \equiv 18`$なので、$`x \equiv 6 \pmod{11}`$である。
- **組み立て**: $`x \equiv 0 \pmod 2`$、$`x \equiv 6 \pmod{11}`$を満たす$`0 \le x < 22`$は$`x = 6`$である。

調べた候補は 2 通りと 11 通りで、22 通りを総当たりするより少ない。一般に、$`p-1`$の素因数がどれも小さいと、$`p`$が大きくても、離散対数は最大の素因数の大きさ程度の手間で求まってしまう。したがって安全のためには、$`p-1`$が大きな素因数を持つように$`p`$を選ぶ必要がある（たとえば$`q`$も素数になるように$`p = 2q + 1`$を選ぶ）。

### 楕円曲線暗号への接続

$`\mathbb{Z}_p^\ast`$の離散対数問題に準指数時間の Index Calculus が使えるのは、$`g^k \bmod p`$を整数として見て、小さな素数の積に分解できるからである。小さな素数だけの積に分解できる数を**滑らかな数**という。たとえば$`g^k \equiv 2^{e_1} 3^{e_2} 5^{e_3} \pmod p`$となる$`k`$が見つかれば、両辺の離散対数を取って

$$
k \equiv e_1 \log_g 2 + e_2 \log_g 3 + e_3 \log_g 5 \pmod{p-1}
$$

という、小さな素数の離散対数についての 1 次式が得られる。このような式を十分な数だけ集めて連立方程式を解けば小さな素数の離散対数が分かり、それを使って任意の$`y`$の離散対数が求まる。そのため安全を保つには、$`p`$を 2048 ビット以上にする必要がある。

[17 章](17_DHと楕円曲線暗号.md)の楕円曲線の点の群には「小さな素数の積に分解する」に当たる操作が無く、一般の楕円曲線では Index Calculus のような準指数時間の方法は知られていない。使えるのは、群の要素数$`n`$に対して$`O(\sqrt n)`$の Pollard の ρ 法などだけである。そのため、同じ安全性をずっと短い鍵で実現できる。

攻撃に約$`2^s`$回の計算が必要なことを、**$`s`$ビットの安全性**という。米国 NIST の推奨では、同じ安全性の水準に必要な鍵長は次のとおりである。

| 安全性の水準 | RSA / DH の鍵長（ビット） | 楕円曲線の鍵長（ビット） |
|---|---|---|
| 112 ビット | 2048 | 224 |
| 128 ビット | 3072 | 256 |
| 192 ビット | 7680 | 384 |
| 256 ビット | 15360 | 512 |

```fig
e15_keylen
```

楕円曲線では、要素数$`n \approx 2^{2s}`$の群なら$`O(\sqrt n) = 2^s`$回の計算が要るので、鍵長は安全性の 2 倍で済む。RSA と DH の鍵長は楕円曲線のおよそ 9〜30 倍で、求める安全性が高いほど差が開く。これが楕円曲線暗号が広く使われるようになった理由である。

## 6. 素数判定 — 鍵生成に必須

RSA-2048 には 1024 ビット程度の素数が 2 つ必要である。その見つけ方を述べる。

### 素数定理

$`x`$以下の素数の個数を$`\pi(x)`$とすると、$`\pi(x) \approx x/\ln x`$である（**素数定理**、証明は省く）。
したがって$`n`$付近の数が素数である確率は約$`1/\ln n`$で、1024 ビットの数なら$`1/\ln(2^{1024}) \approx 1/710`$である。偶数を除けば約 355 個に 1 個が素数なので、ランダムな奇数を選んで判定を繰り返せば、すぐに見つかる。

### フェルマー・テスト

$`a^{n-1} \equiv 1 \pmod n`$を満たさなければ、$`n`$は合成数である（フェルマーの小定理の対偶）。

**弱点**: **カーマイケル数**（561, 1105, 1729, …）は合成数なのに、$`n`$と互いに素なすべての$`a`$で$`a^{n-1} \equiv 1`$となり、テストを通過してしまう。$`\gcd(a, n) \neq 1`$の$`a`$なら不合格になるが、そのような$`a`$を偶然選ぶ確率は小さい。
たとえば$`561 = 3 \times 11 \times 17`$で、$`2^{560} \equiv 1 \pmod{561}`$が成り立つ。

### ミラー・ラビン・テスト（実用の標準）

$`n`$を 3 以上の奇数とし、$`n-1 = 2^s d`$（$`d`$は奇数、$`s \ge 1`$）と分解する。$`n`$が素数なら、$`n`$と互いに素な任意の$`a`$について

$$
a^d \equiv 1 \pmod n \quad\text{または}\quad a^{2^r d}\equiv -1 \pmod n\ \text{となる } r \text{ が } 0 \le r \le s-1 \text{ に存在する}
$$

が成り立つ。

**手順**: $`x_0 = a^d \bmod n`$を計算し、$`x_1 = x_0^2, x_2 = x_1^2, \dots, x_s = x_{s-1}^2`$（$`= a^{n-1}`$）と 2 乗を$`s`$回繰り返す（どれも$`\bmod n`$）。
$`x_0 = 1`$であるか、$`x_0, \dots, x_{s-1}`$のどこかに$`-1`$（$`= n - 1`$）が現れれば「たぶん素数」、そうでなければ「確実に合成数」と判定する。

**方針**: 素数なら$`\mathbb{Z}_n`$は体なので、「2 乗して 1 になる数は$`\pm 1`$だけ」である。列$`x_0, \dots, x_s`$の中に「$`\pm 1`$でないのに 2 乗すると 1」の数があれば、体ではない、つまり合成数だと分かる。

**導出**: $`n`$が素数なら$`\mathbb{Z}_n`$は体（[02 章 3 節](02_群・環・体.md#定理-mathbbzmが体-iff-mが素数)）である。$`x^2 \equiv 1`$は$`(x-1)(x+1) \equiv 0`$と同じで、体には零因子が無い（[02 章 2 節](02_群・環・体.md#環-ring)）ので、$`x - 1 \equiv 0`$か$`x + 1 \equiv 0`$、すなわち$`x \equiv \pm1`$に限る。
列$`x_0, x_1, \dots, x_s`$は最後が$`x_s = a^{n-1} \equiv 1`$（フェルマーの小定理）で、各項は前の項の 2 乗である。最後から逆にたどると、$`1`$の直前の項は 2 乗して 1 になる数なので$`1`$か$`-1`$である。$`1`$ならさらにその前も$`\pm1`$、と続く。
したがって列は「$`1`$ばかり」か「途中で$`-1`$が現れ、その後は$`1`$が続く」のどちらかの形しかとれない。これが上の条件である ∎

**例**: 素数$`n = 13`$、$`a = 2`$では、$`12 = 2^2 \times 3`$なので$`x_0 = 2^3 = 8`$、$`x_1 = 64 \equiv 12 = -1`$、$`x_2 = 1`$で、$`-1`$の後に$`1`$が来る形になっている。
カーマイケル数$`n = 561`$、$`a = 2`$では、$`560 = 2^4 \times 35`$なので$`s = 4`$、$`d = 35`$である。

| $`x_0 = 2^{35}`$ | $`x_1`$ | $`x_2`$ | $`x_3`$ | $`x_4 = 2^{560}`$ |
|---|---|---|---|---|
| 263 | 166 | 67 | 1 | 1 |

$`x_4 = 1`$なのでフェルマー・テストは通過するが、$`x_2 = 67`$は$`\pm 1`$（1 と 560）でないのに$`x_3 = 67^2 \equiv 1`$になっている。$`x_0`$〜$`x_3`$に$`-1 = 560`$は現れないので、561 は合成数と判定される。
実際、$`(67-1)(67+1) = 66 \times 68 = 4488 = 8 \times 561 \equiv 0`$で、$`66`$と$`68`$は$`\mathbb{Z}_{561}`$の零因子である。$`\gcd(66, 561) = 33`$と$`\gcd(68, 561) = 17`$は、561 の約数になっている。

**誤り確率**: 1 回のテストで合成数を「たぶん素数」と誤判定する確率は、$`a`$をランダムに選ぶと$`1/4`$以下であることが知られている（証明は省く）。$`a`$を変えて$`k`$回繰り返せば$`4^{-k}`$以下になり、64 回なら$`2^{-128}`$以下である。
