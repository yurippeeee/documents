# 11. リード・ソロモン符号 — QR コード・CD・宇宙通信の主役

> **この章の位置づけ.**
> CD や DVD の傷、QR コードの汚れ、探査機ボイジャーからの信号、地上デジタル放送、RAID-6、分散ストレージなどで使われているのが**リード・ソロモン符号**（RS 符号）である。
> 1960 年に MIT リンカーン研究所の Irving Reed と Gustave Solomon が 5 ページの論文で発表した。復号法は Peterson らの方法（1960〜61 年）が先にあったが、計算量が大きく、1968〜69 年にバーレカンプ・マッシー法が現れて実用が広がった。
>
> [10 章 5 節](10_BCH符号.md#bch-符号の実用)で述べたとおり、RS 符号は BCH 符号の符号語の各桁を$`\mathrm{GF}(2^m)`$の要素（$`m`$ビットのかたまり）にしたものである。この章では次の 3 点を順に示す。
>
> 1. 検査に使う桁が$`n-k`$個のとき、最小距離は$`n-k+1`$になる。これは[06 章 4 節](06_誤り訂正の基礎.md#シングルトン限界)のシングルトン限界の等号であり、RS 符号は MDS 符号である（1〜3 節）。
> 2. 受信語から、誤りの位置と値を有限体の四則演算だけで求められる（4・5 節）。
> 3. 誤りを$`m`$ビットのかたまり（実用では 1 バイト）単位で数えるので、連続したビットがまとめて壊れるバースト誤りに強い（6 節）。QR コードはこれらをそのまま使っている（7 節）。

## 1. 構成 — シンボルを GF(2^m) の要素にする

### シンボルと位置

符号語の各桁を$`\mathrm{GF}(2^m)`$の要素とし、これを**シンボル**と呼ぶ。1 シンボルは$`m`$ビットで、実用では$`m = 8`$、つまり 1 シンボルが 1 バイトである。
符号語はシンボルを$`n`$個並べたもので、[09 章 1 節](09_巡回符号とCRC.md#多項式表現)と同じく、$`i`$番目のシンボル$`c_i`$を$`x^i`$の係数とする多項式

$$
c(x) = c_{n-1}x^{n-1} + \cdots + c_1 x + c_0
$$

と同一視する。$`i`$を**位置**と呼ぶ。係数が 0 と 1 ではなく$`\mathrm{GF}(2^m)`$の要素である点が 09・10 章と違う。この章の図では、多項式の書き方に合わせて最高次（位置$`n-1`$）を左に描く。
距離と重みも**シンボル単位**で数える。2 つの語のハミング距離は値が違うシンボルの個数、重みは 0 でないシンボルの個数である（06 章の定義のビットをシンボルに置き換えたもの）。

$`\alpha`$を$`\mathrm{GF}(2^m)`$の原始元とし、符号長を$`n = 2^m - 1`$とする。位置$`i`$には要素$`\alpha^i`$を対応させる（[10 章 4 節](10_BCH符号.md#ステップ-1-シンドロームの計算)の**位置元**）。$`\alpha`$の位数は$`2^m - 1`$なので、$`\alpha^0, \alpha^1, \dots, \alpha^{n-1}`$は 0 以外の要素を 1 回ずつ尽くし、位置と 0 以外の要素がちょうど 1 対 1 に対応する。


符号長をこれより長くしないのは、4 節の復号で、誤りの位置$`i`$を要素$`\alpha^i`$として読み取るからである。異なる位置には異なる要素を割り当てる必要があり、0 以外の要素は$`2^m - 1`$個しかない。

### 生成多項式

訂正したいシンボル数を$`t`$とし、

$$
\boxed{g(x) = \prod_{j=1}^{2t}(x - \alpha^{j}) = (x-\alpha)(x-\alpha^2)\cdots(x-\alpha^{2t})}
$$

を**生成多項式**とする。[10 章 1 節](10_BCH符号.md#bch-限界-bch-bound)の BCH 符号と同じく、連続する$`2t`$個のべき$`\alpha, \alpha^2, \dots, \alpha^{2t}`$を根に持つ。BCH 符号では係数を 0 と 1 にそろえるために最小多項式を掛け合わせたが（10 章 2 節）、RS 符号の係数は$`\mathrm{GF}(2^m)`$の要素でよいので、1 次式$`x - \alpha^j`$をそのまま掛ければよい。標数 2 なので$`-\alpha^j = \alpha^j`$である。

**例**: $`\mathrm{GF}(2^3)`$（[05 章 3 節](05_拡大体GF2m.md#生成元-α-によるべき表現)のべき表、$`\alpha^3 = \alpha + 1`$）で$`t = 2`$とする。根を 2 つずつ組にして掛けると、1 次の係数は 2 つの根の和、定数項は積なので

$$
(x - \alpha)(x - \alpha^2) = x^2 + \alpha^4 x + \alpha^3, \qquad (x - \alpha^3)(x - \alpha^4) = x^2 + \alpha^6 x + 1
$$

である（$`\alpha + \alpha^2 = 010 \oplus 100 = 110 = \alpha^4`$、$`\alpha \cdot \alpha^2 = \alpha^3`$、$`\alpha^3 + \alpha^4 = 011 \oplus 110 = 101 = \alpha^6`$、$`\alpha^3 \cdot \alpha^4 = \alpha^7 = 1`$）。この 2 つを掛けるには、左の因子の各項を右の因子に掛け、同じ次数の列にそろえて足す。

```fig
e11_genpoly
```

結果は

$$
g(x) = x^4 + \alpha^3 x^3 + x^2 + \alpha x + \alpha^3
$$

である。

### 符号語の条件

$`g`$の倍数で次数が$`n`$未満の多項式全体を符号$`C`$とする（[09 章 1 節](09_巡回符号とCRC.md#生成多項式)と同じ形）:

$$
C = \{\, q(x)\,g(x) : q = 0 \text{ または } \deg q < n - 2t \,\}
$$

$`q`$の係数は$`n - 2t`$個を自由に選べ、異なる$`q`$からは異なる符号語ができるので、符号語は$`(2^m)^{n-2t}`$個ある。したがって情報を運ぶシンボルの数は$`k = n - 2t`$、検査に使うシンボルの数は$`n - k = 2t = \deg g`$である。この符号を$`\mathrm{RS}(n, k)`$と書く。検査シンボルの数$`n - k`$は偶数でなくてもよく（7 節の QR コードには 7 個や 13 個の場合がある）、そのときは$`n - k`$個の連続するべきを根にする。この章では訂正能力$`t`$との関係が見やすいように$`n - k = 2t`$とする。
上の例は$`n = 7`$、$`k = 3`$の RS(7,3) で、1〜5 節の計算例はすべてこの符号を使う。

符号語かどうかは、$`g`$の根を代入して判定できる。

**定理（符号語の判定）**: 次数$`n`$未満の多項式$`c(x)`$について

$$
c \in C \iff c(\alpha^j) = 0 \quad (j = 1, 2, \dots, 2t)
$$

**方針**: ⇒ は$`g(\alpha^j) = 0`$から従う。⇐ は、根$`\alpha^j`$を 1 つずつ使って因数定理で 1 次式$`x - \alpha^j`$をくくり出し、最後に$`g`$全体をくくり出す。

**導出**: ⇒: $`c = qg`$なら$`c(\alpha^j) = q(\alpha^j)\,g(\alpha^j) = q(\alpha^j) \cdot 0 = 0`$である。

⇐: [04 章 3 節](04_多項式と既約多項式.md#判定法-低次の場合)の因数定理は、係数が$`\mathrm{GF}(2^m)`$でも同じ議論で成り立つ（$`x - \beta`$で割った余りは定数で、$`x = \beta`$を代入すると商の項が消えて余りだけが残る）。$`c(\alpha) = 0`$なので$`c(x) = (x - \alpha)\,c_1(x)`$と書ける。これに$`x = \alpha^2`$を代入すると

$$
0 = c(\alpha^2) = (\alpha^2 - \alpha)\, c_1(\alpha^2)
$$

である。$`\alpha^2 \neq \alpha`$なので$`\alpha^2 - \alpha \neq 0`$で、体には零因子が無いから$`c_1(\alpha^2) = 0`$となり、再び因数定理で$`c_1(x) = (x - \alpha^2)\,c_2(x)`$と書ける。これを$`\alpha^{2t}`$まで繰り返すと

$$
c(x) = (x-\alpha)(x-\alpha^2)\cdots(x-\alpha^{2t})\,c_{2t}(x) = g(x)\,c_{2t}(x)
$$

となり、$`c`$は$`g`$の倍数、つまり$`c \in C`$である ∎

同じくくり出しを$`x^n + 1`$に使うこともできる。$`(\alpha^j)^n = (\alpha^n)^j = 1`$なので$`\alpha, \dots, \alpha^{2t}`$は$`x^n + 1`$の根であり、$`x^n + 1`$は$`g`$で割り切れる。したがって$`C`$は巡回符号（09 章 1 節）でもある。

## 2. 符号化 — 割り算で検査シンボルを付ける

$`k`$個の**情報シンボル**$`u_0, \dots, u_{k-1}`$を係数とする**情報多項式**$`u(x) = u_{k-1}x^{k-1} + \cdots + u_1 x + u_0`$から、[09 章 2 節](09_巡回符号とCRC.md#符号化-送信側)の CRC と同じ組織符号形式で、送る符号語を

$$
T(x) = x^{2t}u(x) + R(x), \qquad R(x) = x^{2t}u(x) \bmod g(x)
$$

と作る。$`x^{2t}`$を掛けて情報シンボルを上位の位置$`2t, \dots, n-1`$に移し、$`g`$で割った余り$`R`$（次数$`2t`$未満）を下位の位置$`0, \dots, 2t-1`$に置く。最高次から読むと、情報シンボルの後ろに$`2t`$個の**検査シンボル**が付いた形である。
$`x^{2t}u(x) = q(x)g(x) + R(x)`$と書くと$`T = qg + R + R = qg`$（標数 2 なので$`R + R = 0`$）で、09 章と同じく$`T`$は$`g`$で割り切れる。

割り算の手順は[04 章 2 節](04_多項式と既約多項式.md#多項式の除算)の筆算と同じで、最高次の項が消えるように$`g`$の何倍かを引くことを繰り返す。違うのは、引く倍数が 0 か 1 ではなく$`\mathrm{GF}(2^m)`$の要素になることである。$`g`$の最高次の係数は 1 なので、各段で「いまの最高次の係数」を倍数に選べば、最高次がちょうど消える。引き算は足し算と同じで、ビットの XOR である。

**例**: RS(7,3) で、情報シンボルを$`u_2 = \alpha`$、$`u_1 = \alpha^5`$、$`u_0 = \alpha^2`$（ビットで$`010, 111, 100`$）とする。$`x^4 u(x) = \alpha x^6 + \alpha^5 x^5 + \alpha^2 x^4`$を$`g`$で割る筆算は次のとおりである。

```fig
e11_encdiv
```

3 段で$`x^6, x^5, x^4`$の項が順に消え、余りは$`R(x) = x^3 + x^2 + \alpha x + \alpha^2`$である。送る符号語は

$$
T(x) = \alpha x^6 + \alpha^5 x^5 + \alpha^2 x^4 + x^3 + x^2 + \alpha x + \alpha^2
$$

で、1 節の判定どおり$`T(\alpha) = T(\alpha^2) = T(\alpha^3) = T(\alpha^4) = 0`$となる（代入の計算方法は 4 節のステップ 1 で示す）。
以下、$`T(x)`$の$`x^i`$の係数を$`T_i`$と書く。

## 3. 評価としての見方と最小距離

### 多項式の値を並べる

符号語の作り方にはもう 1 つの見方があり、Reed と Solomon の最初の論文はこちらで定義していた。
次数$`k`$未満の多項式$`a(x) = a_{k-1}x^{k-1} + \cdots + a_1 x + a_0`$（係数は$`\mathrm{GF}(2^m)`$の要素）を 1 つ選び、$`x`$に位置の要素$`\alpha^0, \alpha^1, \dots, \alpha^{n-1}`$を代入した値を並べて

$$
c_i = a(\alpha^i) \qquad (i = 0, 1, \dots, n-1)
$$

とする。多項式に要素を代入して値を求めることを**評価**という。$`k`$個の係数$`a_0, \dots, a_{k-1}`$を情報とし、それを$`n`$個の値に広げて送ることになる。

**例**: RS(7,3) で$`a(x) = \alpha^6 x^2 + \alpha^4 x + \alpha^5`$を評価すると、下の図のとおり 2 節の符号語$`T`$と同じシンボルが並ぶ。この$`a`$は、$`a(\alpha^0) = T_0`$、$`a(\alpha) = T_1`$、$`a(\alpha^2) = T_2`$の 3 本を$`a_0, a_1, a_2`$についての連立 1 次方程式とみなし、[03 章 4 節](03_有限体GFp.md#gf-p-上の線形代数-誤り訂正の道具)の掃き出し法で解いて求めた。図は、残りの位置 3〜6 でも値が一致することを確かめている。

```fig
e11_eval
```

この一致は偶然ではない。評価で作った語の全体と 1 節の符号$`C`$は、集合として一致する。これを 2 つの補題から示す。

**補題 1（等比数列の和）**: $`\beta^n = 1`$かつ$`\beta \neq 1`$なら、$`1 + \beta + \beta^2 + \cdots + \beta^{n-1} = 0`$である。

**導出**: 和を$`s`$とすると、$`\beta s = \beta + \beta^2 + \cdots + \beta^n`$なので

$$
(\beta - 1)\,s = (\beta + \beta^2 + \cdots + \beta^{n}) - (1 + \beta + \cdots + \beta^{n-1}) = \beta^n - 1 = 0
$$

である。$`\beta - 1 \neq 0`$で、体には零因子が無いので$`s = 0`$ ∎

**補題 2（根の個数）**: 0 でない次数$`d`$の多項式の根は、$`d`$個以下である。

**導出**: 0 でない次数$`d`$の多項式$`a(x)`$が、異なる$`d + 1`$個の根$`\beta_1, \dots, \beta_{d+1}`$を持つとする。1 節の判定の導出と同じく、$`\beta_1, \dots, \beta_d`$について 1 次式を順にくくり出すと、$`a(x) = (x - \beta_1)\cdots(x - \beta_d)\,b`$となる。次数を比べると$`b`$は 0 でない定数である。$`x = \beta_{d+1}`$を代入すると、どの因子$`\beta_{d+1} - \beta_l`$も$`b`$も 0 でなく、体には零因子が無いので積は 0 にならない。これは$`\beta_{d+1}`$が根であることに反する ∎

**定理（2 つの見方は同じ符号）**: 次数$`k`$未満の多項式$`a`$の評価$`\bigl(a(\alpha^0), a(\alpha^1), \dots, a(\alpha^{n-1})\bigr)`$の全体は、符号$`C`$に一致する。

**方針**: (i) 評価で作った語が 1 節の判定の条件$`c(\alpha^j) = 0`$を満たすことを補題 1 で示し、$`C`$に含まれることを言う。(ii) 評価で作った語が、$`C`$の符号語と同じ個数だけあることを補題 2 で示す。含まれていて個数が同じなら、2 つの集合は一致する。

**導出**: (i) $`c_i = a(\alpha^i) = \sum_{l=0}^{k-1} a_l\,\alpha^{il}`$を$`c(\alpha^j) = \sum_{i=0}^{n-1} c_i\,\alpha^{ij}`$に入れ、足す順番を入れ替えると

$$
c(\alpha^j) = \sum_{i=0}^{n-1}\sum_{l=0}^{k-1} a_l\,\alpha^{il}\,\alpha^{ij} = \sum_{l=0}^{k-1} a_l \sum_{i=0}^{n-1}\left(\alpha^{l+j}\right)^i
$$

となる。$`j = 1, \dots, 2t`$と$`l = 0, \dots, k-1`$の範囲では$`1 \le l + j \le (k-1) + 2t = n - 1`$なので、$`\beta = \alpha^{l+j}`$は 1 ではなく（$`\alpha`$の位数は$`n`$）、$`\beta^n = (\alpha^n)^{l+j} = 1`$である。補題 1 より内側の和は 0 で、$`c(\alpha^j) = 0`$となる。1 節の判定より$`c \in C`$である。

(ii) 異なる$`a, a'`$から同じ語ができたとすると、$`a - a'`$は 0 でない次数$`k - 1`$以下の多項式で、$`n`$個の要素$`\alpha^0, \dots, \alpha^{n-1}`$すべてを根に持つ。補題 2 より根は$`k - 1`$個以下なので、$`n > k - 1`$に反する。よって評価で作った語は$`a`$の選び方と同じ$`(2^m)^k`$個あり、1 節で数えた$`C`$の符号語の個数$`(2^m)^k`$に等しい ∎

2 つの見方で違うのは、情報と符号語の対応のさせ方だけである。2 節の割り算では情報シンボル$`u_i`$がそのまま符号語の上位に現れるが、評価では係数$`a_l`$は符号語の中にそのままの形では現れない。どちらの対応で作っても、送られる符号語の集合は同じ$`C`$である。

### 最小距離 — MDS であること

$`C`$は、符号語どうしの和も符号語の定数倍も$`g`$の倍数なので、線形符号である。[07 章 1 節](07_線形符号.md#線形性がもたらす第一の恩恵-最小距離の計算が激減)より、最小距離は 0 でない符号語の重みの最小値に等しい（07 章は 2 元の符号で示したが、2 つの語が違う位置は差$`c_1 - c_2`$が 0 でない位置なので、シンボル単位でも同じ議論が成り立つ）。

**定理**: RS 符号の最小距離は$`d_{\min} = n - k + 1 = 2t + 1`$である。

**方針**: 評価の見方で、0 でない符号語の中の 0 の個数を数える。0 になる位置は$`a`$の根の位置なので、補題 2 で個数を上から押さえられる。

**導出**: 0 でない符号語$`c`$は、0 でない次数$`k - 1`$以下の多項式$`a`$の評価である（上の定理）。$`c_i = 0`$となるのは$`\alpha^i`$が$`a`$の根のときなので、補題 2 より 0 の個数は$`k - 1`$以下、重みは$`n - (k - 1) = n - k + 1`$以上である。よって$`d_{\min} \ge n - k + 1`$。
等号になる符号語もある。異なる$`k - 1`$個の位置$`i_1, \dots, i_{k-1}`$を選んで$`a(x) = (x - \alpha^{i_1})\cdots(x - \alpha^{i_{k-1}})`$とすると、補題 2 より$`a`$の根はこの$`k-1`$個だけなので、符号語はちょうどこれらの位置で 0 になり、重みは$`n - k + 1`$である。したがって$`d_{\min} = n - k + 1`$ ∎

**例**: RS(7,3) で$`a(x) = (x - \alpha^2)(x - \alpha^5) = x^2 + \alpha^3 x + 1`$とすると、位置 2 と 5 だけが 0 になり、重みは$`7 - 3 + 1 = 5`$である（下の図の下段）。上段の$`T`$を作る$`a`$は位置の要素を根に持たないので、0 が無く重みは 7 である。

```fig
e11_minweight
```

$`d_{\min} = n - k + 1`$はシングルトン限界$`d_{\min} \le n - k + 1`$（[06 章 4 節](06_誤り訂正の基礎.md#シングルトン限界)）の等号なので、RS 符号は MDS 符号である。検査シンボルを 1 個増やすごとに最小距離が 1 ずつ増え、同じ$`n, k`$でこれより大きな最小距離は作れない。
なお、[10 章 1 節](10_BCH符号.md#bch-限界-bch-bound)の BCH 限界の証明（ヴァンデルモンド行列式）も、符号語の係数が 0 と 1 に限らず$`\mathrm{GF}(2^m)`$の要素でもそのまま成り立ち、$`d_{\min} \ge 2t + 1`$を与える。

### 訂正能力 — 誤りは t 個、消失は 2t 個

$`d_{\min} = 2t + 1`$と 06 章の結果から、次の 3 つが分かる。

- 位置の分からない**誤り**: $`\lfloor (d_{\min} - 1)/2 \rfloor = t = (n-k)/2`$シンボルまで訂正できる（[06 章 3 節](06_誤り訂正の基礎.md#定理)）。
- 位置が分かっていて値だけが分からない**消失**: $`d_{\min} - 1 = n - k = 2t`$シンボルまで復元できる（[06 章 6 節](06_誤り訂正の基礎.md#消失は誤りの約-2-倍直せる)）。
- 誤り$`\nu`$個と消失$`\rho`$個が混ざる場合: $`2\nu + \rho \le n - k`$なら訂正できる。

3 つ目は 06 章の 2 つの議論を組み合わせて示せる。消失した$`\rho`$か所を除いた残りの位置だけを見ると、異なる 2 つの符号語は$`d_{\min} - \rho`$か所以上で違う（06 章 6 節の導出と同じ）。残りの部分で$`\nu`$個の誤りを訂正できる条件は、06 章 3 節より$`2\nu + 1 \le d_{\min} - \rho`$、すなわち$`2\nu + \rho \le d_{\min} - 1 = n - k`$である。

4 節の復号では、検査シンボル$`n - k = 2t`$個に対応して$`2t`$個の値（シンドローム）が得られ、それを右辺とする式を解く。位置の分からない誤り 1 個は「位置」と「値」の 2 つが未知なので式を 2 本使い、消失は位置が分かっているので「値」の 1 本で済む。上の 3 つの条件は、未知数の個数が式の本数以下という条件と同じ形をしている。

```fig
e11_capacity
```

評価の見方では、消失の上限がさらに直接に読める。消失していない$`k`$個の位置の値から、上の例と同じ連立方程式で$`a`$が決まる。$`a`$がもう 1 つあれば、差が$`k`$個の根を持つ次数$`k - 1`$以下の多項式になり、補題 2 に反するので、$`a`$はただ 1 つである。この$`a`$を評価し直せば、消えた$`n - k`$個のシンボルが分かる。

### 短縮符号

実際の規格では$`n = 2^m - 1`$より短い RS 符号がよく使われる（6 節の CD の RS(32,28)、7 節の QR コードの RS(26,16) など）。これは元の符号の符号語のうち、上位の情報シンボルのいくつかを常に 0 とした**短縮符号**（[08 章 4 節](08_ハミング符号.md#拡張ハミング符号-secded)）である。0 と決めた位置は送らず、受信側は 0 があるものとして復号する。

```fig
e11_shorten
```

短縮した符号語は元の符号の符号語でもあるので、最小距離は元の$`2t + 1`$以上である。検査シンボルは$`2t`$個のままなので、短縮後の長さを$`n'`$、情報シンボル数を$`k'`$とすると、シングルトン限界から$`d_{\min} \le n' - k' + 1 = 2t + 1`$でもある。したがって最小距離はちょうど$`2t + 1`$で、短縮しても訂正能力$`t`$は変わらず、MDS のままである。

## 4. 復号アルゴリズム（この章の本体）

受信語を$`r(x) = c(x) + e(x)`$と書く。$`c`$は送った符号語、$`e`$は**誤りパターン**で

$$
e(x) = \sum_{l=1}^{\nu} Y_l\, x^{i_l}
$$

である。$`\nu`$は誤りの個数、$`i_l`$は誤った位置、$`Y_l`$はその位置のシンボルに足された 0 でない値で、**誤り値**と呼ぶ。受信者が知っているのは$`r`$だけで、$`e`$を求めて$`c = r - e`$と訂正するのが復号である。
流れは[10 章 4 節](10_BCH符号.md#復号の流れ)の BCH 符号と同じで、誤り値が 1 とは限らない点だけが違う。次の 5 段で進める。

```fig
e11_decflow
```

**例（この節を通して使う）**: 2 節の符号語$`T`$を送り、位置 1 に$`\alpha^5`$、位置 5 に$`\alpha^4`$の誤りが加わったとする。

```fig
e11_received
```

位置 1 は$`\alpha + \alpha^5 = 010 \oplus 111 = 101 = \alpha^6`$、位置 5 は$`\alpha^5 + \alpha^4 = 111 \oplus 110 = 001 = 1`$に変わり、受信語は

$$
r(x) = \alpha x^6 + x^5 + \alpha^2 x^4 + x^3 + x^2 + \alpha^6 x + \alpha^2
$$

である。$`r(x)`$の$`x^i`$の係数を$`r_i`$と書く。$`\nu = 2 = t`$なので、訂正できるはずである。

### ステップ 1: シンドローム計算

$$
S_j = r(\alpha^j) \qquad (j = 1, 2, \dots, 2t)
$$

を**シンドローム**とする。1 節の判定より$`c(\alpha^j) = 0`$なので

$$
S_j = c(\alpha^j) + e(\alpha^j) = e(\alpha^j) = \sum_{l=1}^{\nu} Y_l\, (\alpha^{i_l})^j = \sum_{l=1}^{\nu} Y_l\, X_l^j, \qquad X_l = \alpha^{i_l}
$$

である。$`X_l`$は誤り位置$`i_l`$の位置元で、$`X_l`$が分かれば$`i_l`$が分かる。シンドロームは送った符号語によらず誤りパターンだけで決まり、[07 章 4 節](07_線形符号.md#シンドローム-誤りの-指紋)のシンドロームと同じ役割を持つ。
すべて 0 なら誤り無しとして終了する。誤りパターン自体が 0 でない符号語のときも 0 になるが、それは$`d_{\min} = 2t+1`$個以上のシンボルが壊れた場合で、検出できない。
2 元 BCH 符号では$`S_{2j} = S_j^2`$が成り立ったが（10 章 4 節）、RS 符号では$`Y_l`$が 1 とは限らないので成り立たず、$`2t`$個すべてを計算する。

**例**: 受信側は$`r(\alpha^j)`$を**ホーナー法**で計算する。$`r(x)`$を

$$
r(x) = \Bigl(\cdots\bigl((r_6\,x + r_5)\,x + r_4\bigr)\,x + \cdots + r_1\Bigr)\,x + r_0
$$

とくくり直し、最高次の係数から順に「$`\alpha^j`$を掛けて、次の係数を足す」を繰り返す。掛け算は$`n - 1`$回で済む。

```fig
e11_horner
```

結果は$`S_1 = 1`$、$`S_2 = 0`$、$`S_3 = \alpha^6`$、$`S_4 = \alpha^5`$である。検算として、誤りパターン$`e(x) = \alpha^4 x^5 + \alpha^5 x`$に代入しても同じ値になる（$`\alpha^7 = 1`$なので指数は 7 で割った余り）:

| $`j`$ | $`\alpha^5 \cdot \alpha^{j}`$ | $`\alpha^4 \cdot \alpha^{5j}`$ | $`S_j`$ |
|---|---|---|---|
| 1 | $`\alpha^6 = 101`$ | $`\alpha^9 = \alpha^2 = 100`$ | $`001 = 1`$ |
| 2 | $`\alpha^7 = 001`$ | $`\alpha^{14} = 1 = 001`$ | $`000 = 0`$ |
| 3 | $`\alpha^8 = \alpha = 010`$ | $`\alpha^{19} = \alpha^5 = 111`$ | $`101 = \alpha^6`$ |
| 4 | $`\alpha^9 = \alpha^2 = 100`$ | $`\alpha^{24} = \alpha^3 = 011`$ | $`111 = \alpha^5`$ |

$`S_1^2 = 1 \neq 0 = S_2`$で、確かに$`S_2 = S_1^2`$は成り立っていない。

### ステップ 2: 誤り位置多項式 Λ(x) を求める

$$
\Lambda(x) = \prod_{l=1}^{\nu}(1 - X_l x) = 1 + \Lambda_1 x + \cdots + \Lambda_\nu x^\nu
$$

を**誤り位置多項式**という（10 章 4 節）。右辺の$`\Lambda_1, \dots, \Lambda_\nu`$は、左辺の積を展開して$`x`$のべきごとにまとめた係数である。たとえば$`\Lambda_1 = -(X_1 + \cdots + X_\nu)`$、$`\Lambda_\nu = (-1)^\nu X_1 \cdots X_\nu`$で、標数 2 では符号は関係ない。
因子$`1 - X_l x`$は$`x = X_l^{-1}`$のときに限って 0 になるので、$`\Lambda`$の根は位置元の逆数$`X_l^{-1}`$であり、根が分かれば誤り位置が分かる（ステップ 3）。例の誤り位置で作ると次のようになる。

```fig
e11_lambda
```

受信者はまだ$`X_l`$も$`\nu`$も知らないので、係数$`\Lambda_1, \dots, \Lambda_\nu`$をシンドロームから求めるのがこのステップの目的である。[10 章 4 節](10_BCH符号.md#ステップ-1-シンドロームの計算)では未知数を$`X_l, Y_l`$の$`2\nu`$個と数えたが、ここではまず位置の情報だけを$`\Lambda`$の係数$`\nu`$個として求め、値$`Y_l`$はステップ 4 で別に求める。

**シンドロームと$`\Lambda`$の係数の関係式**:

**方針**: $`\Lambda(X_l^{-1}) = 0`$の両辺に$`Y_l X_l^{j+\nu}`$を掛けて$`l`$について足すと、$`Y_l X_l^{(\text{何か})}`$の和、つまりシンドロームが現れる。

**導出**: 各$`l`$について$`\Lambda(X_l^{-1}) = 1 + \Lambda_1 X_l^{-1} + \cdots + \Lambda_\nu X_l^{-\nu} = 0`$である。両辺に$`Y_l X_l^{j+\nu}`$を掛けて$`l = 1, \dots, \nu`$について足すと

$$
\sum_{l} Y_l X_l^{j+\nu}\left(1 + \Lambda_1 X_l^{-1} + \cdots + \Lambda_\nu X_l^{-\nu}\right) = 0
$$

$`\Lambda_i X_l^{-i}`$の項は$`\Lambda_i Y_l X_l^{j+\nu-i}`$になり、$`l`$について足すとステップ 1 の式から$`\Lambda_i S_{j+\nu-i}`$である。添字$`j + \nu - i`$は$`j`$から$`j + \nu`$の範囲にあるので、$`1 \le j`$かつ$`j + \nu \le 2t`$なら計算済みのシンドロームだけで書ける。よって

$$
\boxed{S_{j+\nu} + \Lambda_1 S_{j+\nu-1} + \cdots + \Lambda_\nu S_j = 0} \qquad (j = 1, \dots, 2t - \nu)
$$

である。$`\nu \le t`$なら$`2t - \nu \ge \nu`$なので式は$`\nu`$本以上あり、$`j = 1, \dots, \nu`$の$`\nu`$本は、未知数$`\Lambda_1, \dots, \Lambda_\nu`$の$`\nu`$個についての連立 1 次方程式である ∎

[03 章 4 節](03_有限体GFp.md#gf-p-上の線形代数-誤り訂正の道具)の掃き出し法は$`\mathrm{GF}(p)`$で示したが、使ったのは「割り算は逆元を掛けること」だけなので、$`\mathrm{GF}(2^m)`$でもそのまま使える。誤り訂正の中心は、有限体上の連立 1 次方程式を解くことである。
$`\nu`$は分からないので、掃き出し法で解くときは$`\nu = t, t-1, \dots`$と仮定し、係数行列の行列式が 0 でない最大の$`\nu`$を採る（誤りが仮定より少ないと$`\Lambda`$の候補が 1 つに決まらず、行列式が 0 になる）。

**例**: $`\nu = 2`$とすると、$`j = 1, 2`$の式は

$$
S_3 + \Lambda_1 S_2 + \Lambda_2 S_1 = 0, \qquad S_4 + \Lambda_1 S_3 + \Lambda_2 S_2 = 0
$$

で、$`S_1 = 1`$、$`S_2 = 0`$、$`S_3 = \alpha^6`$、$`S_4 = \alpha^5`$を入れると

$$
\alpha^6 + \Lambda_2 = 0, \qquad \alpha^5 + \alpha^6 \Lambda_1 = 0
$$

となる。1 本目から$`\Lambda_2 = \alpha^6`$、2 本目から$`\Lambda_1 = \alpha^5 / \alpha^6 = \alpha^{-1} = \alpha^6`$。よって$`\Lambda(x) = 1 + \alpha^6 x + \alpha^6 x^2`$で、上の図で正解から作った$`\Lambda`$と一致する。係数行列の行列式は$`S_2 \cdot S_2 - S_1 S_3 = 0 - \alpha^6 = \alpha^6 \neq 0`$なので、$`\nu = 2`$の仮定でよい。

### バーレカンプ・マッシー法

上の連立方程式を掃き出し法で解くと、計算量は$`t^3`$に比例する（$`O(t^3)`$と書く）。これより速い方法がある。
関係式を$`S_{j+\nu} = -(\Lambda_1 S_{j+\nu-1} + \cdots + \Lambda_\nu S_j)`$と書くと、「直前の$`\nu`$個の値の決まった組み合わせで次の値が決まる」という漸化式になっている。このような漸化式で数列を作る装置を**線形帰還シフトレジスタ（LFSR）**という（[13 章 2 節](13_ストリーム暗号とLFSR.md#lfsr-線形帰還シフトレジスタ)で詳しく扱う。13 章は係数が$`\mathrm{GF}(2)`$の場合だが、$`\mathrm{GF}(2^m)`$でも構造は同じである）。

```fig
e11_lfsr
```

「$`S_1, S_2, \dots, S_{2t}`$を作り出す最も短い LFSR（最小の$`\nu`$とその係数）を求める」問題と読み替えると、$`O(t^2)`$で解ける。これが**バーレカンプ・マッシー法**である。

**手順**（正しさの証明は省く）: 現在の LFSR の長さを$`L`$とし、$`\Lambda(x) = 1`$、$`L = 0`$から始める。補正に使う多項式$`B(x) = 1`$と、それに付随する値$`\Delta_B = 1`$、$`j_B = 0`$も用意する。$`j = 1, 2, \dots, 2t`$の順に次を行う。

1. 現在の$`\Lambda`$で$`S_j`$を予測したときのずれ$`\Delta = S_j + \Lambda_1 S_{j-1} + \cdots + \Lambda_L S_{j-L}`$を計算する。$`\Delta = 0`$なら予測が当たっているので、何もせず次の$`j`$へ進む。
2. $`\Delta \neq 0`$なら$`\Lambda(x) \leftarrow \Lambda(x) - \dfrac{\Delta}{\Delta_B}\, x^{j - j_B} B(x)`$と補正する。$`B`$は前に長さを変えたときの$`\Lambda`$で、そのとき$`j_B`$番目で$`\Delta_B`$のずれを出していた。$`x^{j - j_B}`$でずらして$`\Delta/\Delta_B`$倍すると、$`j`$番目でちょうど$`\Delta`$のずれを出す多項式になるので、引けばずれが消える。
3. 2 を行ったとき、$`2L \le j - 1`$なら今の長さでは足りないので、補正する前の$`\Lambda`$を$`B`$に、$`\Delta`$を$`\Delta_B`$に、$`j`$を$`j_B`$に保存し、$`L \leftarrow j - L`$とする。

最後の$`\Lambda`$が誤り位置多項式で、$`L`$が誤りの個数である。

**例**: $`S_1, \dots, S_4 = 1, 0, \alpha^6, \alpha^5`$で 4 回まわすと次のようになる。

```fig
e11_bm
```

$`j = 2`$の後の$`\Lambda(x) = 1`$、$`L = 1`$は、$`\Lambda_1 = 0`$の長さ 1 の LFSR を表す。初期値$`S_1 = 1`$の後に$`0 \cdot S_1 = 0`$を出すので、$`S_1, S_2 = 1, 0`$を作れている。$`j = 3`$で長さ 1 では$`S_3 = \alpha^6`$を作れないと分かり、長さを 2 に増やす。最後の$`\Lambda`$は連立方程式で求めたものと一致する。
なお、同じ$`\Lambda(x)`$は、多項式版の拡張ユークリッドの互除法（[04 章 5 節](04_多項式と既約多項式.md#最大公約多項式とユークリッドの互除法)）を$`x^{2t}`$と$`S(x)`$（ステップ 4 で定義する）に使っても求められる（1975 年の杉山らの方法）。この章では扱わない。

同じ LFSR は[13 章](13_ストリーム暗号とLFSR.md#lfsr-線形帰還シフトレジスタ)のストリーム暗号にも現れる。暗号では LFSR で数列を作り、誤り訂正では数列から LFSR を推定する。短い LFSR で作れてしまう数列は推定されやすいので、暗号にとっては弱点になる（13 章 3 節）。

### ステップ 3: チェン探索（誤り位置の特定）

$`\Lambda(x) = 0`$の根を、$`x = \alpha^{-i}`$（$`i = 0, 1, \dots, n-1`$）を順に代入して探す（10 章 4 節の**チェン探索**）。$`\Lambda(\alpha^{-i}) = 0`$なら$`\alpha^{-i}`$が$`X_l^{-1}`$のどれかなので$`X_l = \alpha^i`$、すなわち位置$`i`$が誤りである。
候補は$`n`$個で、1 つあたり$`\Lambda`$の計算は$`\nu`$回程度の掛け算なので、合計の計算量は$`O(nt)`$である。ハードウェアでは全位置を同時に調べられる。

**例**: 7 個の位置すべてで$`\Lambda(\alpha^{-i}) = 1 + \alpha^6 \alpha^{-i} + \alpha^6 \alpha^{-2i}`$を計算すると、下の図のとおり 0 になるのは位置 1 と 5 だけである。見つかった根の個数 2 は$`\Lambda`$の次数$`L = 2`$と一致している。

### ステップ 4: フォニー・アルゴリズム（誤り値の計算）

$`\Lambda`$には誤りの位置しか入っていない。値$`Y_l`$を求めるには、$`Y_l`$を含むシンドロームと$`\Lambda`$を組み合わせる。
シンドロームを多項式$`S(x) = \sum_{j=1}^{2t}S_j x^{j-1}`$にまとめ、**誤り評価多項式**を

$$
\Omega(x) = \left[S(x)\Lambda(x)\right] \bmod x^{2t}
$$

と定める（「評価」は誤りの値を求めるという意味で、3 節の評価とは別の用語である）。$`\bmod x^{2t}`$は、積のうち$`x^{2t}`$未満の項だけを残すことである。このとき誤り値は

$$
\boxed{Y_l = -\frac{\Omega(X_l^{-1})}{\Lambda'(X_l^{-1})}}
$$

で求まる。標数 2 では$`-Y_l = Y_l`$なので、符号は気にしなくてよい。

$`\Lambda'`$は**形式的微分**で、各項の$`x^s`$を$`s\,x^{s-1}`$に置き換えたものである。極限で定義する微分ではなく、係数の書き換え規則として定める。単項式どうしでは$`x^s x^u = x^{s+u}`$について$`(s+u)x^{s+u-1} = s x^{s-1}\cdot x^u + x^s \cdot u x^{u-1}`$が成り立ち、多項式は単項式の和なので、積の微分の公式$`(AB)' = A'B + AB'`$はこの規則からも成り立つ。
係数の$`s`$は「1 を$`s`$個足したもの」なので、標数 2 では$`s`$が偶数の項は 0 になって消え、奇数次の項だけが残る。

**方針**: $`S(x)`$を$`X_l, Y_l`$で書き、$`\Lambda`$を掛けると等比数列の和が現れて簡単になることを使う。$`x = X_l^{-1}`$を代入すると、$`\Omega`$と$`\Lambda'`$のどちらも$`l`$番目の項だけが残る。

**導出**: ステップ 1 の$`S_j = \sum_l Y_l X_l^j`$を$`S(x)`$に入れると

$$
S(x) = \sum_{l} Y_l X_l \sum_{j=0}^{2t-1} (X_l x)^j
$$

これに$`\Lambda(x) = \prod_p (1 - X_p x)`$を掛ける。$`l`$番目の項には因子$`(1 - X_l x)`$が含まれ、等比数列の和の公式から$`(1 - X_l x)\sum_{j=0}^{2t-1}(X_l x)^j = 1 - (X_l x)^{2t}`$なので

$$
S(x)\Lambda(x) = \sum_l Y_l X_l \prod_{p\neq l}(1 - X_p x) \;-\; \sum_l Y_l X_l (X_l x)^{2t}\prod_{p \neq l}(1 - X_p x)
$$

となる。2 つ目の和の項はすべて$`x^{2t}`$以上の次数である。1 つ目の和は次数$`\nu - 1`$以下で、$`\nu \le t`$（5 節の消失を含めても$`2t`$以下）なので、すべて$`x^{2t}`$未満の項である。したがって$`\bmod x^{2t}`$で残るのは 1 つ目の和だけで

$$
\Omega(x) = \sum_l Y_l X_l \prod_{p\neq l}(1-X_px)
$$

である。$`x = X_l^{-1}`$を代入すると、$`l`$以外の項は因子$`(1 - X_l X_l^{-1}) = 0`$を含むので消え、$`\Omega(X_l^{-1}) = Y_l X_l \prod_{p \neq l}(1 - X_p X_l^{-1})`$となる。
一方$`\Lambda(x) = \prod_p(1 - X_p x)`$を積の微分の公式で微分すると$`\Lambda'(x) = \sum_l (-X_l)\prod_{p \neq l}(1 - X_p x)`$で、$`x = X_l^{-1}`$を入れると同じ理由で 1 項だけ残り、$`\Lambda'(X_l^{-1}) = -X_l \prod_{p\neq l}(1-X_pX_l^{-1})`$となる。
割ると$`X_l`$と$`\prod`$が約分されて$`\Omega(X_l^{-1}) / \Lambda'(X_l^{-1}) = -Y_l`$である ∎

**例**: $`S(x) = 1 + 0 \cdot x + \alpha^6 x^2 + \alpha^5 x^3`$と$`\Lambda(x) = 1 + \alpha^6 x + \alpha^6 x^2`$の積を、$`x^3`$の項まで下の図の表で求めると$`\Omega(x) = 1 + \alpha^6 x`$である。$`\Lambda'(x) = \alpha^6`$で、$`\alpha^6 x^2`$の項は$`2\alpha^6 x = 0`$となって消える。

```fig
e11_forney
```

加えた誤り値$`\alpha^5`$、$`\alpha^4`$と一致した。

### ステップ 5: 訂正

$$

$$

体$`\mathrm{GF}(2^m)`$では引き算は足し算と同じで、ビットの XOR である。

**例**: 位置 1 は$`\alpha^6 + \alpha^5 = 101 \oplus 111 = 010 = \alpha`$、位置 5 は$`1 + \alpha^4 = 001 \oplus 110 = 111 = \alpha^5`$となり、送った$`T`$に戻る。

### 訂正能力を超えた誤り

$`\nu > t`$のときは、手順がどこかで矛盾するか、別の符号語に「訂正」してしまう。

- **失敗を検出できる場合**: バーレカンプ・マッシー法の$`L`$が$`t`$を超える、またはチェン探索で見つかった根の個数が$`L`$と一致しない。このときは訂正せず、訂正できない誤りがあったと報告する。
- **誤訂正**: 受信語が、送った符号語とは別の符号語から距離$`t`$以内にあると、手順は矛盾なく終わり、その別の符号語を出力する。受信者には区別できない（[08 章 2 節](08_ハミング符号.md#ビット誤りでは誤訂正が起きる)の誤訂正と同じ）。

例の 2 個の誤りに、残り 5 か所のどれかへ 3 個目の誤り（値は 7 通り）を加える 35 通りを調べると、32 通りは失敗を検出し、3 通りは誤訂正になる。下の図はそれぞれの例である。

```fig
e11_overcap
```

下の図で誤りの位置と値を変えると、シンドローム、バーレカンプ・マッシー法の各回、チェン探索、フォニー・アルゴリズムの値と訂正の結果が表示される。符号は$`\mathrm{GF}(2^4)`$上の RS(15,11)（$`t = 2`$）と RS(15,9)（$`t = 3`$）にも切り替えられる。

## 5. 消失訂正 — 位置が分かっている場合

ディスクの故障（どのディスクが壊れたかは分かる）や、前段の復号器が「この位置は怪しい」と印を付けた場合（6 節の CD）のように、壊れた位置が分かっていることがある。これが**消失**である。

位置$`i_l`$が最初から分かっているなら、4 節のステップ 2 と 3 は要らない。読めないシンボルを 0 とみなして受信語を作ると、消失した位置の誤り値は元のシンボルそのものになる。$`\Lambda(x) = \prod_l (1 - \alpha^{i_l} x)`$を位置から直接作り、ステップ 1 のシンドロームとステップ 4 のフォニー・アルゴリズムで値を求めればよい。フォニー・アルゴリズムの導出は、$`\Lambda`$の次数が$`2t`$以下なら成り立つ。
未知数は値だけなので、$`2t = n - k`$個までの消失を復元できる。3 節で述べた「消失は誤りの 2 倍」の上限を、実際に達成する手順である。

**例**: 2 節の符号語$`T`$で、位置 3〜6 の 4 シンボル（情報シンボル 3 個すべてと、検査シンボル 1 個）が読めなかったとする。

```fig
e11_erasure
```

4 個の消失は上限の$`n - k = 4`$個で、位置の分からない誤りなら 2 個までしか直せないことと比べると 2 倍である。情報シンボルが 1 つも残っていなくても、検査シンボル 3 個と位置の情報から元に戻る。

**誤りと消失が混ざる場合**: 消失の位置から作った多項式を$`\Gamma(x)`$、未知の誤りの位置多項式を$`\Lambda(x)`$とし、積$`\Psi(x) = \Lambda(x)\Gamma(x)`$を全体の位置多項式とする。$`\Psi`$の根は誤りと消失の両方の位置を表すので、4 節のステップ 2 の関係式は$`\Psi`$について成り立つ。$`\Psi`$の次数は$`\nu + \rho`$なので、式は$`2t - (\nu + \rho)`$本ある。$`\Gamma`$は分かっているので、未知数は$`\Lambda`$の係数$`\nu`$個であり、式が足りる条件$`2t - (\nu + \rho) \ge \nu`$は$`2\nu + \rho \le 2t = n - k`$で、3 節の条件と一致する。$`\Lambda`$が求まれば、$`\Psi`$を使ってステップ 3〜5 を行う。実装では、$`\Gamma`$を掛けたシンドロームにバーレカンプ・マッシー法を使って$`\Lambda`$を求めることが多い。

下の図で各位置を「正常・消失・誤り」に切り替えると、$`2\nu + \rho`$と、復号の各段の値と結果が表示される。

## 6. バースト誤りとインターリーブ

### シンボル単位で数える利点

RS 符号はシンボル（1 バイト）単位で誤りを数える。1 バイトの中で 1 ビット壊れても 8 ビット全部壊れても、どちらも「1 シンボルの誤り」である。
長さ$`b`$ビットのバースト誤りがまたぐバイト数は、始まる位置によって変わる。最も多くなるのは、バイトの最後のビットから始まる場合である。

```fig
e11_burstbytes
```

最悪の場合は、最初のバイトの 1 ビットと、残り$`b - 1`$ビットがまたぐ$`\lceil (b-1)/8 \rceil`$バイトなので、合計$`\lceil (b-1)/8 \rceil + 1`$バイトである（$`\lceil \cdot \rceil`$は切り上げ、[06 章 3 節](06_誤り訂正の基礎.md#導出-2-訂正能力)）。
たとえば RS(255,223)（$`t = 16`$）では、$`\lceil (b-1)/8 \rceil + 1 \le 16`$となる$`b \le 121`$なら、どこで起きても必ず訂正できる。バイトの境界にそろっていれば 128 ビット（16 バイト）まで訂正できる。

各ビットを独立に扱う 2 元 BCH 符号で同じ長さのバーストを必ず訂正するには、121 ビットの訂正能力が要る。ほぼ同じ長さ（2047 ビット）の BCH 符号で$`t = 121`$にすると、検査ビットは 1155 ビットになり、RS(255,223) の 256 ビット（32 バイト）の約 4.5 倍である。

```fig
e11_rsbch
```

BCH 符号はばらばらの位置の 121 ビットも直せるので、比べているのは能力の違う符号である。誤りが固まって起きるという現実の性質に合わせて、シンボル単位で数えることで少ない検査で済ませているのが RS 符号である。

### インターリーブとの組み合わせ

さらに長いバーストに対応するため、複数の符号語のシンボルを交互に並べて送る（**インターリーブ**、[06 章 6 節](06_誤り訂正の基礎.md#インターリーブ-バーストを分散させる)）。並べる符号語の数（深さ）を$`D`$とすると、長さ$`B`$シンボルのバーストが 1 つの符号語に届くのは$`\lceil B/D \rceil`$シンボル以下である（06 章 6 節と同じ理由）。

```fig
e11_interleave
```

RS(255,223) を深さ 4 でインターリーブすると、64 バイトまでのバーストは各符号語に 16 シンボル以下ずつ届くので、すべて訂正できる。ビットで言えば$`\lceil (b-1)/8 \rceil + 1 \le 64`$、つまり 505 ビットまで、どこで起きても訂正できる。

下の図でバーストの長さ・開始位置とインターリーブの深さを変えると、各符号語に届くシンボル誤りの数が表示される。

### CD の CIRC

CD の**CIRC**（Cross-Interleaved Reed-Solomon Code）は、2 つの RS 符号とインターリーブを組み合わせ、さらに 5 節の消失訂正を使う方式である。

```fig
e11_circ
```

- **書き込み側**: 24 バイトの音声データに RS(28,24)（C2）で 4 バイトの検査シンボルを付ける。その 28 バイトを、バイトごとに異なる時間だけ遅らせて散らし（インターリーブ）、RS(32,28)（C1）でさらに 4 バイトの検査シンボルを付けて記録する。どちらも RS(255,251) の短縮符号（3 節）である。
- **読み出し側**: 典型的な復号では、まず C1 で少数の誤りを訂正し、訂正しきれない符号語はそのシンボルに消失の印を付けて渡す。遅れを元に戻して並べ直すと、C2 の各符号語には消失が少しずつ散らばって届くので、C2 は消失訂正で 4 個まで復元できる。

この組み合わせで、約 4000 ビットの連続した誤りを訂正できるとされる。ディスク上では約 2.5 mm の傷に相当する。

## 7. 実例: QR コードの RS 符号

QR コードは$`\mathrm{GF}(2^8)`$を既約多項式$`x^8+x^4+x^3+x^2+1`$（係数を並べたビット列$`1\,0001\,1101`$を 16 進で書いて 0x11D）で作り、原始元$`\alpha = x`$（ビット$`00000010`$）を使う。この多項式が原始多項式であることは[05 章 3 節](05_拡大体GF2m.md#実務の例-リード-ソロモン-qr-コード-の-gf-28)で述べた。1 シンボルは 1 バイトである。QR コードの規格では 1 バイトのシンボルを「コードワード」と呼ぶが、この章では引き続きシンボルと呼ぶ。

### 生成多項式は α⁰ から

QR コードの生成多項式は、根を$`\alpha^0 = 1`$から取る:

$$
g(x) = \prod_{j=0}^{n-k-1}(x - \alpha^j) = (x - 1)(x - \alpha)\cdots(x - \alpha^{n-k-1})
$$

1 節では根を$`\alpha^1`$から取ったが、根が連続する$`n - k`$個のべきであれば性質は変わらない。3 節の評価の見方は$`c_i = \alpha^i a(\alpha^i)`$と$`\alpha^i`$が 1 つ掛かった形になり（導出の$`\alpha^{l+j}`$が$`\alpha^{l+1+j}`$に変わるだけで、$`1 \le l + 1 + j \le n - 1`$は同じく成り立つ）、0 になる位置は$`a`$の根の位置だけなので、最小距離は同じ$`n - k + 1`$である。
復号では、シンドロームを$`S_j = r(\alpha^j)`$（$`j = 0, \dots, n-k-1`$）とし、$`S(x) = \sum_{j=0}^{n-k-1} S_j x^j`$とする。4 節の導出で$`S(x)`$の各項から$`X_l`$が 1 つ減るので、フォニー・アルゴリズムの式は$`Y_l = -X_l\,\Omega(X_l^{-1})/\Lambda'(X_l^{-1})`$になる。ほかの手順は同じである。

検査シンボルが 10 個のときの生成多項式は、係数を$`\alpha`$のべきで書くと

$$
g(x) = x^{10} + \alpha^{251}x^9 + \alpha^{67}x^8 + \alpha^{46}x^7 + \alpha^{61}x^6 + \alpha^{118}x^5 + \alpha^{70}x^4 + \alpha^{64}x^3 + \alpha^{94}x^2 + \alpha^{32}x + \alpha^{45}
$$

である。

### 例: バージョン 1-M の "HELLO WORLD"

最小のバージョン 1（21 × 21 モジュール）は 26 シンボルを運ぶ。誤り訂正レベル M では情報シンボル 16 個と検査シンボル 10 個で、RS(255,245) を短縮した RS(26,16) を使う。
"HELLO WORLD" を英数字モードで符号化した情報シンボルは、モードを表す 4 ビット、文字数 9 ビット、2 文字ずつ 11 ビットにまとめた文字の値、終端の 0 を並べてバイトに区切り、余りを埋め草のバイト 236, 17 の繰り返しで埋めたものである。これを$`u(x)`$とし（最初のシンボルが最高次）、2 節と同じく$`x^{10}u(x)`$を$`g`$で割った余りが検査シンボルになる。

```fig
e11_qrcw
```

### シンボルの配置と誤り訂正レベル

26 個のシンボルは、各 8 ビットが 8 個のモジュール（白黒のマス）になって、右下から 2 列ずつ上下に折り返しながら置かれる。位置検出パターン（3 つの角の大きな四角）、タイミングパターン、形式情報のモジュールは避けて置く。実際の白黒は、偏りを避けるため決まった模様との XOR（マスク）を掛けてから置くが、どのモジュールがどのシンボルに属するかは変わらない。

```fig
e11_qrmap
```

形式情報（誤り訂正レベルなど）は[10 章 5 節](10_BCH符号.md#bch-符号の実用)の BCH(15,5) 符号で守られ、2 か所に同じものが置かれている。位置検出パターンとタイミングパターンは RS 符号では守られない。特に位置検出パターンを隠すと、シンボルの位置や向きが分からなくなり、読み取りに失敗しやすい。

誤り訂正レベルは 4 段階あり、同じバージョンでも情報と検査の配分が変わる。バージョン 1 の値は次のとおりである。

| レベル | 復元できる割合（規格が示すおよその値） | 情報シンボル | 検査シンボル | RS 符号としての$`t = \lfloor (n-k)/2 \rfloor`$ |
|---|---|---|---|---|
| L | 約 7% | 19 | 7 | 3 |
| M | 約 15% | 16 | 10 | 5 |
| Q | 約 25% | 13 | 13 | 6 |
| H | 約 30% | 9 | 17 | 8 |

位置の分からない誤りは検査シンボル 2 個で 1 個訂正できる（3 節）ので、RS 符号として訂正できる数$`t`$は検査シンボル数の半分（切り捨て）である。表の$`t`$を全体の 26 で割ると L 約 12%、M 約 19%、Q 約 23%、H 約 31% で、規格のおよその値とは一致しない。規格は誤訂正（4 節）を避ける余裕として検査シンボルの一部を訂正に使わない場合があり、配分もバージョンによって違うので、規格の割合は目安として扱う。
大きいバージョンでは、シンボルを複数の RS 符号語（ブロック）に分け、ブロックのシンボルを交互に並べて配置する。6 節のインターリーブで、局所的な汚れを複数の符号語に分散させるためである。

QR コードの中央にロゴを重ねても読み取れるのは、ロゴがかかったシンボルの数が訂正能力の範囲に収まっていれば、RS 符号で元に戻るからである。レベル H なら、シンボルの約 30% が読めなくても復元できる。

下の図で汚れ（ロゴ）の位置と大きさを変えると、汚れがかかったシンボルの数と、各レベルで訂正できるかが表示される。レベル M では、汚れがかかったシンボルをすべて誤りとして実際に復号した結果も表示される。

| 構成 | シンボルは$`\mathrm{GF}(2^m)`$の要素（実用では$`m = 8`$）。$`g(x)=\prod_{j=1}^{2t}(x-\alpha^j)`$の倍数が符号語 |
| 符号語の判定 | $`c(\alpha^j) = 0`$（$`j = 1, \dots, 2t`$） |
| 符号化 | $`T = x^{2t}u + [x^{2t}u \bmod g]`$（組織符号）。次数$`k`$未満の多項式の値を並べる評価でも同じ符号になる |
| 最適性 | MDS 符号（$`d_{\min}=n-k+1`$）。0 でない符号語の 0 の個数は$`k-1`$以下 |
| 訂正能力 | 誤り$`t`$個、消失$`2t`$個、混在なら$`2\nu + \rho \le n-k`$ |
| 復号 | シンドローム → バーレカンプ・マッシー法（または連立方程式）→ チェン探索 → フォニー・アルゴリズム → 訂正 |
| 強み | シンボル単位で数えるのでバースト誤りに強い。インターリーブでさらに長いバーストにも対応 |
| 数学的な土台 | $`\mathrm{GF}(2^8)`$（[05 章](05_拡大体GF2m.md#実務の例-リード-ソロモン-qr-コード-の-gf-28)）と有限体上の線形代数（[03 章](03_有限体GFp.md#gf-p-上の線形代数-誤り訂正の道具)） |

これで第 II 部（誤り検出・訂正）は終わりである。次章から暗号に入る。第 I 部で作った合同算術や$`\mathrm{GF}(2^8)`$が、暗号でも中心的な役割を果たす。
