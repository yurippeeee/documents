Chapter 10

BCH 符号 — 訂正能力を「設計」する

この章の位置づけ. CRC（09 章）は誤りを検出できたが、訂正はできなかった。ハミング符号（08 章）は訂正できたが、1 ビットだけだった。 BCH 符号は、訂正したいビット数\(t\)を先に決めると、その能力を持つ巡回符号を作れる方式である。Bose、Ray-Chaudhuri、Hocquenghem の 3 人が 1959〜60 年に発表した。

09 章では生成多項式\(g(x)\)を係数で与えていた。BCH 符号では\(g\)を根で指定する。\(\mathrm{GF}(2^m)\)の中で「\(g\)の根はこれらの要素」と決め、それを満たす次数最小の多項式を\(g\)にする。05 章で作った拡大体をここで使う。

1 節で「根を\(2t\)個続けて指定すれば\(t\)ビット訂正できる」ことを示し、2 節でそのような\(g\)の作り方、3 節で\((15,7)\)符号の実例、4 節で復号の手順を扱う。

この章で使う既出の用語（定義は各リンク先）. 位数（02 章 1 節）、零因子（02 章 2 節）、標数（02 章 3 節）、原始元・離散対数（03 章 3 節）、 多項式の除算・合同式（04 章 2 節）、因数・既約多項式・剰余の定理（04 章 3 節）、原始多項式と\(x^4+x+1\)のべき乗表（04 章 4 節）、拡張ユークリッドの互除法（04 章 5 節）、 \(\mathrm{GF}(2^m)\)の構成と\(\alpha\)のべき表現（05 章 3 節）、定理 2 の系・フロベニウス（05 章 4 節）、検出・訂正能力と\(d_{\min}\)（06 章 3 節）、 線形符号・重み・最小距離（07 章 1 節）、誤りパターン・シンドローム（07 章 4 節）、巡回符号・ビットの位置・生成多項式・情報多項式（09 章 1 節）

1. 設計の原理 — 根を指定する

この章で扱うのは、符号語の各ビットが 0 か 1 の2 元 BCH 符号である。符号語と生成多項式\(g(x)\)は\(\mathrm{GF}(2)\)係数の多項式だが、\(g\)の根は拡大体\(\mathrm{GF}(2^m)\)の中に取る。 ビット列と多項式の対応は09 章 1 節と同じで、位置\(i\)のビットが\(x^i\)の係数である。

GF(2) 係数の多項式に GF(2^4) の要素を代入する

\(\mathrm{GF}(2)\)係数の多項式にも、\(\mathrm{GF}(2^m)\)の要素を代入できる。0 と 1 は\(\mathrm{GF}(2^m)\)にも含まれるので、係数をそのまま\(\mathrm{GF}(2^m)\)の要素とみなし、足し算と掛け算を\(\mathrm{GF}(2^m)\)で行えばよい。

この章の例はすべて、原始多項式\(f(x) = x^4+x+1\)で作った\(\mathrm{GF}(2^4)\)で計算する。05 章 3 節と同じく要素\(x\)（ビット\(0010\)）を\(\alpha\)と呼ぶと、\(\alpha\)は原始元で、0 以外の 15 個の要素は\(\alpha^0, \dots, \alpha^{14}\)で書ける。\(\alpha^i\)のビット表現は04 章 4 節の表（\(x^i \bmod f\)）と同じで、次のとおりである。

\(\alpha^{15} = 1\)なので、掛け算は指数を足して 15 で割った余りを取ればよい。足し算はビットの XOR である。

例: \(f(x) = x^4 + x + 1\)自身に\(\alpha\)と\(\alpha^3\)を代入する。

\(f(\alpha) = 0\)なので、\(\alpha\)は\(f\)の根である。\(\mathrm{GF}(2)\)の中には\(f\)の根は無い（\(f(0) = f(1) = 1\)）が、\(\mathrm{GF}(2^4)\)の中には根がある。一方\(f(\alpha^3) \neq 0\)なので、\(\alpha^3\)は\(f\)の根ではない。

根は倍数に受け継がれる: 多項式の積に値を代入した結果は、それぞれに代入した値の積に等しい。したがって\(\beta\)が\(g\)の根なら、\(g\)の倍数\(c(x) = u(x)g(x)\)について\(c(\beta) = u(\beta) \cdot 0 = 0\)である。巡回符号の符号語は\(g\)の倍数なので（09 章 1 節）、\(g\)の根はすべての符号語の根になる。\(g\)の根を選ぶことは、すべての符号語が満たす条件を選ぶことである。

下の図で\(\mathrm{GF}(2)\)係数の多項式をビット列で入れると、\(\alpha^0, \dots, \alpha^{14}\)を代入した値が表示され、0 になるもの（根）が強調される。\(\alpha^i\)を 1 つ選ぶと、その代入の計算（項ごとの値と XOR）も表示される。

BCH 限界（BCH bound）

\(\alpha\)を\(\mathrm{GF}(2^m)\)の原始元とし、符号長を\(n = 2^m - 1\)とする。\(\alpha\)の位数は\(n\)なので、\(\alpha^0, \alpha^1, \dots, \alpha^{n-1}\)は互いに異なる。

定理: \(\mathrm{GF}(2)\)係数の多項式\(g(x)\)が、連続する\(2t\)個のべき

\[ \alpha, \alpha^2, \alpha^3, \dots, \alpha^{2t} \]

をすべて根に持ち、\(x^n + 1\)を割り切るとする。\(g\)を生成多項式とする長さ\(n\)の巡回符号の最小距離は

\[ d_{\min} \geq 2t + 1 \]

であり、06 章 3 節より\(t\)ビットの誤りを訂正できる。\(2t+1\)を設計距離という。

方針: 重みが\(2t\)以下の 0 でない符号語があると仮定する。符号語は\(\alpha, \dots, \alpha^{2t}\)を根に持つので、1 が立つ位置から連立 1 次方程式が作れる。その式どうしを、うまく選んだ係数で組み合わせると「1 が立っている」ことと矛盾する。

導出: 重みが\(w\)（\(1 \leq w \le 2t\)）の符号語\(c\)があるとし、1 が立つ位置を\(i_1, \dots, i_w\)として\(c(x) = x^{i_1} + x^{i_2} + \cdots + x^{i_w}\)と書く。\(c\)は\(g\)の倍数なので、\(c(\alpha^j) = 0\)（\(j = 1, \dots, 2t\)）である。 \(X_l = \alpha^{i_l}\)とおくと\((\alpha^j)^{i_l} = X_l^j\)なので、\(j = 1, \dots, w\)の\(w\)本の式は、連立 1 次方程式

\[ y_1X_1^j + y_2X_2^j + \cdots + y_wX_w^j = 0 \qquad (j = 1, \dots, w) \]

が\(y_1 = \cdots = y_w = 1\)という解を持つことを表している。位置\(i_l\)は互いに異なり\(n\)未満なので、\(X_l\)は互いに異なる 0 でない要素である。

この連立方程式の解は\(y_1 = \cdots = y_w = 0\)しかないことを示す。まず\(y_1 = 0\)を示す。\(X_1\)以外の\(X_l\)を根に持つ多項式

\[ P(z) = (z - X_2)(z - X_3)\cdots(z - X_w) = p_0 + p_1 z + \cdots + p_{w-1}z^{w-1} \]

を作り、\(j\)番目の式に\(p_{j-1}\)を掛けて\(j = 1, \dots, w\)について足す。右辺は 0 のままである。左辺を\(y_l\)ごとにまとめると、\(y_l\)の係数は\(p_0X_l + p_1X_l^2 + \cdots + p_{w-1}X_l^w = X_l\,P(X_l)\)なので

\[ \sum_{l=1}^{w} y_l\, X_l\, P(X_l) = 0 \]

となる。\(l \geq 2\)では\(P(X_l) = 0\)なので、残るのは\(y_1X_1P(X_1) = 0\)だけである。\(X_1 \neq 0\)で、\(P(X_1) = (X_1 - X_2)\cdots(X_1 - X_w)\)も 0 でない因子の積なので 0 でない（体には零因子が無い）。よって\(y_1 = 0\)である。 \(P\)を「\(X_l\)以外のすべてを根に持つ多項式」に替えれば、同じように\(y_l = 0\)が得られる。ところが\(y_l = 1\)が解になっていたので矛盾する。

よって重みが\(2t\)以下の 0 でない符号語は無く、07 章 1 節より\(d_{\min}\geq 2t+1\)である ∎

\(w = 2\)の場合を図にすると次のようになる。\(P(z) = z - X_2\)なので、「第 2 式 −\(X_2\)× 第 1 式」を作ると\(X_2\)の列が消え、\(y_1\)の項だけが残る。

この連立方程式の係数行列（第\(l\)列が\(X_l, X_l^2, \dots, X_l^w\)）はヴァンデルモンド行列と呼ばれ、\(X_l\)が互いに異なり 0 でなければ、その行列式は 0 でない。上の導出は、そのことを行列式を使わずに確かめたものである。

「根を\(2t\)個続けて指定する」という設計上の要求が、「\(t\)ビット訂正できる」という性能の保証になった。欲しい性能から符号を設計できるのが BCH 符号の特長である。

2. 生成多項式の作り方

1 節の定理を使うには、\(\alpha, \dots, \alpha^{2t}\)を根に持ち、係数が 0 と 1 の多項式を作る必要がある。単に\((x - \alpha)(x - \alpha^2)\cdots\)と掛けると、係数が\(\mathrm{GF}(2^4)\)の要素になってしまう。たとえば、標数 2 では\(-\)は\(+\)と同じなので

\[ (x - \alpha)(x - \alpha^2) = x^2 + (\alpha + \alpha^2)x + \alpha^3 = x^2 + \alpha^5x + \alpha^3 \]

であり（\(\alpha + \alpha^2 = 0010 \oplus 0100 = 0110 = \alpha^5\)）、係数\(\alpha^5\)は 0 でも 1 でもない。そこで根を追加して、係数が 0 と 1 になるようにする。その方法がこの節の内容である。

2 乗しても根 — 共役類

定理: \(\mathrm{GF}(2)\)係数の多項式\(f\)が\(\beta\)を根に持てば、\(\beta^2\)も根に持つ。

方針: \(f(\beta)\)を 2 乗した値が\(f(\beta^2)\)に等しいことを、標数 2 の 2 乗の性質で示す。

導出: 標数 2 では\((a+b)^2 = a^2+b^2\)である（05 章 4 節の定理 4）。項が 3 つ以上でも\((a+b+c)^2 = ((a+b)+c)^2 = (a+b)^2 + c^2 = a^2+b^2+c^2\)と繰り返せば同じである。 \(f(x) = \sum a_i x^i\)とすると、\(a_i\)は 0 か 1 なので\(a_i^2 = a_i\)であり

\[ f(\beta)^2 = \left(\sum a_i \beta^i\right)^2 = \sum a_i^2 \beta^{2i} = \sum a_i (\beta^2)^i = f(\beta^2) \]

よって\(f(\beta)=0\)なら\(f(\beta^2) = 0^2 = 0\) ∎

1 節の例では\(f = x^4+x+1\)が\(\alpha\)を根に持ったので、\(\alpha^2, \alpha^4, \alpha^8\)も根であり、\((\alpha^8)^2 = \alpha^{16} = \alpha\)で元に戻る（1 節の図で確かめられる）。

\(\beta\)から 2 乗を繰り返して得られる互いに異なる要素の集合\(\{\beta, \beta^2, \beta^4, \beta^8, \dots\}\)を、\(\beta\)の共役類という。 0 でない要素は\(\beta^{2^m - 1} = 1\)を満たす（05 章 4 節の定理 2 の系）ので\(\beta^{2^m} = \beta\)であり、2 乗を\(m\)回繰り返すと必ず\(\beta\)に戻る。したがって共役類の要素数は\(m\)以下である。

\(\mathrm{GF}(2^4)\)で\(\beta = \alpha^j\)とすると、\(\beta^2 = \alpha^{2j}\)なので、2 乗は指数を 2 倍して 15 で割った余りを取ることである。0 以外の 15 個の要素は、次の 5 つの共役類に分かれる。

最小多項式

共役類のすべての要素\(\gamma\)について\((x - \gamma)\)を掛けた多項式

\[ M_\beta(x) = \prod_{\gamma \in \beta \text{ の共役類}}(x - \gamma) \]

を\(\beta\)の最小多項式という。\(M_\beta\)は次の 2 つの性質を持つ。

(1) 係数は 0 か 1: \(M_\beta(x) = \sum c_i x^i\)とする。上の導出と同じく標数 2 なので、\(M_\beta(x)^2 = \sum c_i^2 x^{2i}\)である。 一方、各因子を 2 乗すると\((x-\gamma)^2 = x^2 - \gamma^2\)である。共役類を\(\{\gamma_1, \gamma_2, \dots, \gamma_d\}\)（\(\gamma_{s+1} = \gamma_s^2\)、\(\gamma_d^2 = \gamma_1\)）と並べると、2 乗は\(\gamma_1 \to \gamma_2 \to \cdots \to \gamma_d \to \gamma_1\)と類の中を 1 つずつ進めるだけなので、\(\gamma\)が共役類全体を動くと\(\gamma^2\)も共役類全体を 1 回ずつ動く。したがって

\[ M_\beta(x)^2 = \prod_{\gamma}(x^2 - \gamma^2) = \prod_{\gamma}(x^2 - \gamma) = M_\beta(x^2) = \sum c_i x^{2i} \]

である。2 つの式の\(x^{2i}\)の係数を比べて\(c_i^2 = c_i\)、すなわち\(c_i(c_i - 1) = 0\)で、体には零因子が無いので\(c_i = 0\)か\(1\)である。

(2) \(\beta\)を根に持つ\(\mathrm{GF}(2)\)係数の多項式のうち次数が最小で、既約である: まず、根の個数と次数の関係を確かめておく。

根の個数は次数以下: 0 でない多項式\(h\)（係数は\(\mathrm{GF}(2^m)\)）の異なる根の個数は\(\deg h\)以下である。\(h(\gamma) = 0\)なら、\(h\)を\(x - \gamma\)で割った余りは定数で、\(x = \gamma\)を代入するとその定数は\(h(\gamma) = 0\)なので、\(h = (x - \gamma)h_1\)と書ける（04 章 3 節の剰余の定理と同じ考え方）。\(\gamma\)と異なる根\(\gamma'\)は、\((\gamma' - \gamma)h_1(\gamma') = 0\)と\(\gamma' - \gamma \neq 0\)より\(h_1\)の根である。これを繰り返すと、異なる根 1 つごとに次数 1 の因子がくくり出せるので、根の個数は次数を超えない。

\(\beta\)を根に持つ\(\mathrm{GF}(2)\)係数の 0 でない多項式は、上の定理より共役類のすべての要素を根に持つので、次数は共役類の要素数以上である。\(M_\beta\)の次数はちょうど共役類の要素数なので、次数が最小である。 また\(M_\beta\)は既約である。\(\mathrm{GF}(2)\)係数の次数 1 以上の多項式\(A, B\)で\(M_\beta = AB\)と書けたとすると、\(0 = M_\beta(\beta) = A(\beta)B(\beta)\)で、体には零因子が無いので\(A(\beta) = 0\)か\(B(\beta) = 0\)である。\(A\)も\(B\)も\(M_\beta\)より次数が低いので、次数が最小であることに反する。

生成多項式

\(\alpha, \alpha^2, \dots, \alpha^{2t}\)をすべて根に持つ、次数最小の\(\mathrm{GF}(2)\)係数の多項式は

\[ \boxed{g(x) = \mathrm{lcm}\left(M_{\alpha}(x), M_{\alpha^2}(x), \dots, M_{\alpha^{2t}}(x)\right)} \]

である。\(\mathrm{lcm}\)は最小公倍多項式で、並べた多項式すべてで割り切れる多項式のうち次数が最小のものである。 \(\alpha^j\)と\(\alpha^{2j}\)は同じ共役類に入るので\(M_{\alpha^j} = M_{\alpha^{2j}}\)で、並べた中には同じものが何度も出てくる。異なる共役類は共通の要素を持たない（2 乗を繰り返して移り合う要素は、すべて同じ類に入る）ので、異なる最小多項式は共通の根を持たない。したがって\(\mathrm{lcm}\)は「異なる最小多項式を 1 回ずつ掛けた積」であり、その根は、要求した\(\alpha^j\)の共役類の要素をちょうど 1 回ずつ含む。 次数が最小であることも根の個数から分かる。\(\alpha, \dots, \alpha^{2t}\)を根に持つ\(\mathrm{GF}(2)\)係数の多項式は、それらの共役類の要素をすべて根に持つので、次数はその要素の個数（\(g\)の次数）以上である。

g は x^n + 1 を割り切る: \(x^n + 1\)を\(g\)で割って\(x^n + 1 = q\,g + r\)（\(r = 0\)または\(\deg r < \deg g\)）とする。\(g\)の根\(\gamma\)は 0 でない要素なので\(\gamma^n = 1\)（05 章 4 節の定理 2 の系）であり、\(x = \gamma\)を代入すると\(0 = q(\gamma)\cdot 0 + r(\gamma)\)、つまり\(r(\gamma) = 0\)である。\(r\)は\(g\)の異なる根\(\deg g\)個をすべて根に持つが、次数は\(\deg g\)未満なので、根の個数と次数の関係から\(r = 0\)である。 よって\(g\)は 1 節の定理の条件をすべて満たし、\(t\)ビット訂正できる巡回符号の生成多項式になる。

下の図で\(m\)と\(t\)を変えると、要求する根、共役類と最小多項式、組み立てた\(g\)が表示される。符号語が少ない（\(k \le 21\)の）ときは、すべての符号語の重みを数えた実際の最小距離も表示される。\(m = 4\)、\(t = 2\)が次の 3 節の例である。

3. 実例: (15,7) 2 ビット訂正 BCH 符号

\(m=4\)とし、1 節の\(\mathrm{GF}(2^4)\)（\(f(x)=x^4+x+1\)、\(n = 15\)）を使う。\(t=2\)なので、根として\(\alpha,\alpha^2,\alpha^3,\alpha^4\)を要求する。

共役類: 2 節の図のとおり、要求した\(\alpha,\alpha^2,\alpha^4\)は\(\alpha\)の類に、\(\alpha^3\)は\(\alpha^3\)の類に入る。

  • \(\alpha\)の類: 指数\(1 \to 2 \to 4 \to 8 \to 16 \equiv 1\)で一周し、\(\{\alpha, \alpha^2, \alpha^4, \alpha^8\}\)。
  • \(\alpha^3\)の類: 指数\(3 \to 6 \to 12 \to 24 \equiv 9 \to 18 \equiv 3\)で一周し、\(\{\alpha^3, \alpha^6, \alpha^{12}, \alpha^9\}\)。

したがって\(g = M_{\alpha} M_{\alpha^3}\)である。

最小多項式:

  • \(M_{\alpha}(x) = x^4 + x + 1\)。1 節で見たとおり\(f(\alpha) = 0\)で、\(f\)は\(\mathrm{GF}(2)\)係数なので、2 節の定理より\(\alpha\)の共役類の 4 個の要素はすべて\(f\)の根である。2 節の「根の個数は次数以下」の議論で 4 個の因子\(x - \gamma\)をくくり出すと、\(f\)は次数 4 で最高次の係数が 1 なので残りは 1 になり、\(f = M_\alpha\)である。
  • \(M_{\alpha^3}(x) = x^4+x^3+x^2+x+1\)。\((\alpha^3)^5 = \alpha^{15} = 1\)なので、\(\alpha^3\)は\(x^5 + 1 = (x + 1)(x^4+x^3+x^2+x+1)\)の根である。\(\alpha^3 \neq 1\)で体には零因子が無いので、\(\alpha^3\)は後ろの因子の根であり、上と同じ理由でこの因子が最小多項式である（この因子が既約であることは04 章 3 節でも確かめた。2 節の (2) のとおり、最小多項式は必ず既約である）。直接代入しても確かめられる:

生成多項式: \(g(x) = (x^4+x+1)(x^4+x^3+x^2+x+1)\)を展開する。ビット列で書くと\(10011 \times 11111\)で、\(11111\)を\(x^4\)、\(x\)、\(1\)の位置にずらして XOR する（04 章 1 節の繰り上がりの無い掛け算）。

\[ g(x) = x^8+x^7+x^6+x^4+1 \]

\(\deg g = 8\)なので\(k = 15-8 = 7\)で、\((15,7)\)符号である。1 節の定理より\(d_{\min}\geq 5\)で、2 ビット訂正できる。 実際に\(2^7 - 1 = 127\)個の 0 でない符号語の重みを数えると次のようになり、最小は 5 なので\(d_{\min} = 5\)である。

4. 復号の流れ

BCH 符号とリード・ソロモン符号の復号は、次の 4 段階で誤りの位置と値を求め、最後に受信語から誤りを取り除いて訂正する。11 章では、この訂正を第 5 ステップとして数える。ステップ 2 と 4 の一般的な方法は、次章でリード・ソロモン符号と共通に扱う。

ステップ 1: シンドロームの計算

受信者は、受け取ったビット列（受信語）\(r(x)\)に対し

\[ S_j = r(\alpha^j) \qquad (j = 1, 2, \dots, 2t) \]

を求める。\(S_j\)をシンドロームと呼ぶ（07 章 4 節と同じく、誤りの症状を表す値である）。誤りが無ければ\(r\)は\(g\)の倍数で、\(\alpha^j\)は\(g\)の根なので、すべて 0 になる。

誤りパターンを\(e(x) = \sum_{l=1}^{\nu} Y_l x^{i_l}\)とする。\(\nu\)（ニュー）は誤りの個数、\(i_l\)は誤ったビットの位置、\(Y_l\)は誤りの値で、2 元 BCH 符号ではビット反転しかないので\(Y_l=1\)である。送った符号語を\(c\)とすると\(r = c + e\)で、\(c(\alpha^j) = 0\)なので

\[ S_j = e(\alpha^j) = \sum_{l=1}^{\nu} Y_l (\alpha^{i_l})^j = \sum_{l=1}^{\nu} Y_l X_l^j \]

となる。\(X_l = \alpha^{i_l}\)を、誤り位置\(i_l\)に対応する位置元と呼ぶ。\(X_l\)が分かれば、離散対数を取って\(i_l\)が分かる。

一般に（値が 0 と 1 以外も取るリード・ソロモン符号を含めて）、未知数は位置元\(X_l\)と誤り値\(Y_l\)の合計\(2\nu\)個、既知の値は\(S_1,\dots,S_{2t}\)の\(2t\)個である。\(\nu \le t\)なら式の本数のほうが多い。2 元 BCH 符号では\(Y_l = 1\)なので、未知数は\(X_l\)の\(\nu\)個だけである。式は\(X_l\)についてべき乗を含む（線形でない）が、次のステップで線形の問題に直して解く。

2 元 BCH 符号では\(S_{2j} = S_j^2\)が成り立つ。\(S_{2j} = r(\alpha^{2j})\)で、\(r\)は\(\mathrm{GF}(2)\)係数なので、2 節の定理の導出と同じ計算で\(r(\beta^2) = r(\beta)^2\)となるからである。したがって計算が必要なのは奇数番目の\(S_1, S_3, \dots\)だけである。

ステップ 2: 誤り位置多項式を求める

\[ \Lambda(x) = \prod_{l=1}^{\nu}(1 - X_l x) \]

を誤り位置多項式という。\(x = X_l^{-1}\)で因子\(1 - X_l x\)が 0 になるので、根は位置元の逆数\(X_l^{-1}\)である。 シンドロームから\(\Lambda\)の係数を求めるのが復号の中心で、一般にはバーレカンプ・マッシー法か、多項式版の拡張ユークリッドの互除法（04 章 5 節）を使う（11 章で説明する）。\(t = 2\)なら、次の項のように直接の式で求められる。

ステップ 3: 根を探す（チェン探索）

\(\Lambda(x)=0\)となる\(x\)を、\(\alpha^0, \alpha^{-1}, \alpha^{-2},\dots, \alpha^{-(n-1)}\)を順に代入して探す。発案者 Chien の名前を取ってチェン探索という。 \(\Lambda(\alpha^{-i}) = 0\)なら\(\alpha^{-i}\)が\(X_l^{-1}\)のどれかなので\(X_l = \alpha^i\)、すなわち位置\(i\)のビットが誤りである。

ステップ 4: 誤り値を求める

2 元 BCH 符号では誤り値は必ず 1（ビット反転）なので、位置が分かればそのビットを反転して訂正は終わる。 値が 0 と 1 以外も取るリード・ソロモン符号では、\(\Lambda\)とシンドロームから各位置の誤り値を求めるフォニー・アルゴリズムを使う（11 章）。

ここまでの 4 段階と最後の訂正をまとめると、次の図になる。

t = 2 の誤り位置多項式

方針: 誤りの個数が 0、1、2 の場合に分けて、\(S_1, S_3\)を位置元で書き、\(\Lambda\)の係数を\(S_1, S_3\)で表す。

2 個の場合: \(\Lambda(x) = (1 + X_1 x)(1 + X_2 x) = 1 + \sigma_1 x + \sigma_2 x^2\)で、\(\sigma_1 = X_1 + X_2\)、\(\sigma_2 = X_1X_2\)である（標数 2 なので\(-\)は\(+\)）。 シンドロームは\(S_1 = X_1 + X_2 = \sigma_1\)、\(S_3 = X_1^3 + X_2^3\)である。\((X_1 + X_2)^2 = X_1^2 + X_2^2\)（標数 2）を使うと\(X_1^2 + X_1X_2 + X_2^2 = S_1^2 + \sigma_2\)なので

\[ S_3 = X_1^3 + X_2^3 = (X_1 + X_2)(X_1^2 + X_1X_2 + X_2^2) = S_1(S_1^2 + \sigma_2) = S_1^3 + S_1\sigma_2 \]

である。\(X_1 \neq X_2\)なので\(S_1 \neq 0\)である。\(S_1^3\)を左辺へ移す（標数 2 なので符号は変わらない）と\(S_3 + S_1^3 = S_1\sigma_2\)、両辺を\(S_1\)で割ると

\[ \sigma_1 = S_1, \qquad \sigma_2 = \frac{S_3}{S_1} + S_1^2 \]

1 個の場合: \(S_1 = X_1 \neq 0\)、\(S_3 = X_1^3 = S_1^3\)なので、同じ式で\(\sigma_2 = S_1^2 + S_1^2 = 0\)となり、\(\Lambda(x) = 1 + S_1x\)（根は\(X_1^{-1}\)の 1 個）が得られる。

0 個の場合: \(S_1 = S_3 = 0\)である。

\(S_1 = 0\)なのに\(S_3 \neq 0\)なら、どの行にも当てはまらないので、誤りは 3 個以上ある（訂正できないことが分かる）。

復号例: (15,7) 符号の 2 ビット誤り

3 節の生成多項式そのもの\(c(x) = g(x) = x^8+x^7+x^6+x^4+1\)（情報多項式\(u(x) = 1\)の符号語）を送り、位置 3 と位置 10 のビット（\(x^3\)と\(x^{10}\)の係数）が反転して

\[ r(x) = x^{10} + x^8+x^7+x^6+x^4+x^3+1 \]

を受信したとする。

ステップ 1: 受信者は\(r\)に\(\alpha\)と\(\alpha^3\)を代入する。\(r\)の 1 が立つ位置\(i\)について\(\alpha^i\)（\(S_3\)では\(\alpha^{3i}\)）を 1 節の表で引き、XOR する。

\(S_1 = \alpha^{12}\)、\(S_3 = \alpha^7\)である。確認として誤りの部分だけに代入しても、\(S_1 = e(\alpha) = \alpha^3 + \alpha^{10} = 1000 \oplus 0111 = 1111 = \alpha^{12}\)、\(S_3 = e(\alpha^3) = \alpha^9 + \alpha^{30} = \alpha^9 + \alpha^0 = 1010 \oplus 0001 = 1011 = \alpha^7\)で一致する（\(c(\alpha^j) = 0\)だからである）。

ステップ 2: \(S_1 \neq 0\)なので、上の表の 2 個の場合の式を使う。\(\sigma_1 = S_1 = \alpha^{12}\)。\(S_3/S_1 = \alpha^{7-12} = \alpha^{-5} = \alpha^{10}\)、\(S_1^2 = \alpha^{24} = \alpha^9\)なので

\[ \sigma_2 = \alpha^{10} + \alpha^9 = 0111 \oplus 1010 = 1101 = \alpha^{13} \]

よって\(\Lambda(x) = 1 + \alpha^{12}x + \alpha^{13}x^2\)である。

ステップ 3: \(i = 0, 1, \dots, 14\)について\(\Lambda(\alpha^{-i})\)を計算すると、0 になるのは\(i = 3\)と\(i = 10\)だけである。

たとえば\(i = 3\)と\(i = 10\)では次のようになる（\(\alpha^{-7} = \alpha^{8}\)）。

\[ \Lambda(\alpha^{-3}) = 1 + \alpha^{12-3} + \alpha^{13-6} = 1 + \alpha^9 + \alpha^7 = 0001 \oplus 1010 \oplus 1011 = 0000 \]
\[ \Lambda(\alpha^{-10}) = 1 + \alpha^{12-10} + \alpha^{13-20} = 1 + \alpha^2 + \alpha^{8} = 0001 \oplus 0100 \oplus 0101 = 0000 \]

ステップ 4: 位置 3 と位置 10 のビットを反転すると\(g(x)\)に戻り、訂正が完了する。\(\sigma_2 = X_1 X_2 = \alpha^{3+10} = \alpha^{13}\)とも一致している。

下の図で情報ビットと誤りの位置（3 個まで）を選ぶと、シンドローム、\(\Lambda(x)\)、チェン探索、訂正結果が表示される。誤りを 3 個にすると訂正能力を超え、訂正できないと分かる場合と、別の符号語に誤って訂正してしまう場合がある。

(31,21) は\(m = 5\)、\(t = 2\)、(15,5) は\(m = 4\)、\(t = 3\)の BCH 符号で、2 節の図で確かめられる。

BCH 符号とリード・ソロモン符号の関係: この章では符号語の各桁（シンボル）を 0 か 1 とし、根だけを\(\mathrm{GF}(2^m)\)に取った。 各シンボルそのものを\(\mathrm{GF}(2^m)\)の要素（\(m\)ビットのかたまり）にし、生成多項式を\(g(x) = (x - \alpha)(x-\alpha^2)\cdots(x-\alpha^{2t})\)と\(\mathrm{GF}(2^m)\)係数のまま作ったものがリード・ソロモン符号である。係数を 0 と 1 にそろえる必要が無いので、2 節の共役類の議論は要らない。 1 節の定理の証明は、\(y_l\)が 1 ではなく 0 でない\(\mathrm{GF}(2^m)\)の要素になるだけで、そのまま成り立つ。

\(m = 8\)にすると 1 シンボルが 1 バイトになり、コンピュータで扱いやすい。リード・ソロモン符号は 1 バイトの中で何ビット壊れても 1 シンボルの誤りとして数えるので、連続した数十ビットがまとめて壊れるバースト誤りに強い。これが次章の主題である。
