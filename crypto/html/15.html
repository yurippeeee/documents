Chapter 15

数論の道具 — オイラー・中国剰余定理・離散対数

公開鍵暗号に必要な数学を、ここで一気に揃える. 16 章の RSA、17 章の楕円曲線暗号は、どれも「計算は簡単だが、逆算は絶望的に難しい」 という一方向性に安全性を賭けている。

その一方向性を生み出すのが、この章で扱う数論の定理群である。 01 章・02 章・03 章で作った合同算術と群論の上に、公開鍵暗号の土台を組み上げる。

この章で使う既出の用語（定義は各リンク先）. 逆元（02 章 1 節）、閉性（02 章 1 節）、原始元（03 章 3 節）、離散対数（03 章 3 節）

1. オイラーの φ 関数

定義

\(\varphi(n)\) = \(1\)以上\(n\)以下の整数のうち、\(n\)と互いに素（\(\gcd = 1\)）なものの個数。 （\(n\)自身は\(\gcd(n,n) = n\)なので\(n \ge 2\)では数えられない。\(\varphi(1) = 1\)。）

例: \(\varphi(10)\)。\(1\)から\(10\)を順に見ると、\(2,4,6,8,10\)は 2 を、\(5,10\)は 5 を 10 と共有するので除外。残る\(\{1,3,7,9\}\)の 4 個 → \(\varphi(10)=4\)

計算公式

(a) \(p\)が素数: \(\varphi(p) = p-1\) （\(1,\dots,p-1\)すべてが\(p\)と互いに素）

(b) \(p\)が素数、\(k\geq1\): \(\varphi(p^k) = p^k - p^{k-1} = p^k\left(1-\frac1p\right)\)

導出: \(1\)から\(p^k\)のうち\(p^k\)と互いに素でないのは\(p\)の倍数だけ。 \(p\)の倍数は\(p, 2p, \dots, p^{k-1}\cdot p\)の\(p^{k-1}\)個。引けばよい ∎

(c) 乗法性: \(\gcd(m,n)=1\) なら \(\varphi(mn) = \varphi(m)\varphi(n)\)

導出: 3 節 の中国剰余定理により、\(0 \le x < mn\)の整数\(x\)と、組\((x \bmod m,\ x \bmod n)\)は 1 対 1 に対応する。 \(x\)が\(mn\)と互いに素であることは「\(x\)が\(m\)と互いに素、かつ\(n\)と互いに素」と同じなので、 数える対象の組は「\(m\)と互いに素な余り\(\varphi(m)\)通り」×「\(n\)と互いに素な余り\(\varphi(n)\)通り」∎

(d) 一般形: \(n = p_1^{e_1}\cdots p_r^{e_r}\) のとき

\[ \varphi(n) = n\prod_{i=1}^{r}\left(1 - \frac{1}{p_i}\right) \]

RSA で使う最重要ケース: \(n = pq\)（相異なる素数）のとき

\[ \boxed{\varphi(pq) = (p-1)(q-1)} \]

ここに RSA の安全性の急所がある. \(n = pq\)は公開される。しかし\(\varphi(n) = (p-1)(q-1)\)を計算するには\(p, q\)を知る必要がある。 逆に\(\varphi(n)\)が分かれば\(p, q\)も求まる: \(p + q = n - \varphi(n) + 1\)（\(\varphi(n) = pq - p - q + 1\)を変形）と\(pq = n\)から、 \(p, q\)は 2 次方程式\(t^2 - (n - \varphi(n) + 1)t + n = 0\)の 2 解として計算できる。 つまり \(\varphi(n)\)を求めることと\(n\)を素因数分解することは、互いに一方が解ければ他方も解ける同じ難しさの問題である。

  • 鍵を作る人: \(p, q\)を自分で選んだので\(\varphi(n)\)を即座に計算できる
  • 攻撃者: \(n\)しか知らないので、素因数分解しないと\(\varphi(n)\)が分からない

この非対称性が RSA そのものである（16 章）。

2. オイラーの定理

定理

\(\gcd(a,n)=1\) のとき:

\[ \boxed{a^{\varphi(n)} \equiv 1 \pmod n} \]

導出（群論から — 02 章の一般定理の適用）

\(n\)と互いに素な剰余類の集合\((\mathbb{Z}/n\mathbb{Z})^\ast\)は、掛け算について群をなす:

  • 閉性: \(\gcd(a,n)=\gcd(b,n)=1\)なら\(\gcd(ab,n)=1\) ✓
  • 逆元: 01 章の定理より存在 ✓

この群の位数はちょうど\(\varphi(n)\)（定義そのもの）。 02 章のラグランジュの定理の帰結\(a^{|G|}=e\)より\(a^{|G|} = a^{\varphi(n)} = 1\) ∎

系（フェルマーの小定理）: \(n=p\)（素数）なら\(\varphi(p)=p-1\)なので\(a^{p-1}\equiv1 \pmod p\)

02 章で「ラグランジュの定理の帰結がフェルマーの小定理の正体」と述べた話が、 ここでオイラーの定理という一般形に拡張された. 数論の定理に見えるが、本質は有限群では位数乗すると単位元に戻るという代数の事実である。

3. 中国剰余定理 (CRT)

定理

\(m_1,\dots,m_r\)がどの 2 つを取っても互いに素（\(i \neq j\)なら\(\gcd(m_i, m_j) = 1\)）のとき、連立合同式

\[ x \equiv a_1 \pmod{m_1},\quad \dots,\quad x \equiv a_r \pmod{m_r} \]

は\(M = m_1\cdots m_r\)を法としてただ 1 つの解を持つ。

導出（構成的に解を作る）

\(M_i = M/m_i\)（\(m_i\)以外の\(r-1\)個の積）とおく。\(M_i\)の素因数はすべて\(m_i\)以外の\(m_j\)から来るので\(\gcd(M_i, m_i)=1\)。よって 01 章より逆元\(N_i = M_i^{-1} \bmod m_i\)が存在する。ここで

\[ \boxed{x = \sum_{i=1}^{r} a_i M_i N_i \bmod M} \]

とおく。これが解であることを確認する。法\(m_j\)で見ると:

  • \(i \neq j\)の項: \(M_i\)は「\(m_i\)以外すべての積」だから\(m_j\)を因数に含み、\(a_i M_i N_i\)は\(m_j\)の倍数なので\(\equiv 0\)
  • \(i = j\)の項は\(a_j M_j N_j \equiv a_j \cdot 1 = a_j\)（\(N_j\)の定義より）

よって\(x \equiv a_j \pmod{m_j}\)がすべての\(j\)で成立 ✓

一意性: 解が 2 つ\(x, x'\)あれば\(x - x'\)はすべての\(m_i\)で割り切れる。 互いに素なので\(M\)で割り切れ、\(\bmod M\)では同じ ∎

実例

\[ x \equiv 2 \pmod 3, \quad x \equiv 3 \pmod 5, \quad x \equiv 2 \pmod 7 \]

\(M = 105\)、\(M_1=35, M_2=21, M_3=15\)。

  • \(N_1 = 35^{-1} \bmod 3\): \(35\equiv2\)、\(2\cdot2=4\equiv1\) → \(N_1=2\)
  • \(N_2 = 21^{-1}\bmod 5\): \(21\equiv1\) → \(N_2=1\)
  • \(N_3 = 15^{-1}\bmod 7\): \(15\equiv1\) → \(N_3=1\)
\[ x = 2\cdot35\cdot2 + 3\cdot21\cdot1 + 2\cdot15\cdot1 = 140+63+30 = 233 \equiv 23 \pmod{105} \]

検算: \(23 = 3\cdot7+2\) ✓、\(23=5\cdot4+3\) ✓、\(23=7\cdot3+2\) ✓

CRT の実用上の価値: RSA が 4 倍速くなる. RSA の復号\(m = c^d \bmod n\)（\(n=pq\)）は重い。そこで CRT を使う:

  1. \(m_p = c^{d \bmod (p-1)} \bmod p\) を計算（法が半分の大きさ）
  2. \(m_q = c^{d \bmod (q-1)} \bmod q\) を計算
  3. CRT で\(m\)を復元

速くなる理由は 2 つ重なる。\(n\)を\(2k\)ビットとすると

  • 1 回の乗算（筆算方式）のコストはビット数の 2 乗に比例するので、法が\(k\)ビットになれば約\(1/4\)
  • べき乗に要する乗算の回数は指数のビット数に比例する（01 章）。指数が\(d\)（\(2k\)ビット）から\(d \bmod (p-1)\)（\(k\)ビット）になるので約\(1/2\)

合わせて 1 本あたり\(1/8\)、それを\(p\)側と\(q\)側の 2 本やるので\(2/8 = 1/4\)。全体で約 4 倍高速。 実際の RSA 実装（OpenSSL 等）はほぼ全部これを使っている。

ただし副作用がある: この最適化はフォールト攻撃の標的になる。 電源やクロックに瞬間的な異常を与えて\(m_p\)の計算だけを狂わせると、\(m_q\)は正しいまま誤った\(m'\)が出力される。 正しい\(m\)と比べると\(m' - m\)は\(q\)の倍数だが\(p\)の倍数ではないので、\(\gcd(m' - m, n) = q\)で秘密の\(q\)が割り出せる （Bellcore 攻撃。署名なら\(m\)の代わりに「メッセージを公開鍵で検証した値」を使えば正解を知らなくても同じことができる）。 実装では計算結果を公開鍵で検算してから出力することが必須である。

4. 位数と原始根

位数

\(\gcd(a,n)=1\)のとき、\(a^k \equiv 1 \pmod n\)となる最小の正整数\(k\)を\(a\)の位数という。

性質: 位数は\(\varphi(n)\)を割り切る（\(a\)の生成する部分群の位数が群の位数\(\varphi(n)\)を割る = ラグランジュの定理）。

原始根

位数がちょうど\(\varphi(n)\)に等しい\(a\)を原始根という。\(a\)のべき\(a, a^2, \dots, a^{\varphi(n)}\)が\(n\)と互いに素な余りをすべて尽くす、ということである （\(n = p\)が素数のときは03 章の原始元そのもの。ここでは一般の\(n\)に広げている）。

存在定理（証明は省く。事実として使う）: \(n\)が\(1, 2, 4, p^k, 2p^k\)（\(p\)は奇素数）の形のときに限り原始根が存在する。 たとえば\(n = 8\)には無い（\(1, 3, 5, 7\)はどれも 2 乗すると\(1\)になり、位数が最大でも 2 で\(\varphi(8) = 4\)に届かない）。

個数: 存在するとき\(\varphi(\varphi(n))\)個。理由: 原始根\(g\)を 1 つ取ると、互いに素な余りはすべて\(g^k\)（\(1 \le k \le \varphi(n)\)）と書ける。 \(g^k\)の位数は\(\varphi(n)/\gcd(k, \varphi(n))\)なので、位数が\(\varphi(n)\)になるのは\(\gcd(k, \varphi(n)) = 1\)の\(k\)、すなわち\(\varphi(\varphi(n))\)個。

5. 離散対数問題 (DLP)

定義

\(g\)を\(\mathbb{Z}_p^\ast = \{1,\dots,p-1\}\)（\(\bmod p\)で掛け算の逆元を持つ要素の集合。記法は02 章 1 節 例 4）の原始根とする。与えられた\(y\)に対し

\[ g^x \equiv y \pmod p \]

を満たす\(x\)を求める問題を離散対数問題という。

難しさの非対称性

方向計算量2048 ビットでの実時間
\(x \to y = g^x\)\(O(\log x)\)（繰り返し二乗法、01 章）ミリ秒
\(y \to x\)最良でも準指数時間（下の表）現実的に不可能

既知のアルゴリズム:

手法計算量備考
総当たり\(O(p)\)論外
Baby-step Giant-step\(O(\sqrt p)\)メモリも\(O(\sqrt p)\)
Pollard の ρ\(O(\sqrt p)\)メモリ\(O(1)\)、実用的
Index Calculus準指数時間 \(L_p[1/3] = \exp\!\left(c\,(\ln p)^{1/3}(\ln\ln p)^{2/3}\right)\)\(\mathbb{Z}_p^\ast\)では有効

ここで準指数時間とは、\(p\)の桁数\(\ln p\)に対して「多項式（\((\ln p)^k\)）よりは大きいが、指数関数（\(p^{c} = e^{c \ln p}\)）よりは小さい」計算量のこと。 \(L_p[1/3]\)は\(\ln p\)の\(1/3\)乗が指数に乗る形で、\(\sqrt p = e^{(\ln p)/2}\)（指数に\(\ln p\)の 1 乗）よりはるかに小さい。

ここが 17 章の楕円曲線暗号につながる決定的な点. \(\mathbb{Z}_p^\ast\)上の DLP には Index Calculus という準指数時間アルゴリズムが効く。 だから安全性を保つには\(p\)を 2048 ビット以上にする必要がある。

Index Calculus は「\(g^k \bmod p\)を整数として見たとき、小さな素数だけの積に分解できる（滑らかな数という）ものを集めて連立方程式を作る」手法である。 ところが楕円曲線上の点には「小さな素数の積」に当たる概念が無いので、Index Calculus が適用できない。 使えるのは群の位数\(n\)に対して\(O(\sqrt n)\)の Pollard ρ だけ。 したがって同じ安全性を、はるかに短い鍵で達成できる:

安全性レベルRSA/DH の鍵長楕円曲線の鍵長
112 ビット2048224
128 ビット3072256
256 ビット15360512

鍵がおよそ 1/10 から 1/30。安全性を上げるほど差が開く。これが楕円曲線が主流になった理由である。

6. 素数判定 — 鍵生成に必須

RSA には 1024 ビット級の素数が 2 個必要。どうやって見つけるか。

素数定理

\(x\)以下の素数の個数\(\pi(x) \approx x/\ln x\)。

つまり\(n\)付近の数が素数である確率は約\(1/\ln n\)。 1024 ビットなら\(1/\ln(2^{1024}) \approx 1/710\)。 偶数を除けば約 355 回に 1 回。ランダムに選んで判定を繰り返せば、すぐ見つかる。

フェルマー・テスト

\(a^{n-1} \equiv 1 \pmod n\) を満たさなければ\(n\)は合成数（フェルマーの小定理の対偶）。

弱点: カーマイケル数（561, 1105, 1729, …）は合成数なのに、\(n\)と互いに素なすべての\(a\)で\(a^{n-1} \equiv 1\)になり、テストを通過してしまう （\(\gcd(a, n) \neq 1\)の\(a\)なら不合格になるが、そんな\(a\)を偶然引く確率は小さい）。

ミラー・ラビン・テスト（実用の標準）

\(n-1 = 2^s d\)（\(d\)は奇数、\(s \ge 1\)）と分解する。\(n\)が素数なら、\(n\)と互いに素な任意の\(a\)について

\[ a^d \equiv 1 \pmod n \quad\text{または}\quad a^{2^r d}\equiv -1 \pmod n\ \text{となる } r \text{ が } 0 \le r \le s-1 \text{ に存在} \]

手順: \(x_0 = a^d \bmod n\)を計算し、\(x_1 = x_0^2, x_2 = x_1^2, \dots, x_s = x_{s-1}^2\)（\(= a^{n-1}\)）と 2 乗を\(s\)回繰り返す。 \(x_0 = 1\)か、\(x_0, \dots, x_{s-1}\)のどこかに\(-1\)（\(= n - 1\)）が現れれば「たぶん素数」、現れなければ「確実に合成数」。

なぜこれが強いのか: \(n\)が素数なら\(\mathbb{Z}_n\)は体（02 章）なので、 \(x^2 \equiv 1\)の解は\(x=\pm1\)の 2 つだけ。列\(x_0, x_1, \dots, x_s\)は最後が\(1\)（フェルマーの小定理）で、各項は前の項の 2 乗。 最後から逆にたどると、\(1\)の直前は\(1\)の平方根なので\(\pm 1\)のどちらか。\(1\)ならさらに前も\(\pm1\)、と続くので、 列は「\(\pm 1\)でないもの → \(-1\) → \(1 \to 1 \to \cdots\)」か「\(1\)ばかり」のどちらかの形しかとれない。 \(\pm 1\)以外の数の 2 乗が\(1\)になる箇所（自明でない平方根）が見つかれば、体でない = 合成数と分かる。

誤り確率: 1 回のテストで合成数を素数と誤判定する確率は\(\leq 1/4\)。 \(k\)回繰り返せば\(\leq 4^{-k}\)。64 回で\(2^{-128}\) —— 宇宙が終わるまでに間違えない。
