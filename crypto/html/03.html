有限体 GF(p) — 素数個の要素で作る完全な世界

この章の位置づけ. 02 章で、\(\mathbb{Z}_p\)は\(p\)が素数のとき体になることを示した。 この章ではその体を具体的な数で動かし、逆元の公式、原始元、有限体上の連立方程式を扱う。 最後に、要素数が素数でない有限体が必要になる理由を述べ、次章以降につなぐ。

この章で使う既出の用語（定義は各リンク先）. \(a \bmod p\)と\(\equiv\)・\(\gcd\)・拡張ユークリッド・逆元の存在条件・繰り返し二乗法（01 章）、 群・単位元・逆元・\(\mathbb{Z}_p^\ast\)・群の位数と要素の位数・生成元・巡回群・フェルマーの小定理（02 章 1 節）、零因子（02 章 2 節）、 体・標数（02 章 3 節）。

1. GF(p) の構成と演算表

\(p\)を素数とする。02 章の\(\mathbb{Z}_p\)は\(p\)が素数のとき体であり、これを体であることを強調したいときに\(\mathrm{GF}(p)\)と呼ぶ。集合も演算も同じものである。この章を通じて\(p\)は素数を表す。 0 以外の要素がなす掛け算の群は 02 章のとおり\(\mathbb{Z}_p^\ast\)と書く。

乗法表の各行は全要素の並べ替えになる

主張: \(a \neq 0\)を固定して\(a \times 1, a\times 2, \dots, a\times(p-1)\)を並べると、\(1, 2, \dots, p-1\)を並べ替えたものになる。

方針: \(p-1\)個の出力が「互いに異なる」ことと「どれも 0 でない」ことの 2 つを示す。すると\(p-1\)個の異なる出力が\(p-1\)個しかない候補\(\{1,\dots,p-1\}\)に収まるので、全部が 1 回ずつ現れるしかない。

導出: 異なる入力\(x \neq y\)は異なる出力\(ax \neq ay\)を与える。仮に\(ax = ay\)だったとすると、両辺に\(a^{-1}\)を掛けて\(x = y\)となり矛盾するからである。 よって\(p-1\)個の入力は\(p-1\)個の互いに異なる出力に写る。 出力はどれも 0 でない。体に零因子は無いので、\(a \neq 0\)、\(x \neq 0\)なら\(ax \neq 0\)だからである。 したがって出力の候補は\(\{1, \dots, p-1\}\)の\(p-1\)個しか無く、\(p-1\)個の互いに異なる出力がそこに収まるには、全部がちょうど 1 回ずつ現れるしかない ∎

各行に必ず 1 が現れるので、逆元は表から読める。\(2 \times 3 = 1\)より\(2^{-1} = 3\)、\(4\times 4 = 1\)より\(4^{-1} = 4\)である。

2. 逆元の公式

02 章のフェルマーの小定理\(a^{p-1} \equiv 1 \pmod p\)を\(a \cdot a^{p-2} \equiv 1\)と分けると

\[ \boxed{a^{-1} \equiv a^{p-2} \pmod p} \]

GF(5) で\(a=2\)なら\(2^{3} = 8 \equiv 3\)であり、乗法表の\(2^{-1}=3\)と一致する。

逆元の求め方は 2 つある。拡張ユークリッド（01 章）と、上の公式を繰り返し二乗法（01 章）で計算する方法である。 どちらも\(O(\log p)\)で、実装では前者が使われることが多い。

3. 原始元（生成元）と離散対数

掛け算の群\(\mathbb{Z}_p^\ast\)の生成元を、有限体の文脈では原始元と呼ぶ。02 章の例で言えば、\(2\)は\(\mathrm{GF}(5)\)の原始元である。

原始元\(g\)があれば、\(0\)以外のどの要素\(y\)も\(y = g^x\)の形に書ける。この\(x\)を\(g\)を底とする\(y\)の離散対数という。 \(g^x\)は繰り返し二乗法で\(O(\log x)\)で計算できるが、\(y\)から\(x\)を求める効率のよい方法は知られていない。この非対称性がディフィー・ヘルマン鍵交換（17 章）の安全性の根拠である。 また原始元のべき乗は\(p-1\)個すべてを巡ってから 1 に戻るので、周期が最長になる。この性質を LFSR（13 章）とリード・ソロモン符号（11 章）で使う。

\(3\)と\(5\)は 6 個すべてを出すので原始元である。\(2\)は位数が\(3\)で、\(\{2,4,1\}\)しか出ない。 以下、要素について「位数」と言えば 02 章の要素の位数、すなわち単位元\(1\)になるまでに掛ける個数を指す。

原始元の個数

定理: 原始元が 1 つでも存在すれば、原始元はちょうど\(\varphi(p-1)\)個ある。 \(\varphi(n)\)はオイラー関数で、\(1\)以上\(n\)以下の整数のうち\(n\)と互いに素なものの個数である。 \(1\)はどの\(n\)とも互いに素なので\(\varphi(n) \ge 1\)であり、\(\varphi(p-1)\)が 0 になることはない。 したがって「原始元の個数は\(\varphi(p-1)\)」と条件なしに述べると、原始元が少なくとも 1 つ存在するという主張まで含んでしまう。 存在は05 章の定理 2 で示すので、この章では存在を前提にした形で述べる。

方針: 原始元\(g\)を 1 つ固定すると、0 以外の要素はすべて\(g^k\)と書ける。すると問いは「どの\(k\)で\(g^k\)が原始元になるか」に変わる。 \(g^k\)が原始元であるとは、その位数が\(p-1\)であることなので、\(g^k\)の位数を\(k\)の式で求めるのが中心の計算になる。 答えは\((p-1)/\gcd(k, p-1)\)であり、これが\(p-1\)になるのは\(\gcd(k,p-1) = 1\)のときに限る。そのような\(k\)の個数がオイラー関数\(\varphi(p-1)\)の定義そのものである。

導出: 例として\(p = 7\)、\(g = 3\)を並走させる。段階 1 で問いを\(k\)の問いに言い換え、段階 2 と 3 で\(g^k\)の位数を求め、段階 4 で数える。

段階 1: すべての候補を\(g^k\)の形で書く。 \(g\)は原始元なので、0 以外の要素は\(g^1, g^2, \dots, g^{p-1}\)のどれかとしてちょうど 1 回ずつ現れる。 したがって「原始元が何個あるか」は「\(k = 1, \dots, p-1\)のうち\(g^k\)が原始元になる\(k\)が何個あるか」と同じ問いである。 例では\(3^1 = 3, 3^2 = 2, 3^3 = 6, 3^4 = 4, 3^5 = 5, 3^6 = 1\)で、6 個の要素が 1 回ずつ現れている。

段階 2: \(g^n = 1\)となる\(n\)は\(p-1\)の倍数に限る。 これは段階 3 で「\(g^{kj} = 1\)になる\(j\)」を調べるための準備である。\(n\)を\(p-1\)で割って\(n = q(p-1) + r\)、\(0 \le r < p-1\)と書くと

\[ g^n = (g^{p-1})^q \cdot g^r = 1^q \cdot g^r = g^r \]

\(g\)の位数は\(p-1\)なので、\(p-1\)より少ない個数で\(1\)になることはない。よって\(g^r = 1\)となるのは\(r = 0\)のときだけであり、\(g^n = 1 \iff n\)は\(p-1\)の倍数。

段階 3: \(g^k\)の位数は\((p-1)/\gcd(k, p-1)\)である。 \(g^k\)を\(j\)個掛けたものは\(g^{kj}\)である。段階 2 より、\(g^{kj} = 1\)となる条件は「\(kj\)が\(p-1\)の倍数」である。 この条件を満たす最小の正整数\(j\)を求めればよい。

\(d = \gcd(k, p-1)\)とおき、\(k = dk'\)、\(p-1 = dm\)と書く。\(d\)は最大公約数なので、\(k'\)と\(m\)に共通の約数は 1 しかない。 すると条件「\(dk'j\)が\(dm\)の倍数」は、両方から\(d\)を落として「\(k'j\)が\(m\)の倍数」と書き換えられる。

\(k'\)は\(m\)と共通の素因数を持たないので、\(k'j\)が\(m\)で割り切れるなら\(j\)が\(m\)で割り切れる。

ここまでをつなぐと、\(g^{kj} = 1\)となる\(j\)の条件は次のように言い換えられてきた。

\[ g^{kj} = 1 \;\Longleftrightarrow\; kj \text{ が } p-1 \text{ の倍数} \;\Longleftrightarrow\; k'j \text{ が } m \text{ の倍数} \;\Longleftrightarrow\; j \text{ が } m \text{ の倍数} \]

つまり\(g^k\)を\(j\)個掛けて\(1\)になるのは、\(j = m, 2m, 3m, \dots\)のときであり、それ以外の\(j\)では\(1\)にならない。 位数の定義は「初めて\(1\)になる個数」なので、\(g^k\)の位数はこの中で最小の\(m\)である。 \(m = (p-1)/d = (p-1)/\gcd(k, p-1)\)なので、\(g^k\)の位数は\((p-1)/\gcd(k,p-1)\)である。

段階 4: 数える。 \(g^k\)が原始元であるとは位数が\(p-1\)であることなので、段階 3 より\(\gcd(k, p-1) = 1\)と同じである。 そのような\(k\)は\(1\)以上\(p-1\)以下で\(p-1\)と互いに素な整数であり、その個数がオイラー関数の定義そのもの、すなわち\(\varphi(p-1)\)である ∎

例では\(\gcd(k,6) = 1\)となる\(k\)は\(1, 5\)の 2 個なので\(\varphi(6) = 2\)であり、原始元は\(3^1 = 3\)と\(3^5 = 5\)の 2 個である。前の表で見つけた\(3, 5\)と一致する。

4. GF(p) 上の線形代数 — 誤り訂正の道具

体の上では、実数と同じ手順で連立方程式が解ける。 掃き出し法は、1 本の式の係数を割って 1 にし、その式を使って他の式からその変数を消す操作を変数ごとに繰り返す方法であり、必要なのは割り算だけだからである。 有限体では割り算を逆元の掛け算で行う。

GF(5) で連立方程式を解く

\[ \begin{aligned} 2x + 3y &= 4\\ x + y &= 3 \end{aligned} \pmod 5 \]

手順 1: 1 本目の\(x\)の係数を 1 にする。\(2^{-1} = 3\)を両辺に掛ける。

\[ 3(2x + 3y) = 3 \cdot 4 \Longrightarrow 6x + 9y = 12 \Longrightarrow x + 4y = 2 \]

手順 2: 2 本目から 1 本目を引いて\(x\)を消す。

\[ (x + y) - (x + 4y) = 3 - 2 \Longrightarrow -3y = 1 \Longrightarrow 2y = 1 \]

手順 3: 両辺に\(2^{-1} = 3\)を掛けて\(y = 3\)。

手順 4: \(x + y = 3\)に代入して\(x = 0\)。

検算: \(2\cdot 0 + 3\cdot 3 = 9 \equiv 4\)、\(0 + 3 = 3\)。

途中に分数が現れず、すべて\(\{0,1,2,3,4\}\)の中で完結している。 リード・ソロモン符号（11 章）では、壊れた位置を未知数、シンドロームを右辺とする有限体上の連立方程式をこの手順で解く。

5. GF(p) の限界 — なぜ次章が必要か

コンピュータは 1 バイトを\(2^8 = 256\)通りの値として扱う。256 は素数ではないので\(\mathbb{Z}_{256}\)は体にならず、素数 251 を使うと 5 つの値が無駄になってバイト境界とずれる。

体にならないのは\(\mathbb{Z}_m\)の形で作った場合であって、要素数 256 の体が存在しないわけではない。

定理: 有限体\(F\)の標数を\(p\)とすると、\(F\)の要素数は\(p^m\)の形である。逆に、任意の素数\(p\)と正整数\(m\)に対して要素数\(p^m\)の体が存在する。

前半を示す。02 章の定理より有限体の標数は素数なので、標数\(p\)は素数であり、この\(p\)に対して 1 節の\(\mathrm{GF}(p)\)が定まる。 ここで\(\mathrm{GF}(p)\)は\(p\)個の要素\(\{0,\dots,p-1\}\)の具体的な体を指し、有限体一般の略記ではない。 示したいのは「有限体\(F\)の要素数は、その標数\(p\)の何乗かになっている」ということである。

方針: まず\(F\)の中に\(\mathrm{GF}(p)\)と同じ演算表を持つ\(p\)個の要素があることを示す。 次に、\(F\)の要素をその\(p\)個の要素を係数とする和の形で数え上げ、要素数が\(p\)倍ずつ増えていくことを示す。

段階 1: \(F\)は\(\mathrm{GF}(p)\)の写しを含む。 \(1\)を\(i\)個足したものを\(i\cdot 1\)と書き、\(P = \{0\cdot 1, 1\cdot 1, 2\cdot 1, \dots, (p-1)\cdot 1\}\)とおく。 この\(p\)個は互いに異なる。もし\(i < j < p\)で\(i\cdot 1 = j\cdot 1\)なら\((j-i)\cdot 1 = 0\)となり、\(j - i < p\)が標数の最小性に反するからである。 また\(i\cdot 1 + j\cdot 1 = (i+j)\cdot 1\)、\((i\cdot 1)(j\cdot 1) = (ij)\cdot 1\)で、\(p\cdot 1 = 0\)なので添字は\(\bmod p\)で読める。 つまり\(P\)の足し算と掛け算は\(\mathrm{GF}(p)\)の演算表そのものであり、\(P\)は\(F\)の中にある\(\mathrm{GF}(p)\)の写しである。

段階 2: 要素数を数える。 \(F\)の 0 でない要素\(b_1\)を 1 つ取り、\(S_1 = \{c_1 b_1 \mid c_1 \in P\}\)とおく。 \(c_1 b_1 = c_1' b_1\)なら\(b_1^{-1}\)を掛けて\(c_1 = c_1'\)なので、\(S_1\)は\(p\)個の異なる要素からなる。 \(S_1 = F\)ならここで終わりで、要素数は\(p\)である。 そうでなければ\(S_1\)に入らない要素\(b_2\)を取り、\(S_2 = \{c_1 b_1 + c_2 b_2 \mid c_1, c_2 \in P\}\)とおく。 \(S_2\)は\(p^2\)個の異なる要素からなる。もし\(c_1 b_1 + c_2 b_2 = c_1' b_1 + c_2' b_2\)で\(c_2 \neq c_2'\)なら、

\[ b_2 = (c_1' - c_1)(c_2 - c_2')^{-1} b_1 \in S_1 \]

となって\(b_2\)の取り方に反する。よって\(c_2 = c_2'\)であり、すると\(c_1 b_1 = c_1' b_1\)から\(c_1 = c_1'\)である。 同じ手順を繰り返す。\(S_i \neq F\)である限り\(S_i\)に入らない\(b_{i+1}\)を取って\(S_{i+1}\)を作ると、同じ議論で要素数は\(p^{i+1}\)になる。 \(F\)は有限なのでこの手順はどこかで止まり、止まったときの\(S_m\)が\(F\)全体である。よって\(F\)の要素数は\(p^m\)である ∎

線形代数の言葉で言えば、\(b_1, \dots, b_m\)は\(P\)上のベクトル空間\(F\)の基底であり、\(m\)はその次元である。

後半は05 章で\(p = 2\)の場合を実際に作って示す。

\(\mathrm{GF}(256)\)は\(\mathbb{Z}_{256}\)とは別物として作る。 \(\mathrm{GF}(p)\)が整数を素数で割った余りの世界であったのに対し、\(\mathrm{GF}(p^m)\)は多項式を既約多項式で割った余りの世界として作る。 同じ論法を整数の代わりに多項式に適用するために、次章で多項式の世界を整備する。
