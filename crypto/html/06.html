Chapter 06

誤り訂正の基礎 — ハミング距離と「どこまで直せるか」

この章で扱う問い. 通信路やディスクは必ず誤る。宇宙線でメモリのビットが反転し、傷でディスクの読み取りが化ける。 それでもデータを守りたい——そのためにわざと冗長なビットを足しておくのが誤り訂正符号である。

ここで自然に湧く疑問が 3 つある。この章はそれに答える。

  1. なぜ冗長を足すと直せるのか?（直感的には「同じものを 3 回送れば多数決できる」だが、その一般化は?）
  2. 何ビットまで直せるのか? その限界は何で決まるのか?
  3. 冗長はどれだけ必要か? 少なすぎると直せず、多すぎると無駄。最適はどこか?

答えの鍵はすべてハミング距離という 1 つの概念に集約される。

この章で使う既出の用語（定義は各リンク先）. \(\mathrm{GF}(2)\)と XOR \(\oplus\)（02 章 4 節）、\(\lfloor \cdot \rfloor\)（切り捨て。この章 3 節 で説明）

1. 符号とは — 「使ってよい語」を制限する

基本の枠組み

  • 情報語 (message): 送りたい\(k\)ビットのデータ
  • 符号語 (codeword): 冗長を加えた\(n\)ビット（\(n > k\)）
  • 符号化: 情報語 → 符号語の対応付け
  • 符号 \(C\): 符号語全体の集合。\(2^n\)通りの中の\(2^k\)個だけが「正規の語」（5 節 で出てくる通信路容量も慣例で\(C\)と書くが、別物。そこで断る）

この符号を\((n, k)\)符号と呼び、\(R = k/n\)を符号化率という。

誤り検出・訂正の原理は、拍子抜けするほど単純である.

\(n\)ビットの空間には\(2^n\)通りのビット列がある。そのうち\(2^k\)個だけを「正しい語」に選んでおく。 すると残りの\(2^n - 2^k\)個は「絶対に送られないはずの語」になる。

受信したものがその「あり得ない語」だったら → 誤りがあったと分かる（誤り検出）。 さらに「あり得ない語」から見て一番近い正規の語を探せば → 元が復元できる（誤り訂正）。

つまり符号設計とは「正規の語どうしを、なるべく遠くに離して配置する」という配置問題である。 遠く離れていれば、多少ずれても最寄りの語を取り違えない。

例: 3 回繰り返し符号 (3,1)

\(0 \to 000\)、\(1 \to 111\)。符号語は 2 個で、残る 6 通り（001, 010, ...）は非正規。

101 を受信したら → 正規語ではないので誤りと分かる。 111 からは 1 ビット違い、000 からは 2 ビット違いなので、111 が送られたと判断（多数決）。

2. ハミング距離とハミング重み

定義

  • ハミング距離 \(d(x,y)\): ビット列\(x, y\)が異なる位置の個数
  • ハミング重み \(w(x)\): \(x\)の中の 1 の個数（= \(d(x, 0)\)）

ビット列どうしの XOR（\(\oplus\)。各位置で「違えば 1、同じなら 0」）を取ると、異なる位置にだけ 1 が立つので\(d(x,y) = w(x \oplus y)\)。

例: \(x = 10110\)、\(y = 11010\) → \(x \oplus y = 01100\) → \(d = 2\)

距離の公理を満たすことの確認

  • \(d(x,y) \geq 0\)、\(d(x,y) = 0 \iff x = y\) ✓（明らか）
  • \(d(x,y) = d(y,x)\) ✓（XOR は対称）
  • 三角不等式 \(d(x,z) \leq d(x,y) + d(y,z)\)

三角不等式の導出: 位置\(i\)で\(x_i \neq z_i\)なら、\(y_i\)がどちらの値であっても \(x_i \neq y_i\)または\(y_i \neq z_i\)の少なくとも一方が成り立つ （\(y_i\)が\(x_i\)と等しいなら\(z_i\)とは異なる、逆も同様）。 左辺\(d(x,z)\)は「\(x_i \neq z_i\)となる位置\(i\)の個数」、右辺は「\(x_i \neq y_i\)となる位置の個数 + \(y_i \neq z_i\)となる位置の個数」。 左辺で数えた位置はそれぞれ右辺のどちらかで少なくとも 1 回数えられているので、左辺の個数 ≤ 右辺の個数 ∎

三角不等式が成り立つおかげで、「最も近い符号語を選ぶ」という判断が幾何的に意味を持つ。

最小距離

符号\(C\)の異なる 2 語の距離の最小値を最小距離\(d_{\min}\)という:

\[ d_{\min} = \min_{c_1 \neq c_2 \in C} d(c_1, c_2) \]

これが符号の性能を決める最重要のパラメータである。 \((n,k,d)\)符号のように 3 つ組で書くことも多い。

3. 検出能力と訂正能力（この章の中心定理）

定理

最小距離\(d_{\min}\)の符号は:

\[ \boxed{\text{誤り検出: } d_{\min} - 1 \text{ ビットまで}, \qquad \text{誤り訂正: } t = \left\lfloor \frac{d_{\min}-1}{2} \right\rfloor \text{ ビットまで}} \]

（\(\lfloor \cdot \rfloor\)は小数点以下の切り捨て。\(d_{\min} = 4\)なら\((4-1)/2 = 1.5\)を切り捨てて\(t = 1\)。\(d_{\min}\)が奇数なら割り切れるので切り捨ては効かず、\(d_{\min} = 5\)で\(t = 2\)。）

導出 1: 検出能力

\(e\)ビットの誤りが起きると、受信語は送信語から距離\(e\)の位置に移る。 これが別の符号語に化けてしまうと、誤りに気づけない。 別の符号語に到達するには最低\(d_{\min}\)ビット変える必要があるので、 \(e \leq d_{\min}-1\)なら絶対に別の符号語には届かない = 必ず検出できる ∎

導出 2: 訂正能力

各符号語を中心に半径\(t\)の球（距離\(t\)以内のビット列の集合）を考える。 訂正が正しく行えるのは、これらの球が互いに重ならないときである （重なると、その領域のビット列がどちらの符号語から来たか判定できない）。

2 つの符号語\(c_1, c_2\)の球が重ならない条件は

\[ d(c_1, c_2) \geq 2t + 1 \]

である。理由を両方向から見る。

  • \(d(c_1, c_2) \ge 2t + 1\)なら重ならない: もしある語\(y\)が両方の球に入る（\(d(c_1, y) \le t\)かつ\(d(y, c_2) \le t\)）なら、 三角不等式より\(d(c_1, c_2) \le d(c_1, y) + d(y, c_2) \le 2t\)となり仮定に反する
  • \(d(c_1, c_2) = d \le 2t\)なら重なる: \(c_1\)と\(c_2\)が異なる\(d\)箇所のうち\(\lfloor d/2 \rfloor\)箇所だけ\(c_1\)のビットを\(c_2\)の値に書き換えた語\(y\)を作ると、 \(d(c_1, y) = \lfloor d/2 \rfloor \le t\)、\(d(y, c_2) = d - \lfloor d/2 \rfloor = \lceil d/2 \rceil \le t\)で、\(y\)は両方の球に入る

これが全ペアで成り立つには\(d_{\min} \geq 2t+1\)、すなわち

\[ t \leq \frac{d_{\min}-1}{2} \qquad \blacksquare \]

数値例

\(d_{\min}\)検出訂正例
21 ビット0単純パリティ
32 ビット1 ビットハミング符号（08 章）
43 ビット1 ビット拡張ハミング（SECDED）
54 ビット2 ビットBCH 等
76 ビット3 ビット—

検出と訂正のトレードオフ. 訂正と検出を同時に行うときは、「\(t\)ビットまで訂正し、それを超えて\(e\)ビットまでは（訂正はせず）検出する」ことが\(t + e \le d_{\min} - 1\)（\(e \ge t\)）の範囲で可能である。 理由: 受信語が符号語\(c_1\)から\(e\)以内、別の符号語\(c_2\)から\(t\)以内に同時に入ることが無ければ、「距離\(t\)以内に符号語があれば訂正、無ければ検出」という運用が誤動作しない。 三角不等式より\(d(c_1, c_2) \le e + t\)のときに限りその状況が起きうるので、\(e + t \le d_{\min} - 1\)ならよい。 \(d_{\min}=4\)なら、\(t = 0, e = 3\)（3 ビット検出専用）か\(t = 1, e = 2\)（1 ビット訂正 + 2 ビット検出）のどちらでも運用できる。 訂正を狙うと、訂正に距離を使うぶん検出できる範囲が減る。 どちらを選ぶかは応用次第——通信では再送できるので検出重視、 ディスクや宇宙探査機では再送できないので訂正重視、というのが典型である。

4. 符号の限界 — どこまで欲張れるか

「\(n\)を小さく、\(k\)を大きく、\(d\)を大きく」は全部同時には満たせない。その限界を与える定理を見る。

ハミング限界（球充填限界）

\(t\)ビット訂正符号では、各符号語の周りの半径\(t\)の球が重ならない。 球 1 個に含まれるビット列の個数は

\[ V(n,t) = \sum_{i=0}^{t}\binom{n}{i} \]

（\(\binom{n}{i}\)は組み合わせの数\({}_n\mathrm{C}_i = n!/(i!(n-i)!)\)。\(n\)個の位置から誤る\(i\)個を選ぶ選び方の数で、\(i\)ビット誤るパターンが\(\binom{n}{i}\)通り。それを\(i=0\)から\(t\)まで合計）。

球が重ならず全体\(2^n\)に収まる必要があるので:

\[ \boxed{2^k \sum_{i=0}^{t}\binom{n}{i} \leq 2^n} \]

等号が成立する符号を完全符号 (perfect code) という —— 空間に隙間なく球を詰められた状態。 ハミング符号とゴレイ符号がその稀な例である（08 章）。

シングルトン限界

\[ \boxed{d_{\min} \leq n - k + 1} \]

導出: すべての符号語から、先頭の\(d_{\min}-1\)個の位置（どのペアでも共通の、固定した位置）を削除する。 2 つの異なる符号語は\(d_{\min}\)箇所以上で異なる。削除した\(d_{\min} - 1\)箇所がたとえ全部「異なる箇所」だったとしても、異なる箇所はまだ 1 箇所以上残る。 つまり削除後も 2 語は異なる。これがどのペアにも言えるので、削除後の\(2^k\)個の語は全部異なる。 削除後の長さは\(n - d_{\min}+1\)ビットで、これが\(2^k\)個すべて異なるには

\[ 2^{n-d_{\min}+1} \geq 2^k \Longrightarrow n - d_{\min}+1 \geq k \Longrightarrow d_{\min} \leq n-k+1 \qquad \blacksquare \]

等号を達成する符号を MDS 符号 (Maximum Distance Separable、最大距離分離符号) という。「与えられた\(n, k\)で達成できる最大の距離を持ち、かつ情報部と検査部に分離できる」という意味の名前である。 リード・ソロモン符号は MDS である（11 章）——冗長を最大限に活かしきっている、という意味。

ギルバート・ヴァルシャモフ限界（存在保証）

上の 2 つは「これ以上は無理」という上界だったが、こちらは「これなら作れる」という下界:

\[ 2^k \sum_{i=0}^{d-1}\binom{n}{i} \le 2^n \Longrightarrow \text{最小距離 } d \text{ 以上の } (n,k) \text{ 符号が存在する} \]

導出: 符号語を 1 つずつ貪欲に選ぶ。既に選んだ符号語それぞれから距離\(d - 1\)以内の語（1 語あたり\(\sum_{i=0}^{d-1}\binom{n}{i}\)個）を「使用禁止」にし、 禁止されていない語を次の符号語に選ぶ。こうすれば新しい符号語はどの既存符号語からも距離\(d\)以上離れる。 \(2^k\)個選び終わるまで禁止領域の合計が全体\(2^n\)を超えなければ、必ず選べる語が残っているので、条件式の下で\(2^k\)個の符号語が取れる ∎ （線形符号に限れば、検査行列の列を 1 本ずつ「既存のどの\(d-2\)本の和とも一致しない」ように選ぶ議論で、より緩い条件\(2^{n-k} > \sum_{i=0}^{d-2}\binom{n-1}{i}\)でも作れることが知られている。）

5. シャノンの通信路符号化定理（理論的な最終目標）

通信路ごとに通信路容量と呼ぶ数\(C\)が決まる（1 節 の符号\(C\)とは別物。慣例でどちらも\(C\)と書く）。 意味は「その通信路で 1 回の送信あたりに、誤りなく運べる情報の上限（ビット）」である。

定理（1948）: 通信路容量\(C\)より小さい任意の符号化率\(R < C\)に対し、 符号長\(n\)を十分大きくすれば、誤り率をいくらでも 0 に近づけられる符号が存在する。逆に\(R > C\)では不可能。

2 元対称通信路（各ビットが独立に確率\(p\)で反転する通信路）の容量は

\[ C = 1 - H(p), \qquad H(p) = -p\log_2 p - (1-p)\log_2(1-p) \]

\(H(p)\)は「確率\(p\)で起きる出来事の不確かさ」を表す量（2 値エントロピー）で、\(p = 0\)または\(1\)（結果が確定）なら 0、\(p = 1/2\)（完全に五分五分）なら最大の 1。 受信側は 1 ビット受け取るごとに「反転したかどうか」という\(H(p)\)ビット分の不確かさを抱えるので、確実に運べるのは残りの\(1 - H(p)\)ビット、という読み方ができる。

この定理の衝撃と、その後 50 年. シャノンは「誤り率ほぼ 0 で、しかも効率よく通信できる符号が存在する」ことを証明した。 ところがその証明は存在を言うだけで、作り方を教えてくれない。 証明は「\(2^k\)個の符号語をでたらめに（ランダムに）選んだ符号の平均誤り率」を計算し、それが 0 に近づくことを示すもので、 平均が小さいなら良い符号が少なくとも 1 つは存在する、と言えるだけで、どれが良い符号かは示さない。

以来、符号理論は「シャノン限界にどこまで近づけるか」の歴史になった。

  • ハミング符号（1950）— 実用的だが限界からは遠い
  • リード・ソロモン（1960）— バースト誤りに強く、CD・QR で大成功
  • ターボ符号（1993）・LDPC（1962 再発見 1996）— 限界まであとわずか（必要な信号電力が理論限界の 1 割増し程度）に到達

現代の 5G や Wi-Fi は LDPC を使っており、シャノンが 1948 年に示した限界に実質的に到達している。

6. 誤りのモデル

モデル説明有効な符号
ランダム誤り各ビットが独立に反転ハミング、BCH、LDPC
バースト誤り連続する区間がまとめて壊れる（ディスクの傷、無線で電波が一時的に弱まる現象など）リード・ソロモン（11 章）、インターリーブ（複数の符号語のビットを交互に並べ替えて送り、バーストを各符号語に少しずつ分散させる手法。11 章）
消失 (erasure)「どこが壊れたか」は分かるが値が不明RS（訂正できる個数が約 2 倍になる）

消失が有利な理由. 位置が分かっている\(e\)箇所を「空欄」として、残りの\(n - e\)箇所だけを見る。 2 つの異なる符号語は\(d_{\min}\)箇所以上で異なるので、\(e \le d_{\min} - 1\)なら空欄以外にまだ異なる箇所が残り、残りの部分だけで符号語が一意に決まる。 つまり消失は\(d_{\min} - 1\)個まで復元できる。位置未知の誤りの\(t = \lfloor (d_{\min}-1)/2 \rfloor\)個と比べて、およそ 2 倍（\(d_{\min}\)が奇数ならちょうど 2 倍）である。 RAID や分散ストレージが RS 符号を使うのは、ディスク故障が「どのディスクが死んだか分かる」= 消失だからである。
