## 1. アンテナの指標 — 利得・指向性・偏波

1 章 6 節と 4 章 1 節の受信機の流れ図で、アンテナは左の端にあった。アンテナは、空間を進んでくる電波を、ケーブルの中を進む電気の信号に変える部品である。衛星の電波は、受信機の所に 1 m² あたりの電力（密度）$`S`$ [W/m²] で届き、アンテナの端子から取り出せる電力 $`C`$ は、$`S`$ に実効開口面積 $`A_\mathrm{e}`$ を掛けた値である（3 章 1 節）。

```fig
e08_role
```

GNSS のアンテナには、図の (b) の 4 つが求められる。① 上の半分の空のどの向きの衛星の電波も受けること（仰角の低い衛星も使えると DOP が小さくなる。7 章 4 節）。② 衛星の電波の偏波（この節の終わりと 2 節）に合っていること。③ 地面で反射した電波と、地面が出す熱雑音（3 章 5 節のアンテナの雑音温度を上げる）を弱く受けること。④ 機器の中に収まる大きさで、受信機と整合していること（3〜6 節）。この節では、①〜③を数で表すための指標を定義する。

### 放射パターンと指向性

アンテナの性質は、電波を送るときで考えると分かりやすい（受けるときも同じになることを、この節の 3 つ目の項で示す）。アンテナに電力を入れたとき、向きごとに出ていく電波の強さの分布を**放射パターン**（パターン）という。ある向きに出ていく電波の 1 m² あたりの電力を、出ていく電力の全部を全部の向きに均等に出したとしたときの値で割った比を、その向きの**指向性** $`D_\mathrm{a}`$ という。指向性は、アンテナが電波をどの向きに集めているかだけを表す数で、均等に出したときの値で割っているので、全部の向きで平均すると必ず 1 になる。

全部の電力を上の半分の空に均等に出し、下の半分には出さないアンテナを考える。全部の向きの平均が 1 なので、上の半分の指向性は 2（3.01 dBi）、下の半分は 0 である。「上の半分の空を広く見る」という GNSS のアンテナの理想は、この形である（次の図の (a) の緑の破線）。

### 効率と利得

アンテナに入れた電力の一部は、アンテナの金属や材料の中で熱になり、電波にならない。入れた電力のうち電波として出ていく割合を**アンテナの効率** $`\eta_\mathrm{a}`$ という。ある向きの**利得** $`G_\mathrm{a}`$ は、その向きに出ていく電波の 1 m² あたりの電力が、入れた電力を等方性アンテナで出したときの何倍かである（3 章 1 節の言い方）。指向性は出ていく電力を基準にし、利得は入れた電力を基準にするので、$`G_\mathrm{a} = \eta_\mathrm{a}D_\mathrm{a}`$ である（混同しやすい量の整理は[電磁界シミュレーションシリーズ 15 章 3 節](../emsim/15_遠方界.md#アンテナの諸量-混同しやすい-4-つ)）。3 章で「真上で +3 dBi」と書いた値は、この利得である。

```fig
e08_pattern
```

図は、3 章 3 節の例のアンテナ（真上 +3 dBi、仰角 30° で −1 dBi、5° で −5 dBi）に、地平線より下の利得（真下で −13 dBi）と、2 節で定義する逆の偏波の利得を、この章で足したものである（足した値は例の値。どの方位でも同じとした）。このパターンから、効率が求まる。

**方針**: 利得を全部の向きで平均すると、指向性の平均が 1 なので、効率が残る。方位によらないパターンでは、その平均を仰角の積分に直す。

**導出**: $`G_\mathrm{a} = \eta_\mathrm{a}D_\mathrm{a}`$ で、$`\eta_\mathrm{a}`$ は向きによらないので、$`G_\mathrm{a}`$ の全部の向きの平均は $`\eta_\mathrm{a} \times 1 = \eta_\mathrm{a}`$ である。全部の向きの平均は、半径 1 の球の面の上の平均である。仰角が $`\theta`$ と $`\theta + d\theta`$ の間の帯は、周りの長さが $`2\pi\cos\theta`$、幅が $`d\theta`$ なので、面積は $`2\pi\cos\theta\,d\theta`$ で、球の面の全部の面積は $`4\pi`$ である。方位によらない利得 $`G_\mathrm{a}(\theta)`$（真数）の平均は

$$
\eta_\mathrm{a} = \frac{1}{4\pi}\int_{-\pi/2}^{\pi/2} G_\mathrm{a}(\theta)\,2\pi\cos\theta\,d\theta = \frac{1}{2}\int_{-\pi/2}^{\pi/2} G_\mathrm{a}(\theta)\cos\theta\,d\theta
$$

である（$`G_\mathrm{a}`$ は、衛星の電波の偏波に対する利得と、逆の偏波に対する利得の和）∎

例のアンテナで数値の積分をすると、上の半分の衛星の電波の偏波の分が 45.3 %、逆の偏波の分が 5.0 %、下の半分が 6.3 %、合わせて効率は 56.6 % で、残りの 43.4 % が熱になる（図の (c)）。真上の指向性は $`D_\mathrm{a} = G_\mathrm{a}/\eta_\mathrm{a}`$ を dB で書いた $`3 - 10\log_{10}0.566`$ = 5.47 dBi である。上の半分に均等に出す理想（3.01 dBi）より大きいのは、真上に強く、地平線に近い向きに弱く出しているからである。

### 可逆性 — 送るときと受けるときで同じ

同じアンテナを送るときに使ったときの、向きごとの利得と偏波は、受けるときに使ったときの、その向きから来る電波を受ける強さの倍率と、最もよく受ける偏波に等しい。これを**可逆性**（相反性）という（電磁気の法則から導かれる性質で、ここでは結果だけを使う。利得と開口面積の関係の説明は[レーダーシリーズ 11 章 3 節](../radar/11_アンテナとビーム.md#利得と開口面積-03-章の借りを返す)）。パターンは、送るときと受けるときの考えやすいほうで考えてよい。

```fig
e08_recip
```

受けるときの実効開口面積は、その向きの利得から $`A_\mathrm{e} = G_\mathrm{a}\lambda^2/(4\pi)`$ で求まる（3 章 1 節）。L1 の波長 19.03 cm では、0 dBi で 28.8 cm²、例のアンテナの真上（+3 dBi）で 57.5 cm² である。3 節の一辺 25 mm のセラミックの板の面積 6.25 cm² の約 9 倍で、アンテナは自分の大きさより広い範囲の電波を集める。

### 偏波と、地平線で利得が下がる理由

電波は、進む向きに垂直な面の中で電界が振動しながら進む。電界の向きが時間とともにどう変わるかを、その電波の**偏波**という。電界の向きが一定で、大きさと符号だけが変わる偏波を**直線偏波**という（[レーダーシリーズ 2 章 6 節](../radar/02_電波の基礎.md#偏波-電場の向き)）。どの偏波も、進む向きに垂直な 2 つの向きの直線偏波の和に分けられる。この章では、電波の進む向きと真上の向きを含む垂直な面の中の成分（地平線に近い電波では上下に振れる）を**垂直の成分**、それに直交する水平な向きの成分を**水平の成分**という。衛星の電波は、垂直の成分と水平の成分を同じ大きさで含み、2 つの位相が 90° ずれている（2 節の円偏波）。

GNSS で多く使われるパッチアンテナ（小さな平たいアンテナ。3 節）は、金属の板（地板。4 節）の上に置かれる。金属の面に沿う向きの電界は、金属の中の電子が動いて打ち消すので、面のすぐ上では 0 になる。面に垂直な電界は残る（次の図の (b)）。地平線の向きに出ていく電波は地板に沿って進むので、地板に沿う水平の成分は 0 になり、地板に垂直な垂直の成分だけが残る。仰角が上がると水平の成分も出せるようになり、パッチでは仰角の sin にほぼ比例する（例のアンテナでは比例するとした。図の (c)）。

```fig
e08_horizon
```

したがって、地平線に近い向きでは、アンテナは衛星の電波の水平の成分をほとんど受けられない。どれだけ損するかは、2 節で偏波の損失を求めてから計算する。

## 2. 右旋円偏波 — 衛星の電波の向きとマルチパス

### 円偏波 — 電界の向きが回りながら進む

電界の大きさが一定で、向きが 1 周期に 1 回、一定の速さで回る偏波を**円偏波**という。2 つの成分が同じ大きさで位相が 90° ずれているとき、例えば $`\sin\omega t`$ と $`\cos\omega t`$ のとき、和のベクトルの長さは $`\sqrt{\sin^2\omega t + \cos^2\omega t}`$ = 1 で一定になり、先は円を描く。電波の進む向きに見て（電波の後ろから見て）、電界の向きが時計回りに回る円偏波を**右旋円偏波**（RHCP、right-hand circular polarization）、反時計回りに回る円偏波を**左旋円偏波**（LHCP、left-hand circular polarization）という（IEEE の定め方。右手の親指を進む向きに向けたとき、残りの指の曲がる向きに回るのが右旋）。

GPS の衛星は右旋円偏波で電波を出すと規格（IS-GPS-200）で定められており、ほかの衛星系の信号も右旋円偏波である（各衛星系の規格の文書による）。円偏波を使うのは、電波の進む向きのまわりで、衛星と受信機のアンテナの向きの関係がどう回っても、また電離層を通るときに直線偏波の向きが回っても（ファラデー回転）、受ける強さが変わらないからである。

```fig

```

### 楕円偏波と軸比

2 つの成分の大きさが違うか、位相のずれが 90° でないと、電界の先は楕円を描く。この偏波を**楕円偏波**という。直線偏波と円偏波は、楕円偏波の特別な場合（つぶれ切った楕円と、丸い楕円）である。楕円の長い軸と短い軸の長さの比を**軸比**（AR、axial ratio）という。dB で表すことが多く（$`20\log_{10}`$ の比）、円で 0 dB、直線で ∞ である。楕円偏波は、右旋と左旋の 2 つの円偏波の和で表せる（図の (b)）。この分け方を使うと、偏波が合わないときの損失（次の項）と反射（その次の項）が簡単に計算できる。

**方針**: 振幅 $`a_\mathrm{R}`$ の右旋と、振幅 $`a_\mathrm{L}`$ の左旋を足し、和の先の描く形と、長い軸・短い軸を求める。

**導出**: 電波の進む向きに見て、右を $`x`$、上を $`y`$ とする。時計回りの右旋は、時刻 0 で上を向き、1/4 周期で右を向くので $`a_\mathrm{R}(\sin\omega t,\ \cos\omega t)`$、反時計回りの左旋は、時刻 0 で上を向き、1/4 周期で左を向くので $`a_\mathrm{L}(-\sin\omega t,\ \cos\omega t)`$ と書ける（2 つが時刻 0 で同じ向きを向く時刻の原点を選んだ。原点が違うと楕円が傾くだけで、形は同じ）。和は $`x = (a_\mathrm{R} - a_\mathrm{L})\sin\omega t`$、$`y = (a_\mathrm{R} + a_\mathrm{L})\cos\omega t`$ で、$`\sin^2 + \cos^2 = 1`$ から

$$
\frac{x^2}{(a_\mathrm{R} - a_\mathrm{L})^2} + \frac{y^2}{(a_\mathrm{R} + a_\mathrm{L})^2} = 1
$$

の楕円である。長い軸は $`2(a_\mathrm{R} + a_\mathrm{L})`$、短い軸は $`2|a_\mathrm{R} - a_\mathrm{L}|`$ なので、軸比は $`\mathrm{AR} = (a_\mathrm{R} + a_\mathrm{L})/|a_\mathrm{R} - a_\mathrm{L}|`$ である。$`a_\mathrm{R} > a_\mathrm{L}`$ なら $`x`$ の係数が正で、右旋と同じ向きに回る。逆に解くと、振幅の比は $`a_\mathrm{L}/a_\mathrm{R} = (\mathrm{AR} - 1)/(\mathrm{AR} + 1)`$ である ∎

図の (b) は $`a_\mathrm{L}/a_\mathrm{R}`$ = 0.3 の例で、軸比は 1.3/0.7 = 1.86（5.4 dB）である。比が 0 で円、1 で直線になる。

### 偏波が合わないときの損失

右旋の電波を受けるアンテナは、横と縦の 2 つの直線偏波の受け口の出力を、縦の方を 90° 遅らせてから足すもの、と考えられる（パッチで 90° のずれを作る方法は 3 節）。前の項と同じく、電波の進む向きに見て右を横、上を縦とすると、右旋の電波は、横の成分が $`\sin\omega t`$、縦の成分が $`\cos\omega t`$ である。

**方針**: 右旋・横の直線偏波・左旋の 3 つの電波を、電波の電力をそろえて受け口に入れ、足した出力の電力を比べる。

**導出**: 縦の成分を 90° 遅らせると、$`\cos(\omega t - 90°) = \sin\omega t`$ になる。電波の電力は、2 つの成分の振幅の 2 乗の和に比例し、右旋（振幅 1 と 1）と、振幅 $`\sqrt{2}`$ の直線偏波は同じ電力である。

- 右旋（横 $`\sin\omega t`$、縦 $`\cos\omega t`$）: 出力は $`\sin\omega t + \sin\omega t = 2\sin\omega t`$ で、電力は振幅の 2 乗に比例して 4。
- 横の直線偏波（横 $`\sqrt{2}\sin\omega t`$、縦 0）: 出力は $`\sqrt{2}\sin\omega t`$ で、電力は 2。
- 左旋（横 $`-\sin\omega t`$、縦 $`\cos\omega t`$）: 出力は $`-\sin\omega t + \sin\omega t = 0`$。

右旋を受ける電力を 1 とすると、直線偏波は 1/2（−3.01 dB）、左旋は 0 である ∎

可逆性から、逆に直線偏波のアンテナで右旋の電波を受けても、受ける電力は合っている場合の 1/2（−3.01 dB）になる。

アンテナの偏波も楕円偏波になりうる（送るときの電波の偏波で決める）。右旋のアンテナの軸比が有限なら、アンテナの偏波は振幅 $`a_\mathrm{R}`$ の右旋と $`a_\mathrm{L}`$ の左旋の和で、アンテナは、右旋だけを受ける理想のアンテナと、左旋だけを受ける理想のアンテナを、振幅の比 $`a_\mathrm{R} : a_\mathrm{L}`$ で組み合わせたものとみなせる。電力の割合は $`a_\mathrm{R}^2 : a_\mathrm{L}^2`$ なので、右旋の電波を $`a_\mathrm{R}^2/(a_\mathrm{R}^2 + a_\mathrm{L}^2)`$、左旋の電波を $`a_\mathrm{L}^2/(a_\mathrm{R}^2 + a_\mathrm{L}^2)`$ の割合で受ける。軸比 3 dB（1.41 倍）のアンテナでは $`a_\mathrm{L}/a_\mathrm{R}`$ = 0.171 で、右旋の電波は 0.13 dB 損するだけだが、左旋の電波も −15.5 dB で受けてしまう（図の (b) と表）。

```fig
e08_plf
```

1 節の地平線の向きでは、アンテナは水平の成分を出せないので、アンテナの偏波は垂直の直線偏波になる。垂直の成分の大きさが真上と同じでも、出ていく電力は 2 つの成分を出す場合の半分（−3 dB）で、その直線偏波のアンテナで右旋の電波を受けるのでさらに半分（−3 dB）、合わせて 1/4（−6.02 dB）になる。例のアンテナの地平線の利得 −6 dBi が真上より 9 dB 低いのは、これに加えて、垂直の成分も真上より 3 dB 小さいとしたからである（1 節の図の (c)。地板の縁の影響は 4 節）。

### 反射すると回る向きが逆になる

電波が面で反射するとき、入ってくる電波の進む向きと、面に垂直な向きを含む平面を**入射面**という。反射は、電界を、入射面に垂直な成分（面に沿う。H と書く）と、入射面の中の成分（V と書く）に分けて考える。地面での反射では、1 節の水平の成分と垂直の成分そのものである。成分ごとに、反射した波の振幅を入ってきた波の振幅で割った比（符号を含む）を、その成分の**反射係数**といい、$`\Gamma_\mathrm{H}`$・$`\Gamma_\mathrm{V}`$ と書く。V の成分の符号は、面に垂直な部分（地面なら上下の部分）が、入ってきた波と反射した波で同じ向きのときを正とする。面と電波の進む向きのなす角を $`\psi`$ と書く（すれすれで 0°、真上から当たると 90°。7 章の $`\psi_\mathrm{M}`$ とは別の量）。

金属の面では、面に沿う向きの電界が 0 なので（1 節）、入ってきた波と反射した波の、面に沿う部分が打ち消し合う。H の成分は面に沿うので、逆向きに反射する（$`\Gamma_\mathrm{H} = -1`$）。V の成分は、面に沿う部分が打ち消し合うように反射するので、上下の部分は同じ向きになる（$`\Gamma_\mathrm{V} = +1`$）。2 つの成分の片方だけの符号が変わるので、反射した波は、入ってきた波を鏡に映した形になり、回る向きが逆になる。真上から当たるときに見ると分かりやすい（図の (b)）。電界が空間で回る向きは反射しても変わらないが、進む向きが逆になるので、進む向きに見た回り方は逆になる。金属で反射した右旋の電波は、左旋になる。

```fig
e08_mirror
```

一般の面では、$`\Gamma_\mathrm{H}`$ と $`\Gamma_\mathrm{V}`$ は −1 と +1 以外の値をとる。右旋の電波が反射すると、どれだけが右旋で残り、どれだけが左旋になるかを求める。

**方針**: 2 つの反射係数を、「同じ値の部分」と「逆の値の部分」に分け、それぞれの部分が回る向きをどう変えるかを調べる。

**導出**: $`\Gamma_\mathrm{R} = (\Gamma_\mathrm{V} + \Gamma_\mathrm{H})/2`$、$`\Gamma_\mathrm{L} = (\Gamma_\mathrm{V} - \Gamma_\mathrm{H})/2`$ とおくと、$`\Gamma_\mathrm{V} = \Gamma_\mathrm{R} + \Gamma_\mathrm{L}`$、$`\Gamma_\mathrm{H} = \Gamma_\mathrm{R} - \Gamma_\mathrm{L}`$ である。反射は成分ごとに係数を掛けるだけなので、反射した波は、$`\Gamma_\mathrm{L}`$ 倍の「$`\Gamma_\mathrm{V}`$ = +1、$`\Gamma_\mathrm{H}`$ = −1 の反射（金属）」と、$`\Gamma_\mathrm{R}`$ 倍の「$`\Gamma_\mathrm{V} = \Gamma_\mathrm{H}`$ = +1 の反射」の和である。金属の反射は、右旋を同じ振幅の左旋に変える。$`\Gamma_\mathrm{V} = \Gamma_\mathrm{H}`$ = +1 の反射は、金属の反射の後に H の成分の符号だけを変えたものである。円偏波の 1 つの成分の符号を変えると回る向きが逆になる（前の項の右旋の横の成分 $`\sin\omega t`$ を $`-\sin\omega t`$ にすると左旋）ので、左旋になった波が右旋に戻る。したがって、反射した波は、入ってきた右旋に対する振幅の比が $`\Gamma_\mathrm{R} = (\Gamma_\mathrm{V} + \Gamma_\mathrm{H})/2`$ の右旋と、$`\Gamma_\mathrm{L} = (\Gamma_\mathrm{V} - \Gamma_\mathrm{H})/2`$ の左旋の和である ∎

金属では $`\Gamma_\mathrm{R}`$ = 0、$`\Gamma_\mathrm{L}`$ = 1 で、全部が左旋になる。$`\Gamma_\mathrm{V}`$ と $`\Gamma_\mathrm{H}`$ が同じ符号なら右旋が多く残り、逆の符号なら左旋が多い。

下の図で、電波の種類（右旋・左旋・直線・楕円）とアンテナの種類を選ぶと、電界のベクトルが回る動く絵と、横と縦の受け口の波形、受ける電力が表示される。「金属で反射させてから受ける」に印を付けると、反射した後の電波が、反射波の進む向きに見て逆に回る様子と、そのときに受ける電力が表示される。

### 誘電体の面の反射とブルースター角

地面・コンクリート・ガラス・樹脂のように、電気をほとんど通さず、電界の中で内部の電荷がわずかにずれる物を**誘電体**という。コンデンサの板の間をその材料で満たしたとき、静電容量が真空の何倍になるかを表す数を、その材料の**比誘電率** $`\varepsilon_\mathrm{r}`$ という（真空で 1）。誘電体の中では、電波の速さが $`c/\sqrt{\varepsilon_\mathrm{r}}`$ になり、同じ周波数の波長が $`1/\sqrt{\varepsilon_\mathrm{r}}`$ 倍に縮む（3 節で使う）。

損失の無い誘電体の平らな面の反射係数は、面に沿う電界と磁界が面の両側でつながるという条件から、次のように求まる（フレネルの式。導出は電磁気学の教科書による）。

$$
\Gamma_\mathrm{H} = \frac{\sin\psi - \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}}{\sin\psi + \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}}, \qquad
\Gamma_\mathrm{V} = \frac{\varepsilon_\mathrm{r}\sin\psi - \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}}{\varepsilon_\mathrm{r}\sin\psi + \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}}
$$

3 つの場合で確かめる。$`\varepsilon_\mathrm{r}`$ を大きくすると、$`\Gamma_\mathrm{H} \to -1`$、$`\Gamma_\mathrm{V} \to +1`$ で金属と同じになる。すれすれ（$`\psi \to 0`$）では、どちらも −1 に近づき、$`\Gamma_\mathrm{R} \to -1`$、$`\Gamma_\mathrm{L} \to 0`$ で右旋のまま反射する。真上から（$`\psi`$ = 90°）では、$`\Gamma_\mathrm{H} = (1 - \sqrt{\varepsilon_\mathrm{r}})/(1 + \sqrt{\varepsilon_\mathrm{r}})`$、$`\Gamma_\mathrm{V} = (\varepsilon_\mathrm{r} - \sqrt{\varepsilon_\mathrm{r}})/(\varepsilon_\mathrm{r} + \sqrt{\varepsilon_\mathrm{r}}) = -\Gamma_\mathrm{H}`$ で、$`\Gamma_\mathrm{R}`$ = 0、全部が左旋になる（比誘電率 4 で振幅 1/3）。その間で、$`\Gamma_\mathrm{V}`$ は −1 から正へ符号を変える。$`\Gamma_\mathrm{V}`$ が 0 になる角を**ブルースター角** $`\psi_\mathrm{B}`$ という。

**方針**: $`\Gamma_\mathrm{V}`$ の分子が 0 になる条件を、$`\sin\psi`$ について解く。

**導出**: 分子が 0 の条件は $`\varepsilon_\mathrm{r}\sin\psi = \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}`$ で、両辺を 2 乗して $`\cos^2\psi = 1 - \sin^2\psi`$ を入れると、$`\varepsilon_\mathrm{r}^2\sin^2\psi = \varepsilon_\mathrm{r} - 1 + \sin^2\psi`$。移項して $`(\varepsilon_\mathrm{r}^2 - 1)\sin^2\psi = \varepsilon_\mathrm{r} - 1`$ で、両辺を $`\varepsilon_\mathrm{r} - 1`$（$`\varepsilon_\mathrm{r}`$ > 1 で正）で割ると $`\sin^2\psi = 1/(\varepsilon_\mathrm{r} + 1)`$、$`\cos^2\psi = \varepsilon_\mathrm{r}/(\varepsilon_\mathrm{r} + 1)`$ である。比をとって

$$
\tan\psi_\mathrm{B} = \frac{1}{\sqrt{\varepsilon_\mathrm{r}}}
$$

である（左辺が正の解）∎

比誘電率 4（乾いた地面の例の値）で 26.6°、6（壁のコンクリートの例の値）で 22.2°、20（湿った地面の例の値）で 12.6° である。ブルースター角より浅い（すれすれの）反射では、$`\Gamma_\mathrm{V}`$ と $`\Gamma_\mathrm{H}`$ がどちらも負で右旋が多く残り、深い反射では符号が逆で左旋が多い（次の図の (b)）。比誘電率 4 の面に $`\psi`$ = 10° で当たると、右旋は −4.1 dB、左旋は −14.2 dB で反射し、60° では右旋が −26.1 dB、左旋が −9.6 dB になる。7 章 3 節で「反射すると、回る向きが逆になることが多い（反射の角度と面の材料による）」と書いたのは、このことである。実際の地面や壁には損失と凹凸があり、比誘電率も水分で大きく変わるので、値は例である。

### マルチパスを弱める — 反射波と直接波の振幅の比

7 章 3 節で、反射波の振幅を直接波の振幅で割った比を $`\gamma`$ と書いた。$`\gamma`$ は、反射係数と、アンテナがそれぞれの向きと偏波の電波を受ける強さで決まる。仰角 $`\theta`$ の衛星の直接波は、右旋で来て、右旋に対する利得 $`G_\mathrm{R}(\theta)`$ で受ける。平らな地面での反射波は、すれすれの角 $`\psi = \theta`$ で反射し、地平線より下の仰角 $`-\theta`$ から、右旋の分 $`\Gamma_\mathrm{R}`$ と左旋の分 $`\Gamma_\mathrm{L}`$ を含んで来る。それぞれを、その向きの右旋と左旋に対する利得 $`G_\mathrm{R}(-\theta)`$・$`G_\mathrm{L}(-\theta)`$ で受ける（$`G_\mathrm{L}`$ は 1 節の図の赤の破線）。2 つの分の出力の位相の関係はアンテナのその向きの偏波で決まるので、ここでは電力で足した目安を使う。

$$
\gamma = \sqrt{\frac{\Gamma_\mathrm{R}^2\,G_\mathrm{R}(-\theta) + \Gamma_\mathrm{L}^2\,G_\mathrm{L}(-\theta)}{G_\mathrm{R}(\theta)}}
$$

垂直な壁での反射では、$`\psi = 90° - \theta`$ で、反射波は反対の側の同じ仰角 $`\theta`$ から来る（$`G_\mathrm{R}(-\theta)`$・$`G_\mathrm{L}(-\theta)`$ の代わりに $`G_\mathrm{R}(\theta)`$・$`G_\mathrm{L}(\theta)`$）。

```fig
e08_gamma
```

例のアンテナと、向きによらない利得の直線偏波のアンテナで比べる（図の (b)）。比誘電率 4 の地面で、仰角 30° の衛星では、例のアンテナの $`\gamma`$ は 0.11 で、直線偏波のアンテナの 0.40 の約 1/4 になる。比誘電率 6 の壁で仰角 30° の衛星では 0.15 と 0.42 である。ところが仰角 10° の衛星の地面の反射は、すれすれで右旋のまま反射し、地平線のすぐ下から来るので、偏波でも利得でも弱めにくく、0.28 と 0.65 である。

$`\gamma`$ が小さいと、7 章 3 節の誤差が小さくなる。誤差の包絡線の最大 $`\gamma\Delta_\mathrm{EL}cT_\mathrm{c}/2`$ は $`\gamma`$ に比例し、間隔 1 チップでは、仰角 10° の地面の例で、例のアンテナが 40.5 m、直線偏波のアンテナが 95.8 m である。C/N0 も、反射波の位相が回るにつれて揺れる。和の振幅は $`1 - \gamma`$ から $`1 + \gamma`$ の間を動くので、電力は $`(1 \pm \gamma)^2`$ 倍、C/N0 は $`20\log_{10}(1 \pm \gamma)`$ [dB] だけ揺れる。例のアンテナの $`\gamma`$ = 0.276 で +2.1〜−2.8 dB、直線偏波のアンテナの 0.654 で +4.4〜−9.2 dB である。低い衛星の地面の反射を減らすには、地平線より下の利得を特に小さくしたアンテナ（測量用のチョークリング（地板に同心円の溝を付けたもの）など。名前だけ挙げる）や、仰角マスク（7 章 3 節）を使う。

下の図で、衛星の仰角、反射する面（地面・壁）、面の比誘電率、アンテナの種類を変えると、反射の向き、2 つの反射係数、反射波の右旋と左旋の分、$`\gamma`$ と、7 章の誤差の最大と C/N0 の揺れが表示される。衛星の絵をドラッグして仰角を変えることもできる。

## 3. パッチアンテナ — 寸法・誘電体・給電点

### 形と、電波が出る所

GNSS の受信機で最も多く使われるアンテナは、金属の板（地板）の上に誘電体の板を置き、その上に正方形に近い金属の膜（パッチ）を付けたもので、**パッチアンテナ**という（マイクロストリップアンテナともいう）。誘電体には比誘電率の高いセラミックを使い、一辺 25 mm ほどのセラミックの板の製品が多い（代表値。製品による）。受信機へは、地板の穴を通したピンでパッチにつなぐ（図の (a)）。パッチと受信機をつなぐ点を**給電点**という。

```fig
e08_patch
```

パッチと地板の間の電界は、パッチの両端で向きが逆で、中心で 0 になる（図の (b)）。パッチの縁では電界が外へはみ出し、はみ出した電界から電波が出る。2 つの縁のはみ出した電界の水平な部分は同じ向きなので、真上の向きでは 2 つの縁から出る電波が強め合う。

パッチの下の電界がこの形になる理由は、定在波である。給電点から出た波はパッチの下を進み、縁で跳ね返る。反対向きに進む 2 つの波が重なり、場所ごとに決まった大きさで振動して、進まないように見える波を**定在波**という。跳ね返った波が 1 往復して元の波と同じ位相で重なると、波は強め合って大きくなる。これを**共振**といい、共振が起きる周波数を**共振周波数**という。パッチは、L1 で共振するように寸法を決める。

### 一辺の長さ — 誘電体の中の半波長

**方針**: パッチの下の波が縁で跳ね返って 1 往復したとき、元の波と同じ位相になる最も短い長さを求める。

**導出**: 誘電体の中では電波の速さが $`c/\sqrt{\varepsilon_\mathrm{r}}`$ なので、周波数 $`f`$ の波長は $`\lambda_\mathrm{d} = c/(f\sqrt{\varepsilon_\mathrm{r}}) = \lambda/\sqrt{\varepsilon_\mathrm{r}}`$ である（$`\lambda`$ は真空の波長）。パッチの縁の外は開いているので、電圧の波は縁で符号を変えずに跳ね返る（電界は縁で最も大きい）。一辺を $`\ell`$ とすると、1 往復の道のり $`2\ell`$ が $`\lambda_\mathrm{d}`$ の整数倍のとき強め合う。最も短いのは $`2\ell = \lambda_\mathrm{d}`$ で

$$
\ell = \frac{\lambda_\mathrm{d}}{2} = \frac{\lambda}{2\sqrt{\varepsilon_\mathrm{r}}}
$$

である。このとき、パッチの下に半波長の定在波ができ、電界は中心から $`x`$ の所で $`\sin(\pi x/\ell)`$ に比例して、両端で向きが逆、中心で 0 になる（図の (c)）∎

| 空気 | 1 | 95.1 mm | 127.4 mm |
| フッ素樹脂の基板 | 2.2 | 64.1 mm | 85.9 mm |
| FR-4 の基板 | 4.4 | 45.4 mm | 60.7 mm |

実際には、縁ではみ出した電界の分だけ電気的に長く見えるので、パッチは少し短く作る。はみ出しを入れた設計式（[電磁界シミュレーションシリーズ 17 章 2 節](../emsim/17_アンテナ設計.md#パッチアンテナの初期寸法-設計式)）では、比誘電率 20・厚さ 4 mm（例の値）で 20.9 mm になる。25 mm 角のセラミックの製品は、セラミックの板がパッチより一回り大きい。

比誘電率が高いほどパッチは小さくなる。その代わり、2 つの縁が近づくので真上に集める力が弱まり、パターンが広がる（図の (b)。真上の指向性が下がり、地平線に近い向きが上がる。GNSS には都合のよい面もある）。また、共振の帯域が狭くなり、誘電体の中で熱になる電力が増えて効率が下がりやすい（代表的な傾向。[電磁界シミュレーションシリーズ 17 章 6 節](../emsim/17_アンテナ設計.md#アンテナ特有の落とし穴)）。

### 共振の鋭さ Q と帯域

共振は、共振周波数から離れると弱まる。パッチの 1 つの共振で、共振周波数 $`f_0`$ のときに 1 になるようにそろえた、周波数 $`f`$ のときのパッチの下の電界の振幅と位相（複素数）は、コイルとコンデンサの共振回路と同じ形の

$$
K(f) = \frac{1}{1 + jQ\,(f/f_0 - f_0/f)}
$$

で近似できる（[回路シリーズ 3 章 5 節](../circuit/03_過渡応答とフィルタ.md#rlc-回路と共振)）。$`Q`$ は共振の鋭さを表す数で、これを **Q**（Q 値）という（4 章の I・Q の Q や、3 章 6 節の関数 $`Q(x)`$ とは別の量）。$`Q`$ が大きいほど、共振周波数から少し離れただけで $`|K|`$ が小さくなる。

**方針**: 電力 $`|K|^2`$ が共振周波数のときの半分になる周波数を、$`f_0`$ からのずれが小さいとして求める。

**導出**: $`|K|^2 = 1/\{1 + Q^2(f/f_0 - f_0/f)^2\}`$ が 1/2 になるのは、$`Q(f/f_0 - f_0/f) = \pm 1`$ のときである。$`f = f_0(1 + \delta)`$ とおき、$`\delta`$ が小さいとして $`1/(1 + \delta) \approx 1 - \delta`$ を使うと、$`f/f_0 - f_0/f \approx (1 + \delta) - (1 - \delta) = 2\delta`$ なので、$`2Q\delta = \pm 1`$、$`\delta = \pm 1/(2Q)`$ である。電力が半分以上になる周波数の幅は $`f_0/Q`$ で、両端では $`K = 1/(1 \pm j)`$、大きさ $`1/\sqrt{2}`$、位相 ∓45° である ∎

$`Q`$ = 100（例の値）なら、L1 で幅 15.75 MHz である。正方形のパッチには、横の向きに定在波ができる共振と、縦の向きに定在波ができる共振がある。1 つの共振器の、形の違う共振の 1 つ 1 つを**モード**という。正方形なら 2 つのモードは同じ共振周波数で、横のモードは横の直線偏波、縦のモードは縦の直線偏波を出す。

### 円偏波にする — 2 点で給電する方法と、角を切る方法

2 つのモードを同じ大きさで、位相を 90° ずらして起こせば、2 節の「横と縦の受け口を 90° ずらして足す」形になり、円偏波になる。方法は 2 つある。

- 2 点で給電する（図の (a)）: 横のモードと縦のモードを別々の給電点で起こし、一方の道に 90° の遅れを入れる（90° ハイブリッドという部品などを使う）。周波数が変わっても 90° からずれにくく、軸比の良い帯域が広い。部品が増える。
- 1 点で給電し、角を切る（図の (b)）: 正方形の対角の 2 つの角を切ると、切った角を結ぶ対角の向きのモード v は少し短くなって共振周波数が上がり、もう 1 つの対角の向きのモード u と周波数が離れる。給電点を 2 つの対角から同じ角度（45°）の所に置くと、2 つのモードを同じ強さで起こす。どちらの対角を切るかで、右旋か左旋かが決まる。

**方針**: 2 つのモードの共振周波数を $`f_\mathrm{u} = f_0\{1 - 1/(2Q)\}`$、$`f_\mathrm{v} = f_0\{1 + 1/(2Q)\}`$ に置き、$`f_0`$ での 2 つのモードの応答を比べる。

**導出**: $`f_0`$ は、モード u から見ると共振周波数より $`1/(2Q)`$ の割合だけ高く、前の項の導出で $`\delta = +1/(2Q)`$ にあたるので、モード u の応答は $`K_\mathrm{u} = 1/(1 + j)`$ である。モード v から見ると $`\delta = -1/(2Q)`$ なので、$`K_\mathrm{v} = 1/(1 - j)`$ である。大きさはどちらも $`1/\sqrt{2}`$ で等しく、位相は −45° と +45°、差は 90° である ∎

```fig
e08_cpfeed
```

$`Q`$ = 100 では、2 つのモードの共振周波数を 15.75 MHz 離す（図の (c)。数値で計算すると、L1 で振幅は 0.71 と 0.71、位相の差は 90.0°）。L1 から離れると振幅と位相の差が崩れ、軸比 3 dB 以下に保てる幅は 5.5 MHz で、共振の帯域 $`f_0/Q`$ の約 1/3 である。L1 C/A の信号の主ローブ（2.046 MHz）は入るが、幅の広い信号には足りない（5 節）。

### 給電点 — 50 Ω になる場所

受信機の入力とケーブルは、50 Ω の抵抗をつないだときに電力を最もよく受け渡すように作られている（50 Ω にそろえる理由は 11 章と[基板アートワークシリーズ 10 章 1 節](../pcb/10_インピーダンス制御.md#なぜ特性インピーダンスを揃えるのか)。合わせることを 6 節で整合として扱う）。給電点は、パッチの入力の抵抗が 50 Ω になる所に置く。

**方針**: 電波として出ていく電力は縁の電界で決まり、給電点の位置によらない。給電点の電圧から、入力の抵抗を求める。

**導出**: 一辺 $`\ell`$ の定在波で、中心から $`x`$ の所の電界は $`E(x) = E_\mathrm{e}\sin(\pi x/\ell)`$ である（$`E_\mathrm{e}`$ は縁の電界）。給電点の電圧の振幅は、電界に誘電体の厚さ $`h_\mathrm{d}`$ を掛けた $`E(x)h_\mathrm{d}`$ である。共振のとき入力は抵抗 $`R(x)`$ だけに見え、入る電力 $`P = \{E(x)h_\mathrm{d}\}^2/(2R(x))`$ が、出ていく電力（と熱になる電力）に等しい。$`P`$ は縁の電界 $`E_\mathrm{e}`$ だけで決まるので、$`R(x) = \{E(x)h_\mathrm{d}\}^2/(2P) = R_\mathrm{e}\sin^2(\pi x/\ell)`$ である（$`R_\mathrm{e} = (E_\mathrm{e}h_\mathrm{d})^2/(2P)`$ は縁での入力の抵抗）。縁で $`R_\mathrm{e}`$ = 200 Ω（例の値）なら、50 Ω になるのは $`\sin^2(\pi x/\ell) = 1/4`$、$`\sin(\pi x/\ell) = 1/2`$、$`x = \ell/6`$ の所である ∎

一辺 21.3 mm のパッチなら、中心から 3.5 mm の所である（図の (c)）。給電点を縁に寄せるほど抵抗が大きく、中心では 0 になるので、位置を少し変えて 50 Ω に合わせられる（調整の実際は[電磁界シミュレーションシリーズ 17 章 3 節](../emsim/17_アンテナ設計.md#給電と整合)）。

## 4. 地板 — 大きさで変わる指向性と共振周波数

### 地板の働きと、縁での回折

パッチアンテナの下の金属の板を**地板**（グラウンドプレーン）という。地板は、パッチと組になって共振を作る（パッチの下の電界は地板で終わる）。また、パッチから下へ向かう電波を跳ね返して、上の半分へ向ける。地板が無限に大きければ、電波は上の半分だけに出る（次の図の (a)）。

実際の地板は有限である。地板に沿って進んだ電波は、縁で向きを変えて回り込み、縁を中心に全部の向きへ広がる（図の (b)）。電波が物の縁で回り込んで、影になる側にも届くことを**回折**という。回り込んだ電波は、地板の裏（下の半分）にも届く。

```fig
e08_gpidea
```

図の (c) は、地平線の前後の垂直の成分の電界を、地板の奥行きを無限とした 2 次元の近似で、モーメント法（金属の上の電流を未知数にして解く方法。[電磁界シミュレーションシリーズ 8 章](../emsim/08_MoM.md#発想の転換-場ではなく源を未知数にする)）で計算したものである。無限の地板では、地平線を境に電界が急に 0 になる段差がある。有限の地板では、縁で回り込んだ電波が段差をならし、地平線でほぼ半分（一辺 70 mm で 0.48 倍、−6.3 dB）になる。縁の真横の向き（影の境目）では、回り込んだ電波が、段差のちょうど半分を埋めるからである（回折の理論の結果を、ここでは数値の計算で確かめた）。

### 地板の大きさとパターン

真上の利得と真下の利得の比（dB の差）を**前後比**という。前後比が大きいほど、地板の裏へ漏れる電波が小さい。

```fig
e08_gpsize
```

同じ 2 次元の近似で、地板の一辺を変えて計算した（図）。地板が大きいほど真下へ漏れる電波が小さく、その分だけ真上が強い。前後比は、一辺 50 mm で 3.1 dB、70 mm で 6.1 dB、150 mm で 13.7 dB である。地平線の値は、一辺が 50 mm より大きければ大きさであまり変わらず、無限の地板より 5〜7 dB 低い（電界でほぼ半分）。真下や地平線より下の利得が大きいと、地面の反射波（2 節の $`\gamma`$）と、地面の熱雑音（約 290 K。アンテナの雑音温度を上げる。3 章 5 節）を多く受ける。実際の 3 次元の地板では値が変わるので、傾向として見る。製品のデータシートには、どの大きさの地板で測った値かが書いてあり、70 mm 角ほどの地板を前提にする製品が多い（代表値。製品による）。

### 地板の大きさと共振周波数

パッチの縁ではみ出した電界は地板まで伸びるので、地板がパッチに比べて十分大きくないと、はみ出し方が変わり、共振周波数がずれる。どちらへどれだけずれるかは、パッチと地板の形で違う（製品による）。セラミックのパッチの製品は、データシートの大きさの地板で L1 に合うように作られている（代表的な作り方）。それと違う地板で使うときは、6 節の方法で共振周波数を測って確かめる。共振周波数がずれると、L1 での軸比が悪くなる（3 節の 5.5 MHz の幅）。

### 機器の中の地板

機器では、基板のグラウンドの面が地板になる。地板の上や近くにある部品・電池・表示器・ケーブルは、地板の形を変え、電波を遮り、反射する。アンテナを空に向け、データシートのとおりの地板の上に置くのが基本である。基板の上のアンテナの配線と、銅を置かない領域（キープアウト）は 11 章 6 節、筐体の材料と置き方は 22 章で扱う。

## 5. いろいろなアンテナ — チップ・ヘリカル・多周波

### チップアンテナ

**チップアンテナ**は、長さ数 mm〜10 mm ほど（代表値）のセラミックの小さな部品を、基板の端に載せたアンテナである。部品そのものは小さいが、基板のグラウンドの面にも電流が流れ、基板の全体がアンテナの一部として働く。そのため、基板の大きさと部品の置き方で性能が大きく変わり、部品の周りのキープアウトと、50 Ω に合わせる部品（6 節の整合のため。11 章）が要る。偏波は直線偏波に近く、右旋の電波を 3 dB 以上損し（2 節）、反射波を回る向きで区別できない。小さく安いので、腕時計や小さな追跡の機器に使われる。

### ヘリカルアンテナ

**ヘリカルアンテナ**は、導線をらせん状に巻いたアンテナである。GNSS では、4 本の導線を円筒のまわりに巻いた形（四線巻き。QFH、quadrifilar helix）が使われ、4 本を 90° ずつずらした位相で働かせて円偏波にする。上の半分の広い範囲で軸比が小さく、地平線に近い向きの利得がパッチより下がりにくい（代表的な特徴）。大きな地板が要らないので、向きが変わるドローンや、身に着ける機器、測量にも使われる。パッチより大きく、作るのに手間がかかる。

### 多周波アンテナ

L1 と L5 のように、2 つ以上の周波数帯を受けるアンテナを**多周波アンテナ**という（多周波の受信機は 18 章）。L1 だけのパッチより難しい点が 2 つある。1 つは、2 つの周波数で共振させることである。L5 用の大きいパッチ（比誘電率 20 で 28.5 mm）の上に、L1 用の小さいパッチを重ねる形（積み重ねたパッチ）などがある。もう 1 つは、帯域である。L5 の信号はチップレートが L1 C/A の 10 倍（10.23 M チップ/s）で、BPSK の主ローブの幅が 20.46 MHz ある（2 章 4 節）。3 節と同じ $`Q`$ = 100 の 1 点給電のパッチを L5 に作ると、軸比 3 dB 以下の幅は 4.1 MHz で、主ローブの 1/5 しか覆えない（図の (c)）。軸比の幅を 20 MHz にするには $`Q`$ を 20 ほどまで下げる（厚く、比誘電率の低い誘電体にする）か、帯域の広い 2 点給電を使う。L1 の付近でも、BeiDou の B1I（1561.098 MHz）から GLONASS の G1（1602 MHz 付近。衛星ごとに周波数が違う）までを 1 つのアンテナで受けるには、50 MHz 近い幅が要る（2 章 1 節）。

## 6. 整合と測り方 — 反射とリターンロス

### 整合と反射係数

アンテナを受信機（またはケーブル）につないだとき、アンテナが受けた電力が、受信機に全部渡るとは限らない。受信機の入力とケーブルは、基準のインピーダンス $`Z_0`$ = 50 Ω で作られている（11 章）。アンテナの端子から見たインピーダンス（交流の電圧と電流の比を、位相のずれを含めて複素数で表したもの。[回路シリーズ 2 章](../circuit/02_受動素子.md#インピーダンス)）を $`Z_\mathrm{A} = R_\mathrm{A} + jX_\mathrm{A}`$ とする。$`Z_\mathrm{A}`$ を $`Z_0`$ に合わせ、電力を最もよく受け渡すようにすることを**整合**という。

可逆性があるので、損失は送るときで考えてよい。50 Ω の信号源からアンテナに向かう電圧の波は、$`Z_\mathrm{A} \ne Z_0`$ だと一部が跳ね返る。2 節の反射係数と同じく、跳ね返る電圧の波を入っていく電圧の波で割った比（振幅と位相を含む複素数）を、アンテナの反射係数 $`\Gamma`$ という。線路（ケーブルや基板の配線）を進む波の理論から、$`\Gamma = (Z_\mathrm{A} - Z_0)/(Z_\mathrm{A} + Z_0)`$ である（[回路シリーズ 23 章 3 節](../circuit/23_基板設計.md#反射-リンギングの正体)、11 章 1 節）。

**方針**: 内部の抵抗 $`Z_0`$ の信号源にアンテナをつないだ回路で、アンテナに入る電力を、$`Z_\mathrm{A} = Z_0`$ のときの電力と比べる。

**導出**: 信号源の電圧の振幅を $`V_\mathrm{s}`$ とする。電流の振幅は $`I_\mathrm{A} = V_\mathrm{s}/(Z_0 + Z_\mathrm{A})`$ で、アンテナに入る電力は抵抗の部分で消費される $`P = |I_\mathrm{A}|^2R_\mathrm{A}/2 = |V_\mathrm{s}|^2R_\mathrm{A}/(2|Z_\mathrm{A} + Z_0|^2)`$ である。$`Z_\mathrm{A} = Z_0`$ のときは $`P_0 = |V_\mathrm{s}|^2/(8Z_0)`$ なので、比は $`P/P_0 = 4Z_0R_\mathrm{A}/|Z_\mathrm{A} + Z_0|^2`$ である。一方、$`|Z_\mathrm{A} + Z_0|^2 - |Z_\mathrm{A} - Z_0|^2 = \{(R_\mathrm{A} + Z_0)^2 + X_\mathrm{A}^2\} - \{(R_\mathrm{A} - Z_0)^2 + X_\mathrm{A}^2\} = 4Z_0R_\mathrm{A}`$ なので、

$$
\frac{P}{P_0} = \frac{|Z_\mathrm{A} + Z_0|^2 - |Z_\mathrm{A} - Z_0|^2}{|Z_\mathrm{A} + Z_0|^2} = 1 - |\Gamma|^2
$$

である。$`|\Gamma|^2 \ge 0`$ なので $`P \le P_0`$ で、整合したときの電力が最大である ∎

### リターンロス・VSWR・不整合損失

跳ね返った電力の割合 $`|\Gamma|^2`$ を、3 つの数で表す。反射した波が入っていく波より何 dB 小さいかを**リターンロス** RL $`= -20\log_{10}|\Gamma|`$ [dB] という（大きいほど良い）。線路の上では、入っていく波と跳ね返った波が重なって定在波（3 節）ができ、電圧の振幅は、2 つの波が同じ向きに重なる所で $`1 + |\Gamma|`$、逆向きの所で $`1 - |\Gamma|`$ になる（入っていく波を 1 とした）。その比 $`(1 + |\Gamma|)/(1 - |\Gamma|)`$ を **VSWR**（voltage standing wave ratio、電圧定在波比）という（整合で 1、全部跳ね返ると ∞）。渡らなかった分による損失 $`-10\log_{10}(1 - |\Gamma|^2)`$ [dB] を**不整合損失**という。

アンテナでは、リターンロス 10 dB（VSWR 約 2）以上を目安にすることが多い（代表値）。そのときの不整合損失は 0.46 dB で、受ける信号の電力が同じだけ下がる（C/N0 への効き方は、LNA の雑音も関わるので 9 章）。

### スミスチャート

$`\Gamma`$ は複素数なので、複素数の平面の上の点として描ける。$`\Gamma`$ の平面に、抵抗 $`R_\mathrm{A}`$ が一定の線と、リアクタンス $`X_\mathrm{A}`$ が一定の線を描き込んだ図を**スミスチャート**という。$`R_\mathrm{A} \ge 0`$ のアンテナの $`\Gamma`$ は、半径 1 の円の中に入る。中心が $`\Gamma`$ = 0（50 Ω。整合）、左の端が短絡（0 Ω、$`\Gamma`$ = −1）、右の端が開放（∞、$`\Gamma`$ = +1）である。上の半分は $`X_\mathrm{A}`$ > 0（コイルの性質）、下の半分は $`X_\mathrm{A}`$ < 0（コンデンサの性質）で、中心からの距離が $`|\Gamma|`$ なので、中心のまわりの同じ円の上では、リターンロスと VSWR が同じである。例えば 25 Ω は $`\Gamma`$ = −1/3、100 Ω は +1/3 で、どちらも VSWR 2.0 の円の上にある。50 + j50 Ω は 0.2 + 0.4j（$`|\Gamma|`$ = 0.447、リターンロス 7.0 dB）である。

### ネットワークアナライザで S11 を測る

アンテナの反射係数は、**ネットワークアナライザ**で測る。周波数を変えながら、端子から信号を送り込み、跳ね返ってくる信号との振幅と位相の比を測る測定器である。測る前に、ケーブルの先に短絡・開放・50 Ω の 3 つの基準をつないで、ケーブルの影響を取り除く（校正）。1 つ目の端子に送り込んで 1 つ目の端子に戻る比を **S11** という（端子に入る波と出る波の比をまとめた S パラメータの 1 つ。[電磁界シミュレーションシリーズ 14 章 2 節](../emsim/14_Sパラメータ.md#各要素の読み方)）。アンテナの S11 は $`\Gamma`$ そのもので、dB で表した $`20\log_{10}|S_{11}|`$ は、リターンロスに負の符号を付けた値である。

```fig

```

図の (b) は、3 節の例のパッチ（1 点給電、$`Q`$ = 100）の S11 を、2 つのモードの共振回路を直列につないだモデルで計算したものである（L1 で 50 Ω になるようにした）。2 つのモードの共振周波数が離れているので、S11 の谷は広く、−10 dB 以下の幅は 21.4 MHz ある（直線偏波の 1 つのモードなら 10.5 MHz）。軸比 3 dB 以下の幅 5.5 MHz よりずっと広いので、S11 が良くても軸比が良いとは限らない。円偏波のアンテナでは、軸比やパターンも測るか、データシートの値で確かめる。

樹脂の筐体に入れると、共振周波数が下がる（22 章）。例として 5 MHz 下がると、L1 での S11 は −20.7 dB でまだ良く、右旋の電波を受ける強さも 0.42 dB しか下がらないが、軸比は 5.5 dB になり、左旋の反射波を −10.7 dB でしか弱められなくなる（2 節）。10 MHz 下がると、S11 は −10.8 dB、軸比は 10.4 dB、右旋の損失は 1.5 dB になる。L1 の 1 点だけを見ても気づきにくいが、周波数特性を見れば、谷の中心がずれたことが分かる。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 指向性・効率・利得 | 指向性は出ていく電力、利得は入れた電力が基準で $`G_\mathrm{a} = \eta_\mathrm{a}D_\mathrm{a}`$。利得を全部の向きで平均すると効率（例のアンテナで 56.6 %、真上の指向性 5.47 dBi） |
| 可逆性 | 送るときと受けるときで、向きごとの利得と偏波が同じ。実効開口面積は $`G_\mathrm{a}\lambda^2/(4\pi)`$（真上 +3 dBi で 57.5 cm²） |
| 偏波・地平線 | 地板に沿う向きの電界は 0。地平線では水平の成分を失い、右旋の電波を受ける強さは 1/4（−6 dB）になる |
| 円偏波・軸比 | 進む向きに見て時計回りが右旋。楕円偏波は右旋と左旋の和で、軸比 $`(a_\mathrm{R} + a_\mathrm{L})/|a_\mathrm{R} - a_\mathrm{L}|`$ |
| 偏波の損失 | 直線偏波で右旋を受けると −3.01 dB。軸比 3 dB の右旋のアンテナは左旋を −15.5 dB で受ける |
| 反射 | 金属では $`\Gamma_\mathrm{H}`$ = −1・$`\Gamma_\mathrm{V}`$ = +1 で右旋が左旋に。一般には右旋の分 $`(\Gamma_\mathrm{V} + \Gamma_\mathrm{H})/2`$・左旋の分 $`(\Gamma_\mathrm{V} - \Gamma_\mathrm{H})/2`$ |
| ブルースター角 | $`\tan\psi_\mathrm{B} = 1/\sqrt{\varepsilon_\mathrm{r}}`$（比誘電率 4 で 26.6°）。より浅い反射では右旋が残る |
| 反射波の比 $`\gamma`$ | 比誘電率 4 の地面・仰角 30° で、例のアンテナ 0.11、直線偏波 0.40。仰角 10° では 0.28 と 0.65 で、低い衛星の地面の反射は弱めにくい |
| パッチの寸法 | 一辺 $`\lambda/(2\sqrt{\varepsilon_\mathrm{r}})`$（誘電体の中の半波長の定在波）。比誘電率 20 で 21.3 mm。比誘電率が高いほど小さく、パターンが広く、帯域が狭い |
| Q と円偏波 | 帯域 $`f_0/Q`$（Q = 100 で 15.75 MHz）。2 つのモードを $`f_0/Q`$ 離すと L1 で ±45°。軸比 3 dB 以下は 5.5 MHz |
| 給電点 | 入力の抵抗は $`R_\mathrm{e}\sin^2(\pi x/\ell)`$。縁で 200 Ω なら中心から $`\ell/6`$ で 50 Ω |
| 地板 | 縁で回折し、地平線の電界はほぼ半分、裏へ漏れる。前後比は一辺 50 mm で 3.1 dB、150 mm で 13.7 dB（2 次元の近似）。共振周波数もずれるので、使う地板で確かめる |
| ほかのアンテナ | チップ（小さい・直線偏波・基板と一体）、ヘリカル（円偏波を広い向きで・地板が要らない）、多周波（2 つの共振と広い帯域。L5 の主ローブは 20.46 MHz） |
| 整合 | $`\Gamma = (Z_\mathrm{A} - Z_0)/(Z_\mathrm{A} + Z_0)`$、渡る電力 $`1 - |\Gamma|^2`$。リターンロス 10 dB で VSWR 1.92、不整合損失 0.46 dB |
| S11 | ネットワークアナライザで測る $`\Gamma`$。S11 の良い幅（21.4 MHz）は軸比の良い幅（5.5 MHz）より広い。共振が 5 MHz 下がると軸比 5.5 dB |
