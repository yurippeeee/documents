## 1. アンテナの指標 — 利得・指向性・偏波

アンテナは、受信機の流れの最初にあり、空間を進んでくる電波を、ケーブルの中を進む電気の信号に変える。

```fig
e08_role
```

この節では、図の (b) の ①〜③ を数で表す指標を定義する。

### 放射パターンと指向性

アンテナの性質は、電波を送るときで考える。受けるときも同じになることは、後の項で示す。アンテナに電力を入れたとき、向きごとに出ていく電波の強さの分布を**放射パターン**（パターン）という。ある向きに出ていく電波の 1 m² あたりの電力を、出ていく電力の全部を全部の向きに均等に出したときの値で割った比を、その向きの**指向性** $`D_\mathrm{a}`$ という。均等に出したときの値で割っているので、指向性を全部の向きで平均すると 1 になる。

全部の電力を上の半分の空に均等に出すアンテナでは、上の半分の指向性は 2（3.01 dBi）、下の半分は 0 になる。GNSS のアンテナの理想は、この形である。

### 効率と利得

アンテナに入れた電力の一部は、金属や誘電体の中で熱になり、電波にならない。入れた電力のうち、電波として出ていく割合を**アンテナの効率** $`\eta_\mathrm{a}`$ という。ある向きの**利得** $`G_\mathrm{a}`$ は、その向きに出ていく電波の 1 m² あたりの電力が、入れた電力を等方性アンテナで出したときの何倍かである。指向性は出ていく電力を基準にし、利得は入れた電力を基準にするので、$`G_\mathrm{a} = \eta_\mathrm{a}D_\mathrm{a}`$ である（混同しやすい量の整理は[電磁界シミュレーションシリーズ 15 章 3 節](../emsim/15_遠方界.md#アンテナの諸量-混同しやすい-4-つ)）。3 章で「真上で +3 dBi」と書いた値は、この利得である。

次の図は、3 章 3 節の例のアンテナに、地平線より下の利得と、逆の偏波（2 節）に対する利得を足したものである。

```fig
e08_pattern
```

パターンが分かると、効率が求まる。

**方針**: 利得を全部の向きで平均すると、指向性の平均が 1 なので、効率が残る。方位によらないパターンでは、その平均を仰角の積分に直す。

**導出**: $`G_\mathrm{a} = \eta_\mathrm{a}D_\mathrm{a}`$ で、$`\eta_\mathrm{a}`$ は向きによらない。したがって、$`G_\mathrm{a}`$ を全部の向きで平均すると $`\eta_\mathrm{a} \times 1 = \eta_\mathrm{a}`$ である。この平均は、半径 1 の球面の上でとる。仰角が $`\theta`$ と $`\theta + d\theta`$ の間の帯は、周りの長さが $`2\pi\cos\theta`$、幅が $`d\theta`$ なので、面積は $`2\pi\cos\theta\,d\theta`$ である。球面の全体は $`4\pi`$ である。$`G_\mathrm{a}(\theta)`$ を、2 つの偏波に対する利得の和（真数）とすると、その平均は

$$
\eta_\mathrm{a} = \frac{1}{4\pi}\int_{-\pi/2}^{\pi/2} G_\mathrm{a}(\theta)\,2\pi\cos\theta\,d\theta = \frac{1}{2}\int_{-\pi/2}^{\pi/2} G_\mathrm{a}(\theta)\cos\theta\,d\theta
$$

である ∎

例のアンテナで数値の積分をすると、効率は 56.6 % で、残りは熱になる（図の (c)）。真上の指向性は、$`D_\mathrm{a} = G_\mathrm{a}/\eta_\mathrm{a}`$ を dB で書いた $`3 - 10\log_{10}0.566`$ = 5.47 dBi である。上の半分に均等に出す理想の 3.01 dBi より大きいのは、真上に強く、地平線に近い向きに弱く出しているからである。

### 可逆性 — 送るときと受けるときで同じ

送るときの向きごとの利得は、同じアンテナで受けるときに、その向きから来る電波を受ける強さの倍率に等しい。送るときの偏波は、受けるときに最もよく受ける偏波に等しい。これを**可逆性**（相反性）という。電磁気の法則から導かれる性質で、ここでは結果だけを使う（利得と開口面積の関係は[レーダーシリーズ 11 章 3 節](../radar/11_アンテナとビーム.md#利得と開口面積-03-章の借りを返す)）。

```fig
e08_recip
```

受けるときの実効開口面積は、その向きの利得から $`A_\mathrm{e} = G_\mathrm{a}\lambda^2/(4\pi)`$ で求まる（3 章 1 節）。例のアンテナの真上では 57.5 cm² で、25 mm 角のセラミックの板の約 9 倍である。アンテナは、自分の大きさより広い範囲の電波を集める。

### 偏波と、地平線で利得が下がる理由

電波は、進む向きに垂直な面の中で電界が振動しながら進む。電界の向きが時間とともにどう変わるかを、その電波の**偏波**という。電界の向きが一定で、大きさと符号だけが変わる偏波を**直線偏波**という（[レーダーシリーズ 2 章 6 節](../radar/02_電波の基礎.md#偏波-電場の向き)）。どの偏波も、向きが直交する 2 つの直線偏波の和に分けられる。この章では、電波の進む向きと真上の向きを含む垂直な面の中の成分を**垂直の成分**、それに直交する水平な向きの成分を**水平の成分**という。衛星の電波は、2 つの成分を同じ大きさで含み、その位相が 90° ずれている（2 節の円偏波）。

GNSS で多く使われるパッチアンテナ（3 節）は、地板と呼ぶ金属の板の上に置かれる（4 節）。金属の面に沿う向きの電界は、金属の中の電子が動いて打ち消すので、面のすぐ上では 0 になる。地平線の向きに出ていく電波は地板に沿って進むので、地板に沿う水平の成分だけが 0 になる。仰角が上がると水平の成分も出せるようになり、パッチでは仰角の sin にほぼ比例する。

```fig
e08_horizon
```

したがって、地平線に近い向きのアンテナは、衛星から来る電波の水平の成分を、ほとんど受けられない。どれだけ損するかは、2 節で偏波の損失を求めてから計算する。

## 2. 右旋円偏波 — 衛星の電波の向きとマルチパス

### 円偏波 — 電界の向きが回りながら進む

電界の大きさが一定で、向きが 1 周期に 1 回、一定の速さで回る偏波を**円偏波**という。2 つの成分が、$`\sin\omega t`$ と $`\cos\omega t`$ のように、同じ大きさで位相が 90° ずれていると、和のベクトルの長さは $`\sqrt{\sin^2\omega t + \cos^2\omega t}`$ = 1 で一定になり、先は円を描く。電波の進む向きに見て、電界の向きが時計回りに回る円偏波を**右旋円偏波**（RHCP、right-hand circular polarization）という。反時計回りに回る円偏波を**左旋円偏波**（LHCP、left-hand circular polarization）という。この向きの決め方は、IEEE の定め方である。

```fig
e08_cp
```

GNSS の衛星の信号は、右旋円偏波である（GPS は規格 IS-GPS-200 で定めている）。円偏波なら、衛星と受信機のアンテナが、電波の進む向きのまわりでどう回っていても、受ける強さが変わらない。電離層を通るときに直線偏波の向きが回る現象（ファラデー回転）の影響も受けない。

### 楕円偏波と軸比

2 つの成分の大きさが違うか、位相のずれが 90° でないと、電界の先は楕円を描く。この偏波を**楕円偏波**という。楕円の長い軸と短い軸の長さの比を**軸比**（AR、axial ratio）という。$`20\log_{10}`$ をとって dB で表すことが多く、円で 0 dB、直線で ∞ である。楕円偏波は、右旋と左旋の円偏波の和で表せる（図の (b)）。

**方針**: 振幅 $`a_\mathrm{R}`$ の右旋と、振幅 $`a_\mathrm{L}`$ の左旋を足し、和の先の描く形と、長い軸・短い軸を求める。

**導出**: 電波の進む向きに見て、右を $`x`$、上を $`y`$ とする。時刻の原点は、2 つの円偏波がどちらも上を向く時刻に選ぶ。時計回りの右旋は、1/4 周期で右を向くので、$`a_\mathrm{R}(\sin\omega t,\ \cos\omega t)`$ と書ける。反時計回りの左旋は、1/4 周期で左を向くので、$`a_\mathrm{L}(-\sin\omega t,\ \cos\omega t)`$ と書ける。和は $`x = (a_\mathrm{R} - a_\mathrm{L})\sin\omega t`$、$`y = (a_\mathrm{R} + a_\mathrm{L})\cos\omega t`$ で、$`\sin^2 + \cos^2 = 1`$ から

$$
\frac{x^2}{(a_\mathrm{R} - a_\mathrm{L})^2} + \frac{y^2}{(a_\mathrm{R} + a_\mathrm{L})^2} = 1
$$

の楕円である。原点を別の時刻に選ぶと、楕円が傾くだけで、形は同じである。長い軸は $`2(a_\mathrm{R} + a_\mathrm{L})`$、短い軸は $`2|a_\mathrm{R} - a_\mathrm{L}|`$ なので、軸比は $`\mathrm{AR} = (a_\mathrm{R} + a_\mathrm{L})/|a_\mathrm{R} - a_\mathrm{L}|`$ である。$`a_\mathrm{R} > a_\mathrm{L}`$ なら $`x`$ の係数が正で、右旋と同じ向きに回る。逆に解くと、振幅の比は $`a_\mathrm{L}/a_\mathrm{R} = (\mathrm{AR} - 1)/(\mathrm{AR} + 1)`$ である ∎

### 偏波が合わないときの損失

右旋の電波を受けるアンテナは、横と縦の直線偏波を受ける 2 つの受け口を持ち、縦の出力を 90° 遅らせてから足すもの、と考えられる。パッチで 90° のずれを作る方法は、3 節で扱う。前の項と同じく、右を横、上を縦とすると、右旋の電波は、横の成分が $`\sin\omega t`$、縦の成分が $`\cos\omega t`$ である。

**方針**: 右旋・横の直線偏波・左旋の電波を、同じ電力で受け口に入れ、足した出力の電力を比べる。

**導出**: 縦の成分を 90° 遅らせると、$`\cos(\omega t - 90°) = \sin\omega t`$ になる。電波の電力は、各成分の振幅の 2 乗の和に比例する。振幅が 1 と 1 の右旋と、振幅 $`\sqrt{2}`$ の直線偏波は、同じ電力である。

- 右旋（横 $`\sin\omega t`$、縦 $`\cos\omega t`$）: 出力は $`\sin\omega t + \sin\omega t = 2\sin\omega t`$ で、電力は振幅の 2 乗に比例して 4。
- 横の直線偏波（横 $`\sqrt{2}\sin\omega t`$、縦 0）: 出力は $`\sqrt{2}\sin\omega t`$ で、電力は 2。
- 左旋（横 $`-\sin\omega t`$、縦 $`\cos\omega t`$）: 出力は $`-\sin\omega t + \sin\omega t = 0`$。

右旋を受ける電力を 1 とすると、直線偏波は 1/2（−3.01 dB）、左旋は 0 である ∎

```fig
e08_plf
```

可逆性から、直線偏波のアンテナで右旋の電波を受けても、受ける電力は 1/2 になる。

アンテナの偏波は、送るときに出す電波の偏波で決める。軸比が 0 dB でない右旋のアンテナは、右旋だけを受ける理想のアンテナと、左旋だけを受ける理想のアンテナを、振幅の比 $`a_\mathrm{R} : a_\mathrm{L}`$ で組み合わせたものとみなせる。電力の割合は $`a_\mathrm{R}^2 : a_\mathrm{L}^2`$ なので、右旋の電波を $`a_\mathrm{R}^2/(a_\mathrm{R}^2 + a_\mathrm{L}^2)`$、左旋の電波を $`a_\mathrm{L}^2/(a_\mathrm{R}^2 + a_\mathrm{L}^2)`$ の割合で受ける。軸比 3 dB のアンテナは、右旋の電波をほとんど損しないが、左旋の電波も −15.5 dB で受けてしまう（図の (b)）。

地平線の向きでは、アンテナは水平の成分を出せないので、アンテナの偏波は垂直の直線偏波になる（1 節）。そのときの利得の下がり方を、次の図に示す。

```fig

```

図の ① と ② は、地板の上のアンテナなら必ず起き、合わせて 1/4（−6.02 dB）である。地板の縁の影響は、4 節で扱う。

### 反射すると回る向きが逆になる

電波が面で反射するとき、入ってくる電波の進む向きと、面に垂直な向きを含む平面を**入射面**という。反射は、電界を、入射面に垂直で面に沿う成分 H と、入射面の中の成分 V に分けて考える。地面での反射では、H は 1 節の水平の成分、V は垂直の成分である。成分ごとに、反射した波の振幅を入ってきた波の振幅で割った比を、その成分の**反射係数**といい、$`\Gamma_\mathrm{H}`$・$`\Gamma_\mathrm{V}`$ と書く。この比は符号を含む。V の成分の符号は、面に垂直な部分が、入ってきた波と反射した波で同じ向きのときを正とする。面と電波の進む向きのなす角を $`\psi`$ と書く。7 章の $`\psi_\mathrm{M}`$ とは別の量である。

金属の面では、面に沿う向きの電界が 0 なので（1 節）、入ってきた波と反射した波の、面に沿う部分が打ち消し合う。そのため、H の成分は逆向きに反射し（$`\Gamma_\mathrm{H} = -1`$）、V の成分は、面に垂直な部分が同じ向きになる（$`\Gamma_\mathrm{V} = +1`$）。片方の成分だけ符号が変わるので、反射した波は、入ってきた波を鏡に映した形になる。

```fig
e08_mirror
```

したがって、金属で反射した右旋の電波は、左旋になる（図の (b)）。

金属でない面では、右旋の電波が反射すると、どれだけが右旋で残り、どれだけが左旋になるかを求める。

**方針**: 2 つの反射係数を、「同じ値の部分」と「逆の値の部分」に分け、それぞれの部分が回る向きをどう変えるかを調べる。

**導出**: $`\Gamma_\mathrm{R} = (\Gamma_\mathrm{V} + \Gamma_\mathrm{H})/2`$、$`\Gamma_\mathrm{L} = (\Gamma_\mathrm{V} - \Gamma_\mathrm{H})/2`$ とおくと、$`\Gamma_\mathrm{V} = \Gamma_\mathrm{R} + \Gamma_\mathrm{L}`$、$`\Gamma_\mathrm{H} = \Gamma_\mathrm{R} - \Gamma_\mathrm{L}`$ である。反射は成分ごとに係数を掛けるだけなので、反射した波は 2 つの波の和になる。1 つは、金属の反射（$`\Gamma_\mathrm{V}`$ = +1、$`\Gamma_\mathrm{H}`$ = −1）の $`\Gamma_\mathrm{L}`$ 倍である。もう 1 つは、$`\Gamma_\mathrm{V} = \Gamma_\mathrm{H}`$ = +1 の反射の $`\Gamma_\mathrm{R}`$ 倍である。金属の反射は、右旋を同じ振幅の左旋に変える。$`\Gamma_\mathrm{V} = \Gamma_\mathrm{H}`$ = +1 の反射は、金属の反射の後に、H の成分の符号だけを変えたものである。円偏波は、片方の成分の符号を変えると、回る向きが逆になる（右旋の横の成分 $`\sin\omega t`$ を $`-\sin\omega t`$ にすると左旋）。そのため、金属の反射で左旋になった波が、右旋に戻る。したがって、反射した波は、入ってきた右旋の $`\Gamma_\mathrm{R}`$ 倍の右旋と、$`\Gamma_\mathrm{L}`$ 倍の左旋の和である ∎

金属では $`\Gamma_\mathrm{R}`$ = 0、$`\Gamma_\mathrm{L}`$ = 1 で、全部が左旋になる。$`\Gamma_\mathrm{V}`$ と $`\Gamma_\mathrm{H}`$ が同じ符号なら右旋が多く残り、逆の符号なら左旋が多い。

下の図で、電波とアンテナの偏波を選び、金属で反射させて、電界の回る向きと受ける電力を確かめられる。

### 誘電体の面の反射とブルースター角

地面・コンクリート・ガラス・樹脂のように、電気をほとんど通さず、電界の中で内部の電荷がわずかにずれる物を**誘電体**という。コンデンサの板の間をその材料で満たしたとき、静電容量が真空の何倍になるかを表す数を、その材料の**比誘電率** $`\varepsilon_\mathrm{r}`$ という。誘電体の中では、電波の速さが $`c/\sqrt{\varepsilon_\mathrm{r}}`$ になり、同じ周波数の波長が $`1/\sqrt{\varepsilon_\mathrm{r}}`$ 倍に縮む（3 節で使う）。

損失の無い誘電体の、平らな面の反射係数は、次のフレネルの式で表される。面に沿う電界と磁界が面の両側でつながる、という条件から求まる。導出は電磁気学の教科書による。

$$
\Gamma_\mathrm{H} = \frac{\sin\psi - \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}}{\sin\psi + \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}}, \qquad
\Gamma_\mathrm{V} = \frac{\varepsilon_\mathrm{r}\sin\psi - \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}}{\varepsilon_\mathrm{r}\sin\psi + \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}}
$$

式の両端を確かめる。すれすれ（$`\psi \to 0`$）では、どちらも −1 に近づき、$`\Gamma_\mathrm{L} \to 0`$ で、右旋のまま反射する。真上から当たる $`\psi`$ = 90° では、$`\Gamma_\mathrm{H} = (1 - \sqrt{\varepsilon_\mathrm{r}})/(1 + \sqrt{\varepsilon_\mathrm{r}})`$、$`\Gamma_\mathrm{V} = (\varepsilon_\mathrm{r} - \sqrt{\varepsilon_\mathrm{r}})/(\varepsilon_\mathrm{r} + \sqrt{\varepsilon_\mathrm{r}}) = -\Gamma_\mathrm{H}`$ で、$`\Gamma_\mathrm{R}`$ = 0 となり、全部が左旋になる。その間で、$`\Gamma_\mathrm{V}`$ は負から正へ符号を変える。$`\Gamma_\mathrm{V}`$ が 0 になる角を**ブルースター角** $`\psi_\mathrm{B}`$ という。

**方針**: $`\Gamma_\mathrm{V}`$ の分子が 0 になる条件を、$`\sin\psi`$ について解く。

**導出**: 分子が 0 の条件は $`\varepsilon_\mathrm{r}\sin\psi = \sqrt{\varepsilon_\mathrm{r} - \cos^2\psi}`$ である。両辺を 2 乗して $`\cos^2\psi = 1 - \sin^2\psi`$ を入れると、$`\varepsilon_\mathrm{r}^2\sin^2\psi = \varepsilon_\mathrm{r} - 1 + \sin^2\psi`$ になる。移項すると $`(\varepsilon_\mathrm{r}^2 - 1)\sin^2\psi = \varepsilon_\mathrm{r} - 1`$ である。$`\varepsilon_\mathrm{r}`$ > 1 なので、両辺を正の数 $`\varepsilon_\mathrm{r} - 1`$ で割れて、$`\sin^2\psi = 1/(\varepsilon_\mathrm{r} + 1)`$、$`\cos^2\psi = \varepsilon_\mathrm{r}/(\varepsilon_\mathrm{r} + 1)`$ である。比をとり、正の解を選ぶと

$$
\tan\psi_\mathrm{B} = \frac{1}{\sqrt{\varepsilon_\mathrm{r}}}
$$

である ∎

```fig
e08_fresnel
```

比誘電率 4 の面では、ブルースター角は 26.6° である。ブルースター角より浅い、すれすれの反射では、$`\Gamma_\mathrm{V}`$ と $`\Gamma_\mathrm{H}`$ がどちらも負で、右旋が多く残る。深い反射では符号が逆で、左旋が多い。7 章 3 節で「反射すると、回る向きが逆になることが多い」と書いたのは、このことである。実際の地面や壁には損失と凹凸があるので、図の値は目安である。

### マルチパスを弱める — 反射波と直接波の振幅の比

7 章 3 節で、反射波の振幅を直接波の振幅で割った比を $`\gamma`$ と書いた。$`\gamma`$ は、反射係数と、アンテナがそれぞれの向きと偏波の電波を受ける強さで決まる。

```fig
e08_gamma
```

仰角 $`\theta`$ の衛星の直接波は右旋で来るので、右旋に対する利得 $`G_\mathrm{R}(\theta)`$ で受ける。反射波は、右旋の分 $`\Gamma_\mathrm{R}`$ と左旋の分 $`\Gamma_\mathrm{L}`$ を、来る向きのそれぞれの利得 $`G_\mathrm{R}`$・$`G_\mathrm{L}`$ で受ける。$`G_\mathrm{L}`$ は、1 節の図の逆の偏波に対する利得である。2 つの分が出力で重なる位相はアンテナで違うので、ここでは電力で足した目安を使う。平らな地面の反射では

$$
\gamma = \sqrt{\frac{\Gamma_\mathrm{R}^2\,G_\mathrm{R}(-\theta) + \Gamma_\mathrm{L}^2\,G_\mathrm{L}(-\theta)}{G_\mathrm{R}(\theta)}}
$$

である。垂直な壁の反射では、分子の利得を $`G_\mathrm{R}(\theta)`$ と $`G_\mathrm{L}(\theta)`$ に置き換える。

比誘電率 4 の地面で、仰角 30° の衛星では、例のアンテナの $`\gamma`$ は 0.11 である。直線偏波のアンテナの 0.40 の、約 1/4 になる。ところが仰角 10° では、0.28 と 0.65 である。低い衛星の地面の反射は、すれすれで右旋のまま反射し、地平線のすぐ下から来るので、偏波でも利得でも弱めにくい。

$`\gamma`$ が小さいと、7 章 3 節で求めた誤差の最大 $`\gamma\Delta_\mathrm{EL}cT_\mathrm{c}/2`$ が、$`\gamma`$ に比例して小さくなる。C/N0 の揺れも小さくなる。反射波の位相が回ると、直接波との和の振幅は $`1 - \gamma`$ から $`1 + \gamma`$ の間を動くので、C/N0 は $`20\log_{10}(1 \pm \gamma)`$ [dB] だけ変わる。

```fig
e08_gammaeff
```

低い衛星の地面の反射を減らすには、地平線より下の利得を特に小さくしたアンテナか、仰角マスク（7 章 3 節）を使う。前者の例に、地板に同心円の溝を付けた、測量用のチョークリングがある。

## 3. パッチアンテナ — 寸法・誘電体・給電点

### 形と、電波が出る所

GNSS の受信機で最も多く使われるアンテナは、**パッチアンテナ**（マイクロストリップアンテナ）である。地板の上に誘電体の板を置き、その上に正方形に近い金属の膜を付けたもので、この膜をパッチという。誘電体には、比誘電率の高いセラミックを使う。セラミックの板が 25 mm 角ほどの製品が多い（代表値）。受信機へつなぐピンがパッチに付く点を**給電点**という。

```fig
e08_patch
```

パッチの縁からはみ出した電界は、2 つの縁で水平な部分が同じ向きである。そのため、真上の向きでは、2 つの縁から出る電波が強め合う。

パッチの下の電界が図の (b) の形になる理由は、定在波である。給電点から出た波はパッチの下を進み、縁で跳ね返る。反対向きに進む 2 つの波が重なり、場所ごとに決まった大きさで振動して、進まないように見える波を**定在波**という。跳ね返った波が 1 往復して、元の波と同じ位相で重なると、波は強め合って大きくなる。これを**共振**といい、共振が起きる周波数を**共振周波数**という。パッチは、L1 で共振するように寸法を決める。

### 一辺の長さ — 誘電体の中の半波長

**方針**: パッチの下の波が縁で跳ね返って 1 往復したとき、元の波と同じ位相になる最も短い長さを求める。

**導出**: 誘電体の中では電波の速さが $`c/\sqrt{\varepsilon_\mathrm{r}}`$ なので、周波数 $`f`$ の波長は $`\lambda_\mathrm{d} = c/(f\sqrt{\varepsilon_\mathrm{r}}) = \lambda/\sqrt{\varepsilon_\mathrm{r}}`$ である。$`\lambda`$ は真空の波長である。パッチの縁の外は開いているので、電圧の波は、縁で符号を変えずに跳ね返る。一辺を $`\ell`$ とすると、1 往復の道のり $`2\ell`$ が $`\lambda_\mathrm{d}`$ の整数倍のとき、強め合う。最も短いのは $`2\ell = \lambda_\mathrm{d}`$ で

$$
\ell = \frac{\lambda_\mathrm{d}}{2} = \frac{\lambda}{2\sqrt{\varepsilon_\mathrm{r}}}
$$

である。このとき、パッチの下に半波長の定在波ができる。電界は、中心から $`x`$ の所で $`\sin(\pi x/\ell)`$ に比例し、両端で向きが逆、中心で 0 になる（図の (c)）∎

```fig
e08_epsr
```

比誘電率 20 のセラミックでは、L1 の一辺は 21.3 mm になる。実際には、縁ではみ出した電界の分だけ電気的に長く見えるので、パッチは少し短く作る（設計式は[電磁界シミュレーションシリーズ 17 章 2 節](../emsim/17_アンテナ設計.md#パッチアンテナの初期寸法-設計式)）。25 mm 角のセラミックの製品は、セラミックの板がパッチより一回り大きい。

比誘電率が高いと、2 つの縁が近づくので、真上に集める力が弱まり、パターンが広がる（図の (b)）。共振の帯域も狭くなり、誘電体の中で熱になる電力が増えて、効率が下がりやすい（代表的な傾向。[電磁界シミュレーションシリーズ 17 章 6 節](../emsim/17_アンテナ設計.md#アンテナ特有の落とし穴)）。

### 共振の鋭さ Q と帯域

共振は、共振周波数から離れると弱まる。パッチの下の電界が、周波数 $`f`$ のとき、共振周波数 $`f_0`$ のときの何倍かを $`K(f)`$ と書く。$`K`$ は振幅と位相を表す複素数で、コイルとコンデンサの共振回路と同じ形の

$$
K(f) = \frac{1}{1 + jQ\,(f/f_0 - f_0/f)}
$$

で近似できる（[回路シリーズ 3 章 5 節](../circuit/03_過渡応答とフィルタ.md#rlc-回路と共振)）。$`Q`$ は共振の鋭さを表す数で、これを **Q**（Q 値）という。4 章の I・Q の Q や、3 章 6 節の関数 $`Q(x)`$ とは別の量である。$`Q`$ が大きいほど、共振周波数から少し離れただけで $`|K|`$ が小さくなる。

**方針**: 電力 $`|K|^2`$ が共振周波数のときの半分になる周波数を、$`f_0`$ からのずれが小さいとして求める。

**導出**: $`|K|^2 = 1/\{1 + Q^2(f/f_0 - f_0/f)^2\}`$ が 1/2 になるのは、$`Q(f/f_0 - f_0/f) = \pm 1`$ のときである。$`f = f_0(1 + \delta)`$ とおき、$`\delta`$ が小さいとして $`1/(1 + \delta) \approx 1 - \delta`$ を使う。すると $`f/f_0 - f_0/f \approx (1 + \delta) - (1 - \delta) = 2\delta`$ なので、$`2Q\delta = \pm 1`$、$`\delta = \pm 1/(2Q)`$ である。電力が半分以上になる周波数の幅は $`f_0/Q`$ である。その両端では $`K = 1/(1 \pm j)`$ で、大きさは $`1/\sqrt{2}`$、位相は ∓45° である ∎

```fig
e08_q
```

$`Q`$ = 100 なら、L1 での幅は 15.75 MHz である。正方形のパッチには、横の向きに定在波ができる共振と、縦の向きに定在波ができる共振がある。1 つの共振器の、形の違う共振の 1 つ 1 つを**モード**という。正方形なら 2 つのモードは同じ共振周波数で、横のモードは横の直線偏波、縦のモードは縦の直線偏波を出す。

### 円偏波にする — 2 点で給電する方法と、角を切る方法

2 つのモードを同じ大きさで、位相を 90° ずらして起こせば、2 節の「横と縦の受け口を 90° ずらして足す」形になり、円偏波になる。方法は 2 つある。

1 つは、2 つのモードを別々の給電点で起こし、一方の道に 90° の遅れを入れる方法である（次の図の (a)）。周波数が変わっても 90° からずれにくく、軸比の良い帯域が広い。その代わり、90° の遅れを作る部品が要る。

もう 1 つは、1 点で給電し、向かい合う 2 つの角を切る方法である（図の (b)）。角を切ると、2 つの対角に沿うモード u と v の共振周波数が離れる。給電点は 2 つの対角から同じ角度の所に置くので、2 つのモードは同じ強さで起きる。共振周波数をどれだけ離せば円偏波になるかを求める。

**方針**: 2 つのモードの共振周波数を $`f_\mathrm{u} = f_0\{1 - 1/(2Q)\}`$、$`f_\mathrm{v} = f_0\{1 + 1/(2Q)\}`$ に置き、$`f_0`$ での 2 つのモードの応答を比べる。

**導出**: $`f_0`$ は、モード u の共振周波数より、$`1/(2Q)`$ の割合だけ高い。前の項の導出で $`\delta = +1/(2Q)`$ にあたるので、モード u の応答は $`K_\mathrm{u} = 1/(1 + j)`$ である。モード v から見ると $`\delta = -1/(2Q)`$ なので、$`K_\mathrm{v} = 1/(1 - j)`$ である。大きさはどちらも $`1/\sqrt{2}`$ で等しく、位相は −45° と +45° で、差は 90° である ∎

```fig
e08_cpfeed
```

L1 から離れると、振幅と位相の差が崩れる。$`Q`$ = 100 では、軸比を 3 dB 以下に保てる幅は 5.5 MHz で、共振の帯域 $`f_0/Q`$ の約 1/3 である。L1 C/A の信号の主ローブ（2.046 MHz）は入るが、幅の広い信号には足りない（5 節）。

### 給電点 — 50 Ω になる場所

受信機の入力とケーブルは、50 Ω の相手につないだときに、電力を最もよく受け渡す（そろえる理由は[基板アートワークシリーズ 10 章 1 節](../pcb/10_インピーダンス制御.md#なぜ特性インピーダンスを揃えるのか)）。給電点は、パッチの入力の抵抗が 50 Ω になる所に置く。

**方針**: 電波として出ていく電力は縁の電界で決まり、給電点の位置によらない。給電点の電圧から、入力の抵抗を求める。

**導出**: 一辺 $`\ell`$ の定在波で、中心から $`x`$ の所の電界は $`E(x) = E_\mathrm{e}\sin(\pi x/\ell)`$ である。$`E_\mathrm{e}`$ は縁の電界である。給電点の電圧の振幅は、電界に誘電体の厚さ $`h_\mathrm{d}`$ を掛けた $`E(x)h_\mathrm{d}`$ である。共振のとき、入力は抵抗 $`R(x)`$ だけに見える。入る電力 $`P = \{E(x)h_\mathrm{d}\}^2/(2R(x))`$ は、電波として出ていく電力と、熱になる電力の和に等しい。$`P`$ は縁の電界 $`E_\mathrm{e}`$ だけで決まるので、$`R(x) = \{E(x)h_\mathrm{d}\}^2/(2P) = R_\mathrm{e}\sin^2(\pi x/\ell)`$ である。$`R_\mathrm{e} = (E_\mathrm{e}h_\mathrm{d})^2/(2P)`$ は、縁での入力の抵抗である。$`R_\mathrm{e}`$ = 200 Ω なら、50 Ω になるのは $`\sin^2(\pi x/\ell) = 1/4`$、つまり $`\sin(\pi x/\ell) = 1/2`$ で、$`x = \ell/6`$ の所である ∎

```fig
e08_feed
```

給電点の位置を少し変えれば、50 Ω に合わせられる（調整の実際は[電磁界シミュレーションシリーズ 17 章 3 節](../emsim/17_アンテナ設計.md#給電と整合)）。

## 4. 地板 — 大きさで変わる指向性と共振周波数

### 地板の働きと、縁での回折

パッチアンテナを載せる金属の板を**地板**（グラウンドプレーン）という。地板は、パッチと組になって共振を作り、パッチから下へ向かう電波を跳ね返して、上の半分へ向ける。

実際の地板は有限である。地板に沿って進んだ電波は、縁で向きを変えて回り込み、地板の裏にも届く。電波が物の縁で回り込んで、影になる側にも届くことを**回折**という。

```fig
e08_gpidea
```

有限の地板では、地平線の電界が、無限の地板のほぼ半分になる（図の (c)）。地平線は影の境目で、回り込んだ電波が、段差のちょうど半分を埋めるからである。図は、金属の上の電流を未知数にして解くモーメント法で計算した（[電磁界シミュレーションシリーズ 8 章](../emsim/08_MoM.md#発想の転換-場ではなく源を未知数にする)）。

### 地板の大きさとパターン

真上の利得と真下の利得の比を**前後比**という。dB では、2 つの利得の差になる。前後比が大きいほど、地板の裏へ漏れる電波が小さい。

```fig
e08_gpsize
```

地板が大きいほど前後比は大きく、一辺 50 mm の 3.1 dB から、150 mm の 13.7 dB まで増える。前後比が小さいと、地面の反射波（2 節）と、地面の熱雑音（3 章 5 節）を多く受ける。実際の 3 次元の地板では値が変わるので、図は傾向として見る。製品のデータシートは、70 mm 角ほどの地板で測った値を載せることが多い（代表値）。

### 機器の中の地板と共振周波数

機器では、基板のグラウンドの面が地板になる。

```fig
e08_gpuse
```

地板が小さいか、パッチが地板の縁に近いと、縁ではみ出した電界の形が変わり、共振周波数がずれる。どちらへどれだけずれるかは、パッチと地板の形で違う。セラミックのパッチの製品は、データシートの大きさの地板で L1 に合うように作られている（代表的な作り方）。違う地板で使うときは、6 節の方法で共振周波数を測って確かめる。共振周波数がずれると、L1 での軸比が悪くなる（3 節）。

アンテナを空に向け、データシートのとおりの地板の中央に置くのが基本である。アンテナまでの配線と、銅を置かない領域（キープアウト）は 11 章 6 節、筐体の材料と置き方は 22 章で扱う。

## 5. いろいろなアンテナ — チップ・ヘリカル・多周波

### チップアンテナ

**チップアンテナ**は、セラミックの小さな部品を、基板の端に載せたアンテナである。基板のグラウンドの面にも電流が流れ、基板の全体がアンテナの一部として働く。そのため、基板の大きさと部品の置き方で、性能が大きく変わる（11 章）。偏波は直線偏波に近いので、右旋の電波を 3 dB 以上損し、反射波を回る向きで区別できない（2 節）。

### ヘリカルアンテナ

**ヘリカルアンテナ**は、導線をらせん状に巻いたアンテナである。GNSS では、4 本の導線を円筒のまわりに巻いた四線巻き（QFH、quadrifilar helix）が使われる。4 本を 90° ずつずらした位相で働かせて、円偏波にする。地板が要らない代わりに、パッチより大きい。

```fig
e08_types
```

### 多周波アンテナ

L1 と L5 のように、2 つ以上の周波数帯を受けるアンテナを**多周波アンテナ**という（多周波の受信機は 18 章）。L1 だけのパッチより難しい点が、2 つある。1 つは、2 つの周波数で共振させることである。L5 用の大きいパッチの上に、L1 用の小さいパッチを重ねる形などがある（次の図の (a)）。もう 1 つは、帯域である。L5 の信号は、チップレートが L1 C/A の 10 倍で、BPSK の主ローブの幅が 20.46 MHz ある（2 章 4 節）。

```fig
e08_bands
```

3 節と同じ $`Q`$ = 100 の 1 点給電のパッチでは、軸比 3 dB 以下の幅が、L5 の主ローブの 1/5 しかない。主ローブを覆うには、$`Q`$ を 20 ほどまで下げるか、帯域の広い 2 点給電を使う。$`Q`$ を下げるには、誘電体を厚くし、比誘電率を低くする。L1 の付近でも、いくつもの衛星系を 1 つのアンテナで受けるには、広い帯域が要る（図の (a) の下）。

### 比べる

| 種類 | 大きさ（代表値） | 偏波 | パターン | 地板 | 主な用途 |
|---|---|---|---|---|---|
| チップアンテナ | 数 mm〜10 mm の部品と基板 | 直線偏波に近い | 基板で決まり、向きでむらがある | 基板のグラウンドがアンテナの一部 | 腕時計・小さな追跡の機器 |
| パッチアンテナ（セラミック） | 一辺 15〜25 mm の板と地板 | 右旋（1 点給電は帯域が狭い） | 上の半分。地平線で真上より 9 dB ほど低い（例） | 要る（50〜100 mm 角） | 多くの受信機・LNA を入れたアンテナ（9 章） |
| ヘリカルアンテナ（四線巻き） | 直径 1〜4 cm・長さ数 cm | 右旋（広い向きで軸比が小さい） | 上の半分を広く。地平線に近い向きも下がりにくい | 要らない | ドローン・身に着ける機器・測量 |

## 6. 整合と測り方 — 反射とリターンロス

### 整合と反射係数

アンテナを受信機やケーブルにつないだとき、アンテナが受けた電力が、全部渡るとは限らない。受信機の入力とケーブルは、基準のインピーダンス $`Z_0`$ = 50 Ω で作られている（11 章）。インピーダンスは、交流の電圧と電流の比を、位相のずれを含めて複素数で表したものである（[回路シリーズ 2 章](../circuit/02_受動素子.md#インピーダンス)）。アンテナの端子から見たインピーダンスを $`Z_\mathrm{A} = R_\mathrm{A} + jX_\mathrm{A}`$ とする。実部 $`R_\mathrm{A}`$ は抵抗、虚部 $`X_\mathrm{A}`$ はリアクタンスである。$`Z_\mathrm{A}`$ を $`Z_0`$ に合わせ、電力を最もよく受け渡すようにすることを**整合**という。

可逆性があるので、損失は送るときで考えてよい。50 Ω の信号源からアンテナに向かう電圧の波は、$`Z_\mathrm{A} \ne Z_0`$ だと一部が跳ね返る。跳ね返る電圧の波を、入っていく電圧の波で割った比を、アンテナの反射係数 $`\Gamma`$ という。2 節の反射係数と同じ考え方の量で、振幅と位相を含む複素数である。線路（ケーブルや基板の配線）を進む波の理論から、$`\Gamma = (Z_\mathrm{A} - Z_0)/(Z_\mathrm{A} + Z_0)`$ である（[回路シリーズ 23 章 3 節](../circuit/23_基板設計.md#反射-リンギングの正体)、11 章 1 節）。

**方針**: 内部の抵抗 $`Z_0`$ の信号源にアンテナをつないだ回路で、アンテナに入る電力を、$`Z_\mathrm{A} = Z_0`$ のときの電力と比べる。

**導出**: 信号源の電圧の振幅を $`V_\mathrm{s}`$ とする。電流の振幅は $`I_\mathrm{A} = V_\mathrm{s}/(Z_0 + Z_\mathrm{A})`$ である。アンテナに入る電力は、抵抗の部分で消費される $`P = |I_\mathrm{A}|^2R_\mathrm{A}/2 = |V_\mathrm{s}|^2R_\mathrm{A}/(2|Z_\mathrm{A} + Z_0|^2)`$ である。$`Z_\mathrm{A} = Z_0`$ のときは $`P_0 = |V_\mathrm{s}|^2/(8Z_0)`$ なので、比は $`P/P_0 = 4Z_0R_\mathrm{A}/|Z_\mathrm{A} + Z_0|^2`$ である。一方、$`|Z_\mathrm{A} + Z_0|^2 - |Z_\mathrm{A} - Z_0|^2 = \{(R_\mathrm{A} + Z_0)^2 + X_\mathrm{A}^2\} - \{(R_\mathrm{A} - Z_0)^2 + X_\mathrm{A}^2\} = 4Z_0R_\mathrm{A}`$ なので、

$$
\frac{P}{P_0} = \frac{|Z_\mathrm{A} + Z_0|^2 - |Z_\mathrm{A} - Z_0|^2}{|Z_\mathrm{A} + Z_0|^2} = 1 - |\Gamma|^2
$$

である。$`|\Gamma|^2 \ge 0`$ なので $`P \le P_0`$ で、整合したときの電力が最大である ∎

### リターンロス・VSWR・不整合損失

跳ね返った電力の割合 $`|\Gamma|^2`$ を、3 つの数で表す。反射した波が、入っていく波より何 dB 小さいかを**リターンロス** RL $`= -20\log_{10}|\Gamma|`$ [dB] という。大きいほど良い。線路の上では、入っていく波と跳ね返った波が重なって、定在波（3 節）ができる。入っていく波の振幅を 1 とすると、電圧の振幅は、2 つの波が同じ向きに重なる所で $`1 + |\Gamma|`$、逆向きの所で $`1 - |\Gamma|`$ になる。その比 $`(1 + |\Gamma|)/(1 - |\Gamma|)`$ を **VSWR**（voltage standing wave ratio、電圧定在波比）という。整合で 1、全部跳ね返ると ∞ である。渡らなかった分による損失 $`-10\log_{10}(1 - |\Gamma|^2)`$ [dB] を**不整合損失**という。

```fig
e08_mismatch
```

アンテナでは、リターンロス 10 dB 以上を目安にすることが多い（代表値）。VSWR では、約 2 以下にあたる。そのときの不整合損失は 0.46 dB で、受ける信号の電力が同じだけ下がる。C/N0 への効き方は、LNA の雑音も関わるので、9 章で扱う。

### スミスチャート

$`\Gamma`$ は複素数なので、複素平面の点として描ける。$`\Gamma`$ の平面に、抵抗 $`R_\mathrm{A}`$ が一定の線と、リアクタンス $`X_\mathrm{A}`$ が一定の線を描き込んだ図を**スミスチャート**という。

```fig
e08_smith
```

$`R_\mathrm{A} \ge 0`$ のアンテナの $`\Gamma`$ は、半径 1 の円の中に入る。中心からの距離が $`|\Gamma|`$ なので、中心が同じ円の上では、リターンロスと VSWR が同じである。

### ネットワークアナライザで S11 を測る

アンテナの反射係数は、**ネットワークアナライザ**で測る。周波数を変えながら、端子から信号を送り込み、跳ね返ってくる信号との振幅と位相の比を測る測定器である。1 つ目の端子に送り込んで、1 つ目の端子に戻る比を **S11** という。端子に入る波と出る波の比をまとめた S パラメータの 1 つである（[電磁界シミュレーションシリーズ 14 章 2 節](../emsim/14_Sパラメータ.md#各要素の読み方)）。アンテナの S11 は $`\Gamma`$ そのもので、dB で表した $`20\log_{10}|S_{11}|`$ は、リターンロスに負の符号を付けた値である。

```fig
e08_s11
```

図の (b) の青い線は、3 節で例にしたパッチの S11 である。2 つのモードの共振周波数が離れているので、S11 の谷は広く、−10 dB 以下の幅は 21.4 MHz ある。軸比 3 dB 以下の幅 5.5 MHz より、ずっと広い。したがって、S11 が良くても、軸比が良いとは限らない。円偏波のアンテナでは、軸比やパターンも測るか、データシートの値で確かめる。

樹脂の筐体に入れると、共振周波数が下がる（22 章）。例として 5 MHz 下がると、L1 での S11 は −20.7 dB でまだ良いが、軸比は 5.5 dB に悪くなる（図の (d)）。左旋の反射波も、弱めにくくなる。L1 の 1 点だけを見ても気づきにくいが、周波数特性を見れば、谷の中心がずれたことが分かる。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 指向性・効率・利得 | 指向性は出ていく電力、利得は入れた電力が基準で、$`G_\mathrm{a} = \eta_\mathrm{a}D_\mathrm{a}`$。利得を全部の向きで平均すると効率になる（例のアンテナで 56.6 %） |
| 可逆性 | 送るときと受けるときで、向きごとの利得と偏波が同じ。実効開口面積は $`G_\mathrm{a}\lambda^2/(4\pi)`$（真上 +3 dBi で 57.5 cm²） |
| 偏波・地平線 | 地板に沿う向きの電界は 0。地平線では水平の成分を失い、右旋の電波を受ける強さが 1/4（−6 dB）になる |
| 円偏波・軸比 | 進む向きに見て時計回りが右旋。楕円偏波は右旋と左旋の和で、軸比は $`(a_\mathrm{R} + a_\mathrm{L})/\vert a_\mathrm{R} - a_\mathrm{L}\vert`$ |
| 偏波の損失 | 直線偏波で右旋を受けると −3.01 dB。軸比 3 dB の右旋のアンテナは、左旋を −15.5 dB で受ける |
| 反射 | 金属では $`\Gamma_\mathrm{H}`$ = −1・$`\Gamma_\mathrm{V}`$ = +1 で、右旋が左旋になる。一般には右旋の分 $`(\Gamma_\mathrm{V} + \Gamma_\mathrm{H})/2`$・左旋の分 $`(\Gamma_\mathrm{V} - \Gamma_\mathrm{H})/2`$ |
| ブルースター角 | $`\tan\psi_\mathrm{B} = 1/\sqrt{\varepsilon_\mathrm{r}}`$（比誘電率 4 で 26.6°）。それより浅い反射では、右旋が残る |
| 反射波の比 $`\gamma`$ | 比誘電率 4 の地面・仰角 30° で、例のアンテナ 0.11、直線偏波 0.40。仰角 10° では 0.28 と 0.65 で、弱めにくい |
| パッチの寸法 | 一辺 $`\lambda/(2\sqrt{\varepsilon_\mathrm{r}})`$（誘電体の中の半波長の定在波）。比誘電率 20 で 21.3 mm |
| Q と円偏波 | 共振の帯域は $`f_0/Q`$（$`Q`$ = 100 で 15.75 MHz）。2 つのモードを $`f_0/Q`$ 離すと円偏波になり、軸比 3 dB 以下の幅は 5.5 MHz |
| 給電点 | 入力の抵抗は $`R_\mathrm{e}\sin^2(\pi x/\ell)`$。縁で 200 Ω なら、中心から $`\ell/6`$ で 50 Ω |
| 地板 | 縁の回折で、地平線の電界はほぼ半分になり、裏へも漏れる。前後比は一辺 50 mm で 3.1 dB、150 mm で 13.7 dB。共振周波数もずれる |
| ほかのアンテナ | チップは小さく直線偏波、ヘリカルは広い向きで円偏波、多周波は 2 つの共振と広い帯域（L5 の主ローブは 20.46 MHz） |
| 整合 | $`\Gamma = (Z_\mathrm{A} - Z_0)/(Z_\mathrm{A} + Z_0)`$、渡る電力の割合は $`1 - \vert\Gamma\vert^2`$。リターンロス 10 dB で不整合損失 0.46 dB |
| S11 | ネットワークアナライザで測る $`\Gamma`$。S11 の良い幅 21.4 MHz は、軸比の良い幅 5.5 MHz より広い。共振が 5 MHz 下がると軸比 5.5 dB |
