## 1. 受信機の構成 — アンテナから位置まで

### アンテナから位置までの 7 つの段

受信機は、アンテナに届いた全部の衛星の電波から、衛星ごとに、符号の遅れと搬送波の周波数・位相を測り続ける。測った値から擬似距離を作り、位置を解く。この処理を、信号が流れる順に 7 つの段に分ける。

```fig
e04_chain
```

4 の段の、一定の時間ごとに電圧を測って数ビットの数にする変換を、A/D 変換という（[回路シリーズ 17 章](../circuit/17_ADC.md)）。1〜4 の段は、全部の衛星の電波を区別せずに、電圧の波形のまま扱う。アンテナの後から A/D 変換までのこの部分を **RF フロントエンド** という。RF は radio frequency の略で、無線の周波数を指す。搬送波の周波数の信号を最初に受ける部分なので、この名前で呼ぶ。

5〜7 の段は、数になった信号を計算で扱い、5 の段から衛星ごとに分かれる。A/D 変換より後のこの部分を **ベースバンド処理** という。ベースバンドは、搬送波を取り除いた後の、周波数 0 のまわりの信号を指す。5 の段で搬送波を掛けて取り除いてから扱うので、この名前で呼ぶ。

数の量は A/D 変換の直後が最も多く、5 の段の掛けて足す計算で約 2700 分の 1 に減る。この計算は単純だが回数が多いので、専用の回路で行う。その後の少ない数は、マイコンと同じ CPU のプログラムが扱う（5 節）。

### 信号は相関をとるまで雑音の下にある

RF フロントエンドを通る間に、信号と雑音の電力がどう変わるかを、例の値で追う。図の「チップ」は、受信機の回路の多くを 1 つにまとめた集積回路で、6 節で扱う。

```fig
e04_levels
```

増幅器は信号と雑音を同じだけ大きくするので、何段増幅しても SN 比は良くならない。最初の増幅器は、そのうえに自分の雑音を足す。その結果、C/N0 は 3 章 5 節の 1 段の例と同じ 47.7 dB-Hz になる。その後の段が足す雑音は、最初の増幅器の利得で割った大きさにしか効かない（[9 章 1 節](09_LNAとフィルタ.md#縦続接続の雑音指数-フリスの式)）。そのため、全部で 105 dB 増幅した後でも、C/N0 は 47.5 dB-Hz までしか下がらない。

増幅は、信号を A/D 変換で測れる大きさにするために行う。信号が雑音の上に出るのは、5 の段で衛星の符号を掛けて足した後である（3 章 4 節の逆拡散）。したがって、RF フロントエンドの仕事は、雑音の下に埋もれた信号を、なるべく雑音を足さずに相関の計算へ渡すことである。

## 2. RF フロントエンド — 増幅・フィルタ・周波数変換

### 増幅して帯域を絞る — LNA とフィルタ

アンテナの直後に置く、自分が足す雑音を特に小さくした増幅器を **LNA**（low noise amplifier、低雑音増幅器）という。1 節の図の「最初の増幅器」が LNA である。C/N0 は LNA の雑音指数でほぼ決まり、LNA の利得が大きいほど、後の段の雑音は目立たなくなる。

L1 C/A の信号の電力の 90 % は、1575.42 MHz のまわりの 2.046 MHz に入る（2 章 4 節の主ローブ）。一方、アンテナには、この信号より 90 dB 以上強い電波も届くことがある。近くの携帯電話の送信などである。強い電波がそのまま後の段に入ると、増幅器が飽和する（[9 章 4 節](09_LNAとフィルタ.md#帯域の外の強い電波-飽和と相互変調)）。そこで、L1 のまわりだけを通すフィルタを入れる。

```fig
e04_lnafilt
```

1.5 GHz 帯では、小さくて鋭い SAW フィルタ（弾性表面波フィルタ）が多く使われる。フィルタには、通すときの損失がある。LNA の前に置くと、その損失がそのまま雑音指数に加わる。フィルタの置き場所は [9 章 3 節](09_LNAとフィルタ.md#フィルタの置き場所-lna-の前か後か)で選ぶ。

### 周波数を下げる — 混合器と局部発振器

L1 のままで数値に変えるには、最も高い周波数の 2 倍を超える速さで標本をとる必要がある（3 節）。1 秒に 30 億回を超える速さになり、回路が大きく、電力も多く要る。幅 2 MHz の鋭いフィルタも、1.5 GHz より数 MHz の周波数の方がずっと作りやすい。情報は L1 のまわりの数 MHz にしかないので、その数 MHz をそっくり低い周波数に移せばよい。

衛星が動くので、受信機に届く搬送波の周波数は、L1 の 1575.42 MHz から少しずれる（2 章 1 節のドップラー効果）。このずれを**ドップラー周波数**といい、$`f_\mathrm{D}`$ と書く。衛星が近づくときを正とする。止まった受信機では、L1 で最大およそ ±5 kHz である（代表値）。届く搬送波の周波数は $`f_\mathrm{L1} + f_\mathrm{D}`$ になる。

周波数を移すための正弦波を、受信機の中で作る発振器を**局部発振器**といい、その周波数を $`f_\mathrm{LO}`$ と書く。2 つの信号を掛け算する回路を**混合器**（ミキサ）という。届いた信号に局部発振器の正弦波を掛けると、どんな周波数が出るかを求める。

**方針**: 2 章 4 節の BPSK の信号に、局部発振器の正弦波を掛け、三角関数の積の公式で、周波数の差と和の 2 つの成分に分ける。

**導出**: 届いた L1 C/A の信号を $`\sqrt{2C}\,d(t)\,a(t)\cos\{2\pi(f_\mathrm{L1} + f_\mathrm{D})t + \psi\}`$ と書く。$`C`$ は信号の電力で、振幅は 3 章と同じ $`\sqrt{2C}`$ である。$`d(t)`$ はデータのビット、$`a(t)`$ は C/A 符号のチップで、どちらも +1 か −1 をとる。$`\psi`$ は搬送波の位相である。この信号に、局部発振器の $`2\cos(2\pi f_\mathrm{LO}t)`$ を掛ける。係数の 2 は、式を簡単にするために付けた。積の公式 $`2\cos\alpha\cos\beta = \cos(\alpha - \beta) + \cos(\alpha + \beta)`$ を使うと

$$
\sqrt{2C}\,d(t)\,a(t)\cos\{2\pi(f_\mathrm{L1} - f_\mathrm{LO} + f_\mathrm{D})t + \psi\} + \sqrt{2C}\,d(t)\,a(t)\cos\{2\pi(f_\mathrm{L1} + f_\mathrm{LO} + f_\mathrm{D})t + \psi\}
$$

となる。1 つ目は周波数の差、2 つ目は周波数の和の成分である。$`f_\mathrm{LO}`$ を $`f_\mathrm{L1}`$ に近く選ぶと、1 つ目は低い周波数、2 つ目は L1 の約 2 倍の周波数になる。低い周波数だけを通すフィルタで 2 つ目を除くと、

$$
\sqrt{2C}\,d(t)\,a(t)\cos\{2\pi(f_\mathrm{IF} + f_\mathrm{D})t + \psi\}, \qquad f_\mathrm{IF} = f_\mathrm{L1} - f_\mathrm{LO}
$$

が残る ∎

周波数を下げた後の、ドップラーを除いた搬送波の周波数 $`f_\mathrm{IF}`$ を**中間周波数**（IF、intermediate frequency）という。搬送波の周波数と 0 の間にあることからの名前である。この章の例では、$`f_\mathrm{LO}`$ = 1571.328 MHz、$`f_\mathrm{IF}`$ = 4.092 MHz とする。

```fig
e04_mix
```

式の $`d(t)`$・$`a(t)`$・$`\psi`$・$`f_\mathrm{D}`$ は、混合の前と変わらない。混合器は周波数を $`f_\mathrm{LO}`$ だけ引くだけで、符号とデータによる位相の反転も、搬送波の位相も、ドップラー周波数も、そのまま中間周波数に移す。雑音も同じく、L1 のまわりの雑音が中間周波数のまわりに移る。したがって、信号の電力と雑音の電力スペクトル密度の比である C/N0 は変わらない。3 章 4 節で「先に周波数を下げてから標本にしても同じ結果になる」と書いたのは、このためである。

和の成分を除くフィルタは、中間周波数のまわりの、信号のある帯域だけを通す役も兼ねる。このフィルタを中間周波数のフィルタと呼び、通す幅を $`B_\mathrm{IF}`$ と書く。この章の例では $`B_\mathrm{IF}`$ = 2.046 MHz で、1 節の図の雑音は、この幅の中で数えた。

$`f_\mathrm{LO}`$ を $`f_\mathrm{L1}`$ より高く選ぶこともできる。そのときは $`f_\mathrm{IF} = f_\mathrm{LO} - f_\mathrm{L1}`$ で、周波数の並びが裏返り、ドップラーの符号が逆になる。

### イメージ周波数 — 反対側から来る雑音

混合器が出す差の周波数は、局部発振器を挟んで L1 の反対側にある周波数 $`f_\mathrm{LO} - f_\mathrm{IF}`$ の入力からも、同じ $`f_\mathrm{IF}`$ になる。$`\cos(-\theta) = \cos\theta`$ なので、差が $`-f_\mathrm{IF}`$ でも $`+f_\mathrm{IF}`$ と区別できないからである。混合器の出力で、L1 と同じ中間周波数に重なってしまう、局部発振器を挟んで反対側の周波数を**イメージ周波数**といい、$`f_\mathrm{im}`$ と書く。$`f_\mathrm{im} = f_\mathrm{LO} - f_\mathrm{IF} = f_\mathrm{L1} - 2f_\mathrm{IF}`$ である。

イメージ周波数に衛星の信号は無いが、LNA が増幅した雑音は、L1 のまわりと同じ密度である。何もしなければ、その雑音も中間周波数に重なって、雑音の密度が 2 倍になる。C/N0 は 3.0 dB 下がる。混合器より前でイメージ周波数を $`A`$ dB 弱めると、雑音の密度は $`1 + 10^{-A/10}`$ 倍で済む。

```fig
e04_image
```

弱める方法は 2 つある。1 つは、混合器の前のフィルタで除く方法である。イメージ周波数は L1 から $`2f_\mathrm{IF}`$ 離れているので、中間周波数が高いほど除きやすい。

もう 1 つは、局部発振器の cos と、それを 90° ずらした sin で、2 つの混合器を使って別々に混合する方法である。2 つの出力を、複素数の実部と虚部とみなす。すると、$`\cos\theta = (e^{j\theta} + e^{-j\theta})/2`$ の 2 つの項のうち、$`e^{-j2\pi f_\mathrm{LO}t}`$ だけを掛けたことになる（[DSP シリーズ 2 章 2 節](../dsp/02_複素指数関数とオイラーの公式.md#cos-と-sin-を複素指数で表す-逆向きの公式)）。正の周波数の L1 の成分は $`+f_\mathrm{IF}`$ に、イメージ周波数の成分は $`-f_\mathrm{IF}`$ に移り、周波数の符号で分けられる。2 つの経路にはわずかな違いがあるので、打ち消しは完全ではない。

中間周波数は、イメージ周波数の除きやすさと、A/D 変換の速さの釣り合いで選ぶ。

```fig

```

### 局部発振器の周波数 — TCXO と PLL

局部発振器の 1571.328 MHz は、基準の発振器の 16.368 MHz を、PLL で 96 倍にして作る（例の値）。PLL は、出力の位相を基準に合わせ続けて、周波数を整数倍にする回路である（[回路シリーズ 9 章 3 節](../circuit/09_コンパレータと発振.md#pll-位相同期ループ)）。基準の発振器は、A/D 変換の標本をとる時刻と、ベースバンド処理の回路の時計にも使う。1 章 2 節の「受信機の時計」は、この基準の発振器である。

水晶の発振の周波数は、温度で変わる。水晶の温度を測り、周波数のずれを打ち消すように直す回路を組み込んだ発振器を **TCXO**（temperature compensated crystal oscillator、温度補償水晶発振器）という。使う温度の範囲で、補償しない水晶の発振器の周波数は ±10〜30 ppm ずれる。ppm は 100 万分の 1 である。TCXO のずれは ±0.5 ppm ほどである。どちらも代表値で、1 章 2 節の例の 100 万分の 0.5 は TCXO の値である。

```fig
e04_tcxo
```

基準の周波数のずれが、受信機の中でどう見えるかを求める。

**方針**: 局部発振器と標本の時刻が同じ発振器から作られることを使い、標本の中に見える搬送波の周波数を、受信機の時計で測った値として書く。

**導出**: 基準の発振器の周波数が、相対的に $`r = \Delta f_\mathrm{ref}/f_\mathrm{ref}`$ だけ高いとする。$`f_\mathrm{ref}`$ は基準の周波数、$`\Delta f_\mathrm{ref}`$ はそのずれである。局部発振器も同じ割合で高くなり、$`f_\mathrm{LO}(1 + r)`$ になる。混合器の出力の周波数は $`f_\mathrm{L1} + f_\mathrm{D} - f_\mathrm{LO}(1 + r)`$ である。受信機は、この周波数を、同じ発振器で刻んだ標本の時刻で測る。受信機の時計が $`1 + r`$ 倍速く進むので、周波数 $`f`$ は $`f/(1 + r) \approx f(1 - r)`$ に見える。掛け算をして $`r^2`$ と $`rf_\mathrm{D}`$ の小さな項を捨てると、見える周波数は

$$
\{f_\mathrm{IF} + f_\mathrm{D} - rf_\mathrm{LO}\}(1 - r) \approx f_\mathrm{IF} + f_\mathrm{D} - r(f_\mathrm{LO} + f_\mathrm{IF}) = f_\mathrm{IF} + f_\mathrm{D} - rf_\mathrm{L1}
$$

となる ∎

したがって、基準の周波数の誤差は、全部の衛星の搬送波に、同じ $`-rf_\mathrm{L1}`$ の見かけのドップラーとして入る。TCXO の +0.5 ppm なら −787.7 Hz で済む。補償しない水晶の 20 ppm なら −31.5 kHz になり、衛星の動きによるドップラーの範囲の 6 倍を超える。

受信機は、信号を見つけるまで、このずれを知らない。ずれが大きいほど、探す周波数の範囲が広がり、見つけるのに時間がかかる（[5 章 1 節](05_捕捉と追尾.md#捕捉-符号の位相とドップラーを探す)）。GNSS の受信機が TCXO を使うのは、このためである。信号を見つけた後は、全部の衛星に共通のずれを、時計のドリフト（時計の進み方の誤差）として、位置や速度と一緒に求める（[6 章 5 節](06_位置を解く.md#速度を求める-ドップラーから)）。

## 3. A/D 変換 — 中間周波数・サンプリング・量子化

A/D 変換は、一定の時間ごとに電圧を測る標本化（サンプリング）と、測った値を決まった段階の数に丸める量子化からなる（[回路シリーズ 17 章 1 節](../circuit/17_ADC.md#基本の枠組み)）。1 秒に標本をとる回数を**サンプリング周波数**といい、$`f_\mathrm{s}`$ と書く。標本の間隔は $`T_\mathrm{s} = 1/f_\mathrm{s}`$ である。この節では、中間周波数に合うサンプリング周波数の選び方と、量子化のビット数を決める。

### 標本をとると周波数が折り返す

周波数 $`f`$ の正弦波を、時刻 $`kT_\mathrm{s}`$ で標本にした値は $`\cos(2\pi fkT_\mathrm{s} + \psi)`$ である。$`k`$ は 0, 1, 2, … の整数である。整数 $`m`$ について $`2\pi mf_\mathrm{s}kT_\mathrm{s} = 2\pi mk`$ なので、周波数を $`f - mf_\mathrm{s}`$ にしても標本の値は同じである。$`\cos(-\theta) = \cos\theta`$ なので、周波数の符号を変えても同じである。したがって、標本の列では、周波数 $`f`$ と $`|f - mf_\mathrm{s}|`$ を区別できず、どの周波数も 0〜$`f_\mathrm{s}/2`$ のどこかに見える。これを折り返し、またはエイリアシングという（[DSP シリーズ 1 章 3 節](../dsp/01_離散時間信号とサンプリング.md#サンプリング定理とエイリアシング)）。

中間周波数の信号は、$`f_\mathrm{IF}`$ のまわりの幅 $`B_\mathrm{IF}`$ の帯域にある。帯域の下の端を $`f_\mathrm{min} = f_\mathrm{IF} - B_\mathrm{IF}/2`$、上の端を $`f_\mathrm{max} = f_\mathrm{IF} + B_\mathrm{IF}/2`$ と書く。この帯域が、折り返した後に自分と重ならない条件を求める。

**方針**: 周波数の軸を、$`f_\mathrm{s}/2`$ ごとの区間に分ける。各区間が 0〜$`f_\mathrm{s}/2`$ にどう移るかを調べ、帯域が 1 つの区間に収まる条件を式にする。

**導出**: 区間 $`n`$ を $`(n - 1)f_\mathrm{s}/2 \le f \le nf_\mathrm{s}/2`$ とする。$`n`$ は 1, 2, 3, … の整数である。上の折り返しの規則で、区間 1 はそのまま、区間 2 は $`f \to f_\mathrm{s} - f`$ で裏返って、区間 3 は $`f \to f - f_\mathrm{s}`$ でずれて、0〜$`f_\mathrm{s}/2`$ に移る。区間の中の異なる 2 つの周波数は、移った後も異なる。そのため、帯域が 1 つの区間に収まっていれば、折り返しても自分と重ならない。帯域が区間の境目をまたぐと、境目の両側が同じ所に移って重なる。境目は $`f_\mathrm{s}/2`$ の整数倍である。したがって条件は、ある整数 $`n`$ について $`(n - 1)f_\mathrm{s}/2 \le f_\mathrm{min}`$ かつ $`f_\mathrm{max} \le nf_\mathrm{s}/2`$、つまり

$$
\frac{2f_\mathrm{max}}{n} \le f_\mathrm{s} \le \frac{2f_\mathrm{min}}{n - 1}
$$

である。$`n`$ = 1 のときの右辺は無限大とする ∎

$`n`$ = 1 は、よく知られた条件 $`f_\mathrm{s} \ge 2f_\mathrm{max}`$ で、最も高い周波数の 2 倍より速く標本をとる。帯域が狭ければ、$`n \ge 2`$ の区間を使って、もっと遅く標本をとれる。帯域の信号を、最も高い周波数の 2 倍より低いサンプリング周波数で、帯域が重ならない区間を使って標本にすることを**帯域通過サンプリング**という。$`n`$ が偶数の区間は裏返って移るので、周波数の並びが逆になり、ドップラーの符号が変わる。

```fig
e04_alias
```

この章の例では、$`n`$ = 1 で 10.23 MHz 以上、$`n`$ = 2 で 5.115〜6.138 MHz が使える。実際のフィルタは帯域の端で少しずつ弱めるので、帯域の端は、区間の境目から離しておく。この章で使う 16.368 MHz では、中間周波数が $`f_\mathrm{s}/4`$ に来て、0 と $`f_\mathrm{s}/2`$ のどちらからも離れる。8.184 MHz のように $`f_\mathrm{s}/2`$ が帯域の中に来ると、標本の列からは搬送波の位相が分からなくなり、位相によっては信号が消える。

サンプリング周波数を高くすると、4 節の掛けて足す計算の回数が増え、電力も増える。低くすると、次に見る量子化の損失が増える。サンプリング周波数は、この釣り合いで選ぶ。原理の上では、L1 を、周波数を下げずに帯域通過サンプリングすることもできる。ただし、1.6 GHz の信号を受けられ、標本の時刻の揺れが L1 の 1 周期の 0.635 ns より十分小さい A/D 変換器が要る。

### 量子化 — 1〜2 bit で足りる理由

センサの電圧を測る A/D 変換器は、10〜16 bit のものが多い。GNSS の受信機の A/D 変換は、1〜3 bit のことが多い（代表値）。妨害に強くするために、もっと多くのビットを使う受信機もある。1〜3 bit で足りるのは、A/D 変換の入力がほとんど雑音で、信号はその上の小さな偏りにすぎないからである。最も粗い 1 bit の量子化で、相関の後の SN 比がどれだけ下がるかを求める。

**方針**: 1 bit の量子化は、標本の値の符号だけを残し、正なら +1、負なら −1 を出す。信号が雑音よりずっと小さいとき、出力の平均が信号の値に比例することを示し、量子化しない場合と、相関の後の SN 比を比べる。

**導出**: 標本の値を $`x = s + w`$ とする。$`s`$ は信号の値、$`w`$ は平均 0・標準偏差 $`\sigma`$ の正規分布にしたがう雑音である（[統計学シリーズ 8 章 4 節](../stats/08_連続分布.md#標準正規分布)）。量子化した値を $`q`$ とし、$`x \ge 0`$ なら +1、$`x < 0`$ なら −1 とする。$`q`$ = +1 の確率は、$`w > -s`$ の確率である。これは、正規分布の密度を $`w`$ = 0 から $`-s`$ の間で積分した分だけ、1/2 より大きい。$`|s| \ll \sigma`$ なら、その間の密度は 0 での値 $`1/(\sqrt{2\pi}\,\sigma)`$ とみなせるので、

$$
\Pr(q = +1) \approx \frac{1}{2} + \frac{s}{\sqrt{2\pi}\,\sigma}, \qquad \Pr(q = -1) \approx \frac{1}{2} - \frac{s}{\sqrt{2\pi}\,\sigma}
$$

である。$`q`$ の平均は $`\Pr(q = +1) - \Pr(q = -1) \approx \sqrt{2/\pi}\,s/\sigma`$ である。$`q^2`$ はいつも 1 なので、$`q`$ の分散は $`1 - (\sqrt{2/\pi}\,s/\sigma)^2 \approx 1`$ である。つまり、量子化した値は、信号の部分 $`\sqrt{2/\pi}\,s/\sigma`$ と、分散 1 の雑音の部分の和とみなせる。

相関の計算は、標本に局部の符号と搬送波を掛けて足す（3 章 4 節）。信号の部分は足した回数に比例する。雑音の部分は、標本どうしが独立なら、分散が回数に比例する。標本 1 つで見た、信号と雑音の電力の比は、量子化しないとき $`s^2/\sigma^2`$、量子化した後は $`(2/\pi)\,s^2/\sigma^2`$ である。したがって、相関の後の SN 比も同じ比

$$
\eta_\mathrm{q} = \frac{2}{\pi} = 0.637 \qquad (-1.96\ \mathrm{dB})
$$

で下がる ∎

```fig
e04_dither
```

標本の 1 つ 1 つは符号しか残らないのに、多くの標本を足すと、信号の大きさが平均として現れる。雑音が、信号の小さな偏りを、+1 と −1 の出る割合の偏りに変えるからである。雑音が無ければ、弱い信号は符号の列として残るだけで、大きさの情報は失われる。

出力を 4 段階にする 2 bit の量子化も、同じ計算で損失が求まる。例として、しきい値を雑音の標準偏差の $`\gamma`$ 倍とし、$`|x|`$ が $`\gamma\sigma`$ より小さければ ±1、大きければ ±3 を出すとする。$`q`$ の平均は、出力が切り替わる所の密度と、切り替わりの大きさの積を足して、$`s`$ を掛けたものになる。切り替わる所は 0 と $`\pm\gamma\sigma`$ で、平均は $`(s/\sigma)(2 + 4e^{-\gamma^2/2})/\sqrt{2\pi}`$ である。$`q^2`$ の平均は $`\Pr(|w| < \gamma\sigma) + 9\Pr(|w| \ge \gamma\sigma)`$ である。損失は、平均の $`s/\sigma`$ の係数の 2 乗を、$`q^2`$ の平均で割った

$$
\eta_\mathrm{q} = \frac{\{(2 + 4e^{-\gamma^2/2})/\sqrt{2\pi}\}^2}{\Pr(|w| < \gamma\sigma) + 9\Pr(|w| \ge \gamma\sigma)}
$$

になる。

ここまでの式は、標本どうしが独立な場合である。雑音の電力スペクトル密度が 0〜$`f_\mathrm{s}/2`$ で平らな場合にあたる。この章の例のように、帯域の幅 $`B_\mathrm{IF}`$ より速く標本をとると、隣の標本の雑音が似た値になり、量子化の損失は小さくなる。この場合の損失は、シミュレーションで求めた。

```fig
e04_qloss
```

2 bit の損失は、しきい値 $`\gamma\sigma`$ が雑音の標準偏差に近いとき、最も小さい。雑音の大きさは、アンテナや温度で変わる。そこで受信機は、A/D 変換の入力の雑音がしきい値に合う大きさになるように、増幅の利得を自動で変え続ける。この回路を AGC（automatic gain control）という。AGC の利得は、妨害を見つける手がかりにもなる（[20 章 6 節](20_妨害とノイズの源.md#ノイズを見つける-c-n0-の比較とスペクトラム)）。

16.368 MHz で標本をとると、量子化による損失は 1 bit で 1.1 dB、2 bit で 0.2 dB になる。標本が独立なときの半分ほどである。フィルタの分を合わせた損失は、2 bit で −0.7 dB である。

1 節の例の C/N0 = 47.5 dB-Hz を 2 bit・16.368 MHz で受けると、相関をとった後に見える C/N0 は 46.7 dB-Hz になる。1 ms の積分の後の SN 比は 16.7 dB である。受信機が相関の後の値から測る C/N0 は、この損失を含んだ値である。なお、帯域の中に雑音より強い妨害の電波があると、1 bit の量子化では出力の符号が妨害に支配され、損失がずっと大きくなる（20 章）。

## 4. 相関器 — 局部の符号と搬送波を掛けて足す

### 局部の搬送波と符号を作る — NCO

3 章 4 節の $`Y_\mathrm{I}`$・$`Y_\mathrm{Q}`$ を計算するには、受けた標本の列に、手元で作った搬送波の cos と sin、手元で作った符号を掛けて足す。受信機が手元で作る搬送波と符号を、**局部の搬送波**・**局部の符号**という。局部の搬送波の周波数は、標本の中に見える搬送波の周波数に合わせる。中間周波数に、ドップラーと、2 節で求めた見かけのドップラーを加えた周波数である。局部の符号の遅れは、受けた符号の遅れに合わせる。どちらも、ずれを見ながら細かく変え続ける必要がある（5 章）。

足し算を繰り返すだけで、決まった周波数の位相を作る回路を **NCO**（numerically controlled oscillator、数値制御発振器）という。NCO は、標本ごとに、レジスタに決まった数 $`K`$ を足す。32 ビットのレジスタなら、値が $`2^{32}`$ を超えると、あふれた桁を捨てて、超えた分だけが残る。レジスタの値を $`2^{32}`$ で割った値を、1 周期を 1 とした位相とみなす。標本 $`k`$ 個の後の位相は $`kK/2^{32}`$ 周期で、その間の時間は $`k/f_\mathrm{s}`$ である。したがって、NCO の周波数は

$$
f_\mathrm{NCO} = \frac{K}{2^{32}}\,f_\mathrm{s}
$$

である。$`K`$ を 1 変えると、周波数は $`f_\mathrm{s}/2^{32}`$ だけ変わる。

```fig
e04_nco
```

搬送波の NCO は、位相の上位の数ビットで cos と sin の表を引き、局部の搬送波の値にする。符号の NCO は、位相があふれた回数をチップの番号として数え、1023 で一巡させて、C/A 符号の表を引く。この表は、2 章 2 節のシフトレジスタで作ったものである。衛星が近づくと、搬送波と同じ割合で符号も速く届く。そこで、符号の NCO の速さは $`1.023\ \mathrm{M} \times (1 + f_\mathrm{D}/f_\mathrm{L1})`$ チップ/s にする。

### 掛けて足す — 相関器と I・Q

受けた標本に、局部の搬送波の cos と sin、局部の符号を掛けて、積分の時間のあいだ足す回路を**相関器**という。標本を $`y_k`$、その時刻を $`t_k = kT_\mathrm{s}`$、局部の符号の遅れを $`\hat\tau`$、搬送波の NCO の位相を $`\hat\psi_k`$ とすると、相関器は

$$
I = \frac{1}{J}\sum_{k=0}^{J-1} y_k\,a(t_k - \hat\tau)\cdot 2\cos\hat\psi_k, \qquad Q = \frac{1}{J}\sum_{k=0}^{J-1} y_k\,a(t_k - \hat\tau)\cdot 2\sin\hat\psi_k
$$

を計算する。$`J = f_\mathrm{s}T_\mathrm{coh}`$ は、積分の時間に入る標本の数である。cos を掛けた方を **I**（in-phase、同相）、sin を掛けた方を **Q**（quadrature、直交）という。直交は、90° ずれていることを指す。3 章 4 節の $`Y_\mathrm{I}`$・$`Y_\mathrm{Q}`$ と同じ式で、局部の搬送波を NCO で作り、局部の符号の遅れ $`\hat\tau`$ を自由に選べるようにしたものである。

標本は 1〜2 bit、符号は ±1 なので、掛け算は符号を変えるか、表を引くだけで済む。相関器の出力からずれを求めて、NCO の $`K`$ を書き換え続ける計算を、5 章で追尾と呼ぶ。

```fig
e04_corrblock
```

### I・Q が表すもの

局部の符号と搬送波が、受けた信号から少しずれているときの I・Q を求める。受けた標本の信号の部分を、2 節で求めた混合器の出力の形 $`\sqrt{2C}\,d\,a(t_k - \tau)\cos\{2\pi(f_\mathrm{IF} + f_\mathrm{D})t_k + \psi\}`$ とする。振幅は、受信機の利得で割ってアンテナの所の値に直し、3 章と同じ $`\sqrt{2C}`$ と書く。$`d`$ は、積分の時間のあいだ変わらないとする。局部の搬送波の位相を $`\hat\psi_k = 2\pi(f_\mathrm{IF} + \hat f_\mathrm{D})t_k + \hat\psi`$ とする。$`\hat f_\mathrm{D}`$ は、局部の搬送波に入れたドップラーである。符号のずれを $`\Delta\tau = \hat\tau - \tau`$、周波数のずれを $`\Delta f = f_\mathrm{D} - \hat f_\mathrm{D}`$、位相のずれを $`\Delta\psi = \psi - \hat\psi`$ と書く。

**方針**: 3 章 4 節と同じく、積の公式で 2 倍の周波数の項を除く。残った式を、「受けた符号と局部の符号の積」と「搬送波の位相の差のずれ方」の 2 つの平均に分けて、それぞれ求める。

**導出**: 積の公式で $`2\cos\alpha\cos\beta`$ を差と和の cos に直すと、和の成分は 2 倍の周波数で正負に振れ、多くの標本を足して $`J`$ で割るとほぼ 0 になる。残りは

$$
I_\mathrm{s} = \sqrt{2C}\,d\,\frac{1}{J}\sum_{k} a(t_k - \tau)\,a(t_k - \hat\tau)\cos(2\pi\Delta f\,t_k + \Delta\psi)
$$

である。符号の積 $`a(t_k - \tau)\,a(t_k - \hat\tau)`$ の平均は、2 章 3 節の自己相関を 1023 で割った値である。$`|\Delta\tau| < T_\mathrm{c}`$ では三角形 $`\Lambda(\Delta\tau) = 1 - |\Delta\tau|/T_\mathrm{c}`$、1 チップより大きくずれるとほぼ 0 になる。符号の積は、+1 と −1 がチップの単位で細かく入れ替わる。cos の因子は、数百 Hz 以下の $`\Delta f`$ でゆっくり変わるだけである。そのため、積の平均は、それぞれの平均の積とみなせる。cos の因子の平均は、和を積分に直し、$`\sin\alpha - \sin\beta = 2\cos\frac{\alpha + \beta}{2}\sin\frac{\alpha - \beta}{2}`$ を使うと

$$
\frac{1}{T_\mathrm{coh}}\int_0^{T_\mathrm{coh}}\cos(2\pi\Delta f\,t + \Delta\psi)\,dt = \frac{\sin(2\pi\Delta f\,T_\mathrm{coh} + \Delta\psi) - \sin\Delta\psi}{2\pi\Delta f\,T_\mathrm{coh}} = \mathrm{sinc}(\Delta f\,T_\mathrm{coh})\cos(\pi\Delta f\,T_\mathrm{coh} + \Delta\psi)
$$

である。ここで $`\mathrm{sinc}\,u = \sin(\pi u)/(\pi u)`$ である。$`Q_\mathrm{s}`$ は、積の公式 $`2\cos\alpha\sin\beta = \sin(\alpha + \beta) - \sin(\alpha - \beta)`$ から、cos の代わりに $`-\sin`$ が残り、同じ計算になる。まとめると

$$
(I_\mathrm{s},\ Q_\mathrm{s}) = \sqrt{2C}\,d\,\Lambda(\Delta\tau)\,\mathrm{sinc}(\Delta f\,T_\mathrm{coh})\,(\cos\overline{\Delta\psi},\ -\sin\overline{\Delta\psi}), \qquad \overline{\Delta\psi} = \Delta\psi + \pi\Delta f\,T_\mathrm{coh}
$$

となる ∎

この式は、I を横、Q を縦にとった平面の点として読むと分かりやすい。$`\Lambda`$ と sinc は、点を原点へ向けて縮める倍率である。$`\Lambda`$ は、2 章 3 節で見た相関の山の形である。$`\overline{\Delta\psi}`$ は、点を原点のまわりに回す角である。積分の時間のあいだの位相のずれ $`2\pi\Delta f\,t + \Delta\psi`$ の平均にあたる。データのビット $`d`$ が反転すると、点は原点の反対側に移る。

```fig
e04_iq
```

$`T_\mathrm{coh}`$ = 1 ms では、1 kHz のずれで sinc が 0 になる。3 章 4 節の、位相が 1 回転して和が 0 になる場合である。

雑音は、I と Q のそれぞれに、分散 $`N_0/T_\mathrm{coh}`$ の揺れを加える（3 章 4 節）。3 節の量子化などの損失は、この雑音がその分だけ大きくなったように見える。符号と搬送波が合っているときの $`I_\mathrm{s}^2 + Q_\mathrm{s}^2`$ を、雑音の 2 乗の和の平均で割った値が、3 章の相関の後の SN 比 $`(C/N_0)\,T_\mathrm{coh}`$ である。中間周波数の標本で確かめると、式と標本の和の差は、どの点でも 0.02 以内だった。

### 早い・即時・遅い — E・P・L

符号のずれ $`\Delta\tau`$ を測るには、2 章 3 節のとおり、三角形の頂点をはさむ左右 2 点の相関の値が要る。そこで、同じ局部の搬送波を使い、局部の符号の遅れだけを少しずつ変えた 3 つの相関器を並べる。合わせたつもりの遅れの符号を使う相関器を **P**（prompt、即時）という。それより $`\Delta_\mathrm{EL}/2`$ チップ早めた符号を使う相関器を **E**（early、早い）という。$`\Delta_\mathrm{EL}/2`$ チップ遅らせた符号を使う相関器を **L**（late、遅い）という。

$`\Delta_\mathrm{EL}`$ は、チップで数えた E と L の間隔で、1 チップが基本である。0.1〜0.2 チップに狭くして、雑音とマルチパスの影響を減らす受信機もある（[7 章 3 節](07_誤差とDOP.md#マルチパス-反射した電波が混ざる)）。マルチパスは、建物などで反射した電波が混ざることである。$`\Delta_\mathrm{EL}`$ = 1 チップのとき、$`\sqrt{2C}`$ で割った I・Q の大きさは、E が $`\Lambda(\Delta\tau - T_\mathrm{c}/2)`$、P が $`\Lambda(\Delta\tau)`$、L が $`\Lambda(\Delta\tau + T_\mathrm{c}/2)`$ である。

```fig
e04_epl
```

したがって、E と L の大きさの差の符号で、局部の符号を早めるか遅らせるかが決まる。ずれが三角形の辺の上にある間は、差の半分 $`(E - L)/2`$ が、チップで数えたずれになる。2 章 3 節の頂点の式に、E と L の値を入れた結果である。これを繰り返して符号に合わせ続ける仕組みが、[5 章 3 節](05_捕捉と追尾.md#符号の追尾-遅延ロックループ)の DLL である。

P は、搬送波に合わせ続けるためと、データのビットを読むために使う。I・Q の点の角度が、位相のずれを表す（[5 章 4 節](05_捕捉と追尾.md#搬送波の追尾-位相ロックループと周波数ロックループ)）。P の I の符号が、データのビットを表す（3 章 6 節）。

## 5. チャネル — 衛星ごとに相関器を並べる

### 衛星ごとに、別の符号の位相とドップラー

1 つの衛星の 1 つの信号を受け続けるための、搬送波の NCO・符号の NCO・E・P・L の相関器の組を**チャネル**という。A/D 変換の標本の列は 1 つで、全部のチャネルが同じ標本を使う。チャネルごとに、局部の符号の PRN 番号と、NCO の $`K`$ の値が違う。

衛星ごとに、受信機までの距離と、受信機に近づく速さが違う。そのため、符号の位相もドップラーも、衛星ごとに違う。ここでの符号の位相は、届いた符号の遅れの、1 ms に満たない端数である。1 章の GPS の近似の配置で、東京から見える 8 機の値を計算した。

```fig
e04_sats
```

各チャネルは、自分の衛星の値に NCO を合わせる。ほかの衛星の信号は、2 章 3 節の相互相関のとおり、小さな値にしかならない。

受信機の時計のずれ $`\delta t_\mathrm{r}`$ は、全部の衛星の符号の位相を同じだけずらす。1 章 3 節の、全部の擬似距離に入る $`b`$ である。基準の発振器の周波数の誤差は、全部の衛星のドップラーを同じだけずらす。2 節の $`-rf_\mathrm{L1}`$ である。どちらも全部のチャネルに共通なので、受信機は、位置と速度と一緒に求めて取り除く（6 章）。

### 1 ms ごとの分担 — 回路とプログラム

チャネルは、1 ms ごとに、E・P・L の I・Q の 6 つの数を出す。CPU のプログラムは、この 6 つの数から符号と搬送波のずれを計算し、新しい $`K`$ を NCO に書き込む。数を出す相関器と、ずれを直す計算が、フィードバックの輪をつくる。

```fig
e04_bank
```

相関器は、標本ごとに 6 回、掛けて足す。12 チャネルでは、1 秒に約 12 億回になる。一方、プログラムが扱うのは、1 秒に 7.2 万個の数である。回数の多い単純な計算を専用の回路に、回数の少ない複雑な計算をプログラムに分けるのが、受信機の作りの基本である。

チャネルの数は受信機によって違い、12 から数十である（代表値）。複数の衛星系と複数の周波数を受ける受信機では、さらに多い。L1 と L5 を受けるなら、同じ衛星でも周波数ごとにチャネルが要る。GLONASS の衛星は、衛星ごとに搬送波の周波数が違う（2 章 1 節の FDMA）。そこで、チャネルの搬送波の NCO を、その衛星の周波数に合わせる。RF フロントエンドも、その周波数を通す必要がある。

まだ見つけていない衛星を探すときは、符号の位相とドップラーの組を、数多く試す。そのため、追尾のチャネルよりずっと多くの相関器か、FFT（高速フーリエ変換）を使う計算が要る（[5 章 2 節](05_捕捉と追尾.md#fft-を使った捕捉)）。

## 6. モジュールとチップ — 何が中に入っているか

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 受信機の 7 つの段 | 増幅 → 帯域を絞る → 周波数を下げる → 数値に変える → 掛けて足す → 見つけて追う → 位置を解く |
| RF フロントエンド・ベースバンド処理 | アンテナの後から A/D 変換までの、全部の衛星をまとめて扱う部分／A/D 変換より後の、数の計算の部分 |
| 信号と雑音のレベル | 増幅しても SN 比は良くならない。信号は、相関をとるまで雑音の下にある |
| LNA | アンテナの直後の、雑音の小さい増幅器。その雑音指数が C/N0 をほぼ決める |
| ドップラー周波数 | 衛星の動きで、届く搬送波の周波数が L1 からずれる量 $`f_\mathrm{D}`$。最大およそ ±5 kHz（代表値） |
| 局部発振器・混合器・中間周波数 | 周波数を移すための正弦波の発振器／2 つの信号を掛ける回路／差の周波数 $`f_\mathrm{IF} = f_\mathrm{L1} - f_\mathrm{LO}`$（例 4.092 MHz） |
| イメージ周波数 | $`f_\mathrm{im} = f_\mathrm{L1} - 2f_\mathrm{IF}`$。その雑音を除かないと、C/N0 が 3.0 dB 下がる |
| TCXO | 温度による周波数のずれを補償した水晶の発振器。誤差 $`r`$ は、全部の衛星に $`-rf_\mathrm{L1}`$ の見かけのドップラーとして入る |
| サンプリング周波数・帯域通過サンプリング | 1 秒に標本をとる回数 $`f_\mathrm{s}`$／$`2f_\mathrm{max}/n \le f_\mathrm{s} \le 2f_\mathrm{min}/(n - 1)`$ を満たす、$`2f_\mathrm{max}`$ より低い $`f_\mathrm{s}`$ での標本化 |
| 量子化の損失 | 標本が独立なとき、1 bit で $`2/\pi`$（−1.96 dB）。この章の例の 2 bit・16.368 MHz では、フィルタの分を合わせて −0.7 dB |
| 局部の搬送波・局部の符号・NCO | 受信機が手元で作る搬送波と符号／標本ごとに $`K`$ を足して位相を作る回路。$`f_\mathrm{NCO} = Kf_\mathrm{s}/2^{32}`$ |
| 相関器・I・Q | 標本に局部の搬送波と符号を掛けて足す回路／cos と sin を掛けた 2 つの出力。$`\sqrt{2C}\,d\,\Lambda(\Delta\tau)\,\mathrm{sinc}(\Delta f\,T_\mathrm{coh})(\cos\overline{\Delta\psi}, -\sin\overline{\Delta\psi})`$ |
| E・P・L | 局部の符号を $`\Delta_\mathrm{EL}/2`$ チップ早めた・合わせた・遅らせた 3 つの相関器。E と L の差で符号のずれが分かる |
| チャネル | 1 つの衛星の信号のための、NCO と E・P・L の組。1 ms ごとに 6 つの数をプログラムに渡す |
| チップとモジュール | RF フロントエンドとベースバンド処理を入れた集積回路／それに TCXO・フィルタなどを加えて 1 つにまとめた部品 |

この章では、相関器の I・Q を、符号と搬送波のずれが分かっているものとして計算した。次章では、受信機が最初はずれを知らない状態から、符号の位相とドップラーを探して衛星の信号を見つける仕組みを見る。これを捕捉という。見つけた後に、E・P・L の I・Q からずれを測って NCO を直し続ける追尾の仕組みも、次章で扱う。
