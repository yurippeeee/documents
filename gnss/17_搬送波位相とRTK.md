# 17. 搬送波位相と RTK — センチメートル級の仕組み

> **この章で扱う問い.**
> 16 章の補正は、擬似距離、つまり符号のずれで測った距離を直すもので、補正の後に残るマルチパスと受信機の雑音のために、精度はメートル級にとどまった。この章では、符号の代わりに、波長 19 cm の搬送波の位相で距離を測る。そのうえで、基準局と移動局の 2 つの受信機と、2 つの衛星で差をとり、センチメートル級の位置を求める方法（RTK）を組み立てる。
>
> この章では次の 3 つの問いに答える。
>
> 1. 搬送波の位相で距離を測ると、符号で測るより何桁細かく測れるのか。その代わりに、何が分からないまま残るのか。
> 2. 2 つの受信機と 2 つの衛星で差をとると、どの誤差が消え、何が残るのか。残った整数の未知数をどう決め、決め誤りをどう避けるのか。
> 3. 基準局の観測を、どんな形で、どう移動局へ届けるのか。初期化の時間・追尾の途切れ・基線長は、使える範囲と精度をどう決めるのか。
>
> 答えの道具は、波長の目盛を数えること、観測方程式の引き算（16 章と同じ）、実数の解に最も近い整数の点を探すこと、そして 2 番目に良い候補との比べである。

## 1. 搬送波位相 — 波長 19 cm のものさし

### 符号の目盛と搬送波の目盛

擬似距離は、受けた符号の遅れを相関の山の位置で測った値で（[2 章 3 節](02_衛星の信号.md#相関-符号のずれを見つける)）、その目盛は C/A 符号の 1 チップ（293 m）である。符号を載せている搬送波も、同じ道を通って、遅れの分だけ位相がずれて届く。L1 の搬送波の波長は $`\lambda`$ = 19.03 cm で、1 チップの間に 1540 周期ある（[2 章 1 節](02_衛星の信号.md#周波数帯-l1-l2-l5-と各衛星系)）。搬送波の位相で遅れを測れば、目盛が 1540 倍細かいものさしになる。

5 章 4 節の PLL は、局部の搬送波の位相を、受けた搬送波の位相に合わせ続ける。ロックしている間、局部の搬送波を作る NCO の値（1 周期を 1 とした端数。[4 章 4 節](04_受信機の中.md#相関器-局部の符号と搬送波を掛けて足す)）は、受けた搬送波の位相を表す。受信機は、局部発振器から作る基準の搬送波（周波数がちょうど L1 の波）の位相から NCO の位相を引いて、受けた搬送波の遅れを読む。衛星までの距離が $`\lambda`$ 延びると、受けた搬送波は 1 周期多く遅れるので、遅れの端数が 1 を超えて 0 に戻る回数を数えれば、追尾を始めてから遅れが何周期増えたかが分かる。PLL が追尾している局部の搬送波の位相を、受信機の基準の搬送波からの遅れとして、周期の端数と、追尾を始めてから数えた周期の数で表した値を**搬送波位相**（carrier phase）という。周期で数えた値を $`\phi`$ [周期]、波長を掛けて距離に直した値を $`\Phi = \lambda\phi`$ [m] と書く。


搬送波位相の変化は、距離の変化を、波長の目盛で直接数えたものである。

### 細かさ — 雑音とマルチパス

熱雑音による位相のずれの揺れは、PLL のループの帯域と C/N0 で決まり（5 章 4 節の式の $`\sigma_\psi`$ [rad]）、距離では $`\lambda\sigma_\psi/(2\pi)`$ である。符号の擬似距離の揺れ（5 章 3 節の DLL の式）と、同じ C/N0・代表的な帯域で比べると、1800 分の 1 ほどになる（次の図の (c)）。

マルチパスでは、PLL は直接波と反射波を足した波の位相に合わせる。反射波の振幅の比を $`\gamma`$、直接波との位相の差を $`\psi_\mathrm{M}`$ とする（[7 章 3 節](07_誤差とDOP.md#マルチパス-反射した電波が混ざる)の記号）。合わせた位相がどれだけずれるかを求める。

**方針**: 直接波を長さ 1、反射波を長さ $`\gamma`$ の矢印（複素数）で表し、和の矢印の角度の最大を、図形で求める。

**導出**: 反射波の矢印は、直接波の矢印の先から始まり、$`\psi_\mathrm{M}`$ が変わると、その先は、直接波の矢印の先を中心とする半径 $`\gamma`$ の円の上を回る。和の矢印の角度 $`\delta`$ は、$`\tan\delta = \gamma\sin\psi_\mathrm{M}/(1 + \gamma\cos\psi_\mathrm{M})`$ を満たす。$`\gamma < 1`$ なら円は原点を含まないので、$`\delta`$ が最も大きいのは、和の矢印が円に接するときである。接する点で、半径（反射波の矢印）は和の矢印に垂直なので、長さ 1 の直接波の矢印を斜辺、長さ $`\gamma`$ の反射波の矢印を $`\delta`$ の向かいの辺とする直角三角形ができ、$`\sin\delta_\mathrm{max} = \gamma`$ である。距離に直すと、誤差の大きさは $`\lambda\arcsin\gamma/(2\pi)`$ を超えない。$`\gamma`$ を 1 に近づけても $`\delta_\mathrm{max}`$ は 90° を超えないので、誤差は $`\lambda/4`$ = 4.76 cm 以下である ∎

```fig

```

$`\gamma`$ = 0.5 の反射波では、搬送波位相の誤差は最大 1.59 cm で、同じ反射波が擬似距離に生む誤差（7 章 3 節で数十 m）の数千分の 1 である。受信機の雑音もマルチパスも、搬送波位相では mm〜cm の大きさになる。この章では、代表値として、精密な測位に使う受信機とアンテナで、開けた空の、1 つの受信機の 1 つの衛星の誤差（マルチパスを含む）の標準偏差を、擬似距離 $`\sigma_\rho`$ = 0.3 m、搬送波位相 $`\sigma_\Phi`$ = 3 mm とする（100 分の 1）。

## 2. 整数値バイアス — 何周期分かが分からない

### 数え始めの周期の数

PLL がロックした瞬間に受信機が知るのは、遅れの 1 周期の端数だけである。衛星から受信機までには 1 億周期あまりの波が並んでいる（2 万 km ÷ 19 cm）が、どの周期も同じ形なので、何周期並んでいるかは位相からは分からない。受信機は、数えた周期の数を、追尾を始めたときに決めた整数（0 や、$`\Phi`$ が擬似距離に近くなる整数。製品による）から数え始める。そのため、搬送波位相は、本当の遅れから、ある整数の周期だけずれる。このずれの周期の数を**整数値バイアス**（integer ambiguity、アンビギュイティ）といい、$`N`$ と書く（3 章の熱雑音の電力の $`N`$ とは別の量である）。追尾が途切れずに続く間、$`N`$ は変わらない。なお、データを載せた信号では、5 章 4 節のコスタスループの 180° の取り違えのため、プリアンブルで直すまでは、半周期の端数も決まらない。

```fig
e17_ambig
```

擬似距離は、本当の距離を、目盛が粗く雑音の大きいものさしで測る。搬送波位相は、距離の変化を mm の細かさで測るが、ものさしの 0 の位置が整数の周期だけ分からない。擬似距離で 0 の位置を絞っても、$`\sigma_\rho`$ = 0.3 m の ±3 倍の幅には 19 cm ごとの候補が 9 個ほど入り、1 つに決まらない。

### 搬送波位相の観測方程式

6 章 1 節では、衛星の時計の補正で直した後の擬似距離を観測方程式に使った。この章では、時計のずれが差で消える様子を見るため、補正する前の擬似距離を、7 章 1 節の源とともに書く（2 章 5 節のとおり、衛星の時計が $`\delta t^\mathrm{s}_i`$ 進んでいると、擬似距離は $`c\,\delta t^\mathrm{s}_i`$ だけ短く測られる）。衛星 $`i`$ の擬似距離と搬送波位相は、同じ記号で

$$
\begin{aligned}
\rho_i &= r_i + b - c\,\delta t^\mathrm{s}_i + I_i + T_i + M_i + \varepsilon_i \\
\Phi_i &= r_i + b - c\,\delta t^\mathrm{s}_i - I_i + T_i + \lambda N_i + \varepsilon^\Phi_i
\end{aligned}
$$

と書ける。$`I_i`$・$`T_i`$ は電離層遅延と対流圏遅延、$`M_i`$・$`\varepsilon_i`$ は擬似距離のマルチパスと受信機の雑音（7 章 1 節の記号）で、$`\varepsilon^\Phi_i`$ は、搬送波位相のマルチパスと雑音をまとめたものである。このほか、受信機と衛星の発振器の初めの位相の端数も入るが、時計のずれと同じく受信機ごと・衛星ごとに共通なので、3 節の二重差で消える。ここでは省く。

```fig
e17_terms
```

距離・2 つの時計のずれ・対流圏の遅れは、2 つの式に同じ量で入る。時計は、符号と搬送波を同じ時刻の基準で作り、同じ基準で測るからで、対流圏の遅れは、L バンドでは周波数によらないからである（7 章 2 節）。違うのは、電離層の項の符号と、整数値バイアスの有無と、誤差の大きさである。

### 電離層は、符号を遅らせ、搬送波の位相を進める

7 章 2 節では、電離層の電子の中で、符号の届く速さが $`c/(1 + 40.3N_\mathrm{e}/f^2)`$ になり、遅れが $`I = 40.3\,\mathrm{TEC}/f^2`$ になることを使い、搬送波の位相は逆に同じ量だけ進んで見える、と書いた。その理由を示す。電子の中では、搬送波の山（同じ位相の点）の進む速さは、真空の中の光の速さより速く、$`c/(1 - 40.3N_\mathrm{e}/f^2)`$ になる（7 章 2 節の式と同じく、電子と電波の相互作用の物理の結果として使う）。この速さで 7 章 2 節と同じ足し合わせをすると、位相で見た道のり（位相の遅れを距離に直した値）は、$`L(f) = r - 40.3\,\mathrm{TEC}/f^2`$ になる。符号の届く時刻がなぜ遅れるかを、この $`L(f)`$ から求める。

**方針**: 周波数が少しだけ違う 2 つの搬送波を足した波は、包絡線（うなり）の形をもつ。符号の変化も、周波数の少し違う成分の重なりでできているので、包絡線の山と同じ速さで届く。包絡線の山が届く時刻を、2 つの波の位相がそろう条件から求める。

**導出**: 周波数 $`f`$ の波は、受信機に $`\cos\{2\pi f(t - L(f)/c)\}`$ の形で届く。周波数 $`f_1`$ と $`f_2`$ の 2 つの波を足すと、2 つの位相が等しい時刻に山が重なり、包絡線が山になる。$`2\pi f_1\{t - L(f_1)/c\} = 2\pi f_2\{t - L(f_2)/c\}`$ を $`t`$ について解くと、

$$
t = \frac{f_2L(f_2) - f_1L(f_1)}{c\,(f_2 - f_1)}
$$

で、$`f_2`$ を $`f_1`$ に近づけると $`t = \dfrac{1}{c}\dfrac{d\{fL(f)\}}{df}`$ となる。$`fL(f) = fr - 40.3\,\mathrm{TEC}/f`$ を $`f`$ で微分すると $`r + 40.3\,\mathrm{TEC}/f^2`$ なので、包絡線（符号）の道のりは $`r + I`$、位相の道のりは $`r - I`$ である ∎

符号の遅れは、7 章 2 節で使った届く速さの式と一致する。周波数の低い成分ほど位相が大きく進むので、2 つの波の山がそろう所は後ろへずれる。これが、位相が進むのに符号が遅れる理由である（次の図）。

```fig

```

$`\Phi_i - \rho_i = -2I_i + \lambda N_i + \ldots`$ なので、搬送波位相と擬似距離の差は、一定の $`\lambda N_i`$ に、ゆっくり変わる電離層の遅れの 2 倍を足したものになる。この差は、6 節で、追尾の途切れを見つけるのに使う。

## 3. 二重差 — 時計の誤差を消す

### 一重差 — 受信機の間の差

16 章の基準局は、擬似距離の補正値を作って配った。搬送波位相を使うときは、基準局も搬送波位相を測り、移動局が、同じエポック（同じ時刻の観測の組）の基準局の観測と差をとる。基準局の量に添字 ref、移動局の量に添字 rov を付ける（16 章 2 節と同じ）。同じ衛星 $`i`$ を同じエポックに 2 つの受信機で観測した値の差（移動局 − 基準局）を**一重差**（single difference）といい、$`\Delta`$ を付けて $`\Delta\Phi_i = \Phi_{\mathrm{rov},i} - \Phi_{\mathrm{ref},i}`$ と書く（この章の $`\Delta`$ は、受信機の間の差の印である）。

**方針**: 2 節の搬送波位相の式を 2 つの受信機について書き、引く。どの項が 2 つの受信機で同じかを調べる。

**導出**: 2 つの式は

$$
\begin{aligned}
\Phi_{\mathrm{rov},i} &= r_{\mathrm{rov},i} + b_\mathrm{rov} - c\,\delta t^\mathrm{s}_i - I_{\mathrm{rov},i} + T_{\mathrm{rov},i} + \lambda N_{\mathrm{rov},i} + \varepsilon^\Phi_{\mathrm{rov},i} \\
\Phi_{\mathrm{ref},i} &= r_{\mathrm{ref},i} + b_\mathrm{ref} - c\,\delta t^\mathrm{s}_i - I_{\mathrm{ref},i} + T_{\mathrm{ref},i} + \lambda N_{\mathrm{ref},i} + \varepsilon^\Phi_{\mathrm{ref},i}
\end{aligned}
$$

である。衛星の時計のずれ $`\delta t^\mathrm{s}_i`$ は、同じ衛星なので、2 つの式で等しい（2 つの電波を送った時刻の差は数 ms 以下で、その間の時計のずれの変わりは無視できる）。引くと $`c\,\delta t^\mathrm{s}_i`$ が消え、

$$
\Delta\Phi_i = \Delta r_i + \Delta b - \Delta I_i + \Delta T_i + \lambda\,\Delta N_i + \Delta\varepsilon^\Phi_i
$$

となる（$`\Delta b = b_\mathrm{rov} - b_\mathrm{ref}`$、$`\Delta N_i = N_{\mathrm{rov},i} - N_{\mathrm{ref},i}`$ は整数の差なので整数）∎

$`\Delta I_i`$ と $`\Delta T_i`$ は、共通の誤差（[16 章 1 節](16_DGNSSとSBAS.md#共通の誤差-近くの受信機は同じ誤差を受ける)）の 2 つの受信機の差なので、基線長が短ければほぼ 0 である。エフェメリスから計算した衛星の位置の誤差も、同じ理由でほぼ消える（16 章 3 節のとおり、軌道の誤差 1 m で、基線長 100 km でも 5 mm 以下）。残る大気の差が基線長とともにどう増えるかは 6 節で見る。一重差に残る時計の項は、受信機の時計のずれの差 $`\Delta b`$ だけで、これはどの衛星の一重差にも同じ量で入る。

### 二重差 — 衛星の間の差

2 つの衛星 $`i`$・$`j`$ の一重差の差を**二重差**（double difference）といい、$`\nabla\Delta\Phi_{ij} = \Delta\Phi_j - \Delta\Phi_i`$ と書く（$`\nabla`$ は衛星の間の差の印で、$`i`$ を基準の衛星と呼ぶ）。

**方針**: 一重差の式を 2 つの衛星について書き、引く。

**導出**: $`\Delta b`$ は衛星によらないので、引くと消える。短い基線で大気の差を 0 とおくと、

$$
\nabla\Delta\Phi_{ij} = \nabla\Delta r_{ij} + \lambda\,\nabla\Delta N_{ij} + \nabla\Delta\varepsilon^\Phi_{ij}, \qquad
\nabla\Delta\rho_{ij} = \nabla\Delta r_{ij} + \nabla\Delta(M + \varepsilon)_{ij}
$$

となる（擬似距離も同じ手順で差をとった）。$`\nabla\Delta N_{ij} = \Delta N_j - \Delta N_i`$ は整数である ∎

```fig
e17_sddd
```

時計のずれは、何 km あっても、引き算で正確に消える。2 節で省いた発振器の初めの位相の端数も、衛星の分は一重差で、受信機の分は二重差で消えるので、二重差の整数値バイアスは整数のまま残る。残るのは、移動局の位置で決まる $`\nabla\Delta r_{ij}`$ と、整数の $`\lambda\,\nabla\Delta N_{ij}`$ と、雑音である。

受信機ごとの誤差（マルチパスと雑音）は、差をとっても消えない。二重差の雑音は、4 つの観測の雑音を +1・−1・−1・+1 の重みで足したものなので、4 つが独立で同じ標準偏差 $`\sigma`$ なら、分散は $`4\sigma^2`$、標準偏差は $`2\sigma`$ である（1 節の例の値で、擬似距離 0.6 m・搬送波位相 6 mm）。同じ基準の衛星を使う 2 つの二重差は、基準の衛星の 2 つの観測を共有するので、共分散が $`2\sigma^2`$（相関係数 0.5）ある。次の図は、数値の例である。

```fig
e17_ddnum
```

衛星が $`n`$ 機見えていると、二重差は $`n - 1`$ 本でき、未知数は、移動局の位置の 3 つと、$`n - 1`$ 個の整数値バイアスである（基準局の位置は分かっている）。移動局を $`\delta\boldsymbol{p}`$ だけ動かすと、$`\nabla\Delta r_{ij}`$ は、6 章 2 節の線形化と同じく、$`-(\boldsymbol{l}_j - \boldsymbol{l}_i)\cdot\delta\boldsymbol{p}`$ だけ変わる（$`\boldsymbol{l}_i`$ は視線の単位ベクトル。基線が短いので、2 つの受信機でほぼ同じ）。

下の図で、2 つの衛星と移動局を動かし、時計のずれと大気の遅れを変えて、一重差と二重差でどの項が消えるかを確かめられる。

## 4. 整数値バイアスを決める — フロート解とフィックス解

### フロート解 — 整数値バイアスを実数として解く

1 エポックの二重差の搬送波位相は $`n - 1`$ 本で、未知数は $`3 + (n - 1)`$ 個あるので、搬送波位相だけでは解けない。そこで、二重差の擬似距離の $`n - 1`$ 本を加え（式は $`2(n - 1)`$ 本になり、衛星が 4 機以上なら未知数の数以上になる）、整数値バイアスをひとまず実数とみなして、重み付き最小二乗法（[6 章 3 節](06_位置を解く.md#最小二乗法-衛星が多いときの解き方)。重みは、3 節の二重差の雑音の共分散から決める）で解く。こうして求めた解を**フロート解**（float solution、実数の解）という。実数として求めた値には ^ を付ける。

解の形を図に描くため、小さな例を使う。移動局は東西に延びた線路の上にあり、基準局から測った東の座標 $`e`$（ENU 座標の東の成分）だけが分からないとする。衛星は 6 章・7 章の東京の G9（基準の衛星）・G6・G22 の 3 機で、整数値バイアスは 2 つ（以下 $`N_6`$・$`N_{22}`$ と書く）である。移動局を東へ $`e`$ 動かすと、二重差の距離は $`g_je`$ だけ変わる（$`g_j`$ は $`-(\boldsymbol{l}_j - \boldsymbol{l}_9)`$ の東の成分。図に値を書いた）。

**方針**: 1 エポックの最小二乗法で、搬送波位相の式が $`e`$ の値を決めるのに使われるかを調べ、整数値バイアスの実数の値の誤差を、位置の誤差で表す。

**導出**: 搬送波位相の 2 本の式は、$`e`$ をどんな値にしても、$`N_6`$・$`N_{22}`$ を選べば満たせる。したがって、最小二乗法の解の $`\hat e`$ は、擬似距離の 2 本の式だけで決まる。その $`\hat e`$ を搬送波位相の式に入れると $`\hat N_j = (\nabla\Delta\Phi_j - g_j\hat e)/\lambda`$ で、$`\nabla\Delta\Phi_j = g_je + \lambda N_j + \varepsilon_j`$（$`\varepsilon_j`$ は二重差の搬送波位相の雑音）を代入すると

$$
\hat N_j - N_j = -\frac{g_j}{\lambda}(\hat e - e) + \frac{\varepsilon_j}{\lambda}
$$

となる ∎

2 つの整数値バイアスの誤差は、同じ位置の誤差 $`\hat e - e`$ に、それぞれ $`g_j/\lambda`$ を掛けたものである。したがって、点 $`(\hat N_6, \hat N_{22})`$ は、本当の整数の点を通り、向きが $`(g_6, g_{22})`$ の直線の近くに並ぶ。直線に沿った広がりは擬似距離の雑音で、直線に垂直な幅は搬送波位相の雑音で決まる（次の図。1 節の例の雑音で計算した）。

```fig
e17_float
```

1 つの値を最も近い整数に丸めたとき、正しい整数になる確率を求める。

**方針**: $`\hat N`$ が平均 $`N`$・標準偏差 $`\sigma_N`$ [周期] の正規分布にしたがうとして、丸めて $`N`$ になる範囲に入る確率を、3 章 6 節の $`Q(x)`$（標準正規分布にしたがう量が $`x`$ より大きくなる確率）で書く。

**導出**: 丸めて $`N`$ になるのは $`|\hat N - N| < 0.5`$ のときである。$`(\hat N - N)/\sigma_N`$ は標準正規分布にしたがうので、外れる確率は、上と下の両側で $`2Q(0.5/\sigma_N)`$ である。したがって、正しく丸まる確率は

$$
P = 1 - 2Q\!\left(\frac{1}{2\sigma_N}\right)
$$

となる ∎

$`\sigma_N`$ = 0.2 周期で 98.8 %、0.15 周期で 99.9 % である（図の (c)）。丸めで決めるには、標準偏差を 0.15〜0.2 周期ほどより小さくする必要がある。例の 1 エポックでは、直線に沿った広がりのために、2 つの実数の値の標準偏差が 1.5〜1.7 周期もあり、2 つを丸めて両方とも正しいのは 23.2 % にとどまる。

### 誤差の楕円に合わせて探す — 整数の最小二乗と LAMBDA 法

点が細い直線の近くに並ぶことは、2 つの値を別々に見るより多くのことを教える。直線に垂直な向きには、点はほとんど散らばらないからである。そこで、整数の組 $`\boldsymbol{a}`$ の候補のうち、

$$
J(\boldsymbol{a}) = (\hat{\boldsymbol{N}} - \boldsymbol{a})^\mathsf{T}\,\Sigma_{\hat N}^{-1}\,(\hat{\boldsymbol{N}} - \boldsymbol{a})
$$

を最も小さくする組を選ぶ（$`\hat{\boldsymbol{N}}`$ は実数の値を並べたベクトル、$`\Sigma_{\hat N}`$ はその誤差の共分散で、最小二乗法の解の誤差の共分散（[7 章 4 節](07_誤差とDOP.md#dop-衛星の並びが誤差を広げる)）の一部として求まる）。$`J`$ は、重み付き最小二乗法と同じ重みで測った 2 乗の距離で、誤差の楕円の形に合わせた距離である。このように、重み付きの 2 乗の距離が最も小さい整数の組を選ぶことを**整数の最小二乗**（integer least squares）という。例では、正しい整数が選ばれる実数の値の範囲は、正方形ではなく、直線に沿って細長い 6 角形になり、正しく決まる割合は 79.3 % に上がる（次の図の (a)。範囲の中の確率を数値で積分した値）。

整数値バイアスが多いと、楕円は高い次元で細長く、全部の候補を調べることはできない。**LAMBDA 法**（least-squares ambiguity decorrelation adjustment。1990 年代に Teunissen が提案した）は、整数値バイアスを、整数の足し引きで作った新しい組（例では $`z_1 = N_6 + N_{22}`$・$`z_2 = 7N_6 + 6N_{22}`$）に置き換え、誤差の相関を小さくしてから探す。整数の足し引きで作った組は整数で、逆の足し引きで元の組に戻せるので、置き換えた組で最も近い整数を探して戻せばよい。相関が小さいと楕円が丸くなり、調べる候補が少なくて済む（図の (b)）。例では、組み替えた後の値をそれぞれ丸めるだけで 79.1 % になり、探した結果とほぼ同じになる。多くの受信機が、この方法か、その変形を使う。

```fig

```

### フィックス解

整数値バイアスを決めた整数 $`\check{\boldsymbol{N}}`$（ˇ は、決めた整数の印）に置き、位置だけを解き直した解を**フィックス解**（fixed solution）という。整数値バイアスが分かれば、二重差の搬送波位相は、mm の雑音で距離を測る式になるので、位置も mm の精度で決まる。例では、フロート解の $`\hat e`$ の標準偏差 0.59 m が、フィックス解では 5.9 mm になる。

ただし、誤った整数に決めると、位置は、搬送波位相の式を誤った整数でも満たすように、まとまった量だけずれる。例の $`(N_6, N_{22})`$ を本当の値から $`(-1, +1)`$ だけ誤ると、$`e`$ は 37.5 cm ずれる。ずれた位置も、雑音は mm のままなので、フィックス解の散らばりを見ても、誤りに気づけない。次の図は、東京の GPS の 6 機で 5 エポックを使った、3 次元の例である。

### 2 番目の候補と比べる — 比の検定

最も小さい $`J`$ を $`J_1`$、2 番目に小さい $`J`$ を $`J_2`$ とする。$`J_2`$ が $`J_1`$ とあまり違わなければ、どちらが正しいかは、はっきりしない。$`J_2/J_1`$ がしきい値（2〜3 が代表値）以上のときだけ整数を決め、そうでなければ、フロート解のまま次のエポックを待つ方法を**比の検定**（ratio test）という。

比の検定は、仮説の検定（[統計学シリーズ 12 章 4 節](../stats/12_仮説検定の枠組み.md#2-種類の誤り)）と同じく、2 種類の誤りの釣り合いで、しきい値を選ぶ。正しい整数を退けると、フィックス解が出るのが遅れ、誤った整数を受け入れると、位置が誤る。しきい値を上げるほど、誤ったフィックスは減るが、フィックス解が出る割合も減る。また、フロート解の誤差が大きいときは、誤った候補が偶然に大きな比をもつことがあり、比の検定を通った解でも誤りの割合が大きい（次の図の 1 エポック）。そのため、受信機は、フィックスした整数が次のエポック以降も式に合い続けるかも確かめる（代表的な方法）。


移動局は、フィックス解を GGA の測位の品質 4 で、フロート解を 5 で出す（[12 章 2 節](12_NMEAを読む.md#主な文-gga-rmc-gsa-gsv)）。[15 章 3 節](15_組み込みでの実装.md#状態の管理-測位の品質と状態機械)の状態機械が、測位の状態をフィックスとフロートの間で入れ替えるとき、悪いほうへすぐ移るのは、誤ったフィックスの位置を使う害が大きいからでもある。

## 5. RTK の構成 — 基準局・移動局・補正の配信

### RTK

基準局が、搬送波位相と擬似距離の観測値と、自分の座標を、エポックごとに移動局へ送り、移動局が、自分の同じエポックの観測値と二重差を作り、整数値バイアスを決めて、フィックス解をその場で出す方法を **RTK**（real-time kinematic、リアルタイムキネマティック）という。キネマティックは、移動局が動いていてもよいことを表す（動かずに長く記録し、後でまとめて解く測量の方法と区別する名前である）。DGNSS（16 章）が衛星ごとの補正値を送るのに対し、RTK では観測値そのものを送り、移動局の側で差を作る（16 章 5 節）。

```fig
e17_rtk
```

### 基準局の 3 つの選び方

- 自分で置く: 座標の分かった点に受信機を置く。16 章 6 節のとおり、基準局の座標の誤差は、向きも大きさもそのまま移動局の位置の誤差になるので、cm 級の位置には、基準局の座標も cm より細かく、使う側と同じ座標の基準で決めておく必要がある。
- 電子基準点: 国土地理院が全国に置いている、GNSS の連続観測点を**電子基準点**という。国土地理院の発表では、全国に約 1,300 点、約 20 km の間隔で置かれ、1996 年から観測網として運用されている。観測データは、離島などを除き 1 秒ごとに国土地理院の中央局へ集められ、2002 年からは、配信の機関を通じて、民間の事業者にリアルタイムで提供されている（どれも書いた時点の発表による）。
- ネットワーク型 RTK: 移動局のまわりの複数の基準局（電子基準点など）の観測から、場所による大気と軌道の誤差の分布を求め、移動局の場所に合わせた観測値や補正を作って配る方式を**ネットワーク型 RTK** という。代表的な方式の 1 つは、移動局のすぐ近くに仮の基準局（仮想基準点）を置いたとして、その観測値を計算して送る。移動局は、自分のおおよその位置を GGA の文で送る。実際の基準局が遠くても、近くに基準局がある場合と同じように、大気の差が小さくなる。配信のサービスには、公的なものと商用のものがある。

### 観測値を送る形 — MSM

RTCM の版 3（[16 章 5 節](16_DGNSSとSBAS.md#補正情報の形式-rtcm)）では、基準局の座標を 1005（アンテナの高さも送るときは 1006）で、観測値を MSM で送る。衛星ごと・信号ごとの擬似距離・搬送波位相・C/N0 と、追尾が途切れずに続いている時間の目安（ロックの時間）、半周期の端数が決まったかの印などを、衛星系ごとに 1 つのメッセージにまとめた、版 3 の観測値のメッセージを **MSM**（multiple signal messages）という。中身の多さで MSM1〜MSM7 があり、GPS の MSM4 は 1074、MSM7 は 1077 である（Galileo・みちびき・BeiDou はそれぞれ 1094・1114・1124 など）。ロックの時間は、基準局の側で追尾が途切れたかを移動局が知るのに使う（6 節）。メッセージの大きさは衛星と信号の数で決まり、1 秒に 1 回送るなら、多くても 1 秒に 1 kB あまりである（次の図の (a)。公開されている解読のプログラムの欄の表で数えた）。

### インターネットで流す — NTRIP

インターネットで RTCM の流れを配るための決まりを **NTRIP**（Networked Transport of RTCM via Internet Protocol）という。RTCM の規格（RTCM 10410。版 2.0 は 2009 年）になっていて、要点は 16 章 5 節で見たとおりである。基準局の側は、観測の流れを、名前（マウントポイント）を付けてキャスタに送り、移動局は、HTTP の要求でマウントポイントを指定して、TCP のコネクションの上で流れを受け続ける。ネットワーク型 RTK では、移動局が、同じコネクションで自分の GGA の文をキャスタへ送る。自分で置いた基準局からは、無線機で送ることも多い。

### 通信の遅れと更新の周期

基準局の観測値は、移動局に届くまでに、通信の遅れ（携帯電話の回線で 0.1〜1 s ほど。代表値）だけ古くなる。移動局は、同じエポックの観測がそろうのを待って解くか、届いている最新の基準局の観測を今のエポックまで延ばして使う。待つと、位置の遅れ（[13 章 3 節](13_バイナリプロトコルと設定.md#設定-出力-更新レート-通信速度)）に通信の遅れが足される。延ばして使うと、遅れは増えないが、基準局の観測の古さ（補正の年齢。[16 章 3 節](16_DGNSSとSBAS.md#補正の年齢)）の分だけ、衛星の時計と大気の変わりの誤差が加わる。移動局の更新レートを 5 Hz や 10 Hz にしても、基準局の観測が 1 秒に 1 回なら、延ばして使う方式で間を埋める（図の (b)）。GGA の 13 番の欄には、DGNSS と同じく補正の年齢が書かれる。年齢が決めた限度（製品と設定による）を超えると、移動局はフロート解か単独の解に戻る。

## 6. RTK の実際 — 初期化の時間・サイクルスリップ・基線長

### 初期化の時間

移動局が観測を始めてから（または追尾が途切れた後から）、整数値バイアスが決まってフィックス解が出るまでの時間を**初期化の時間**という。4 節のとおり、整数値バイアスの実数の値の広がりは、主に擬似距離の雑音で決まり、エポックを重ねて平均すると縮む。ただし、マルチパスの誤差は数十秒〜十分ほど続く（7 章 3 節）ので、続けて測ったエポックの誤差は独立ではなく、平均しても思うほど縮まない。一方、衛星が多いと、二重差の式が増え、1 エポックでも楕円の細い向きが増える。次の図は、東京の仰角 10° 以上の衛星で、L1 だけの受信機の初期化をシミュレーションした例である。

```fig
e17_init
```

例のモデルでは、マルチパスが続くと、GPS だけの 6 機ではなかなか決まらないが、GPS・Galileo・みちびきの 19 機なら 1 エポックで決まる（図の (b)）。代表値として、L1 だけの受信機の初期化の時間は、衛星の数と周りの環境で、数秒から数分まで変わる。複数の周波数を使うと、さらに短くなる（[18 章 2 節](18_多周波とPPP.md#多周波の受信機とアンテナ)）。

### サイクルスリップ

ビルや木や橋で電波が一瞬さえぎられたり、C/N0 が下がったり、急に動いたりして、PLL のロックが外れると、受信機は追尾をやり直す。やり直した後も端数は正しく測れるが、途切れた間に何周期進んだかは分からないので、数えた周期の数が整数だけ跳ぶ。追尾の途切れなどで、数えた周期の数が整数だけ跳ぶことを**サイクルスリップ**（cycle slip）という。跳ぶと、その衛星の整数値バイアスが変わるので、前の整数を使い続けると、フィックス解は cm〜dm だけずれる。

```fig
e17_slip
```

見つけ方の要点は 3 つある。1 つ目は、2 節の $`\Phi - \rho`$ を見ることで、跳んだ周期の数 × 19 cm の段ができる。擬似距離の誤差より大きな段（例の値で数周期以上）は見つかるが、1〜2 周期の段は誤差に埋もれる（図の (b)）。2 つ目は、測ったドップラー周波数から、途切れた間の位相の進みを予想して比べることで、途切れが短ければ小さな段も見つかる。3 つ目は、2 つの周波数の搬送波位相を組み合わせる方法で、18 章で扱う。基準局の側の途切れは、MSM のロックの時間で知る（5 節）。見つけたら、その衛星の整数値バイアスだけを決め直す。ほかの衛星の整数値バイアスが決まったままなら、決め直しは速い。

### 基線長

3 節では、短い基線で、大気の遅れの差を 0 とおいた。16 章 3 節のとおり、2 点の大気の遅れの差は、近い所では基線長にほぼ比例して増える。その比例の係数は電離層の状態で大きく変わり、電離層の二重差に残る誤差は、代表値として、静かなときに 1 km あたり 1〜2 mm（1〜2 ppm）で、活発なときにはその数倍になる。対流圏の差は、2 つの受信機の高さがそろっていれば小さいが、高さの差が大きいと増える。残った大気の差は、フロート解を本当の整数からずらすので、基線長が長いほど整数が決まりにくくなり、誤った整数に決まりやすくなる。決まった後も、その差はそのままフィックス解の誤差になる。次の図は、初期化の時間の例と同じモデルに、二重差の電離層の誤差を足して調べた例である。

```fig
e17_baseline
```

例のモデルでは、整数が決まる基線長は、1 km あたりの電離層の差にほぼ反比例して縮む（図の (a)）。RTK の受信機の精度は、「水平 1 cm + 1 ppm」のように、一定の部分と基線長に比例する部分を足した形で書かれることが多い（値は代表的な例。1 ppm は基線長 1 km ごとに 1 mm）。代表値として、L1 だけの RTK が使えるのは基線長 10 km ほどまで、2 つの周波数を使う RTK は数十 km までである（18 章）。ネットワーク型 RTK（5 節）は、移動局の近くの大気の差を基準局の網から求めるので、近くに基準局が無くても、短い基線と同じように使える。

## 7. まとめ

| 項目 | 内容 |
|---|---|
| 搬送波位相 | PLL が追う局部の搬送波の位相を、受信機の基準の搬送波からの遅れとして、周期の端数と、追尾を始めてから数えた周期の数で表した値。$`\phi`$ [周期]、$`\Phi = \lambda\phi`$ [m]。L1 の目盛は 19.03 cm で、1 チップの 1540 分の 1 |
| 細かさ | 熱雑音は 45 dB-Hz・15 Hz で 0.67 mm（符号の 1800 分の 1）。マルチパスは $`\lambda\arcsin\gamma/(2\pi)`$ 以下で、$`\lambda/4`$ = 4.76 cm を超えない。代表値は擬似距離 0.3 m・搬送波位相 3 mm |
| 整数値バイアス（アンビギュイティ） | 追尾を始めたときに分からない、整数の周期の数 $`N`$。追尾が続く間は変わらない |
| 観測方程式 | $`\rho_i = r_i + b - c\,\delta t^\mathrm{s}_i + I_i + T_i + M_i + \varepsilon_i`$、$`\Phi_i = r_i + b - c\,\delta t^\mathrm{s}_i - I_i + T_i + \lambda N_i + \varepsilon^\Phi_i`$。電離層は、符号の道のりが $`r + I`$、位相の道のりが $`r - I`$（包絡線が $`d\{fL(f)\}/df`$ で届くため） |
| 一重差・二重差 | 同じ衛星を 2 つの受信機で観測した値の差（衛星の時計のずれが消える）／2 つの衛星の一重差の差（受信機の時計のずれも消える）。$`\nabla\Delta\Phi_{ij} = \nabla\Delta r_{ij} + \lambda\nabla\Delta N_{ij} + \ldots`$。雑音の標準偏差は 2 倍 |
| フロート解 | 整数値バイアスを実数として、二重差の擬似距離と搬送波位相から最小二乗法で解いた解。整数値バイアスの誤差は、共通の位置の誤差を通して強く相関する |
| 丸めの確率 | $`P = 1 - 2Q(1/(2\sigma_N))`$。0.2 周期で 98.8 %、0.15 周期で 99.9 % |
| 整数の最小二乗・LAMBDA 法 | 重み付きの 2 乗の距離 $`J`$ が最も小さい整数の組を選ぶこと／整数の足し引きで相関を減らしてから探す方法。例で、丸めの 23.2 % に対して 79.3 % |
| フィックス解 | 決めた整数を使って位置を解き直した解。例で 0.59 m → 5.9 mm。誤った整数でも散らばりは小さく、気づきにくい |
| 比の検定 | 2 番目に良い候補との比 $`J_2/J_1`$ がしきい値（2〜3）以上のときだけ整数を決める方法。2 種類の誤りの釣り合いで、しきい値を選ぶ |
| RTK | 基準局の観測値と座標を送り、移動局が二重差を作って、フィックス解をその場で出す方法。GGA の品質 4（フィックス）・5（フロート） |
| 電子基準点・ネットワーク型 RTK | 国土地理院の GNSS の連続観測点（約 1,300 点・約 20 km 間隔。書いた時点）／複数の基準局から、移動局の場所に合わせた観測値や補正を作って配る方式 |
| MSM・NTRIP | RTCM 版 3 の観測値のメッセージ（GPS の MSM4 は 1074）／インターネットで RTCM の流れを配る決まり |
| 初期化の時間 | 観測を始めてから整数値バイアスが決まるまでの時間。衛星が多いと 1 エポック、少なくマルチパスが続くと数分（例のモデル） |
| サイクルスリップ | 追尾の途切れなどで、数えた周期の数が整数だけ跳ぶこと。$`\Phi - \rho`$ の段・ドップラーからの予想・2 周波（18 章）で見つける |
| 基線長 | 二重差に残る大気の差は基線長にほぼ比例する（電離層は静かなとき 1〜2 ppm。代表値）。精度は「1 cm + 1 ppm」の形で書かれることが多い |

この章の RTK は、L1 の 1 つの周波数で考えた。初期化の時間・サイクルスリップ・基線長のどれにも、2 つ以上の周波数を使うと効く。次章では、2 つの周波数で電離層の遅れを消す組み合わせと、基準局を使わずに精密な軌道と時計の補正情報で cm〜dm を目指す PPP を扱う。
