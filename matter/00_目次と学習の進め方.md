# 00. 目次と学習の進め方

## このシリーズの狙い

**Matter** は、Connectivity Standards Alliance (CSA) が策定したスマートホーム機器の接続標準である。
2022 年 10 月に 1.0 が公開され、Apple・Google・Amazon・Samsung をはじめとする主要エコシステムが揃って対応した。

Matter を「開発する」とき、必要になる知識は驚くほど広い。

- **IPv6 とネットワーク**（Thread / Wi-Fi / Ethernet、mDNS、マルチキャスト）
- **データモデル**（Endpoint / Cluster / Attribute という抽象化）
- **公開鍵暗号と PKI**（証明書チェーン、SPAKE2+、SIGMA）
- **組み込み実装**（SDK のビルド、ZAP、Factory Data、省電力）
- **認証と製品化**（VID/PID、DAC の量産時注入、テストハーネス）

**どれか 1 つを知っていれば作れる、という代物ではない。**
そしてどの層も、「なぜそうなっているか」を知らないまま触ると必ず詰まる。

このシリーズは全 24 章で、これらを**下から順に積み上げて**説明する。
各章にはブラウザ上で動かせるツール（オンボーディングコードのエンコーダ、TLV コーデック、
ACL 判定器、chip-tool コマンドビルダーなど）を置いた。仕様書を読む前後に触ってほしい。

> **重要な前提: 仕様書が唯一の正である.**
> Matter は活発に更新されている標準である。このシリーズは概念と全体像を掴むためのものであり、
> **実装の細部は必ず、対象バージョンの仕様書と SDK のソースで確認すること**。
> 各章では「仕様書のどこを見るか」を可能なかぎり示す。

## 読み方

- **順番に読むのが基本**。特に 02 章（用語の地図）と 03 章（IPv6）は後の全章で前提になる。
- **手を動かせる環境を先に作るのも有効**。15 章の SDK ビルドと 20 章の chip-tool を先にやり、
  「動くもの」を見てから 07〜14 章に戻ると、抽象的な話が具体的に見える。

### 目的別の近道

| 目的 | ルート |
|---|---|
| とりあえず動かしてみたい | 01 → 02 → 15 → 20 |
| 自社製品を Matter 対応させたい | 01 → 02 → 07 → 08 → 13 → 15 → 17 → 22 |
| コミッショニングでハマっている | 03 → 06 → 12 → 13 → 21 |
| 既存機器をブリッジしたい | 02 → 07 → 08 → 19 |
| アプリ／コントローラを作りたい | 02 → 06 → 09 → 10 → 14 → 20 |

| ぜんぶ | 01 → 24（推奨） |

## 前提知識

| 分野 | 必要な水準 |
|---|---|
| ネットワーク | TCP/IP の基本。IPv6 は 03 章で必要な範囲を説明する |
| 暗号 | 公開鍵暗号・ハッシュ・署名の「何をするものか」。詳細は 11 章で補う |
| C/C++ | デバイス側を実装するなら必須。SDK は C++ |

| ビルドツール | GN / Ninja / CMake に触れたことがあると楽 |

## 記法の約束

| 表記 | 意味 |
|---|---|
| `0x0006` | クラスタ ID・属性 ID は 16 進で表記する |
| Endpoint 0 | ルートノード。ユーティリティクラスタが載る特別なエンドポイント |
| **SHALL / SHOULD / MAY** | 仕様書の要求レベル（RFC 2119）。SHALL は必須 |
| 「仕様書」 | Matter Core Specification（特記なければ最新の安定版を想定） |

> **仕様書の入手.** Matter の仕様書（Core Specification / Application Cluster Specification /
> Device Library Specification）は CSA のサイトから**無償で公開**されている。
> 会員でなくてもダウンロードできる。**手元に置いて、常に参照しながら読み進めてほしい。**
> このシリーズはあくまで「仕様書を読むための地図」である。
